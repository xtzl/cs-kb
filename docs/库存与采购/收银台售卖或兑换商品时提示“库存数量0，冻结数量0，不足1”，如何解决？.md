# 问题描述：

收银台售卖或兑换商品时提示“库存数量0，冻结数量0，不足1”，如何解决？

报错如图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf0904ae07e0e&type=max)

# 解决办法：

1、检查商品剩余库存数量以及所在仓库
到后台--商品--仓储查询--库存查询，查询一下该商品的库存数量以及库存所在仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf0937d857e10&type=max)

2、检查收银台终端绑定的售卖仓库，
收银台左下角查询绑定仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf099bced7e16&type=max)

或者到后台--设置--收银设置--收银终端---检查收银台终端绑定的售卖仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf09acfb47e17&type=max)

3、如果收银终端绑定的售卖仓库跟商品剩余库存的仓库不是同一个的话，需要通过调拨单调拨到收银终端绑定的售卖仓库；

操作路径：商品--仓储管理--调拨单，点击新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf09f6c2e7e1b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf0a2e8017e28&type=max)

4、如果需要更换收银台售卖仓库的话
操作方法：在后台--设置--收银设置--收银终端，选择收银台终端，点击编辑，修改售卖仓库。注意：修改好之后收银台需要重新登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf0a5f7367e2f&type=max)
