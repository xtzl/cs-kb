# 应用场景
当门店想调整入库、出库、盘点的审核流程设置时，可参考此教程进行设置。

# 操作流程、
路径：仓库→仓库基础设置

#### 进入【仓库基础设置】界面，找到【是否自动审核采购单、入库单、调拨单、出货单、退货单】的设置，将设置设置为“否”，点击【保存】完成设置；此时，上述的单据完成录入后都需要手动审核一次才生效库存。
