# 应用场景
如果入库单中的商品成本价填写错误了，并且已经保存入库完成了，那应该如何修改？

# 操作流程
路径：仓库→入库单

#### 进入【入库单】界面，点击需要修改的入库单
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826523191-fd8cf300-707a-4abb-837a-67fdfff591c3.png)

#### 点击右下角【取消审核】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826547581-509cd94b-1f80-47cd-8085-e3dcd1d90cea.png)

#### 出现提示时，点击【确定】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826569977-aa6af672-93a6-4d35-96b8-b92985760744.png)

#### 此时入库单变成可编辑状态，这时候就可以修改对应的数量和金额，点击保存完成修改
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826632831-3fcfe2ac-43f7-48a8-b4c2-59793a35bea6.png)
