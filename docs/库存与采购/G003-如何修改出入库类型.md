# 操作路径

后台--商品--仓储管理--出入库分类管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9ea713a02c9c&type=max)

# 操作步骤

- 点击仓储管理中的出入库类型管理

- 点击新增

- 填写相关参数

- 保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9eaa10e22c9e&type=max)

# 注意事项
必填项：分类编号、分类名称。
命名出入库类型名称可参照常规出入库发生原因摄制。
