# 操作路径

后台--商品--仓储管理--仓库设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3a49ba92dc2&type=max)

# 操作步骤

- 点击仓储管理中的仓库设置

- 点击新增或者选择一项进行编辑

- 填写相关数据

- 保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3a9f98f2dda&type=max)

# 注意事项
必填项：仓库编号、仓库名称、启用仓库下限提醒、库存下线值。
已有库存的仓库无法删除。
