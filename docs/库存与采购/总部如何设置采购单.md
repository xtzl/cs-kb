# 应用场景
总部所属连锁门店的商品库存统一由总部管控，由总部负责给门店采购商品，当商品发货到门店，再由门店仓管人员清点到货数量，根据采购单做入库

# 操作流程
总部后台-->采购-->采购单-->新增采购单

1.进入系统后台，找到采购单新增路径

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722327945848-6f1a597b-5030-4fc0-bcbb-18e5a5464df1.png)

2.选择指定的门店、采购商品的供应商、采购的商品及数量，点击保存，完成采购单。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722328338023-5c566ced-152a-4b9f-8476-3597207fcca1.png)

3.保存采购单之后的提示，点击【确定】即可

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722328574279-d7fe1237-4474-47bb-b0dd-668112b6b270.png)

4.总部采购单完成生成后，当采购的商品到门店之后，**<font style="color:#DF2A3F;">登录门店后台，</font>**门店可直接引用生成入库单，将采购的商品进行入库

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722328847911-bc73074a-3c36-499c-9a14-4b2df2c22c2d.png)
