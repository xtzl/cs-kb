# 应用场景
门店如果有多个仓库，并且需要将某商品从一个仓库调拨到另外一个仓库，可按照下面操作进行查询

# 操作流程
路径：仓库→调拨单

#### 点击【新增】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826054265-8827e302-3dbe-4f58-b05a-18291e76fddd.png)

#### 选择【转出仓库】以及【转入仓库】，并在【从模板导入】、【从商品列表】或【商品编码】一栏中找找到你需要调拨的商品，添加后商品后，输入本次调拨的数量，点击【保存】完成调拨
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826366853-d5162512-6a34-48ba-88dc-7fda88a14782.png)
