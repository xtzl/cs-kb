# 🔴报表说明
此报表用于查询仓库每个月的结存情况。（需要每月盘点后，手动结存才会有数据）可查询每个商品在对应的月份中的入库数量、入库金额、出库数量、出库金额等数据。

# 🔴报表样式
路径：后台→财务→财务报表→出入库结存表
