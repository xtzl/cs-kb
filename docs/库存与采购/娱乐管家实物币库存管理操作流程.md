# 一、使用场景

实物币作为电玩城日常经营中的核心流通载体，其规范管理不仅是保障场所正常运营、精准核算营收的基础工作，更是防范内部损耗、杜绝舞弊风险、提升服务体验与运营效率的关键环节，对电玩城实现安全有序经营、控制成本、维护长期稳定发展具有重要且现实的必要性。

# 二、基本流程图

## 1. 源头管控：采购与主仓管理

• 采购实物币：实物币的起点，分为初次开业采购和后续补充采购，采购后需完成入库操作，进入实物币主仓。

• 实物币主仓：全场实物币的核心库存中枢，承担「总控」职能：

o 入库：接收采购新币、回收旧币；

o 调拨 / 加币：向兑币机 / 柜台售币机分配运营用币；

o 盘点：定期核对账实，保障库存准确。

## 2. 前端流通：兑币与玩家使用

• 兑币机（自助售币机 / 柜台售币机）：连接主仓与玩家的关键节点，接收主仓调拨的币后，通过「客户取币」将实物币交付给玩家。

• 玩家端流转：

o 玩家取币后，通过「投币游玩」将币投入机台，完成消费；

o 游玩后剩余的余币，可选择存入存币机，或继续在机台使用；

## 3. 闭环回收：机台清币与主仓回流

• 机台：玩家消费的核心载体，接收投币后，定期通过「收币、盘点」完成清币，清出的币统一入库回流至实物币主仓，完成全流程闭环。

# 四、执行步骤

## 场景一：实物币（初次购货/收币/二购买次入库）入库

### 场景说明

所有的实物币采购，都需要通过入库步骤进行入库，来完成库存的建立。后续从机台回收的游戏币也需要通过入库重新回到门店仓库里面

#### 第一步：盘点实物币，并按1袋1000币分袋装好，并放到仓库

说明：可以用数币机或者用电子称来数好数量，然后用袋子装好，方便后续加币时使用。

#### 第二步：在系统中录入本次入库的数量

路径：后台-仓库-入库单-新建

入库仓库选择【实物币主仓】，入库商品编码（商品名称）搜索【实物币】，并按照本次实际入库数量填写入库数量。单价可填0或者实际成本价。然后点击保存和审核通过，完成入库。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7dd57abc&type=med)

同理：从机台回收的币，也同样按照这个流程来执行。

## 场景二：自助兑币机、柜台售币机缺币时，需要给设备进行加币。

#### 场景说明

当兑币机、柜台售币机等实物币设备缺币时，需要对设备进行加币，此时则需要在给机台倒入实物币同时，也要在系统执行加币的步骤。

#### 执行步骤

第一步：从仓库那里领取对应数量的游戏币，并倒入到机器中。

第二步：在系统中录入本次加币的数量

录入方式有几种：

第一种（所有设备通用）：在收银台直接给自助兑币机和柜台售币机录入加币数量

路径：收银台-更多-加币清币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7ddd7abd&type=med)

第二种（兑币机专用）在对币机后台，直接录入加币数量。

路径：长按自助兑币机右上角齿轮-进入设置界面-输入本机管理密码-选择【加、清币】-点击【加币】-输入加币数量-确认

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7de37abe&type=med)

第三种（收银台柜台售币机专用）在收银台直接点击右上角售币机图标进行加币

路径：收银台-右上角兑币机图标-加币-填写加币数量-点击确认完成加币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7de97abf&type=med)

## 场景三：存币机回收实物币情况

#### 场景说明

当存币机达到一定数量的时候，需要将存币机里面的币进行回收入库，并需要在系统中记录回收了多少币。

第一步：将存币机的币倒出来，并用数币机盘点清楚，然后用币袋装好送回仓库。

第二步：在系统上录入本次从存币机的币的数量，完成币回收操作。

路径：收银台-更多-加币清币-输入回收币的数量，点击确定完成回收（存币机显示的库存数量有可能有轻微差异，需要把存币机里面的币单独清点后，在收银台存币机清币功能里面填写实际清点的数量，后台回自动生成清币记录）

注意：回收后的币，会自动调拨会实物币主仓库，无需额外任何操作。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb5be866402e9&type=med)

## 场景四：定期对设备里面的实物币进行盘点，修正差异（自助售币机/柜台售币机）

#### 场景说明：

建议门店定期对各个自助设备的实物币实际数量进行盘点，并同步到系统。由于机台里面可能有各种原因（例如加币的时候少了，币导入设备里面时掉出来了等等原因）会导致里面的实物币实际数量和系统数量不一致，所以需要通过盘点来修正数量。

特别说明：系统中的清币指的是清点币数，清币后需要将币倒回设备里面。

情况一：给自助兑币机盘点币数量

步骤一：准备一个较大的币桶放置到出币口下方，并安装兑币机币道配件将币引流到桶里面

步骤二：长按兑币机右上角齿轮-设置-输入本机管理密码-点击【加、清币】-点【清币】-等待所有币都清出来后，点确认完成清币，并将所有实物币倒回到机台中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7ded7ac0&type=med)

情况二：为柜台售币机进行清币

步骤一：准备一个较大的币筛放置到出币口下方用于接币

步骤二：收银台-右上角兑币机图标-设备清币-开始清币-等待清币完成后，需要把币放回兑币机里面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb49d7df37ac1&type=med)
