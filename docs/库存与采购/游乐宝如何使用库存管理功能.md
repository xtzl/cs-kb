# 一． 仓库管理

## 1. 仓库管理：新增或者删除系统里的仓库

## 2. 路径：商品--仓储管理--仓库设置--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef19cfba0f2b&type=max)

进入新增仓库信息界面填写仓库名称，仓库类型，点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef19eb770f2c&type=max)

保存之后，即可在仓库设置界面查看到新增的仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef19fd5e0f2e&type=max)

## 3. 常见问题：

问题1

场景：仓库没有库存也可以售卖商品

解决：在新增仓库的时候把允许负库存勾选上

# 二． 出入库分类管理

## 1. 出入库分类管理：出入库原因，方便场地通过出入库分类查看出入库

## 2. 路径：商品--仓储管理—出入库分类管理--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a17960f2f&type=max)

进入新增出入库分类信息界面填写分类名称，出入库类型点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a2a740f30&type=max)

保存之后，即可在出入库分类管理界面查看到新增的出入库分类

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a40e90f33&type=max)

# 三． 入库单

## 1. 入库单：给商品添加库存

## 2. 路径：商品--仓储管理--入库单--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a60870f34&type=max)

进入新增入库单信息界面选择仓库，入库分类，点击商品编码旁的“+”号添加商品输入商品入库的数量，点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a80260f36&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1a958e0f37&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1aa7460f38&type=max)

保存之后，即可在入库单管理界面查看到新增的入库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1ac3b00f39&type=max)

## 3. 常见问题

问题1

场景：入库单添加商品的时候数量填写错了并点击了新增

解决：在商品--仓储管理--入库单--找到对应的入库单，点击进去点击取消审核即可重新修改入库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1ad9e90f3a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1aebf00f3b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1afdea0f3c&type=max)

# 四． 出库单

## 1. 出库单：破损过期的商品减少库存

## 2. 路径：商品--仓储管理--出库单--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b13530f3f&type=max)

进入新增出库单信息界面选择仓库，出库分类，点击商品编码旁的“+”号添加商品输入商品出库的数量，点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b27690f40&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b378a0f42&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b4b5d0f43&type=max)

保存之后，即可在出库单管理界面查看到新增的出库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b5e520f44&type=max)

## 3. 常见问题：

问题1

场景：出库的时候商品数量输入错误

解决：在商品--仓储管理--出库单--找到对应的出库单，点击进去点击取消审核即可重新修改出库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1b765b0f45&type=max)
