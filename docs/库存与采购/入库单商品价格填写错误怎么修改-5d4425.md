入库单商品价格填写错误怎么修改

应用场景

如果入库单中的商品成本价填写错误了，并且已经保存入库完成了，那应该如何修改？

操作流程

路径：仓库→入库单

1. 进入【入库单】界面，点击需要修改的入库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b0b4d3ab1&type=med)

2. 点击右下角【取消审核】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b0b553ab2&type=med)

3. 出现提示时，点击【确定】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b0b5a3ab3&type=med)

4. 此时入库单变成可编辑状态，这时候就可以修改对应的数量和金额，点击保存完成修改

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b0b5f3ab4&type=med)
