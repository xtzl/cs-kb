# 游戏卡片读卡器
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1779098222821-c975dc3f-64ea-4064-9e16-90a3fa3df4b1.png)

### 设备安装：
通电即用，无需做任何配置

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1780021221481-65e9cc3d-238c-4eeb-bb7e-4a8fe27c3c34.jpeg)

### 应用场景：
部分机台奖励会出特定的卡片，顾客可通过回收转化成门店储值奖励，相当于增多一种游戏玩法，也可以增加集卡片活动，玩家可收集多张卡片兑换终极大奖

### 流程说明：
回收卡片商品设置（业务系统后台操作）-> 卡片激活->卡片出库，分发到对应机台中去->顾客游玩获得卡片->收银台回收，转换成储值->回收的卡片会自动入库



### 使用前置条件：
1.系统版本：10.4.3296及以上版本

2.卡片机及相关回收卡片需要从油菜花采购，暂不支持第三方卡片。

###### 回收卡片商品设置：

卡片激活完成后，将这批卡片出库投放到各个机台上

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1780021458256-fccce37a-6343-4952-9357-e5f47a345c64.png)

###### 卡片回收：
顾客游玩机台获取卡片奖励后，可将卡片拿到收银台来进行回收
