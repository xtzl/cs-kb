# 应用场景
当需要盘点仓库里的商品时，应该如何操作？

# 操作流程
路径：仓库→快速盘点

#### 在【快速盘点】中，点击【新增】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826683234-9b02e65d-0802-4d0c-ae9c-0d360d1bb80a.png)

#### 在【盘点单信息】中，选择你要盘点的仓库，并通过【盘点仓库全部商品】、【从商品列表选择】以及手动填写需要盘点的商品来选择选择你盘点的商品，选择完毕后，在右边【盘点数量】中填写对应的数量。最后点击【保存】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826836506-48a6713f-14d3-42f1-8c74-8eddea32f305.png)
