# 一、作业说明

本文旨在用于指导自助售货机的安装

# 二、外观展示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018a838662924122&type=max)

# 三、安装准备

1. 十字螺丝刀*1
2. 放置位置预留设备电源

3. 现场预留给设备使用的无线网络

4. 读卡器*1

5. 会员卡*1

6. 提前准备好服务器连接域名地址（该设备只支持域名连接）

7. 手机*1

8.系统版本：游乐宝8.1.6404以上，娱乐管家10.3.4453以上

# 四、安装标准

1.自助售货配件安装到位（顶部发光字）

2.自助售货机天线垂直立正

3.自助售货机地脚已固定

4.自助售货机连接系统正常，功能能正常使用（包括加货功能、兑换功能以及售货功能均正常）

5.培训客户使用售货机（包括如何加货、如何更换货物和如何兑换使用）

# 五、注意事项

1.售货机运输要求会将货道用扎带进行固定，安装前需要将扎带全部清理完毕

2.售货机重量比较重，请至少两个人以上进行搬运，避免发生倾倒

3.由于售货机网络要求较高，请提供专用无线网络给予售货机使用，避免因为无线网络不稳定导致功能异常

# 六、作业步骤

## 第一步：配件安装

配件清单：发光字

1.发光字

售货机顶部有发光字，直接安装到顶部即可，并接入预留电源即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d21749360f8&type=max)

2.天线

顶部天线将其树立

3.地脚

将地脚打到底，使售货机不摇晃

## 第二步：现场网络设置

### 情况一：现场无线网络可自定义，且支持长wifi名，则可使用自动连接wifi的连接方式进行设置，不需要使用配置卡进行配置

1.在后台生成通用WIFI

路径：游乐宝后台→设置→卡头wifi通讯→通用配置卡

在【通用配置卡】界面，点击【重新设置通讯网络】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910cf1de626041&type=max)

2.选择【外场】，并输入域名地址，一般域名地址为：y********.yun.youcaihua.net，端口为88，然后点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910cf3c939604f&type=max)

3.点【生成自动连接WIFI】，这里会自动生成特定wifi名称和密码，注意不要修改生成的WIFI名称和密码，直接将自动生成的WIFI名称和密码配置到现场给售货机使用的网络设备中。此界面点击下一步，完成设置。

特别提醒：该设备WIFI只支持2.4G网络，所以需要将WIFI中的双频合一功能关闭掉

网络配置参考可参照以下配置文档：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910cf92c1e606d&type=max)

《游乐宝/娱乐管家云服务器网络调试文档，适用范围：油菜盒子》

《游乐宝/娱乐管家本地服务器网络调试文档，适用范围：油菜盒子（低配版AP方案）（本地服务器）》
《游乐宝/娱乐管家本地服务器网络调试文档，适用范围：油菜盒子（中配版AP方案）（本地服务器）》
《游乐宝/娱乐管家本地服务器网络调试文档，适用范围：油菜盒子（高配版AP方案）（本地服务器）》
《游乐宝/娱乐管家网络调试文档，适用范围：油菜盒子（无线方案）（云服务器、本地服务器通用）》

4.点击【服务器地址同步到游智云】完成网络设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d036bf26098&type=max)

### 情况二：现场无线网络不可自定义，或者使用不支持长wifi名设备（锐捷/锐易），则可设置自定义WIFI名称连接，并需要读卡器写配置卡
现场网络配置步骤如下：
1.修改后台通用配置卡信息

路径：设备→基础设置→卡头 wifi 通讯设置→通用配置卡

在【通用配置卡】界面，选择【重新设置通讯网络】，并选择【外场】，输入服务器域名地址，一般域名地址为：y********.yun.youcaihua.net，端口为88，然后点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018a83af0eda4152&type=med)

输入现场给予售货机使用的无线网络名称和对应的连接密码，点下一步。

注意：此WIFI需要符合以下要求

a.无线WIFI需要是2.4G无线网络，并且不支持双频合一功能，如现场网络开启了双频合一功能需要关闭掉。

b.此无线WIFI名称和密码不能有符号和中文，必须纯英文或者纯数字或者是英文加数字组合。

c.无线WIFI需要能通外网

d.无线WIFI不能是隐藏网络

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d0cf9af60ba&type=max)

点击同步至游智云，完成现场网络配置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d11e9bb60c7&type=max)

## 第三步：售货机联接网络

说明：

当现场为上一步骤情况一，则售货机会自动联网进入到带配置过程，可跳过此步骤；

当现场为上一步骤情况二，则售货机需要刷通用配置卡才能联网，请按照下述步骤进行操作。

1.将空白卡放置到读卡器上，并在通用配置卡界面，点【网络参数写入配置卡】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d19262060d7&type=max)

2.用十字螺丝刀卸掉背面的防尘网，拉出通讯盒子,并将售货机进行通电。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d1710f860d3&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019110ba209c6847&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019110ba21a96848&type=med)

3.将读卡模块接入到通讯盒子，并长按通讯盒子的设置键5~10秒后将刚刚写好的配置卡放置到读卡模块中进行读取。联网成功后，盒子会显示【电源】【联网】【强度】都常亮绿色灯，【待机】显示红色闪烁。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910d1ccde960e3&type=max)

# 七、常见问题

1.自助售货机兑换后不出货

答：一般因为售货机没有联网或者联网失败导致，检查盒子连接情况，如果连接成功，盒子应该是【电源】【联网】【强度】【待机】等都亮绿色灯，且不会灭；网络强度弱则【强度】为黄色灯；

2.顾客扫码后，提示设备离线，如何处理？

解决：

如果是WiFi版售货机，检查当地网络是否稳定，WIFI是否覆盖到位；

以上检查了无误后，再检查下售货机设备里边的盒子状态，看下盒子是否正常。

3.顾客扫码支付后，货道不出货或者出错货品。

解决：

检查游乐掌柜后台货道上架是否设置错误，库存是否不足。

4.售货机的库存能否直接通过入库单进行补货？

答：不可以，只能通过游乐掌柜补货。

5.使用测试货道时，商品掉落下来后，会减少系统库存吗？

答：不会，所以需要将商品放回去。
