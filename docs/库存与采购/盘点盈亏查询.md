# 🔴报表说明
此报表用于查看每次盘点盈亏情况，所有盘点记录都可以通过此业务查询，包括统计某一时间段的盈亏总金额等数据都可以查询汇总出来，如需查询该明细请通过此业务查询。

# 🔴报表样式
路径：后台→仓库→仓储报表→盘点盈亏查询
