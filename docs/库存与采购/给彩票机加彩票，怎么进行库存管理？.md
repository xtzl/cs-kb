给彩票机加彩票，怎么进行库存管理？

应用场景

门店如果想通过系统来精准把控彩票的库存，可通过此操作来管理。

操作流程

路径：仓库→机台库存管理→彩票机

1. 在【机台库存管理】中，选择【批量调拨彩票】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea791d3d39bb&type=med)

2. 选择你从哪个主仓库中调拨彩票，并在【彩票商品编号】中选择系统中的“彩票”这个商品，如果没有这个商品，需要在【零售商品】界面中新增并且进行入库。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea791d4239bc&type=med)

3. 在端口号一栏中，点【+】好选择对应的机台P位（即机台仓库），点解【保存】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea791d4639bd&type=med)

4. 输入对应加彩票的数量，点击【保存】完成添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea791d4c39be&type=med)
