# 操作路径

后台--商品--仓储查询--历史库存查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3afc15c2df3&type=max)

# 操作步骤

- 点击商品

- 点击仓储查询

- 点击历史库存查询

- 选择账期

- 点击查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3b1479e2df6&type=max)

# 注意事项
根据自己已知的商品、仓库信息进行关键词搜索，能够加快速度。
