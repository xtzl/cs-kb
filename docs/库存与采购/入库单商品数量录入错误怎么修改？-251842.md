入库单商品数量录入错误怎么修改？

应用场景

当我们使用入库单入库时，不小心录入错数量，应该怎么来修改？

操作流程

路径：仓库→入库单

1. 进入【入库单】界面，点击需要修改的入库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b82123ae2&type=med)

2. 点击右下角【取消审核】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b82173ae3&type=med)

3. 出现提示时，点击【确定】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b821c3ae4&type=med)

4. 此时入库单变成可编辑状态，这时候就可以修改对应的数量和金额，点击保存完成修改

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea7b82203ae5&type=med)
