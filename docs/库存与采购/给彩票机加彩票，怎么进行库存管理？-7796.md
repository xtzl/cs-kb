# 应用场景
门店如果想通过系统来精准把控彩票的库存，可通过此操作来管理。

# 操作流程
路径：仓库→机台库存管理→彩票机

#### 在【机台库存管理】中，选择【批量调拨彩票】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830658373-efe85c98-b240-4645-9809-19d9798edc12.png)

#### 选择你从哪个主仓库中调拨彩票，并在【彩票商品编号】中选择系统中的“彩票”这个商品，如果没有这个商品，需要在【零售商品】界面中新增并且进行入库。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717831606570-f95fee27-03fa-4178-bad8-479fc9569d1c.png)

#### 在端口号一栏中，点【+】好选择对应的机台P位（即机台仓库），点解【保存】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717831667594-6cae4c25-f189-4676-be09-ae59c87512e4.png)

#### 输入对应加彩票的数量，点击【保存】完成添加
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717831757532-080d2310-963e-470a-8da6-ce73a6d1fe16.png)
