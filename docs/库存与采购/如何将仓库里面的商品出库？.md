# 应用场景
当门店需要将商品出库，或者去掉部分商品在系统的库存，可按照下述的说明进行操作。

# 操作流程
路径：仓库→出库单

#### 在【出库单】界面中点击【新增】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717826938574-0a844632-55c6-4b8f-aa4c-a58f74101e05.png)

#### 选择你要出库的商品所在的仓库，并选择对应的【出库类型】，出库商品可通过【从模板导入】【从商品列表中添加】、【添加仓库所有商品】或者直接填写“商品编码”“商品名称”来添加需要出库的商品，并在【数量】一列中填写对应要出库的数量，点击【保存】完成出库。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717827058652-b1699e2a-ae1f-4f56-92d4-3cc76b030be7.png)
