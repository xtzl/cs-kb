# 应用场景
盘点机支持对礼品进行快速入库，出库以及盘点，本教程则用于说明。

①当门店采购的礼品到货后，如何使用盘点机进行快速入库。

②当门店的礼品遇到需要出库的场景（如活动领用等），如何用盘点机进行出库。

③当门店例行进行库存盘点，如何用盘点机进行盘点。

# 操作流程
## 礼品入库
##### 场景一：有采购单情况下
操作步骤：选择本次入库的采购单→选择入库数量默认显示值→调整入库数量→选择需要入到哪个仓库→完成入库

<font style="color:#DF2A3F;">注意事项：入库时，系统会自动按照采购单的单价作为成本价进行入库。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786692609428-006f894f-9dd0-4fe6-9ea8-e0b00091ea3e.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786692650561-b680e0f6-1330-48f5-a813-876146b3ff08.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786692690932-2861c1d5-6250-4d03-bc45-eaa17db3c313.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786692758935-ce265bcc-055c-4e65-80b2-887c93c4e812.png)

##### 场景二：礼品直接入库到仓库
操作说明：

在商品入库界面→通过扫码枪扫条形码→输入入库成本及数量→选择要入到哪个仓库以及入库类型→完成入库

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786693887124-1269d8c0-0451-40f2-b18f-a131667264b4.png)

注意事项：如果商品编码与条形码不一致，也可以采用手动输入商品名称、商品编码等形式找到需要入库的商品。

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786693952510-7ff048a8-37d4-46cd-adb5-5cc7fc6c6f9a.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786694027200-a34e0cfc-348d-4636-b8da-7e33a95d9964.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786694078657-43c7f11e-72cc-4e89-8d48-0a587f5ce183.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786694118730-51bfd048-3ab0-440e-aaf6-fbbd4e189895.png)

##### 其他场景：可在盘点机查看已入库的入库单，支持未审核的入库单进行审核

## 日常盘点
##### 场景说明：为了保证库存准确，建议定期对门店库存进行盘点。
第一步 进入盘点界面，选择需要盘点的仓库

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787195500356-93d12b09-a9fc-4877-94d3-73666b31bfcc.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275267042-1962191d-c429-4b24-a0d8-18d8f9b92cac.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275302883-13368b3b-a696-4885-badc-0ba0555f97f0.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275321470-3e5b830b-5047-45a1-988b-d953b2e39a49.png)

第二步 对盘点目标库进行锁库（锁库后该仓库无法进行任何的入库出库调拨动作）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275369024-2553d7be-b3bc-48b4-a1d3-333ce8300d56.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275407021-d7631826-3c89-421e-8d80-3ff4c2e09a81.png)

第三步 点击【盘点】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275440158-987629e1-b9d0-40c7-be4f-a1ab41840530.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275457398-e557dde3-c7f1-4842-9a88-19cdbf0feddc.png)

第四步 选择是盘点所有，还是盘点单个商品

小技巧：POS机对准商品条码并按下侧面键，则可以快速添加商品。并结合第五步的录入数量的步骤，可以实现快速找到商品并完成数量盘点的动作。

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1787275598021-9d019f22-0c5d-4b42-9af2-a929ebfa1b1d.png)

# 常见问题
1. 为什么我的POS机里面没有盘点功能

答：普通的POS机是没有该功能，需要盘点机才有。

2. 为什么盘点是我这边没有显示系统库存数量

答：需要在后台→仓库→仓库基础设置→**<font style="color:rgb(19, 19, 20);">盘点结果录入是否显示库存数量</font>**→选择显示
