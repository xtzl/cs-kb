# 应用场景
总部所属连锁门店的商品库存统一由总部管控，由总部负责给门店采购商品并直接做入库，门店不再需要在商品入库操作

# 操作流程
总部后台-->采购-->入库单-->新增入库单

1.进入系统后台，找到入库单新增路径，点击【新增】，选择要入库的门店

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722330334875-ba396157-d0bc-419e-8416-ed556a30af84.png)

2.填写入库单信息，填入入库商品库存数量，点击保存

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722330667473-90709775-0396-4527-8b59-4aaa2b79c3de.png)

3.保存成功，即成功给该门店指定仓库加入了商品库存

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722330829440-44cac1cc-a19a-4b17-871e-d3208e4d5b77.png)

4.可切换到门店后台，查看到该商品入库数据。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722333441633-ec36a2af-0d93-43e1-9ab8-feb3093f19b8.png)
