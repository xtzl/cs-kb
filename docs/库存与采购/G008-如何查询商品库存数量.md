# 操作路径

后台--商品--仓储查询--库存查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa32447cb2d84&type=max)

# 操作步骤

- 点击商品

- 点击仓储查询

- 点击库存查询

- 输入商品名称

- 点击查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa326e5492d87&type=max)

# 注意事项
可以选择不显示数量为0的商品
