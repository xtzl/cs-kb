# 应用场景
连锁总部下有多家连锁门店，当A门店商品库存不足时，而B门店商品库存充足，可申请从B门店借调库存到A店

注意：该功能会涉及总部下2家门店的调拨审核，**<font style="color:#DF2A3F;">且调拨商品必须是总部商品</font>**

# 操作流程
门店A发起调拨申请-->门店B接收申请并同意-->门店B审核并作跨店出库-->门店A接收调拨单做调拨入库

### 调拨申请
门店A发起调拨申请，申请从门店B借调商品

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722331969271-0bcd8e95-32fa-483d-a7b0-201c2805fed7.png)

填入借调的商品信息

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332048929-92d67756-fe7c-46c1-b09b-d2e727d79f56.png)

新增成功之后，可在此处查看到调拨申请单

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332195856-6840ff24-af62-4e2d-b02c-222083aefb04.png)

### 调拨审核
跳转到门店B，可在仓库--【调拨审核】查看到门店A发起的调拨申请单，点击查看

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332245213-93fbe43d-1fcb-45ac-9c26-e5147179c317.png)

核实数量无误后，点击【审核】确认

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332293566-6a480072-c137-44e9-8994-76dbd1644a35.png)

可在审核描述处填写审核备注，描述调拨商品出借缘由

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332316375-19614369-6362-4baa-93bb-638a78d9ea42.png)

点击【是】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332336757-126f5f9d-ed19-4276-8a10-82810417a836.png)

选择出库仓库，将出借调拨商品库存减掉，核实无误后，点击确认，至此门店B调拨审核完成

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722332386965-27acf71e-ff8b-429e-a5f3-6435904acdbd.png)

### 调拨出库
门店B同意调拨后，可在该路径下找到对应的调拨申请单，选择要出库的仓库生成出库单，将调拨商品库存出掉，后续门店A才可申请调入，将调拨商品进行入库。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723711433552-e462d9b3-5787-4922-a6f2-9bb4c99b6eee.png)

### 调拨入库
门店B同意调拨后，在门店A仓库-【调拨入库】可查看得到申请的调拨入库单，点击【确定入库】，可将借调的商品库存录到门店A指定仓库。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723708027334-aa34804f-9ae0-4f29-9da8-3601a151ced1.png)

选择录入的指定仓库，点击确定入库

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723708231542-202eaf24-ca9f-40cb-ba88-065d497e3735.png)
