# 一、作业说明

本文旨在用于指导自助售货机的安装

# 二、外观展示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52c936d1f&type=med)

# 三、安装准备

1. 十字螺丝刀*1
2. 放置位置预留设备电源

3. 提前准备好服务器连接域名地址（该设备只支持域名连接）

4. 手机*1

5.系统版本：游乐宝8.1.6404以上，娱乐管家10.3.4453以上

# 四、安装标准

1.自助售货配件安装到位（顶部发光字）

2.自助售货机天线垂直立正

3.自助售货机地脚已固定

4.自助售货机连接系统正常，功能能正常使用（包括加货功能、兑换功能以及售货功能均正常）

5.培训客户使用售货机（包括如何加货、如何更换货物和如何兑换使用）

# 五、注意事项

1.售货机运输要求会将货道用扎带进行固定，安装前需要将扎带全部清理完毕

2.售货机重量比较重，请至少两个人以上进行搬运，避免发生倾倒

# 六、作业步骤

## 第一步：配件安装

配件清单：发光字

1.发光字

售货机顶部有发光字，直接安装到顶部即可，并接入预留电源即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52d996d20&type=med)

2.天线

顶部天线将其树立

3.地脚

将地脚打到底，使售货机不摇晃

## 第二步：同步服务器地址

路径：娱乐管家后台→卡头WIFI通讯

在【通用配置卡】界面，点击【重新设置通讯网络】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52da36d21&type=med)

2.选择【外场】，并输入域名地址，一般域名地址为：y********.yun.youcaihua.net，端口为88，然后点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52eba6d22&type=med)

3.这里点击【生成自动连接WIFI】然后直接点保存完成设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b33b326d0f&type=max)

4.点击【服务器地址同步到游智云】完成网络设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52ec26d23&type=med)

在【智能终端】界面中点击【新增】，选择【自助售货机】并填写设备盒子码

展示如图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b52fbf6d25&type=med)

4. 找到刚才创建的项目，设置售货机仓库，及自助售货机货道，如图所示：

设置售货机仓库：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b530976d26&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b5319f6d27&type=med)

设置货道数量，请根据实际情况选择，一般为36货道6*6；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b532a56d28&type=med)

设置售货方式，支持仅购买（只支持微信支付）、仅兑换、或者两者都支持

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b532ac6d29&type=med)

下载消费二维码：

5. 将该消费二维码打印出来，并贴于售货机上

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b534096d2b&type=med)

6.在后台设置小程序支付（如有可跳过）

路径：后台→财务→支付方式

在【支付方式】中，点击【新增】，在支付类型中选择“小程序支付”，并填写支付名称，保存该支付方式。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b535136d2c&type=med)

## 第四步：新建售货机需要上架的商品并添加库存到仓库

说明：一般门店会将售货机库存单独设置一个仓库进行管理，当门店采购商品回来后，会先入到门店主仓库，只有在售货机缺货时才通过系统调拨的功能调拨到售货机仓库，以下流程为采购入库到门店主仓库的流程。

1.后台设置零售商品，设置定价及初始化库存。（新商品适用，已有商品请直接看第5点）

商品设置路径：商品→零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b536f86d2d&type=med)

2.单个商品可以以这种方式进行设置。

点击【新增】，填写按照下面信息进行填写

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b538156d2e&type=med)

3.若商品数量多的话，也可以以批量导入的形式进行商品资料录入。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b538fb6d2f&type=med)

4.下载好模版之后，将商品资料按照模版的格式导进系统，如图：

注意：导入不支持商品图片导入

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53a116d30&type=med)

5.后续库存可通过入库单进行入库补充到门店仓库

路径：仓库→入库单

点击【新增】添加入库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53a1a6d31&type=med)

按照下述信息填写入库单，点击保存完成入库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53afe6d32&type=med)

## 第五步：给员工开通售货机补货权限

1.员工需要提前新增好账号（不要求管理员权限）

路径：后台→设置→用户管理

点击新增，给员工添加新账号，已有系统登录账号可跳过此步骤

注意：此位置需要将联系电话也要填上，而且此电话需要和员工微信的手机号一致

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53c0e6d33&type=med)

2. 开通游乐掌柜账号，并勾选授权【仓管】功能

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53d216d34&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53e336d35&type=med)

3. 登录游乐掌柜账号关联的手机微信，在程序搜索栏，搜索【游乐掌柜】，点击自助售货机功能，进行补货入仓；

微信搜索游乐掌柜：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b53f156d36&type=med)

若该手机微信是已经关联后台且开通了游乐掌柜功能，则登录进去即可看到【售货机补货】功能，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b540286d37&type=med)

## 第六步：上架货物/补货

1. 打开售货机，将货道架用力往上提，提上之后稍微用力往下拖动，再依次在货道架上上架商品。

注：若需要调整货道空间（有时候饮料占地空间过大），可拽紧货道弹簧一端，稍微用力往后拖动，顺时针方向旋转，以此调整货道间隔。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b540326d38&type=med)

2.货物放置后，在系统上进行补货数量填写，打开游乐掌柜，选择【售货机补货】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b5413e6d39&type=med)

3.选择相应货道，进行上货：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b541456d3a&type=med)

4.后台设置好零售商品，在弹窗口搜索该商品，进行货品上架

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b542586d3b&type=med)

5.上架完毕后将售货机门关闭即可。

## 第七步：更换货物

在游乐掌柜中，选择对应的货道，并点击【更换商品/货回主仓】可以进行商品变更

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b542616d3c&type=med)

## 第八步：补货

在游乐掌柜上选择对应的货道，输入需要补货的数量，点击加货即可完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b543346d3d&type=med)

# 七、常见问题

1.自助售货机兑换后不出货

答：一般因为售货机没有联网或者联网失败导致，检查盒子连接情况，如果连接成功，盒子应该是【电源】【联网】【强度】【待机】等都亮绿色灯，且不会灭；网络强度弱则【强度】为黄色灯；如果出现网络异常，找到盒子，打开替换一下sim上网卡测试是否上网卡出现异常。

通讯盒子位置如下：

用十字螺丝刀卸掉背面的防尘网，拉出通讯盒子

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b544516d3f&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b544596d40&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019111b544626d41&type=med)

2.顾客扫码后，提示设备离线，如何处理？

解决：

同问题1解决方法

3.顾客扫码支付后，货道不出货或者出错货品。

解决：

检查游乐掌柜后台货道上架是否设置错误，库存是否不足。

4.售货机的库存能否直接通过入库单进行补货？

答：不可以，只能通过游乐掌柜补货。

5.使用测试货道时，商品掉落下来后，会减少系统库存吗？

答：不会，所以需要将商品放回去。
