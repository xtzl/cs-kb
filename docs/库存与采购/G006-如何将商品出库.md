# 操作路径

后台--商品--仓储管理--出库单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa2d009d02d43&type=max)

# 操作步骤

- 点击仓储管理

- 点击出库单

- 点击新增

- 填写相关单据信息

- 保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa2ce82462d42&type=max)

# 注意事项
必选项：仓库、出库单号、出库类型、商品编码、数量。

- 所有单据可以点击【导出单据】来导出已选定的出库单。

- 未审核的单据可通过点击入库单号或者勾选后点击【编辑】来修改相关信息。也可以点击【删除】来删除未审核单据。
