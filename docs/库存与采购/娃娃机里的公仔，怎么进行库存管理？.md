# 应用场景
当门店想通过系统管控娃娃机库存时，可按照下述操作进行管理

# 操作流程
路径：仓库→机台库存管理→礼品机  


#### 在【机台库存管理】界面中，给每个礼品机创建仓库  
点击同步礼品机仓库
#### 在【机台库存管理】界面中，选择礼品机，并点击【批量调拨礼品】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830240857-b183bba3-0ee8-4cfb-a768-6c2a3562a454.png)

#### 先选择礼品原来所在的仓库
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830287898-a4ff1eba-4c88-44c4-b654-7d136fdad73e.png)

#### 点击图中的【+】号，添加需要在哪台设备中添加礼品
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830335448-32f560d1-9e5e-4d4f-9dad-182b409882fe.png)

#### 选择本次需要添加礼品的P位
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830396735-c4d60cb8-2122-4652-abcc-a39905a89c6f.png)

#### 点击图中的【+】号，或者通过输入商品名称的方式来选择需要添加的礼品
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830454216-390f1ff3-be9c-486e-9cde-91e455ea003c.png)

#### 选择本次需要放多少个礼品到此机台（注意，此步骤的意义是从你第一步选择的仓库中将礼品调拨到这个机台独立的仓库里面），并点击【保存】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830496398-9f8caf0c-2224-4b11-8ddb-291feb1e8399.png)

#### 确认对应的礼品增加数量是否无误，如无错误点击【确认】即可
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830541585-67f4ab44-fcaf-44a5-af76-ba2ee1f66b1f.png)

#### 此时可通过此界面查看到当前的机台对应的礼品库存。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717830565978-ddaaad17-ca40-4ee0-90d2-a1938d009b0b.png)
