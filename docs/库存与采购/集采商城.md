# 功能亮点：
1、多个源头礼品厂家入驻合作，省去寻找货源的烦恼；

2、礼品资料支持自动同步到油菜花系统，礼品采购，资料建档，入库一站式搞定；

3、基于门店采销数据，可自动生成动态采购模型；

4、AI分析各门店滞销与畅销品趋势；

5、智能库存预警，降低损耗，提升资金周转

# 实例场景：
1、连锁总部/单店运营中有礼品采购需求，由采购者在线上商城挑选完礼品后，发起采购申请，总部/单店管理员审批并付款；

2、审批完成后，礼品资料支持自动同步到油菜花系统，无须仓管人员单独创建采购单；

3、门店可根据完成审批的采购单进行入库；

4、总部/单店管理员可实时监管整个采购环节，避免出现人为偷减费用的情况。

**安全库存： **当门店商品库存低于设置安全库存值时，二期需求优化完成后，系统将会自动进行采购补货，会自动帮门店采品，生成确认给相关负责人确认，如若选品不符预期，则可另行选择。

**关联集采平台商品分类：**

该商品分类并非系统后台设置的商品分类，也并非的采购店铺界面的采购商品分类，而是供应商平台后台的商品分类（有油菜花方自定义，供应商平台后台无法修改），关联上后，后续采购补货会自行从对应的集采平台商品分类中选中礼品进行填补采购。

## 注意事项：
### 采购订单如何对接到油菜花系统？
1.1、游乐宝：暂不支持，可以通过excel导入（商家提供excel模板）

1.2、娱乐管家：下单后，根据选择收货地址的门店自动推送到系统，可在采购看板里查看订单和物流进度

1.3、<font style="color:#DF2A3F;">选择收货地址时，务必要选择门店的地址，否则订单无法推送</font>（可以找客服补推送订单）

如果找不到门店地址？可通过绑定改门店的手机报表或开通改门店的游乐掌柜即可

新增收货地址：用于不关联油菜花系统的，其他系统的客户下单使用。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1742270292883-4ac34c04-1f4e-43be-aa67-a2d5f8b6ccfa.png)

1.4、商品结算的优惠券并非系统后台所派发的优惠券，而是供应商后台所派发的优惠券。

### 商品退货
如果选购的商品中含残次品需退货，则需单独在系统做出库单修正对应的数据
