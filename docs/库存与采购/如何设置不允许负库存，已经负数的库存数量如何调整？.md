# 应用场景
如果想将仓库设置为不允许负库存，可通过这个操作流程进行设置。

# 操作流程
路径：仓库→仓库设置

#### 在【仓库设置】中，选择需要修改的仓库，找到【允许负库存】的设置，去掉勾选，点击【保存】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718789132131-a6d32fcf-8b8f-4382-84ce-a89f069993cd.png)

已经是负库存的商品，正常使用入库功能填平负库存即可正常使用。
