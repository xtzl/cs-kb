# 应用场景
当门店有自己的IP产出并可作为供应商给予分销商卖货时，可通过出货单进行售卖出货

# 操作流程
路径：后台→仓库→出库单

点击【新增】选择新增出货单

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723625627239-d40eb231-ff51-44c9-a4cb-c45b41ad8877.png)

按照下图填写出货单，点击确认进行出货![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723625996898-edcabe3e-5a71-40af-8a56-805b5d8b6721.png)

假如客户买了这批货后有部分需要退货，需要通过退货单进行退货

路径：后台→仓库→退货单

点击【新增】退货单

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626112660-9bddbc6a-9a39-4709-81f6-b22ba32d07f0.png)

按照下图选择退货的客户和退回的商品重新进回哪个仓库，并点击【从出货单列表中添加商品】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626248337-fb2aa3d9-0733-48f0-9e55-c8242dc2211e.png)

选择出货单

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626300317-a39b25d1-4102-415e-9569-a9a2e8da40d4.png)

选择需要退货的商品，并输入退货数量和退货原因备注，点击保存

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626376364-08c3cfdf-24c2-4781-b836-cf49aea66432.png)

确认无误后点击保存完成退货

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626420038-c6234ef6-a03b-4317-be74-5e20087414dd.png)

# 如何查询出货单出货记录
路径：后天→仓库→仓储管理→出货记录查询

通过【出货记录查询】界面，可查询出货明细、退货明细以及按客户汇总相关出货数据

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723626680704-6b36d6dc-6f3d-4cff-94b8-2d17d2a63f62.png)
