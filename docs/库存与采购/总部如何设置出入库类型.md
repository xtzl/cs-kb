# 应用场景
门店出入库原因统一规范化，由总部统一设置，后续所属门店直接引用

**<font style="color:#DF2A3F;">注意：系统做出入库单时，出入库类型设置属于必填项</font>**

# 操作流程
总部后台-->采购-->出入库类型管理-->新增

1.进入系统总部后台，找到出入库类型管理设置，新增出入库类型

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547840547-d54ebcae-ca45-4b90-8134-12173ec876c2.png)

2.类型分为出库、入库类型，分类名称即出入库缘由，可根据门店实际情况填写

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547922432-3a5f064e-a056-4444-85d5-5481c975926a.png)
