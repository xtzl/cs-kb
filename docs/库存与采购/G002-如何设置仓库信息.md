# 操作路径

后台--商品--仓储管理--仓库设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9def1bec2c4b&type=max)

# 操作步骤

- 仓储管理中的仓储设置

- 点击新增

- 填写相关参数

- 保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9e79504b2c75&type=max)

# 注意事项
必选项：仓库编号、仓库名称。非必选项：仓库地址、允许负库存、主仓库、启用下限提醒。
点击【编辑】或【删除】可修改或者删除仓库参数设置。已有库存的仓库无法删除。

点击【实物币主仓】可手动修改实物币仓库。
