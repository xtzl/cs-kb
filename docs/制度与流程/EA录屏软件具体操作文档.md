# 一. 文档说明

本文档主要说明远程培训流程中，需要录制视频提供给客户，需要使用到EV录屏软件进行视频录制

# 二. EV录屏软件安装

## 2.1 EV录屏软件

EA录屏软件下载链接：https://www.ieway.cn/evcapture.html

## 2.2 EV录屏软件安装流程

1.复制EV录屏软件下载地址到浏览器，按回车键下载EV录制程序安装包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195cb2d62053e6f&type=max)

2.双击下载成功的EV录制程序安装包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195cb2df88f3e71&type=max)

3.安装EV录屏软件到电脑上

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195cb2ec8183e73&type=max)

4.点击EV录屏软件，打开录屏软件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195cb2fac953e75&type=max)

# 三. EV录屏软件录屏流程

1. EV录屏软件打开之后，录制区域选择全屏录制，录制音频选择麦和系统声音

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c7857eee31c5&type=max)

2.点击EV录屏右下角开启按钮，开始录屏

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c786cc453214&type=max)

3.点击开始录屏后，屏幕会出现倒计时，倒计时结束EV录屏软件开始录屏

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c78924f232a6&type=max)

4.录屏开始之后，电脑右下角会有一个悬浮球，可以点击悬浮球结束屏幕录制或暂停屏幕录屏

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c789fca532d1&type=max)

5.录屏结束之后，点击录屏文件后面的更多可以查询录屏文件保存的位置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c78c5849335f&type=max)

# 四. EV录屏软件常见问题

问题1：录屏没有声音

解决：EV录屏录制音频设置中没选择麦和系统声音

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c78d9e7133a6&type=max)

问题2：录制的视频画面不全

解决：录制区域没有选择全屏录制

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c78f0c8c33fc&type=max)
