# 一、 作业说明

新版娱乐管家刷配置卡时，需安装油菜花助手及配置网页参数，方可进行正常的配置卡刷卡

# 二、 作业准备

#

1.下载安装油菜花助手
2.修改网页配置参数

# 三、 注意事项

1.必须要用到谷歌浏览器；

2.新版娱乐管家后台只能用网页端打开，没有后台安装程序。

# 四、 作业标准

配置卡能刷卡成功

# 五、 配置流程

## 安装油菜花助手

1.打开系统后台，下载油菜花助手

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2ac1f8138e7&type=max)

2.双击下载的油菜花助手

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2ae29ff38f3&type=max)

3.运行并安装油菜花助手

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2afdd5538f5&type=max)

4.检查油菜花助手版本是否是0.0.2版本以上的

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2b09b7a38f9&type=max)

5.成功安装后运行，点击完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2b0f72138fc&type=max)

## 配置浏览器参数

1.将 chrome://flags/#block-insecure-private-network-requests 地址复制粘贴到浏览器上，按回车

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2b326883905&type=max)

2.修改配置参数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2b618da390e&type=max)

准备工作完成后，成功刷配置卡如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cf2bc99953955&type=max)

# 六、常见问题

1.

问题：按照流程配置完成后，还是刷不了配置卡。

解决：检查是否同时开启了收银台
