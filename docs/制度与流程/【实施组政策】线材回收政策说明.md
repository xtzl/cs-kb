# 政策说明

安装卡头时往往剩余非常多的线材，为了充分利用资源，并返利给客户，降低客户安装成本，即日起（2025年3月31日），正式落地线材回收政策。

# 内容说明

1.所有线材回收，必须获得客户同意才能回收，严禁未经客户同意回收线材。

2.所有回收的线材必须是未使用未拆封才可以回收。

3.回收回来所需要的运费，由客户或者技术自行商议确定，到付一律不收。

4.回收线材所获得的收益，待收货后次月月底统一结算到客户银行卡账户中。实施人员可从中获得佣金，佣金同样直接结算到银行卡中。

# 流程说明

1.现场技术协助客户对回收的线材类型、数量进行盘点并打包好。

2.现场数量盘点后，通过钉钉OA审批-【线材回收审批流程】进行相关信息填写，并与客户确认后由客户签字确认，且告知回收金到账时间一般为次月月底统一结算。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195dc32bfc01dac&type=max)

3.提交流程后，安排寄回，并找到自己的流程，在后续流程中填写快递单号。

4.工厂安排质检后入库，并调整实际入库数量后，完成流程

5.次月由实施组组长提交审批并发放回收款项以及佣金。

# 注意事项

回收线材仅指配套线材，赠送线材不计入到回收数量范围；比如说，客户场地有100个卡头，如果发过去的线材有110条，那多出来的10条不计入回收范围内，属于赠送部分，需要回收，但依然计算技术支持的佣金部分。此部分内容需要与客户解释清楚！
