# 一. 文档说明

本文档主要明确月度专项培训的培训流程和培训要求，目前月度专项培训只针对新版娱乐管家系统

# 二. 培训主题

## 2.1 客户需求问题调研

1）技术当月上门或者远程培训的客户，技术将专项培训调查表发客户群进行调研

2）系统后台发布对应的z专项调查表，让客户自行填写

3）答疑群发布调查表，引导客户填写

## 2.2 培训主题确认

1）根据客户填写的需求问题调研，选择调查报表最多的开展专项培训

2）每次月度培训增加系统当月新功能发布的讲解

# 四. 专项培训

### 4.1 培训准备

工具准备：腾讯会议 https://meeting.tencent.com/download/

### 4.2 培训链接

专项培训的腾讯会议链接必须提前一个小时发送到培训答疑群和钉钉工作群，通知客户提前进入腾讯会议参加培训

### 4.3 培训开始

1）设置腾讯会议全体静音，避免在培训过程中有客户发出其他声音打扰

2）在培训开始前需告知客户在培训过程中保持安静，有疑问先进行记录，等培训结束之后统一解答

话术指导：

您好，我是今天的xx系统xx业态的培训老师。因为此次培训有许多客户同时参加，麻烦在培训过程中保持静音，避免影响其他客户培训，在培训过程中有任何的疑问都可以先记录下来，培训结束之后我们会留出一段时间专门用来解答场地的问题。

### 4.4 培训录屏

专项培训需要进行屏幕录制，培训结束之后将录制视频发到答疑群和钉钉群，让销售发给客户

### 4.5 培训问题答疑

培训结束之后，询问客户是否有疑问，进行问题解答

话术指导：

您好，今天xx系统xx业态的培训已经结束了，请问在培训过程中系统哪里还有不清楚的吗？还有什么疑问吗？现在我们开始进行问题解答，可以帮场地解答一下问题。

### 4.6 培训维护和后续培训通知

引导客户进培训答疑群，后续客户问题可在答疑群进行答疑。通知下次专项培训时间

话术指导：

您好，本次培训已经结束，后续有问题可以在我们答疑群里面进行询问，每天都有人员值班进行问题解答，培训录屏待会我们也会同步到答疑群里面，对系统不清楚的地方也可以下载培训录屏进行二次观看。我们每个月都有类似的专项培训，感兴趣的可以关注一下
