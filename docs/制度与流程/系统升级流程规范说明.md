# 一、流程说明

此流程用于规范系统升级的流程整体流程，明确系统升级各项流程的工作职责和步骤流程。帮助各位同事能更好为客户做好申请准备工作和完成升级任务。

# 二、流程分类

系统升级流程分为以下几种情况

1. 娱乐管家标准版/大客户版/游乐宝单店版本升级（低版本升高版本）

2. 娱乐管家标准版/大客户版连锁版本升级（低版本升级高版本）

3. 娱乐管家单店商城合并总部/娱乐管家连锁商城分离单店

4. 娱乐管家标准版升级游乐宝

5. 娱乐管家标准版升级娱乐管家大客户版（单店商城）

6. Y2000升级娱乐管家标准版

7. Y2000升级游乐宝

8. Y2000升级娱乐管家大客户版

三、各项流程说明

## 1. 娱乐管家标准版/大客户版/游乐宝单店版本升级（低版本升高版本）

升级前准备：

1) 确认客户升级前后版本功能变化是否影响客户使用，包括硬件部分和软件功能差异性。并获取客户同意。

2) 通过石墨文档《升级排期表》排期并发布到排班群中，通知客服时间。

升级过程流程：

1) 客服在指定升级时间段内联系，并与客户确认营业结束时间

2) 备份门店数据库和系统文件

3) 营业结束后升级系统

4) 升级完毕后与客户电话联系，确认所有设备是否正常运作。

## 2. 娱乐管家标准版/大客户版连锁版本升级（低版本升级高版本）

升级前准备：

1) 确认客户升级前后版本功能变化是否影响客户使用，包括硬件部分和软件功能差异性。并获取客户同意。

2) 通过石墨文档《升级排期表》排期并发布到排班群中，通知客服时间。

升级过程流程：

1) 客服在指定升级时间段内联系，并与客户确认各个门店营业结束时间，并告知客户升级过程中保持服务器处于正常开机并通网状态。

2) 报备运维组升级事项。

3) 备份总部数据库和系统文件。

4) 营业结束后升级总部系统。

5) 总部升级完毕后升级门店系统。

6) 升级完毕后与客户电话联系，确认所有门店的所有设备是否正常运作。

## 3. 娱乐管家单店商城合并总部/娱乐管家连锁商城分离单店

准备阶段：

1) 销售收集客服总部/门店数据库备份文件及系统文件，并发送到实施组进行测试（需时3~7个工作日）

2) 实施组给出测试报告并告知销售结果

3) 销售与客服预约分离/合并时间，并与客户沟通时间排期

分离/合并总部流程：

1) 客服在指定时间与客户确认时间节点。

2) 备份数据库及系统文件

3) 执行分离/合并操作

4) 客服与客户确认合并/分离后系统是否正常运作

5) 销售回访

## 4. 娱乐管家标准版升级游乐宝

升级前准备：

1) 确认客户升级前后版本功能变化是否影响客户使用，包括硬件部分和软件功能差异性。并获取客户同意。

2) 将数据库和系统文件备份收集，并提供到实施组进行测试。

3) 实施组给出测试报告。

4) 销售收集客户现有场地运营资料，并安排远程培训，培训完毕后给出培训结果。

5) 通过石墨文档《升级排期表》排期并发布到排班群中，通知客服时间。

升级过程流程：

1) 客服在指定升级时间段内联系，并与客户确认营业结束时间

2) 备份门店数据库和系统文件

3) 营业结束后升级系统

4) 升级完毕后与客户电话联系，确认所有设备是否正常运作。
