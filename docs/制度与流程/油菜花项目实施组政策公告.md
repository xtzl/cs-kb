# 2025年3月20日，销售线索奖励机制调整

说明：重新调整销售线索奖励机制，奖励机制如下：

奖励金额说明：在销售部原有的500元成交奖励上进行划分

1.单次订单总金额低于或等于5万元，则销售人员（指销售部、客成经理或销售助理）得400元，推荐人员（指技本部技术支持、服务商）获得100元奖励。

2.单次订单总金额高于5万元，则销售人员（指销售部、客成经理或销售助理）得400元，推荐人员（指技本部技术支持、服务商）获得200元奖励（其中100元为公司额外奖励）。

3.以上奖励按客户发放，不按门店方法，例如：一个新客户下单2个门店订单，只计一次奖励。

流程说明：

获得线索→告知张琼云（由张琼云进行分配跟踪）→客户成单→次月月底前统计后由梁建宁发放奖励。

PS:原流程中的客情关系收集表取消不再需要填写。

# 2023年11月6日，更新关于获得客户红章点赞的政策需求（已取消）

1.所有红章点赞都需要客户发朋友圈才视为有效

2.获得点赞的技术，只需要转发红章点赞以及客户朋友圈截图到销售助理即可

3.销售助理只需要同步信息到钉钉《项目实施回访群》，需@梁建宁 @何梓敏

4.每次获得奖金金额统一整合为500元/次奖励

5.但只有红章点赞或者朋友圈点赞的将不再获得奖金

# 2023年11月9日，发布服务商发展政策

政策说明
为了加速服务商发展，扩大服务商规模，现阶段有以下政策，执行如下：
1.提供可用服务商线索者奖励100元/人，奖金将在服务商完成第一个订单以后完成后月结。如果服务商未能达到考核要求且无法接单则无法获得奖励。
2.完成服务商培训，且培训后能完成考核，并且能独立完成订单，负责培训此服务商的人则可以一次性获得400元/人奖励，在服务商完成第一个订单后月结。
要求如下：
1.所有线索提供者，需要向我提供该服务商的联系人、联系电话、所在省份。由实施组联系确认后作为登记
2.服务商培训师需要在实施组组长进行报备，报备绑定后才能算。

# 2024年5月1日，发布监督管理制度

#### 政策说明

大家在现场安装时，如果遇到同一个商场有其他技术曾安装过的门店，可以抽时间去检查回访一下，如果有发现当时技术或者服务商安装时有问题，可以通过以下链接反馈相关问题。

#### 政策内容
1.可提交的反馈人员包含：本部技术、服务商、客户成功经理、销售经理、客成助理、油菜花其他岗位工作人员；

2.提交要求，需要有文字描述以及证明图片；文字描述需要清楚描述相关内容，图片需要能显示到安装错误的信息；

3.提交时需要有相关的门店名称；

4.监督范围，所有油菜花上门实施门店（无安装日期限制）；

5.保密措施：所有提交的问题，均有1~3个月的保护期，也就是说当日反馈的问题，会隔1~3个月后才统一通报；通报时，不通报反馈人，只通报被揭露实施技术。

6.所有被反馈的情况均由实施组审核，并根据《现场巡查惩罚措施》检验并处罚；

7.
反馈人获得被
揭露实施技术
的对半处罚，如A技术违反规则安装，并处罚200元，则反馈人获得100元奖金；但如果

反馈人在现场获得全部证据为准，此反馈制度不适用于客户通过微信等其他途径获得的违规反馈；

9.反馈人奖金发放为匿名发放。

10.反馈时不需要填写安装人，后面核查时会由油菜花内部核查。

11.以上反馈规则，仅适用于已经验收的门店，未验收门店不在反馈范围内。
