# 流程说明

本流程为明确实施人员出差情况处理及注意事项提醒。

# 总体要求

1.行程全程务必注意人生安全；
2.到达每一站点及时反馈；
3.特殊情况需要及时汇报。

# 执行标准

## 本部实施组

1.严格按照实施任务中所委派的开始实施时间来安排行程，必须在开始实施时间前到达门店；

2.在公共交通运营时间段以内的，应选择乘坐地铁或大巴出行；

3.出行方式，应按照优先公共交通（公交、地铁）、其次是轨道交通（动车、火车、高铁），路程特别偏远可考虑飞机出行；

4.计划行程后，需要提前和客户沟通完毕后再进行订票。

## 服务商

1.严格按照实施任务中所委派的开始实施时间来安排行程，必须在开始实施时间前到达门店；

2.计划行程后，需要提前和客户沟通完毕后再进行订票。

特殊情况处理方式

航班延误、塞车、因不可抗力改换其他交通方式时，要及时电话与客户沟通。
示例话术：（自我介绍）吴总您好，我是油菜花的技术人员陈工，之前有电话跟您沟通过基本情况，（说明原因）但是我这边出了点小问题，因为天气原因航班取消了，导致不能如期到场，我改成今晚10点的航班可以吗（寻求客户的谅解）不知道您这边会不会介意，如果现场实施条件准备好了的话我这边应该会赶着开业前完成实施工作，不会耽误咱们开业，（客户答），（感谢客户的谅解）非常感谢吴总的理解与支持，那咱们到时再见！
通知方式可以通过短信、微信、电话等形式。情况紧急务必通过电话联系，如紧急情况联系不上客户，可联系销售经理代为持续联系。

# 严禁事项

1.严禁隐瞒行程；

2.严禁乘坐无牌无证交通工具，以免危机人身安全。

3.严禁虚假报销、因公肥私、通过虚假欺骗手段从公司得到报酬或其它补贴等行为，一经发现，开除，无任何经济补偿或赔偿，并承担因此给公司造成的一切经济损失及止损费用，并返还因此所得的全部款项。
