# 一、交接说明

本交接流程主要针对技术支持在现场进行项目实施后，客户项目售后交接的完整流程。请实施同事按照本流程执行。

# 二、流程说明

实施阶段：

1) 实施完毕后，需要将《项目交接表》填写完整，并上传到CRM。

2) 现场留下实施人员的联络方式及公司客服的联络方式

3) 本次实施人员将需要维护客户的售后服务，为期1个月。并以以下属于告知客户已经完成实施

标准话术：

各位XXXX乐园的领导你们好，本次实施在大家的积极配合下已经顺利完成,谢谢大家对我们工作的支持和理解。实施工作虽然结束，服务还将继续，如有问题可联系我来处理，电话：13xxxxxxxx。如联系不上（在飞机或高铁等信号较差的地方），也可联系我司客服跟进处理：

联系方式：

1、拨打电话4009999261

2、微信关注“油菜花信息科技”公众号，输入您的问题

3、一键联系客服（软件右上角点头像图标）

服务时间：每天8:30-24:00

再次谢谢对我们工作的支持和理解，祝生意兴隆，财源滚滚。

实施人：____________

日期：____________

4) 实施后一个月，则可以将此客户转交给客服进行维护。（前提是所有交接文件都需要上传CRM）交接时需要以微信告知客户，话术如下

标准话术：

各位领导你们好，不知不觉项目实施结束已经一个月，贵公司的业务也已经稳定运作，即日起将由我们的售后团队给您提供专业售后服务，具体信息如下：

联系方式：

1、拨打电话4009999261

2、微信关注“油菜花信息科技”公众号，输入您的问题

3、一键联系客服（软件右上角点头像图标）

服务时间：每天8:30-24:00

期待跟您再次相遇，谢谢！
