# 一. 文档说明

本文档主要明确远程培训7天维护，在培训之前需告知客户的培训7天维护事项

# 二. 适用范围

远程培训7天维护（芸苔系统，游乐宝系统，娱乐管家系统）

# 三. 具体内容

需将以下内容在培训之前同步给客户：

1.本次培训的服务期为1＋7＋1，即1天培训＋7天维护＋1天问题答疑，从培训时间节点开始计时，整个完整的服务期共9天。

2.培训方式将用腾讯会议同步电脑屏幕，以远程沟通讲解系统为主，培训期间会进行视频录制，技术员需在培训结束后，将该录制视频发到群中；

3.培训技术员仅在维护期间会留群，并于7天维护期内在群内进行1对1问题解答。一般情况下，技术员需在工作日半小时内答复问题，若超时未答复，培训对象可拨打技术员电话进行问题咨询。

4.7天维护期结束后，技术员在1天问题答疑期解决完培训对象尚存的问题，整个培训服务结束，后续服务将转交客服，所遇系统问题，可联系客服进行处理；

5. 客服是与我们的研发一块办公的，处理问题会更高效。
