# 文档说明

本文旨在说明远程培训的录屏应如何正确上传到oss新垃圾桶

# 背景描述

远程培训完成后，需要将此次培训的录屏文件发给客户，并且此录屏文件还需要上传到oss垃圾桶指定路径，做备份使用

# 操作准备

提前下载安装好oss新垃圾桶程序

具体可参考如下文档：oss新垃圾桶安装配置说明

# 操作步骤：

1.运行oss新垃圾桶程序，并进行登录；

具体可参考oss新垃圾桶程序安装说明文档，可点击此处查看

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019c26acf7530764&type=max)

2.找到需要上传的录屏文件路径

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019c26a54206073c&type=max)

3.选择当前培训的月份文件夹路径， 如培训订单是1月份的，则选择1月份的录屏文件夹路径。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019c26a72bb50748&type=max)

4.点击【上传】，选择需要上传的录屏文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019c26a9eac90752&type=max)

4.等待录屏文件上传完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019c26aa41ef0754&type=max)

# 注意事项：

## 1. 录屏文件命名格式

格式如：培训人姓名＋培训的门店＋培训时间

如：高某＋油菜花娃娃机店＋2026年2月4日16:00

## 2.录屏需在当天及时上传

培训当天需要及时上传该录屏文件，若后续检查到没有该文件，则按无录屏文件进行惩处
