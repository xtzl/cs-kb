# 应用场景
当门店需要调整系统的节假日时间、添加国家法定节假日放假时间，并用于设置套票可使用时间时，可通过调整系统的日历系统自定义节假日。

# 操作流程
路径：系统后台→设置→运维→日历管理

在【日历管理】，可以查看到现在系统的法定节假日和周末的日期是哪些，蓝色代表周末假期，橙色代表法定节假日。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723517374880-f9851429-b107-48ac-92c2-7676b0a3cb64.png)

每年都需要点击【获取法定节假日】来同步国家定义的法定节假日，这里同步的节假日不包含地区性法定节假日。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723517427299-63260190-36b8-4712-9303-36a180e5f11b.png)

点击确定完成同步

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723517453014-68d26ce4-3dea-4336-b279-7475c234e208.png)

如果需要修改地区性节假日，则点击对应的日期则会切换到周末，再点击则切换成法定节假日。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723517539495-067e9bf1-2147-4d51-abfc-1e0056bb56de.png)
