# 应用场景
门店是以纸质腕带过闸的形式进行套票核销的话，则可以通过在收银台出门票时，关联绑定纸质腕带上的二维码，后续用腕带上的二维码来核销验票

# 操作流程
收银台→选择出票方式→绑定票码

#### 门票成功售卖后，在门票选择出票方式界面，选择【绑定票码】，用扫码枪扫纸质腕带上的二维码，待票码显示栏显示出腕带二维码信息后，点击确定进行关联
