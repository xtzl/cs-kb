# <font style="color:#E8323C;">🌟</font><font style="color:#E8323C;">使用场景</font>
1. 吸引会员到店：通过社群，公众号，系统批量派送等方式让会员领赠币券，会员需要在指定时间内到门店收银台或兑币机上才能核销领币，相比直接赠币可以更好的吸引顾客到店
2. 提升复购：送优惠券， 购买套餐自动核销，相比满减代金券会降低客单的方式；赠币券可以指定购买某些套餐再核销赠币，并不会降低客单，而是多送币，也一样可以达到促销的目的。

# <font style="color:#E8323C;">🌟</font><font style="color:#E8323C;">派券方式</font>
优惠券可通过系统自动/手动派券、小程序派券、充值赠送等方式下发，用户根据预设的核销方式（购买核销/到店核销）核销成功后，权益立即到账。

# <font style="color:#E8323C;">🌟</font><font style="color:#E8323C;">核销方式</font>
1）购买商品核销

购买指定任一商品时，可选择使用赠币券，购买成功权益立即到账户内。

支持小程序、收银台，Pos机、兑币机

2）到店核销

盈客宝：出示优惠券二维码，供兑币机反扫核销

收银台：登录会员-优惠券列表可手动核销，成功后权益立即到账户内。

兑币机：反扫核销后，券内包含代币则立即出实物币，其他权益存入账户内。

3）订单金额≥xx元

单笔订单金额满足条件时，可选择使用赠币券，购买成功权益立即到账户内。

支持小程序、收银台，Pos机、兑币机

# <font style="color:#E8323C;">🌟</font><font style="color:#E8323C;">如何设置</font>
1) 总部、门店都可以设置，进入营销-赠币券-新增赠币券![](https://cdn.nlark.com/yuque/0/2023/png/1584417/1700564335511-be03a4a0-afa3-451e-b3ae-11b923166637.png)

2）设置券规则

派券方式：

小程序派发勾选后，可在小程序领券中心领取优惠券

系统自动派发勾选后，可设置自动发派规则

游乐掌柜派券勾选后，可结合企微的1元购列表等活动派券。



核销方式：

购买核销：支持添加一个或多个商品，购买其中任一商品后自动核销；

到店核销：无需购买商品，可在兑币机自助核销或收银台核销。

单笔订单金额≥XX元

## <font style="color:#E8323C;">🌟</font><font style="color:#E8323C;">使用赠币券（购买核销）</font>
### 盈客宝
可通过小程序首页选购商品或进入优惠券详情，点击“去下单”后购买任一商品即可选择使用赠币券。零售商品需完成取货后，系统自动核销。

![](https://cdn.nlark.com/yuque/0/2022/png/1584417/1662373495577-873b8d57-122d-4b21-b1c0-34fa679c7c6d.png)![](https://cdn.nlark.com/yuque/0/2022/png/1584417/1662373500893-00ad03f0-4bdb-41c4-912d-c49189640a4c.png)



### 收银台
将指定商品放入购物车后，系统自动选择可用赠币券，购买后自动核销。

![](https://cdn.nlark.com/yuque/0/2022/png/1584417/1662373517610-1f81ab5a-338c-4f8b-ae3c-66fe62b50d8e.png)

### 兑币机/Pos机
购买指定商品后，系统自动使用可用的赠币券并核销，权益发放至用户账户内。
