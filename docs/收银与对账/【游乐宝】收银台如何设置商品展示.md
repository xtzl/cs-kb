# 应用场景

1、收银台显示的商品如何设置统一分组显示？

2、如何对商品在收银台的显示颜色进行设置？

3、后台是否可以统一设置收银台分组？

# 操作步骤

1、收银台显示的商品如何设置统一分组显示？

商品售卖界面右上角点击三个点--进入设置商品展示--可进行设置商品显示分组、商品显示顺序、商品显示颜色

# 注意事项

1、未分组的显示分组是系统默认显示的分组，只要没有设置分组的商品都会显示在未分组里，所有商品都设置好分组后未分组则自动不显示
