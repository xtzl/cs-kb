# 应用场景
当会员账户里有优惠券，在收银台买单时该如何使用？

# 操作流程
路径：收银台→商品→售卖商品

**在收银台选择需要购买的商品，加入购物车后，会自动获取满足使用条件的优惠券，并自动计算折扣**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772098328319-14837139-9f47-458b-93de-68866e29ad68.png)



**如果有其他优惠券也满足使用条件，可点击优惠券折扣一栏，选择其他想要使用的优惠券**
