# 应用场景
客户在小程序参与抽奖活动，中了实物礼品，需要去收银台核销取货，此时收银员该如何操作？

# 操作流程
路径：收银台-会员-抽奖核销

**1.打开收银台，点击会员-抽奖核销，输入礼品的券码，点击查询。查询到该礼品信息后，点击领奖即可核销**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772438078629-0f03be2f-6279-431b-b079-d72b0eadfb8e.png)

# 常见问题
1.中奖礼品券码如何查找？

**点击转盘抽奖界面右上角【我的奖品】，进入后即可看到待核销的礼品，点击领奖即可显示券码**
