# 应用场景
查询具体时间内收银交账记录

# 操作流程
方法一：

路径：财务--收银员交账查询

 **点击财务，在收银员交账查询中，筛选账期时间和具体收银员进行查询交账**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772098610828-91f131ee-fe29-4092-a97a-e6912122caf0.png)



方法二：

路径：财务--日结记录--选择查询账期

**点击财务，在日结记录中，查询具体账期时间，收银一览查询账期内每个收银对应交账总明细**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772158067044-2d2d2d65-2e18-4647-a3ee-df741cc94c9d.png)
