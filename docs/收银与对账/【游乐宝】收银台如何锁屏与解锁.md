# 应用场景

1、为防止收银员因事离开收银台，导致收银台被无关人员操作，可对收银台进行锁屏

# 操作步骤

收银台右上角点击锁头图标即可锁屏收银台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792bbb87fa6356&type=max)

锁屏后输入当前登录收银台的收银员账号密码即可解锁

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792bfdd9e2635d&type=max)

# 注意事项

1、不要把收银账号密码透漏给无关人员
