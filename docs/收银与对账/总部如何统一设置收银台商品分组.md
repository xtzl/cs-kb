# 应用场景
为了避免门店重复工作，可在总部统一管理所有门店的收银台显示套餐的分页。

# 操作流程
路径：登录总部后台→商品→收银台分页管理

在【收银台分页管理】中，先在顶部位置，点【切换】切换至总部管理

然后，可选择【+新增分组】来新增所需要的前台收银台分组

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721530660505-6215b29c-5e0a-4878-88da-2c31c75960f7.png)

勾选对应需要调整商品的分组的商品后，点击【调整分组】，并选择对应需要调整的到哪个分组，点击【确定】完成调整

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721530700062-eef2da01-7181-4782-a3d7-5036e97095f7.png)
