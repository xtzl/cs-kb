# 问题原因：

当收银台在退订单时提示“抽奖券不足（9999）”，是因为要退的商品设置的有购买送抽奖券，会员已经把抽奖券使用掉了，此时会员账户没有抽奖券，所以退不了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e22c6c90fad&type=max)

# 解决方法：

1.设置一个零售商品，商品类型选择虚拟商品，设置0元；

2.将这个零售虚拟商品添加到抽奖活动中；

3.在收银台给这个会员补一个这个商品再去退原订单就可以退了。

## 详细步骤：

### 1.创建商品
1.1 在娱乐管家后台，商品>零售商品>新建；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e23ce2f0fba&type=max)

1.2 商品名称填写“补抽奖券”，售价0元，商品属性选择虚拟商品，保存；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e2412a10fbf&type=max)

### 2.商品加入转盘/盲盒抽奖
2.1 再到小程序>转盘/盲盒抽奖>活动列表>编辑；

注：根据顾客获得的抽奖券是那个活动决定将补抽奖券商品添加到那个活动里

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e2459510fc0&type=max)

2.2 添加补抽奖券的商品到活动中；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e2511540fcc&type=max)

2.3 可以通过搜商品名称快速找到刚才创建好的“补抽奖券”商品，添加；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e2562340fd6&type=max)

2.4保存抽奖活动方案；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e2588970fda&type=max)

### 3.收银台补抽奖券

到收银台读取会员卡，将“补抽奖券”商品添加到购物车并结算；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e25b84d0fdb&type=max)

### 4.重新退单

此时，再去退原订单就可以退了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a14e25e6b20fdd&type=max)
