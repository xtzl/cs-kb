# 一定要到收银台漫游么？

答：不一定，只要后台启用了自动漫游，A店会员只需要拿卡直接再B店的卡头或者自助设备上面刷卡消费就能实现自动漫游！

# 注意：以下特殊情况需要手动漫游

1.A店开通了盈客宝，该会员是线上会员，没有实体会员卡，而B店没有开通盈客宝则需要到收银台手动漫游
2.A店和B店都开通了盈客宝小程序，但是门店不是共用的一个小程序，是分开的，这种情况也需要让会员先到收银台漫游。
