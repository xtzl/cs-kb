# 应用场景

主要用于给会员或散客活动赠送代币、金币、积分、彩票。

# 操作步骤

操作路径：登录游乐宝收银台——商品——活动赠送——读会员卡（非会员可手动输入身份证出实物币）——选择赠送方案——赠送。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b81d8f3db7472&type=max)

已经赠送的储值可以取消赠送。
操作路径：登录游乐宝收银台——商品——活动赠送——选择已赠方案——选择要取消的记录——确认取消。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b81dd5e2b7474&type=max)

暂停赠送。

操作路径： 登录游乐宝收银台——商品——活动赠送——读会员卡——暂停赠送。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b81e07d0e7475&type=max)

# 注意事项
如果散客使用了身份证领取了活动赠送，再使用次身份证入会，则不再享受活动赠送，反之会员领取过活动赠送，然后登记未曾参与过活动赠送的身份证信息后，也不可再享受活动赠送。
