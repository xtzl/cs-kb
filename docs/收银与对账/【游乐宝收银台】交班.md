# 应用场景

收银员用查看核对当天的收入并进行交账。

# 操作步骤

操作路径：收银台——交账——交班——选择班次——输入金额——保存——是否打印交账回执。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b2049f9d358a7&type=max)

交班成功后，可以打印交账回执，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b204a9e8f58a8&type=max)

# 注意事项

1.存在多个支付方式时，需要下拉滚动条可以分页显示剩余的支付方式。

2.只有选择了实点的支付方式才能在此进行交账。

3.当天账期做实后无法进行修改和交账。

4.同一账期、同一收银员重复交账会覆盖上一次交账的记录。
