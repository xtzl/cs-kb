# 应用场景
顾客在小程序上购买了商品，后续顾客不需要该商品，在小程序上申请了退款，此时还需收银员操作才可退款，收银员应该如何操作？

# 操作流程
路径：收银台-订单-待售后

**1.进入收银台，点击订单，选择待售后，找到对应订单并点击进入**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772436544044-a45eb871-5021-4ed4-bf12-f23158327c90.png)



**2.进入订单详情界面后，点击右下角的售后处理**![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772436603270-69175deb-00c9-4edd-be1f-25760be01a8a.png)



**3.选择处理结果，填写好相应的处理说明后，点击确认即可**![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772436729553-07e247de-70ac-4108-b2c2-79f983ed3e8a.png)
