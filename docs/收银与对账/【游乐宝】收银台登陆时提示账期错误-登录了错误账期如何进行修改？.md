# 应用场景

1、收银台登陆时提示账期不对如何进行修改？

2、收银台登陆账期错误如何进行切换正确账期？

# 操作步骤

收银台登陆时提示账期不对如何进行修改？点击修改登录账期，选择正确的账期时间进行登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179309b60b56384&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179321cdae6638e&type=max)

收银台登陆账期错误如何进行切换正确账期？收银台左下角显示账期错误，直接点击账期修改成正确的账期即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101793221368f6390&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179321f6e04638f&type=max)

补充1：

为什么登录时会提示登录账期错误并能登录之前的账期？是由于之前的账期未作实导致的

后台财务--账期做实--选择之前的账期做实

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179322875f76391&type=max)

# 注意事项

1、提示登录账期错误时，切勿选择仍登录当前账期，否则会导致当天的订单与账期不一致，入账也会入到错误的账期里

2、每天营业结束后都要做实账期，切勿在当天没有结束营业就做实账期，否则已做实账期收银台则将无法登录回正确的账期，如何做实账期可见上述-- 补充1
