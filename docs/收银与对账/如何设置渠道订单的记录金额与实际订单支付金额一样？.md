# 应用场景
设置绑定渠道商品时，想要渠道订单的记录金额与库克实际支付的订单金额一致，该如何设置？

# 操作流程
路径：后台-线上-结算价规则设置

**1.进入后台，点击线上-结算价规则设置，找到对应渠道的结算价设置，选【取平台订单实收】。此时系统订单金额取平台订单实收=订单总金额-商品优惠券（不扣除平台券）。**
