# 应用场景
收银员误操作多售卖了一笔订单，或客户体验不佳想退款，可通过收银台订单作订单退款操作

# 操作流程
路径：收银台→订单→订单查询→退货

#### 登录收银台，点击收银台左边菜单栏【订单】→在【订单查询】界面，通过筛选查询找到并点击指定订单，在弹窗界面点击【退货】
