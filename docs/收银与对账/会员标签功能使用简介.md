# 应用场景
<font style="color:rgb(51,51,51);background-color:rgb(255,255,255);">会员标签是为客户手动打标或按照商户设定条件自动一次性打标签，帮助商户更好筛选客户。</font>

# 操作流程
<font style="color:#000000;">路径：会员</font>**→**<font style="color:#000000;">会员标签</font>

#### 会员标签页面基本介绍
会员标签对所有会员级别和非注销的会员状态生效；

当收银台读卡的会员无相关数据时自动隐藏标签组；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719480208940-bc1da661-e513-4896-aa35-b34d3f5fa1bd.png)

#### 重要标签会在收银台售卖界面读卡显示给收银员，帮助收银员了解顾客，提高客单价；
收银台展示方式：随机展示4个重要标签

![标签颜色说明和重要标签展示方式](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719484165142-1ec88013-1ec4-43c8-aae7-bea366b0888f.png)

#### 根据门店需要设置标签的数值，默认统计的时间段为12个月；
![标签定义](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719484391926-fdafd1fc-826f-4e7e-9553-502397ddf825.png)

#### 后台支持点击会员进入查看当前标签组的所有会员；
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719484860072-cd733064-5c8a-414d-8496-c22a06913d46.png)



#### 自定义标签的名称，最多10个汉字字符，且名称不可重复；
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719485155822-366e825b-942c-4f8a-9a21-71db19d80fe7.png)

# 常见问题
1. 收银台和后台如何手动打标签？

答：点击**<font style="color:#DF2A3F;">新增标签</font>**按钮，选择想添加的标签即可（手动贴的标签支持删除，自动标签不支持删除）。

![收银台手动新增标签](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719481513240-ca46c7b8-d6c4-4972-9476-a78bd8def68f.png)

![后台手动新增标签](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719482030064-08ed8f3c-0757-4c69-a50e-239795821d9d.png)
