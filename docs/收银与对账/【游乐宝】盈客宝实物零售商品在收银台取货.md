# 应用场景

当客户在小程序上购买了实物零售商品后，可以凭取货二维码或会员号到收银台取货。

# 操作步骤

操作路径：登录收银台——订单查询——在订单号处扫描会员取货码——点击该订单——点击取货——完成取货。

# 注意事项

取货完成后小程序订单状态会变成已完成，收银台也不再显示取货按钮。
