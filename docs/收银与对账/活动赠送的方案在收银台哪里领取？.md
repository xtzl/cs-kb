# 应用场景
门店如有设置像每月会员赠币等功能情况下，当游客来到收银台时，可通过活动赠送功能核销赠送储值给到会员。

# 操作流程
路径：收银台→商品→活动赠送

#### 在【活动赠送】界面中，读取会员信息，则系统会显示可赠送的方案，选择对应的方案，点击赠送即可完成操作。
