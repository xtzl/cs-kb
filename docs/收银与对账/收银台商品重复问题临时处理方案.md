# 收银台商品展示重复

场景：后端只设置了一个商品，但收银台展示有多个，如图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dafa60e5648e3&type=max)

# 临时处理方案

复制以下脚本，把其中的12345678改为门店编号/加密狗，在门店数据库执行，连锁需要总部数据库也执行。

DECLARE @BusinessNum nvarchar(32)

set @BusinessNum = '12345678' --【这里把12345678换成门店编号（加密狗）】

DECLARE @BusinessID uniqueidentifier
select @BusinessID = ID from Mall_Business where BusinessNum = @BusinessNum

IF EXISTS (
SELECT 1
FROM Mall_GoodPrices
WHERE IsAllTerminalCanSale=1
AND Channel is null
AND ID IN (SELECT GoodsPrice FROM Mall_TerminalPrice GROUP BY GoodsPrice)
AND OwnedBusiness = @BusinessID
)
BEGIN
UPDATE Mall_GoodPrices
SET IsAllTerminalCanSale = 0
WHERE IsAllTerminalCanSale = 1
AND Channel IS NULL
AND ID IN (SELECT GoodsPrice FROM Mall_TerminalPrice GROUP BY GoodsPrice)
AND OwnedBusiness = @BusinessID
END

# 问题原因

历史BUG，总部切换了分组模式引起的偶发BUG，2026-04-20已优化，后续发版后可升级更新。
