# 操作路径

后台--设置--员工管理

# 操作步骤

按里面的内容填写员工的基础信息，例如姓名，手机号等，录入后点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a803740b91f94&type=max)

# 注意事项

在设置中，有一项是：是否有收银权限，如果选择否，内是该员工无法在收银台销售商品。如果是收银员，请记得要选为”是“
