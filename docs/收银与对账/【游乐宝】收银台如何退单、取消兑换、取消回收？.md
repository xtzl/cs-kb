# 一.订单退货步骤

订单 > 订单查询 > 全部订单

通过收银台在【订单查询】里找到对应订单号，点开详情，点击退款即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977811f5f40404&type=max)

# 二.取消兑换步骤

订单 > 兑换查询 > 全部订单

通过收银台在【兑换记录】找到对应订单号，点开详情，点击退款即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197781130ba0400&type=max)

# 三.取消回收步骤

订单 > 回收查询 > 全部订单

通过收银台【取消回收】找到对应订单号，点开详情，点击退款即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197780f7b5003fe&type=max)

# 四.常见问题

### 1.收银台订单退货时提示“会员余额不足3004”是什么原因呢？

答：会员将订单的游戏币消耗掉了一部分，账户里不够订单的币数了，退单时是需要扣除这么多币数的，可以通过补币的方式补足订单币数，就可以退单了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197781931cc041e&type=max)

### 2.收银台退单时提示"卖家余额不足、基本账户余额不足，请充值后重新发起、商户号余额不足”，这些都是收款所用的商户号余额不足了，如何解决呢？

答：情况1：更换过商户号，那之前的商户号提现过了，账户里没有资金了，这笔单子是无法原路退回的，需要给之前商户号充值或者私下退记一笔其他支出。

情况2：没换过商户号，那就是门店商户号刚提现过，商户号里还没有足够的余额去退这一单，解决办法有两种↓方法1自己购买一单比这笔金额更大的订单，先退顾客，等收到足够的金额后再退自己的；

方法2给这个收款的商户号充值，充值够足够的金额后，就可以给顾客退了；

方法3与顾客协商晚些退，等商户号营业收到足够的金额后再退顾客。
