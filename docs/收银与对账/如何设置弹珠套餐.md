# 支持哪些场景
+ 门店兑珠机进行上下架弹珠套餐
+ 收银台、兑珠机售卖弹珠套餐，收银台存珠
+ 兑珠机出珠异常，处理后可继续出珠
+ 收银台手动补弹珠
+ 后台可查询出珠、存珠等记录；会员管理、查询、储值变更、储值平衡表支持查询弹珠数据；
+ 小程序支持查看弹珠储值与变更记录
+ **弹珠储值支持漫游**

:::
