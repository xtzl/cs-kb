# 🔴应用场景
在售卖套餐或进行礼品兑换时，可设置打印多张小票供客户使用

# 🔴操作流程
路径：收银台→ 更多→打印设置 

#### 进入【打印设置】，填入打印小票的数量，点击【保存】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718441741852-6c56256b-f6c8-49db-bdb1-419a150f57c4.png)

# **<font style="color:rgb(38, 38, 38);">🔴</font>**常见问题
❓︎问：我在游戏币套餐里设置了不打印充值小票， 这里设置了“售卖”打印1张小票，有影响吗？

答：后台设置的该商品要不要打印小票， 而这里设置的是：假设需要打印小票，打印几张
