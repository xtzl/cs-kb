# 🔴应用场景
<font style="color:#DF2A3F;">加币</font>：当场地兑币机或者柜台售币机游戏币库存不足时，提币或售币会提示库存不足，导致售币机无法正常出币，此时可通过加币给设备添加游戏币库存。

<font style="color:#DF2A3F;">清币</font>：要注意，这里的“清”指的是<u><font style="color:#DF2A3F;">清点</font></u>，而不是<u><font style="color:#DF2A3F;">清空</font></u>。一般一周左右，就要对场地的兑币机或售币机进行清币，设备会自动把所有币都“吐”出来，并数币，你只要输入清币的数量，设备的库存币数就会更改为清币的数量。通过这种方式可以检查库存显示的币数与实际币数是否相符。 （记得清币后，要把币再倒回设备）



<u>如果你想把设备里的实物币清空，可在清币后，将数量填写为“０”</u>

# 🔴操作流程
路径：收银台 →更多→ 加币清币

#### 进入【加币清币】界面
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718441047716-880dd7c5-31d2-412f-9f9b-e674cb84564b.png)

#### 找到对应的设备，点【加币】则可以进行加币，【清币】则为清点币数。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718441090878-eba4734e-8043-43ec-a1e1-ddbc06bee10b.png)

# **<font style="color:rgb(38, 38, 38);">🔴</font>**常见问题
❓︎问：我想加1000个币，不小心输多了一个0， 现在机台币数错误了，怎么办？

答：你可以再次加币， 把加币数输入为负数即可。例如输入：-9000
