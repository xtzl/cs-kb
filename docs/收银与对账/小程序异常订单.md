# 🔴报表说明
此报表可以查询小程序的异常订单，包含有售卖订单、卡头扫码游玩订单和押金订单，可以通过对应的异常类型给这些订单进行异常处理、退款或完成

路径：后台→小程序→异常订单→小程序异常订单
