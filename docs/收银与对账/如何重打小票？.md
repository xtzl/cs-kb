# 应用场景
客户小票票据丢失，可以在收银台重新打印一张小票给到顾客

# 操作流程
路径：收银台→订单→订单查询→重打小票

#### 在【订单】界面中，选择【订单查询】，并找到需要重打小票的订单，点进去，选择【重打小票】即可
