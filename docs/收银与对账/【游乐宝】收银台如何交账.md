# 应用场景

收银员营业结束后，需要将本人所收缴的费用填写到以下对应的支付方式中，交账成功后在后台的账期做实界面会显示对应收银员的实收。将账期做实实收和应收进行对比，当出现红色字样时，则代表有数据差异；无红色字样，则代表数据无差异。交班界面默认情况下只有现金需要实点交账，若其他支付方式也需要手动交账，则需要将后台支付方式设置成实点即可在收银台显示。

# 操作步骤

操作路径：登录游乐宝收银台--交账--交班

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e6701783580dd3c279b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e670178359d448927f4&type=max)

点击打印交账回执后，打印出来的界面如下图显示。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e67017835d587db2870&type=max)

交账成功后，系统后台账期做实以及收银员交账查询界面会显示对应的交账数据。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e67017835dda8ba287d&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e67017835de2c04287e&type=max)

补充1：收银台需要其他支付方式也需要交账，需要在后台设置支付方式实点路径：后台--财务--支付方式设置--编辑

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e67017835e1807e287f&type=max)

补充2：交账后账期做实界面有红色字样，显示有差异，如何判断。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e77994e67017835e5c7d4288b&type=max)

上图账期做实界面显示的红色差异主要在于该账号无对应应收，但是收银员却填写了实收数据导致的。需要将实收金额改成0即可显示正常无差异。

# 注意事项

交班是每次修改都会更新，而并不是累加。
