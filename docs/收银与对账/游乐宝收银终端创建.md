# 一． 创建收银终端

1. 收银终端：在后台创建收银终端将收银台和后台绑定相关联

2. 路径：设置--收银设置--收银终端--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018edfe8e84c6817&type=max)

在新增收银终端界面，填写终端名称，售卖仓库（主仓库），回收仓库（主仓库），场地使用收银电脑收银即终端类型选择PC收银台，场地使用pos机收银收银终端选择POS机

场地有多台收银电脑或者pos机，需要设置对应数量的收银终端，进行一对一的绑定

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018edfe909de6818&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018edfe92f98681b&type=max)

# 二． 绑定收银终端

1. 路径：打开游乐宝收银台

在服务器地址输入场地的服务器地址，已经输入了可以跳过过

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018edfe94d7c681c&type=max)

在设置终端界面输入管理员账号密码，选择对应的收银终端，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018edfe96d67681d&type=max)
