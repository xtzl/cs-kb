# 一. 文档说明

本文档主要明确了音响设备安装的工作内容、作业准则、工作要求以及禁止事项，请所有实施相关人员务必认真阅读。

# 二. 主要设备

音响喇叭，音响线卷，专业狮乐功放两分区,话筒，播报软件

## 3.2 音响喇叭安装流程

### 音响喇叭支架安装

1）音响喇叭支架需正对音响正面，方便后续调整。如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193718726636ad7&type=max)

2）连接音响喇叭支架和底座的螺丝需要朝下安装（播放音乐时音响会抖动，螺丝安装在下方会导致螺丝掉落,有安全隐患）。如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193718a39a86ae0&type=max)

### 音响喇叭固定上墙

1）先用音响喇叭底座在墙面上标记好打孔位置，用冲击钻在墙面上精确开孔（音响打膨胀螺丝的位置必须是水泥墙，不能是石膏板，泡沫砖需加长膨胀螺丝，木板需在背后用木板加固）

2）将音响喇叭支架底座取下，安装好膨胀螺丝

3）用锤子将安装了膨胀螺丝的音响喇叭底座，敲进打好的孔里面（打孔的时不能直接把膨胀螺丝打入，冲击钻会导致膨胀螺丝错位导致对应不上音响喇叭底座）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193719a16126b21&type=max)

4）将音响线连接到音响喇叭上面（红色的是正极，黑色的是负极，一般音响线上有标记的是正极，不同的供应商的音响线会有所不同），正负极不能接反，接反会导致音响烧坏。裸露在外的音响线需要用黑管包裹避免外露

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371a522a46b38&type=max)

5）将音响喇叭支架对接螺丝拧紧，安装到墙面上，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371ac0be16b48&type=max)

## 3.3 专业狮乐功放两分区安装流程

### 专业狮乐功放两分区摆放要求

1）专业狮乐功放两分区需要放在空旷位置或者放置的箱子不能有门，功放运行的热量很高，散热不好容易烧坏

2）多个专业狮乐功放两分区不能叠在一起，需要隔开一些距离，避免散热不行烧坏

###

### 专业狮乐功放两分区安装要求

1）一个专业狮乐两功放区最多只能连接6个音响喇叭，超过6个音响喇叭需要多个专业狮乐两功放区

2）将音响喇叭的音响线连接到专业功放两分区的正负极和对应的分区，正负极不能接反。音响线需打好标签标记具体连接的音响喇叭

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371b847f46b6a&type=max)

3）专业狮乐两功放区只有4个正负极接口，如需接6个音响喇叭。需将两个音响喇叭音响连接线正负极合并在一起，一个分区只能接一个合并的音响连接线，不能将两个合并的音响连接线都接到同一个分区，功放设备带不动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371bf76df6b80&type=max)

4）用音频线将收银台电脑和专业狮乐功放两分区连接在一起

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371c3ee056b8b&type=max)

# 五. 播报软件使用

## 5.1 基础设置

1）在播报软件首页点击设置，需将开机自启动和不关闭程序打开

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371d889646bdb&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371d9e3566bdf&type=max)

2）播报软件自带播报任务，但是需要将播报任务里面的门店名称修改成场地的名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371daf1166be4&type=max)

3）播报软件可设置定时播报，需提前设置好闭店播报和日常播报的定时任务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371dd26a06bec&type=max)

## 5.2 音乐软件设置

1）播报软件建议使用酷狗音乐播放音乐（其他音乐软件也支持），酷狗音乐可以在手机上更换音乐，其他音乐软件不支持

在酷狗音乐里面点击设置，手机Play可以用手机酷狗音乐扫码同步电脑酷狗音乐，从而手机上更改播放的音乐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371e326b16c09&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019371e27ea06c05&type=max)

2）更改音乐软件需要重启播报软件生效
