# 操作路径

后台--设置--收银设置--收银交账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad1435de8443a&type=max)

# 操作步骤

- 点击设置

- 点击收银设置

- 点击收银交账

- 选择班次

- 点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad143fbed443b&type=max)

# 注意事项

- 每天交账次数最大为3次

- 应收金额选择''是''

- 应收和实收不等是否可做实：此开关为是否强制应收实收相等才能坐实，如果选择是，则为不需要相等即能做实。
