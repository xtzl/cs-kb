# 一、作业说明

本文旨在说明芯烨58mm网口打印机的安装方法，常用于点餐功能使用。

# 二、作业准备

网口打印机，网口，电源口，电脑一台（用于配置打印机ip）

查找ip网段方式如下：

根据现场网络配置ip地址，查看方式如下：

打开“开始”菜单，在搜索栏中输入“cmd”，然后按下“Enter”键打开命令提示符窗口

在命令提示符窗口中，输入“ipconfig”命令，然后按下“Enter”键

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda9b7f875d3b&type=med)

# 三、注意事项

小程序下单时，收银台程序同时开启；

收银台点餐功能要注意配置关联接单收银台；

# 四、作业标准

客户扫码下单时，网口打印机能正常出单

# 五、作业步骤

1.将小票打印机组装好，并通电；

2.小票打印机ip配置；

a.登录 https://www.xprinter.net/companyfile/5/ 下载安装打印测试工具

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda2355a35c43&type=max)

b.解压工具包并打开解压文件；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda2748605c47&type=max)

c.双击运行XPrinter程序

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda27b9bc5c48&type=max)

d.将小票打印机通过usb线接入电脑，并配置XPrinter设置

通讯端口选择USB，打印机选择XP-58，点击【高级】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda2e8b7a5c56&type=max)

点击【网络设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda2ef51d5c57&type=max)

ip地址栏选取一个尚未被占用的ip地址，

本文配置的ip地址以192.168.110.220为例【该地址如何来的，可参考下二、作业准备中的ip地址查看方式】

ip地址：192.168.110.220

子网掩码：255.255.255.0

默认网关：192.168.110.1

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda30be2f5c5d&type=max)

设置完成点击【返回】，返回初始设置界面，点击【ping】，测试打印机ip地址是否能使用，若提示无法访问目标主机，则表示该ip地址可使用

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda3ea4f75c7a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda3f4fd15c7c&type=max)

检测小票打印机ip是否配置成功；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda4846c85c8a&type=max)

3.收银台配置小票打印机端口；

登录 https://www.xprinter.net/companyfile/10/ 网址，下载安装小票打印机驱动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda5382ff5c99&type=max)

点击【是】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018dda5400365c9b&type=max)

添加新端口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de38c34e46a5d&type=max)

点击【下一页】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de38cba936a5f&type=max)

输入上述的ip地址 192.168.110.220，点击【下一页】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de38e2be16a61&type=max)

点击【设置】，确认端口信息，点击【确定】后，再点击【下一页】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de3efea396b0a&type=max)

核对端口信息，点击【完成】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de3f3bdd66b16&type=max)

小票打印机端口设置完成如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018de3f495616b19&type=max)

4.小票打印机测试
