# 取消机台扣费

## 路径

### 收银台 > 游乐 > 取消机台扣费

在收银台找到对应的订单，点击“取消”就可以返还在项目上扣的币或者套票

（注意：只能取消账期还没有做实的记录，已经做实后的是没办法更改的）。
