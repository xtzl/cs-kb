# 应用场景

当客户在某个时间段无法游玩项目时，进行 “请假”变更套票的使用时间，需要使用时直接通过“销假”恢复套票的正常使用。

# 操作步骤

操作路径：收银台——套票查询——点击需要请假/销假的套票——请假/销假。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b1f5c52e65822&type=max)

# 注意事项

1.未使用的套票不支持请假。

2.请假中的套票无法使用。

3.请假中的套票可通过“销假”功能来恢复正常使用。

4.请假的套票有效期须大于一天。
