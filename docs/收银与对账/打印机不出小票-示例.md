## 常见现象

- 收银结账后，小票机没有任何反应，指示灯不亮
- 小票机在走纸，但打出来是空白
- 小票打印一半卡住，或字迹模糊、缺行
- 系统提示"打印失败""打印机未连接"

## 排查顺序（按这个顺序问，能省一半时间）

1. **问电源**：机器电源灯是否亮？插座是否被同事拔掉过？换插座试一次。
2. **问连接**：USB 线是否插紧？无线/网口打印机看指示灯是否常亮（闪烁通常代表没连上）。
3. **问纸**：热敏纸是否装反（光滑面朝打印头）？纸宽是否和机器匹配（58mm/80mm）？
4. **问系统**：收银端"打印机设置"里，当前选择的打印机名称是否正确？是否被改成了"Microsoft Print to PDF"。
5. **重启顺序**：先关收银软件 → 关打印机电源 → 等 10 秒 → 开打印机 → 开软件。**顺序反了经常不好使。**

## 对应处理

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 灯不亮 | 电源/插座 | 换插座、换电源适配器；不行直接报修 |
| 空白纸 | 热敏纸装反 | 翻面重装 |
| 打一半卡住 | 纸仓卡纸、灰尘 | 开盖清纸屑，用酒精棉擦打印头 |
| 提示未连接 | 驱动/端口掉了 | 重装驱动或换 USB 口，重启软件 |
| 字迹浅 | 打印头老化 | 调高打印浓度应急，安排换机 |

## 话术要点

先安抚再排查："您别急，小票打不出来我先帮您确认两件事，一分钟就能定位。"避免让店员自己拆机。

## 升级条件

同一台机器 24 小时内复发 2 次以上，或确认打印头损坏 → 提交报修单，附机器编号 + 现场照片。
