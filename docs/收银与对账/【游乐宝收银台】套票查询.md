# 应用场景
当顾客想要了解自己会员账户下套票使用情况时来到前台，在收银员和顾客确认了顾客信息之后，收银员需要在系统中进行以下套票使用查询的业务流程操作（
通过此套票查询业务同时可以查询某个时间段内所有套票的使用情况，包括过户、请假/销假、延期、打印套票、绑定票码和退票操作 ）。

# 操作步骤

操作路径：登录游乐宝收银台——套票——套票查询。

套票查询：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b1a4ed62754b1&type=max)

注：

1.使用特定的时间周期和自定义时间周期进行查询。

2.通过读卡信息查询相应数据，可以通过点击【VIP】切换卡模式（含键盘输入、身份证读取模式和会员卡读取模式）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b1a52a8f954b2&type=max)

3.按销售渠道分类搜索查询。

4.通过打印和绑定套票的票码查询。

5.通过手动输入订单号/套票名称/购票人姓名和手机号查询。

6.重置：会清空手动输入的信息。

7.待使用：含未使用和使用中的套票记录。已失效：含已过期和已完成的套票记录。全部：查询全部套票的记录。
