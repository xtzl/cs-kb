# 操作流程
路径：(收银员）收银台→交账→交账

#### 在【交账】界面中，收银员对今日收取的金额进行盘点并且填写交账金额，点击【保存】完成交账
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718267196864-8b1c0062-5a9f-46fa-b502-28404944e4a7.png)

路径：（财务、店长、值班经理、管理员）后台→财务→日结做实

#### 进入【日结做实】界面中，核对收银员交账的金额和系统金额是否一致，并查看是否有长短款，确认结算无误后，点击【做实（结账）】，完成一天的结账。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718267404253-9e3b1233-4d2a-4104-9cac-a23e267b3674.png)
