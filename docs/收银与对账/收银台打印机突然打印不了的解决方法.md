收银台打印机突然打印不了的解决方法

# 第一步

检查一下电脑右下角是否卡打印队列了；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197545b15cc7322&type=max)

# 第二步

鼠标右键选择这个打印机；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197545b15a07320&type=max)

# 第三步

点击【打印机】选择【取消所有文档】，队列都被清除掉后，再尝试打印看是否正常了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197545b15a17321&type=max)
