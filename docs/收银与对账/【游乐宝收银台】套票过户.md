# 应用场景
此功能用于将一个会员的套票转赠给另一个会员使用。

# 操作步骤

操作路径：收银台——套票查询——查询到相应套票并点击——过户。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b1b61e2ff5783&type=max)

# 注意事项
已过期和已完成的套票无法过户。
