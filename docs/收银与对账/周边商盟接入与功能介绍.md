# 产品说明

周边商盟是以门店为中心，与周边的商家合作，让用户的储值可以兑换更多线下实物商品/权益。门店与商家线下进行对账结算，完成业务闭环。

通过联盟更多优质的商家，即可给周边的商家导流，又可增加彩票等储值的价值增加会员粘性。

# 接入说明

1.平台将向场地方收取每笔订单（用户实兑金额）1%的手续费，以菜籽的形式自动扣除。

2.兑换金额后门店与商家线下进行对账结算，后台可导出报表，供双方对账

# 接入条件

1.使用游乐宝和娱乐管家

2.需开通“盈客宝”小程序

3.需开通“游乐掌柜”小程序

# 功能说明

## 商户后台设置

### 1）功能开关

路径：游乐宝-线上-线上兑换-兑换设置

路径：娱乐管家-线上管理-线上兑换-兑换设置

开关控制整个活动状态，关闭后用户将无法通过任何入口进行兑换操作。

### 2）设置兑换比例与活动规则

路径：游乐宝-线上-线上兑换-兑换设置

路径：娱乐管家-线上管理-线上兑换-兑换设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c4224b53e0570&type=max)

支持单选3种储值方式中的一种，并设置兑换比例XXX（储值）：1元。

活动规则非必填，填写后将在用户兑换页面中展示。

注：会员级别限制与折扣对本活动正常生效

### 3）添加商盟

路径：线上兑换-商盟管理-添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182cdeb8fa82de5&type=max)

商盟：用于后台记录商盟信息的唯一标识

商盟显示名称：用于用户端显示的名称，可在商盟名称的基础上添加更多引导类的描述，例如楼层、门牌号、分店名等

管理员手机号：商盟管理员的手机号，用户登录游乐掌柜查账对账

状态：当前商盟的启用状态

备注：非必填，对当前商盟的备注内容，可用于备注记录上一次对账日期等

### 4）导出商盟二维码

路径：线上兑换-商盟管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182cdec76062de6&type=max)

导出二维码可用于打印出来放置至商户收银台，以供用户扫码进入该商盟的兑换页面中。

### 5）查看订单明细/汇总

路径：线上兑换-订单管理-周边商盟

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182cded9ca72de7&type=max)

明细：所有周边商盟的订单

按商盟汇总：按照商盟统计所有订单与金额。（只能查昨天之前的数据汇总，每天凌晨更新）

# 商盟查账对账—游乐掌柜

## 1）登录查账

路径：游乐掌柜小程序-周边商盟

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182cdf06c572ded&type=max)

通过商户后台-商盟管理中，所设的管理员手机号登录游乐掌柜小程序。即可查看该商盟的收款明细及汇总。

·支持完善商盟资料（可设置商家定位）

·支持开启语音播报功能

·商盟侧支持取消当天订单，超过当天则不再显示“取消订单”入口
