# 应用场景

收银员可以使用此功能增加其它收入金额。

# 操作步骤

操作路径：收银台——交账——其它收入——选择收入分类——收入金额——支付方式——填写备注——保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b2069cb2758bc&type=max)

# 注意事项

其它收入填写错误可以到后台修改。也可在后台新增其它收入。
