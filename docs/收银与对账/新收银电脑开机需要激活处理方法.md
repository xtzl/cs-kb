# 文档说明

由于现在Windows11限制，新电脑开机后，需要使用windows账户进行登录，而门店一般没有windows账号，所以可以参考此文档进行跳过限制直接登录到桌面

# 教程说明

## 视频说明

https://www.bilibili.com/video/BV1UJ4m1H7we/

## 文字说明

1.根据开机后的流程，一直下一步，直到出现联网的界面，在联网的界面用组合键shift键加F10 或者shift键+FN键+F10进入cmd命令行界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f0901905e4b3d&type=max)

2.在cmd中输入命令 oobe\bypassnro,输入正确命令后，电脑会进行重启

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f0902b9a34b40&type=max)

3.重启后即可，然后继续按照引导步骤完成激活即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f0903ae4c4b42&type=max)
