# 应用场景
收银人员在收银台软件上面给客户退还未使用完的预存款

# 操作流程
路径：登录娱乐管家收银台-会员-登录会员-编辑资料旁的下拉列表-退预存款

#### 登录娱乐管家收银台-会员-输入会员手机号/扫描会员二维码-点击编辑资料旁边的下拉列表-退预存款，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592616548-798d914e-1db3-4cbe-bf82-8e0373458bf5.png)

#### 选择退款方式，点击退款，显示退款成功则代表客户预存款退款成功了
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592634445-feeafe14-6f66-4219-a1b9-c4abe6dd8d6a.png)
