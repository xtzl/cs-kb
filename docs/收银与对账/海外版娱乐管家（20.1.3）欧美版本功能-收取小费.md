# 欧美版本功能-收取小费

## 一、功能概述

小费是欧美服务行业的重要文化与支付习惯，小费收取功能旨在为消费者提供便捷的小费支付方式，同时帮助商家规范结算流程、提升服务体验，满足当地消费场景需求。收银员可以在售卖商品时对顾客发起收取小费，顾客可以按照自身情况，选择支付小费或者不支付小费，管理员可以通过后台查询到每个收银员收取小费的明细与汇总。

## 二、功能操作指南

### 1、版本要求

欧美版本：V20.1.3193

东南亚版本：无该功能

国内&港澳台版本：无该功能

## 三、常见问题答疑

### 1、收银员的小费会汇总到营业额里面吗？

答：不会，系统显示的营业额是商品实收的金额，小费会单独进行显示并计算汇总

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84e072eb34df&type=med)

### 2、后台哪里可以查看到小费的总额？

答：后台-财务-日结做实，可以查看到每个收银员收取的小费汇总

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84e072f134e0&type=med)

后台-报表-商品订单报表，可以查看收取小费的明细，也可以按照其他的汇总方式进行查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84e072f634e1&type=med)

### 3、订单退款后，小费会进行退回吗？

答：小费不会进行退回，如果需要退小费，只能进行现金线下返还，系统上填写其他支出（后续会优化小费原路返还）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84e072fa34e2&type=med)

### 4、小费如何结算给收银员

答：系统提供数据，门店自行进行结算
