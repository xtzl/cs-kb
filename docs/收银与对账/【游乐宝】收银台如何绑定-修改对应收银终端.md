# 应用场景

1、收银台首次安装/重装后提示设置收银终端，如何设置？

2、错绑收银终端如何修改已绑定的收银终端？

# 操作步骤

操作路径：首次安装或重装收银台后打开收银台--自动提示设置收银终端--输入后台管理员账号密码--选择收银终端--保存完成绑定

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792b5886c3630d&type=med)

保存完成绑定后收银员账号进行登录收银台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792b5886d3630e&type=med)

如何修改已绑定的收银终端？打开收银台--点击收银终端一栏里的更改--重复上述步骤即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792b5886e2630f&type=med)

补充1：

收银终端需要先在后台设置好才能在收银台进行选择绑定，操作路径：后台--设置--收银设置--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792b5887fc6310&type=med)

# 注意事项

1、不能使用收银账号进行绑定收银终端，会导致无法选择收银终端，同时也不能使用后台管理员账号登录收银台，除非后台管理员账号同时拥有收银权限与后台管理员权限

2、收银终端是一对一的，两台及两台以上的电脑不能同时使用相同收银终端，可在后台新增收银终端给其他电脑使用，操作步骤可见上述--补充1查看
