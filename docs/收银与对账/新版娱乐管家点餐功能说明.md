# 文档说明

本文档用于指导如何使用点餐功能，点餐功能分两种模式，一种是摊位点餐，用于美食广场一类的情况，扫摊位上的二维码进入菜单，点餐后凭取餐号到对应的摊位取餐；另外一种是桌号点餐，用于餐厅场景使用，在餐桌上有对应的二维码，顾客通过扫餐桌二维码进行点餐，由工作人员安装桌号进行送餐。

# 流程说明

## 设置流程

设置桌号→设置餐厅商品→设置后厨打印（二次打印方案设置）

## 使用流程

### 自助点餐（常用于餐厅点餐）

游客扫餐桌二维码进行点餐→前台收到订单后点接单打印→后厨同时出单品订单→后厨根据小票内容制作餐品→出餐并附上小票→服务员根据小票上显示的桌号将餐送到游客餐桌上

### 收银台/POS机/点餐二维码点餐（常用于奶茶店、美食广场摊位等场景）

游乐来到前台告知收银员需要点的餐品→收银员操作购买并有游客付款→收银员打印取餐小票给予游客并告知等待叫号→后厨收到餐品开始制作→制作完毕后小票和餐品给到服务人员→收银员在订单找到对应的订单点击【取餐】完成订单→叫号并给游客餐品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f57030c6c6f57&type=max)

# 配置流程

## 第一步：确认功能是否开通

1.确认系统是否已经开通点餐功能，可以查看一下门店后台-商品-餐厅管理，点击新增看看有没有报错，如果报错证明还没开启该功能；

## 第二步：设置餐厅及餐桌

### 说明

同一个门店是可以有多个餐厅设置，如果使用摊位模式，即代表着在此位置需要设置多个餐厅，一个餐厅代表一个摊位；反之，如果是类似家庭娱乐中心内的一个亲子餐厅，则只需要设置1个餐厅即可。

### 1.添加餐厅（无论是餐桌点餐模式还是摊位点餐模式必须设置）

操作步骤：在后台-商品-餐厅管理-新增，添加餐厅

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb77d2b6c23a1&type=max)

餐厅名称：给予此餐厅命名；

商品分类：扫码点餐展示的商品分类，分类编号排序越大越前，商品排序越大越前；由于不同餐厅是可以独立生成餐厅码，所以此位置设置的分类决定着在餐厅码扫码后能显示哪些分类的餐品；

接单终端：选择点餐后接单的收银终端，支持收银台电脑、POS机以及云打印机接单

接单自动打印订单小票：选择该选项，对应的接单终端自动打印小票（顾客联）

接单自动打印后厨小票：选择该选项，对应的后厨打印机会自动打印小票（后厨联）

云打印方案：可在此添加或管理云打印机以及管理所有的打印方案设置。

云打印售卖仓库：支持单独设置云打印机的打印方案。

其他收银台：支持一个餐厅多个收银，用于同一个餐厅下有多个收银台来使用。

### 2.餐厅二维码下载导出（摊位点餐模式必备，餐桌模式可忽略）

步骤说明：餐厅码一般用于贴在前台位置供客人扫码点餐并通过取餐码取餐时使用，如果是用餐桌点餐功能则在另外一个界面进行导出，而不需要使用餐厅码；餐厅码场景更合适于摊位场景使用。

操作步骤，导出位置如下图所示，此餐厅码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f09c74ad34d83&type=max)

### 3.设置餐桌（餐桌点餐模式必备，摊位模式可忽略）

#### 步骤一：新建餐桌：后台-商品-餐厅管理-餐桌管理-新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f09d22d724d98&type=max)

餐厅名称：选择你需要在那个餐厅新建餐桌

桌号：输入你对餐桌的命名，建议单一个餐厅的 使用“1号桌”、“2号桌”这种命名；如果说是多个餐厅的，可以使用A01、A02、B01、B02这一类的餐桌命名，好用于后面区分餐厅；

#### 步骤二：导出餐桌二维码并贴到对应的桌子上

# 常见问题

问：收银台餐饮商品可以跟其他商品一起下单吗？

答：不可以，餐厅商品的订单和其他商品的订单在收银台是分开的

问：不注册会员可以下单吗？答：可以问：支付支付宝吗？

答：目前暂不支持，仅支持预存款、微信支付

问：如何开启预存款吗？

答：财务-支付方式设置预存款支付方式

问：已后厨打印，再退餐会打印后厨退单小票吗？

答：会，小票上会显示“退单”字样

问：如果估清菜品？
答：在设置菜品每天限购数量，或者直接估清将限购数量设置=0。

操作路径：后台-商品-零售商品-选择菜品-餐饮商品的标签页

问：饮料一类的如何选择冰/热、甜度等选项。

答：这种需要使用组合商品来完成。

具体做法是：

①分别建立冷、热、各种甜度的虚拟餐厅商品

②建立组合商品，修改组合分值，比如冷和热属于二选一，则将该子商品归为一类，只能二选一，其他选择同理。
