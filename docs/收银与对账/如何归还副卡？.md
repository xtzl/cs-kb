# 应用场景
会员开过副卡，现在不需要使用需要归还，收银员该如何操作？

# 操作流程
路径：收银台-会员-主副卡管理

**在【会员】界面，搜索到该会员，点击编辑资料右侧的展开按钮，找到主副卡管理，点击进去**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772099298129-b53865a5-a264-45f5-9363-12adffc7d025.png)



**找到顾客想要退还的副卡，点击还卡即可**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772099474421-abd817bf-d197-4572-b4e7-a568d0bff055.png)
