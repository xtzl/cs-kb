# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
当收银员需要给游客手工存彩票，则可以使用手工存票功能进行存票

# **<font style="color:rgb(38, 38, 38);">🔴</font>**操作流程
路径：收银台→商品→兑换商品

#### 进入【兑换商品】界面，选择【存票】，在界面中读取会员信息，并输入需要存入的彩票数量，点击【确定】完成设置
