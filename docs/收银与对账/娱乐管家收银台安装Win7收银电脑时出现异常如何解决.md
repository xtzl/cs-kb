# 异常现象

win7电脑安装娱乐管家收银台时，出现登录异常、闪退、报错的情况

# 原因分析

win7需要额外的运行环境，需要将以下运行环境安装才能正常。

# 解决方法

将以下的运行环境都安装一遍，如果已有安装环境则可以跳过

# 注意事项

以上环境仅支持win7 64位系统 32位系统不支持，只能重装为win10。

如果是海外版，还需要额外安装.net4.8.1运行环境
