# 应用场景

总部设置收银台分组可以保证收银台分组的整洁性，收银台分组统一由总部进行管理。

# 总部如何新增收银台分组

1、收银台分组需要设置总部管理，总部才能设置商品门店的收银台分组

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb610d88b4f42&type=max)

2、在总部点击商品--收银台分组管理--新增分组

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb61262c44f45&type=max)

3、填写对应的分组名称和分组的序号，然后点击确定

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb612b7454f49&type=max)

4、分组信息的修改和删除。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb61315be4f4a&type=max)

5、勾选对应的商品可以调整商品的分组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb6141b9d4f4c&type=max)

# 注意事项

1、收银台分组需要设置总部管理，总部才能设置商品门店的收银台分组。

2、删除收银台分组的时候，如果有商品选择了该收银台分组，则这个分组无法删除。
