# AB账功能定义

1.作用说明：AB账功能可实现内帐和外账显示，内账反映真实营收，外账反映部分营收（为保证数据的可信度，取订单数量的比例）。相当于设置AB账功能后显示部分账期做实，另可选择不显示“其他收入”部分。

2.功能支持范围：账期做实、经营报表、结账历史查询、商品订单查询、售币记录、会员储值余额和会员活跃分析报表。需单独给外账账号增加‘’角色’，权限仅用于查看上述报表。

# AB账设置操作路径

## 单个账号设置不同比例

操作路径：

1.设置-员工管理-新增用户

2.连续快速点击红框区域6次，直至出现“查询权限”，可选择“订单比例”、“限定查询终端”、“按金额比例（日结做实、日结记账、结账历史查询）”，演示比例可选5%-100%，可勾选“含其他收入”，点击保存（即账期做实金额不包含当日的其他收入）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001972fc33b072786&type=max)

订单比例：按订单数量计算，订单金额随机；

限定查询终端：可选“销售终端”、“消费终端”的部分终端；

按金额比例（日结做实、日结记账、结账历史查询）：按当天应收金额计算。

订单数量越多，取数越准
