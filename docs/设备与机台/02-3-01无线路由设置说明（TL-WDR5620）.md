一、 作业说明

本教程主要围绕如何设置 无线 路由器的操作来展开说明。

二、 作业准备

电脑一台，网线 一 根。

三、 注意事项

网线不要插错口

四、 作业标准

电脑开机，路由器通电。

五、 作业步骤

1. 把电脑的网线接到路由器LAN口。

2. 打开浏览器，清空地址栏并输入路由器的管 理地址tplogin.cn 或192.168.1.1，在弹出的设置管理密码界面中，设置管理密码 ：****（已脱敏，请向运维索取） 点击确定 。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac80fbae23f2f&type=max)

3. 上网方式选择自动获取ip地址。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac81028713f30&type=max)

4. 设置无线网络名称为YocartoonNet6，密码为****（已脱敏，请向运维索取）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b624d87166ada&type=max)

注意：5G无线网络需要关闭

5. 设置 LAN 口的 IP 地址为：10.0.0.1，子网掩码255.255.0.0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac810745e3f32&type=max)

6. 等待路由器完成配置并重启，至此，路由器已经设置完成。

六、 常见问题

1. 无线路由器WAN口有可能是自动获取的 IP 地址或者固定的 IP 地址。

2. 如果有多个无线路由器必须区分开每个路由器的WAN口 IP 地址。
