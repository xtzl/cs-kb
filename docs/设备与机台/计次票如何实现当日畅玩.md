计次票如何实现当日畅玩

应用场景

票务场地中，可能会有按次扣费且扣一次则可以当日无限进出场地的需求场景，遇到此类场景，该如何在油菜花系统中实现？

操作流程

方式一：使用允许离场时间，在允许离场时间范围内可以无限进出。

优点：

通过计次票的功能即可实现，无需额外设置。支持设置限时游玩。

缺点：

单张计次票只允许单个会员进场游玩，不支持多人进场，在使用腕带的场景中效果不好。并且必须离场时刷出闸后才能再次进场。并且容易因为没有刷出口闸机时再次入场时容易误扣费

设置方式

路径：后台→游乐套票→新增/编辑计次票→高级设置→允许离场时间

设置说明：在允许离场时间，填写对应可离场时间，如果当日无限畅玩，一般可设置为600分钟覆盖整个营业时间即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea5669d73450&type=med)

方式二：使用期限票代替单次票，使用组合商品来组合期限票来实现多次票。

优点：

在使用腕带绑定/打印的场景下，支持多个人同时使用；不需要出口闸机就可以支持。

缺点：

系统设置相对复杂一些，数据报表统计会呈现期限的统计而不会按照组合后的商品来统计。

设置方式

第一步，设置期限票，设置时，将期限票的【有效期】设置为整个组合商品可使用时间范围，如1个月等，代表这个多次票可以在一个月内时间。并且将【首次使用后】的有效期设置为1天，代表只要入闸一次，对应的单次票就只能今天有效。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea5669dd3451&type=med)

第二步，通过组合商品，将上一步设置的期限票组合一起，如想设置5次票，就等于在组合商品将5张期限票组合成一个新的组合商品。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea5669e13452&type=med)

方式三：使用会员领腕带功能实现

优点：

只需要正常设置单次票即可，不需要额外设置。不限制是否有刷闸机出口。进场前就将卡内次数扣掉，防止逃票。

缺点：

现场必须是通过腕带绑定进场或者腕带打印进场的场景，不支持直接通过会员二维码进场的场景。只支持当个项目进场，不支持多个进场的场景，不支持限时游玩场景。

设置方式

后台：仅需要正常设置计次票即可，可在后台→设置→系统设置→票务基础设置→会员扣次领取的腕带可进闸次数中，选择【当天不限次数】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea5669e63453&type=med)

收银台：在【会员扣次领腕带】功能中，选择对应的项目，并选择扣的次数，然后读取会员信息，并选择需要扣的套票，点击【核销】，然后绑定/打印套票，完成核销。此时绑定的腕带则具有无限进出场地的功能且仅当天有效。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea5669eb3454&type=med)

方式四：使用人脸绑定计次票单独次数，后续刷脸可以无限进出。

优点：

不需要使用腕带，仅需要设置计次票即可；且可以支持散客多次票使用。

缺点：

使用该模式后，不支持非人脸入闸情况，所有套票进场都需要录入人脸；必须闸机具备人脸功能。
