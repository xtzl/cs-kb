# 操作流程
路径：登录总部后台→总部→项目分类

点击【+新增】，进入新增界面

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547161017-60770107-8dcd-4968-b155-b5edfe0f77de.png)

按照下面提示进行填写

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547220799-c92544e1-d1fc-4c6f-87ee-5109b3e786bc.png)

**模拟机**：用于只投币游玩体验的机台（适用设备：反扫卡头、钻石V2/V9）

**礼品机**：用于出礼品机台，可计算出礼品数（适用设备：反扫卡头、钻石V2/V9）

**彩票机**：用于出彩票类的机台，可计算出彩票数（适用设备：钻石V2/V9）

**闸机**：用于门禁设备、刷卡桩（适用设备：星战摆闸、蝴蝶闸机、立式验票桩、户外三辊闸）

**体育类**：用于体育项目、台球设备等（适用设备：台球终端）

**卡丁车**：用于卡丁车项目（适用设备：车辆控制盒）

**碎票机**：用于配置柜台碎票机和3P存票站使用（适用设备：柜台碎票机V2/V8、3P存票站）
