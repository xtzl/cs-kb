# 一、 说明：本教程用于安装TSC门票打印机驱动安装以及设置方法

# 二、打印纸安装

1.将打印纸压在打印通道，并调节一下底部黑标光眼检测位置，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54ab7a3a6d63&type=max)

# 三、驱动安装

1.先下载驱动到电脑中，解压，如如图所示

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/6.常用驱动程序/油菜花工具包_7.驱动程序_TSC-T300A打印机驱动.rar

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a0208b6d36&type=max)

2.在windows系统中，找到【设置】-【蓝牙和其他设备】-【打印机和扫描仪】-【添加设备】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a0724a6d37&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d549f874a6d32&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a0eb4c6d39&type=max)

3.如图所示，选择【通过手动设置添加本地打印机或网络打印机】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a121616d3a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d549ce4bb6d27&type=max)

4.选择【使用现有的端口】，并选择【LPT1:(打印机端口）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d549de1986d2a&type=max)

5.选择【从磁盘安装】，选择【浏览】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d549e46526d2c&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a600c16d4e&type=max)

6.选择驱动中的【TSC.inf】文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a220a06d3e&type=max)

7.选择打印机型号，可以看一下打印机的铭牌写的是哪个型号，如本示例为TSC T300A，则选择该驱动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a349aa6d44&type=max)

8.选择【安装】等待片刻后完成安装，可以看到打印机列表多出此打印机

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a6b51c6d54&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a3e0ff6d45&type=max)

9.找到这个打印机，点开该打印机-选择【打印机属性】，并选择【首选项】-【页面设置】-【新建】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a760c46d57&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a707e06d55&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a56d6c6d49&type=max)

10，设置打印腕带的宽度和高度，一般左右暴露宽度一般预留1.5~2mm左右。设置完后点击保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018d54a8f69f6d5b&type=max)

# 四、调节系统打印模板，并测试打印打印效果。
