# 一、作业说明

本教程用于本地服务器使用油菜盒子的场地使用，设备清单如下：

主路由：TP-LINK TL-ER6110G

隔离路由器：TP-LINK TL-ER6110G

AC控制器：TL-AC100

建议卡头数量大于200个以上使用

# 二、作业准备

调试电脑*1台

网线*1根（用于调试使用）

AP已提前挂顶，AP线路连接到机柜中

外网已经通路

标签纸

# 三、注意事项

1.监控网络不要与系统网络共用主路由

# 四、作业标准

1.机柜整洁

2.线路清晰

3.网络平均延迟低于40ms

# 五、设置步骤

## 步骤一：网络设备接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb40d2d8e&type=med)

## 步骤二：主路由设置

1.把电脑的网线接到主路由器（型号：TP-LINK TL-ER6110G）LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4192d8f&type=med)

2.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4222d90&type=med)

3.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb42a2d91&type=med)

4.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4362d92&type=med)

5.跳过快速设置

6.选择【基本设置】-【WAN设置】-连接方式选择“自动获取IP”-点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4462d93&type=med)

7.选择【基础设置】-【LAN设置】-IP地址设置为192.168.10.1，子网掩码设置为255.255.255.0，然后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb46a2d94&type=med)

8.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

9.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4752d95&type=med)

10.选择【基本设置】-【LAN设置】-【DHCP服务】，开始地址设置为192.168.10.50，结束地址：192.168.10.200，网关设置为192.168.10.1，首选DNS设置为119.29.29.29，如下图所示

说明：DHCP分配网段设置后，油菜花其他需要固定IP的设备，则使用范围外的网段，如柜台碎票机，当需要设置柜台碎票机时，可设置IP地址为192.168.10.201，避免因为固定IP和DHCP中的IP地址冲突。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019178f087ff7171&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019178f088087172&type=med)

## 步骤三：隔离路由器设置

1.拔掉调试电脑网线，将调试电脑网线接入到第二个路由器（隔离路由器，型号：TP-LINK TL-ER6110G）

2.在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4812d96&type=med)

3.在出现的界面设置路由器的用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb48d2d97&type=med)

4.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4982d98&type=med)

5.跳过快速设置

6.选择【基本设置】-【WAN设置】-连接方式选择“自动获取IP”-点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4a22d99&type=med)

7.选择【基础设置】-【LAN设置】-IP地址设置为10.0.0.1，子网掩码设置为255.255.0.0，然后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4ab2d9a&type=med)

8.选择【DHCP服务】，点击

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4b42d9b&type=med)

，对DHCP进行设置，设置如下图所示

开始地址：10.0.10.2；结束地址：10.0.10.250；地址租期：120；网关地址：10.0.0.1；首选DNS：119.29.29.29；备选DNS服务器：223.5.5.5

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4bf2d9c&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ac43dbf6ed5&type=max)

9.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4cf2d9e&type=med)

## 步骤四：调试AC控制器

1.拔掉调试电脑网线，将调试电脑网线接入到AC控制器（AC控制器型号：AC-100）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4d82d9f&type=med)

2.在电脑打开网页，并输入地址10.0.0.253，进入界面（如果无法进入，请尝试将电脑IP固定为192.168.1.100，固定IP的方法如下：https://jingyan.baidu.com/article/a17d5285fba7dac199c8f222.html IP固定完毕后，在网页输入192.168.1.253，进入界面）

3.第一次登录提示需要设置账号及密码，账号设置为：admin密码设置****（已脱敏，请向运维索取）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4e32da0&type=med)

4.设置完毕后，用新的账号密码重新登录进去设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb4eb2da1&type=med)

5.先设置AC控制器的IP地址，选择【网络设置】-【接口设置】，设置ip地址，点【设置】

IP地址设置为10.0.0.253

子网掩码：255.255.0.0

网关10.0.0.1

DNS为119.29.29.29 和223.5.5.5

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ac53f556ee4&type=max)

6.保存后，调试电脑会断开连接，此时需要把电脑固定IP重新设置为自动获取IP，等待片刻后可以通过10.0.0.253重新访问到设置界面

7.设置AP分配地址，进入【网络设置】-【IP地址分配】-选择【仅为AP分配】并按照下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ac598256ee8&type=max)

8.选择【无线管理】-【无线服务】，并修改第一个无线网络，点

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5072da4&type=med)

进入设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5112da5&type=med)

9.登录油菜花后台系统

游乐宝路径为：【后台】-【设备】-【基础设置】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店本地IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

娱乐管家路径为：【后台】-【终端】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店服务器IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f858288db5e3e&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f858288e85e3f&type=med)

10.修改SSID、安全选项和PSK密码，点【确定】，设置如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5242da7&type=med)

11.将其他无用的无线网络禁用掉，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb52c2da8&type=med)

12.点

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5372da9&type=med)

进入射频绑定界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5462daa&type=med)

13.勾选5G频段，然后点绑定（注意，如果此位置没有获取到AP列表，可重启整体网络之后再进去设置）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb54f2dab&type=med)

14.再次打开AC控制器，找到【射频设置】，选择【射频调优】，并设置频段宽带为20MHz，点击【设置】并点立即调优

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ac8d4ae6ef9&type=max)

## 步骤五：检查卡头连接状态

1.设置完毕后，魔方卡头V9和钻石V9卡头会自动连上该网络，并提示联网成功，扫码绑定门店，此时网络设置已经完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187279bb5592dac&type=med)
