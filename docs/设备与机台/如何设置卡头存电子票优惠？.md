# 🔴应用场景
门店的魔方V9和钻石V9卡头可实现“存电子票”功能， 为降低实物彩票成本， 门店可以为直接在卡头上存电子票的会员额外赠送一近比例的彩票，例如多送3%或5%的彩票。 

即便加上额外赠送的部分，出电子票成本也远低于出实物票的成本，经过大部分客户场地实测，使用此功能后，彩票成本可降10%~20%左右

需要注意是：开启此功能后， 不会影响到原机台出实物彩票的功能， 只是给会员多一种选择：如果你愿意直接出电子票，会有额外附赠～
