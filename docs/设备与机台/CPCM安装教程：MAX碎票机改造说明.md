# MAX碎票机外观

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47f6b2606884&type=max)

# 准备说明

MAX的碎票机改造，油菜花是使用卡头进行改造，需要使用到以下材料

①油菜花卡头一个（需要特殊程序）

②油菜花投币彩票信号线一条

③投币转接线一条

# 改造说明

## 第一步，调整MAX碎票机拨码

1.Max主板拨码与接线,将开关2往上拨(重启生效)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47af798a670c&type=max)

## 第二步，油菜花投币彩票线改造

说明：通过投币&彩票线材，改造好这样的线。下面的线按看卡头彩票线颜色。

改线步骤：

①剪掉投币信号转接线的多余的端口，只保留一个接口端口，如下图所示，并将原来黑色和黄色的线序互换。

注意：黄色线需要调整线序，图片线序是正确的，黄色线材初始是在右边，调整线序后黄线在左边。投币器线头需要保留，按照图片颜色对接好，投币线多余部分可以去除掉。

②将投币彩票信号线的端口直接剪掉（注意尽量保留适当长度的线），并按下面线序来接：

白色（彩票线）接黄色（转接线）

红色（彩票线）接黑色（转接线）

绿色（彩票线）接绿色（转接线）

其他线先空出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47c304a96756&type=max)

## 第三步，将油菜花卡头的彩票线电源接口接入到碎票机主板

1.先找到碎票机主板的电源位置，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47d244246775&type=max)

2.油菜花卡头的彩票线中的电源线和地线并入到主板的电源位置，接线如下：

黄色（彩票线）并入黄色（碎票机主板）

黑色（彩票线）并入黑色（碎票机主板）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47c47a8c675b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b3677b6718&type=max)

## 第四步，将油菜花卡头的蓝色线并入到碎票机主板的清屏信号线上（注意：碎票机如果没有屏幕的情况下可以不接）

1.先找到碎票机主板的清屏信号线（绿色）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47d64074678b&type=max)

2.卡头彩票线的蓝色线并接到清屏绿色线

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b3fac8671c&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b457a7671f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b4a5826721&type=max)

## 第五步、拔掉旧卡头的信号线，接上油菜花卡头的线

1.找到原来旧卡头的信号线，如下图位置所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47d90a8967c6&type=max)

2.把旧的卡头插头拔掉，换到油菜花卡头接头。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b573c56725&type=max)

## 第六步、拆除旧卡头并安装固定新卡头
1.拆掉原有卡头,安装卡头底座

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b5d7a86728&type=max)

2.安装卡头底板,注意螺丝不能用电动螺丝刀打会滑丝.或者用更长的螺丝

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b62b71672c&type=max)

3.穿线绑扎带

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b677636732&type=max)

4.做好内部扎线

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d47b6de456737&type=max)

## 第七步、将原来碎票机中的按钮绿色线拔掉封好（或者直接拆除按钮）

拆除后则完成全部改造。

## 第八步、刷通用配置卡，让卡头自动联网，联网后设备会自动注册完成配置

接好线后进行启动机器，刷通用配置卡，卡头链接上网络，会自动进行注册项目

# 改造后测试方法

1.不插卡,塞彩票碎票机不会吸票进去

2.插卡后,塞彩票碎票机会吸票并且开始计数

3.彩票在卡头保存成功时会将碎票机上的屏幕清零(如果碎票机有屏幕),如果没有屏幕,清屏线可不接

# 注意事项

1.接了卡头后,碎票机原来的按钮的绿色线要拔掉,防止按钮误按清零,或者直接拆掉按钮

2.Max主板卡关2一定要拨对,不拨对可能烧板子

3.卡头程序不是普通游戏机用的卡头,需要单独的程序.
