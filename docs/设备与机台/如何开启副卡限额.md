# 🤗应用场景
家长带领小朋友到门店游玩时，在取卡机取限额副卡，后续给小孩子通过限额副卡在门店游玩，副卡消费超过额度后无法继续消费；如果需要调整限额，家长可以盈客宝小程序进行调整副卡限额；

:::success
副卡限额，针对<font style="color:#DF2A3F;">代币、金币、预存款</font>三个储值类型进行消费限制；

:::

# 🧐如何开启副卡限额？
### ①门店开启副卡限额
1）进入后台【副卡押金设置】，开启副卡限额功能

2）门店工作人员可自行根据需要调整限额额度选项，点击保存即可

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722561158545-82731216-65a9-4489-a46c-6c96449b182d.png)



### ②如何配置额度
##### 1）收银台配置副卡额度
收银台进入主副卡功能，如果当前门店开启了副卡限额，则开通副卡时收银员可选择副卡额度；（额度与后台配置额度数据一致）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722561729299-b1e5e26b-5fd4-4ea9-8b16-c9f5d27bd624.png)

#### 2）取卡机配置副卡额度
①取卡机首页点击【取副卡】

②进入取副卡页面时，可通过- +按钮进行调整出卡数量；

③选择副卡额度，点击【确定】开始出卡即可（额度与后台配置额度数据一致）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722514170248-f0370f5d-452d-4fec-bb35-007c44ef50dd.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722514206611-b516aad4-21ba-41db-b2d6-b9eca4a878a5.png)![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1722515385918-8b6d3c71-7835-423d-a6f3-c1ea2a8c787a.jpeg)

#### 3）小程序配置副卡额度
①小程序点击【实体卡】入口

②选择你需要修改额度的副卡，点击【额度】

③滑动滚动条，调整副卡额度，点击保存即可；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722561927851-dd83dd04-be9b-45cb-b75d-8c6e55614a09.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722562082664-181a69d5-e79a-410c-b9a4-ade41fea8244.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1722562100589-ea439d1c-4936-4bda-9008-d7cba6246e41.png)

# 🧐常见问题
问：限额的额度支持漫游吗？

答：暂不支持



问：哪些设备支持副卡限额功能？

答：卡头、闸机；但限额副卡无法提实物币，且限额的副卡不能取副卡；

<u><font style="background-color:#FBE4E7;"></font></u>

问：副卡限额支持哪些储值？

答：代币、金币、预存款；



问：副卡额度不足会怎么样？

答：卡头会提示E512错误码
