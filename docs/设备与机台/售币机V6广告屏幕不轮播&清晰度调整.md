# 现场情况

售币机V6在设置广告后，会自动进行轮播，且广告发白，不清晰

# 调整思路

售币机V6是有程序的，可以通过程序来进行调整亮度与对比度，实现显示清晰；调整转场特效和图片时间时长，实现图片固定或轮播

# 调整方式

a.拿售币机钥匙打开带屏幕的面板，拿的时候要注意屏幕与灯板的连接线

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a18058a9d56bbf&type=max)

b.打开后，门板留缝，方便遥控器对屏幕程序进行操控

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a1805944c86bd0&type=max)

c.在售币机内部找到遥控器，对屏幕打开处进行遥控

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a180598a7a6bd7&type=max)

d.遥控点击设置键，进入程序设置页面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a18059c2d46bdb&type=max)

f.按照程序设置，对应设置图片显示速度：图片多长时间会进行切换图片转场效果：调整后看效果，只有一张图片可以把转场效果关闭亮度：显示的亮度，实测调整越低显示更清晰对比度：画面里最亮和最暗之间的差距，实测调整越低越清晰

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a1805a11476be0&type=max)

安装场地情况，自行调整，调整到合适为止
