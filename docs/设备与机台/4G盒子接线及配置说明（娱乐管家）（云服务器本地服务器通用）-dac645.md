# 一、作业说明

新到场地的盒子要与场地系统连接，就要安装接线与配置，下列为4G盒子的安装说明，4G盒子本身同时支持游乐宝/娱乐管家系统以及芸苔系统，本说明针对娱乐管家系统来调试。

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8520ed095947&type=med)

# 三、作业准备

### 工具准备

1.扎带（若干）

2.3M双面胶

*注意：工具准备清单目录请参考：链接

### 系统准备

1.娱乐管家系统版本升级为10.3.6171以上版本

2.本地部署需要开通云互联功能，此卡头只支持域名连接

3.扫码游戏，需要开通盈客宝小程序（微聆不支持4G盒子扫码游戏功能）

# 四、注意事项

1.卡头安装前，必须机台处于断电情况；

2.安装后，需要及时清理残渣。

3.4G盒子较为依靠4G网络信号，天线部分需要尽可能外置在机器外部

# 五、安装标准

1.4G盒子内置在机台里面，并且通过扎带或者双面胶固定在机台内部

2.4G盒子的天线，尽量外置摆放，并且保持垂直，部分特殊机台无法外置情况下，也要保证4G盒子天线垂直并且不与机台内壁接触。

3.接线后，线路需要整理梳理好，用扎带固定，且要求不能影响机台正常功能，包括不影响调试机台、回收硬币，打开检修口等操作。

# 七、测试要求

#### 投币信号匹配测试

使用实物币投币，机台能正常启动，并且后台【项目消费查询】能查询到对应投币数据，连续测试10次，均为正常代表测试通过；

#### 礼品信号匹配测试

将礼品扔到出礼品口，模拟出礼品过程，机器显示中奖，油菜花后台记录【出礼品查询】，则完成礼品测试过程；

#### 投币信号高低电平匹配测试

机台断电，等30秒后上电，机台上电后，机台报错误，则代表参数设置正常；

#### 扫码游戏功能测试

通过微信扫码，选择已设置的扫码游戏方案，会员扣除储值数与机台上币数一致。

# 八、常见问题：

1.如果需要解绑重连，可长按盒子端解绑按钮5~10秒进行解绑

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8520f492595d&type=med)

2.如果盒子出现异常，可长按盒子设置键5~10秒，然后断电再上电进行重置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8520f49b595e&type=med)

3.连接完毕后，出现重启后多上币，或者机台报卡币，可尝试调试盒子上的常开常闭设置，一般以机台中投币器的NO/NC进行设置，原来是NO则对应就是常开信号，反之常闭。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8520f572595f&type=med)

4.如果机台投币后机器不启动，请检查机器信号线电压，并在下图中位置调整信号线电压。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8520f57c5960&type=med)
