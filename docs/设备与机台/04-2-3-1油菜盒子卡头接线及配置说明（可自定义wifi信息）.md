# 一、 作业说明

新到场地的盒子要与场地系统连接，就要安装接线与配置，下列为油菜盒子的安装说明

# 二、 作业准备

准备盒子专用的读卡器

# 三、 注意事项

机台卡头通电，网络信号覆盖到位

# 四、 作业标准

1.油菜花盒子 安装完正常扣费，机器上币正场，礼品反馈数据正常。

2.天线需要直立在机台内部，并且不接触任何东西。

3.所有的先需要理顺捆绑，达到轻微拉扯不出现线断开情况，不妨碍开机台门等。

# 六、后台配置说明

## 1.机台项目的创建

### 1.1.添加机台项目类型：

注：

项目类型说明：

礼品机：娃娃机；

彩票机：需出彩票的机台；

娱乐机：需退币的机台；

模拟机：任意机台类型（机台有投币信号线）

路径 : 系统后台 - 设备管理 - 游乐项目 - 新增分类（根据机台属性，选择对于的项目类型）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401865839d2813d2f&type=med)

### 1.2.添加机台项目

路径 : 系统后台 - 设备管理 - 游乐项目 - 新增项目

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401865839d28b3d30&type=med)

如图，以娃娃机为例，按实际情况设置完成后，点击【下一步】，直接保存；

## 2.配置卡的配置说明

### （现有网络）通用配置卡的写卡及配置

路径 : 系统后台 - 设备 - 基础设置 - 卡头 WiFi 通讯设置 - 通用配置卡

2.1.1按照路径，进入“卡头WIFI通讯设置”界面，右上角 点击【重新设置通讯网络】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018658065c2b3cf5&type=max)

2.1.2 根据客户现场情况，选择内网 ip 或外网域名进行配置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018658068fa53cf6&type=max)

如果系统是本地部署，则勾选内场：

输入本地服务器ip地址＋9999，具体格式如下：

***.***.***.***:9999

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

如果系统是云部署，则勾选外场，

直接输入门店域名地址，第一个空格输入：y********.yun.youcaihua.net 第二个空格输入： 88;

若不清楚门店域名访问地址，请联系跟单助理进行咨询；

2.1.3 填写盒子使用的 WiFi 信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401865807cbe83cf8&type=max)

2.1.4点击服务器地址同步到游智云，再连接读卡器，放个空的会员卡，点击网络参数写入配置卡，配置卡写入完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186580842ba3cf9&type=max)

2.1.5 用手机扫码第一个二维码或直接输入 WiFi 信息，连接到盒子使用的 WiFi 上，再扫第二个二维码进入配置界面; （ 注：要用手机浏览器扫，手机 wfi 和卡头连的 wifi 为同一个局域网）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401865808b1853cfa&type=max)

2.1.6 拿已经写好的配置卡，连接好读卡器，长按盒子设置键 5s ，待机灯快闪，把配置卡贴近读卡器，让盒子读取信息。等到盒子上的电源灯，联网灯和强度灯常亮绿色，待机灯闪烁，即可进行配置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186580986583cfb&type=max)

2.1.7手机配置界面 - 选择要绑定的项目，选择添加端口或直接绑定（端口已存在选择跟换卡头，不存在端口，选择添加端口） - 选择绑定对应的盒子编号。 Ps: 绑定完成后，盒子四个灯常亮，代表盒子以正常配置成功。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018658172b8d3d00&type=max)
