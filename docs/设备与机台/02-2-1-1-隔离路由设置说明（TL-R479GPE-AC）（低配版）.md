# 一、 作业说明

本教程主要围绕如何设置 隔离路由 器的操作来展开说明。

# 二、 作业准备

电脑一台，网线一根。

# 三、 注意事项

网线不要插错口

# 四、 作业标准

电脑开机，路由器通电。

# 五、 作业步骤

### 1. 把电脑的网线接到路由器LAN口

### 2. 在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fe3fe83ec2&type=max)

### 3. 在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fe60af3ec3&type=max)

### 4. 路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fe850f3ec4&type=max)

### 5. 跳过快速配置界面

### 6. 选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007215d0902f5&type=max)

### 7. 选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“10.0.0.1”-将【子网掩码】设置为“255.255.0.0”-然后点【设置】，按下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101800725703002fb&type=max)

### 8. 在【AP管理】-【AP设置】-勾选【启用AP管理功能】-【保存】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007286a0702fe&type=max)

### 9. 在【AP管理】-【无线网络设置】中-选择【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e4610180072ba7ae0300&type=max)

### 10.按照以下设置内容进行设置，如下图:

a.【无线网络名称】设置为“YocartoonNet8”

b.【AP设备】选择“自动绑定所有AP”

c.【射频选择】勾选“2.4G1,2.4G2”

d.【加密方式】选择“WPA-PSK/WPA2-PSK（推荐）”

e.【无线密码】输入“****（已脱敏，请向运维索取）”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101800732c3130304&type=max)

### 11.（非必要）如果有魔方V9卡头，需要按照下列步骤进行设置，如果没有可以跳过此步骤

①先将无线网络启用，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101800736ca530305&type=max)

②点设置，对5G第二个无线网络进行设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101800737e0190306&type=max)

③在油菜花系统中，【卡头wifi通讯设置】找到通用配置卡，并设置通用网络，将通用网络生产的WIFI名称和密码记录配置到路由上

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e4610180073bf11d0307&type=max)

④其他设置需要按照下列设置来设置

a.【AP设备】选择“自动绑定所有AP”

b.【射频选择】勾选“5G1,5G2”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e4610180074157220309&type=max)

### 12.选择【射频调优】-将【信道调优】开启，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101800745ca2b030a&type=max)

### 13.等待路由器完成配置并重启，至此， 隔离 路由器已经设置完成。

# 六、 常见问题

1. 路由器WAN口可以用自动获取的IP地址或者固定的IP地址。

2. 如果有独立的AC管理器就不需要启用隔离路由的AP管理功能。
