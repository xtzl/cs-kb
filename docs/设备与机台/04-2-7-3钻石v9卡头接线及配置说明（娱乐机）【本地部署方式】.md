# 一、 作业说明

此文档旨在讲解钻石v9卡头的现场安装及接线、调试

# 二、 作业准备

小十字螺丝刀、镊子、读卡器、钻石卡头、相关线材

# 三、 注意事项

12V别短接错；

安装定位点需跟客户再三确认；

系统安装版本需在8.1.5以上；

# 六、 常见问题

## 卡头报错代码

1.经常误报检测到干扰

- 检查马达线是否加了磁环

- 检查防干扰灵敏度是否在"灵敏"挡位,可拨到一般

2.游戏机报投币故障

- 投币选项的常开常闭切换下尝试

3.每次出票都多一张或者少一张

- 投币选项的常开常闭切换下尝试

4.投多个币时机器显示的币数比卡头的少(吃币)

- 投币速度太快,降低投币选项的投币速度,和投币脉宽,一般脉宽=投币速度*0.6
5.出票时卡头记录的比机器显示的多(多出币)

- 出票速度太快,降低出票选项的出票速度和出票脉宽,一般脉宽=出票速度*0.6

6.出票时卡头出够5000就报缺票了

- 后台设置了单次最大出票数量,此选项是防止线路接触不良或者游戏机死机造成无线出票情况的.出现后只需按下服务键继续出票即可,如果每次出票都很大可适当调整数量
7.出票是出现顿卡,一阵一阵的卡

- 出票延时太高,大部分机器可设置到10ms,如果异常再调整到200ms左右
8.出票时每次出一张就停了

- 单次最大出票数设置成了0,调整好即可.

9.卡头一直显示连接WIFI

- 网络没配好

- 恢复出厂设置重新刷配置卡

- 量下12v电压是否正常,低于5V时卡头无法正常工作
