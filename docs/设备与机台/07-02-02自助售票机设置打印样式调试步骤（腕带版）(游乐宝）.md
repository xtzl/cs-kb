# 一、作业说明

本内容主要说明自助售票机V6腕带版如何调试打印机打印对应的样式。

# 二、作业准备

1.获取腕带的尺寸

2.准备1卷腕带进行测试

3.售票机通电并连接完成

# 三、注意事项

本教程仅用于腕带版打印机使用，门票版打印机可参考此教程

# 四、作业标准

# 五、作业步骤

## •简单参考参数调试步骤：

游乐宝后台套票模板设置参考参数：

宽度：19（打印位置的宽度，建议可以比实际位置略小1mm）

高度：78（打印位置的高度，建议可以比实际位置略小1mm）

售票机后台打印设置参考参数：

宽度：19（腕带实际宽度，建议可以币实际纸张尺寸略小1mm）

高度：257（腕带实际高度减去黑标偏移尺寸后的高度，建议可以币实际纸张尺寸略小1mm）

横向偏移：0

纵向偏移：0

黑标偏移：30mm

--------------以上参数如果设置完打印不正确，请按照手动调试步骤进行调试-----------

## •手动调试步骤：

1.登录游乐宝，选择【设置】-【套票设置】-编辑套票模板。

注意事项：售票机是可以获取到套票模板的预览情况，但仅限于默认套票模板，所以调试时需要使用默认套票模板先进行校对，校对完毕之后再复制该设置到其他模板并应用到其他门票。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece501a75&type=med)

2.我们以下面这个腕带的尺寸为例子

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece601a76&type=med)

由此可见，它的打印区域为19mm*78mm的大小。那我们可以把后台默认模板尺寸设置为略小于打印位置的尺寸，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece601a77&type=med)

3.保存模板。然后我们需要在机台进行调试。

4.按机台内部的设置键，进入机台设置后台，选择功能选择，然后选择打印机设置，进入下图界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece6f1a78&type=med)

5.先把票宽设置为100，票高设置为100，此时应该就会看到系统默认模板的所显示的情况，这时就可以通过下面的显示看到在系统上设置的内容会在示例上呈现的位置。如上图所示显示的位置，这里可以看到打印内容在上方位置，则我们可以按照此位置设置正确的打印纸（腕带的大小），示例的大小为287.05mm*19mm，那我们就设置为票宽为18mm，票高为256mm（这里需要减去黑标偏移的30mm），并把整个票角度旋转为90&deg;。如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece7f1a79&type=med)

6.然后打印出来看看实际效果会偏差多少

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece8f1a7a&type=med)

7.根据实际偏移情况，再通过调整横向偏移和竖向偏移，直到符合我们目标要求为止。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017bec9ece8f1a7b&type=med)

8.最后通过再次调整游乐宝后台的套票模板来调整字体和二维码大小即可完成整个调试。
