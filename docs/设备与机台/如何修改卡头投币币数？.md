# 🔴常见问题
❓︎问：修改后， 为什么还是原来的投币数？

答：修改后， 需要重启卡头才可以（最简单的方式是：把机台关了重新打开）



❓︎问：我想周一到周五，卡头扣费的价格自动半价， 可以实现吗？
