# 一、作业说明

本教程用于芸苔系统使用油菜盒子的场地使用；使用的网络设备：

主路由器：TL-R476G

无线路由器：WDR5620

# 二、作业准备

电脑一台，网线一根。

# 三、注意事项

网线不要插错口

# 四、作业标准

卡头网络正常可使用

# 五、设置步骤

## 第一部分，接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873127344e355a&type=med)

## 第二部分，调试主路由

2.把电脑的网线接到主路由器（型号：TL-R476G）LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873127345c355b&type=med)

3.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731273466355c&type=med)

4.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731273474355d&type=med)

5.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873127347d355e&type=med)

6.跳过快速配置界面

7.选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731273486355f&type=med)

8.选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“192.168.10.1”-将【子网掩码】设置为“255.255.255.0”-然后点【设置】，按下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873127348f3560&type=med)

9.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

10.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734983561&type=med)

## 第三部分，调试无线路由器

11.拔掉调试电脑网线，将调试电脑网线接入到各个无线路由器（隔离路由器，型号：WDR5620）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734a03562&type=med)

12.在浏览器中输入tplogin.cn按回车键，接入设置界面，并设置登录密码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734aa3563&type=med)

13.跳过向导

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734b33564&type=med)

14.进入路由设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734be3565&type=med)

15.进入上网设置，【上网方式】选择【自动获取IP地址】，并点【保存】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734c93566&type=med)

16.往下拉，找到【WAN口设置】，WAN口设定设置为【固定WAN网口】，保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734d83567&type=med)

17.选择【无线设置】，其中WI-FI多频合一需要关闭掉。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734e23568&type=med)

18.登录芸苔新零售公众号，点【管门店】，登录后，选择【我的】-【网络规则】，将WIFI名称和密码复制出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734eb3569&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734f4356a&type=med)

19.找到【2.4G设置】，复制上一步的无线名称和密码并填入到对应无线名称和密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187312734fc356b&type=med)

20.选择【LAN口设置】，LAN口IP设置为【手动】，并设置IP地址改为10.0.0.1，子网掩码设置为255.255.0.0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731273506356c&type=med)

21.更改完毕后，电脑会暂时断开连接，等待1~2分钟后，重新登录到设置界面

22.选择【DHCP服务器】，按照下图设置设置对应的参数，保存，完成设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731273510356d&type=med)

## 第四部分，测试

23.设置完毕后，油菜盒子会自动连上该网络，并且电源、联网和强度灯均为绿色灯，待机为红色灯闪烁；如果使用反扫卡头，则会显示H07等待配置。
