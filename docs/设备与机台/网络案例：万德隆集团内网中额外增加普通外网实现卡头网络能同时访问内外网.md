# 文档说明

万德隆的电玩城原来使用的是集团网，由于增加了小程序访问需求以及钻石V9需要与外网通讯。且万德隆属于连锁商城，本地门店服务器系统通过集团网与总部服务器进行数据交换。因此需要对现有仅集团网的进行改造。解决思路为：通过设置策略路由，让数据流量根据不同的需要来走线路，以实现同时访问的效果。

# 改造需求

1.服务器地址不变

2.依然需要接入到集团网，用于与总部进行数据通讯。

3.额外增加外网通讯功能。

# 前期准备

1.准备一个双WAN口企业路由器，用于增加集团网的和外网的接入。

推荐型号:TP-LINK TL-ER3220G

2.提前确认网络架构

# 方案调整说明

## 第一步：配置双WAN口，使其能正常连集团网和外网。

接入新的路由器，并且按正常配置配置两个WAN口，其中WAN1为集团内网配置，WAN2为外网配置，如下图所示

#### WAN2设置：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d428fd9b65a75&type=max)

## 第二步，新增一个WAN1口的地址池（用于后续设置策略路由时所需要选择的地址池范围来使用）

1.先设置地址范围

路径：对象管理→地址管理→地址→新增

Ip类型填写要求：写你要访问的内网ip地址范围（像本次的案例，wan口为固定地址，地址为192.168.110.150，所以这里的IP地址范围则192.168.110.1~192.168.110.250这个范围），然后地址组-地址名称选wan1（内网口）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d42b50c0b5ae8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d42c90dea5b30&type=max)

2.建立地址池

路径：对象管理→地址管理→地址池→新增

在这里。只要填写这个地址池的名称，以及选择刚刚建立的地址范围，点击确认完成地址池设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d7b08363224e0&type=max)

## 第三步：分别设置wan1和wan2的策略路由

### 先设置wan1的策略路由

路径：传输控制→路由设置→策略路由→新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d42cda25f5b45&type=max)

在新增的界面中，先设置wan1的路由规则

规则名称写刚才设置的地址组里面的地址名称（wan1）。只需要修改目的地址为wan1（第二步所设置的IP地址池范围），生效接口wan1，其余配置为默认。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d42d80d825b69&type=max)

### 再设置一个wan2的路由规则

因wan2要访问普通外网，规则名称选wan2，生效接口选wan2，其余默认，

注意：目的地址尤其重要，如选了wan1，就访问到wan1内网去了，从而无法访问外网了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d42e144a95b85&type=max)

# 服务器接线要求

服务器只需要留一跟网线接入到路由器或者路由器下的交换机即可。

# 注意事项

1.一般策略路由需要配合【流量均衡】/【负载均衡】功能来使用，关闭该功能可能使策略路由失效。

2.需要先设置集团网的策略路由规则后，再设置外网的策略路由。一般策略路由是从上往下匹配的，所以优先匹配集团网，再匹配外网。
