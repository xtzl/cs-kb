# 一、作业说明

本文旨在说明芯烨58mm网口打印机的安装方法。通过局域网连接到后厨打印机并打印实现点餐后自动打印功能。

# 二、作业准备

芯烨58mm网口小票打印机，网线，电源口，电脑一台（用于配置打印机ip）。

# 三、注意事项

1、小票打印机接电源

2、小票打印机插网线

3、小票打印机放好纸

4、准备一台电脑

5、网线和电脑处在同一个局域网

6、小程序下单时，收银台程序同时开启；

7、收银台点餐功能要注意配置关联接单收银台；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517337a1c&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517437a1d&type=med)

# 四、作业标准

客户通过扫餐厅码或者餐桌码下单时，网口打印机能正常出单。

# 五、操作步骤

1、小票打印机插上网线，并打印自检页。

自检页打印的方法如下：打印机关机--按住FEED键不放，再打开电源开关，2秒松开，打印机会自动打印出一张“Selftest”开头的自检页进行备用。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517557a1e&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517607a1f&type=med)

2、操作软件之前，需要先确定本机IP、子网掩码和网关等信息

操作方法：打开“开始”菜单，在搜索栏中输入“cmd”，然后按下“Enter”键打开命令提示符窗口在命令提示符窗口中，输入“ipconfig”命令，然后按下“Enter”键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517697a20&type=med)

记录下所需内容：

IP地址：192.168.110.87

子网掩码：255.255.254.0

默认网关：192.168.110.1

3、浏览器打开该地址下载调试软件 https://www.xprinter.net/companyfile/5/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517777a21&type=med)

4、解压文件，双击 XPrinter.exe 打开调试软件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c45177f7a22&type=med)

5、打开调试工具后，操作以下步骤

a.通讯工具选择“网口”，

b.打印机选择“XP-58”，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517897a23&type=med)

c.点击【自动设置IP】按钮，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517927a24&type=med)

d.点击查询，工具会查询局域网内的打印机。

e.通过刚刚“自检页”打印出来的打印机ID，进行选择对应需要调试的打印机。

f.设置打印机的IP、子网掩码、网关。要注意打印机IP不能冲突。子网掩码和网关按照命令提示符窗口获取的进行对应填写。端口默认不需要修改。设置好点击保存。

g.设置成功的打印机在点击保存按键后，会发出“滴”的一声。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c45179f7a25&type=med)

6、测试一下是否能PING通设置好的打印机IP。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517a87a26&type=med)

7.设置好小票打印机IP后，需要给对应收银电脑安装打印机驱动

芯烨小票打印机驱动下载地址 ： https://www.xprinter.net/companyfile/10/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517b37a27&type=med)

8.双击打开驱动，按以下步骤进行操作。

a.对应选择是否有自动切纸功能功能。

b.选择网口打印机，填写设置好的打印机IP。

c.点击开始安装打印机驱动。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517c07a28&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517c97a29&type=med)

9.确认打印机驱动，并打印测试页，确认驱动已经正确安装好

a.windows10系统可以通过底部任务栏的放大镜【搜索】控制面板，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517d57a2a&type=med)

b.点击查看设备和打印机

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517de7a2b&type=med)

c.找到xp-58的这个打印机，右键，打印机属性

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517f17a2c&type=med)

d.确认该打印机驱动的端口是否与设置的一致。如果不一致那就不是对应的驱动。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4517fa7a2d&type=med)

d.属性--成功--打印测试页，网口打印机打印出测试页。确认网口小票打印机已经能正常使用。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c4518057a2e&type=med)
