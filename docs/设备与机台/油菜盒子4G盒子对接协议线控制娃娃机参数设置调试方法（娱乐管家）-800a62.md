# **<font style="color:#333333;">文档说明</font>**
<font style="color:#333333;">油菜盒子、4G盒子支持配置后直接通过后台设置对娃娃机参数（游玩时间、出奖率、抓力等）进行设置，支持品牌为：时欣、大空艺。</font>



# **<font style="color:#333333;">系统版本要求</font>**
<font style="color:#333333;">支持系统：娱乐管家10.3.7以上版本</font>

# **<font style="color:#333333;">接线方式</font>**
<font style="color:#333333;">使用协议线，从盒子“游戏协议”位置接入并连接到娃娃机主板为止（除天线外其他线路不需要接）</font>
