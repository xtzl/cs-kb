# **<font style="color:#333333;">三、作业准备</font>**
<font style="color:#333333;">1.提前在碎票机安装位置预留网线和电源线，且网线需要和服务器处于同一个网络中。</font>

<font style="color:#333333;">2.提前按照下列尺寸图预留废票口；</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241694783-4626b935-5f74-4cfd-bf05-6718313f5bc6.jpeg)

<font style="color:#333333;">（柜台碎票机V8开孔尺寸图）</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241694971-8fd5de7b-6118-4c7a-bca9-fe37350288d8.jpeg)

<font style="color:#333333;">（柜台碎票机V10开孔尺寸图）</font>

<font style="color:#333333;">3.检查柜台碎票机配件是否齐全，包括进票口五金件(柜台碎票机V8)、钥匙、备用刀组、清票刚尺、电源线、出票口五金件(柜台碎票机V8)。</font>

<font style="color:#333333;">2.准备读卡器*1，空白会员卡*1</font>

<font style="color:#333333;">3.准备网线一根。</font>

<font style="color:#333333;">4.准备一些彩票用于测试。</font>

# **<font style="color:#333333;">四、注意事项</font>**
<font style="color:#333333;">1.安装前一定要和客户确认柜台碎票机放置位置。并在底部位置预留出票口。</font>

<font style="color:#333333;">预留口如图所示：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241695148-31b3a117-63f7-42d1-86c9-e7a90bf7c60d.jpeg)

<font style="color:#333333;">2.由于部分金属件较为锋利，建议带上手套放置刮伤</font>

<font style="color:#333333;">3.安装配件，挪动时，必须确保碎票机在断电状态</font>

<font style="color:#333333;">4.安装后，需要检查保险开关是否处于正常状态，在存票状态电机转动情况下，打开面板，电机必须是停止转动的状态。如果保险功能失灵，请务必不能使用，并及时返修。</font>

# **<font style="color:#333333;">五、作业标准</font>**
<font style="color:#333333;">1.网络连接正常，断电开机不出现掉线情况。</font>

<font style="color:#333333;">2.所有配件已经安装到位。</font>

<font style="color:#333333;">3.连续碎票10次不出现卡票情况。</font>

<font style="color:#333333;">4.连续碎票20张票，计数准确无误。</font>

### **<font style="color:#333333;">填写配置卡信息</font>**
<font style="color:#333333;">1.在生成设置卡界面，填写配置卡信息，分别录入以下信息：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241698299-bda26981-90ca-4f70-a9f4-ba0ae8ea6403.jpeg)

+ <font style="color:#333333;">服务器通讯方式：勾选内网；</font>
+ <font style="color:#333333;">服务器地址：输入门店服务器的IP地址；</font>

<font style="color:#333333;">若不知道如何查看本地ip地址，可参考以下文档进行查看：</font>

[<u>win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)</u>](https://jingyan.baidu.com/article/48b37f8df201691a6564887c.html)

+ <font style="color:#333333;">IP地址：请填写本碎票机使用的IP地址，根据现场提供的网线的IP地址来填写；</font>
+ <font style="color:#333333;">网关：填写本碎票机使用的IP地址所对应的网关，根据现场提供的网线的IP地址来填写；</font>

**<font style="color:#E53333;">若不知道如何查找网络ip地址或网关，可用笔记本电脑接入碎票机预留网线，参考下述文档进行查找判断：</font>**

[<u>win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)</u>](https://jingyan.baidu.com/article/48b37f8df201691a6564887c.html)

<font style="color:#333333;">比如，笔记本电脑获取到的一个ip地址为：</font>

<font style="color:#333333;">i</font><font style="color:#60D978;">p地址：192.168.110.20</font>

<font style="color:#60D978;">子网：255.255.255.0</font>

<font style="color:#60D978;">网关：192.168.110.1</font>

<font style="color:#333333;">则可以给碎票机分配为</font>

<font style="color:#60D978;">IP地址：192.168.110.*      （*号代表2~254之间的任意数字）</font>

<font style="color:#60D978;">子网：255.255.255.0</font>

<font style="color:#60D978;">网关：192.168.110.1</font>

<font style="color:#333333;">此时，在通过电脑运行cmd命令行，并尝试用ping 准备给碎票机分配的地址，看看有没有连接，如果没有任何设备连接，则代表此IP可以用；例如你想分配给碎票机192.168.110.241，则用ping来测试，如下图所示</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732241698484-9662b3dc-5e9b-4e13-94b1-751aed674ab2.png)

<font style="color:#333333;">注意：如果发现地址已经被占用，则需要再次跟换地址，直到不被占用为止，建议使用ip地址段200-250之间的地址会比较好。</font>

<font style="color:#333333;">2.上述信息填写录入完成后，将读卡器接入电脑，将准备好的空白会员卡放在读卡器上，点击【保存并写入卡中】，配置卡配置完成。</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241698950-8d71af7e-4325-46c9-b901-3d28e81553e6.jpeg)

# **<font style="color:#333333;">九、常见问题</font>**
<font style="color:#333333;">1.碎票机出现黑屏幕，并显示IP地址等信息。</font>

<font style="color:#333333;">答：连接失败，无法连接服务器，检查网络是否正常。</font>

<font style="color:#333333;">2.扫码登录直接退出</font>

<font style="color:#333333;">答：保存按键短路</font>

<font style="color:#333333;">3.经常显示断线</font>

<font style="color:#333333;">答：</font>

<font style="color:#333333;">a.更换ip再刷配置卡</font>

<font style="color:#333333;">b.更换网线</font>

<font style="color:#333333;">c.主板出现问题</font>

<font style="color:#333333;">4.碎票会减票</font>

<font style="color:#333333;">答：清理光眼或者更换光眼</font>

<font style="color:#333333;">5.存票的时候没有成功</font>

<font style="color:#333333;">答：重启碎票机是否显示A802报错，机台碎票机端口冲突</font>

<font style="color:#333333;">6.不显示扫码二维码</font>

<font style="color:#333333;">答：后台盈客宝没配置好</font>

<font style="color:#333333;"> 7：系统是本地部署，当用会员码扫自助设备或核销或登录时，提示会员码过期。</font>

<font style="color:#333333;">答：校正本地服务器时间，检查本地服务器时间是否跟世界时间一致，若不一致更改一致即可；</font>
