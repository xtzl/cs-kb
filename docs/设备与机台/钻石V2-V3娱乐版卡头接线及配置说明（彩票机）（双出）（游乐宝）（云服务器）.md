# 六、卡头固定安装标准

## 安装方法：

1.与客户沟通，初步确认大概安装位置，并用记号笔标记位置；

2.打开机台投币器位置，观察内部结构，进一步判断预计安装位置是否影响游客游玩和日常维护；并且判断投币信号线和马达信号线是否能连接到投币器和马达位置；

3.使用手电钻进行开孔，开孔时，根据不同情况使用不同的开孔器，情况如下：

- 机台表面为纯铁面，使用开孔器（铁）（20mm）进行开孔；

- 机台表面为木或者瓦克力，使用开孔器（木）（20mm）进行开孔；

- 机台表面为复合型双层面，顶部为瓦克力，底部为铁质，先使用开孔器（木）（20mm）对表面进行开孔，后再用开孔器（木）（20mm）对铁质内部进行开孔

4.使用手电钻，更换成批头，将底座放置到机台表面，对准位置后，用自攻螺丝将卡头底座进行固定，对不同材质有对应要求：

- 机台表面为纯铁面，直接使用自攻螺丝进行固定即可；

- 机台表面为复合型双层面，需要先使用麻花钻（3mm）对第一层面进行开孔，再使用自攻螺丝进行固定；

- 机台表面为木质或者亚克力面板时，直接使用自攻螺丝进行固定。

5.将线材通过孔位引入到机台内部，并接入卡头中，并且盖上卡头上盖，用小十字螺丝到扭紧固定完毕。

## 安装标准：

1.所有机台位置，必须是客户认可位置进行安装；

2.卡头安装时，需要断电操作，禁止带电安装，特殊情况需要与客户沟通双方达成一致后再进行作业；

3.卡头固定必须都使用自攻螺丝进行固定，客户有特殊要求除外；

4.当客户无安装经验时，可适当提供安装位置建议，建议原则如下：

- 安装高度一般不低于机台实物币投币器位置，且不影响实物币投币

- 卡头正面角度建议与机台呈水平或者垂直状态

- 卡头显示板方向建议位于机台正前方，可轻易看出终端位置并刷卡

- 安装位置应保证距离不影响机台的正常游玩以及正常机台维护

- 尽量安装机台平面位置

5.卡头安装固定时，卡头与机台位置平行或者垂直；

6.卡头为垂直安装时，如有配备卡头支架，应使用卡头支架进行固定；

# 九、 调试说明

## 钻石卡头调试说明

1.先把卡头接入的投币信号线接入到卡头中，注意不是盒子的投币信号线，是卡头的投币信号线！如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001916e5132034d85&type=max)

2.用铁丝短接接投币器端的黑色绿色线，约5s~10秒左右；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001916e51e7a44d89&type=max)

2.短接完成后，卡头界面显示“请刷配置卡”；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001916e5239574d8c&type=max)

3.将写好的配置卡放在钻石卡头上面，读卡；

4.钻石卡头显示扫码界面，即表示配置完成；

5.配置完成后，拿一张有储值的会员卡上去测试，如能成功扣款，则表示调试成功，设备可以正常使用。

# 十一、测试要求

#### 投币信号匹配测试

将会员卡放到卡头手上读取，卡头能显示卡内余额，并在1秒内扣除余额，机台上对应的币数，机台自带码表正常增加扣币数量则代表投币信号正常无异常；

#### 礼品信号匹配测试

将礼品扔到出礼品口，模拟出礼品过程，机器显示中奖，油菜花后台记录出礼品数，则完成礼品测试过程；

#### 投币信号高低电平匹配测试

机台断电，等30秒后上电，机台上电后，机台和卡头无报错误代码，则代表参数设置正常；

#### 网络信号通讯测试

连续刷卡5次，每次读取速度不高于1秒，同一张卡刷卡保护和后台设置间隔一致，则代表网络正常；

# 十二、 常见问题

1.点保存并写入卡中没反应

答：检查是否使用网页打开后台，此步骤需要使用程序打开后台才能写卡；

2.提示无法连接读卡器

答：由于读卡器被占用导致，请检查是否通知打开收银台和后台，如果是则关闭收银台，并插拔一次读卡器

3.提示读卡失败

答：有可能读卡器有干扰导致，尝试将读卡器拿到手上进行写卡

4.域名解析失败

答：由于部分地区域名解析失败，需要在路由器的LAN设置中的DHCP中添加DNS分配

DNS设置为：119.29.29.29,223.5.5.5

5.大部分卡头能正常链接，在网络覆盖范围良好情况下，卡头随机无法连接

答：有可能DHCP（自动分配地址功能）的地址范围不够，可增大分配的IP地址尝试是否能解决。
