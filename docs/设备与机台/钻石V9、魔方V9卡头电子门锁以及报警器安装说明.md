# 文档说明

钻石V9、魔方V9娱乐版卡头，支持安装门锁以及报警器，以实现非法开机台时会自动产生警报。

# 安装说明

1. 前期准备，电子锁感应器、报警器

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4437c45b5&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4438145b6&type=med)

2. 需要把S4门锁检测功能开启，拨到1开启，拨到0关闭

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4438945b7&type=med)

3. 接线，报警器出厂就已配置好，只需要在指定位置固定通上电（12v）就好，门锁感应器装门上，一个机器需要装两个门锁感应器的话只需串联接上去就行。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4439045b8&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4439645b9&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8ab4439d45ba&type=med)

4. 接好线测试，门锁感应器闭合，卡头、报警器不会报警，感应器打开卡头报警提示，收银台也会收到提醒，报警器一直响。工作人员需要开门的话只需要刷机修卡（员工卡）就可以不会报警。
