一、 作业说明

本教程主要围绕如何配置 证卡打印机（斑马(ZEBRA)ZXP3C）配置说明的操作来展开说明。

二、 作业准备

在官网下载驱动程序或者从随机附送的光盘上拷贝驱动程序。

三、 注意事项

不要搞错驱动程序

四、 作业标准

电脑开机，打印机通电。

五、 作业步骤

1. 把打印机的连接线插到电脑主机后面的USB口上。

2. 按图示安装好打印机的色带。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac82c131c3fab&type=max)

3. 安图示调节好卡片的厚度，一般为30左右。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac82c36b13fac&type=max)

4. 按图示把需要打印的卡片放进打印机里面 。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac82c833b3fad&type=max)

5. 将打印机电源开关设置在 “ 关闭 (O)” 位置，并在电脑上运行已 下载好的打印机驱动程序Install Zebra Printer Driver （安装 Zebra 打 印机驱动程序）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac82cbf693fae&type=max)

6. 选择 Install USB printer drivers （安装 USB 打印机驱动程序），并单击 Next （下一步）按钮。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac83447e13fb0&type=max)

7. 确保打印机的电源开关置于 “ 关闭 (O)” 位置，并单击 OK （确定）按钮。。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac83473c33fb1&type=max)

8. 显示 License Agreement （许可证协议）窗口，单击 Yes （是）按钮。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac834918c3fb2&type=max)

9. 显示 Setup Type （设置类型）窗口，选择 Complete （完整）安装所有程序 功能，并单击 Next （下一步）按钮。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac834b8fa3fb3&type=max)

10. 显示 Select Program Folder （选择程序文件夹）窗口，单击 Next （下一步）按钮。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac8359b7a3fb4&type=max)

11. 安装完成后将显示 Congratulations （祝贺）窗口。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac835c97f3fb5&type=max)

12. 此时，打开打印机电源开关，然后单击 Next （下一步）按钮。 Windows New Hardware Found （发现 Windows 新硬件）向导将找到打印机并自动安装驱动程序，等待 显示 InstallShield Wizard Complete （InstallShield 向导完成）窗口时，请单 击 Finish （完成）按钮。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac835f34e3fb6&type=max)

13. 选择 Start （开始） > Devices and Printers （设备和打印机）。右键单击 Zebra ZXP Series 3 Card Printer （Zebra ZXP Series 8 卡片打印机）列表。选择 Printer properties （打印机属性） > Device Settings （设备设置）；然后单击 Tools （工具）按钮。从 Print Test Card （打印测试卡片）下拉菜单中，选择所需的测试卡片 。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac83628493fb7&type=max)

14. 单击 Print（打印）按钮打印选定的测试卡；请参见下面的测试样卡。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac83657e43fb8&type=max)

15. 如果测试样卡打印成功，即可使用打印机打印更多卡片。

六、 常见问题

1. 如果打印出来的卡片颜色不均匀或者缺色，请更换打印机色带 。

2. 装完后不要随意更换打印机连接线的USB口，否则会导致打印 机无法使用。
