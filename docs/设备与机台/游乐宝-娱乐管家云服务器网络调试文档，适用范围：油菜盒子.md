# 一、作业说明

本教程用于云服务器只使用油菜盒子的场地使用；

使用的主路由器型号为TP-LINK TL-R479GPE-AC

刷卡终端使用数量：少于100个

# 二、作业准备

调试电脑*1台

网线*1根（用于调试使用）

AP已提前挂顶，AP线路连接到机柜中

外网已经通路

标签纸

# 三、注意事项

1.监控网络不要与系统网络共用主路由

# 四、作业标准

1.机柜整洁

2.线路清晰

3.网络平均延迟低于40ms

# 五、作业步骤

### 1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bad4cce&type=med)

### 2.把电脑的网线接到路由器LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bb84ccf&type=med)

### 3.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bc34cd0&type=med)

### 4.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bcc4cd1&type=med)

### 5.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bd64cd2&type=med)

### 6.跳过快速配置界面

### 7.选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bdf4cd3&type=med)

### 8.选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“10.0.0.1”-将【子网掩码】设置为“255.255.0.0”-然后点【设置】，按下图设置

注意：其他需要固定IP的设备配置连接时，只需要选择子网地址，由系统自动生成的地址来连接即可。如柜台碎票机连接，在写配置卡界面中，选择网络类型为子网类型，则会自动生成地址。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595be84cd4&type=med)

### 9.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

### 10.进入【LAN设置】，找到【DHCP服务】，将DHCP服务开打，开始地址为“10.0.10.2”；结束地址为“10.0.10.254”，网关地址为：“10.0.0.1”，首选DNS服务器：119.29.29.29，备用DNS服务器：223.5.5.5，然后点保存设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914a84bf636cc6&type=med)

### 11.选择【AP管理】-【AP设置】-将【AP管理功能】勾选上，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595bff4cd6&type=med)

### 12.选择【AP管理】-【无线网络设置】-将【多频合一】关闭掉

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595c094cd7&type=med)

### 13.登录油菜花后台系统，

游乐宝路径为：【后台】-【设备】-【基础设置】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【外场】并填入门店域名地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

娱乐管家路径为：【后台】-【终端】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【外场】并填入门店域名地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595c134cd8&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f85612b765bdf&type=max)

### 14.继续回到路由器设置界面，选择第一个无线网络设置，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595c1e4cd9&type=med)

### 15.如下图所示设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595c2b4cda&type=med)

### 16.点【AP管理】-【射频调优】-【信道调优】选择启用-【2.4G信道集合】改成1.5.9.13,-最后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018681595c364cdb&type=med)

### 17.设置完毕后，油菜盒子会自动连上该网络，并且电源、联网和强度灯均为绿色灯，待机为红色灯闪烁。
