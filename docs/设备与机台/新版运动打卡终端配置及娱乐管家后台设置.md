# 文档说明

此文档用于指引如何配置新版运动打卡系统使用及功能使用。

# 功能说明

1.支持随机打卡获得成绩

2.支持按顺序打卡获得成绩

3.支持挑战类打卡，按最高成绩计算打卡成绩

4.支持达成一定成绩获得奖励

5.支持成绩展示在任务机中

# 所需工具

1.螺丝刀*1

2.电工胶布*1

3.斜口钳*1

4.显示屏*1（配置时需要）

5.鼠标键盘*1（配置时需要）

# 硬件安装前置准备工作

#### 1.打卡点位预留24V电源（0.5mm电源线）

方式一（推荐此方式：攀爬区等游客容易接触到的地方不建议直接预留220V电源，容易产生安全隐患）：

电线预留按标准预留， 预留的电线电压在总电房/天花顶部电箱通过变压器转换成24V，打卡终端直接直接接正负极通电使用。

方式二：（适合于非攀爬类项目，游客不容易接触到220V的场景）

电线预留没有按标准要求预留，预留的电线电压是直接从总电机出来的220V，需要单独在每个预留的电线处，单独接变压器把电压装换成24V，再接入打卡终端电源正负极（此场景需要额外注意变压器的存放位置）

注意事项：24V电源线建议不超过50m，否则可能有电压衰减引起打卡终端不正常运作。

## 项目游戏设置

### 总体说明

项目游戏设置用于设定该项目完成的条件和分值计算逻辑，玩家需要满足该逻辑才算游戏结束并获得分数奖励。

### 字段说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f8e30dac92aa8&type=max)

打卡得分：开启后，每打一个终端，则直接获得得分

随机打卡：当开启打卡得分后，每个终端可单独设置对应的分数，随机打卡则获得对应的分数。可同时设置最对打多少卡才有分数和封顶能获得多少分数（达到最低要求打卡数后会一次性计算所有的分值）。使用随机打卡是，同一个终端只能获得一次分值。

顺序打卡，分数相加：当开启打卡得分后，每个终端可单独设置对应的分数，需要要求玩家依次打卡才能获得积分，跳过顺序是无法完成打卡并显示X的标识。

去

计时得分：开启后，计算从标记为开始的终端开始，计算到最后一个标记为终点的终端的总时长，根据时长进行得分。（一次性计算）

计时规则：用于设置起点到终点每个等级的具体时间段及对应获得的额外得分。

游戏超时：设置后，超过设置的时间则代表此项目游戏结算，并结算获得得分。后续在打卡也不会再获取得分。

超时没有成绩：勾选后，超时没有成绩（包括打卡得分的成绩），不勾选则会直接结算已有成绩。

特殊设置逻辑

1.如果想设置打卡封顶分值，可设置有效至少打卡数为0，并设置累计封顶多少分。

2.只有1个打卡终端时，不支持设置计时得分和超时没有成绩这两个功能。

## 得分后奖励设置

#### 总体说明

目前新版互动打卡能获得的奖励分两种，一种是储值类的奖励，通过设置【任务】获得，一种是勋章，通过【成就】获得。每个独立的项目只可以设置一种类型的【任务】和【成就】。

#### 常见玩法问题

1.我想实现能力值的体现，可以实现吗？

答：如果所有储值都不使用的情况下，可以实现，只要把储值类型的名称改为对应的能力值名称即可，比如【代币】可以更名为【力量】、【金币】更名为【敏捷】等。配合【新运动馆】的小程序界面，玩家就可以清楚看到自己的能力值。

2.如果想实现持续游玩可以获得经验，并形成不同的等级，如【新手】【学徒】【资深】【大宗师】等不同等级。可以实现吗？

答：可以，在设置对应的任务或者成就时，勾选获得成长值即可，配合【会员自动升级】功能即可实现游玩→完成任务→获得经验→累积经验升级这个流程闭环。

3.在问题一中，相关能力值有哪些好用吸引的点？

答：常见的推广方式有：献祭一定能力值可获取神器（礼品兑换）

4.相关的任务以及获得的能力玩家可以从哪里查看到？

答：【新运动馆】的小程序界面中，【任务】功能可以查看到。

字段说明（任务相关）

项目：选择需要设置的游玩项目，显示所有的项目类型为模拟机、成绩终端。

玩法：设置该任务成就的属性，会体现在任务机和小程序中。其中，游戏得分，根据打卡分数来获取奖励，并在任务机中安分数显示排行；而，计时（秒）根据打卡总时长来获取奖励，在任务机中则按时间显示排行。

任务规则：根据所选项设置“阶梯规则”、“按得分倍数奖励”。填写时，如果选择阶梯规则，前者匹配的是分数，后者匹配的是奖励的储值数量及对应的储值类型。如果选择【按得分倍数奖励】，则代表玩家完的分数会直接按比例转换成奖励的储值数量及储值类型。

奖励同等数量的成长值：勾选项，勾选后，可奖励达成任务规则奖励储值的同等数量的成长值

奖励周期：“每天最多一次”即玩家每天只能获取一次奖励，若最佳成绩更新，会补足满足任务规则奖励和已获得奖励的差额奖励。“每次”即每次达成任务都能获得奖励。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f8ccf269b1dac&type=med)

字段说明（成就相关）

总体说明：成就可以是和任务同时获得，除了获取单次任务中的奖励外，还可以根据累积成绩获取成就奖励。

达成条件：一般设置为“总分”条件，其他选项均取值第三方调用我们提供的上报分数接口而获取的分数值。设置总分后，意味只要玩家持续挑战任务，获得总分超过达成条件则视为达成成就，并获得相应奖励

有效期：该成就显示在玩家勋章中的时长。

### 场景二：玩家游玩后所获得的游戏得分自动转成积分，并可以用积分兑换礼品。且每天同一个项目的游戏只获得一次奖励

设置说明：

在任务规则中，选择按得分倍数获得奖励，并选择积分即可。

在奖励周期中，选择每天最多一次。选择此规则之后，玩家当天玩同一个项目时，只会获得一次分数奖励，并且多次游玩时，如果下一次成绩比上一次好，则会补送最好一次成绩的奖励。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fac88ed7d2a7e&type=max)

### 场景三：玩家游玩游戏后，每次都能按照成绩区间获得额定数量的积分奖励

设置说明：

在任务规则，选择阶梯规则，并设置多个阶梯规则和获得的储值类型。设置后，系统会跟进获得的分数区间给予对应的储值奖励。

而任务周期，选择每次，代表每一次游玩都能获得奖励。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fac9168842ac1&type=max)

### 场景四：玩家每次游玩后，都能获得经验，达到一定的经验后可以升级。

设置说明：

在任务和成就规则中，都有勾选奖励成长值的选项，勾选够，获得多少储值奖励也会同时获得对应数量的成长值。

然后再【会员自动升降级】中设置对应的成长值升级方案即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fac95c01f2aea&type=max)

### 场景五：想设置玩家完成特定高难度的任务后，获得勋章，如何设置？

设置说明：

在成就一栏设置达成条件，并且上传对应的勋章图库即可。如有储值类型的奖励，可设置对应的奖励条件。

特别注意：分项得分功能，仅用于特定厂商的对接设备上传分值才支持，常规条件下只支持总分达成功能。

# 测试要求

1.打卡终端反应不超过1S。

2.打卡终端打卡后无掉线情况。

3.各个项目玩法流程都需要测试一遍，并且每个项目能正常获得分数并显示在排行榜上。

# 验收要求

1.打卡项目游玩玩法正确无异常。

2.打卡项目对应的游玩奖励设置正确。

3.打卡终端无掉线、高延迟情况。

4.打卡终端显示颜色符合客户要求。

5.打卡终端安装位置结实，无掉落风险。

6.打卡终端电源位置隐蔽，无漏电或者误触风险。

# 常见问题

1. 若打卡成绩无在【运动馆游戏分数查询】中显示

需检查边缘网关状态，心跳恢复正常后会自动重新上报成绩

2. 打卡终端异常或更换绑定门店

需在原绑定的【游乐项目】中删除打卡终端，然后到游智云上解绑该终端后，再进行重置打卡终端流程。

3.新增打卡终端报错提示
22：找不到会员信息
27：该会员找不到套票
30：套票过期
4.按顺序打卡模式下，如果玩家没有按顺序打卡，被打卡终端屏幕会显示玩家应打卡的终
端序号。如：玩家打卡起点后，直接去打卡“03”的终端，“03”终端会报错，并显示
“02”的序号，提示玩家应该去打卡“02”号终端
5.现在玩家可以多次打卡同一打卡终端，但得分和时间只会记录第一次打卡的数据。
