# 应用场景
当门店有闸机并且需要使用闸机来录入人脸时，可以按照下面教程来开通闸机管理员卡来使用该功能。

# 操作流程
路径：设置→用户管理

#### 进入【用户管理】界面，选择需要开通闸机管理员卡的员工账号，在【员工卡类型】选择“闸机管理员卡”，然后把空白卡放到读卡器上，点击【读卡】，读卡完成后，点击【确定】完成开卡
