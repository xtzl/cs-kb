# 文档说明

由于目前网卡驱动版本较多，有可能在安装电脑操作系统后无法用万用驱动等工具来驱动系统时，可尝试以下方法来实现。

本文档针对是win10、win11或者win7的操作系统的解决方法。

# 操作说明

## 1.确认网卡型号

在未驱动的情况下，可以通过设备管理器中查看目前识别出来的硬件型号

路径：右键点击此电脑→管理→设备管理器→网络适配器；

若网卡未识别，会显示“未知设备”或带黄色感叹号；右键选择属性→详细信息→硬件ID，复制以“PCI\VEN_”开头的字符串（如PCI\VEN_14C3&DEV_7922）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d85b8f97f375c&type=max)

## 2.通过devicehunt.com查询，可确认网卡为厂商及型号

如上述案例，找到的是厂商是MediaTek，型号MT7922A22M

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d85bd2b99376e&type=max)

搜索出来结果如下

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d85eefea237ed&type=max)

3.通过https://driverpack.io/zh-cn 网站寻找相近的驱动（可以尝试一下，但是成功几率比较低）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8600b1af3829&type=max)

## 3.查到型号后就可以通过网页找一下对应的通用驱动了

一般驱动要么就是联发科要么就是intel。有针对性找对应的驱动下载。

如果下载的是压缩文件，那就需要手动安装一下

步骤为：

步骤1：下载MTK通用驱动（可从CSDN博客或联发科官网获取，如MTK_USB_Driver.zip）；
步骤2：解压驱动文件，进入“Win7”或“Win10”文件夹（选择对应系统版本）；
步骤3：右键点击此电脑→管理→设备管理器，找到“未知设备”（网卡），右键选择更新驱动程序；
步骤4：选择“浏览我的计算机以查找驱动程序软件”，定位到解压后的驱动文件夹，点击下一步；
步骤5：若系统提示“Windows安全警告”，选择“始终安装此驱动程序软件”；
步骤6：安装完成后，重启电脑，确认网卡识别正常。
