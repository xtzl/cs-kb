# 文档说明

此文档用于针对弹珠机安装时指引如何接线的说明视频

# 具体操作

## 步骤一：卡头安装

弹珠机卡头安装位置如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9182e0451a&type=med)

## 步骤二：如何接投珠信号线

打开机器面板：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9182e6451b&type=med)

弹珠机投珠光眼线如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9182ee451c&type=med)

卡头投币线接弹珠机：

把弹珠机的投币信号线剪断，分别接入投币信号入投币信号出，出如下图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9182fc451d&type=med)

## 第三步：接卡头12V供电线

12V卡头供电一般弹珠机厂家有提供电源对接头，在机器后面：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a918302451e&type=med)

## 第四步：接入弹珠机出珠信号线

弹珠机光眼：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a91830b451f&type=med)

卡头光眼线接弹珠机：

把弹珠机的光眼信号线（如图所示为灰色线）剪断一分二，分别接入光眼信号入，光眼信号出如下图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9183144520&type=med)

## 第五步：接入马达使能

弹珠机马达线：

白色：负极 橙色：正极

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a91831c4521&type=med)

卡头马达线接弹珠机：

把弹珠机的正极剪断，分别接入马达信号入，马达信号出如下图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d8a9183244522&type=med)
