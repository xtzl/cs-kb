# 一、文档说明

本文档用于说明在如果遇到置换系统订单时，需要将客户原来的设备进行销毁。并记录在验收单中。

# 二、销毁目的

第三方设备在置换系统商务沟通中，已包含原设备的处置权转交至油菜花，油菜花有权对这些第三方设备进行处置。但由于第三方设备对油菜花并没有用处，且寄回产生的运费过于昂贵，所以油菜花侧采用现场销毁方式，后续客户自行处理废物的流程。

# 四、哪些需要销毁哪些可以保留

## 销毁部分：

1. 所有第三方的自助设备（如兑币机、存币机、售卡机、售票机等），不包含二次利用全换油菜花配件的自助设备

2. 第三方加密狗

3. 卡头部分

## 可保留部分：

1.收银电脑/办公电脑等设备，包括对应的配套设备，如小票打印机、扫码枪等。

2.通过便携式闸机改造二次利用的第三方闸机。

3.二次利用全换油菜花的自助设备。

# 五、销毁流程

1.销毁过程需要全场录像，或拍照记录已销毁的设备图片。

2.销毁方式为直接破坏屏幕。主板拆卸后寄回（邮费由公司承担）。

例如：兑币机烧毁，找到对应的主板，在断电情况下，直接拆除主板寄回（邮费由公司承担），而屏幕进行破坏（注意破坏时玻璃飞溅，建议先用胶布封好再砸）。

# 六、常见问题

问：如果客户不同意对第三方设备进行烧毁应如何处理

答：将相关情况反馈给助理/销售，由助理/销售进行沟通确认，按最终确认情况来进行处理

# 七、违规说明

由于客户和公司签订了置换合同，并从油菜花拿到置换补贴。所以技术支持在现场有监督销毁的义务。如果后续发现技术在现场未尽到监督销毁/回寄等义务且客户将设备再次二手贩卖的情况，公司会将追究相关损失。
