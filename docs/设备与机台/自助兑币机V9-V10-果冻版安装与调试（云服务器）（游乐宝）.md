# 一、 作业说明

自助兑币机V9/V10/果冻版是一款集自取币、买币、充值一体的并支持刷会员卡、二维码、微信人面识别支付的智能售币终端。

# 三、支持功能

1.散客购币、会员充储值、会员提币、会员余额查询、储值转增功能。

2.美团抖音快手核销游戏币套餐、支持核销时强制要求注册会员并可选择核销后自定义出实物币数量。

3.支持赠币券核销、支持口令补币功能。

4.首页支持半屏广告或待机模式下全屏广告。

5.支付方式支持现金支付、微信支付宝支付（原生/汇付）、预存款支付、人脸支付（仅部分配置支持）

6.支持故障外观显示红灯醒目提醒以及余币不足后台提醒。

# 四、作业准备

1.十字螺丝刀*1

2.预留可通外网的网线以及220V电源线

3.（云服务器）提前准备好门店域名地址，一般格式为：y********.yun.youcaihua.net:88/admin

# 五、注意事项

1.挪动位置时，请提前将币清空，并至少2人以上进行搬运，以免发生意外

# 六、 作业标准

1.币杯架安装到位

2.系统连接完毕

3.测试各项功能均为正常

## 2.套餐上架

说明：

兑币机套餐是直接获取系统的套餐来使用，根据系统设置的售币类型不一样会有不一样的效果。

游乐宝上架流程：

a.登录后台-【商品】-【商品管理】-【新增】-【游戏币】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc2db066b1ce3&type=max)

b.填写参数，注意，售币类型会决定着套餐会在哪个位置呈现在兑币机上，请根据情况来选择

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc2dffd401ced&type=max)

售币类型（自动）：在兑币机上【买游戏币/非会员购币/购币】和【会员充值/会员优惠购币/充值】界面均显示该套餐

售币类型（实物币）：在兑币机上仅【买游戏币/非会员购币/购币】界面中显示

售币类型（代币）：在兑币机上仅【会员充值/会员优惠购币/充值】界面中显示

注意事项：当兑币机无上传任何广告时，套餐会显示在首页中，但售币类型为自动的套餐，仅在首页直接购买套餐中显示在会员充值一栏。

## 3.兑币机加币

说明：当兑币机缺币需要加币时，需要将加到兑币机的币数输入到兑币机中，以更新兑币机库存。另外，兑币机加币既可以通过兑币机上的加币功能加币来增加，也可以从收银台的【更多】-【加币清币】功能中来增加。对于门店库存来说，每次加币的过程实际上是从系统的“实物币主仓”将“实物币”这个商品调拨到“兑币机仓库”里面的过程。

操作方法：在兑币机设置界面，选择加币清币功能，进行设备加币，也可以在收银台设置界面-加币清币功能里面进行加币。

## 4.兑币机清币（盘点币数）

说明：兑币机需要定期对机器里面的游戏币进行盘点，以修正设备内的币数。注意，盘点后如果出现盘点差异，此差异部分都是关联到“实物币主仓”，比如盘点后，盘点数量为0，那就代表着原来记录的数量都会全部调拨回“实物币主仓”里面。

操作方法：进入到兑币机后台，选择【加币清币】-【清币】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc23061841aa0&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc230b15b1aa1&type=max)

点击【确定】后，币都全部数出来，并显示本次数币数量为多少，点击确认完成即可完成同步，此时只需要将币倒回兑币机即可完成全部步骤。

## 7.升单功能设置

说明：兑币机可以设置升单功能，当游客购买套餐时，兑币机会推荐游客加钱可以购买更优惠的套餐，并可设置首次购买时享受一定的奖励

设置逻辑：

a.设置游戏币套餐时，需要设置对应的套餐的原价，用于系统计算折扣率使用，推荐游客时，会按照折扣率来推荐优惠套餐。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc2e87ed71d21&type=max)

b.在后台-【线上】-【盈客宝管理】-【营销活动】-【升单】中开启升单功能，并进行设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc2eaab901d33&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc2eb391e1d35&type=max)

#### 注意事项：

1.开启升单功能后，不单单只是兑币机购币可以享受升单优惠，小程序购币同样也能触发相同优惠，收银台不触发；

2.升单可以设置加赠，但加赠的前提是需要成为会员才能加赠，并且一个会员只会享受一次；

3.加赠内容可以是储值，也可以是优惠券。

# 九. 整机测试

测试一：读卡是否能正确读取出会员信息；

测试二：扫会员二维码是否能正确识别会员资料；

测试三：纸钞（1元、5元、10元、20元、50元、100元）功能是否能正确识别纸钞；

测试四：通过提币功能，测试是否能提取正确的币数，至少提取20币以上，并且至少测试3次。

# 十、 常见问题

问题1：套餐在兑币机上不显示。

解决：检查兑币机游戏币库存是否多于套餐币数；或者游戏币套餐是否限制售卖终端。

问题2：纸钞机不能正常塞钞票。

解决： 检查纸钞机是否卡纸

问题3：出币数量不准确。

解决：检查马达光眼是否正常；或者检查币道是否堵塞或者偏移。

问题4：实物币尺寸太小，导致币出币时不计数

问题5：如果忘记管理密码，如何进行重置？

答：将键盘接入到背面的USB口中，并长按右上角进入设置界面，等待出现需要输入密码的地方时按F12直接进入设置界面，然后点击修改密码即可。

答：校正本地服务器时间，检查本地服务器时间是否跟世界时间一致，若不一致更改一致即可；
