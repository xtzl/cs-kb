# 文档说明：
本文档旨在说明自助售票机腕带打印模版是如何调整的

# 调试准备：
1.自助售票机通电通网，且已完成配置

2.打印腕带（要明确知道腕带尺寸）

打印腕带尺寸入如图所示：本文以该尺寸为例，作为参照说明

腕带全长尺寸：260mm（票高）X26mm（票宽）

腕带自助售票机打印区间尺寸：85mm（票高）X26mm（票宽）

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1738742431093-f8c616e3-8618-4268-bcd2-053f749dd882.png)

### 设备调试：
#### 自助售票机腕带打印机调试：
打开自助售票机背部位置，找到打印机，并开始摆放腕带

1. 将打印机用力往后拉动

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1738746494189-2015f330-a156-4707-b26a-8879681dcf0a.png)

2. 打开打印机上盖

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1738746537881-bf59976e-7648-42c9-b6cb-27286022ae2c.png)

3. 拆开固定轮，可旋转固定轴调整腕放置空间，并固定腕带，将一卷腕带一端置于固定轴，盖上打印纸上盖

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1738746601044-053b90ab-f72b-4184-9e05-8f91dc21ab56.png)

4. 用力将打印机往前顶，直至顶到固定点，无法轻易拖动为止

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1738746813415-a89e6944-4929-4c42-b999-90888c71d256.png)

6. 摆放好自助售票机另一端存放点位，将腕带卷套进固定点位，确保腕带卷不会轻易散落

# 常见问题
#### 1.后台打印模版设置好了，但打印效果跟后台打印模版偏差相差过大。
解决：

检查后台自助售票机终端是否有关联正确的打印模版，是否有选对正确自助售票机终端。

#### 2.打印显示的内容跟打印模版偏差太大
解决：

可适当调整缩小打印模版的画布尺寸，或者自助售票机打印机设置的票宽票高。
