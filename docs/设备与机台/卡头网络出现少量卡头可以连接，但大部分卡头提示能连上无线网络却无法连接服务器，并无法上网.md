# 现象说明

1.使用的是TP-LINK T系列路由器（3220T、5120T），或者YLR450-E系列企业路由器（特点，各个端口自定义，并且没有傻瓜式WAN LAN口设置）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e43543c41752c&type=max)

2.使用了255.255.0.0子网掩码（如下图所示），并且DHCP也使用了多个网段，（如下图2所示）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e434a405d7483&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e434eca7174b6&type=max)

3.少量卡头可以连，并且可以连接的卡头IP应该为10.0.0.**网段，而10.0.**.**网段的卡头全部不能连

# 原因分析

在使用这类型的路由器时，如果使用快速配置来进行配置，配置后默认的为lan口网段/24，如10.0.0.0/24，对应就是只在10.0.0.1~10.0.0.254之间IP地址与WAN口（GE1）通讯。（说明：/24=255.255.255.0）

而自动分配IP时（DHCP设置），分配的是10.0.0.1~10.0.255.254，导致有大量的IP地址是无法和WAN（GE1）进行通讯，导致网络不通

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4346cf57747c&type=max)

# 解决方法

将NAT设置中 LAN出口到GE1的规则中，源地址范围扩大，并重启路由器即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e435174b57504&type=max)

# 其他问题可能性

如果NAT列表为空，也有可能导致无法连网，手动添加一个规则即可。
