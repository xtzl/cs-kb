# 一、作业说明

本教程用于油菜花提供网络设备的接线使用教程，涉及的网络设备如下：

主路由器：TP-LINK TL-R479GPE-AC

交换机：TP-LINK TL-SG2218（可变更其他交换机，不影响使用）

AP：TP-LINK 1500MTL-NXAP1500-GC2-PD/AX1500（同品牌其他型号也支持）

刷卡终端使用数量：少于100个

# 二、作业准备

光猫设置为自动获取IP

短网线*3根

AP已提前挂顶，AP线路连接到机柜中

外网已经通路

标签纸

# 三、注意事项

1.网络设备已经在出厂时已经进行配置，无需额外配置。

2.所有卡头配置都需要刷通用配置来进行配置，不支持自动连WIFI功能。

3.监控网络不要与系统网络共用主路由。

# 四、作业标准

1.线路需要清晰连接

2.对各个设备进行标注

# 六、油菜花系统配置

#### 钻石V9、魔方V9通用配置卡配置

路径：

游乐宝：后台→设备→基础设置→卡头WIFI通讯设置→通用配置卡→重新设置通讯网络

娱乐管家：后台→终端→卡头WIFI通讯设置→通用配置卡→重新设置通讯网络

设置内容：

①服务器地址填写自己服务器地址，本地服务器默认为192.168.110.10:9999；云服务器地址则为域名地址

②WIFI名称设置为：YCH5G WIFI密码设置为：****（已脱敏，请向运维索取）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019aa056478e7047&type=max)

#### 反扫卡头、果冻卡头、全能投币器单独配置卡设置

路径：

游乐宝：后台→设备→基础设置→卡头WIFI通讯设置→单独配置卡

娱乐管家：后台→终端→卡头WIFI通讯设置→单独配置卡

设置内容：

①设置SSID：YCH2G WIFI密码设置为：****（已脱敏，请向运维索取）

②通讯设置如下：

网段类型设置为：其他地址

子网掩码设置为：255.255.255.0

卡头分配网段：设置为192.168.110.100

默认网关：192.168.110.1

服务器IP：如果是本地服务器则填写自己服务器地址，默认为192.168.110.10:9999；如果是云服务器就留空。

服务器域名：如果是本地服务器则留空；云服务器地址则为域名地址。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019aa05b1d817059&type=max)

# 七、配置卡头注意事项

#### 需要固定的设备（柜台碎票机、3P存票站）

固定IP地址段为192.168.110.20-192.168.110.99

#### 钻石V9卡头、魔方卡头、油菜盒子

1.所有卡头需要刷通用配置来配置后再绑定终端

#### 反扫卡头、果冻卡头、全能投币器
配置卡头独立IP网络，可使用50到99之间的网段
