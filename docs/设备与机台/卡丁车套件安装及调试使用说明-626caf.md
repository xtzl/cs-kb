# 一、说明

卡丁车套件（通用套件）用于安装在卡丁车上，通过控制开关（一般控制油门开关）来达到控制卡丁车的效果。

# 二、产品参数

1、产品电压DC＜48V—0.8A、DC5V—0.4A；

2、额定功率100W；

3、产品材质：ABS、PVC、亚克力、五金

4、使用温度：-20℃--60℃

5、产品尺寸：

卡丁车套件电源板W x D x H 120*90*48mm

# 六、安装说明

1.使用开孔器在卡丁车适当位置开孔，用于放置安装按键

2.翻开卡丁车底部，放置卡丁车地感，用扎带固定

3.拆开卡丁车面板，找到油门控制线，卡丁车电源线如下图接入线（卡丁车与油门线路颜色可能与下图有所差异，请根据实际情况来接入）

# 七、调试说明

## 1.准备说明

1)系统要区分本地服务器和云服务器，如果是本地服务器，需要开通云互联功能。

2)卡丁车功能需要额外开通卡丁车增值服务，需要联系油菜花实施组组长进行开通，不需要额外费用

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b33644141a9&type=med)

3)调试前需要对卡丁车进行编号，以方便管理。

4)卡丁车支持收银台启动及POS机启动，由于卡丁车需要服务员管理，如果卡丁车入口没有收银台，建议配备POS来扣费启动。

5)确保业务系统是否支持卡丁车，游乐宝需要8.0.9以上，娱乐管家暂不支持。

6)卡丁车需要有电视显示排行榜等信息，需要确保电视是否为智能电视，并支持安装APP

## 3.后台其他参数设置（主要涉及游玩模式、计费模式等设置）

1)设置游玩方式（计圈/计时）

说明：此方式决定着游玩的计费方式

计圈模式：设置游玩一次可以玩多少圈，假如设置为3圈，当卡丁车已经跑完3圈后，就会开始倒计时10秒，随后停车。（优点，顾客无论水平如何，都可以完成预设的圈数，并且每圈都会有相关的单圈成绩，较为适合竞技类卡丁车；缺点是假如顾客水平较低的情况下，整体游玩时间偏长）

计时模式：设置付费一次可以玩多久，并可以设置计时结束后是否到终点后才停车，假如设置为10分钟，卡丁车游玩10分钟，在最后一分钟快结束时开始倒计时。

2)设置默认圈数及最多圈数（计圈）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364cd41b4&type=med)

说明：默认圈数为服务员为顾客扣除一次游玩费用后，默认开启的圈数，这个圈数可视情况增加，但增加的最大值不能超过最多圈数

3)设置默认分钟及最多分钟（计时）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364cd41b5&type=med)

说明：默认圈数为服务员为顾客扣除一次游玩费用后，默认设置的可玩时间，这个时间可视情况增加，但增加的最大值不能超过最多分钟数。

4)设置停车提醒（计圈）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364dd41b6&type=med)

说明：在通过最后一圈后，开始倒计时多少秒停车。

5)设置停车提醒（计时）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364ec41b7&type=med)

说明：设置计时后，计时结束倒计时多少秒停车，可设置经过最后一圈终点后再停车。

6)设置排行榜计算规则

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364fc41b8&type=med)

7)设置计圈器感应间隔

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f1b3364fc41b9&type=med)

说明：此间隔为卡丁车重复经过计圈器后，多少秒内不再重复感应（用于防止顾客走错路重复经过导致计时时间错误的情况）

8)设置背景图片

设置排行榜的背景图片

## 4、遥控器使用

1.上个记录按键：回到上个记录的数字

2.下个记录按键：回到下个记录的数字

3.复位按键：复位卡丁车的所有状态，可强制解绑卡丁车

4.计圈按键：在已经输入数字的情况下，按“-”进入计圈模式

5.计时按键：在已经输入数字的情况下，按“+”进入计时模式

6.清除按键：卡丁车未启动时，清除数码管一位数字，以此类推

7.数字按键：设置游玩的圈数/时长

# 十、常见问题

1、新出厂卡丁车可能遇到无法激活的情况，一般由于卡丁车在出厂前进行绑定检查，出厂时未进行解绑，如出现这种情况，需要手动解绑一下，解绑方法如下：

第一步，确认卡丁车编号

第二步，在网页上输入以下内容：https://yzy.gzych.vip/yzy/api/v1/device/unbind/卡丁车盒子串码

回车后即可强制解绑

2.常见错误代码

H01 扫描wifi
H02 游智云连接测试成功，获取MQ信息，卡在H02的话，就是没激活
H05 获取IP成功，开始连接游智云
H06 获取升级信息
H08 等待绑定车辆
H11 连接游乐宝

E01 没有注册或者绑定
E02 没有找到AP
E03 连接AP超时
E04 连接游智云失败
E05 获取游乐宝地址失败
E06 获取MQ失败
E07 获取注册号失败
E08 轮询注册失败
E11 连接游乐宝失败
E12 AP密码错误
