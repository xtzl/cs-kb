# 文档说明

此文档针对客户以下需求所编写的操作文档，用于指引如何批量绑定一次性二维码腕带（进出闸机专用）。

# 客户案例情况及需求说明

1.场地闸机只用于进出，不用于核销游乐套票。

2.游客需要进闸时，使用场地派发的一次性二维码腕带（腕带不需绑定会员）。

3.一次性二维码腕带编码需批量导入系统，支持场地长期派发，且腕带首次使用后仅当天有效。

4.一次性二维码腕带可自行采购，票码要求：15位以上数字+字母。

# 前置条件

1.开一个任意级别的会员账号，可开电子会员或者实体卡，实体卡可作为内部员工卡。

参考操作：《如何设置入会套餐（连锁）》《如何给顾客开卡（连锁）》

2.新建闸机专用的游乐套票，仅用于闸机刷一次性二维码腕带进出

参考操作：《如何设置游乐套票（连锁）》

特殊注意设置内容：

a.设置套票时，有效期建议设置1年（即未使用的腕带1年后失效），首次使用后1天内有效（即使用中的腕带当天失效）；

b.记录套票编码，后续批量导入一次性二维码腕带票码时需要用到；

c.添加需要闸机绑定的游乐项目；

d.价格设置为0元，其他默认即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e48544f3f095d&type=max)

3.准备好已经做好的腕带二维码。

# 操作步骤

1.登录总部后台，并跳转到门店系统（注意：一定要在总部系统操作）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4862f6ad0987&type=max)

2.在【会员】→【会员资料导入】→【下载模板】对模板进行下载。

也可以通过以下链接直接下载模板

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/%E5%AE%9E%E6%96%BD%E7%BB%84%E5%AE%89%E8%A3%85%E5%B7%A5%E5%85%B7/10.%E5%85%B6%E4%BB%96%E5%AE%A2%E7%94%A8%E6%96%87%E6%A1%A3%E6%A8%A1%E6%9D%BF/%E4%BC%9A%E5%91%98%E5%A5%97%E7%A5%A8%E8%B5%84%E6%96%99%E5%AF%BC%E5%85%A5.xlsx

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e48646816098c&type=max)

3.打开模板，并对模板进行编辑，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4869c25b09dd&type=max)

4.将编写好的套餐导入模板，在系统界面中的【选择文件】进行选择

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e486ad06a09e0&type=max)

5.选择完毕后，确认导入数据是否有问题，没有问题则点击导入完成操作。导入后，对应导入的票码即可实现直接过闸的功能。
