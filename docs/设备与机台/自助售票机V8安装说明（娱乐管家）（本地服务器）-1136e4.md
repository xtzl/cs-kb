# 一、作业说明

本说明用于指导如何正确安装自助售票机v8所使用

# 二、产品外观

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e019201e&type=med)

# 三、支持功能

1.支持散客通过售票机进行购票；

2.支持会员通过售票机进行取票；

3.支持线上平台核销，支持票付通平台、美团、抖音、快手平台；

4.支持微信、支付宝、现金、预存款支付、微信支付支持人脸支付；

5.支持打印票平台核销后可选择支持存入会员卡中不需要出实体票；

6.支持设置购票须知；

7.支持设置购票时填写入园信息；

8.打印支持常规尺寸门票打印，也支持腕带打印，并可切换色带打印或者热敏打印；

# 四、门票纸张尺寸要求

## 纸质要求

支持彩色铜版纸和热敏纸

如果采用碳带打印方式，印制普通彩色铜版纸即可

好处:打印纸成本较低，打印效果较好，对环境温度影响较低

坏处:需要经常更换碳带

如果采用热敏打印方式，印制需要使用热敏纸

好处:不需要定期更换碳带

坏处：受环境问题影响较大，受热敏纸质量影响较大，而且热敏纸成本较高

## 尺寸要求

宽带（高度）：54mm～85mm 可调， 建议在 60~80cm 之间。

长度：最大长度 98cm。 建议：10~20cm 之间。 （票面越长，成本越高）

厚度：0.1~0.3mm 印刷铜板纸

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e021201f&type=med)

## 正面设计要求

要求每张票都预留黑边、识别孔和手撕线

打印机对每张票的识别通过以下两个方面：

1、黑边：每张票的连接处，需要设计黑边隔开，作为打印机识别每张票断开的位置。黑边

的宽度为 3 毫米。

2、识别孔：同样作为打印机识别每张票断开处的作用，长度为：1.2 毫米。

3、手撕线：是为了方便打印完门票后，手动把门票撕开。 印刷厂印制时，在此打虚线的针孔即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e0282020&type=med)

## 背面设计要求

背面设计游客须知内容，以及打印二维码信息等

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e0312021&type=med)

预留打印信息空白处位置尺寸：高度不小于 4.5 厘米，用于打印二维码、门票名称、日期、价格等信息，效果如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e0382022&type=med)

## 门票卷纸的直径要求

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e03f2023&type=med)

售票处的打印机：用的卷纸门票，总直径应小于或等于 20 厘米/卷 。

注意：如用于自助售票机，卷纸门票的总直径，应小于或等于 15 厘米/卷。

## 卷纸的方向要求

如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e1522024&type=med)

1、 卷纸的票面在外，或者背面在外，均可。

2、 “游客须知”在上部，首先进入打印机。

# 五、碳带要求（热敏模式可忽略）

宽度85毫米最大外径66毫米的外涂层碳带

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e15d2025&type=med)

# 六、作业准备

1.5mm螺丝刀*1
2.尺子*1

3.门票若干

# 七、注意事项

1.安装时，注意需要佩戴手套进行安装，内部部分五金件较为锋利
2.挪动时，需要至少2个人协助负责搬运，避免发生意外

# 八、作业标准

1.顶部发光字/广告图固定不摇晃；

2.机台放置后固定不摇晃；

3.打印纸安装到位；

4.门票内容能正确打印相关内容，切纸正常；

1.拆除设备包装，检查设备整体外观是否完好无损。

## 打印纸安装

1.装纸前需根据票使用的票纸调整打印机纸槽宽度(见下图)；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e37c202e&type=med)

2.装纸：打开电源，将纸装入打印机入纸口。（见下图）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e388202f&type=med)

注意，如果纸卷尺寸较大，可将票纸放置到自助售票机底部空间内。

3.自检

# 十一、调试流程

1.设备开机，等待启动完成

2.开机之后，弹出服务器连接地址

本地部署，则输入本地ip地址＋9999，具体格式如下：

***.***.***.***:9999

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

输入完成，点击确认，若页面提示连接服务器失败，请检查网络是否正常，网线是否有问题，并且确认网络跟服务器在同一局域网内。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e4c12032&type=med)

3.点击确认后，正常完成连接。

4.长按右上角，进入设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e4c92033&type=med)

5.提示输入管理密码时，输入默认密码：****（已脱敏，请向运维索取）261或者1，进入设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e4d12034&type=med)

7.进入后台之后，选择设置本机的功能特征。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e4d92035&type=med)

8.根据现场情况进行设置，相关参数说明如下

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e5112036&type=med)

- 首页显示：可设置购票功能和取票功能开关

- 支付方式：可设置购票时可使用哪些支付方式，注意，刷脸支付仅支持使用原生支付的微信支付，如果使用汇付支付等聚合支付平台则不支持。

- 取票方式：可设置支持哪些渠道取票

- 售票方式：

存入会员指当进行售票后，可选择直接存入会员卡内而不需要打印实体票，游客可凭会员卡、小程序会员二维码方式进行入闸

打印套票指进行售卖后，直接打印套票

会员打印多张票，勾选后会员可一次性打印多张门票

- 会员登录：可设置多种类型的会员登录方式，注意，刷脸登录仅支持使用原生支付的微信支付，如果使用汇付支付等聚合支付平台则不支持。

- 购票信息

显示购票须知：当购买门票时，可显示入园须知，路径：后台→终端→入园须知设置，在后台此位置设置后，则会在购买门票时显示对应的信息。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e5f42037&type=med)

必填入园信息：当购买门票时，强制需要填写购买人信息，购买人需要填写的内容可在后台设置，路径：后台→设置→系统设置→票务基础设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e6002038&type=med)

9.设置打印设置，点击打印机设置，根据门票大小，调整打印位置。

票宽、票高，根据票的大小进行设置

偏移：一般不需要设置，默认为0或者1即可

黑标偏移：一般不需要设置，默认为0

设置参数后，点击设置打印大小和设置偏移大小，并打印测试也

注意：除此为止外，还需要设置后台的打印样式，路径为：后台→设置→系统设置→套票打印设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e7102039&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918e29e71a203a&type=med)

设置之后，测试售卖打印是否正常即可。

注意，如果使用的是腕带，则可参考此文档进行设置

《自助售票机设置打印样式调试步骤（腕带版）(游乐宝）》

# 十二、测试流程

1.测试正常购买时，打印门票是否正确打印到指定位置

2.检查打印门票是否清晰可见

3.打印后切纸位置是否正确

4.使用微信、支付宝支付是否能正常支付

5.使用现金购票是否现金都能正确识别
