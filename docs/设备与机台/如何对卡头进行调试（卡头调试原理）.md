# 一、 作业说明

本文档用于指引大家如何调试卡头与机台链接的物理参数

# 二、 作业准备

万用表，小十字螺丝刀

# 三、 注意事项

调试时不要将12V电源与地线碰在一起导致短路

# 四、 作业标准

投币数据无差异，出礼品数据无差异，出彩票数据无差异，重启后卡头正常

# 五、原理说明

### 投币信号线基本认识

说明：投币信号线一般有3种，其中最常用的是4P接口以及6P接口，不同的接口适配不同的投币器。用于投币后给反馈给机台投了多少个游戏币用。

#### 4P接口信号线

一般适用于侧投投币器（安装在游戏机侧面的投币器）通常用于模拟机居多

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019758af515f7ee2&type=max)

4P接口线路说明：

分别有12V供电线（常用黄色、红色线居多）、投币信号线（没有固定颜色）、地线（常用黑色线居多）以及码表线（可有可没有）。例如上图中的4P接口，黄色为12V，绿色为投币信号线、黑色为地线。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019758af33fc7ee1&type=max)

#### 6P接口信号线

一般适用于直投投币器，常用于彩票机居多。

6P接口线路说明：分别有12V供电线（常用黄色、红色线居多）、投币信号线（没有固定颜色）、地线（常用黑色线居多）例如上图中的4P接口，黄色为12V，绿色为投币信号线、黑色为地线。

关于投币信号线调试要点

①12V电源线只用于供电，仅在卡头没有正常工作时（如卡头不亮、卡头没有显示）时才考虑是否供电问题导致。如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019758b408e87ef4&type=max)

②12V电源和投币信号线是公用地线，所以只要12V通路，但信号的地线必然是通路不用排查，有一种情况是地线和投币信号线线序反了，此时12V和投币信号（大概率是5V信号），有电压差且公用地线的原因，通电显示正常。投币器也仅仅只是闭合信号线和地线电路产生电压差从而产生信号，所以机台也能正常使用，但接入卡头后无法投币。这时候就需要重新调整线路令线序正确。

③投币信号线有5V信号以及12V信号两种，取决于用哪个电压是机台能否识别，与投币器无关。因此遇到投币信号不识别的情况，优先考虑是否投币信号电压不对导致游戏机无法识别。

### 投币器工作原理

投币器通过瞬间变化电压产生一次脉冲信号给到游戏机主板进行识别，使游戏机识别出投了多少个游戏币。例如，投币信号线在机台没有投币的时候是5V电路，当投币时，投币器瞬间短路投币信号线以及电线，导致5V电路瞬间变成0V电路，并且马上断开短路恢复5V电路。游戏机在这过程中检测到1次电压变化，识别为投了一个币。

信号变化参考图如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197589d7dab7e93&type=max)

#### 专业名词解析

高低电平/常开常闭：高电平是指相对投币时产生的电压所处于电位的高低，例如：未投币状态下是5V信号，投币瞬间变成0V信号，此时未投币时的电压高于投币瞬间的电压，我们就称为投币信号是高电平信号。而高电平信号对应的就是常开电路，在投币器拨码中以NO（normal open）表示；反之则为低电平，也叫常闭电路，在投币器拨码中以NC（normal close）表示。

投币速度：这里的名称是指油菜花系统物理参数中的投币速度，指代连续投币信号时，单个完整投币信号时所需要的时间。

投币脉宽/输出脉宽：指每个投币完整的投币信号，变化持续时长。如上图所示。

### 彩票信号线基本认识

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019758d0fa117f7c&type=max)

#### 说明

彩票信号线由12V电源线、地线、使能信号线以及光眼信号线组合而成。彩票信号的产生其实是有两组信号共同完成出彩票的动作。其中使能信号时给予彩票器转动的信号，从机台输出到彩票器完成。而光眼信号则通过出的彩票经过彩票器的光眼产生，所以光眼信号时从彩票器输出回机台，用于告知机台出了多少个彩票。

#### 专业名称解析

使能（SW1）：机台输出给出票器的信号，持续信号，用于驱动出票器电机运作使用；

光眼/光眼信号(SW2)：出票器反馈到机台已经出的彩票数。

光眼常开/光眼常闭：指光眼信号的高低电平，与投币信号原理一致。

使能高电平/低电平：指使能未输出状态下电压相对电平，常规情况一般为低电平。

#### 调试注意事项

①光眼信号也有5V和12V区别，卡头可调试光眼信号，接安全盒子则不需要调整，自动动态调整；

②当遇到提示缺票的情况，或者出实体票一卡一卡的情况，一般是光眼信号没调试好，如果出现卡票的情况，则有可能是使能问题；不是绝对，但是可以参考。

### 出票器/彩票器工作原理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975cde6a4f0bb9&type=med)

#### 出票器/彩票器工作流程

机台输出使能信号→→→使出票器电机转动→→→带动彩票从出票器出来→→→彩票经过出票器的光眼产生计数脉冲→→→输出到机台→→→机台知道已经出多少彩票→→→机台出到目标需要出的彩票数→→→机台停止输出使能信号→→→出票器停止转动

# 六、 调试步骤

## 投币信号配置

### 第一步，先观察原厂设备的投币器的信号输出模式，一般为NO（常开）和NC（常闭）两种模式，根据原厂模式设置后台物理参数中的【投币器电平】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1e44ef65c96&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1e510e25c97&type=max)

注意：如果该设置为常闭情况下，则配置后，卡头投币信号线绿色线端要接回投币器，否则会出现机器关机后重新开机时会进入配置模式的情况。

### 第二步，调试投币信号线电压

做法：在不接卡头情况下，将万用表测试设备中的投币信号线和地线之间的电压，一般为5V左右和12V左右，根据实际情况调整卡头上设置对应的投币信号电压，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1f506635cc0&type=max)

### 第三步，调整投币速度和投币脉宽

说明：如果默认情况下投币正常，则不需要调整该参数；如果出现投币数不准，投币少币情况下，可调整该参数进行调整。

调整方法：

1.同样先观察投币器输出脉宽是否有变动，默认应该为快（20ms）。如果有特殊设置，可按照上述的设置来更改脉宽，比如，输出脉宽是中，一般则为40ms左右，慢则为100ms左右，可将对应的脉宽设置到物理参数中，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1f1e1765cb9&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1f2b42d5cba&type=max)

2.投币速度，按照投币脉宽的两倍以上进行设置即可，过少可能会存在刷卡吞币的情况

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1f418ce5cbc&type=max)

其他参数含义说明：

识别投币脉宽：投币器回传信号识别长度

投币脉冲数：默认0，代表卡头设置多少币则输出多少个投币信号给机台，如果非0情况，则无论卡头设置每局投币数多少，都强制按照该脉冲数输出信号。

## 彩票信号调试

### 第一步 先观察原厂彩票出票器参数，并按照该参数进行调整物理参数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1f966155ccc&type=max)

说明：

SW1:马达电平信号

SW2：光眼电平信号

### 第二步，通过出票器参数调整后台参数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd20a1ad05cf9&type=max)

彩票调试常见问题：

1.接卡头后出实物票出票但是不计数，机台也不扣数

答：光眼信号电压太低，有可能是出票器端的信号太低，或者是输出端信号太低导致。可以通过接入电阻拉高电压

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd2089a475cf6&type=max)

2.开机自动出票

答：开机时马达电平不对导致

3.出票直接报彩票器故障/缺票

答：答案同1

4.出实物票速度慢，出票一卡一卡

答：光眼信号、卡头光眼信号和机台接收光眼信号不匹配

### 第三步，调整其他参数（出票延迟、出票速度）

说明：

出票延迟：卡头收集信号的出票延时，一般不低于80毫秒，其中，海茂品牌部分机台采用脉冲信号，所以需要将出票延迟调至20ms，但部分延迟越低，会使抗干扰能力下降，部分特殊机台请根据《特殊机台库》进行调试

出票速度：光眼脉冲长短，一般不少于80毫秒，部分特殊机台请根据《特殊机台库》进行调试

其他参数保持默认。

使能电压和光眼：在钻石v9卡头上有使能电压和光眼电压，建议设置为5V，可更好识别到对应信号。

# 六、其他问题排查

## 钻石V2常见问题：

1.退彩票没下到会员上

答：

1)出票异常那里查一下有没有信息
2)设备日志看看有没有相关报错

3)出票的时候是否有更换会员卡的操作

2.机台数据和后台数据对不上

答：查看抄表问题分析

3.疯狂魔鬼城对账对不上

答：

1）投币线要接在盒子上
2）防干扰盒子的蓝色跳帽拔掉
3）魔鬼城对账要按照盈利来对，因为同时投币退蓝票，魔鬼城后台不记账，油菜花后台会记账，两者盈利是一致的
4）油菜花后台查对账，要按照0点到0点来查投币记录汇总和出蓝票记录汇总，魔鬼城账目是0点到0点，不要看油菜花的手机报表或者当天做实账，时间会对不上
4.刷被禁用或者无效的会员卡还能扣上一个玩家的币（钻石V2）

答：卡头升级到最新版本

5.有异常的实物币数，很大不正常（钻石V2）

答：卡头升级到最新版本

6.卡头花屏，显示不正常（钻石V2）

答：

1）重新加载图库

2）更换卡头

7.一直显示错误，请看后台日志（钻石V2）

答：刷了机修卡出礼品或者出分之类的，后台会报这个错误

8.连接云服务器，显示域名解析失败（钻石V2）

答：

1）升级卡头到DHCP版本，215以上
2）dns 填上这个119.29.29.29
3）路由器开DHCP
9.后台日志显示疑似重复出币（钻石V2）

答：

1）卡头断网，再联网的时候连续两条出币数据导致的，要补币
2）可以在后台setting文件把这个判断逻辑关闭掉

10.卡头没接投币器有实物币数据
答：把投币输入线并接到12V线上，不要悬空

11.卡头出票或者出币比机台多一张或者少一张（钻石V2）

答：彩票器或者马达光眼的常开常闭是否和后台参数设置为一致

12.退电子蓝票机台计数，退实物蓝票机台报错，但是蓝票出来了

答：马达底部接了两个光眼线，要拔掉其中一条光眼线

13.退实物蓝票，马达没有转动（钻石V2）

答：通常是因为供电问题，导致继电器没有闭合，要外接12V供电

14.报错 重复ID或者标识错误或者数据错误（钻石V2）
答：

1）通常是ip冲突造成
2）升级DHCP版本

15.报错 指令标识已经成功过（钻石V2）

答：升级卡头到最新版本

16.钻石v9升级系统后提示IO连接异常

答：升级卡头到最新版本

## 果冻卡头/反扫卡头常见问题：

1.刷卡只显示币数，不扣币（果冻卡头、反扫卡头）

答：升级卡头到最新版本，反扫卡头需要升级到125以上版本

2.同一时间会计数几个礼品（果冻卡头）

答：升级卡头到204以上版本（果冻卡头），升级卡头到126以上的版本（反扫卡头）

3.卡头没接投币器有实物币数据（果冻卡头）

答：把投币输入线并接到12V线上，不要悬空

4.报干扰，实际没干扰（反扫卡头）

答：

1）把干扰检测线去掉

2）如果还报，把干扰线并接到地线

## 魔方卡头常见问题：

1.连接业务系统失败

答：看服务器地址端口是不是显示1016，1016是旧的配置卡，不是通用配置卡

2.双塔，接安全盒子不出实物票

答：

1）出票使能要短接上拉到12V

2）或者12V加2K上拉到出票使能（使能线接2K电阻）

3.出实物票机台不计数，例如航海大富翁

答：通常是接了机械码表造成的，把机械码表线拔掉。第二个方法是要把限流电阻R68短路。

4.扫码扣币了 机台不上币

答：

1）查看异常订单信息，看看具体系统什么原因导致。

2）如果没有异常订单，有可能是小程序请求业务系统超时了，去系统日志ykb请求那里找到订单号，给欧江平查订单信息。

5.刷卡扣币了 机台不上币

答：

1）系统数据库超时，查看longtimerequest日志

2）机台异常那里，卡头增加上报功能

6.屏幕显示设备不在线或者8002

答：端口冲突，重置，重新绑定项目

7.经常会出现游智云成功，连接业务系统失败

答：服务器电脑更新TCP补丁并且重启

## 全能投币器常见问题：

1.刷卡只显示币数，不扣币

答：升级卡头到最新版本

2.卡头没接投币器有实物币数据

答：把投币输入线并接到12V线上，不要悬空

## 油菜盒子+二维码出票器：

1.出票器打印的票是之前的记录

答：油菜盒子升级卡头到17以上版本

2.常见错误报错

E01---缺纸

E02---还没登录后台或者没绑定项目

E03---请求打印时，盒子串口返回超时，检查盒子和出票器的通信线是否连接好，再按"打印"按键重新打印

E04---请求打印时，盒子处于离线状态，再按"打印"按键重新打印

E05---请求打印时，服务器返回超时或者失败，如果有票数再按"打印"按键重新打印，如果无票数长按"重置"按键清除错误

3.后台有多条重复请求记录

答：盒子和出票器通信线没接好，重复按"打印"导致的，检查盒子和出票器的通信线是否连接好。虽然后台有多条记录，但是出票器只能打一张票的。
