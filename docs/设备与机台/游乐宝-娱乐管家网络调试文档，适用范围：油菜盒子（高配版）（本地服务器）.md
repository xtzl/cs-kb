# 一、作业说明

本教程用于本地服务器使用油菜盒子的场地使用，设备清单如下：

主路由：TP-LINK TL-ER6110G

隔离路由器：TP-LINK TL-ER6110G

AC控制器：TL-AC100

建议：卡头数量大于200个以上

# 二、作业准备

调试电脑*1台

网线*1根（用于调试使用）

AP已提前挂顶，AP线路连接到机柜中

外网已经通路

标签纸

# 三、注意事项

1.监控网络不要与系统网络共用主路由

# 四、作业标准

1.机柜整洁

2.线路清晰

3.网络平均延迟低于40ms

# 五、设置步骤

## 第一部分，接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401872787229a2d2a&type=med)

## 第二部分，主路由调试

1.把电脑的网线接到主路由器（型号：TP-LINK TL-ER6110G）LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722aa2d2b&type=med)

2.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722b32d2c&type=med)

3.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722bc2d2d&type=med)

4.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722c82d2e&type=med)

5.跳过快速设置

6.选择【基本设置】-【WAN设置】-连接方式选择“自动获取IP”-点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722d72d2f&type=med)

7.选择【基础设置】-【LAN设置】-IP地址设置为192.168.10.1，子网掩码设置为255.255.255.0，然后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722e32d30&type=med)

8.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

9.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722ee2d31&type=med)

10.选择【基本设置】-【LAN设置】-【DHCP服务】，开始地址设置为192.168.10.50，结束地址：192.168.10.200，网关设置为192.168.10.1，首选DNS设置为119.29.29.29，如下图所示

说明：DHCP分配网段设置后，油菜花其他需要固定IP的设备，则使用范围外的网段，如柜台碎票机，当需要设置柜台碎票机时，可设置IP地址为192.168.10.201，避免因为固定IP和DHCP中的IP地址冲突。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019178ea78647136&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019178ea786d7137&type=med)

## 第三部分，隔离路由器调试

1.拔掉调试电脑网线，将调试电脑网线接入到第二个路由器（隔离路由器，型号：TP-LINK TL-ER6110G）

2.在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278722fa2d32&type=med)

3.在出现的界面设置路由器的用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723022d33&type=med)

4.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401872787230d2d34&type=med)

5.跳过快速设置

6.选择【基本设置】-【WAN设置】-连接方式选择“自动获取IP”-点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723172d35&type=med)

7.选择【基础设置】-【LAN设置】-IP地址设置为10.0.0.1，子网掩码设置为255.255.0.0，然后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723222d36&type=med)

8.选择【DHCP服务】，点击

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401872787232c2d37&type=med)

，对DHCP进行设置，设置如下图所示

开始地址：10.0.10.2；结束地址：10.0.10.250；地址租期：120；网关地址：10.0.0.1；首选DNS：119.29.29.29；备选DNS服务器：223.5.5.5

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723452d38&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ab0b61f6e59&type=max)

9.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723572d3a&type=med)

## 第四部分，AC控制器调试

1.拔掉调试电脑网线，将调试电脑网线接入到AC控制器（AC控制器型号：AC-100）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723622d3b&type=med)

2.在电脑打开网页，并输入地址10.0.0.253，进入界面（如果无法进入，请尝试将电脑IP固定为192.168.1.100，固定IP的方法如下：https://jingyan.baidu.com/article/a17d5285fba7dac199c8f222.html IP固定完毕后，在网页输入192.168.1.253，进入界面）

3.第一次登录提示需要设置账号及密码，账号设置为：admin密码设置****（已脱敏，请向运维索取）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401872787237f2d3c&type=med)

4.设置完毕后，用新的账号密码重新登录进去设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401872787238d2d3d&type=med)

5.先设置AC控制器的IP地址，选择【网络设置】-【接口设置】，设置ip地址，点【设置】

IP地址设置为10.0.0.253

子网掩码：255.255.0.0

网关10.0.0.1

DNS为119.29.29.29 和223.5.5.5

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ab134b06e5b&type=max)

6.保存后，调试电脑会断开连接，此时需要把电脑固定IP重新设置为自动获取IP，等待片刻后可以通过10.0.0.253重新访问到设置界面

7.设置AP分配地址，进入【网络设置】-【IP地址分配】-选择【仅为AP分配】并按照下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ab7bdcf6e75&type=max)

8.选择【无线管理】-【无线服务】，并修改第一个无线网络，点

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723b22d40&type=med)

进入设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723bd2d41&type=med)

9. 登录油菜花后台系统

游乐宝路径为：【后台】-【设备】-【基础设置】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店本地IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

娱乐管家路径为：【后台】-【终端】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店服务器IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f85816b125e13&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f85816b1c5e14&type=med)

10.修改SSID、安全选项和PSK密码，点【确定】，设置如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723cd2d42&type=med)

11.将其他无用的无线网络禁用掉，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723d82d43&type=med)

12.点

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723e32d44&type=med)

进入射频绑定界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723ee2d45&type=med)

13.勾选2.4G频段，然后点绑定（注意，如果此位置没有获取到AP列表，可重启整体网络之后再进去设置）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187278723fa2d46&type=med)

## 第五部分，连接测试

1.设置完毕后，油菜盒子会自动连上该网络，并且电源、联网和强度灯均为绿色灯，待机为红色灯闪烁。
