一、 作业说明

本教程主要围绕如何设置主路由器的操作来展开说明。

二、 作业准备

电脑一台，网线两根。

三、 注意事项

网线不要插错口

四、 作业标准

电脑开机，路由器通电。

五、 作业步骤

1. 把宽带的网线接到WAN口，电脑的网线接到 LAN 口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fb53213eac&type=max)

2. 打开浏览器，清空地址栏并输入路由器的底部管理地址 192.168.1.1，在弹出的设置管理密码界面中，设置用户名：admin管理密码 ：****（已脱敏，请向运维索取） 点击确定

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fb76f43ead&type=max)

3. 路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fbace93eae&type=max)

4. 按照快速设置向导设置WAN口数量，选单 WAN 口即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fbddbd3eaf&type=max)

5. 根据宽带类型选择 PPPoE、静态 IP 或者动态 IP 的上网方式。此处以宽带拨号上网为例，在对应设置框中选择 PPPoE 拨号，输入运营商提供的宽带账号和密码，并确定该账号密码输 入正确，点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fc0d873eb0&type=max)

6. 根据网络规划设置 LAN 口的 IP 地址及子网掩码，同时选择设置 AP 管理状态为开启或者关闭，然后点击连接网络，此处 LAN 口的 IP 地址为 192.168.100.1

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fc38ae3eb1&type=max)

7. 等待路由器完成配置并重启，至此，路由器已经设置完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7fc52803eb2&type=max)

六、 常见问题

1. 路由器WAN口有可能是自动获取的 IP 地址或者固定的 IP 地址。

2. 主路由的AP管理功能一般不需要启用。
