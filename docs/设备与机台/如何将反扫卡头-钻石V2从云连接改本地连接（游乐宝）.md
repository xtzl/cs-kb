# 为啥要改本地连接？
当门店使用本地服务器时，使用本地连接连接设备将获得更稳定的使用体验，同时也可以避免因门店外网因不可抗因素导致无法使用时，也可以不影响本地连接的设备正常使用。

<font style="color:#DF2A3F;">注意：如果场地是外场网络（与服务器不在同一局域网内），则不可以切换至本地连接。</font>



# 如何判断设备是云连接还是本地连接？
+ 反扫卡头

卡头重启时，会进入连接状态显示，如果在连接过程中显示E40（正在解析域名），则代表此卡头是通过云连接来使用的。

+ 钻石V2/V3卡头

卡头重启时，卡头显示的服务器地址为120卡头的服务器地址，且机台端口显示并非1016，则代表此卡头为云连接来使用。



# 如何修改为本地连接
<font style="color:rgb(51, 51, 51);">1.准备好读卡器以及空白会员卡</font>

<font style="color:rgb(51, 51, 51);">2.登录系统后台，打开路径为：后台-设备-终端管理-游乐项目</font>

<font style="color:rgb(51, 51, 51);">3.找到对应需要修改的项目，并点击【卡头】</font>

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1737354840396-b0a1c18f-15db-4cef-af06-e5d103278c1b.png)

<font style="color:rgb(51, 51, 51);">4.在跳转界面， 点击【刷卡】</font>

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1737354894983-35953743-7f03-4a44-b52f-09a6ee9c8c41.png)

5.将服务器通讯修改为【内网】,其他参数保持不变。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1737354936502-3871d333-bb9b-48af-8627-608e1b5d51b1.png)

<font style="color:rgb(51, 51, 51);">5.将读卡器接入电脑，并拿一张没有用过的读卡器放在读卡器上面 （注：若读卡器无反应，可重新拔插一下），完成上述操作后，点击【保存并写入卡中】</font>

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1737354998547-d393cda3-9d9b-4d0a-bc8b-515dbec55bbc.png)

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1737355029915-dfad5b78-7d81-4f3c-ad9c-eb12c09df2b5.png)

<font style="color:rgb(229, 51, 51);">（注意：网页不支持写入配置卡，需要通过客户端写入）</font>

6.<font style="color:rgb(51, 51, 51);">用铁丝短接接投币器端的黑色绿色线，约6s左右；短接完成后，卡头界面显示E06或者请刷配置卡；</font><font style="color:rgb(38, 38, 38);"></font>
