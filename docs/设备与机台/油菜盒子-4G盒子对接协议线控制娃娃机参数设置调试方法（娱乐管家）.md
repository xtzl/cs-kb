# 文档说明

油菜盒子、4G盒子支持配置后直接通过后台设置对娃娃机参数（游玩时间、出奖率、抓力等）进行设置，支持品牌为：时欣、大空艺。

# 系统版本要求

支持系统：娱乐管家10.3.7以上版本

# 接线方式

使用协议线，从盒子“游戏协议”位置接入并连接到娃娃机主板为止（除天线外其他线路不需要接）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ad7d8db6f8f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ad91ffe6f95&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914adb788a6f9b&type=max)

接线正确后，通电，在盒子下图位置会闪烁对应的指示灯，代表协议线通讯正常

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ae5f6de6fba&type=max)

# 协议配置

1. 长按娃娃机的设置按键，进入设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914adf159b6fa5&type=max)

2.输入设置密码，密码为：****（已脱敏，请向运维索取）（不同厂商可能密码不一样，请联系厂商确认）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914adfe0226fa7&type=max)

3.选择支付模块

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ae135f66faa&type=max)

4.选择【油菜花】，点击确认，然后退出设置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914ae1d28b6fab&type=max)

5.完成设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914aeaaad16fcc&type=max)

选择机台功能

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914aeb1edd6fcd&type=max)

则可以通过功能设置设置对应的参数
