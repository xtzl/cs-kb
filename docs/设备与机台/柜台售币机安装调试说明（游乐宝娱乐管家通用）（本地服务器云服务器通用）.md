# 三、支持功能

1.支持通过收银台买实体币后直接出币

2.支持放置广告图（柜台售币机V9独有）

1.售币机钥匙*2

2.档币插针*5（不同型号可能略有差异）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191931cbabb34b9&type=max)

3.串口通讯线（不同版本可能略有差异）

4.电源线

# 六、注意事项
1.开机前请检查马达内部是否有杂物
2.放置柜台售币机的桌面需要能承重100KG以上的承重力

3.摆放时建议至少2人以上进行搬运，避免出现意外

# 七、 作业标准

1.系统连接完毕

2.测试出币数量正确无异常

# 八、 调试步骤

## 连接收银台并对售币机进行加币
1.将售币机配备的USB币线接入电脑中，并接入到售币机中，并将售币机通电
2.在电脑中安装驱动，等待安装完成后，登录收银台，检查右上角位置是否正确显示售币机状态

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191933350713519&type=med)

3.在收银台界面，点击右上角的售币机图标，进入加币清币界面

4.点击加币，将定量游戏币加入到售币机中，并输入本次加币数量，完成加币。

## 清点币数

1.点击右上角售币机图标，点击清币，游戏币将通过售币机出来，并显示数币数量

2.全部币出完后，将游戏币放回售币机内，并将售币机上显示的数币数据填写到清币数量中，完成清币。

## 广告图功能（柜台售币机V9独有功能）

1，先用钥匙打开锁，把屏幕从底部往上推，就能把屏幕拿下来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001919333507b351a&type=med)

2，取出屏幕背面的U盘，更换这个U盘里的图片

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019193335083351b&type=med)

注意，此广告面可更换到另外一边，用于匹配收银台摆放柜台售币机的位置

# 九、测试要求

1.测试出币10次，检查出币数量是否正确

# 十、常见问题

## 1.卡币，数码管显示E031

答：

### 方案1：打开下方的主电路板，按主板中间的马达转动按键，尝试通过逆转功能看看能不能解决卡币问题

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191932c4ec234f7&type=max)

### 方案二：拆除马达，将异物取出

1)将插针插入币箱(如下图)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019193335198351c&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191933351a2351d&type=med)

2)将马达拆下后检查币斗、转盘内是否有异物导致马达卡币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191933351ab351e&type=med)

3)检查马达底部

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001919333528b351f&type=med)

## 2.出币数量不准

答：

通过调整马达光眼位置后再测试

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191932ef27d3500&type=max)

## 3、售币机不出币，并显示STOP字眼

解决方法：

1)检查前面板出币暂停按键是否卡死

2)检查币杯检测光眼是否被异物挡住

3)关闭收银系统币杯检测功能(如下图)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191933352933520&type=med)

## 4、售币机连接不上电脑,电脑提示“售币机未连接”

解决方法：

1)检查售币机重新开机，数码管是否显示转动。

2)数码管转动，则重启收银系统。是否成功连接。

3)检查电脑到售币机USB线是否有松动或者损坏。

4)检查设备主板电源指示灯是否是正常状态
