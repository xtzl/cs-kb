# 三、作业准备

1.提前在碎票机安装位置预留网线和电源线；

2.提前按照下列尺寸图预留废票口；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190390038277258&type=med)

（柜台碎票机V8开孔尺寸图）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190390038307259&type=med)

（柜台碎票机V10开孔尺寸图）

3.检查柜台碎票机配件是否齐全，包括进票口五金件(柜台碎票机V8)、钥匙、备用刀组、清票刚尺、电源线、出票口五金件(柜台碎票机V8)。

2.准备读卡器*1，空白会员卡*1

3.准备网线一根。

4.准备一些彩票用于测试。

# 四、注意事项

1.安装前一定要和客户确认柜台碎票机放置位置。并在底部位置预留出票口。

预留口如图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201903900390b725a&type=med)

2.由于部分金属件较为锋利，建议带上手套放置刮伤

3.安装配件，挪动时，必须确保碎票机在断电状态

4.安装后，需要检查保险开关是否处于正常状态，在存票状态电机转动情况下，打开面板，电机必须是停止转动的状态。如果保险功能失灵，请务必不能使用，并及时返修。

# 五、作业标准

1.网络连接正常，断电开机不出现掉线情况。

2.所有配件已经安装到位。

3.连续碎票10次不出现卡票情况。

4.连续碎票20张票，计数准确无误。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201903954fff5755c&type=max)

### 后台新增碎票机的游乐项目

1. 登录娱乐管家后台，新建一个碎票机项目：

路径：【终端】-【游乐项目】-【新增】

游乐项目名称，可命名为【柜台碎票机】或者【柜台碎票机-1】

项目类型选择刚刚设置的【碎票机】

点击【保存】

完成新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395713b7756f&type=max)

2.找到刚创建成功的碎票机项目，点击右边的【端口管理】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395a6b13758f&type=max)

## 写配置卡

### 路由器密码设置

若知道路由器密码，可直接进行设置，

若不知道，则可随意编辑设置；

展示如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395c8a9a75a7&type=max)

### 填写配置卡信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395d5a8275b0&type=max)

1.在生成设置卡界面，填写配置卡信息，分别录入以下信息：

- 服务器通讯方式：勾选外网；

- 服务器域名地址：输入门店域名地址，如y********.yun.youcaihua.net；

注意：域名地址不需要填末端的88，只需要到net结束，域名地址由销售助理提供

- 机台端口：输入四个数字的机台端口，可通过后台中台配置信息中查询到

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019715f6aaf437c4&type=max)

- IP地址：请填写本碎票机使用的IP地址，根据现场提供的网线的IP地址来填写；

- 网关：填写本碎票机使用的IP地址所对应的网关，根据现场提供的网线的IP地址来填写；

若不知道如何查找网络ip地址或网关，可用笔记本电脑接入碎票机预留网线，参考下述文档进行查找判断：

怎么查看自己电脑网关和ip地址？_百度知道 (baidu.com)

比如，笔记本电脑获取到的一个ip地址为：

ip地址：192.168.110.20

子网：255.255.255.0

网关：192.168.110.1

则可以给碎票机分配为

IP地址：192.168.110.* （*号代表2~254之间的任意数字）

子网：255.255.255.0

网关：192.168.110.1

此时，在通过电脑运行cmd命令行，并尝试用ping 准备给碎票机分配的地址，看看有没有连接，如果没有任何设备连接，则代表此IP可以用；例如你想分配给碎票机192.168.110.241，则用ping来测试，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190390042007266&type=med)

注意：如果发现地址已经被占用，则需要再次跟换地址，直到不被占用为止，建议使用ip地址段200-250之间的地址会比较好。

2.开启后台读卡助手

路径：后台管理网页-右上角下载-选择后台助手安装包-安装

安装教程：《娱乐管家读卡助手安装教程》

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395fc5ce75c6&type=med)

安装完毕后，右下角会显示油菜花助手的运行图标

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190395fc5d975c7&type=med)

3. 上述信息填写录入完成后，将读卡器接入电脑，将准备好的空白会员卡放在读卡器上，点击【保存并写入卡中】，配置卡配置完成。

# 九、常见问题

1.碎票机出现黑屏幕，并显示IP地址等信息。

答：连接失败，无法连接服务器，检查网络是否正常。

2.扫码登录直接退出

答：保存按键短路

3.经常显示断线

答：

a.更换ip再刷配置卡

b.更换网线

c.主板出现问题

4.碎票会减票

答：清理光眼或者更换光眼

5.存票的时候没有成功

答：重启碎票机是否显示A802报错，机台碎票机端口冲突

6.域名连接显示域名错误或者url error

答：

a.路由器DNS填上119.29.29.29，一般在DHCP服务器设置中找到该配置，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190390049e2726e&type=med)

b.路由器开启DHCP功能

c.在系统上填写域名地址不要加http://和结尾的端口号（如:88）

d.联系运维检查域名连接端口是否正常

7.不显示扫码二维码

答：后台盈客宝没配置好
