一、 作业说明

本教程主要围绕如何设置 隔离路由 器的操作来展开说明。

二、 作业准备

电脑一台，网线一根。

三、 注意事项

网线不要插错口

四、 作业标准

电脑开机，路由器通电。

五、 作业步骤

1. 把电脑的网线接到路由器LAN口

2. 在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac805e1f33f00&type=max)

3. 在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac8060b253f01&type=max)

4. 路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac80633cc3f02&type=max)

5. 按照快速设置向导设置WAN口数量，选单WAN口即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac8064e0a3f03&type=max)

6. 等待页面跳转进入到选择上网方式界面， 选择 动态 IP 的上网方式。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac80671de3f04&type=max)

7. 设置 LAN 口的 IP 地址为：10.0.0.1，子网掩码255.255.0.0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac8069ff33f05&type=max)

8. 开启路由器的AP管理功能。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac806cdc93f06&type=max)

9. 设置无线网络名称为YocartoonNet6，密码为****（已脱敏，请向运维索取）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac806f1dc3f07&type=max)

10.等待路由器完成配置并重启，至此， 隔离 路由器已经设置完成。

六、 常见问题

1. 路由器WAN口可以用自动获取的IP地址或者固定的IP地址。

2. 如果有独立的AC管理器就不需要启用隔离路由的AP管理功能。
