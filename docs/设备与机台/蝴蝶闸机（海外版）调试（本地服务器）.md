# 一、文档说明

本文档为蝴蝶闸机（海外版）的安装要求与调试教程

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db838167f77a1&type=med)

闸机按不同通道不同类型一般为：

#### 双通道单机双机芯一进一出

说明：中间一个机箱，左右两边分别用于进闸和出闸使用

#### 单通道

说明：左右两边分别为一个机箱，在中间通道同时支持进闸和出闸，支持一进一出或者只进不出两种产品

#### 双通道

说明：左中右各一个机箱，形成两个通道，支持一进一出、两进两出、两进一出、两进不出等产品；

#### 三通道或者以上

说明：并排四个或者以上机箱，形成三个通道或以上的通道，根据通道数可有相应的进出产品；

# 三、尺寸说明

闸机预留位置说明如下：

#### 双通道单机双机芯一进一出

横向宽度为：830mm

纵向深度为：1330mm

闸机高度为：933mm

#### 单通道

横向宽度为：1050mm（可定制加长100mm）

纵向深度为：1330mm

闸机高度为：933mm

#### 双通道或以上

横向宽度为：1050mm+820mm（增加一个通道增加820mm横向宽度，可定制加长，加长后宽度可增加100mm）

纵向深度为：1330mm

闸机高度为：933mm

# 四、支持功能

1.支持多种验票方式，包括、RFID会员卡/腕带、纸质票/电子二维码门票、Miniapp会员码、扫码过闸等；

2.支持扣储值、扣次数、计时扣费、包时段等收费方式；

3.支持非法闯入报警、防夹检测、灯光指示灯；

4.可设置红外感应出闸；

5.支持设置允许离场时间，在允许离场时间范围内，重新入闸不额外扣费；

# 五、工具准备

1.冲击钻*1、14mm冲击钻钻头*1

2.铁锤*1

3.12mm扳手*1

4.2mm一字螺丝*1

5.免钉胶枪*1（根据现场是否使用免钉胶）

6.免钉胶*N（根据现场是否使用免钉胶）

7.六角螺丝刀*1套

8.卷尺*1

9.记号笔*1

10.USB键盘

# 六、前期准备

1.每个机箱位置需要预留220V电源

2.每个刷卡位置需要预留网线

3.机箱与机箱之间预留60mm线槽

# 七、配件说明

机箱主体*N

从机线*N

闸机钥匙*2（一组闸机2套钥匙）

遥控器*1（一组闸机1个遥控）

12mm膨胀螺丝*4（一个机箱配4个膨胀螺丝）

# 八、注意事项

1.安装前需要确保电源是断电状态

2.安装时需要佩戴手套，以免因五金件锋利导致弄伤手

3.搬运闸机时，建议至少2人以上进行搬运

4.从机线注意不要接错，此线是从一端的主机板接入到另一端的从机版

5.机箱与靠墙一端预留5CM的宽度，以免导致无法开启检修口

6.固定闸机底部前，需要提前与现场确定底部是否有电源线管或者供暖水管，以免打膨胀螺丝时将管路打穿

# 九、作业标准

1.闸机按照客户要求摆放到位

2.闸机与闸机之间需要平行对正

3.闸机与墙壁距离不少于5CM，不大于10CM

4.闸机门之间不大于10CM

5.闸机固定在地面不摇晃

6.220V电源不与地面接触

7.闸机调试完毕后，闸机不报错，功能正常（刷卡功能正常、扫码功能正常、屏幕显示正常、闸门开启正常、遥控器工作正常）

# 十、作业步骤

## 第一步：闸机机台安装

1.闸机设备到场后，拆除设备包装，检查设备整体外观是否完好无损。

2.检查完毕后，将闸机机台放置于事先预留好的定位口，如果网口、线管、线槽预留得当，则可以直接将闸机机台盖上去，走线槽从机台底部穿线。（注意：需要需要拆从机线的接线口前，建议提前拍照记录，以免重新安装接线口时搞错线序，两端的线序是不一样的）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db838169177a2&type=med)

3.用钥匙打开侧翼闸机机台上盖，拿出放在里边的主从机线，一端插在主机的接线口，再从机台内部走线，从预留的线槽引入，接入另一端从机的接线口。

打开闸机上盖，接入主机线一端：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db838169877a3&type=med)

将主从机线从闸机内部走线，将线引入线槽，由线槽引进闸机从机组机台：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816a077a4&type=med)

主从机线一段接入从机组：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816a777a5&type=med)

建主机板和从机板图如下（注意从机线一定是主机板接从机板，同时连接两个主机板会有烧板风险）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816ab77a6&type=med)

主机组机台、丛机组机台进行通电，将闸机的电源线接入预留在闸机底部的电线口进行通电：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816b177a7&type=med)

4.主从机接入完成后，用闸机遥控器简单测试， 测试是否闸机俩端连接是否正常。

5.闸机主机组及丛机组接入网络，将底部的网线，贯穿内部接入闸机主机组、丛机组网口进行联网：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816b677a8&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816bc77a9&type=med)

7.测试闸机通电后正常开机后用遥控器遥控开关闸门是否正常，如果不正常，则需要检查从机线是否按照主机板→从机板这种方式连接，一般出现开门不正常原因为：

①主机板连接到另外一端机箱内的主机板

②从机线拆线后线序不对（不同版本的线序可能有差异，目前新的闸机两端线序是不一样的，务必要提前拍照记录）

8.将闸机放置到指定为，用卷尺测量位置币对正放好，放置指定位置后，由客户进行检查确认。

9.位置确认后，在闸机内部，找到膨胀螺丝孔，用记号笔进行标记

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db83816c177aa&type=med)

10.打入膨胀螺丝，教程可参考此网上视频：【如何打入膨胀螺丝 】

11.将闸机进行固定，如膨胀螺丝固定不稳情况下，可根据情况适当补充使用免钉胶进行辅助固定，免钉胶打入到闸机底部即可。

# 十一、测试流程

1.开机通电，闸机门关闭，屏幕正常显示对应的项目并无报错；

2.关机断电，闸机门自动打开；

3.（人脸模块），前台录入人脸并购买套票，在闸机上直接刷脸后正常开闸

4.使用会员二维码刷码正常入场并扣除次数或储值，用会员二维码刷码能正常离场；

5.使用会员卡刷卡入场，正常扣储值或者次数并闸机正常打开，刷卡出场闸门正常打开；

6.开闸后，用手捂住中间光眼，持续1分钟，闸机不关门；

7.使用遥控器，能正常遥控闸机开闸和关闸。

# 十二、常见问题

1.闸机开机提示登录失败

解决方案：

①检查网线是否正常

②重启看看是否恢复正常，如果恢复正常后门店营业结束后第二天营业问题依旧，则尝试固定闸机IP地址试试

③升级闸机版本

2.单机箱双机芯一进一出能否更换入闸方向

答：不可以

3.排队机如何配合闸机使用？

答：闸机本身不需要特别设置，在排队机中绑定相应项目即可，具体教程可查看排队机教程。

4.闸机一直报非法闯入，该如何调整？

答：

①闸机两边机箱没有做到平衡，导致闸机上的红外感应一直感应到有障碍物，重新调整闸机机箱即可；

②闸机红外设置距离过长，在红外感应器上有个小旋钮，可调整感应度

③闸机顶部有强光源，导致误感应，撤掉闸机顶部的照明灯或者改变顶部的照明灯的方向

5.闸机门断电后不会自动开闸？

答：闸机本身自带电池，电池馈电会产生该情况，通电运行一段时间后应该会解决，如无法解决需要检查电池是否异常。

6.想设置出口位置不需要刷卡，直接人经过直接开门

答：

①长按SET（中间按钮）直到数码管闪烁，进入参数设置。

②数码管第一，二位显示菜单，第三、四位显示数值，左开按钮设置菜单，右开按钮设置数值。

③长按2秒左右，数码管停止闪烁，菜单数值保存成功。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db838177477c2&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db838177977c3&type=med)

如果需要设置红外感应，则需要选择菜单1，并设置参数为02或者03，长按SET 2秒保存设置（由于闸机安装可能存在方向问题，所以需要测试到底用02参数还是03参数，01则是两边都需要刷卡，04则两边都红外感应）

7.翼闸模式下门板到位调整方法

①连续按下SET（中间按钮）5次，系统提示“请手动调整翼门位置”并进入翼门（门板）调整模式。

②主机板的“左开”和“右开”可控制主电机往复运动，从机板的“左开”和“右开”可控制从电机往复运动，通过按钮控制翼门运动至目标位置停下，保持3秒不动，语音提示“嘟”一声或相应灯光闪烁一下，表示当前位置已采样完成。

*系统会根据翼门所在的位置自动判别当前采样的位置为左到位、右到位。

③长按中间按钮2秒以上松开，程序会退出调整模式。
