# 功能说明：
### <font style="color:rgb(64, 64, 64);">应用说明：</font>
<font style="color:rgb(64, 64, 64);"> 门店选择接入氛围系统，目的为了提升用户体验、营造品牌形象、促进特定活动（如消费、游玩体验）、增强沉浸感，进而提高客户满意度及会员粘性</font>

### 系统组成结构：
**<font style="color:rgb(64, 64, 64);">灯光系统：</font>**<font style="color:rgb(64, 64, 64);"> 对接灯光系统，可自行控制灯带的颜色、亮度变化</font>

**<font style="color:rgb(64, 64, 64);">声音系统：</font>**<font style="color:rgb(64, 64, 64);"> 对接音响系统，可自行调整播放的音乐、环境音效等</font>

**<font style="color:rgb(64, 64, 64);">影像系统：</font>**<font style="color:rgb(64, 64, 64);">可投影播放活动比赛排行榜、门店活动宣传海报等</font>

# 项目准备：
## 现场相关设备确认事项
#### 氛围主机盒子接入准备
氛围系统程序主要是安装在氛围主机盒子上的，所以氛围主机盒子是必须要接入的。

##### 准备确认事项
若门店是本地服务器，则需要将氛围主机盒子接入本地服务器所在的局域网，一般是接入本地服务器所用的本地主路由或主交换机。

若门店是云服务器，则正常接入门店所用网络局域网即可

#### 影音氛围系统接入准备
可通过氛围系统控制投屏电视播放内容、音响播放

##### 准备确认事项
1.投屏电视机数量及定位、音响数量及总控制台定位

2.在总控制台处预留影音氛围盒子电源，及接入影音氛围盒子的网线（从接入氛围主机盒子的网络出来）

3.接入影音氛围盒子的需是3.5mm音频线，若存在多个音响，则将音响控制终端用3.5mm音频线接入影音氛围盒子，再由音响控制终端接入对应点位的音响去进行控制，定点音响及总控制终端之间的接线需让场地自行走线

4.若场地存在多个投屏电视机，则屏幕分发器到投屏电视机定点处之间需预留好网线（电视机通过网线-HDMI转接头转接）

#### 灯光氛围系统接入准备
通过氛围系统控制场地灯光效果

##### 准备确认事项
1.确定场地所采用灯带类型：

<font style="color:rgb(0, 0, 0);">单色灯带：只能控制亮灭，不能控制颜色的灯带；</font>

<font style="color:rgb(0, 0, 0);">幻彩灯带：通过后台控制颜色，且可分段显示不同颜色</font>

<font style="color:rgb(0, 0, 0);">RGB三色灯带：通过后台控制颜色的灯带,但不支持分段控制，整条灯带一个颜色</font>

<font style="color:rgb(0, 0, 0);">2.确定灯带电源盒</font>

## <font style="color:rgb(0, 0, 0);">软件功能相关确认事项</font>
软件版本：V10.3.9041及以上

边缘网关版本： 2025052801

卡头版本：目前只支持钻石V9，V3.0.0

影音盒子版本：V1.0.6

抽奖机版本：V1.0.5

抽奖机卡头版本：V1.0.0

功能开通确认：需联系相关平台管理员在业务平台开通此项功能

# 操作说明：
### 硬件调试
除氛围主机盒子是必配之外，灯光氛围系统及影音氛围系统可根据门店实际情况选用配置。

门店现场会因为场地已装修完毕无法加装氛围灯带、或场地仅需要接入影音氛围系统投放广告等现场情况，不一定会配齐全套模块，所以按需选用配置即可
