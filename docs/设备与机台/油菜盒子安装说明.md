# 三、配网设置

## 1.刷通用配置卡

### （1）网络配置

打开系统：设置—基础设置—卡头wifi通用设置—重新设置通讯

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f77e1263b5a13&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f77e12b8a5a14&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f77e12ec65a15&type=med)

点完成

### （2） 设置配置卡 电脑插上读卡器

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f77e132315a16&type=med)

读卡器上放卡后点“网络参数写入卡中”然后写配置卡完成。

## 2.在油菜盒子上刷配置卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f77e136775a17&type=med)

把配置卡放到读卡器上，设置完成， 等待待机灯闪红色灯时， 油菜盒子就连上服务器了，

## 3.手机关联项目与情况一致

如遇到装在室外的，只装卡头扣费的情况：

1：把适配器的头减掉，就是圆孔的头，减掉，然后用黑色和红色的线，短接到卡头的信号线，黑接黑，红接红，接完后就可以插电通电在室外使用。
