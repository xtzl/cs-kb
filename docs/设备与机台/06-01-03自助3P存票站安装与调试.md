# 1、作业说明

本教程主要对3P存票站的安装方法以及调试方法。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bd1c11a685bc2&type=max)

# 2、作业准备

1.会员卡一张

2.读卡器一个

# 3、注意事项

1.无

# 4、作业标准

1.设备能正常读卡、扫码，存票功能无异常

2.机台不摇晃。

# 5、作业步骤

1.登录后台，选择【设备】-【设备管理】-【营业设备】-【新增】-【碎票机】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017baa8c330d0e4a&type=med)

2.填入设备名称，保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017baa8c330d0e4b&type=med)

3.点击【端口管理】-【添加端口】-【保存】-然后点【刷卡】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017baa8c331c0e4c&type=med)

4.填入服务器地址及该设备的IP地址，然后把卡放到读卡器上，点击保存并写入卡中。（注意一张卡代表1个IP地址，所以此处需要3张会员卡或者配置完一个再重新写一次其他P位的）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017baa8c331c0e4d&type=med)

5.打开自助存票站门，长按主板上的按键，等待显示E06

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017c72a1d10e0daf&type=max)

6.把配置卡放到读卡位置读取后等待连接成功即可。其他P为重复此做法即可。

# 6、常见问题

1. 碎票机出现E01是什么原因？

答：主板上的网线口松了

2.碎票机上出现E25是什么原因？

答：连接不上服务器，检查配置卡IP及服务器IP是否正常。

3.扫码登录直接退出

答：保存按钮短路

4.经常显示断线

答：

a.更换ip再刷配置卡

b.更换网线

c.主板出现问题

5.碎票会减票

答：清理光眼或者更换光眼

6.存票的时候没有成功

答：重启碎票机是否显示A802报错，机台碎票机端口冲突

7.域名连接显示域名错误或者url error

答：

a.路由器DNS填上119.29.29

b.路由器开启DHCP功能

c.在系统上填写域名地址不要加http://和结尾的端口号（如:88）

d.联系运维检查域名连接端口是否正常

8.其他错误报错原因

E02 读卡器报错

E03 铁电报错，有可能为卡票

E04 卡效验错误，一般为读卡错误，卡未加密或者卡损坏

E06 进入刷配置卡模式

E31 获取配置失败，配置卡内信息错误或者读卡出问题

E32 注册IP冲突，更换IP地址再尝试

E33 搜索不到服务器地址，代表此设备未能连接到服务器

E34 获取DHCP失败，路由器的DHCP功能为未打开

E35 注册失败/连接测试失败

E36 域名错误，代表配置卡中的所配置的域名地址错误，或者无法连接解析该域名，可尝试添加DNS试试能否解决

E37 域名解析成功，但连接不上服务器，代表此设备已经能上网并且能解析出域名地址，需要检查机台端口、服务器状态等情况

E38 连接外网失败，代表此设备连接不上外网，且导致无法域名解析失败

E41 获取固件错误，升级程序中出现的错误

E42 固件信息错误，程序有问题

E43 固件效验错误，同上

E44 升级中，代表固件程序正在升级，请勿断电

E45 升级固件效验中，代表固件程序正在升级，请勿断电
