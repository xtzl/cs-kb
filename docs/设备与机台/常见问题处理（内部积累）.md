1.收银台使用会员拍摄，提示报错？

解决：重新安装下vs软件即可。

2.导入数据提示导数据限制sql溢出？

解决：数据里面设置的生日时间问题，重新编辑下生日时间。

3.台球设备装好后灯常亮是什么原因?

解决：卡头拨到12v，断电重新刷卡配置。

4.3P存票站刷卡位置刷卡刷不上、扫码扫不了（时常刷卡没反应） 日期10.23

解决：确定不是网络问题、人为操作问题（刷卡配置、刷卡操作等）后，让工厂那边发主板进行跟换。

5.小程序提示业务平台100000业务系统平台无法访问502问题。 日期10.02

解决：门店vpn问题，检查vpn是否是正常连接。

6.果冻版卡头装了礼品线但是不统计散客投币出礼品的。 日期10.05

解决：升级卡头程序

7.果冻卡头配置完显示正常。12v/5v都试过.线序也对了下.投币和刷卡不上分（能扣币）投币迈宽从默认80剪5改到15了.还是不行. 日期10.06 冯善良

解决：先万用表测试不接卡头时多少v，投币时瞬间变成多少v，通过万用表测试机器本身处于哪个电平，如果默认为5V则卡头的信号线电压为5V，如果投币瞬间信号线电压变成5V以下，则默认状态为高电平

8.这个打卡终端的账号密码是专用的？必须设置的和知识库一样吗？日期10.16

解决：打卡终端连接的AP须是tplink（wifi密码设置字符限制，锐捷只支持设置16位），若客户用的是锐捷设备别，要么换AP，要么换终端设备（寄回公司重写程序）

9.存票站刷配置卡提示E905。 日期10.20

解决：检查端口问题，是否被禁用、被删除等。

10.ab账是否支持手机报表查看？

解决：不支持

13.接卡头就报E9，不接没事？（部分卡头不报）日期：11.11

解决：大概率是投币器故障，参数不对；卡头的5V，12V还需要调。

14.娃娃机都没有出礼品记录？
日期：11.11

解决：码表线没有接对，没数据，都将线剪断，直接剥线接的；礼品码表一般黄色的是供电灰色是信号，礼品线蓝色的是信号，黑色是供电，要看下线序对不对的上。

15.小程序获取不了头像和昵称了？日期11.15, 冯善良
解决：微信平台限制，目前已经没法获取微信头像和昵称；

16.游乐宝后台打开小程序，提示请求地址不存在。日期11.15冯善良
解决：盈客宝正在更新导致的。

17.卡头显示22币一次，但是刷卡只能刷21个。日期11.18，靳涛
解决：检查下高低电平问题。

18.操作系统后台，提示赋能平台请求失败。
解决：尝试修改下电脑dns。

19.现在反扫卡头会出现不读卡。或使用中自己重启。还有就是读完卡后又自动变E06的问题。 日期11.22，王子龙
解决：外接12V（可从电源拿上拿或灯带上），把卡拿起来，高于读卡区2-3cm。

20.芸苔会员结账提示，sub_much_id与sub_appid不匹配。日期11.24 王海峰
解决：支付和小程序主体不一致，销售没绑定APPID，联系对应销售助理处理。

21.退完币就提示干扰报卡币（已将干扰灵敏调到最小了，后台也关了干扰）日期11.26 冯善良
解决：将干扰帽拔了尝试一下。

22.卡丁车排名，想让排名按速度快的，别用速度最慢的。日期11.26 冯善良
解决：卡丁车那里游玩模式的设置，设置成计圈的，并在综合得分计算方式那设置成，1800-({laptime}/1000)

23.后台改了储值别名 怎么收银台不变？日期11.27 卓建帆

解决：生效范围只对 C 端有效， 比如魔方卡头， 兑币机V6 。

24.小程序从会员码的充值进去怎么是没有套餐的？日期11.29 卓建帆
解决：该界面不显示组合商品的。

25.娱乐管家批量设置商品售卖终端要怎么设置啊?日期12.08 梁建宁
解决：在终端售卖设置菜单设置，可以先用商品定价的菜单，批量设置终端。

26.钻石卡头可以退除彩票和游戏币以外的储值吗？日期12.15 周定国
解决： 加娱乐版控制盒，项目功能设置为娱乐机，可以选择退其他储值，譬如：积分、金币、娃娃。

27.钻石V2是不支持万达吗？日期12.16 贺凯
解决：要发固定ip的版本，DHCP，万达的用不了的。

28.小程序提示获取手机号失败。日期12.25杜刚敏
解决：小程序违规了，先把京东商城和兑换中心下架了，然后到小程序后台申诉。

29.身份证阅读器是不是不支持用在新版收银台？安装驱动后提示动态库异常日期12.28梁建宁
解决：转件远程调。

30.升级套餐，原套餐100是微信支付，升级以后变成现金支付，还退款了。日期12.29刘宏喜
解决：退款的钱会放到升单套餐中抵扣，然后在退款单里以现金方式退款。

31.宝贝王娱乐管家，卡头刷卡没反应，不扣币，也不上分，高低电频调试，后台确认投币器常开。投信号线也正确。那么出现刷卡没反应是什么原因？ 日期12.31刘宏喜

解决：升级卡头版本。

32.存币机e501a日期01.01杨晓华
解决：E510:(E0510、E50A)会员级别受限制。

33.总部怎么不能下发计时票。只有门店才可以优计时票？商户版在分店设置的计时票。怎么小程序发布商品找不到计时票？ 日期01.04杜刚敏

解决：暂时不支持总部设置计时票 ，计时票不支持小程序了。

34.主机游戏。只能按照设置的基础时间向上叠加？不可自由编辑时间还是？没找到自由编辑时间的地方。 日期01.05 杜刚敏
解决：开台的时候选择，不能自由编辑开台时间， 计费也是按倍数计算，中途不想玩了可以提前结算。

35.小程序兑换中心，提示1000404。日期01.12周定国
解决：业务系统版本低了，需要推送版本。

36.收银台微信支付宝付款扫了码，要回车一下才能收款是什么情况日期01.17卓建帆
解决：扫码枪自带了回车功能，咨询对应扫码枪厂家处理。

37.有没有遇到过闸机设置通道，入口被默认了，其他入口2和出口都不能选择的？入口和出口全部默认成入口了。 日期01.20刘炜杰
解决：拔掉接入闸机的usb线，检测一下。
