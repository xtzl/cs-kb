# 文档说明
手机报表累计3天蓝票机亏损

特别提醒：避免机台故障或偷分，导致损失，请排查！

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749533736192-11bdf208-3bcd-44ad-a69f-9be89c2e7c12.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749533748344-adc2d137-6d8c-459b-8d1c-404b5b89c525.png)

从上图可以看到，过去三天出现了亏损，这很可能是因为机台设置错误或不法分子作弊。需要重点检查一下相关机台有没有异常情况。

## 常见问题
**问：我从机台查看账目是正常盈利的，但是通过油菜花系统显示是亏损的，这个到底以哪个为准**

答：

情况一：门店以电子币为主

盈亏判断以系统为准，系统呈现亏损状态即为实际亏损。

情况二：门店以实物币为主

盈亏判断以机台账目为准，机台账目呈现亏损即为实际亏损。

**问：如何比对机台账目与系统的数据？**

答：可以通过系统后台【机台经营报表-自然日】来进行比对，如下图所示

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749547473328-fd6760e9-bbe6-40a1-bd83-ce778ceb7c76.png?x-oss-process=image%2Fformat%2Cwebp)

**问：发现数据对不上时，并发现后台突然有一个差额很大的投实物币记录，这是什么原因？**

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749606158247-8ddee292-508f-48c5-83fb-71a9748017ad.png)

答：这种情况是由于卡头在长时间断网，导致投实物币的记录一直累计在卡头中，重新联网后一次性上传所有数据所导致。

**问：据说有些机台在爆机之后机台账目就不统计数据，是真的吗？**

答：确实会这样，比如疯狂魔鬼城在爆机后就不在接收投币信号，所以此时如果卡头还在投币，则这部分的币就不会记录在魔鬼城账目上，而卡头依旧会记录这个投币数，因此会产生对应的误差。另外类似的还有山海苍龙，此机器达到爆机之后，后续的投币会直接转换成出蓝票，并且爆机后的投币和出蓝票都不会记录在机台账目上，但卡头会记录，因此也会造成入币数和出蓝票数的误差。



## 情况一：机台账目与系统后台出蓝票数相差较大
### 原因分析
由于卡头参数与机台物理参数不匹配，如出票速度过快等异常，导致机台检查出票数不准确，导致出现多出情况。

### 解决方法
1. 先确认是否因为使用数码币引起，如使用数码币需要机台更换数码币专用马达。
2. 尝试不接卡头，测试出实物币数量是否准确（排查是否机台本身异常）。
3. 接入卡头，再次测试出蓝票数量是否准确。如果出现不准确，调整卡头物理参数（调整出票速度与出票脉宽）



## 情况二：人为原因被偷分，使用干扰器或者被加装遥控器实现干扰。
### 原因分析
部分不法分子，利用作弊器、遥控器进行遥控投币，并获利。其中有以下两种类型干扰器

**干扰器（特斯拉线圈）**：一种通过产生高频信号干扰投币器，使机台产生被投币错觉的干扰器。一般是手机或者充电宝外观，甚至还有安装在鞋子上使用人体为导体来实现干扰。干扰时需要靠近投币器或者卡头。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749524646219-6c54b998-b772-4719-a8c6-ef237fe66186.png)

**遥控器**：一种通过加装在游戏机内部的接收器，通过遥控产生投币信号。一般需要接入到机台内部，并且外部通过遥控器遥控投币出奖。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749525012977-ce1376c8-3ca7-4189-a57e-ebc5d12de549.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749525064736-acea446f-9a57-4573-8051-a62c95d68ea9.png)

### 现象
现象一：机台账目投币数远远大于系统后台统计的投币数，此类现象通常为安装遥控器。

现象二：机台账目出蓝票数远远小于系统后台统计的出蓝票数，此类现象通常为干扰下蓝票。

### 解决方法
1. 检查机台接口位置，重点检查投币信号线接口、出票器接口、马达接口、马达光眼接口等位置是否被加装不知名东西。务必要拔插一下检查是否有异物接入信号源。
2. 检查【项目异常记录】中，是否有产生被干扰记录。如有发现检查当时游玩的会员是哪个，针对该会员检查对应的消费记录、投币记录以及出蓝票记录是否为正常。并根据异常时间结合监控查看是否有作弊动作并收集作弊证据进行举报。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749527663252-49a5e039-97ad-4fe0-8a5d-5fb7fa470ea1.png)

3.  另外可以通过【会员活跃分析】检查是否有异常会员，选择统计时间，并按代币一栏进行排序，找到此段时间内赢币多的会员，并进一步检查该会员是否有匹配的消费情况。如果消费少且代币消耗数据呈现较大的负值，该玩家需要重点关注。发现有作弊情况收集证据后进行举报。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749527322928-1eb50e8a-a3c7-400b-bf0e-a67c8f1f04ca.png)

### 防范方法
1. 使用油菜花系统AI风控功能，及时收到可能出现异常的情况。设置参考文档如下：

[AI风控](https://ychylb.yuque.com/staff-gcg8pk/ylgj/ep6v6hqsp79ky0zb)

2. 提高干扰检测等级，并设置干扰后的处理方式（可选锁卡头或者直接锁会员）。注意：如果是安装安全盒子，需要确认安全盒子上的物理参数是以后台为准还是以盒子拨码为准，如果是盒子拨码为准，灵敏度需要在盒子上调整。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749527758524-237647eb-5f6b-4e08-b04b-5fd3e5e2434e.png)

3. 建立每天抄码表机制，及时发现异常情况；
4. 建议加装电子锁（油菜花电子锁作用时当机修需要开锁时，需要插机修卡到卡头才能开锁，否则人为开锁系统会发出警报）防止非员工开锁。
5. 加装第三方安全卫士，如【通利安全卫士】，进一步加强抗干扰能力。
