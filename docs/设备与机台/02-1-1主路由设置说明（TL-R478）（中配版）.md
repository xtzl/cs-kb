# 一、 作业说明

本教程主要围绕如何设置 隔离路由 器的操作来展开说明。

# 二、 作业准备

电脑一台，网线一根。

# 三、 注意事项

网线不要插错口

# 四、 作业标准

电脑开机，路由器通电。

# 五、 作业步骤

### 1. 把电脑的网线接到路由器LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401867d6adef84b9b&type=max)

### 2. 打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007baa5640369&type=med)

### 3. 在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007baa564036a&type=med)

### 4. 路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401867d6c2ccb4b9c&type=max)

### 5. 跳过快速配置界面

### 6. 选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007b6d9a7035b&type=max)

### 7. 选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“192.168.10.1”-将【子网掩码】设置为“255.255.255.0”-然后点【设置】，按下图设置

### ![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007b631be0359&type=max) 8.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018007b866ee0365&type=max)

# 六、 常见问题

1. 路由器WAN口有可能是自动获取的IP地址或者固定的IP地址。

2. 主路由的AP管理功能一般不需要启用。
