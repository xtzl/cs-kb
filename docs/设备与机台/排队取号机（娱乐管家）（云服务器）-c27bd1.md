# 一、作业说明

顾客购买次票/期限票/陪同票到收银台绑定二维码腕带或RFID腕带，凭腕带到自助取号机取号，等待叫号后方可入场，叫号支持语音播报。

# 三、功能说明

1.设备支持配合闸机限制进场人数，并支持叫号功能

2.开始排队后，支持排队序号4位，支持每天以随机数开始，或者按顺序取号

3.游客临时离场时由工作人员按遥控器开门，不减少场内人数；游客回园时，可继续开闸，不增加场内人数
4.工作人员可临时增补人数，以满足同行游客同时进场的需求【操作流程：工作人员持员工卡在闸机刷一次，即可多进一人】
5.游客过号后，工作人员可用上述第4点，放顾客进场
6.不支持会员码取票码，仅支持腕带取号
7.项目设置需排队取号后，闸机管理卡将做增补人数用途，不再直接开闸，紧急开闸可用遥控开闸

# 六、前期准备

1.安装位置需要预留220V电源

2.安装刷卡位置需要预留网线

# 七、安装要求：

1. 自助取号排队机安装到地面不摇晃；

2. 安装后功能能正常使用（刷芯片腕带功能正常、扫码功能正常、屏幕显示正常、打印功能正常）

3. 电视能正常显示排队人数和进场人数

# 九、安装步骤

## 排队取号机安装

### 1.硬件安装

1.将排队取号机底部使用膨胀螺丝固定

2.将网线接入到网线接口

3.插入电源线，并进行通电

### 2.基础配置

打开应用，首次进入应用且未进行基础设置时，自动弹出设置页面。也可通过点击右上角“设置”按钮唤起设置页面。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8a2a1885&type=med)

获取地址：根据本机ip自动获取服务器地址并填入“服务器地址”输入框内。

服务器地址：可通过获取或手动输入，输入后点击“连接”尝试连接服务器。

云服务器一般通过域名地址链接，如域名地址为http://y********.yun.youcaihua.net:88/admin，则在服务器地址一栏填写y********.yun.youcaihua.net:88即可。点击测试连接

选择项目：选择需要启用排队取号的闸机项目。

### 3.功能设置

上述步骤中，点击开启【排队取号】，则可设置以下内容

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8a351886&type=med)

打印测试：测试打印一张取号小票检验打印是否正常，测试打印不占用实际的取号排队人数。

容纳人数：项目的场内容纳人数，超出此人数后无法直接过闸入场，需等待叫号。

触发取号人数：当场内人数达到指定数量后，后续入场需取号排队才可入场。

每日初始号：取号的初始号码，默认从1开始，可选择随机数。以便每日的营业数据不被泄露。

过号时间：用户取号后的有效入场时间，未过号的用户可在指定时间内入场，已过号的用户需由工作人员刷员工卡后过闸入场。

以上设置完毕后，点击保存，完成该设备的设置。

## 闸机

### 1）安装应用

找对接同事拿apk安装包后，安装应用，版本号2023.01.11以上

非人脸闸机升级方法：

闸机升级方法：

1.下载对应的安装包apk

2.放置在服务器中YCHMall文件夹内的CltUpdate文件夹中

3.重启闸机即可。

人脸闸机升级方法：
1.找到闸机的的设备串码

2.将设备串码提供给硬件客服，让硬件客服推送版本

3.等待闸机升级

### 2）基础配置

正常配置闸机链接即可。

# 十、使用流程

1.游客需要通过绑定腕带功能，将进场次数绑定成腕带

2.未到预设值的触发排号人数时，可直接通过腕带入闸

3.触发排号时，需要使用腕带，在排队取号机中取号，并打印对应的排队凭证号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918cd824511955&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918cd825321956&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918cd8253c1957&type=med)

4.电视也会显示对应的前面排队的编码和人数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918cd825461958&type=med)

5. 等待排到对应游客时，电视机会播报相应号码邀请游客入场，游客需要凭腕带在预设的进场时间内进场

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8c181888&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8d361889&type=med)

6.特殊情况支持刷员工卡后，过闸一人。该过闸不受排队号（未取排队号或未到入场状态）限制，不受项目容纳人数限制（即使当前容纳满员，仍可入场）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8d41188a&type=med)

7.已过号的票码无法入闸，可通过工作人员刷员工卡增补入闸

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918c9d8d4c188b&type=med)
