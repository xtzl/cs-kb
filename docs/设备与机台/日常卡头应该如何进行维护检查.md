# 文档说明

使用卡头的场地，建议定期对卡头进行检查，尤其是在节假日高峰期来临前，可通过全方位检查卡头情况来减少因卡头问题而导致一些客诉，提高客户满意度。本教程为快速检查教程，属于日常检查维护，旨意可以通过以下操作快速定位问题从而进行问题处理，精度可能没有那么高，但相对比较省时且高效。

# 检查目标

涵盖模拟机卡头、彩票机卡头、礼品机卡头、娱乐机卡头等。包括卡头外观、按键功能、出彩票礼品等功能检查。

# 检查前准备工作

1.准备一张机修卡，用于检测使用。

# 检查流程

## 1.卡头外观检查及按键功能测试

步骤①、步骤②和步骤③可以同步进行

①全场卡头逐一检查外观是否完整，螺丝是否都固定好，并且尝试用手掰一下看看是否稳固。

②（带屏幕显示功能的卡头）检查卡头所绑定的项目与实际机台是否一致。

③用机修卡刷卡测试，如果是反扫卡头直接尝试刷卡投币，检查机台反应。按键卡头则只需要是否读卡成功，并且按键看看是否正常可用。

## 2.后台利用报表数据，快速检查机台是否有记录，以此判断卡头P位是否正常

①先打开【机台经营报表】，按P位汇总查询仅30天内的数据，可根据实际情况依次先检查模拟机、礼品机、彩票机及娱乐机，也可以一次性全部检查。

路径：后台→终端→机台经营报表

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a1217d11ebf&type=max)

②查看报表，先检查是否都有数据，主要核心检查的数据有

#### 所有机台必查数据

投实物币→检查是否有投实物币数据，如没有则有可能此机台投币口有问题，需要检查排查（纯电子币场地可忽略）

投代币/投金币/投限定币/投弹珠/投预存款→检查投电子币数据是否过低，一般建议低于100币都建议去复查一下机台是否有异常。（纯实物币场地可忽略）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a1b73872633&type=max)

#### 娱乐机必查

奖励实币/奖励蓝票→检查是否有数据，如果具备同时都会出的场景则两列都检查，没有数据则代表有异常，需要复查机台是否有故障

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a25efa12b5b&type=max)

#### 彩票机必查

出实物票/出电子票→检查是否有数据，如果具备同时都会出的场景则两列都检查，没有数据则代表有异常，需要复查机台是否有故障

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a28de0f2cb9&type=max)

#### 礼品机必查

出礼品数→检查是否有数据，没有数据则代表有异常，需要复查机台是否有故障

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a2b01932db7&type=max)

## 3.检查娱乐机盈利数据，通过数据分析是否有异常

①【机台经营报表】中的分页切换至按机台汇总

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a3341483180&type=max)

②检查返蓝票率是否正常，高于100%均属于异常，一般正常范围在80%~90%左右，过大过小也是有可能存在异常，具体视机台返奖情况，不同机台略有差异。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a3527233250&type=max)

注意：超过100%大概率是出蓝票异常导致，可结合机台自己的账目报表进一步复查机台是否有异常问题（如出蓝票不准等问题）。可参考文档：《蓝票机亏损后如何测试排查》。

同时建议蓝票机每日都通过抄码表的来及时发现蓝票机问题，避免对门店经营造成重大损失，参考教程：《【新门店必看】新安装卡头设备如何通过手抄码表功能来检查机台出奖是否正常》

## 4.检查彩票机盈利数据，通过数据判断是否有异常

①【机台经营报表】中的分页切换至按机台汇总

②检查出票比是否正常，由于彩票机出票比都不太一样，并且出票比实际与币单价是进行挂钩的，币单价越低情况下，出票币可能就设置越高，常见出票比通常在25~35之间居多，如果过高或者过低都有可能代表机台有异常，需要复查是否存在故障。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a4a74f637a2&type=max)

## 5.检查礼品机盈利数据，通过数据判断是否有异常

①【机台经营报表】中的分页切换至按机台汇总

②根据不同的机台种类检查【每礼品币数】是否存在异常。

检查逻辑为：每礼品币数*门店币单价>单个礼品成本，则为正常。反之，有可能机台未设置好或者投币数不对等导致抓取率过高，需要复查机台是否有异常。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d9a5180e838c4&type=max)

## 6.核心机台（彩票机、蓝票机），检查投币线接口是否有被安装偷分器。

针对高风险机台，应采取定期检查投币信号线是否有被加装偷分器。

# 其他问题

1.以上数据都正常，是否就代表所有卡头都正常？

答：不一定，一段时间的经营数据确实能反映卡头情况，但部分异常原因有可能因为数据量采集比较少导致无法反馈出来。此文档只是提供建议可以通过数据分析来快速排查可遇见的卡头问题。

2.我的数据查看不正常，但是机台复查数据又正常是什么原因？

答：一方面部分机台在爆分时就不在投币，导致系统已经记录了数据却没到机台上，导致机台盈利数据不准。另一方面也有可能门店存在有玩家利用作弊工具获得盈利。每日手抄机台码表与后台数据核对是最有效的检查手段。
