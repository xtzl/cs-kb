# 作业说明：

由于安装硬件时需要使用部分工具，实施工程师可根据实际情况提前进行准备。

# 作业标准：

1.【必要性】为“必要”的工具，必须在安装前提前准备好。

2.【必要性】未“非必要”的工具，可根据自己的实际情况进行准备，此类工具一般为提高效率工具或者为常规情况下极小概率使用的工具。

3.如工具购买链接失效时，可执行：①根据工具名称、工具尺寸、工具外观图购买同等功能或同等性能的工具作为代替；②联系油菜花实施组组长更新购买链接。

4.工具准备完毕时效必须在上面实施前1天完成。
