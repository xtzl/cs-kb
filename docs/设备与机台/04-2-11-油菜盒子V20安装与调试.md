# 三、作业准备

1.本地部署系统需要开通云互联功能，需要使用域名功能才能连接

2.如果需要使用扫码游戏，需要开通盈客宝小程序（微聆不支持油菜盒子V20扫码游戏功能）

3.由于油菜盒子V20自带网关，所以场地不需要额外配置网络。

# 四、注意事项

投币输入和投币数据接口比较相似，注意不要接错，在线路上请根据标记准确接入。

# 五、接线标准

### 油菜盒子V20网关接线要求：

1.紫色盒子接入USB供电电源。

2.紫色盒子接入天线。

3.紫色盒子放置在黄色盒子中间位置，如果有两个紫色盒子，均匀分布在场地两侧。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53a52d7a&type=med)

### 油菜盒子V20接线要求：

1.从机台中引出投币信号线，接入到盒子端投币输出，并将盒子端的投币输入接入到机台投币器。

2.（礼品机）从礼品接口接入礼品线，并接入礼品机的礼品码表的地线中。

3.接入天线，注意，如果天线位置较里面信号不够，则需要使用长天线连接，并将长天线引到机器外部的顶部位置，严禁天线接触金属外壳。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53b62d7b&type=med)

# 六、调试作业

1.油菜盒子V20网关（紫色）放置到场地合适位置（只有一个则放中间位置，如果2个以上放置到边缘位置）

2.等待油菜盒子V20网关正常通电即可，切记不要对油菜盒子V20网关进行绑定配置。

3.可以通过打开盒子内部，观察内部显示板判断是否已经联网成功，如果显示两位数字则代表已经正常通讯，显示的数字代表信号强度，如下图所示（信号强度为46）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53c72d7c&type=med)

4.连接油菜盒子V20信号线，并通电，等待盒子端联网，联网成功工正常为3绿常亮1红闪烁（电源、联网和强度为绿色灯，待机为红色闪烁）

5..登录后台，依次进入路径：后台→设备→基础设置→卡头WiFi通讯设置→重新设置通讯网络

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53e02d7d&type=med)

6.配置现场网络基础信息，如下图所示配置

选择外场→输入服务器域名地址→下一步→无线名称和密码忽略不需要修改→直接点完成→点服务器地址同步到游智云

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53ea2d7e&type=med)

注意：此处填入门店域名地址，不支持内场IP地址

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab53f72d7f&type=med)

注意：这里的无线名称和密码忽略不用修改

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54002d80&type=med)

注意：这里务必点同步，否则有可能引起异常。

7.再次扫配置码进入配置界面（注意，虽然这里提示请勿使用微信扫一扫，但是新版已经支持微信扫一扫使用）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab540c2d81&type=med)

8.进入配置界面之后，添加项目，建立项目，添加端口，绑定盒子编码，完成配置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54162d82&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54202d83&type=med)

# 七、常见问题

1.如果需要解绑重连，可长按盒子端解绑按钮5~10秒进行解绑

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab542b2d84&type=med)

2.如果盒子出现异常，可长按盒子设置键5~10秒，然后断电再上电进行重置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54362d85&type=med)

3.连接完毕后，出现重启后多上币，或者机台报卡币，可尝试调试盒子上的常开常闭设置，一般以机台中投币器的NO/NC进行设置，原来是NO则对应就是常开信号，反之常闭。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54472d86&type=med)

4.如果机台投币后机器不启动，请检查机器信号线电压，并在下图中位置调整信号线电压。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a02ab54572d87&type=med)

4.打开油菜盒子V20网关后，LED显示板会现场错误代码，含义如下：

H4 连接测试游智云

H5 注册游智云

H6 检测更新

H7 获取绑定信息

5.配置油菜盒子V20时，绑定时需要等待非常久的时间，并且最终报超时无法绑定

原因：网关网络问题/网关被绑定成游乐项目

解决方法：检查网关网络/解除网关绑定
