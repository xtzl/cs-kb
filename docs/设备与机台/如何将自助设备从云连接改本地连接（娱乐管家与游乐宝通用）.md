# 为啥要改本地连接？
当门店使用本地服务器时，使用本地连接连接设备将获得更稳定的使用体验，同时也可以避免因门店外网因不可抗因素导致无法使用时，也可以不影响本地连接的设备正常使用。  
<font style="color:rgb(223, 42, 63);">注意：如果场地是外场网络（与服务器不在同一局域网内），则不可以切换至本地连接。</font>

<font style="color:rgb(223, 42, 63);"></font>

# 教程适用范围设备
自助兑币机所有版本

自助存票机V6

自助售票机

自助发卡机

人脸闸机

立式验票桩

说明：安卓程序类设备都可以通过此方式更改

<font style="color:rgb(223, 42, 63);"></font>

**如何判断设备是云连接还是本地连接？**

拔掉网线，重启设备，此时设备会提示连接不了服务器，并显示服务器地址，如果服务器地址使用http://y********.yun.youcaihua.net:88/,则代表是云连接



**如何修改为本地连接**

**1.先将设备网线断开，并重启设备**

**2.等待提示服务器地址时，将连接的服务器地址修改为本地地址，并插上网线，点击确认完成连接**

<font style="color:#333333;">若不知道如何查看本地ip地址，可参考以下文档进行查看：</font>

<font style="color:#333333;">输入完成，点击确认，若页面提示连接服务器失败，请检查网络是否正常，网线是否有问题，并且确认网络跟服务器在同一局域网内。</font>
