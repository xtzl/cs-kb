# 置换说明：

客户万达专版系统因客观需求需要切换成新版娱乐管家系统。

原万达专版系统为应对部分突发情况，需保留几个月，当发生会员储值纠纷问题时可供工作人员在原万代专版系统上查询数据，故存在原服务器上安装双系统的情况。

同时，系统所用的万达专网也需更换成普通外网，部分网络设备需一并更换。

# 置换准备：

原万达系统服务器迁移确认（部分门店的服务器可能是存放在万代机房内，需从机房迁移至门店）；

网络设备确认（主路由、交换机、AP路由器是否需要更换，需更换的网络设备是否到位）；

门店营业时间确认（明确门店结束营业时间，需结合现场做合理的时间规划）

万达服务器开机密码确认：默认为 ****（已脱敏，请向运维索取）

原万达系统跟新版娱乐管家系统是否共用一个小程序

# 置换流程：

在完成原万达系统服务器迁移确认工作，即确保服务器在门店内，且处于正常开机状态，即可开始进行切换。

### 同一服务器上安装双系统：

1.下载安装并运行新系统host文件，注意编辑安装路径为：D:\Program Files\YCHMallnewylgj

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8b134b78ab&type=max)

2.主机端口设置为9998，机台端口更改为1098，数据库实例名修改为门店加密狗8位数

注意：部分场地的反扫卡头因为版本过低，会出现用新机台端口1098连接不上，只能用1016端口连接的情况。如若遇到该情形，则需要将原服务器端口更换成其他端口1090，再将新装的服务器机台端口改成1016，用此端口去进行配置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8b459078ae&type=max)

3.安装确认。

在桌面找到安装成功的服务，右键打开文件所在文件夹

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8b5eb778af&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8b7d4e78b4&type=max)

注意：新安装娱乐管家后，原旧系统的授权文件，需要重新授权一遍，不然旧系统可能会隔几天后出现异常无法使用

### 数据导入：

万达专版系统数据不能直接从原万达系统上直接导出（直接导出的数据是不准的），需由客户方联系万达集团的工作人员导出提供。

该数据需结束实际情况做调整，具体数据整理可参考如下视频：

#### 常用导入数据：

会员卡号、手机号、游戏币（若场地原本支持游戏币扣淘气堡次数，建议导入成金币，且游戏币有效期无法导入）、次卡年卡（含淘气堡、小火车等项目）

商品资料（可提前在系统录入，商品库存需等门店结束营业之后再录入新系统）

#### 可能会涉及到的导入数据：（需跟客户确认是否要导入）

彩票、积分、会员有效期

#### 数据导入检查：

1.比对客户提供的总表储值数据，比对导入系统的总值是否一致

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8b968878b8&type=max)

2.随机在客户给的原万代会员储值表抽取几个手机号，在新系统会员查询查找该手机号信息，比对导入的储值是否一致。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979a8bad2d78ba&type=max)

### 网络重构：

原万达专用网络需更换普通外网，所有更换的网络设备统一要求更换为TPLink品牌型号。

需新增的网络设备有：主路由器、主交换机、隔离路由器（POE-AC一体）、AP

### 机台设备调试：

#### 调试准备：

机台信息录入
可实现将场地机台信息录入新系统，便于后期直接调试写配置卡。

机台开锁
找到场地所有机台钥匙，提前将需要重刷配置卡的机台开锁，避免因开不了锁导致无法重新配置卡头

#### 卡头调试：

万达专版系统所用卡头除非新增卡头为钻石V9卡头，否则通常为反扫卡头，少部分为钻石V2卡头

具体卡头配置可参考以下文档：

反扫卡头接线及配置说明（模拟机礼品机）（娱乐管家）（本地服务器）

#### 调试检查：

调试完成的每个卡头都需要刷卡检查是否能正常使用。

### 培训指导：

万达专版系统跟新版娱乐管家系统绝大多数功能相同，到部分操作细节及UI界面略有不同，培训时需加以强调。

# 常见问题：

问题1：新系统盈客宝小程序是否可以延用原先的万达专版系统的小程序？
解答：可以，但会导致顾客无法在手机端查询原来万达系统的会员数据

问题2：先万达专版系统的会员卡能否在新版系统继续使用？
解答：按逻辑是可以的，如若遇到不能使用的情况，需联系助理开会员卡刷卡额度，再到收银台转卡。
