# 一、文档说明

由于卡片质量可能出现问题，或者读卡器出现问题，导致实际写入配置卡信息和在系统上配置的配置卡信息不一致，从而进一步引起硬件设备读取错误的配置信息导致无法连接。此时我们需要排查到底是读卡器问题，还是会员卡问题，又或者是硬件读卡模块问题。

# 二、排查思路

通过读卡工具，来读取实际卡内写入的信息是什么；如果读取出来的信息和系统上信息有误差，换一张卡（非同批次卡）再测试。如果读取出来是一致的，但是到卡头上写入不一致，则换其他卡头再测试，确认是否卡头问题导致。

# 三、工具准备

1.会员卡若干，最好准备多个批次多种样式的会员卡进行测试

2.读卡器若干，轮留更换测试用

3.电脑若干，轮换电脑测试

4.读卡工具下载：https://nos-pulic.nos-eastchina1.126.net/%E8%8E%B7%E5%8F%96%E9%85%8D%E7%BD%AE%E5%8D%A1%E5%B7%A5%E5%85%B7/%E8%8E%B7%E5%8F%96%E9%85%8D%E7%BD%AE%E5%8D%A1%E4%BF%A1%E6%81%AF%E5%B7%A5%E5%85%B7.zip
