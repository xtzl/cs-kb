# 为啥要改本地连接？
  
当门店使用本地服务器时，使用本地连接连接设备将获得更稳定的使用体验，同时也可以避免因门店外网因不可抗因素导致无法使用时，也可以不影响本地连接的设备正常使用。  
<font style="color:rgb(223, 42, 63);">注意：如果场地是外场网络（与服务器不在同一局域网内），则不可以切换至本地连接。</font>

#   
  
如何判断设备是云连接还是本地连接？


重启卡头时，会显示服务器地址，如果此服务器地址并非本地服务器地址（本地服务器地址一般为192.168开头），则代表此卡头通过云服务器连接

#   
  
如何修改为本地连接


<font style="color:#333333;">修改通用配置卡信息</font>

<font style="color:#333333;">路径如下：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732179614354-d992c217-cf7d-4b49-8799-12b1d0388143.jpeg)

<font style="color:#333333;">进入配置信息后，选择【内场】并确认服务器地址和端口是否正确</font>

<font style="color:#333333;">服务器地址一般为192.168.**.**，默认端口为9999，</font>

<font style="color:#333333;">若不知道如何查看本地ip地址，可参考以下文档进行查看：</font>

[<u><font style="color:#4F7CCE;">win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)</font></u>](https://jingyan.baidu.com/article/48b37f8df201691a6564887c.html" \t "http://kms.gzych.vip/webdoc/real/_blank)

<font style="color:#333333;">填入现场无线网络的WIFI名称和密码，点击保存完成设置</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732179614837-e95e1857-ec93-4375-9cdd-acab88321004.jpeg)

<font style="color:#333333;">点击服务器地址同步到游智云，并将空白卡放置到读卡器中，并启用油菜助手后点击【网络参数写入配置卡】完成配置卡写入。</font>
