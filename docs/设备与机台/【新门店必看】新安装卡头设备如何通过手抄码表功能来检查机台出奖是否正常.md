# 应用场景
为确保新装卡头设备（如彩票机/礼品机/娱乐机）的出奖数据精准性，避免因参数偏差造成经营损失，我们特别整理了一套简单易行的数据核验流程。请您在设备启用后，务必按以下步骤建立日常核查机制。

# 注意事项
1. 机台本身是没有账期的概念，记录的账目均为按自然日技术，系统有账期的概念；所以如果只按当日来记录比对数据，可能少许误差，此情况需要同时比对多日记录来核查对应的数据。
2. 数码币会影响对应的机台数据，请务必提前了解您的机台是否已经安装适配数码币的装置，避免因为机台问题导致产生误差。
3. 市面部分机台虽然单次投币和出奖品时是正确的，但是在大量的投币数据和出奖励数据时才会呈现误差，务必按以下步骤建立日常核查机制。
4. 一般新机器刚出厂时出奖概率相对比较高，这个是正常现象，但机台一般还是会盈利，如果出现亏损，务必留意是否有异常。
5. 实物币投币记录，卡头可能会有延迟，这是因为卡头为了避免频繁传输数据到数据库导致性能下降所优化的机制，属于正常现象。

# 操作流程
### 第一步：在机台中找到营业账目或者是查看码表（此步骤在当日营业开始前或者前一天营业结束后来读取）
由于不同机台查看方式不一样，请您查看对应的机台的说明书来查看看，例如下图所示：

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749005340138-8655f6d7-ea6b-4237-b73a-b9c2731b84c6.png)

以上图为例，抄写数据时，我们可以按累计数来取数，记录到系统中，而上图的累计数则为第三行数据和第四行数据。

### 第二步：将抄写的数据记录到系统中，通过手机端的【游乐掌柜】小程序功能中的【手抄码表】功能来记录。（以下以彩票机为案例）
1.先给抄码表的员工添加后台登录账号以及游乐掌柜账号，可参考以下文档

[如何给员工开游乐掌柜账号？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/za3tbq8o3u3v1ttw)

注意：在新增游乐掌柜账号时，需要基于员工有【手抄码表】的权限

2.打开微信，在小程序中搜索【游乐掌柜】，并授权登录

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749007407754-c8441497-7c8a-4d0f-af4d-65af3be50f99.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749007468919-5c0d8ebc-c009-4bcf-a000-65008c5c1f9d.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749007514312-626cce9f-4998-488d-93c1-f7b1550f0e91.png)

3.登录【游乐掌柜】后，在【店务】中找到【手抄码表】，打开后，找到对应的机台，并选择对应的P位中输入对应的投币数和彩票数，填写完毕后点击【保存】，完成当天该机台的数据记录，如下图所示

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749007114221-1de07948-0de8-4983-bd14-51bf0d7a89bd.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749007733900-4ee6a157-43f2-45c4-830a-2021932b905b.png)



温馨提示：

1.如果当次记录码表数据错误，可以在手机中的【已抄表】一栏中进行修改。

2.手抄码表功能除了可以记录码表状态以外，还可以记录【收币】、【期初票】、【加票】、【余票】等数据，丰富记录信息。

### 第三步：查看后台【手抄码表】数据，检查系统数据误差
登录后台，打开【手抄码表】界面（路径：后台→报表→手抄码表），检查对应的机台的差异是否有异常。![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749009923804-84b36c7d-5766-4a6c-aefc-72ee60080863.png)

说明：

收币误差可以体现出来系统记录的投币数和实际的投币数的误差值，一般超过3%为异常，且误差一栏会标记为红色

出票误差可以体现出彩票或者其他奖励储值的误差值，一般超过3%为异常，且误差一栏会标记为红色。



# 常见问题
1. 门店营业时间超过凌晨0点，当日手抄码表的差异数和实际机台账目差异数无法对上

答：核对机台码表数可按一段时间周期整体来看，比如按可选择按日报并选择一周时间来核对。按周期核对差异数较少情况下均可以判断为正常。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1749010229796-ea2626cf-1cdf-4bbf-ad6b-ad63ddf85495.png)

2. 假如抄码表的数据来算是亏损的，但是系统显示的是盈利的，在数据对不上的情况下，门店到底有没有亏钱？

答：如果是实物币占比不高的情况下，系统显示是盈利的则一般为盈利，因为游客是按系统记录的数据来游玩和兑奖的，不会按照机台的营收来兑奖。但如果门店实物币占比较大，是否盈利则无法判断。

3. 哪些情况下，机台和卡头参数正常也会产生误差？

答：部分机台在爆机情况下是禁止且无法投币的，在这种情况下，会产生误差；例如某机台，机台游玩逻辑是当出现爆机（即达到机台最大游玩分值）后，所有投币失效且后续投如的游戏币会直接转换成奖励（退彩票或退游戏币），此时机台账目不会记录后续继续投入的游戏币到账目上也不会记录出的奖励分值，而系统依旧会记录这部分的数据，这时就会产生误差。这种情况建议降低每一个游戏币对应的游戏分值，降低爆机出现的概率。并且建议及时关注这个机台的盈利情况。

4. 发现了机台亏损，并初步判断大概率是参数不对导致出奖数据异常应如何处理

答：及时调整物理参数，部分机台物理参数可查询[机台参数记录](https://ding.cjfx.cn/f/wmuhk8n4/query) 来进行查询，如未能查询到，可联系硬件客服协助调试。
