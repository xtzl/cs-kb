# 🔴应用场景
场地增加路由器或ＡＰ后， 要把WIFI按系统要求进行设置，不然卡头或其他设备可能无法连接上系统

# 🔴操作流程
根据卡头不同的配置方式，有两种方式可查看卡头WIFI设置

方法1：单配置卡模式（指的是每次配置一个卡头都要单独写一张配置卡）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719455936836-befd2cff-f5e6-4e7e-a127-68cf13bc296a.png)

方法２：通用配置卡模式（指的是用一张配置卡就能配置全场卡头）
