## 问题描述：

魔小方卡头是支持自定义更换卡灯光颜色的，可以如何操作？

## 问题解决：

颜色调整无法完全自定义，只能按目前系统内置好的几种颜色去调整，并且是按卡头规划的区域去进行统一设置

### 具体步骤如下：

#### 1.新增区域：

业务系统后台 -> 区域设置 -> 【新增】
