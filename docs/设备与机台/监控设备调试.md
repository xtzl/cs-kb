# 一. 文档说明

本文档主要明确了音响设备安装的工作内容、作业准则、工作要求以及禁止事项，请所有实施相关人员务必认真阅读。

# 二. 主要设备

企业级路由器，交换机，海康监控主机32路，海康监控摄像头

# 三. 监控设备安装流程

## 3.1 监控设备连接示意图

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938a649189138a&type=max)

注意事项：

1）监控设备需24小时不断电，需要门店拉一根电线和主电源开关分开（电源线建议和消防电线连接在一起，连接在消防联动的上级）

2） 需要将网络设置好之后在调试监控，网络调试好之后监控设备会自动连接

##

## 3.2 监控设备安装流程

### 监控摄像头安装流程

1）将监控摄像头连接好网线，在固定位置用电钻将底座固定住

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b14a5cd14de&type=max)

2）监控网线会有裸露在外的，需要使用黑胶管包裹

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b1690a514e1&type=max)

3）将网线的一头接在给监控供网的交换机上面，用寻线仪找到对应的网线并进行标记

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b61e1dc1590&type=med)

### 海康监控主机32路安装流程

1）将海康监控主机32路通电，用网线连接到给监控供网的路由

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b1e9e4414ff&type=max)

2）用电视高清线将海康监控主机32路和显示屏连接在一起

## 监控基础调试

1）用电视遥控器将显示屏切换成海康监控主机32路的HDML1口，显示屏会自动跳转出设置密码界面，设置好监控密码，点击激活并自动配置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b35831e152d&type=max)

2）点击确认自动配置，等监控设备自动配置成功之后，点击下一步直至成功

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b3858a31532&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b3974011533&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b3b2d0c153a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b417c951547&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001938b4198a71548&type=max)

3）根据门店具体情况，需调整监控角度
