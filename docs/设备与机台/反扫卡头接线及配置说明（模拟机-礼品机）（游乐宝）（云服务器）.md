# 三、功能说明
<font style="color:rgb(51, 51, 51);">1.同时支持刷卡扣储值（代币、金币、预存款）和投实物币使用，并分别统计投币数量；</font>

<font style="color:rgb(51, 51, 51);">2.支持按次扣费（计次票功能）和包月验证（扣期限票）功能（仅支持存入会员卡内的套票扣费）；</font>

<font style="color:rgb(51, 51, 51);">3.支持会员二维码直接读取会员扣费；</font>

<font style="color:rgb(51, 51, 51);">4.支持微信付款码支付和支付宝付款码支付扣款；</font>

<font style="color:rgb(51, 51, 51);">5.支持设置闸机模式，并支持设置为出入口模式；</font>

<font style="color:rgb(51, 51, 51);">6.支持导出机台二维码功能，机台二维码可用于扫码游戏，机台库存管理扫码补库，扫码录入手抄码表，扫码进行收币车收币功能；</font>

<font style="color:rgb(51, 51, 51);">7.支持统计出礼品功能，单礼品模式下支持出礼品直接扣库存；</font>

# <font style="color:rgb(51, 51, 51);">六、卡头固定安装标准 </font>
## <font style="color:rgb(51, 51, 51);">安装方法：</font>
<font style="color:rgb(51, 51, 51);">1.与客户沟通，初步确认大概安装位置，并用记号笔标记位置；</font>

<font style="color:rgb(51, 51, 51);">2.打开机台投币器位置，观察内部结构，进一步判断预计安装位置是否影响游客游玩和日常维护；并且判断投币信号线和马达信号线是否能连接到投币器和马达位置；</font>

<font style="color:rgb(51, 51, 51);">3.使用手电钻进行开孔，开孔时，根据不同情况使用不同的开孔器，情况如下：</font>

+ <font style="color:rgb(51, 51, 51);">机台表面为纯铁面，使用</font><font style="color:rgb(51, 51, 51);">开孔器（铁）（20mm）进行开孔；</font>
+ <font style="color:rgb(51, 51, 51);">机台表面为木或者瓦克力，</font><font style="color:rgb(51, 51, 51);">使用</font><font style="color:rgb(51, 51, 51);">开孔器（木）（20mm）进行开孔；</font>
+ <font style="color:rgb(51, 51, 51);">机台表面为复合型双层面，顶部为瓦克力，底部为铁质，先使用</font><font style="color:rgb(51, 51, 51);">开孔器（木）（20mm）对表面进行开孔，后再用</font><font style="color:rgb(51, 51, 51);">开孔器（木）（20mm）对铁质内部进行开孔</font>

<font style="color:rgb(51, 51, 51);">4.使用手电钻，更换成批头，将底座放置到机台表面，对准位置后，用自攻螺丝将卡头底座进行固定，对不同材质有对应要求：</font>

+ <font style="color:rgb(51, 51, 51);">机台表面为纯铁面，直接使用自攻螺丝进行固定即可；</font>
+ <font style="color:rgb(51, 51, 51);">机台表面为复合型双层面，需要先使用</font><font style="color:rgb(51, 51, 51);">麻花钻（3mm）对第一层面进行开孔，再使用自攻螺丝进行固定；</font>
+ <font style="color:rgb(51, 51, 51);">机台表面为木质或者亚克力面板时，直接使用自攻螺丝进行固定。</font>

<font style="color:rgb(51, 51, 51);">5.将线材通过孔位引入到机台内部，并接入卡头中，并且盖上卡头上盖，用小十字螺丝到扭紧固定完毕。</font>

## <font style="color:rgb(51, 51, 51);">安装标准：</font>
<font style="color:rgb(51, 51, 51);">1.所有机台位置，必须是客户认可位置进行安装；</font>

<font style="color:rgb(51, 51, 51);">2.卡头安装时，需要断电操作，禁止带电安装，特殊情况需要与客户沟通双方达成一致后再进行作业；</font>

<font style="color:rgb(51, 51, 51);">3.卡头固定必须都使用自攻螺丝进行固定，客户有特殊要求除外；</font>

<font style="color:rgb(51, 51, 51);">4.当客户无安装经验时，可适当提供安装位置建议，建议原则如下：</font>

+ <font style="color:rgb(51, 51, 51);">安装高度一般不低于机台实物币投币器位置，且不影响实物币投币</font>
+ <font style="color:rgb(51, 51, 51);">卡头正面角度建议与机台呈水平或者垂直状态</font>
+ <font style="color:rgb(51, 51, 51);">卡头显示板方向建议位于机台正前方，可轻易看出终端位置并刷卡</font>
+ <font style="color:rgb(51, 51, 51);">安装位置应保证距离不影响机台的正常游玩以及正常机台维护</font>
+ <font style="color:rgb(51, 51, 51);">尽量安装机台平面位置</font>

<font style="color:rgb(51, 51, 51);">5.卡头安装固定时，卡头与机台位置平行或者垂直；</font>

<font style="color:rgb(51, 51, 51);">6.卡头为垂直安装时，如有配备卡头支架，应使用卡头支架进行固定；</font>

#### <font style="color:rgb(51, 51, 51);">联网常见问题</font>
#### <font style="color:rgb(51, 51, 51);">常见问题：</font>
<font style="color:rgb(51, 51, 51);">1.点保存并写入卡中没反应</font>

<font style="color:rgb(51, 51, 51);">答：检查是否使用网页打开后台，此步骤需要使用程序打开后台才能写卡；</font>

<font style="color:rgb(51, 51, 51);">2.提示无法连接读卡器</font>

<font style="color:rgb(51, 51, 51);">答：由于读卡器被占用导致，请检查是否通知打开收银台和后台，如果是则关闭收银台，并插拔一次读卡器</font>

<font style="color:rgb(51, 51, 51);">3.提示读卡失败</font>

<font style="color:rgb(51, 51, 51);">答：有可能读卡器有干扰导致，尝试将读卡器拿到手上进行写卡</font>

<font style="color:rgb(51, 51, 51);">4.域名解析失败，报E52、E53、E25，但不显示E40</font>

<font style="color:rgb(51, 51, 51);">答：由于部分地区域名解析失败，需要在路由器的LAN设置中的DHCP中添加DNS分配</font>

<font style="color:rgb(51, 51, 51);">DNS设置为：119.29.29.29,223.5.5.5</font>

<font style="color:rgb(51, 51, 51);">5.大部分卡头能正常链接，在网络覆盖范围良好情况下，卡头随机无法连接</font>

<font style="color:rgb(51, 51, 51);">答：有可能DHCP（自动分配地址功能）的地址范围不够，可增大分配的IP地址尝试是否能解决。</font>

# <font style="color:rgb(51, 51, 51);">七、测试要求</font>
#### <font style="color:rgb(51, 51, 51);">投币信号匹配测试</font>
<font style="color:rgb(51, 51, 51);">将会员卡放到卡头手上读取，卡头能显示卡内余额，并在1秒内扣除余额，机台上对应的币数，机台自带码表正常增加扣币数量则代表投币信号正常无异常；</font>

#### <font style="color:rgb(51, 51, 51);">礼品信号匹配测试</font>
<font style="color:rgb(51, 51, 51);">将礼品扔到出礼品口，模拟出礼品过程，机器显示中奖，油菜花后台记录出礼品数，则完成礼品测试过程；</font>
