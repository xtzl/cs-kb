# 一、作业说明

本教程用于芸苔使用无线版的油菜盒子、反扫卡头的场地使用，使用的主路由器型号为TP-LINK TL-R479GPE-AC

# 二、作业准备

电脑一台，网线一根。

# 三、注意事项

网线不要插错口

# 四、作业标准

卡头网络正常可使用

# 五、作业步骤

## 第一部分，接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731174414351c&type=med)

## 第二部分，主路由调试

2.把电脑的网线接到路由器LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117441f351d&type=med)

3.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117442d351e&type=med)

4.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018731174438351f&type=med)

5.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744423520&type=med)

6.跳过快速配置界面

7.选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117444e3521&type=med)

8.选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“10.0.0.1”-将【子网掩码】设置为“255.255.0.0”-然后点【设置】，按下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744583522&type=med)

9.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

10.进入【LAN设置】，找到【DHCP服务】，将DHCP服务开打，开始地址为“10.0.10.2”；结束地址为“10.0.10.254”，网关地址为：“10.0.0.1”，首选DNS服务器：114.114.114.114，备用DNS服务器：223.5.5.5，然后点保存设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744643523&type=med)

11.选择【AP管理】-【AP设置】-将【AP管理功能】勾选上，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117446e3524&type=med)

12.选择【AP管理】-【无线网络设置】-将【多频合一】关闭掉

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744783525&type=med)

13.登录芸苔新零售公众号，点【管门店】，登录后，选择【我的】-【网络规则】，将WIFI名称和密码复制出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744823526&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117448b3527&type=med)

14.继续回到路由器设置界面，选择第一个无线网络设置，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744943528&type=med)

15.如下图所示设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873117449f3529&type=med)

16.点【AP管理】-【射频调优】-【信道调优】选择启用-【2.4G信道集合】改成1.5.9.13,-最后点【设置】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187311744a9352a&type=med)

## 第三部分，测试连接

17.设置完毕后，油菜盒子会自动连上该网络，并且电源、联网和强度灯均为绿色灯，待机为红色灯闪烁；如果使用反扫卡头，则会显示H07等待配置。
