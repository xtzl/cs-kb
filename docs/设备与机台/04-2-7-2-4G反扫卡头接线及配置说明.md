# 一、作业说明

新到场地的盒子要与场地系统连接，就要安装接线与配置，下列为4G盒子的安装说明，4G盒子本身同时支持游乐宝/娱乐管家系统以及芸苔系统，本说明针对游乐宝/娱乐管家系统来调试。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841d7415282c2d&type=max)

# 二、作业准备

1.反扫卡头需要固定在机台上

2.反扫卡头与4G盒子接线无无误

3.本地部署系统需要开通云互联功能，需要使用域名功能才能连接（云服务器不需要）

4.如果需要使用扫码游戏，需要开通盈客宝小程序（微聆不支持4G盒子扫码游戏功能 ）

# 三、注意事项

投币输入和投币数据接口比较相似，注意不要接错，在线路上请根据标记准确接入。

# 四、接线标准

### 1.从机台中引出投币信号线，接入到盒子端投币输出。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841d77f4e42c30&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841d7a5db72c34&type=max)

### 2.盒子线材中标记为【投币器】的一段接入到投币器，另一端标记为【投币输出盒子端】接入到盒子中的投币输出

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841d9fb9802c75&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da07ccd2c77&type=max)

### 3.（礼品机）从礼品接口接入礼品线，并接入礼品机的礼品码表的地线中。

### 4.（支持协议的机台）从机台协议端口引出线路接入到游戏协议

### 5.（接入反扫模块）从反扫模块中的线路分别接入到盒子端的扫码模块和灯光模块

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da1d4732c78&type=max)

### 6.接入天线，注意，如果天线位置较里面信号不够，则需要使用长天线连接，并将长天线引到机器外部的顶部位置

最终接线图如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da47f6d2c79&type=max)

# 五、调试作业

### 1.机台通电，等待盒子端联网，联网成功工正常为3绿常亮1红闪烁（电源、联网和强度为绿色灯，待机为红色闪烁）

### 2.登录后台，依次进入路径：后台→设备→基础设置→卡头WiFi通讯设置→重新设置通讯网络

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da596052c7b&type=med)

### 3.配置现场网络基础信息，如下图所示配置

选择外场→输入服务器域名地址→下一步→无线名称和密码忽略不需要修改→直接点完成→点服务器地址同步到游智云

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da5961f2c7c&type=med)

注意：此处填入门店域名地址，不支持内场IP地址

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da5962e2c7d&type=med)

注意：这里的无线名称和密码忽略不用修改

# 六、常见问题：

1.如果需要解绑重连，可长按盒子端解绑按钮5~10秒进行解绑

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da597882c82&type=med)

2.如果盒子出现异常，可长按盒子设置键5~10秒，然后断电再上电进行重置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da597942c83&type=med)

3.连接完毕后，出现重启后多上币，或者机台报卡币，可尝试调试盒子上的常开常闭设置，一般以机台中投币器的NO/NC进行设置，原来是NO则对应就是常开信号，反之常闭。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da5979e2c84&type=med)

4.如果机台投币后机器不启动，请检查机器信号线电压，并在下图中位置调整信号线电压。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01841da597a82c85&type=med)
