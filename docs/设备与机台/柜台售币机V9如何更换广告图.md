# 图片尺寸

- 广告图片尺寸为：1920*1080 (竖屏），JPG图片格式

- 可上传多张广告图轮播

# 如何更换

1，先用钥匙打开锁，把屏幕从底部往上推，就能把屏幕拿下来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7de10cd3017debe1c6eb058a&type=max)

2，取出屏幕背面的U盘，更换这个U盘里的图片

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7de10cd3017debe43f5e058e&type=max)
