# 🔴应用场景
原来更换兑币机等设备的广告图需要插U盘操作，繁琐复杂。 使用此功能，你可以在油菜花系统后台批量更改各类带“屏幕”的硬件设备广告图，例如：兑币机，售票机， 双屏收银电脑等

注意：<u><font style="color:#DF2A3F;">柜台售币机Ｖ９</font></u>目前暂不支持此操作～
