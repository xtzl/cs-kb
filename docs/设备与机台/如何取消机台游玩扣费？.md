# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
由于机台故障导致游客刷卡扣币后不启动机台，可以通过系统将本次扣币进行取消。

# **<font style="color:rgb(38, 38, 38);">🔴</font>**操作流程
路径：收银台→游乐→取消机台扣费

#### 打开【取消机台扣费】的界面，读取会员信息，或者通过查询条件进行查询，找到扣费记录，点击【取消】将扣费记录进行取消
