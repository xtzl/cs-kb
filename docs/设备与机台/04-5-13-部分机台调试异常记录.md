# 疯狂魔鬼城/凤凰城

1.机台帐时间是按照每天的， 后台对账也要按照每天对，不要看
经营报表，时间有时候对不上。
2.对账要按照盈利来对，应为魔鬼城同时上下分会不计数，后台是
计数的。
3.接彩票线退分，拨码要调到12V，常开，机台爆分的时候会吃分，多的分不会下到卡头。
4.机台爆分，有时候会上10币退20币，要调慢退票速度。
5.有时候机台账目会不准，卡头上1000，P位显示有1000，但是账目会增加大于1000，多测试才能测出来，只能让他们找魔鬼城的换套件

# 魔术师

1.游戏机黑屏死机，退币马达会一直转，卡头一直退分。
2.出票延时要调300，出票速度要调200，不然机台计数电子币会少。
3.场地使用数码币，而且光眼是接在出币口的，盒子程序要升级最新的，有光眼计数间隔的，所有推币机都一样。
4.出币马达光眼是用挡片的情况，出实物币盒子有可能会多计数，这个是因为挡片和光眼有时候装的位置不好，导致一个币，光眼会计数两次，这个时候要调整光眼位置，所有推币机都一样。

# 小火车

1.出票延时要调800，不然机台计数实物币会少。

# 航海大富翁

1.彩票机械码表不计数，外接12V电源，这是因为投币供电给卡头只有10V，码表一直是导通的

# 五虎上将

1.光眼线线序是错的，要把信号和地对调，马达的也要改

# 海茂机台

1.出票延时要调10，IO板要升级到最新，调10后，无出票延时，这个问题是因为他们控制板的出票使能不是连续的，是脉冲形式

代表机台：神秘海域

2.钻石V9卡头，如果出现出票过程中突然提示【欠彩票】的报错，则因为钻石V9有特殊针对海茂机台的程序，需要升级到该程序。

# 六层妖塔

1.出实物票过程中插卡，偶尔会报出票错误，按服务键没反应必须重新读卡；此情况需要将卡头使能光眼拨码到5V，出票器拨码常闭、高电平

# 恐龙帝国

1.游玩过程中机器会报数币器错误，但不影响卡头出币；此情况需要厂商升级程序

# 天时之约（宏冠）/碧海传说（宏冠）

1.出票速度要调到120，其他默认不变，否则会出现出币不准的情况
