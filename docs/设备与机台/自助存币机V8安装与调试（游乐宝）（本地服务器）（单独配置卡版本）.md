# **<font style="color:#333333;">一、作业说明</font>**
<font style="color:#333333;">自助存币机V8是一款支持扫码，读卡的自助存币设备。请按照安装说明准确安装设备。</font>

# <font style="color:#333333;">二、外观说明</font>
![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241623703-17c05db3-6126-47c8-9446-7890d91cd600.jpeg)

# **<font style="color:#333333;">三、功能说明</font>**
<font style="color:#333333;">1.支持会员卡读卡存币</font>

<font style="color:#333333;">2.支持会员二维码反扫读取会员存币</font>

<font style="color:#333333;">3.支持正扫二维码读取会员信息存币</font>

<font style="color:#333333;">4.不支持识别假币</font>

# **<font style="color:#333333;">四、作业准备</font>**
<font style="color:#333333;">1.预留可通外网的网线以及220V电源线；</font>

# **<font style="color:#333333;">五、作业标准</font>**
<font style="color:#333333;">1.存币机放置到位（由于存币机不支持识别假币，建议放置到收银台内部）；</font>

<font style="color:#333333;">2.存币机连接正常；</font>

<font style="color:#333333;">3.存币机存币数量正确无误差。</font>

# **<font style="color:#333333;">六、调试步骤</font>**
### **<font style="color:#333333;">后台存币机项目</font>**
<font style="color:#333333;">1.登录游乐宝后台，新建一个存币机项目：</font>

<font style="color:#333333;">路径：【设置】-【设备管理】-【营业设备】-【新增】-【存币机】</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241623883-1dc9c5dc-eba3-4e2a-8855-ddeb467f7fac.jpeg)

<font style="color:#333333;">2.选择【存币机无反扫口】</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241624102-bb2c3bbb-6cbf-43a8-a1d0-8e3efaf5e0f3.jpeg)

<font style="color:#333333;">3.填写存币机的设备名称，并按照下述信息填写相关内容，然后将空白卡放到读卡器中，点击写入卡，完成配置卡写入。</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732241624323-2b3a4b39-01bb-4c49-badf-5ad9b5676932.png)

+ <font style="color:#333333;">服务器通讯方式：勾选内网；</font>
+ <font style="color:#333333;">服务器地址：输入门店服务器的IP地址；</font>

<font style="color:#333333;">若不知道如何查看本地ip地址，可参考以下文档进行查看：</font>

[<u>win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)</u>](https://jingyan.baidu.com/article/48b37f8df201691a6564887c.html)

+ <font style="color:#333333;">IP地址：请填写本碎票机使用的IP地址，根据现场提供的网线的IP地址来填写；</font>
+ <font style="color:#333333;">网关：填写本碎票机使用的IP地址所对应的网关，根据现场提供的网线的IP地址来填写；</font>

**<font style="color:#E53333;">若不知道如何查找网络ip地址或网关，可用笔记本电脑接入碎票机预留网线，参考下述文档进行查找判断：</font>**

[<u>win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)</u>](https://jingyan.baidu.com/article/48b37f8df201691a6564887c.html)

<font style="color:#333333;">比如，笔记本电脑获取到的一个ip地址为：</font>

<font style="color:#333333;">i</font><font style="color:#60D978;">p地址：192.168.110.20</font>

<font style="color:#60D978;">子网：255.255.255.0</font>

<font style="color:#60D978;">网关：192.168.110.1</font>

<font style="color:#333333;">则可以给碎票机分配为</font>

<font style="color:#60D978;">IP地址：192.168.110.*      （*号代表2~254之间的任意数字）</font>

<font style="color:#60D978;">子网：255.255.255.0</font>

<font style="color:#60D978;">网关：192.168.110.1</font>

<font style="color:#333333;">此时，在通过电脑运行cmd命令行，并尝试用ping 准备给碎票机分配的地址，看看有没有连接，如果没有任何设备连接，则代表此IP可以用；例如你想分配给碎票机192.168.110.241，则用ping来测试，如下图所示</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241624585-9c9dfa56-0079-4752-a665-182e86ae6eaf.jpeg)

<font style="color:#333333;">注意：如果发现地址已经被占用，则需要再次跟换地址，直到不被占用为止，建议使用ip地址段200-250之间的地址会比较好。</font>

<font style="color:#333333;">4.用钥匙打开存币机，找到内部的主板，一直按第二个按钮，直到显示E06</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241624822-e56f7133-0bd7-4d4b-b40d-40c6ec161357.jpeg)

<font style="color:#333333;">5.将配置卡放置到读卡器中，等待读取，并等待连接成功。</font>

# **<font style="color:#333333;">七、测试要求</font>**
<font style="color:#333333;">1.开通会员，通过打卡位置读取会员卡，测试是否能正常读取</font>

<font style="color:#333333;">2.通过小程序会员二维码反扫读卡，测试否是能读取会员</font>

<font style="color:#333333;">3.通过正扫机器二维码，会员能正常登录</font>

<font style="color:#333333;">4.测试存币，存20币以上，并测试至少3次，无误差</font>

<font style="color:#333333;"></font>

# **<font style="color:#333333;">八、常见问题</font>**
<font style="color:#333333;">问题1：报E01</font>

<font style="color:#333333;">答：未检测到网线，有可能未插网线，或者网线接口松动</font>

<font style="color:#333333;">问题2：实物币尺寸太小，导致币出币时不计数</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241624998-2b1a1cf3-3cff-438f-a26f-ca1981c0f4cf.jpeg)

<font style="color:#333333;">问题3.报E04报错</font>

<font style="color:#333333;">答：马达卡币，检查里面是否有杂物卡币</font>



<font style="color:#333333;">问题4.不显示二维码</font>

<font style="color:#333333;">答：后台微聆或者盈客宝没配置好</font>

<font style="color:#333333;">问题5.存币机显示 【X】号 无法连接</font>

<font style="color:#333333;">答：按着设置位置2个按键不放，同时按下开机电源，一直按到30秒左右，松开手，再等待一分钟之后看看结果。</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241625178-eb92eb1b-29bc-445c-afac-d5246714552c.jpeg)

<font style="color:#333333;"> 问题6：系统是本地部署，当用会员码扫自助设备或核销或登录时，提示会员码过期。</font>

<font style="color:#333333;">答：校正本地服务器时间，检查本地服务器时间是否跟世界时间一致，若不一致更改一致即可；</font>
