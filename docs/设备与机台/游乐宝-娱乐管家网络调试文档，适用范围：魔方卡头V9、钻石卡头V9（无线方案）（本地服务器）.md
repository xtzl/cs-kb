# 一、作业说明

本教程用于本地服务器使用魔方卡头V9、钻石卡头V9的场地使用；使用的网络设备：

主路由器：TL-R476G

无线路由器：WDR5620

# 二、作业准备

电脑一台，网线一根。

# 三、注意事项

网线不要插错口

# 四、作业标准

卡头网络正常可使用

# 五、设置步骤

## 第一部分，接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da96b342c&type=med)

## 第二部分，调试主路由

2.把电脑的网线接到主路由器（型号：TL-R476G）LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9a2342d&type=med)

3.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9ac342e&type=med)

4.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9b5342f&type=med)

5.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9bd3430&type=med)

6.跳过快速配置界面

7.选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9c73431&type=med)

8.选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“192.168.10.1”-将【子网掩码】设置为“255.255.255.0”-然后点【设置】，按下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9cf3432&type=med)

9.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

10.选择【AP管理】-【AP设置】-将【AP管理功能】取消掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9d83433&type=med)

## 第三部分，调试无线路由

11.拔掉调试电脑网线，将调试电脑网线接入到各个无线路由器（隔离路由器，型号：WDR5620）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9e73434&type=med)

12.在浏览器中输入tplogin.cn按回车键，接入设置界面，并设置登录密码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9f23435&type=med)

13.跳过向导

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309da9fb3436&type=med)

14.进入路由设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa043437&type=med)

15.进入上网设置，【上网方式】选择【自动获取IP地址】，并点【保存】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa133438&type=med)

16.往下拉，找到【WAN口设置】，WAN口设定设置为【固定WAN网口】，保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa213439&type=med)

17.选择【无线设置】，其中WI-FI多频合一需要关闭掉。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa2b343a&type=med)

18.登录油菜花后台系统

游乐宝路径为：【后台】-【设备】-【基础设置】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店本地IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

娱乐管家路径为：【后台】-【终端】-【卡头wifi通讯设置】-【通用配置卡】-【重新设置网络通讯】-选择【内场】并填入门店服务器IP地址-【下一步】-【生成自动连接wifi】-并复制对应的wifi名称和密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8588bf5a5ed2&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f8588bf655ed3&type=med)

19.找到【5G设置】，复制上一步的无线名称和密码并填入到对应无线名称和密码,并设置频段带宽为【****（已脱敏，请向运维索取）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa40343c&type=med)

20.选择【LAN口设置】，LAN口IP设置为【手动】，并设置IP地址改为10.0.0.1，子网掩码设置为255.255.0.0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa4a343d&type=med)

21.更改完毕后，电脑会暂时断开连接，等待1~2分钟后，重新登录到设置界面

22.选择【DHCP服务器】，按照下图设置设置对应的参数，保存，完成设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa54343e&type=med)

## 第四部分，测试连接

23.设置完毕后，魔方卡头V9和钻石V9卡头会自动连上该网络，并提示联网成功，扫码绑定门店，此时网络设置已经完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309daa5f343f&type=med)
