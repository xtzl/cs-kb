# 一、作业说明

本教程用于本地服务器使用反扫卡头、钻石卡头v2/v3的场地使用；

使用的网络设备：

主路由器：TL-R476G

无线路由器：WDR5620*N

建议卡头数量少于50个使用，一个路由器建议带机数15~20个左右。

# 二、作业准备

调试电脑*1台

网线*1根（用于调试使用）

AP已提前挂顶，AP线路连接到机柜中

外网已经通路

标签纸

# 三、注意事项

1.监控网络不要与系统网络共用主路由

# 四、作业标准

1.机柜整洁

2.线路清晰

3.网络平均延迟低于40ms

# 五、设置步骤

## 第一部分：接线

1.网络接线，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096538733bf&type=med)

## 第二部分：设置主路由器

2.把电脑的网线接到主路由器（型号：TL-R476G）LAN口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096539233c0&type=med)

3.打开浏览器，并在浏览器中输入tplogin.cn按回车键。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309653d033c1&type=med)

4.在出现的界面设置路由器的 用户名：admin管理密码：****（已脱敏，请向运维索取） 点击确定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309653dc33c2&type=med)

5.路由器跳转到管理界面后， 输入刚才设置的用户名和密码进入管理界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309653e733c3&type=med)

6.跳过快速配置界面

7.选择【基本设置】-【WAN设置】-将【接口设置】中的连接方式改为【动态IP】-点击【保存】，如下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309653f033c4&type=med)

8.选择【LAN设置】-【接口设置】-将【模式设置】改为“手动”-将【IP地址】设置为“192.168.10.1”-将【子网掩码】设置为“255.255.255.0”-然后点【设置】，按下图设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187309653f933c5&type=med)

9.此时可能会出现需要重新进入路由器设置界面，需要等待几分钟等调试电脑重新获取地址即可，如出现无法登录，请将网线拔掉再重新接上等待重新获取IP地址。

10.重新使用192.168.10.1，登录到主路由器设置界面，选择【基本设置】-【LAN设置】-【DHCP服务】，开始地址设置为192.168.10.50，结束地址：192.168.10.200，网关设置为192.168.10.1，首选DNS设置为119.29.29.29，如下图所示

说明：DHCP分配网段设置后，油菜花其他需要固定IP的设备，则使用范围外的网段，如柜台碎票机，当需要设置柜台碎票机时，可设置IP地址为192.168.10.201，避免因为固定IP和DHCP中的IP地址冲突。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917918d6bd7217&type=med)

## 第三部分：设置无线路由器

1.拔掉调试电脑网线，将调试电脑网线接入到各个无线路由器（隔离路由器，型号：WDR5620）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096540f33c7&type=med)

2.在浏览器中输入tplogin.cn按回车键，接入设置界面，并设置登录密码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096541a33c8&type=med)

3.跳过向导

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096542433c9&type=med)

4.进入路由设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096542e33ca&type=med)

5.进入上网设置，【上网方式】选择【自动获取IP地址】，并点【保存】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096543933cb&type=med)

6.往下拉，找到【WAN口设置】，WAN口设定设置为【固定WAN网口】，保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096544433cc&type=med)

7.选择【无线设置】，其中WI-FI多频合一需要关闭掉。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096544e33cd&type=med)

8.找到【2.4G设置】，按下图进行设置

无线名称设置为YocartoonNet0，也可以设置自定义无线名称，无线名称不支持中文或者符号。

认证类型 WPA-PSK/WPA2-PSK

无线密码：设置为****（已脱敏，请向运维索取），其中****设置为门店编码前4位

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914accd4fd6f34&type=max)

9.选择【LAN口设置】，LAN口IP设置为【手动】，并设置IP地址改为10.0.0.1，子网掩码设置为255.255.0.0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096546433cf&type=med)

10.更改完毕后，电脑会暂时断开连接，等待1~2分钟后，重新登录到设置界面

11.选择【DHCP服务器】，按照下图设置设置对应的参数，保存，完成设置

注意：DNS必须设置为119.29.29.29以及备用DNS为223.5.5.5

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401873096546e33d0&type=med)

## 第四部分：连接卡头测试

1.设置完毕后，在卡头写配置卡的界面，设置对应的WIFI名称和密码，网段类型选择子网地址，并填入对应的服务器地址即可写配置卡。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001914acdbe856f3b&type=med)
