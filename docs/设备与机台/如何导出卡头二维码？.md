# 🔴应用场景
部分款的卡头是不带屏幕的， 如果你希望可以实现会员扫码投币的功能， 则需要单独把这些机台的二维码导出来，打印并贴在机台上。例如一些外场的娃娃机。 

把这个二维码贴在机台上还有其他的作用， 例如使用“盘点机”或“收币车”扫码后可直接识别该机台的名称，这样就可以直接添加礼品或收币
