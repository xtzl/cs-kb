# 文档说明

门店网络至关重要，建议门店定期对网络进行检查。检查时务必在营业结束且第二天非节假日前进行检查。

# 检查流程

## 1.重启门店所有网络设备，等待重启后，检查全场设备是否连接正常。

需要重启的设备有：光猫、所有企业路由器、所有交换机（包括POE交换机）、无线路由器等。

合格标准：重启后所有设备均能正常使用（包括收银电脑、自助设备以及卡头硬件等）

## 2.检查油菜花后台中的项目监控情况，观察是否有大量延迟。

路径：油菜花系统后台→终端→项目监控＆升级→手动刷新

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d996c76f34f7f&type=max)

检查标准：

①最后活动不超过20秒（超过则代表已离线）

②延迟显示红色机台不超过所有机台的10%（由于无线网络会存在波动，少量出现瞬间高延迟属于正常情况）

# 其他注意事项

1.使用云服务器的用户，强烈建议自备一个5G路由或4G路由器作为外网来源，当外网被切断情况下（如网络故障、欠费停机等情况）时，可以快速将电信网络切换成5G网络进行使用，减少因断网导致系统无法使用的风险。本地服务器的用户，也可以根据自己情况判断是否需要自备5G路由器或4G路由器，作为运营保障（尤其是特别依赖小程序和美团抖音团购核销的客户）

推荐购买型号：

5G路由器（中兴（ZTE）G5 C 5g移动路由器）---推荐使用，网速更快

4G路由器（华为移动路由Pro）

推荐购买链接

2.务必不要使用过多小交换机进行中转转接，导致网络网路复杂，容易产生回路。

3.监控网络、游戏机网络以及客用WIFI网络务必不要接入到油菜花相关网络中去，避免影响系统网络正常运行。

4.如需接入其他路由器时，需要将路由器WAN口进行固定，避免因为突发断电导致网络混乱产生网络异常。
