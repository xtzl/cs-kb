# 一、作业说明

本说明为3P存票站安装方法与调试说明。

# 二、产品外观

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019072209f1c183c&type=med)

# 三、作业准备

1.提前在3P存票站安装位置预留网线和电源线；

3.检查柜台碎票机配件是否齐全，包括进票口五金件(柜台碎票机V8)、钥匙、备用刀组、清票刚尺、电源线。

2.准备读卡器*1，空白会员卡*1

3.准备网线一根。

4.准备一些彩票用于测试。

5.提前准备本地服务器的ip地址，一般为192.168.*.*

# 四、注意事项

1.安装前一定要和客户确认3P存票站机放置位置。一般为靠墙位置。

2.由于部分金属件较为锋利，建议带上手套放置刮伤

3.安装配件，挪动时，必须确保碎票机在断电状态

4.安装后，需要检查保险开关是否处于正常状态，在存票状态电机转动情况下，打开面板，电机必须是停止转动的状态。如果保险功能失灵，请务必不能使用，并及时返修。

# 五、作业标准

1.网络连接正常，断电开机不出现掉线情况。

2.所有配件已经安装到位。

3.连续碎票10次不出现卡票情况。

4.连续碎票20张票，计数准确无误。

# 六、作业步骤

## 固定安装

3P存票站位置确认后，需要把滚轮上的地脚扭下来，使存票站稳固放置在地面

## 系统后台配置

### 后台创建碎票机项目类型

登录娱乐管家后台，选择【终端】-【项目分类】-【新增】

在【新增分类】界面，项目类型名称为【碎票机】，项目功能为【碎票机】，如图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019072209f2a183d&type=med)

### 后台新增碎票机的游乐项目

1. 登录娱乐管家后台，新建一个碎票机项目：

路径：【终端】-【游乐项目】-【新增】

游乐项目名称，可命名为【柜台碎票机】或者【柜台碎票机-1】

项目类型选择刚刚设置的【碎票机】

点击【保存】

完成新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019072209f37183e&type=med)

2.找到刚创建成功的碎票机项目，点击右边的【端口管理】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019072209f43183f&type=med)

3.先点击【添加端口】，再点【保存】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019072209f511840&type=med)

4.点击【刷卡】，跳转到配置卡信息填写界面；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a0661841&type=med)

## 写配置卡

### 路由器密码设置

若知道路由器密码，可直接进行设置，

若不知道，则可随意编辑设置；

展示如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a0701842&type=med)

### 填写配置卡信息

1.在生成设置卡界面，填写配置卡信息，分别录入以下信息：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a07b1843&type=med)

- 服务器通讯方式：勾选内网；

- 服务器地址：输入门店服务器的IP地址；

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

- IP地址：请填写本碎票机使用的IP地址，根据现场提供的网线的IP地址来填写；

- 网关：填写本碎票机使用的IP地址所对应的网关，根据现场提供的网线的IP地址来填写；

若不知道如何查找网络ip地址或网关，可用笔记本电脑接入碎票机预留网线，参考下述文档进行查找判断：

怎么查看自己电脑网关和ip地址？_百度知道 (baidu.com)

比如，笔记本电脑获取到的一个ip地址为：

ip地址：192.168.110.20

子网：255.255.255.0

网关：192.168.110.1

则可以给碎票机分配为

IP地址：192.168.110.* （*号代表2~254之间的任意数字）

子网：255.255.255.0

网关：192.168.110.1

此时，在通过电脑运行cmd命令行，并尝试用ping 准备给碎票机分配的地址，看看有没有连接，如果没有任何设备连接，则代表此IP可以用；例如你想分配给碎票机192.168.110.241，则用ping来测试，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a0851844&type=med)

注意：如果发现地址已经被占用，则需要再次跟换地址，直到不被占用为止，建议使用ip地址段200-250之间的地址会比较好。

2.开启后台读卡助手

路径：后台管理网页-右上角下载-选择后台助手安装包-安装

安装教程：《娱乐管家读卡助手安装教程》

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a15e1845&type=med)

安装完毕后，右下角会显示油菜花助手的运行图标

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a1691846&type=med)

3. 上述信息填写录入完成后，将读卡器接入电脑，将准备好的空白会员卡放在读卡器上，点击【保存并写入卡中】，配置卡配置完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a1741847&type=med)

# 七、设备测试

## 读卡碎票测试

1.将会员卡防止【刷卡】位置，检查屏幕是否正确读取出会员卡卡内彩票数；

2.将20~40张彩票放置到碎票口进行碎票，检查碎票数量和存入数量是否一致。

## 反扫测试

将会员二维码放置在反扫口进行读取，测试是否能正常读取会员，并且尝试碎票20张，保存后在小程序中是否能看到存票记录。

# 八、配件使用说明

## 1. 钢尺

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a359184c&type=med)

#### 使用方法：

当碎票机卡票时，可打开碎票机的档板，用钢尺直接捅入进票口，连续多次捅入，一般可以快速解决

## 2. 光眼、胶圈

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a364184d&type=med)

#### 使用说明：

- 胶圈用于替换压票滚轮位置的胶圈。

- 光眼用于替换感应光眼用。

以上设备都是易损件，当使用时间较长的情况下，可能出现损耗，损耗后可自行更换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a36e184e&type=med)

## 3. 备用刀组

#### 使用说明：

碎票机内部有备用刀组，当原刀组已经磨损消耗较为厉害，并且出现票已经切不断卡顿的情况，此时需要更换备用刀组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a379184f&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001907220a3841850&type=med)

# 九、常见问题

1.3P存票站上出现E25是什么原因？

答：连接不上服务器，检查配置卡IP及服务器IP是否正常。

2.扫码登录直接退出

答：保存按键短路

3.经常显示断线

答：

a.更换ip再刷配置卡

b.更换网线

c.主板出现问题

4.碎票会减票

答：清理光眼或者更换光眼

5.存票的时候没有成功

答：重启碎票机是否显示A802报错，机台碎票机端口冲突

6.屏幕显示FULL

答：碎票已满，需要更换底部的碎票垃圾桶
