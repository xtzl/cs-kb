一、 作业说明

投币器可以根据样币来识别真假币，请按照安装说明准确调试。

二、 作业准备

样币 投币器

三、 注意事项

无

四、 作业标准

1.能正常投币并识别假币。

五、 作业步骤

1. 打开兑币机后门，取出投币器，把样币放到指定位置。并调节样币尺寸。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017acc61a6d9421e&type=max)

2. 安装回原位，进行投币测试。如果识别不准确可以调节投币器来控制。

六、 常见问题

1. 投币不识别？

1.1 更换样币或调节币大小到合适位置。

2. 识别不精确？

2.1 调节精准度。
