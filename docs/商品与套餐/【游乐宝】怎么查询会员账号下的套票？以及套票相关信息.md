# 怎么查询会员的可用套票

路径：会员--会员资料--套票

步骤：输入会员账号点击查询，选择套票，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179d25285b03c45&type=max)

# 如何查询套票可玩项目？以及套票有效期，剩余次数

步骤：选择对应套票，点击套票名称即可看到套票的可玩项目，以及购买时间和有效期以及剩余次数
