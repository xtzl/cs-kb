# 礼品回收

一． 礼品回收

1. 礼品回收：电玩城场地按照一定的彩票或者积分价格回收客户抓到的娃娃

2. 路径：商品--商品管理--新增--零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0475a60e71&type=max)

进入新增商品界面填写商品的名称，分类，售卖价格等信息，商品回收一般是不支持售卖只支持回收的，所以售卖设置的是否上架选择否

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0488b20e73&type=max)

在兑换设置里面设置该商品回收所需的回收数量，点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef049f2e0e74&type=max)

3. 呈现演示

收银台--商品--兑换商品--商品回收--选择回收方式--输入会员卡号或者电话号码--查找需要回收的商品--点击回收，完成商品的回收

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef04b45c0e75&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef04db330e77&type=max)

4. 常见问题

问题1

场景：新增的回收商品在收银台查找不到

解决：刷新一下收银台，商品的新增需要手动刷新或者重新登录收银台，商品信息才会更新

问题2

场景：回收商品时回收错商品了

解决：在收银台--订单--回收查询里面找到对应的回收订单可以取消回收
