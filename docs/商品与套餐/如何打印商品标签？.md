# 应用场景
当门店需要将商品的标签打印出来时，可以如何操作？

# 操作流程
路径：商品→零售商品

#### 进入【零售商品】界面，选择【批量操作】，并选择【打印标签】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718430668307-aaaeaafc-1417-4d3c-89fd-c56914c5ca6e.png)

#### 选择打印的模式以及勾选需要显示的内容，点击【打印】开始打印
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718430719320-0800deb9-337c-421a-a198-22d5de88efc8.png)
