# 一. 文档说明

本文档主要明确技术支持帮助部分着急开业，学习能力较差的客户设置系统套餐时的要求和注意事项，需按照以下内容要求执行。

# 二. 适用范围

目前仅适用于电玩城场地，游戏币套餐需求较简单客户。客户学习能力较差或着急开业的等特殊情况下可按照该流程处理

以下场地坚决不处理：电玩城退币场地，儿童乐园场地，景区

# 三. 流程详解

## 4.1 协助套餐设置协议签署

技术支持帮助客户设置套餐前必须让客户签署协助设置套餐协议，才能帮客户设置套餐

协助套餐设置协议链接：https://ding.cjfx.cn/f/mv3hxbvv

## 4.2 客户套餐需求整理

（1）助理端或销售端需提前要求客户整理好门店套餐需求，提供给技术支持。

（2）以下门店套餐需求为例或以表格文档的形式提供给技术支持（套餐需求需描述详细）：

## 4.3 套餐设置要求

需在客户系统创建一下技术支持的账号，使用创建的账号帮客户设置套餐和后台设置，让系统进行操作记录

（1）需按照客户需求设置后台商品分类，收银台分组，微信小程序分组

（2）线下售卖套餐需和客户核对套餐需求，价格和套餐内容需和客户需求一致

（3）抖音美团套餐绑定需根据抖音美团上架套餐，价格和绑定套餐内容需一致

（4）扫码游戏方案需扫码游戏上币数与机台上币数一致

## 4.4 套餐检查

（1）检查所有套餐对应的储值是否一致,包括但不限于游戏币套餐、预存款套餐、游乐套票套餐、零售商品售卖与兑换等；

（2）检查所有线上售卖的套餐是否与预想的为一致，包括价格以及套餐内容；

（3）检查是否存在0元或者低价风险套餐在售卖，包括线下收银台、自助设备以及小程序内；

（4）

（5）检查机台投实物币、刷卡扣费、扫码游戏上币数是否与机台上币数一致，退储值功能是否准确无误，礼品计数数量是否正确无误，特别注意扫码游戏方案时是否与刷卡方案效果一致；

（6）检查员工账号权限是否与预想一致，尤其针对涉及补币、退款、订单查询等敏感功能权限是否符合您的预期。

## 4.6 简单系统培训

主要培训收银台操作和系统后台财务对账（根据客户实际情况培训收银流程），培训需录屏保留

## 4.7 特殊客户留档记录保存

技术支持帮客户设置完套餐之后，需填写协助客户设置套餐留档记录表，留档记录：
