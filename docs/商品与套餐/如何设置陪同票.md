# 应用场景
如果想在门票中设置陪同票，可按照下述流程进行设置

# 操作流程
路径：后台→商品→游乐套票

选择需要开启陪同票的套票，点击编辑，在【高级设置】中找到【陪同票】，选择【含陪同票】

设置腕带数量，则陪同票可用于绑定腕带使用，设置打印可用次数，则代表可打印多少条陪同票腕带。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723624339598-5f0987db-97ad-41fd-8ab1-3cbe2b6fea03.png)

在底部可设置陪同票对应的语音播报和打印样式
