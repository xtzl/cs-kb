**新娱迭代版本10.4.4076  ****<font style="color:#8A8F8D;">2026年9月1日</font>**

1. 新增 闸机支持掌纹出入闸，如果录入了掌纹，那么手环二维码就不能入园，只能用来扫码启动设备
2. 新增 闸机员工码：游乐掌柜员工码可用于出入闸，有出入闸记录，每日都需要收银台激活，激活后码当天有效，可截屏保存设置手机壁纸，快速开闸门
3. 新增 可设置自动做实
4. 新增 扣次领腕带：支持扣1次领多人票，非封顶计时票也支持扣次领腕带
5. 新增 套票绑定腕带：可设置只有含闸机项目的套票才可以打印/绑定腕带
6. 新增 外部合作券：以兑换码形式合作，在油菜花生成一批兑换码/券（系统设好兑换的商品），给外部合作方，外部合作方通过积分兑换或者赠送或者其他形式最终给到用户，用户拿兑换码在油菜花小程序可以兑换成对应的门票或者其他商品，外部合作是有收入的，使用兑换码兑换后要生成销售订单，支付方式就是这个券对应的第三方
7. 新增 收银台-年卡会员扣次领腕带时，支持照片验证是否专人，并可生成比对照片供管理员核实
8. 新增 套票部分退款可设置违约金比例，按套票剩余次数违约金比例退款，支持财务审核后退款
9. 新增 运动馆-麻将房，卡头扫码开门及灯光通电，控制单次时长到点灯光关闭
10. 新增 抖音平台发生整单退款时，同步推送油菜花系统退订单，功能需手动开启
11. 新增 次票购票自动延期：次票（之前购买未使用完的次票自动延期）期限票（当前购买的票生效日期=之前购买的套票截止日期+1天）
12. 新增 运动馆小程序游玩地图可以查询项目介绍，可以呈现项目预计等待时长
13. 新增 小程序扫码激活，支持无需激活的单次票，首次扫码可以过户到小程序会员
14. 新增 售票机支持1次多人
15. 新增 闸机支持多次一验（横屏版）竖屏版之前已支持
16. 新增 增加其他收入/支出，必填备注开关
17. 新增 入库单，库存变更，库存查询 显示税率，税费
