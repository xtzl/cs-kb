# 1． 礼品兑换：电玩城场地客户用彩票或者娃娃兑换礼品

# 2． 路径：商品--商品管理--新增--零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef018b4f0e46&type=max)

进入新增商品界面填写商品的名称，分类，售卖价格等信息，兑换商品一般是不支持售卖只支持兑换的，所以售卖设置的是否上架选择否

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef01a0010e48&type=max)

在兑换设置里面设置该商品兑换所需的兑换数量，点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef01b7850e49&type=max)

# 3． 呈现演示

收银台--商品--兑换商品--选择对应的储值兑换--输入会员卡号或者电话号码--查找需要兑换的商品--点击兑换，完成商品的兑换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef01ccdd0e4a&type=max)

# 4． 常见问题

问题1

场景：在收银台兑换商品里面找到对应的商品点击兑换，显示库存不足

解决：在后台-商品-仓储管理-入库单-给该商品添加库存

问题2

场景：后台刚设置好了兑换商品，收银台查找不到新增的兑换商品

解决：刷新一下收银台，商品的新增需要手动刷新或者重新登录收银台，商品信息才会更新

问题3

场景：兑换商品的时候给客户兑换错了

解决：在收银台--订单—兑换查询里面找到对应的兑换订单可以取消兑换
