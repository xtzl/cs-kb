# 设置步骤

娱乐管家后台 > 限定币 > 新增限定币套餐

### 1.新增限定币套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975506bd0c74b8&type=max)

### 2.设置可用机台

可用机台有三种：指定机种、机台分类、指定机台

注意：门店创建的限定币套餐不支持漫游，总部的限定币套餐支持漫游

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197550b686b74be&type=max)

# 限定币的规则

机台消费：刷卡/会员码/扫码游戏，默认优先使用限定币，有效期短的优先扣费

项目类型：模拟机、礼品机、彩票机、娱乐机、闸机、卡丁车、射箭

漫游：总部套餐支持，门店套餐不支持
提限定币：不支持
存限定币：不支持
出限定币：不支持
升级套餐：不支持
退套餐：未使用可退，部分使用可强制退(只扣回剩余币数)漫游出再漫回暂不可退
修改可用机台：已售卖的币也按照修改后的使用

限定币被充值赠送，任务等触发赠送：不支持，只能通过套餐充值

限定币套餐可加入组合商品：可组合

限定币兑换其他商品：不支持

限定币被彩票等储值兑换：支持

加入币单价计算
机台经营报表计算投币数量
售币记录可查售卖订单
订单商品类型：游戏币
上架终端：收银台，兑币机(放在会员充值)，POS机(放在买游戏币里)，小程序
