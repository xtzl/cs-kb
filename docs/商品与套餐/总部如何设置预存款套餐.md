# 应用场景
总部支持批量设置预存款套餐，并将预存款套餐直接下发上架到指定门店，以下教程为如何设置预存款套餐的操作流程。

# 操作流程
路径：登录总部后台→商品→预存款套餐

点击【+新增预存款套餐】，进入新增界面

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531655682-7139fa6e-159e-4da2-93fa-41b9bcead6c4.png)

在【新增预存款】界面中，按照下图设置对应的预存款套餐的内容，点击【保存】完成设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531756985-2550bdc3-04ec-4146-a0cb-fd164b6a672a.png)

# 常见问题
1.预存款套餐没有显示赠金一项

答：

路径：登录总部后台→总部→系统设置→预存款模式

在预存款模式中，可以切换成本金+赠金模式进行，并且可设置先消耗本金还是先消耗赠金或者按比例消耗三种模式。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721620516403-850df518-f40c-4715-b862-f6891377333e.png)

2.预存款本金模式下，想要修改预存款数量和售价不一致的

答：

路径：登录总部后台→总部→系统设置→预存款模式

在预存款模式一中，选择预存款套餐售价为“可修改”。但模式二中，不支持可修改操作，固定为本金金额=套餐售价。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721620516403-850df518-f40c-4715-b862-f6891377333e.png?x-oss-process=image%2Fformat%2Cwebp%2Fresize%2Cw_750%2Climit_0)
