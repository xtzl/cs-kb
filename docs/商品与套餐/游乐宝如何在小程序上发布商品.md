# 4. 常见问题

问题1

场景：微信小程序上的商品和收银台售卖的价格不一样

解决：在发布商品的时候输入的售卖价格和后台的不一样

问题2

场景：在盈客宝管理里面发布了商品，但是在微信小程序里面找不到商品

解决：发布商品的时候售卖设置里面是否上架选择了否
