# 路径

售卖设置——游乐套餐——游乐套票——新增——期限票（年卡有效期设置为1年，月卡有效期设置为1月）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0d2d02e4209&type=max)

# 总部设置

基础信息：

有效期：设置售卖后0天生效即立即生效，1天则购买日第二天生效。有效期设置1年，则购买日起1年后失效。设置套票首次使用后1年失效，从使用到套票开始计算1年后失效（如果设置有效期1年，套票首次使用后6月失效，顾客购买后立即进行使用，则以套票首次使用后失效时间为准，即6月后会失效。如果顾客购买后经过了7个月才使用，则因为有效期只剩余5个月了，所以即使设置套票首次使用后6月失效，还是会5个月后会失效）

添加可玩项目（当修改可玩项目设置时，已售套票也会同步修改）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0d64bf44215&type=max)

高级设置：

跨店使用：勾选支持时，在任意门店购买本套票，都可以在全国所有门店使用，勾选不支持时，只能在购买本套票的门店使用

陪同票：设置陪同票张数和最多可用次数，陪同票不会进行生物识别

专人专用：设置为是时，闸机验票过闸时需要使用指纹或人脸识别判断是否购票的会员，选择使用人数，选择多少人就可以在小程序购买套票可录入多少数量的头像

使用日期限制：可以限制游玩日和时间段以及不可用的日期

使用频率限制：可以限制每个或所有添加的项目某个时间最多使用几次

注意：专人专用需要选择使用人数后专人专用才会生效

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0da798b421d&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0db1f88421f&type=max)

售卖设置：

添加上架该套票的门店，设置门店是否自主定价，填写售卖价格以及上下架时间

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0dd2ceb4226&type=max)

兑换设置：

添加可以兑换该套票的门店，是否允许门店自主定价兑换价格，设置各储值的兑换数量

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0dddd6f4228&type=max)

# 门店设置

基础信息和高级设置与总部一样

设置套餐的售卖价格后就可以设置在收银台的展示分组，以及可售卖终端，可限制对应的售卖终端
注意：门店设置套票的兑换价格，售卖设置—定价和兑换—商品兑换设置—新增兑换商品
