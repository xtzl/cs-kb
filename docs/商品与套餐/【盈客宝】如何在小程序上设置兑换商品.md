# 1、小程序如何开启兑换

路径：线上--盈客宝管理--功能开关--首页，副功能区，添加兑换中心的入口。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e81682328&type=med)

线上--盈客宝管理--商品资料管理，点击商品标题，兑换设置，能否线上兑换选择“是”，设置兑换需要的储值数量。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e81732329&type=med)

# 2、小程序如何调整兑换商品的分组

点击“兑换分组设置”，选择兑换商品，点击“调整分组”，选择分组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e828c232a&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e8490232b&type=med)

# 3、如何调整商品在兑换分组里的显示顺序

找到需要调整显示顺序的商品，点击编辑的图标，输入数字（数字越小显示顺序越靠前）。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e849e232c&type=med)

勾选商品，可以选择“置于分组最前”或“置于分组最后”，快速调整商品显示顺序。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e857e232d&type=med)

# 4、如何设置兑换分组

1）添加兑换分组。

点击“添加”，可添加分组，设置分组名称、显示顺序。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e8686232e&type=med)

2）删除兑换分组

选中需要删除的分组，点击删除，确认即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e885f232f&type=med)

3）编辑分组

选中对应的分组，点击编辑的图标，可以修改分组名称、显示顺序。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e88692330&type=med)

# 5、如何设置兑换中心排行榜
点击“排行榜设置”，开启排行榜， 如果开启了多个排行榜，在小程序的兑换中心会默认显示一个排行榜。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e88732331&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e4e894c2332&type=med)
