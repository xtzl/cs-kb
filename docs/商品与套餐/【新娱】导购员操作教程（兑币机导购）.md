1.创建导购员
路径：商品--导购员列表--批量操作—新增/导入系统用户（将员工账号直接生成导购员）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019154ae68ff18e6&type=max)

2.将系统商品设置为导购商品

路径：商品—导购商品—新增—选择系统商品—设置提成比例（可设置为0%-100%）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019154af3c7618ea&type=max)

3.导购员业绩查看

路径：商品—导购商品—导购—导购销售明细/导购员销售汇总/导购员业绩汇总

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019154af6ee318eb&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019154af86c118ed&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019154af9bbb18ee&type=max)

4.兑币机登录导购员

路径：右上角设置—切换导购—输入导购员编号—确认
