# 应用场景
总部支持同一设置组合商品，如需要设置多门店适用的组合商品时，可通过此操作流程进行设置。值得注意的是，总部的组合商品内的子商品，需要同样是在总部所设置的其他类型的套餐才能设置。不可以将某一门店设置的套餐在总部组合商品内进行组合。

# 操作流程
路径：登录总部后台→商品→组合商品

点击【+新增组合商品】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721529985908-ea2d9978-ebee-4c16-b673-f9347ca334b2.png)

在【新增组合商品】界面中，按下述说明填写设置套餐内容，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531141541-34c1e4fc-2966-4654-a814-51c2538c1cf8.png)

特别说明：组合类型含义如下：

【固定组合】:子商品内容固定，设置商品内容和数量都是不可选；

【A】：子商品设置顾客可以在多个子商品中选择1个或者多个，具体选多少个可预设；

【A+B】【A+B+C】【A+B+C+D】【A+B+C+D+E】：子商品可划分多个选择区域，不同的选择区域可以选择指定的数量，此方案可给予顾客更丰富的选择，并支持餐厅商品。
