# 操作路径

后台--商品--商品管理--新增--零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9dc739f62c09&type=max)

# 操作步骤

- 点击商品

- 点击商品管理

- 选择商品资料中的零售商品

- 新增\编辑零售商品

- 保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a9dcbf8512c0e&type=max)

# 注意事项

必填项：商品名称、售卖价格、上架时间、手续费 。 非必填项：商品分类、商品编号、商品条码（建议填写）等。

- 底部工具栏可删除、批量分类、设置套餐。

- 已经产生售卖记录的套餐不能尽心删除。

- 新增商品时，初始库存支持输入为0，为0时不产生入库单。

- 标签打印模板，增加一个不显示售价的选项。
