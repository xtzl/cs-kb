# 一、文档说明

本教程用于指导如何调试启用POS机以及POS功能说明。教程适用范围：商米POS机、商米盘点机。

# 三、配件说明

1.POS主机*1

2.POS数据线*1

3.POS充电头*1

4.POS机58mm小票打印纸*1（盘点机没有此配件）

5.盘点机手带*1

6.说明书*1

# 四、支持功能

售卖类：

1.支持会员卡开卡、手机号开会员等功能；

2.支持零售商品购买与兑换，支持直接扫商品条形码快速选择商品，支持使用POS机回收商品；

3.支持游戏币充值、预存款充值和游乐套票充值功能；

4.支持超时游玩后通过POS机进行付超时费用；

5.支持在POS上退订单；

6.支持线上团购单次票POS直接验票过闸，

7.支持餐厅功能，购买、接单、取餐。

扣费类：

1.支持套票扣次、期限票验证；

2.支持直接扣代币和金币；

3.支持按项目扣费，并支持选择扣储值还是扣套票；

4.支持直接扣彩票、积分等储值

会员类：

1.支持查询会员信息、会员储值、套票列表和游玩记录；

2.支持会员录入人脸；

3.支持会员补卡换卡。

仓库类：

1.支持礼品入库、盘点和调拨功能，并支持采购单直接审核入库；

2.支持机台库存功能，针对机台库存进行盘点；

其他类：

1.支持互动打卡项目副卡绑定；

2.支持卡丁车扣费核销并发车；

3.支持机台直接出彩票到会员卡中。

# 五、注意事项

1.首次使用前，需要对POS机激活，激活时需要有WIFI网络

2.首次使用前，请提前对POS机进行充电

3.POS自带流量相对较少，在安装和更新程序时，请务必使用WIFI网络进行下载，以免流量不足

# 六、安装标准

1.POS机正常进入激活状态

2.POS所有功能正常

3.POS流程激活成功

输入本地ip地址＋9999，具体格式如下：

# 八、整机测试

1.流量功能正常使用，在不连接无线网络时，可正常使用POS机功能

2.购买一个测试商品，能正常收款并正常打印消费小票

3.通过扫码枪扫会员二维码，能正确读取会员信息

4.通过游乐套票售卖散客票，打印出来的票码能正常由闸机读取

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910cbcca4c5de8&type=med)

功能说明：此功能用于给散客售卖门票，或者给会员充值次票和期限票使用。

选择需要购买的游乐套票套餐→输入购买次数→点击存入会员卡→读取会员信息→确认订单内容（可扫优惠券二维码进行折扣）→点击支付→选择支付方式→完成充值以及打印消费小票
