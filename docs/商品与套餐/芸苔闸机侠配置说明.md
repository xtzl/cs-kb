# 一、作业说明

如何正确调试闸机侠，连接芸苔系统进行使用

# 二、作业准备

立式验票机 V8

# 三、注意事项

无

# 四、作业标准

闸机侠能正常连接芸苔系统进行使用。

# 五、作业步骤

#### 1. 新建零售商品，用于绑定闸机侠项目

设置路径：

进入芸苔后台 -- 点击零售商品 -- 点击新增商品 -- 输入商品信息（后面匹配项目要用到） -- 选择上架门店 -- 点击保存

注 : 新建商品时， 需开启游戏币兑换用于扫会员码扣币启动

流程如图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c018234e833fb798c&type=max)

#### 2. 新增游乐套票信息，用于绑定闸机侠项目

设置路径：

进入芸苔后台 -- 点击游乐套票 -- 点击新增商品 -- 填写套票信息（具体套餐设置可参考芸苔后台操作文档） -- 确认信息无误后，选择上架门店 -- 点击保存

流程如图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c018234e9718a7990&type=max)

#### 3. 设置注册，进行项目配置

设置路径：

进入芸苔后台 -- 点击设备管理 -- 点击设备注册 -- 将二维码对准设备扫码口进入配置页面 -- 输入芸苔账号 -- 选择门店 -- 选择商品（步骤 1 创建的商品） -- 选择核销的套票项目（步骤 2 创建的游乐套票） -- 点击确定。

注：这里设置完后台设备管理里不会显示绑定了这个闸机，这里把二维码给闸机侠扫只是启动了里面预装的芸苔闸机软件，所以也可以直接进入闸机侠的系统桌面里启动芸苔闸机 app 进行配置绑定。
