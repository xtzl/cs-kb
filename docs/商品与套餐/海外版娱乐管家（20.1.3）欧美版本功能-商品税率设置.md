# 欧美版本功能-商品税率

## 一、功能概述

每个国家对于税率的收取模式是不同的，国内默认商品售价都是含税的，但是像美国是商品售价不含税的，在收费时单独计算税费进行付款的，欧美国际版新娱目前就支持对应功能。

## 二、功能操作指南

### 1、版本要求

欧美版本：V20.1.3193

东南亚版本：无该功能

国内&港澳台版本：无该功能

### 2、操作流程

①需要先将商品税率功能打开

连锁版路径：后台-总部-系统设置-商品税率

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df730b34c0&type=med)

单店版路径：后台-设置-系统设置-商品税率

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df731034c1&type=med)

②设置业务分类，将不同业务所收取的税率填写好

总部版路径：总部-商品-业务分类

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df731534c2&type=med)

单店版路径：后台-商品-业务分类

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df731a34c3&type=med)

③设置商品对应的业务

商品会根据所选的业务分类设置的税率进行收取税率费用

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df732134c4&type=med)

④商品结算时，会附带商品税费，进行结算。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df732634c5&type=med)

## 三、常见问题答疑

### ①营业额包含税费吗？

答：包含有的

### ②如果我需要对该订单进行免税，该如何操作

1:)需要将订单免税功能打开

路径：设置-系统设置-收银台手动改价

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df732b34c6&type=med)

2:)商品添加至购物车，在结算前把免税选项选上

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84df733134c7&type=med)
