# 问题描述

为避免出现套餐上架价格过低的情况，作为门店管理者想要实现当上架套餐低于某个预设定的单价值时，该套餐需要经过审核方可上架，如何在系统实现？

# 解决方案

系统版本要求：10.4.2124及以上

### 具体操作【单店版】

1.根据如图指定路径，开启【商品套餐审核】开关，并设置触发审核的单价价值

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ff38ea71854&type=max)

2.在新增储值套餐，将会触发提醒

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ff8d1d61893&type=max)

3.找到需审核的上架套餐，点击【审核】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ff9886e1898&type=max)

4.在弹窗界面，点击【审核通过】，在弹窗输入【审核备注】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ff9fc4a189e&type=max)

5.确认【上架】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ffa4ee118a1&type=max)

# 注意事项

1.该审核操作有对应的开关权限，且相关记录可在【套餐-修改记录】查询。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0ffd61cf18b4&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e1000894418c6&type=max)

2.充值赠送的游戏币不包含币单价计算

3.如果是门店商品，线下/小程序商品任意一个低于设定的币单价，整个商品都会下架变待审核状态
