# 应用场景
连锁商城支持总部导入商品，因门店币单价不同允许门店自定义售价和兑换价，以下教程为总部人员统一设置游戏币套餐的操作流程。

# 操作流程
1、导入商品：登录总部后台→商品→导入→新建商品→选择文件→导入配置→适用门店（全选）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1768183950525-80fc7c58-cc4c-46b8-9a67-4edb0cdc585d.png)

2、已导入商品开启门店售卖定价设置：登录总部后台→商品→新店商品批量配置→勾选门店定价为否的商品→选择从门店移除→添加可售卖商品→勾选商品→独立上架

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1768208954758-9d5ecf6e-db1f-4b22-a114-4affbcb24aaf.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1768184302484-c722f99a-148c-437c-9f75-a5cb7d0baaac.png)

3、已导入商品开启兑换门店定价设置：登录总部后台→商品→勾选商品→批量操作→批量修改兑换门店设置→勾选门店→开启门店定价

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1768184393148-389d60c9-8928-458b-bd41-6573c9c44a20.png)

# 常见问题
###### 问题一：
Q：总部有ABC三个门店，总部统一管理的情况下，只更新AB门店商品的兑换价，C门店兑换价维持原样，要怎么操作呢？

A：使用商品资料导入，修改商品时，适用门店选择AB，未选择的门店要选择保留门店商品设置即可；

:::danger
<font style="color:#DF2A3F;">请注意：导入数据一次不要超过3W条数据，且要在非营业时间操作，否则会影响门店营业</font>

:::

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1769657438893-572b6483-a0d9-4971-8809-1edb1ade5923.png)

###### 问题二：
Q：新增商品时，怎么单独给某些门店设置门店定价呢？

A：总部新增商品需导入两次商品数据，以实现允许部分门店定价和部门门店不定价

1）先【新增商品】导入【适用门店】选择所有门店导入

2）再使用**<font style="color:#DF2A3F;">【修改商品】</font>**导入【使用门店】勾选需要开启门店定价的门店导入，同时勾选保留门店商品设置选项

###### 问题三：
Q：怎么单独给某些门店独立上架零售商品呢？

A：总部使用商品资料导入，选择**<font style="color:#DF2A3F;">【修改商品】！</font>**，适用门店只选择上架门店，填写上架时间，勾选门店定价，未选择的门店要选择<font style="color:#DF2A3F;">【</font>**<font style="color:#DF2A3F;">保留门店商品</font>**<font style="color:#DF2A3F;">】！</font>

<font style="color:#DF2A3F;">（必须同时勾选允许售卖的上架、门店定价才能实现独立上架）</font>![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1784542215837-ea06ed49-32d4-4e9f-a211-6053a1505373.png)

<font style="color:#DF2A3F;">如实际不允许门店定价，需操作：已导入商品开启门店售卖定价设置：登录总部后台→商品→新店商品批量配置→勾选门店定价为是的商品→选择从门店移除→添加可售卖商品→勾选商品→独立上架</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1784541958729-ffba44bb-c8a0-4f33-814c-796ac4bd2092.png)
