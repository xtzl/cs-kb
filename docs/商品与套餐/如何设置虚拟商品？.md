# 应用场景
如果门店部分商品无法统计库存，那可以通过以下设置来将此商品设置为虚拟商品，且不再统计库存。

# 操作流程
路径：商品→零售商品

#### 在【零售商品】的界面中，选择需要修改的商品，点击该名称进入编辑界面，其中找到【商品属性】一栏，将该商品的商品属性改为【虚拟商品】，点击【确定】完成设置。
