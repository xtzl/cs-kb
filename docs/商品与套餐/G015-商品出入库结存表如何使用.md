# 操作路径

后台--商品--仓储查询--商品出入库结存表

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa41973f42e74&type=max)

# 操作步骤

- 点击商品

- 点击仓储查询

- 点击商品出入库结存表

- 输入相应的信息

- 点击查询

- 结存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa41b07942e76&type=max)

# 注意事项

- 确认数据库无误在结存，否则我无法更改

- 结算周期一个月

- 必须结存上一个月的库存才能查看下一个月的情况
