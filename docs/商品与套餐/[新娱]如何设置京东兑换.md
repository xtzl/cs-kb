# 如何设置京东兑换

第一步：后台--小程序--线上兑换--兑换设置--启用线上兑换--勾选对应储值--设置兑换比例

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019503baea7378a9&type=max)

第二步：后台--小程序--线上兑换--充值对账--充值（如果需要开发票请联系油菜花销售进行充值，后台充值只能开收据）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019503ca46ae78d6&type=max)

第三步：后台--小程序--小程序装修--副功能区--兑换商城

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019503cdfd3278de&type=max)

## 常见问题

1> 兑换后商品质量问题如何退货？

答：让顾客进入兑换商城后，点击订单--找到对应的订单后点击售后--拨打京东售后电话，然后转人工，联系到人工客服后，将京东订单号提供给人工客服

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019503d33d8f78e9&type=max)

2>如何查询菜籽兑换充值明细？

答：后台充值对账--查询
