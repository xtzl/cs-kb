# 应用场景
总部可统一设置兑换折扣优惠券，在兑换商品的时候给拥有优惠券的会员打折，可带动冷门商品的兑换，或作为会员福利奖励  


# 前提条件
小程序，pos机需升级

# 操作流程
路径：登录总部后台→促销→优惠券

点【新增兑换折扣券】

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1751626121265-24daacaa-3a9d-4963-905f-9728b349f013.png)

在新增的优惠券方案中，按照下图描述进行配置，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1751626086859-2619c537-5add-44de-a5e0-294e21e8b10a.png)

1、按折扣打折，例如9折，输入90%  
2、使用场景：  
	可勾选线下兑换（包括收银台，pos机）  
<font style="color:rgb(19, 19, 20);">	 线上兑换 (小程序兑换中心，不适用京东商城和周边商盟)  
</font><font style="color:rgb(19, 19, 20);">3、使用规则：  
</font><font style="color:rgb(19, 19, 20);">	一个商品使用一张（单个打折），  
</font><font style="color:rgb(19, 19, 20);">	一笔订单使用一张（整单打折）且每笔订单只能使用一张  
</font><font style="color:rgb(19, 19, 20);">4、可选择券使用的商品，当一个商品使用一张，如果购物车里多个商品参与折扣券，取兑换价最大的商品打折。</font>
