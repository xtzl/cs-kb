# 应用场景

将第三方渠道口碑对接到游乐宝系统，便于核销，统一管理门店数据。

# 操作步骤

1、门店需要先申请好口碑账号（ 账号申请需咨询口碑客服）。

2、进入到游乐宝后台，点击线上--线上渠道--口碑--配置--授权。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d860713b2202&type=max)

2、点击授权会跳转到一个支付宝登录界面，登录进去，然后勾选协议，点击确认授权。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d86f9cf52204&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d871080e2205&type=max)

3、授权后会登录到口碑插件中，在插件中找到门店信息管理，里面有对应的门店编码以及绑定编码，将门店编码以及绑定编码复制到后台配置页面对应的填写处，填写好之后点击保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d873f10d2206&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d874cdc12209&type=max)

4、后台对接好渠道后，点击口碑商品即可进入到口碑插件上新增代币、门票、年/月卡等套餐。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d94cf5342242&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d94c0a192241&type=max)

5、口碑上新增好套餐后，在油菜花后台线上--线上商品--口碑--绑定商品中绑定对应的商品，然后再点击同步口碑商品信息即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d9518a3d2243&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d953ae272246&type=max)

# 注意事项

注：1、 只有通过游乐宝后台口碑商品界面进到口碑插件中新增的商品，在口碑上上架，才可以在收银系统进行核销，直接在口碑后台新增的套餐无法在油菜花系统进行核销。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d9594c24224f&type=max)

2、要是在口碑插件上的门店信息管理里面没有相关的门店信息的话，就需要在口碑平台新增门店信息后在口碑插件上刷新同步下即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10178d96ddf892298&type=max)
