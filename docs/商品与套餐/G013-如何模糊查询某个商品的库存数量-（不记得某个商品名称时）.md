# 操作路径

后台--商品--仓储查询--库存查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3dfd3152e39&type=max)

# 操作步骤

- 点击后台商品

- 点击仓储查询

- 点击库存查询

- 输入已知对应的商品信息

- 点击查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa3e561722e42&type=max)

# 注意事项
根据自己已知的信息进行填写查询。
