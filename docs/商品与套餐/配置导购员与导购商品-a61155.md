配置导购员与导购商品

��应用场景

①配置导购员

后台支持配置导购员信息，并且可关联在职员工；

②配置导购商品

后台支持配置导购商品与提成比例；

③自助设备配置导购员

兑币机支持配置导购员；

④查看导购订单

后台支持统一查看导购订单，并且展示对应导购员信息；

��如何设置？

①配置导购员

1) 进入【导购员列表】，点击新增导购员

2）填写对应导购员信息

3）可以选择导购员对应在系统的用户；（非必选；选择后员工在收银台自动对应导购信息）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f3bba2714&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f3bbf2715&type=med)

②配置导购商品

1) 进入【导购商品管理】，点击新增

2）选择对应需要导购分成商品，并且填写分成比例；点击保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f3bc52716&type=med)

③兑币机支持切换导购员

1) 进入兑币机管理页面，点击下方【切换员工】

2）输入导购员编号，点击保存即可

注意，兑币机重启后会清空导购员信息；请重启后及时输入导购员信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f3bca2717&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f3bd02718&type=med)

④查看导购订单

进入导购销售明细，即可查看对应时间段导购订单信息；
