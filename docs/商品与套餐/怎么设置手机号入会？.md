# 应用场景
适用于无实体卡会员的门店

# 操作流程
路径：商品**→**入会套餐**→**新增

**<font style="color:rgb(51, 51, 51);">1.点击新增，填写基本信息</font>**

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718683475586-c79d7f94-c908-4a51-94a4-47436a24067a.png)

<font style="color:rgb(51, 51, 51);">套餐编号：系统自动生成，无特别要求可不更改</font>

<font style="color:rgb(51, 51, 51);">套餐名称：同一类的入会套餐商品名称不可重复</font>

<font style="color:rgb(51, 51, 51);">商品分类：按套餐选择分类</font>

<font style="color:rgb(51, 51, 51);">入会级别：顾客购买入会套餐，成为的会员级别</font>

<font style="color:rgb(51, 51, 51);">初始有效期：会员卡的有效期</font>

<font style="color:#DF2A3F;">入会介质：选择手机号</font>

<font style="color:rgb(51, 51, 51);">工本费和卡押金：不需收取，可填写为0</font>

<font style="color:rgb(51, 51, 51);">套餐售价：不可手动更改，根据工本费+卡押金+子商品的定价决定</font>

**<font style="color:rgb(51, 51, 51);"></font>**

**2.套餐定价：****<font style="color:rgb(51, 51, 51);">选择需要是否上下架及上下架时间</font>**

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718683522086-86966d9d-f754-49a9-977a-6eedc72dacb9.png)

**3.商品展示：设置该入会套餐在收银台的展示分组、显示排序、背景颜色、字体颜色、售卖打印小票、可售卖终端。**

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718683572353-bb331c4a-1e0d-4672-8532-cc25e98f8f83.png)
