# 1.组合套餐：多个商品绑定一起售卖

# 2.路径：商品--商品管理--新增--组合商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0ffd290ed0&type=max)

进入新增组合商品界面填写商品名称，分类，售卖价格，添加子商品（入会套餐不可添加），点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1027670ed1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef104bf70ed2&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1063630ed4&type=max)

保存之后，即可在商品管理界面查看到新增的组合商

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1077060ed5&type=max)

# 3.呈现演示：

收银台--商品--售卖商品--选择需要购买的套餐--点击结账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef1096120ed6&type=max)

# 4.常见问题：

问题1

场景：添加子商品界面找不到入会套餐

解决：组合商品不可以添加入会套餐

问题2

场景：顾客购买商品后只得到一个子商品

解决：顾客是单独购买的子商品，需要让顾客购买组合商品
