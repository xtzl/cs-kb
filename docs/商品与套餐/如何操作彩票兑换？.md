# 应用场景
<font style="color:rgb(51, 51, 51);">用于会员消耗彩票储值兑换指定商品。</font>

# 操作流程
路径：<font style="color:rgb(51, 51, 51);">登录娱乐管家收银台-商品-兑换商品-彩票兑换</font>

#### <font style="color:rgb(51, 51, 51);">登录娱乐管家收银台-商品-兑换商品-彩票兑换-查询到会员-可兑换商品-选择需要兑换的商品-兑换，如下图所示：</font>
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593515357-d3f448e5-ed8f-4aee-8d88-cfb2af342dc2.png)

#### <font style="color:rgb(51, 51, 51);">兑换的时候可以任意输入兑换折扣比例进行兑换，如图所示：</font>
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593576783-4fc47c1d-9bb8-476d-a1cd-adba01baabe1.png)

# 常见问题
1.<font style="color:rgb(51, 51, 51);">登录的收银终端需要绑定售卖仓库，兑换的实物商品需要在登录终端绑定的仓库中有库存（启用库存的情况下，如不启用库存，可以直接兑换，不需要有库存）</font>

<font style="color:rgb(51, 51, 51);">2.预存款类型商品不可兑换；组合商品的子商品中包含有预存款也不允许设置兑换商品</font>
