# 业务场景

暑假套餐第一次购买200元=200币，第二次购买200元=200币套餐额外赠送50币

# 实现步骤

第一步：新增200元=200币游戏套餐（如果已经有对应活动套餐可以跳过）

路径：后台--商品--商品管理--新增--游戏币套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f1993de33026c&type=max)

第二步：新增50币赠币券

路径：后台--营销--赠币券--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f28a3e0c72a6c&type=max)

第三步：给对应活动套餐设置充值赠送赠币券

路径：后台--营销---充值赠送--添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f28ab56032aae&type=max)

## 注意事项：

1》如果复购套餐加赠游戏币，只额外送一次，记得再充值赠送界面勾选每个会员只赠送1次
2》如果要限制，只有重复购买时才会赠送，例如第2，4，6次购买时才额外赠送，第3次和第5次购买不送时，请再充值赠送界面勾选使用优惠券或自动促销购买时不再赠送

3》赠币券的有效期规则如何选择？
如果赠币券是限制只能再6月9号到7月31号使用，则选择指定日期，如果是获得后，需要再7天内使用，不然则失效，这种情况则勾选第二种赠送后0天生效--有效期7天
