# 操作路径

后台--商品--商品管理--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad11fdf2d43e0&type=med)

# 操作步骤

- 点击商品

- 点击商品管理

- 选择新增或者点击商品进行编辑

- 点击计时票
