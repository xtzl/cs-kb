# 🤗支持系统
新娱乐管家10.3.7183

# 🤗应用场景
 支持所有娃娃机关联同一个仓库，每台娃娃机只需要关联商品，礼品掉落时自动扣减库存，适用于频繁回收礼品  

# 🤗如何设置
### ①开启所有P位共用一个仓库
进入【仓库 - 仓库基础设置 】

1）选择【商品排序优先】

2）选择所有机台P位共用的仓库<font style="color:#2F8EF4;">（共用仓库建议</font>**<font style="color:#2F8EF4;">不要使用主仓库</font>**<font style="color:#2F8EF4;">，商品数据过多加载较慢；建议另选一个礼品仓库用于存放礼品与设置为共用仓）</font>

:::danger
<font style="color:#DF2A3F;">注意：选择共用一个仓库模式并且保存后，所有机台都会绑定同个仓库；如果再切换回其他模式，需用户手动逐个更改机台对应的仓库，请谨慎操作</font>

:::

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1724151768223-39b81a14-f86c-4c07-b0b0-1d1eb63c7e27.png)



### ②为所有机台配置礼品
进入【仓库 - 机台绑定礼品】

1）选择你需要配置商品的机台，在【商品编号】中输入关键字，检索当前共享的仓库商品，选择想配置的商品即可；如果需要配置多个商品，请点击【多礼品】

2）一个P位有多个礼品的时候，可以通过上移/下移调整顺序

3）配置商品的顺序后，后续礼品机出库商品，均按照当前配置顺序进行扣减库存；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1724152330262-cc47347e-eb8b-4599-a2b3-d548311c8f1d.png)



# 🧐常见问题
问：库存不够的情况下，礼品会扣减吗？

答：库存不够的情况下，礼品会顺延往下个商品进行扣减；
