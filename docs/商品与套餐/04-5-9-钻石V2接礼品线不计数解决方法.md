# 一、 作业说明
安装完钻石v2之后发现礼品不计数，但不接卡头能正常出礼品，且使用的是钻石v2版卡头

# 二、 作业准备
小十字螺丝刀、电烙铁、焊丝、小镊子，330Ω电阻若干、热熔胶

# 三、 注意事项
断电操作，小心操作

# 四、 作业标准
安装完后出礼品统计正常

# 五、 作业步骤

1.拆开图中三个螺丝，将主板拆除出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018001fceb3701d2&type=max)

2.打开钻石v2卡头将下图第三个电阻去掉，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018001fc122c01cf&type=max)

3.在图中位置接入330Ω电阻，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018001faec9801c8&type=max)

4.在电阻上打入热熔胶，防止金属脚位接触到其他元器件

5.将卡头安装回原状，检查电阻是否有接触到其他元器件，并通电测试礼品计算是否正常。
