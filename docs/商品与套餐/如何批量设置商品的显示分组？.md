# 应用场景
显示分组用于在收银台售卖界面，按照设置来分页显示套餐，以方便收银员可以快速找到对应想要售卖的套餐，下述设置就是用于设置该分组。

# 操作流程
路径：商品→展示商品分组

#### 在【展示商品分组】界面中，勾选对应需要调整分组的商品，并点击【调整分组】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718439077331-eaf0258b-3148-4cb8-99a9-588191998950.png)

#### 选择你需要调整到哪个分组，点击【确定】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718439107234-ef877981-0570-43f2-8a92-458897d1ebb0.png)
