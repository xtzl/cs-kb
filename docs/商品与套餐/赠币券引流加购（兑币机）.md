# <font style="color:rgb(0, 0, 0);">场景说明</font>
电玩城经常做的活动是在商场用10个币引流，但是这种引流的转化率极低，有没有一直方式让顾客在领到这10币的时候，就自动推荐一个加购套餐？  
使用场景：打印一批10个币的赠币券，拿到商场去派发，顾客引流到店后，引导到兑币机核销，核销的过程中，自动弹出加购套餐，吸引顾客加购，极大的提高了转化率  
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786356993603-149cd377-814b-4ca6-a462-67691089e999.png)![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786356759483-12e0d2d7-b2f1-4b92-9490-af88db8ca98d.png)

## 一、赠币券的设置与打印二维码
### 配置说明
<font style="color:rgb(51, 51, 51);">第一步：新增赠币券，设置到店核销，选择加购套餐，（加购套餐售卖状态设置成“下架”，即不单独售卖，但是可通过加购流程完成下单）</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1786356323238-29c8ad64-2f1b-4006-b525-cc8c98299123.png)



第二步：打印赠币券核销二维码，一券一码，需要派发几张就导出几张二维码
