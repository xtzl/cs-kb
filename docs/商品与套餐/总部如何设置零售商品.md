# 应用场景
总部可以统一设置零售商品，在总部设置零售商品的好处很多，比如可以支持总部统一采购并设置入库单，支持商品跨店调拨、总部统一设置售卖兑换价格等功能，这些功能是门店自有商品时不支持的。当连锁门店需要使用此类功能时，则可以在总部统一设置零售商品。

# 操作流程
路径：登录总部后台→商品→零售商品

在【零售商品】界面，选择【+新增】添加单独一个商品

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531259016-5764048e-84db-4701-9418-4e5750d655fa.png)

在【新增商品】界面中，按照下面说明进行设置，点击新增完成单个零售商品。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531472379-69835c36-5ddc-491e-b28d-3e1ac8fba6e7.png)

如果需要批量导入商品，也可以点击【导入】通过导入方式进行批量导入，可参考下面步骤进行导入。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531594193-ab0d2fc6-c536-4926-8e13-9625eec78fc8.png)
