# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
在收银台的售卖界面中，如果套餐的分组比较凌乱，或者完全没有分组的情况下，会十分影响收银员的操作效率，因此我们可以通过修改设置收银台的售卖分组实现套餐合理分类分页，方便收银员操作。

# **<font style="color:rgb(38, 38, 38);">🔴</font>**操作流程
路径：商品→售卖商品

#### 如下图所示，找到【设置商品展示】，点进去
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591003755-95c67369-9fd4-4ebe-8cbb-9f1eda5bb908.png)

#### 在右边【+】号位置可以新增你需要的分组
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591032815-4a2baec1-2b2f-4a9c-b886-fe029afd3abe.png)

#### 选择你需要编辑的套餐，则会显示可以修改颜色和对应的分组，可以同时多选多个一次性修改，点击【保存】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591125497-4e55ff23-0f23-4061-bf59-dbc7b0e1a4cb.png)
