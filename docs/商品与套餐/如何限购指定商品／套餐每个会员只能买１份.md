# 🔴应用场景
1. 门店推出VIP专享套餐， 但每个会员只能买一份
2. 门店有多个抖音套餐，其中最优惠的引流套餐， 想限定每个会员只能核销一份

# 🔴操作流程
进入到对应游戏币，套票或商品的设置页面中， 找到以下选项就能设置限购了。 你可以同时设置哪些会员能参与限购。

# 🔴常见问题
❓️问：我按上面设置后， 顾客在小程序购买也会同样限购吗？

答：是的， 上面设置限购数量后， 顾客无论是在收银台，兑币机或小程序购买， 都会同时受到限购数量限制
