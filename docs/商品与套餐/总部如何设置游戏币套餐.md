# 应用场景
连锁商城支持总部统一设置游戏币套餐，以下教程为总部人员统一设置游戏币套餐的操作流程。

# 操作流程
路径：登录总部后台→商品→游戏币套餐

在【游戏币套餐】的界面中，选择【+新增游戏币套餐】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721532651372-eb158e45-a276-49d6-a084-a149572d0479.png)

按照下图说明，填写相关信息，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721532888386-896324cb-78c1-4424-9e72-aca87fab55cc.png)
