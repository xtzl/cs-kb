1. 先梳理你的人事架构，[设置不同岗位的权限](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/egwbx0t0tvd2r0wg)，例如店长，机修，收银员，财务等
2. 为登陆总部的人员[创建账号](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/wr5gem380ftgho5d)，你可以控制每个账号[分别能看到和管理哪些门店](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/ol2kufm1i6s5bqnl)
3. 总部统一创建[游乐项目分类](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/rnwb7p97utd63q0l), [商品分类](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/idmv0gkrwv465wex), [会员等级](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/gnl7no8uqqatut9f)，为便于管理和分析各门店的数据
4. 创建各门店要上架的商品，例如[入会套餐](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/ogtids2vm27yuugg)，[零售商品](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/lt2zqnwo7av5v0bz)， [游戏币套餐](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/xbry53orfkw25ov2)，[套票](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/vmvuf1bsobq5yi0w)，[预存款套餐](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/aocchkzbplbhlkbk)，[组合商品](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/tnu5pepqoznib89e)
5. 统一各个门店的[小程序装修](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/sn78z00sadbs95op)
6. 如果你需要实现会员充值后可跨店消费，请参考：[会员漫游功能](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/kgxe07pexhq1o22u)  [会员漫游设置](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/qq95mw65oa410g7y)
7. 总部可统一配置各门店的营销活动，例如：[秒杀](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/mwf6980gga94ivh5)，[满减](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/cex99272gc94e871)，[折扣](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/icboei5cbk8429pf)，[特价](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/rw9f55vpfa88arps)，[赠币券](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/ld2h8c1pdkgy7sll)，[优惠券](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/qgnc4ibfw1yubpkn)等
8. 你还可为每个门店[创建业绩指标](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/bg1xxuq8piii125b)，同时在[手机报表](https://ychylb.yuque.com/org-wiki-ychylb-hi0389/pmrnai/smgxmbo7mrxv5zc7)上查看各门店业绩数据
