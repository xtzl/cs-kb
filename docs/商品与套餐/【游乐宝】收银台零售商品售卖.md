# 应用场景

描述：售卖商户的零售商品，启用库存控制时，对应商品必须有库存（具体操作在仓库管理 —入库单中入库）且售卖终端的仓库有需要购买零售商品的库存；不启用库存控制，可以直接购买不扣库存（相当于虚拟商品）

前置条件：

1、登陆门店后台 —【商品】—【商品资料】—新增零售商品（具体商品设置查看后台操作文档）

2、设置 —【收银终端】中绑定售卖仓库

3、商品 —【仓储管理】入库单中含有指定商品库存（不启用库存控制则不需要）

4、如有需要可以设置商品优惠促销在购物车中会显示促销后的商品价格总价（具体设置促销操作查看后台操作文档）

# 操作方法

1、在【商品】 —【商品售卖】页面点击需要购买的零售商品或者在购物车下方的搜索栏中根据商品名称、商品编号、商品条形码筛选商品加入购物车，有促销时（具体促销设置查看后台操作文档），会显示优惠后金额

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018712330eca1ed4&type=max)

2、加入购物车的商品可以按快捷键 F11【挂单】，会暂时隐藏已添加的商品，再次按F11 会恢复挂单之前的商品

3、结账的时候，可以单支付，也可以混合支付（混合支付不支持部分退订单、抹零支付不生效）目前支持：现金、其他、预存款（预存款类型商品不支持）、抹零（只有单支付、现金类型生效；抹角或者抹分）、扫码支付（微信、支付宝付款码支付）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc2401871234937d1edb&type=max)

4、售卖成功后，相应的销售金额会记入登录账号、所登录账期的【应收】记录中；相应的商品库存会从绑定仓库中扣减（不启用库存不会减库存）

# 注意事项

1、后台商品设置成虚拟商品，则商品库存不会变动
