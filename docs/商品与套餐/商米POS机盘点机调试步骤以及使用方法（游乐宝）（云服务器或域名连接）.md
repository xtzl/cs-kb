# **<font style="color:#333333;">四、支持功能</font>**
<font style="color:#333333;">售卖类：</font>

<font style="color:#333333;">1.支持会员卡开卡、手机号开会员等功能；</font>

<font style="color:#333333;">2.支持零售商品购买与兑换，支持直接扫商品条形码快速选择商品，支持使用POS机回收商品；</font>

<font style="color:#333333;">3.支持游戏币充值、预存款充值和游乐套票充值功能；</font>

<font style="color:#333333;">4.支持超时游玩后通过POS机进行付超时费用；</font>

<font style="color:#333333;">5.支持在POS上退订单；</font>

<font style="color:#333333;">6.支持线上购买订单POS机直接取货核销</font>

<font style="color:#333333;">扣费类：</font>

<font style="color:#333333;">1.支持套票扣次、期限票验证；</font>

<font style="color:#333333;">2.支持直接扣代币和金币；</font>

<font style="color:#333333;">3.支持按项目扣费，并支持选择扣储值还是扣套票；</font>

<font style="color:#333333;">4.支持直接扣彩票、积分等储值</font>

<font style="color:#333333;">会员类：</font>

<font style="color:#333333;">1.支持查询会员信息、会员储值、套票列表和游玩记录；</font>

<font style="color:#333333;">2.支持会员录入人脸；</font>

<font style="color:#333333;">仓库类：</font>

<font style="color:#333333;">1.支持礼品入库、盘点功能、并支持采购单直接审核入库；</font>

<font style="color:#333333;">2.支持机台库存功能，针对机台库存进行盘点；</font>

<font style="color:#333333;">其他类：</font>

<font style="color:#333333;">1.支持互动打卡项目副卡绑定；</font>

<font style="color:#333333;">2.支持卡丁车扣费核销并发车；</font>

# **<font style="color:#333333;">五、注意事项</font>**
<font style="color:#333333;">1.首次使用前，需要对POS机激活，激活时需要有WIFI网络</font>

<font style="color:#333333;">2.首次使用前，请提前对POS机进行充电</font>

<font style="color:#333333;">3.POS自带流量相对较少，在安装和更新程序时，请务必使用WIFI网络进行下载，以免流量不足</font>

# **<font style="color:#333333;">六、安装标准</font>**
<font style="color:#333333;">1.POS机正常进入激活状态</font>

<font style="color:#333333;">2.POS所有功能正常</font>

<font style="color:#333333;">3.POS流程激活成功</font>

# **<font style="color:#333333;">十、常见问题</font>**
<font style="color:#333333;">1.链接不到服务器。</font>

<font style="color:#333333;">答：</font>

<font style="color:#333333;">使用域名连接情况下可能出现的原因</font>

<font style="color:#333333;">①流量不足，可联系销售助理协助充值流量或者使用无线热点来连接</font>

<font style="color:#333333;">②域名失效，检查服务器的VPN（本地服务器情况）或者检查云服务器是否出现异常</font>

<font style="color:#333333;">使用本地wifi连接本地服务器可能出现情况</font>

<font style="color:#333333;">①WIFI网络差，请检查无线网络</font>

<font style="color:#333333;">②连接的WIFI无法连接服务器，请检查无线网络</font>
