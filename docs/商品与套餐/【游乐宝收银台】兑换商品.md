# 应用场景
用于会员消耗固定储值兑换指定商品。

# 操作步骤

操作路径：登录游乐宝收银台——商品——兑换商品——新增（彩票、积分、代币、金币）兑换——查询到会员——可兑换商品——选择需要兑换的商品——兑换。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b8156766673e0&type=max)

兑换的时候可以任意输入兑换折扣比例进行兑换

# 注意事项
1、登录的收银终端需要绑定售卖仓库，兑换的实物商品需要在登录终端绑定的仓库中有库存（启用库存的情况下，如不启用库存，可以直接兑换，不需要有库存）。

2、后台【商品】-【商品资料】-【兑换设置】中设置兑换商品数。

3、后台【商品】-【商品资料】-对应商品没有设置限制可兑换终端。

4、预存款类型商品不可兑换；组合商品的子商品中包含有预存款也不允许设置兑换商品。

5、可设置会员兑换折扣（后台-促销-兑换折扣，中设置），折扣后价格取整数显示（最小单位：1）。

6、计时票不允许兑换。

7、会员被禁用、储值被冻结、储值为零，无法兑换。

8、散客彩票兑换是针对出票器打印出来的二维码。
