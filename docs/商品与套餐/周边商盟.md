# 场景说明： 
游乐运营门店跟周边商家合作，相互引流，打通门店彼此的消费通道，让游乐场地顾客可以消耗游乐门店的储值到商盟店消费，购买商盟店的商品，后续游乐运营门店跟周边商家再另做结算，达到互惠共赢的目的。

**<font style="color:#DF2A3F;">注意：</font>**

若使用该功能，系统每笔订单会收取1%的手续费，通过菜籽结算，1菜籽=1元。

## 商盟店设置：
###### 开通商盟店账号：
将商盟店提供的管理员手机号录入系统，并根据双方事先约定的内容决定是否要设置抽成比例（游乐门店替商盟店引流，可抽取一部分结算比例费用作为引流费，若无可忽略）

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1741450336999-ef540587-8bdc-4e80-9257-493ede531416.png)

将商盟店码导出给到商盟店负责人，后续消费者可通过扫该商盟店码进行兑换相应代金券，购买商盟店商品

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1741450583994-fea5a810-3d4e-4414-8945-8ce6b1684095.png)

系统若设置了自动打款，可做到自动结算，将钱打到商盟店商户号，且打款账号必须是企业级支付宝

# 合作商盟店相关操作的内容
## 常规操作：
##### 使用门店消费码
拿到游乐门店提供的商盟店消费码，让上门的消费者扫码兑换，根据兑换的金额给予消费者同等价值的商品

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1741488249387-c50ce2d7-9eb0-4418-947f-45e19cacc643.png)

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1741571256750-dcf30a78-1d04-40af-9a8b-8934ae460df3.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1741571271436-4a06fb04-da38-4d9a-a214-fb063c1e9f26.png)



##### 登录游乐掌柜进行查账
微信端搜索游乐掌柜小程序，若游乐门店已给商盟店分配了权限，根据提示，选择按微信手机号登录，可进一步进行查账，找到周边商盟功能，点击可查看到对应的订单数据。

# 常见问题：
1.开通业务每笔订单将收取1%的平台手续费是否支持设置成门店承担，而非顾客承担？

答：**支持，在业务后台该功能路径下设置。（****<font style="color:#DF2A3F;">支持业务系统版本：10.3.9114</font>****）**

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1750661042950-9d961e93-8da3-4c7f-bf53-3db10716cbce.png)

顾客兑换示例如图：

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1750661375849-bb8225b0-6fa4-451a-8059-f797ecc18b62.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1750661432620-1141bc58-900c-4398-a399-7422bd04670f.png)

2.是否支持设置不同商盟店有不同的兑换比例？

答：**支持，在业务后台商盟店设置处，开启单独门店兑换比例设置，自行填写门店兑换比例。**

**（****<font style="color:#DF2A3F;">支持业务系统版本：10.3.9114</font>****）**
