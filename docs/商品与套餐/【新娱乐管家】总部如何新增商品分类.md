# 应用场景

可以将对应类型的商品进行归类方便商品的查找

#

# 总部如何新增商品分类

1、在总部点击商品--商品分类--新增分类

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb5d4d6174e81&type=max)

2、上级分类不用选择、分类编码可以自定义也可以默认、分类名称自定义，然后确定，之后创建商品就可以选择对应的分类了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb5d56df44e87&type=max)

3、删除和修改商品分类，在对应的商品分类后面点击删除或者修改

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb5d6023e4e89&type=max)

# 注意事项

1、连锁版的需要在总部才可以设置商品分类，门店是不可以进行设置的。

2、删除商品分类的时候，如果有商品选择了这个分类，则这个分类是删除不了的。
