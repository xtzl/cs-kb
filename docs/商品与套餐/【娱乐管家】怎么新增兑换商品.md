# 应用场景

会员消耗固定储值兑换指定的商品

# 操作步骤

1. 路径（总部）：售卖设置——其他套餐——零售商品——新增（填写商品基本信息）——兑换设置——添加兑换的门店，填写兑换的储值数量

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb651903a502d&type=max)

1.1 路径（门店）：售卖设置——其他套餐——零售商品——新增（填写商品基本信息）——保存，

售卖设置——定价和兑换——商品兑换设置——新增兑换商品——找到兑换的商品，填写各储值兑换的数量——保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb65666fb5035&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb65700ef5037&type=max)

2. 设置对应的兑换仓库（售卖仓库），设备管理——硬件设备——收银终端——点击对应的收银终端——选择售卖仓库——保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb658b8bd5039&type=max)

3. 收银台进行兑换，商品-兑换商品——选择需要兑换的储值类型——输入会员号——可兑换商品（或输入礼品名称查找）——输入要兑换的数量——点击兑换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb65b7045503d&type=max)

4. 如果需要取消礼品兑换，收银台——订单——兑换查询——选择要取消的订单点击退货

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb65e5b605041&type=max)

5. 兑换的记录可以在后台进行查看，会员管理——会员兑换记录——选择对应的储值的兑换查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb65ffdd05044&type=max)
