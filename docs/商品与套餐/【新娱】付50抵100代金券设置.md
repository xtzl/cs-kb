# 业务场景

适用与门店促销活动付50抵100元活动

# 实现步骤

第一步：新增50元零售商品（如果已经有了可以跳过）
路径：后台--商品--零售商品--新增
注意事项：该商品属性设置为虚拟商品，这样设置后不需要设置商品库存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932484e24d2286&type=max)

第二步：新增100元代金券
路径：后台--营销--优惠券--新增代金券--审核代金券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019324889fe02295&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193248d6aca22a5&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193248f53f022ac&type=max)

第三步 设置充值赠送，购买指定零售商品送指定代金券

路径：后台--营销--充值赠送--添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932493ffb122e7&type=max)

# 常见问题：
顾客如何获取代金券？

答:收银台或者小程序购买指定零售商品，系统将会自动将代金券送到会员账户。

顾客如何使用代金券？
答：收银台或者小程序购买套餐时，只要符合代金券使用条件，系统会自动使用。

代金券的有效期设置错了能否修改，修改后已经获得的代金券有效期是否会同步？
答：代金券有效期没有结束的情况下可以登录后台修改，如果已经结束则不能修改，，修改后，之前已经获得的代金券有效期也会同步。
