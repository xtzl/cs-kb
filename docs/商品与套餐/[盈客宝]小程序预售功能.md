# 1、功能路径

游乐宝预售功能路径：线上——盈客宝管理——营销活动——商品预售
娱乐管家预售功能路径：线上管理——盈客宝小程序——小程序功能设置——营销活动——商品预售

# 2、预售功能设置

步骤一：可自定义设置预售活动界面

步骤二：新增预售活动

步骤三：设置活动名称和时间，并且选择一种预售规则，分别是全款和定金两种规则，并且设定发货时间
全款规则：购买预售套餐时可直接支付套餐金额，支付完成后等到发货即可。
定金规则：购买预售套餐时需要先支付设置的定金金额，待到支付尾款时间支付剩余的套餐金额后商品才会发货。

注意：活动结束后，未支付尾款的订单，将预售失败，不自动退定金。如果门店需要给顾客退定金，需要在预售活动的活动概况点击查看-》预售订单界面操作退定金，具体步骤如图所示。
