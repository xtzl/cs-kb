# 应用场景
娱乐管家系统中，新增套餐、零售商品等套餐内容时，都需要设置商品分类，而商品分类最大的作用是很多报表都会通过此商品分类进行归类统计。请总部管理员根据使用情况，对门店商品进行商品分类的设置。商品分类最大支持二级分类。

# 操作流程
路径：登录总部后台→商品→商品分类

点击【+新增分类】，进行分类新增

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721529638329-eb8e3584-9b89-474e-b907-c257084ff001.png)

在分类名称输入对应想要设置的分类名称，如【游戏币套餐】【游乐次票】【游乐年卡】【礼品兑换】等类容。如果新增的商品分类是二级分类，还需要在【上级商品分类】中选择归属的一级分类，点击【确定】完成设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721530748242-6de93223-d0cc-4c04-b7fd-157b54b7e171.png)
