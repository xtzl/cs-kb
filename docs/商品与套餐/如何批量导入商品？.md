# 应用场景
当门店录入的商品数量比较多的情况下，我们可以统一使用EXCEL表来导入到系统里面。

# 操作流程
路径：商品→零售商品

#### 进入【零售商品】的界面，并选择【导入】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718430943601-5c3782e5-766e-443b-8ce4-b682d84f0cb0.png)

#### 先点【下载模板】将模板下载下来
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718430969562-64379121-108b-46b6-8df8-005167db5098.png)

#### 打开下载的模板，按照模板的格式填写商品资料
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431014248-3616c649-41ba-4c61-8ff8-72a1a5f28744.png)

#### 回到系统的导入界面，点【选择文件】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431687976-9dc92a4c-990d-4bee-9ab8-1762abdfd8d3.png)

#### 选择已经编辑好了EXCEL文件
#### ![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431724077-360383dd-b743-4a6e-a6c5-2624ab66c651.png)
#### 选择完毕后，如下图所示
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431807139-aedd1452-b2db-40a7-ab96-8c6c8b3ff571.png)

#### 点击【导入】完成商品导入
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431840566-f42ca402-69ab-42b3-96ff-a05d92763d4e.png)

#### 导入后，界面会显示【导入成功！本次导入*个商品】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718431872565-c9dff691-b95f-4219-8572-9f6b7fc1065c.png)
