# 🔴应用场景
在举办某些活动时，假如想让游客在小程序领券后，员工通过手机核销券码来确认游玩资格时，可以按照此文档流程来进行设置和核销。

# 🔴操作流程
## 第一步：设置用于核销的优惠券。
①先设置一个虚拟的零售商品作为优惠券的基础商品

路径：后台→商品→零售商品→新增商品

注意：设置该商品时，需要设置为【虚拟商品】

第二步：设置优惠券的派发方式。

第三步：给员工设置核销功能权限。

第四步：员工核销该优惠券。
