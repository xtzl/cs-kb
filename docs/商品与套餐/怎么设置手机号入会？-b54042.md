怎么设置手机号入会？

应用场景

适用于无实体卡会员的门店

操作流程

路径：商品→入会套餐→新增

1.点击新增，填写基本信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea4cdf6b32f0&type=med)

套餐编号：系统自动生成，无特别要求可不更改

套餐名称：同一类的入会套餐商品名称不可重复

商品分类：按套餐选择分类

入会级别：顾客购买入会套餐，成为的会员级别

初始有效期：会员卡的有效期

入会介质：选择手机号

工本费和卡押金：不需收取，可填写为0

套餐售价：不可手动更改，根据工本费+卡押金+子商品的定价决定

2.套餐定价：选择需要是否上下架及上下架时间

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea4cdf7032f1&type=med)

3.商品展示：设置该入会套餐在收银台的展示分组、显示排序、背景颜色、字体颜色、售卖打印小票、可售卖终端。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea4cdf7532f2&type=med)
