# 应用场景

总部需要统一设置游戏币套餐，便于统一管理。

# 操作步骤

设置思路：设置一个游戏币套餐两步即可，三四步根据实际需要设置。

## 第一步：打开商品页面

实现路径：新版娱乐管家总部后台——商品——游戏币套餐——新增游戏币套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c4a2a1f7715f5&type=max)

## 第二步：点击新增游戏币套餐

实现步骤：娱乐管家总部后台——商品——游戏币套餐——新增游戏币套餐——基本设置（带*为必填项）

保存后，一个基本的游戏币套餐就设置完成了。如果还想设置充值赠送、兑换，请继续看第三、四的附加步骤设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c4ee8ba4d19b5&type=max)

## 第三步：设置赠送（附加步骤）

第三步是根据您的实际需求设置的，若没有设置需求，可以跳过此步骤。

其中，赠送的优惠券是需要提前设置的。（新娱乐管家如何设置优惠券？超链接待补充）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c4ee6443619b3&type=max)

## 第四步：兑换设置（附加步骤）

第四步是根据您的实际需求设置的，若没有设置需求，可以跳过此步骤。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c4f17db2219cb&type=max)

# 常见问题

1.为什么我设置的游戏币在收银台出不了币？

解答：检查下第二步中的【售币类型】是不是设置成了代币，设置成代币是出不了实物币的。

2.为什么我设置的游戏币散客无法购买？

解答：检查下第二步中【限购规则】是不是设置了限购，如果设置了限购，散客是无法购买。

3.我设置了充值赠送游戏币，设置的分期返还。顾客购买了此套餐后，我把赠送设置的分期返还游戏币关闭了，那游戏币还能继续返还到顾客会员账户吗？

解答：关闭前购买的顾客，分期赠送返还的游戏币是可以继续返还的，关闭后再购买的顾客就赠送不了了。
