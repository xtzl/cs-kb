# 应用场景

该回收礼品功能可以将礼品回收转化成对应的储值，使用储值可以兑换其他礼品。

# 操作步骤

1. 总部——售卖设置——其他套餐——零售商品——点击对应礼品——兑换设置——添加可兑换回收的门店——设置“是否可回收”为是—设置各储值兑换回收的数量

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb119df7c42fa&type=max)

1.1 门店——售卖设置——定价和兑换——商品兑换设置——新增兑换商品——找到对应礼品勾选“可回收”——填写各储值兑换回收数量

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb11b3c2c4301&type=max)

2. 设置对应的回收仓库，设备管理——硬件设备——收银终端——点击对应的收银终端——选择回收仓库——保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb11dc6294308&type=max)

3. 收银台进行回收，商品-兑换商品——礼品回收——选择回收方式——输入会员号——输入礼品名称——输入要回收的数量——点击回收

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb11ef95f4310&type=max)

4. 如果需要取消礼品回收，收银台——订单——回收查询——选择要取消的订单点击取消回收

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb120c29b4322&type=max)

5. 回收的商品可以在后台进行查看，售卖设置--定价和兑换-礼品回收查询，可以查看到回收的礼品记录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb121a3654324&type=max)

# 注意事项

（1）实物商品回收要填写估算成本价，如果不填写的话，回收的礼品是没有库存单价的
