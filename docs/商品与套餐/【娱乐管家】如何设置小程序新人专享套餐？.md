# 业务场景

用于小程序引流，针对注册小程序后从来没有购买过套餐的会员

说明：

1、只针对小程序上入会没有消费过的会员有效，没有注册时间限制
2、开启活动后，首页广告不显示；若新用户购买过此套餐，则显示首页广告
3、新注册会员每人限购一次
4、只能设置一个套餐活动

# 设置路径

油菜花后台 > 小程序 > 营销活动 > 新人专享套餐活动
