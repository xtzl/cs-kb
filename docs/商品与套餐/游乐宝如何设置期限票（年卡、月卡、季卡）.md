1. 创建游乐项目：创建场地对应的游乐项目，方便设置期限票和核销

路径：设备--设备管理--游乐项目

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b17db67ff3&type=max)

点击新增分类，创建项目类型和分类，建议选择闸机项目。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b1a5877ff4&type=max)

点击闸机项目，点击新增项目，在新增项目界面填写项目名称，出入口改成2，点击下一步保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b1d2b57ff5&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b208d37ff7&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b21c607ff8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b231e57ffa&type=max)

2. 期限票：设置场地项目的月票，年票

路径：商品--商品管理--新增--期限票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b254547ffb&type=max)

进入新增期限票界面填写套票名称，商品分类，售卖价格，套票有效期 ，点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b26fe07ffc&type=max)

在可玩项目里设置使用频率，添加游乐项目，点击下一步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b298c57ffd&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b2af7c7ffe&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b2c4c57fff&type=max)

售卖设置里面是否上架选择是，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b2ea060000&type=max)

保存之后，即可在商品管理界面查看到新增的期限票套票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b2fd090001&type=max)

3. 呈现演示：收银台--商品--售卖商品--选择需要购买的期限票--点击结账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b313d10002&type=max)

点击结账顾客付款后，可以选择出票方式，打印套票，绑定腕带或者票码，在闸机上扫码即可。如不需要绑定则点击关闭即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b32a150003&type=max)

4. 套票核销：核销期限票，登记客户的使用记录

路径：收银台软件--游乐--验票过闸

在验票过闸里面选择对应的游乐项目，需要扣次的会员和套票，点击过闸即可扣次

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b36a890005&type=max)

5. 常见问题：

问题1

场景：怎么查看客户期限票的过期时间

解决：在收银台--会员--输入会员卡号或者手机号--点击套票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9b3801d0006&type=max)
