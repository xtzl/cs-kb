# 注意事项

套餐设置里的“售币类型”

- 代币：套餐只能充到会员卡里，不能出实物币。有些套餐很优惠，但是限定只能会员才能充值，这时候就能选择这种模式

- 实物币：套餐只能以实物币的方式出币，不能充到会员卡里；一般对于一些散客套餐使用比较多

- 自动：套餐既可以充到会员卡里，也可以出实物币；收银员可以根据客户需求，选择对应的出币类型
