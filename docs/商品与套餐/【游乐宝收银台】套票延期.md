# 应用场景

给会员套票的有效期延长一定时间。

# 操作步骤

操作路径：收银台——套票查询——点击需要延期的套票——延期。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b1f68992c5837&type=max)

# 注意事项

1.已完成和已退票的套票不支持延期。

2.延期时间需要大于当前套票有效时间。

3.请假中的套票也支持延期。

4.期限票的延期分摊：

①未分摊的套票，分摊金额不变，平均分摊金额变小。

②已部分分摊的套票，已分摊的分摊金额不变，未分摊的根据新的分摊系数重新计算分摊金额。
