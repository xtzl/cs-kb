# 一、作业说明

本文旨在用于指导自助兑换柜的安装

# 二、外观展示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001930b0344d56a53&type=med)

# 三、安装准备

1. 十字螺丝刀*1
2. 放置位置预留设备电源

3. 提前准备好服务器连接域名地址（该设备只支持域名连接）

4. 手机*1

5.系统版本：游乐宝8.1.6404以上，娱乐管家10.3.4453以上

# 四、安装标准

1.自助兑换柜配件安装到位（顶部发光字）

2.自助兑换柜天线垂直立正

3.自助兑换柜地脚已固定

4.自助兑换柜连接系统正常，功能能正常使用（包括加货功能、兑换功能以及售货功能均正常）

5.培训客户使用兑换柜（包括如何加货、如何更换货物和如何兑换使用）

# 五、注意事项

1.兑换柜运输要求会将货道用扎带进行固定，安装前需要将扎带全部清理完毕

2.兑换柜重量比较重，请至少两个人以上进行搬运，避免发生倾倒

# 六、作业步骤

## 第一步：配件安装

配件清单：发光字

1.发光字

礼品兑换柜顶部有发光字，直接安装到顶部即可，并接入预留电源即可

2.天线

顶部天线将其树立

3.地脚

将地脚打到底，使礼品兑换柜不摇晃

## 第二步：同步服务器地址

路径：娱乐管家后台→卡头WIFI通讯

在【通用配置卡】界面，点击【重新设置通讯网络】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001930b0344df6a54&type=med)

2.选择【外场】，并输入域名地址，一般域名地址为：y********.yun.youcaihua.net，端口为88，然后点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001930b0345b56a55&type=med)

3.这里点击【生成自动连接WIFI】然后直接点保存完成设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001930b0345bd6a56&type=med)

# 七、测试流程

1.打开微信，扫一下兑换码，兑换一下其中一个商品；检查对应的格子柜是否打开。

2.检查所有商品的定价和兑换价是否正确。

# 八、常见问题

1.礼品兑换柜兑换后不出货

答：一般因为礼品兑换柜没有联网或者联网失败导致，检查盒子连接情况，如果连接成功，盒子应该是【电源】【联网】【强度】【待机】等都亮绿色灯，且不会灭；网络强度弱则【强度】为黄色灯；

2.顾客扫码后，提示设备离线，如何处理？

解决：

如果是WiFi版礼品兑换柜，检查当地网络是否稳定，WIFI是否覆盖到位；

以上检查了无误后，再检查下礼品兑换柜设备里边的盒子状态，看下盒子是否正常。

3.顾客扫码支付后，货道不出货或者出错货品。

解决：

检查游乐掌柜后台货道上架是否设置错误，库存是否不足。

4.礼品兑换柜的库存能否直接通过入库单进行补货？

答：不可以，只能通过游乐掌柜补货。

5.使用测试货道时，商品掉落下来后，会减少系统库存吗？

答：不会，所以需要将商品放回去。
