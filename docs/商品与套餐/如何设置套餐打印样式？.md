# 应用场景
当门店想调整门票上的打印内容时，我们可以通过系统的打印样式进行调整。

# 操作流程
路径：设置→系统设置→套票打印设置

#### 打开【套票打印设置】界面，找到需要编辑的打印样式，选择【设计模板】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718330317843-d3a60a1b-5bd0-43d5-8cb4-0f1fd1b39f5f.png)

#### 在编辑界面中根据自己的需求进行调整即可。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718330329538-1bfd7c4d-1413-40bd-9f28-a749513dad6e.png)
