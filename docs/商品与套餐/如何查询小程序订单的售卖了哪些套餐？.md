# 应用场景
查询小程序售卖订单明细，可依靠会员信息查询小程序订单售卖

查询时间段内小程序售卖商品信息汇总表

# 操作流程
方法一：查询时间段内小程序具体订单购买记录明细

路径：财务--支付订单查询--渠道筛选

**点击财务，在支付订单查询中，筛选时间和渠道，查看时间段内支付订单详情**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772162969054-25304176-5145-4f19-8108-e567e6bf9fc5.png)



方法二：查询时间内，小程序销售商品套餐汇总

路径：财务--渠道报表--渠道商品一览

**点击财务，在渠道报表中，选择时间爱你，点击渠道商品一览，查看时间段内商品销售汇总表**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772163294317-0177b5ca-fffe-4067-b78d-7bc90341188c.png)
