# 🔴常见问题
❓️问：我门店的商品很多，后面新增加的商品， 是不是还要重新设置一次满减？

答：按上图操作，在“参与商品”那里选“按商品分类”，这样后续新增的商品只要在相应分类下，就会自动参与满减。
