# 应用场景
零售商品指的是店内售卖非套餐一类的商品，如礼品、零食、饮料等，如门店需要售卖此商品，或者需要兑换商品，需要按照此步骤新增零售商品。

# 操作流程
路径：商品→零售商品

#### 进入【零售商品】界面，点击【新建】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718438081775-535a5a94-df4d-4489-9cad-269169b8696d.png)

#### 按照下图说明，填写零售商品相应的设置，点击【确定】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718438192788-b5b2bb03-e8f2-4129-9e09-053bdc7bdb14.png)
