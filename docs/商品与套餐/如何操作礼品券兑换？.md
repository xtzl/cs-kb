# 应用场景
如何在收银台核销客户的礼品券

# 操作流程
路径：登录娱乐管家收银台-商品-兑换商品-礼品券兑换

#### 在娱乐管家收银台软件上点击礼品券兑换，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591170900-43fc7e9c-ee33-4ebf-9d9e-006e74c3a563.png)

#### 用扫码枪扫码客户礼品券核销券码，点击核销即可，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591405835-bbd6c18e-ced5-4039-a4ba-8a8225cef887.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718591303913-5493a68d-8624-4d0b-a9c2-3ba97c55f04d.png)
