# 1、总部如何新增组合商品

1.1.路径：总部后台---商品---组合商品---新增组合商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0c0e9f141d8&type=max)

1.2.步骤：点击新增组合商品---填写商品基础信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0c5fd3f41e6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0c894a841eb&type=max)

1.2.组合类型

（1）固定组合：即购买该组合商品都可以获得已添加完成的所有子商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0cb3c6841f2&type=max)

（2）A类型：即购买该组合商品可以在已添加完成的子商品任选N个

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0cf318041f7&type=max)

（3）A+B类型:即购买该组合商品可以根据已添加的子商品设置的分组类型任选N个

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0d4f2a24211&type=max)

（4）A+B+C类型：跟（3）同理

1.3.售卖设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0d863474218&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0d94902421a&type=max)

# 2、如何设置购买组合商品赠送奖励

2.1.路径：商品---组合商品---新增组合商品---赠送设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0db73bd4221&type=max)

2.2.步骤：打开赠送设置---输入赠送的储值数量，勾选完成赠送和赠送周期规则点击确定保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0dd269a4225&type=max)

# 3、如何在收银台购买组合商品

3.1.步骤：收银台商品---售卖商品---点击对应的商品---结账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cb0f2c03f4281&type=max)

# 4、注意事项

（1）已创建好的组合商品无法修改组合类型

(2）组合商品中的子商品没有库存数量需要到分店的仓库---入库单--新增库存
