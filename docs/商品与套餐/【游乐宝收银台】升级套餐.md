# 应用场景

低价套餐更换到高价套餐，仅需要支付差价即可，避免手动退单即可完成套餐的变更，套餐变更后，新套餐的使用情况继承旧套餐的使用情况。

# 操作步骤

操作路径：登录游乐宝收银台——商品——读取会员卡——选择升级的商品套餐——升级套餐——选择原套餐——结算——支付。

# 注意事项

1.升级套餐目前仅支持：游戏币、预存款、计次票、期限票；组合商品暂不支持升级。

2.升级套餐的价格需要大于原套餐的价格。

3.升级套餐的各类储值的数量不能小于原套餐的各类储值的数量。
4.如果套餐存在出过实物币，则在升级套餐界面直接过滤掉（实物币套餐不支持升级）。

5.升级的计次票的有效期不能小于原套餐的有效期。
6.升级的计次票的可使用次数不能小于原套餐。
7.升级的或被升级的计次票不支持非共享且多项目的套餐升级，但单项目非共享可以升级。
8.计次票升级期限票，仅需要价格高于原套餐即可。

9.期限票间的升级，仅需要同时满足价格高于原套餐与有效时间和核销有效时间不小于原套餐即可。
