# 文档说明

此文档针对客户以下需求所编写的操作文档。用于指引如何批量绑定可过闸二维码腕带。

# 客户案例情况及需求说明

1.客户购买了闸机，并且闸机只用于进出，不需要核销。

2.游客需要进闸时，直接提供不记名二维码腕带通过闸机。

3.客户希望提前可以一次性在系统生成可用腕带，届时，游客来了之后直接派发腕带即可。

4.客户使用的腕带是预生成二维码腕带。

# 准备工作：

提前准备好打印好的二维码腕带票码信息，要求为15位数字＋字母组合方式的编码

### 闸机安装配置说明

点击此处可查看闸机安装配置教程：闸机的安装配置使用

# 流程简介：

该设置方案共三步：

## 步骤一：开集团内部会员账号

创建会员级别（总部后台设置）->创建总部入会套餐，并下发到对应门店（总部后台设置）->门店收银台开内部员工账号（门店收银台操作）

## 步骤二：创建总部导入套票商品

创建门店游乐项目（门店后台设置）->创建总部套票，并下发到对应门店，但不需要上架（总部后台设置）

## 步骤三：总部后台跳转门店导入套票资料

下载套票模版->整理套票模版（结合提前收集到的二维码腕带票码）->导入套票->导入套票检查

# 具体流程：

## 集团内部账号设置：

### 创建内部员工会员级别

为方便管理，在总部后台提前创建一个内部会员级别（内部开门店账号使用，后续将套票存到该会员账号）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4d8387472081&type=max)

### 创建内部员工入会套餐（供后续门店创建内部员工账号使用）

套餐名称：定义为内部使用（可自定义设置）

商品分组：选择【会员卡】（系统自带生成的分组）

入会级别：勾选设置好的【内部套票账号】

售卖门店：勾选需要下发的门店，并设置上架时间

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e4f018f2387&type=max)

### 门店开内部会员卡：

#### 登录门店收银台：

注意：记住此时开卡的会员卡号，后续导入会员套票时需要用到，若完成该会员账号开卡， 则可进入到总部后台取消该入会套餐上架，避免影响门店日常营业

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e68a035243f&type=max)

## 套票资料操作：

从总部后台切换进入门店后台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4d9864b520d0&type=max)

### 1.创建一次性套票商品

1.创建关联的套票核销项目

套票核销时需选择对应的核销项目，则在设置套票前，需要提前创建该核销项目信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4d9b33de20da&type=max)

### 2.创建总部一次性核销套票商品

#### 2.1总部套票创建路径：

套票设置路径： 【商品】-> 【游乐套票】->【新增期限票】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4dd49b5d21be&type=max)

#### 2.2一次性套票具体设置：

套票名称定义：一次性核销套票（也可自定义）

套票编号：YCH123456789（也可自定义，后续导入套票步骤需要用到）

商品分类：勾选默认【套票】分组即可

售价：设置为【0】

套票有效期设置：按要求设置成 购买后【0】天生效，有效期【1年】，首次使用后【1天】有效（当顾客开始核销时，该套票有效期会变成1天，即腕带仅限当天有效）

可玩项目：关联【创建关联的套票核销项目】，可勾选多门店核销项目

售卖设置：勾选【下架】

其余设置按默认设置即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e40acb82328&type=max)

#### 高级设置：

跨店使用勾选：支持，结算金额设置【0】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e3bbeda2321&type=max)

## 套票资料导入

### 1.进入总部后台，并切换至门店后台

具体操作如图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e432f1a232f&type=max)

### 2.下载导入套票模版

套票数据导入系统，是需要匹配系统模版， 则需要先【下载套票模版】，根据模版结合已拿到的二维码腕带票码数据，整理成完整的模板进行导入

#### 【会员资料模板】下载路径：

在【会员】→【会员资料导入】→【下载模板】对模板进行下载

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e43d0d92332&type=max)

也可以通过点击下方【下载链接】直接下载模板

下载链接：

### 3.整理导入资料模版

#### 具体参数设置如下：

会员号填入 开内部员工账号时的会员卡卡号

套票套票编号填入一次性套票的商品编号：YCH123456789

开卡日期填入：填入套票导入当天的日期，如2026年*月**日

剩余次数填入：9999

截止日期填入：在开卡日期上加一年， 如2027年*月*日

剩余金额设置为：【0】

票码：复制粘贴导入准备好的票码信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e76d65f246a&type=max)

### 4.导入套票信息模版

将编写好的套餐导入模板，在系统界面中的【选择文件】进行选择，确认导入数据是否有问题，没有问题则点击导入完成操作。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e798fe02476&type=max)

### 5.导入套票检测

导入套票后，可在后台【套票查询】查看该资料

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e8296d92486&type=max)

或在收银台输入该会员卡号查看会员套票资料

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e4e7a9595247b&type=max)
