# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
当门店收银员需要给游客贩卖游戏币时，那应该如何操作？

# **<font style="color:rgb(38, 38, 38);">🔴</font>**操作流程
路径：收银台→商品→售卖商品

#### 在【售卖商品】界面，选择需要售卖的游戏币套餐，选择后在右边的购物车会显示已经选择的商品，如果该商品需要充值到卡内，可先读取会员信息后，再点结账，完成售卖过程。
