# 说明：预存款：给顾客充值会员卡

# 路径：商品--商品管理--新增--预存款

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0cb1970eba&type=max)

进入新增预存款商品界面，填写套餐名称，预存款数量和售卖价格（建议一比一设置），点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0d501e0ebd&type=max)

保存之后，即可在商品管理界面查看到新增预存款商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0d69320ebe&type=max)

# 呈现演示：

收银台--商品--售卖商品--在右边输入会员卡号--选择需要充值的套餐--点击结账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eef0d7dc20ebf&type=max)

# 常见问题：

问题1

场景：预存款可不可以用彩票，积分等储值兑换

解决：预存款是不可以用其他储值兑换的
