# 应用场景
<font style="color:rgb(51, 51, 51);">用于会员消耗代币储值兑换指定商品。</font>

# 操作流程
路径：<font style="color:rgb(51, 51, 51);">登录娱乐管家收银台-商品-兑换商品-代币兑换</font>

#### <font style="color:rgb(51, 51, 51);">登录娱乐管家收银台-商品-兑换商品-代币兑换-查询到会员-可兑换商品-选择需要兑换的商品-兑换，如下图所示：</font>

# 常见问题
1.<font style="color:rgb(51, 51, 51);">登录的收银终端需要绑定售卖仓库，兑换的实物商品需要在登录终端绑定的仓库中有库存（启用库存的情况下，如不启用库存，可以直接兑换，不需要有库存）</font>

<font style="color:rgb(51, 51, 51);">2.预存款类型商品不可兑换；组合商品的子商品中包含有预存款也不允许设置兑换商品</font>
