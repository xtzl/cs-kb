# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
通过这项功能， 可以帮你实现：

1. 在兑币机或收银台售卖的套餐自动关联为指定员工的业绩
2. 自动计算提成各个员工销售提成，省时省力高效

# **<font style="color:rgb(38, 38, 38);">🔴</font>**后台操作流程
### <font style="background-color:#FBDE28;">01 创建导购员</font>
<font style="color:#333333;background-color:#FFFFFF;">路径：商品--导购员列表--批量操作—新增/导入系统用户（将员工账号直接生成导购员）</font>

<font style="color:#333333;background-color:#FFFFFF;">在这一步操作中， 要记下</font><u><font style="color:#DF2A3F;background-color:#FFFFFF;">每个导购员的编号</font></u>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723705136159-d8586d79-3da0-4048-ab68-3ab8371a548a.png)

### <font style="background-color:#FBDE28;">02 </font><font style="color:#333333;background-color:#FBDE28;">设置导购商品和提成比例</font>
<font style="color:#333333;background-color:#FFFFFF;">路径：商品—导购商品—新增—选择系统商品—设置提成比例（可设置为0%-100%）</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723705223241-1675f1d1-9ea6-4412-9dbf-526ecdbfa885.png)

### <font style="background-color:#FBDE28;">03 在兑币机上输入导购员编号进行登陆</font>
<font style="color:#333333;background-color:#FFFFFF;">路径：右上角设置—切换导购—输入导购员编号—确认 （可以在上面第1步操作中查看</font><u><font style="color:#DF2A3F;background-color:#FFFFFF;">各导购员编号</font></u><font style="color:#333333;background-color:#FFFFFF;">）</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723705428490-2eb22100-4252-4bbe-a806-3704cb27d6f0.png)
