## 1. 零售商品：创建零食，饮料，玩具等商品，方便收银台的售卖和管理库存

## 2. 路径：商品--商品管理--新增--零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eeefc689f0e24&type=max)

进入新增商品界面填写商品的名称，分类，售卖价格等信息，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eeefc80ca0e25&type=max)

保存之后，即可在商品管理界面查看到新增的零售商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eeefc9a630e26&type=max)

## 3. 呈现演示：

在收银台-商品-点击对应的零售商品-点击结账-客户付款即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eeefcb0940e27&type=max)

## 4. 常见问题：

问题1

场景：商品在收银台杂乱无章，不方便找到对应商品

解决：售卖设置收银台分组里面选择对应的分组，点击旁边的“+”可以添加收银台分组

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018eeefcc80c0e28&type=max)

问题2

场景：商品只能在收银台一号售卖，不能在收银台二号售卖

解决：售卖设置可售卖终端选择限制，选择可售卖的终端，没有选择的终端部可以售卖此商品

问题3

场景：商品在收银台上没有展示

解决：售卖设置是否上架选择是，才能在终端上售卖

问题4

场景：商品不能进行出入库的设置

解决：基础设置启动库存控制没有选择实物商品，选择实物商品才能进行库存管理
