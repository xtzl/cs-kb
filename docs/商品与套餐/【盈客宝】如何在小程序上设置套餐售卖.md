# 1、小程序如何上架新套餐

1.1.路径：线上--盈客宝管理--商品资料管理。

1.2.步骤：选择本地的商品点击"发布"

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5156ce2362&type=med)

上传商品图片，勾选线上售卖，设置售卖、市场价格。下一步保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5156da2363&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5156e32364&type=med)

# 2、小程序如何下架套餐

点击商品名称，进入编辑状态，修改商品的上下架状态为“否”，下一步保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5157fa2365&type=med)

# 3、小程序商品如何设置分组名称以及调整商品分组

3.1设置分组名称：售卖展示设置，点击编辑图标修改分组名称。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5158042366&type=med)

3.2调整商品分组：

1）点击商品标题，进入编辑模式，显示分组位置调整单个商品的分组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5158db2367&type=med)

2）点击"售卖展示设置"，选择需要调整分组的商品，批量修改商品分组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5158e62368&type=med)

# 4、顾客购买小程序实物商品后，如何核销？

1）发货方式选择："门店自提"。购买后，需要到门店的收银台，搜索对应的订单进行取货；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e5159bd2369&type=med)

2）发货方式选择："物流快递"。购买商品时，会要求填写收货地址，支付后，订单发货，可到订单里边查看物流单号。（可用于门店发布到其他电商平台的商品作为礼品，门店上架后，顾客进行兑换，然后门店根据客户填写的地址到对应平台下单，下单后生成单号进行填写）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e515ad3236a&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e515adc236b&type=med)

# 5、常见报错，注意事项

①小程序提示未绑定售卖仓库。

到后台 设置盈客宝渠道仓库 检查是否有绑定仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e515ae6236c&type=med)

②客户购买时提示库存不足。

检查绑定的仓库，对应的实物商品是否有库存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e515aef236d&type=med)

③小程序发布游戏币套餐的时候，套餐的售币类型需要设置为自动或者代币 。

因为小程序上购买游戏币套餐是需要存入会员账号的，售币类型选择实物币，无法存入会员账号

④线上商品提示不能删除。

正在参与线上营销活动的商品是不能进行删除的

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e515bfc236e&type=med)
