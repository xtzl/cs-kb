业务价值：

### 1. 现金流价值

- 提前回笼资金，缓解运营、采购、营销、扩建压力

- 稳定淡旺季收入波动

### 2. 锁客价值

- 锁定用户长期复购，降低流失

- 提升用户粘性与消费频次

### 3. 经营价值

- 提高客单价（充值后更愿意消费）

- 便于做会员体系、积分、等级、权益

- 便于数据化运营，精准营销

### 4. 渠道 / 合作价值

- 方便做企业团建、工会福利、礼品卡

- 便于和景区、酒店、乐园做联营一卡通

#### 一、 主要使用场景

### 1. 景区 / 乐园 / 主题公园

- 园区一卡通：门票、二消、餐饮、购物、机台卡头项目付费

- 年卡 / 次卡预付费

- 亲子乐园、电玩城储值币

### 2. 休闲体验类

- 体育类项目

#### 二、 获取方式

- 套餐购买：购买“预存款”套餐

- 赠送

#### 三、 套餐设置

- 路径（总部和门店一样）：商品—预存款套餐

设置页面

- 基本设置：

功能按钮：确定，取消；

基础必填:套餐名称，套餐编号，商品分类，售价，预存款本金（ps:支付的多少钱，比如100元等于120预存款，那本金可以填100元就是，赠金可以填20元）；

基础选填：业务分类，预存款赠金（ps:支付的钱以外附加的，比如100元等于120预存款，那本金可以填100元就是，赠金可以填20元），售卖设置（是否售卖，总部独有的门店上架时间设置和售卖门店设置，上架时间，限制可售日期，可售终端选项，展示分组，限购规则，授权设置）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019caa3ff7cf7735&type=max)

- 赠送设置：

功能按钮：确定，取消

基本设置：活动时间，赠送类型（代币（有效期）；金币（有效期）；弹珠；积分；彩票；娃娃；能量；成长值；优惠券），【赠送规则（购买赠送；团购核销赠送；兑换赠送；每个会员只赠送一次；使用优惠券或自动促销购买时，不再赠送），赠送周期（优惠券会立即赠送）；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019caa4067897737&type=max)

- 修改记录页面

功能按钮：搜索门店查询框，列设置，确定，取消；

导航栏1：基本信息，售卖设置，小程序商品，赠送设置；

导航栏2：修改时间，修改人，修改记录，修改门店；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019caa418ecc7738&type=max)

- 门店可以设置 小程序商品页面：

功能按钮：发布小程序开关，取消，确定；

基础设置：商品名称，优惠说明，商品图片，售卖设置（是否上架，上架时间，限制可售日期，展示分组，显示排序，售卖价格，市场价格，能否线上退款，商品展示，已售数量，商品详情）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019caa453030773a&type=max)

注:设置了预存款商品后，顾客通过购买预存款商品获取到预存款储值，需要在路劲：后台系统 -财务-支付方式设置 ； 页面新增设置好预存款支付方式，收银台才能通过预存款收款的方式让顾客使用预存款支付
