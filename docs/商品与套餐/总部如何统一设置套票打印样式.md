# 应用场景
当总部想统一设置门店门票打印的样式时，可通过总部的套票打印样式进行管理统一设置

# 操作流程
路径：登录总部后台→商品→套票打印样式管理

点击【新增】添加打印模板

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721529518681-a0eaa944-bbc5-4f97-a40e-e92505f38c63.png)

输入打印模板名称，并设置此模板是纸质票模板还是腕带模板，点击【编辑模板】进行下一步

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721530011644-8a755bdf-3e54-4bbe-874c-6a4d996874a5.png)

在【编辑模板】界面中，根据需要调整打印样式，点击【保存】完成设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721530590496-5d1b7ec9-a370-4c8c-98fc-3873e5fa17a2.png)
