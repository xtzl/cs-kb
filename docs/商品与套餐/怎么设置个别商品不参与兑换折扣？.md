# 🔴应用场景
场地原先设置了金卡会员彩票兑换95折， 门店新进了一批限量手办，店长希望这批手办不参与兑换折扣

# 🔴操作流程
你需要到后台先找到对应的礼品， 参考路径：后台--“商品”--“零售商品”

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718803345839-f429bab4-c2c9-40e6-802c-e23e7dc14c59.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718803396337-6a7df5a0-d18b-4eac-8099-c2e7512bc586.png)

# 🔴常见问题
问：我按上面操作了， 但修改不了， 是灰色的

答：最可能的原因是：你这个商品是总部创建的，门店编辑不了，要到总部修改
