# 应用场景

通过此项打印套票的二维码信息，使用套票二维码进行扫码游玩项目。（此功能用于把已存入会员卡的套票打印成纸质票时又或者游客套票丢失时进行套票重打，收银员需要在系统中进行以上会员套票打印流程操作。）

# 操作步骤

操作路径：收银台——套票查询——点击需要打印的套票——打印套票。
