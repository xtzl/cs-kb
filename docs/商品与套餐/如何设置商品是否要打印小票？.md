# 应用场景
如果某些商品不需要打印小票，可以按照下述教程修改成不打印小票。

# 操作流程
路径：商品→零售商品（游乐套票、游戏币套餐、预存款套餐、组合商品、入会套餐）

#### 进入对应的界面，选择需要修改的商品，点进去编辑商品，找到【售卖小票】，可选择“打印”或者“不打印”，并点击【确定】完成修改
