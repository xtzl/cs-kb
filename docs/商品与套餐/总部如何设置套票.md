# 应用场景
连锁商城如果想实现多次票或者年票、月票可以多门店使用时，则需要通过总部来设置套票来实现，以下为总部计次票的设置操作流程。

# 操作流程
路径：登录总部后台→商品→游乐套票

点击【+新增计次票】或者【+新增期限票】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531793381-f3a9fb51-3ed7-407d-9ef6-d63f8738168a.png)

在设置套票中按照下图进行设置，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721531994427-80aeebeb-6bab-4853-83d5-7db685cbc6b2.png)



# 常见问题
1. 如何实现跨门店使用套票，需要哪些设置

答：

a.套票添加的项目，需要将能用的门店项目都进行添加

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721631916023-fd74d416-9d3f-4e95-86c2-a09ff0c2b49a.png)

b.在设置套票中，高级设置中的跨店使用需要开启

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721632092855-a1ccfaae-67a4-483c-9a69-d2fd330a07d9.png)

c.在路径：总部→系统设置→会员漫游设置→套票可跨店使用

将此开关打开

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721632168678-e34730a3-0002-430c-b409-5bf25a3b8976.png)

3. 调整总部计次票或者期限票的可游玩项目后，已购买的顾客会受影响吗？

答：会，会同步对应可游玩的项目。
