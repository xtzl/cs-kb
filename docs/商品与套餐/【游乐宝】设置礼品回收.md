# 应用场景

该功能可以将礼品回收转化成对应的兑换储值，当客户的储值累积到一定数量可以兑换其他礼品。

# 操作步骤

1、登录后台——商品——商品管理（管理商品资料）——点击对应礼品名称——兑换设置——启用兑换的储值——输入兑换数量——启用礼品回收——保存。（实物商品回收要填写估算成本价，如果不填写的话，回收的礼品是没有库存单价的）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0fb4590b27ec&type=med)

2、设置好对应的回收仓库，登录后台——设置——收银设置——收银终端——新增（或选择已有的）收银终端——选择礼品仓库——保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0f9ce95e27b5&type=max)

3、最后在收银台进行回收，商品--兑换商品--礼品回收

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0fa3bc6527cb&type=max)

4、回收的商品可以在后台进行查看，商品--礼品回收查询--选择对应的储值

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0fb45a1727ed&type=med)

5、取消礼品回收，收银台订单--回收查询--选择要取消的订单点击取消回收

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0fb45b3827ee&type=med)

# 注意事项

①回收礼品的收银终端要设置回收仓库。

②实物商品回收要填写估算成本价，如果不填写的话，回收的礼品是没有库存单价的
