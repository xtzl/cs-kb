# 🔴应用场景
如果门店想对某些商品修改为可通过储值进行兑换的商品，可以按照下述操作进行调整。

# 🔴操作流程
路径：商品→零售商品

#### 在【零售商品】界面中，选择想要修改的零售商品，在【兑换价】中修改各种储值可兑换此商品需要的数量，点击【确定】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718438315342-9871073c-4256-4175-8894-940cd85ffc6d.png)

# 🔴常见问题
❓︎问：如果我想要这商品也能在小程序上兑换，要怎么操作？

答：请按以下操作， 勾选“小程序兑换”即可
