# 操作路径

后台--商品--商品管理--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad10e49e543bd&type=max)

# 操作步骤

- 点击商品

- 点击商品管理

- 选择新增或者点击商品进行编辑

- 点击计次票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad10f69ad43be&type=max)

# 注意事项
设置计次票分为三个部分：内容、可玩项目、售卖与兑换
