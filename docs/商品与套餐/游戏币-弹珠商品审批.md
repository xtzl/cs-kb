**1、功能介绍**

为了避免门店上游戏币、限定币、弹珠套餐时，误设错了价格，导致套餐币单价过低被会员薅羊毛的情况，上线审批功能，单价低于设定价的商品需要审批后才能上架售卖；

<font style="color:#E4495B;">支持套餐类型：游戏币、限定币、弹珠套餐</font>

<font style="color:#E4495B;"></font>

**2、如何操作设置**

**开启套餐审核按钮**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1769766496380-c8180865-f28f-47e8-843b-0439b97b6193.png)



**商品保存时，低于设定价，就提示需要走审核后才能上架；****<font style="color:#DF2A3F;">（套餐变待审核后，自动下架商品）</font>**

:::success
1）如果是门店商品，线下/小程序商品任意一个低于设定的币单价，整个商品都会下架变待审核状态

2）如果是总部商品：

a）统一管理模式下，线下商品由总部审核，小程序商品由门店自己审核

b）门店管理模式下，且商品开启门店定价后。线下/小程序商品由门店自己审核；

c）门店管理模式下，总部统一控制售价情况，线下商品由总部审核，小程序商品由门店自己审核

:::
