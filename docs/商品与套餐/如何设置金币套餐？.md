# 应用场景
金币属于系统储值的一种，类似代币，其特点为只能存到卡里面，并且只支持游玩机台和兑换商品。不支持提币等功能。如果需要设置金币套餐，可按照下述操作进行设置。

# 操作流程
路径：商品→游戏币套餐

#### 在【游戏币套餐】的界面中，点击【新增游戏币套餐】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270962797-a38f3ba4-fb32-41b4-a442-a1115f4ef760.png)

#### 按照下图中的说明填写游戏币套餐的基本内容，点击【确定】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718271108064-dfaa9680-b653-4146-ad6a-9c4cb18a1c48.png)
