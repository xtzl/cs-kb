# 现象说明

游客购买同一类商品多个时，实际只出一个商品

# 解决方法

在setting文件中增加以下参数

ShippedSleep = 3000

说明：

1000等于1秒，设置3秒一般能解决

设置完后重启服务器和冷藏柜即可。
