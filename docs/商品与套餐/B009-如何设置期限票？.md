# 操作路径

后台--商品--商品管理--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad11b98b243d1&type=med)

# 操作步骤

- 点击商品

- 点击商品管理

- 选择新增或者点击商品进行编辑

- 点击期限票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad11b3a2643cf&type=max)

# 注意事项
设置期限票分为三个部分：内容、可玩项目、售卖与兑换
