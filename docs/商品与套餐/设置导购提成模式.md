# 🤗应用场景
导购模式支持【按比例提成】和【固定提成】

:::color2
注意：<font style="color:rgb(102, 102, 102);">更改提成方式，</font><font style="color:red;">已配置的导购商品提成金额会被清空，需重新配置；</font><font style="color:rgb(102, 102, 102);">不影响已销售的导购订单与提成数据</font>

:::

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1750212350633-d63876f1-52c4-49d4-9a35-ef0561636249.png)



:::color2
**门店商品**能直接设置导购固定提成，开启后，可在商品详情设置提成

<font style="color:#DF2A3F;">提示：必须要开启【固定提成】模式</font>

:::
