# 1. 创建游乐项目：创建场地对应的游乐项目，方便设置计次票和扣除次数

路径：设备--设备管理--游乐项目

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7642c7fb4&type=max)

点击新增分类，创建项目类型和分类，建议选择闸机项目。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a784d67fb5&type=max)

点击闸机项目，点击新增项目，在新增项目界面填写项目名称，出入口改成2，点击下一步保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7a07c7fb7&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7b2047fb8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7c36a7fb9&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7db047fba&type=max)

# 2. 创建计次票：创建项目的单次票和多次票

路径：商品--商品管理--新增--计次票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a7edd67fbc&type=max)

进入新增计次票界面填写套票名称，商品分类，售卖价格，套票有效期 ，点击下一步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a808b17fbd&type=max)

在可玩项目里设置使用频率，添加游乐项目，设置套票可玩的次数，点击下一步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a81f097fbe&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a992547fc6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a9a5527fc7&type=max)

售卖设置里面是否上架选择是，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a9bc077fc8&type=max)

保存之后，即可在商品管理界面查看到新增的计次票套票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a9d4077fc9&type=max)

# 3. 呈现演示：

收银台--商品--售卖商品--选择需要购买的计次票--点击结账

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9a9eb797fca&type=max)

点击结账顾客付款后，可以选择出票方式，打印套票，绑定腕带或者票码，在闸机上扫码即可。如场地不需要绑定直接关闭即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9aa01f67fcb&type=max)

# 4. 套票核销：计次票扣除对应的次数

路径：收银台软件--游乐--验票过闸

在验票过闸里面选择对应的游乐项目，需要扣次的会员和套票，点击过闸即可扣次

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9aa1aab7fcc&type=max)

# 5. 常见问题：

问题1

场景：怎么查看会员名下的套餐和剩余的使用次数

解决：收银台--会员--输入会员卡号或者手机号--点击套票--可以查询到会员拥有的套票和套票的使用次数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9aa2fb77fcd&type=max)

问题2

场景：在验票过闸里面给客户多扣除了次数

解决：收银台软件--游乐--取消机台扣费—选择对应的扣次记录--点击取消扣次

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee9aa43e47fcf&type=max)
