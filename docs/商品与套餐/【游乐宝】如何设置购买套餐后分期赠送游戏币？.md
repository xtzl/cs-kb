# 应用场景

门店需要设置营销活动时使用。

# 操作步骤

设置思路：先设置一个商品，再给这个商品设置充值赠送，游戏币选择分期返还即可。

## 第一步：设置游戏币套餐

注：其他商品类型也可以，这里以游戏币为例

设置路径：游乐宝后台——商品——商品管理——新增——游戏币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c32ca5d2a2c8f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c32d4cecf2cb2&type=max)

## 第二步：设置充值赠送

设置路径：游乐宝后台——营销——营销方案——充值赠送——新增——选择上一步的那个套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c32d6d16a2cbf&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c32dc26602cca&type=max)

# 注意事项

1.如果想停止赠送分期的游戏币，在【充值赠送】将相应方案移除即可；

2.充值方案移除后，之前购买赠送的分期游戏币会根据购买时的分期规则继续返还，直到返还完为止。
