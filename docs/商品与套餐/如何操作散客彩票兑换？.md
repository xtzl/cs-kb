# 应用场景
<font style="color:rgb(51, 51, 51);">用于散客暂存的彩票储值兑换指定商品。</font>

# 操作流程
路径：路径：登录娱乐管家收银台-商品-兑换商品-散客彩票兑换

#### <font style="color:rgb(51, 51, 51);">登录娱乐管家收银台-商品-兑换商品-散客彩票兑换-输入存票单号/存票单二维码-可兑换商品-选择需要兑换的商品-兑换，如下图所示：</font>
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718604821287-eeb4da50-4f05-47c7-b592-5d85523761bb.png)

#### <font style="color:rgb(51, 51, 51);">兑换的时候可以任意输入兑换折扣比例进行兑换，如图所示：</font>
