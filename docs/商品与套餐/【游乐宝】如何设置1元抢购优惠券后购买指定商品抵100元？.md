# 应用场景

门店开展活动时使用

# 操作步骤

实现思路：设置1个虚拟零售商品、1张用于指定商品的100元抵扣券，给这个虚拟零售商品设置充值赠送，购买这个虚拟零售商品即可赠送这张优惠券

## 实现方法

### 第一步：设置虚拟零售商品

实现路径：游乐宝后台——商品——商品管理——新增——零售商品——填写商品资料

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e7c6551240d&type=max)

### 第二步：设置100元优惠券

实现路径：营销——营销方案——创建营销方案——满减促销——设置此方案——审核通过

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e7ff8e22414&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e846f872427&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e898c802440&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e875ea3242d&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e8880bf2437&type=max)

### 第三步：设置充值赠送券

实现路径：营销——营销方案——充值赠送——新增——选择第一步创建的虚拟零售商品——勾选优惠券并添加优惠券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e96e2ca245d&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0e99f73b2475&type=max)

以上步骤，就是1元抢购优惠券后购买指定商品抵100元的设置方法。

# 注意事项

1.如果不想要这个充值赠送，移除就可以了
