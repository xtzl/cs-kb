# **<font style="color:rgb(38, 38, 38);">🔴</font>**应用场景
当游客需要购买购买门票或者次卡等套票套餐时，可按照下述说明进行售卖。

# **<font style="color:rgb(38, 38, 38);">🔴</font>**操作流程
路径：收银台→商品→售卖商品

#### 在【售卖商品】界面中选择需要卖的门票或者次票，点击读取会员信息，然后在右边的购物车确认数量无误后，点击结账，完成付款即可。
