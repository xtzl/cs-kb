# 1.设置路径

商品-预存款套餐、菜单栏直接搜索“预存款”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cceefd545762e&type=med)

# 2 .基本设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cceefd61e762f&type=med)

必填项：套餐名称（同一类的预存款套餐名称不可重复）、套餐编号（自动生成、无特殊要求可不修改）、商品分类、售价（不可填写，根据预存款本金来定价）、预存款本金

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cceefd7317630&type=med)

售卖设置设置上下架时间以及上架售卖的门店，套餐如需限购或者限制会员级别购买，则勾选上限购规则，根据门店需求进行设置

# 3.赠送设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cceefd73a7631&type=med)

购买预存款套餐赠送代币、金币等储值，可勾选上充值赠送按钮选择赠送的储值类型。并根据门店需求来设置赠送储值的规则和周期
