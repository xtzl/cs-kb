# 一、文档说明

本教程用于指导如何调试启用POS机以及POS功能说明。教程适用范围：商米POS机、商米盘点机。

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910c95389c57aa&type=med)

# 三、配件说明

1.POS主机*1

2.POS数据线*1

3.POS充电头*1

4.POS机58mm小票打印纸*1（盘点机没有此配件）

5.盘点机手带*1

6.说明书*1

# 四、支持功能

售卖类：

1.支持会员卡开卡、手机号开会员等功能；

2.支持零售商品购买与兑换，支持直接扫商品条形码快速选择商品，支持使用POS机回收商品；

3.支持游戏币充值、预存款充值和游乐套票充值功能；

4.支持超时游玩后通过POS机进行付超时费用；

5.支持在POS上退订单；

6.支持线上购买订单POS机直接取货核销

扣费类：

1.支持套票扣次、期限票验证；

2.支持直接扣代币和金币；

3.支持按项目扣费，并支持选择扣储值还是扣套票；

4.支持直接扣彩票、积分等储值

会员类：

1.支持查询会员信息、会员储值、套票列表和游玩记录；

2.支持会员录入人脸；

仓库类：

1.支持礼品入库、盘点功能、并支持采购单直接审核入库；

2.支持机台库存功能，针对机台库存进行盘点；

其他类：

1.支持互动打卡项目副卡绑定；

2.支持卡丁车扣费核销并发车；

# 五、注意事项

1.首次使用前，需要对POS机激活，激活时需要有WIFI网络

2.首次使用前，请提前对POS机进行充电

3.POS自带流量相对较少，在安装和更新程序时，请务必使用WIFI网络进行下载，以免流量不足

# 六、安装标准

1.POS机正常进入激活状态

2.POS所有功能正常

3.POS流程激活成功

## POS终端绑定

1.添加POS机终端

路径：游乐宝后台→设置→收银设置→收银终端

点击【新增】，终端类型选择“移动收银台”，并按照下图进行填写

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001910c9538c057ae&type=med)

###

2.打开POS机的【油菜花系统】，提示绑定终端，输入服务器地址和对应的账号密码，点击获取终端

本地服务器请先将POS连接场内局域网WIFI，并确保连接的WIFI能通过服务器地址访问到系统后台

输入本地ip地址＋9999，具体格式如下：

***.***.***.***:9999

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

输入完成，点击确认，若页面提示连接服务器失败，请检查无线网络是否正常，并且确认网络跟服务器是否在同一局域网内。

# 八、整机测试

1.流量功能正常使用，在不连接无线网络时，可正常使用POS机功能

2.购买一个测试商品，能正常收款并正常打印消费小票

3.通过扫码枪扫会员二维码，能正确读取会员信息

4.通过游乐套票售卖散客票，打印出来的票码能正常由闸机读取

# 十、常见问题

1.链接不到服务器。

答：

使用域名连接情况下可能出现的原因

①流量不足，可联系销售助理协助充值流量或者使用无线热点来连接

②域名失效，检查服务器的VPN（本地服务器情况）或者检查云服务器是否出现异常

使用本地wifi连接本地服务器可能出现情况

①WIFI网络差，请检查无线网络

②连接的WIFI无法连接服务器，请检查无线网络
