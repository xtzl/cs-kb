# 应用场景

用于兑换礼品券商品。

# 操作步骤

操作路径：登录游乐宝收银台——商品——兑换商品——礼品券兑换——扫描券码——查询——核销。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b8160865473ed&type=max)

# 注意事项
1.核销的礼品券不支持小票打印。

2.核销后的订单，不支持退货。
