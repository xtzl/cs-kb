设置导购提成模式

��应用场景

导购模式支持【按比例提成】和【固定提成】

注意：更改提成方式，已配置的导购商品提成金额会被清空，需重新配置；不影响已销售的导购订单与提成数据

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea20f35e27a8&type=med)

门店商品能直接设置导购固定提成，开启后，可在商品详情设置提成

提示：必须要开启【固定提成】模式
