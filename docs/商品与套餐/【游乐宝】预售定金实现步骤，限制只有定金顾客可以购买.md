# 业务场景：

双十一前夕预付50元定金，双11当天付450元尾款，可购1600游戏币

# 实现步骤

第一步： 新增50元押金商品
路径: 后台--商品--商品管理--新增零售商品--库存控制设置为虚拟商品，售价设置为50元

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f18fbceb9001e&type=max)

第二步：新增预售活动套餐
路径：后台--商品--商品管理--新增--游戏币套餐--套餐售价设置为450元（活动价格减去押金的价格）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f1904ea9e002e&type=max)

第三步：新增限购促销优惠券

路径：后台--营销--商品促销--新增限购促销-促销方式凭券--添加对应预售套餐--立即审核

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f1977eea801ef&type=max)

第四步：设置充值赠送

路径：后台--营销--充值赠送--选择对应定金套餐--勾选赠送对应优惠券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f197e4d03020f&type=max)

注意事项：点击添加时需要选择定金套餐，添加优惠券时需要选择对应预售套餐的优惠券

## 常见问题

1》顾客支付定金后，不想要了需要退款怎么处理
答：收银台--订单--订单管理--找到对应订单点击退货
2》顾客支付定金后并且已经购买了预售套餐怎么处理
答:收银台-订单--订单管理--先退顾客的预售套餐订单，再退定金套餐订单
3》如果需要顾客可以自己再小程序购买怎么操作

答：后台--线上--盈客宝管理--商品资料管理--发布定金套餐和对应预售活动套餐
