# 业务场景：

五一前夕购买套餐，五一当天发货。

# 实现步骤
第一步：新增活动套餐（根据自身需求提前设置好对应的套餐）。

注意事项：因为是预售，先付款后发货，所以对应的预售套餐需要是上架状态，并且后台的下架时间需要包含发货时间，所以下架日期需要选择到5月1号。如果不想预售套餐显示在收银台，可以限制一下售卖终端

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbeb0efac4ff1&type=max)

第二步：将预售套餐上架小程序

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbeb4cc755008&type=max)

### 注意事项：

发布上架小程序时，套餐需要是上架状态，如果您的门店计划预售套餐只在预售期间能购买，发货期间不进行售卖，您小程序套餐上架时，下架日期就截止到付款的最后一天(4月30号)，如果发货当天也能购买那下架日期就截止到发货日期（5月1号）

第三步：预售活动设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbebaf0925017&type=max)

1）新增预售活动，填写活动名称，选择对应的预售规则和

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbebefa6a5024&type=max)

### 注意事项：

设置预售活动的时候要先核实确认好预售活动的开始时间，结束时间和套餐发货时间（如果是充值类的套餐，例如游戏币，门票，预存款等，发货后才会到顾客的会员账户）一旦设置后不能修改的，只能结束活动重新设置

2）选择预售套餐，填写预售价格，预售的总数量以及每个顾客可以购买的数量

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbec7d5005038&type=max)

### 注意事项：

Q1：预付定金模式下，顾客支付定金后不想要了怎么处理？

A1：预售活动点开对应的活动概况，找到对应的订单，退定金，退定金前需要确认一下当天小程序有大于定金金额的总收款（确认收款账户有足够的余额），才能发起，不然退定金会失败，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbecf2672504e&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019dbece28e65042&type=max)

Q2：预售套餐发货后，顾客因为特殊情况不想要了怎么退款？

A2：和普通小程序订单一样，登陆收银台，在订单--订单查询找到对应订单发起退单，退单前需要确认一下当天小程序有大于这笔订单金额的总收款（确认收款账户有足够的余额），才能发起，不然会因为账户余额不足退款失败
