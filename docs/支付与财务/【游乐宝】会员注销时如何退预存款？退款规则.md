# 会员注销时如何退预存款？

## 前提：先设置好会员预存款退款比例
路径：
1》后台--会员--会员级别--注销退款系数

步骤：

1》填写退款系数保存即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179cd5bc4c23b30&type=max)

注意： 退款系数只能填写1~0，填写1是原价退，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179cd5d73bb3b32&type=max)

## 退预存款

路径：

1）会员--编辑资料--退预存款

2）会员--编辑资料--注销

步骤：

1) 第一种：点击退预存款，选择退款方式点击退款，这种适用于客户只是退预存款，而不是注销

注意：对于退预存款金额有疑问的可以点击退款说明

退款说明

支持微信、支付宝的原路退款

1.后进先出。当退款涉及到多个充值预存款的订单时，优先退最近时间的订单，按订单时间依次退款，一直到将余额退完

2.原路退回。原订单支付方式为微信、支付宝时可原路退回（1年内支付的），不满足原路退回条件统一补退现金

3.退款金额计算
应退金额=退预存款数X注销退款系数（注销退款系数可在“会员级别”的设置中进行变更）

举例：某会员充值100元，获得120预存款，消费后剩余52预存款，此时要将余额退款，则：应退金额=退预存款数X注销退款系数=52X0.8=41.60元

4.退款对账。退款账单在其他支出显示，一笔退款申请从多笔订单退款时，将记录多笔支出。

注：卡押金也支持原路退款，且只能查找入会套餐订单进行原路退款，如果不适用则以补退现金方式退卡押金

2) 第二种：确认一下退款金额，点退卡即可，这种适用于客户需要注销会员卡，并且这个退卡金额是支持手动修改的

退款方式：
现金退款：就是系统只是做一个退款的支出，实际需要自己手动给会员转账
原路退回：如果客户是支付宝付款，就直接退回当时这笔预存款的付款账号，这个和系统后台的设置有关
