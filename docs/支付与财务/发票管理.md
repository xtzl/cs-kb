**场景介绍：**

支持会员进行操作开票，顾客在购买订单后，有以下两种方式进行开发票

1）收银台 - 小票下方开票二维码

2）小程序 -  开发票 功能

:::color2
需注意：开票功能必须要开通盈客宝小程序

:::

业务系统支持版本≥**10.4.3199**



如何使用：

1）进入门店后台，设置发票相关秘钥

获取秘钥：开通发票渠道，请先完成银联/诺诺商户进件（已有账户的可直接设置，未有账户请联系助理协助进件）；

在线开票起算时间：可通过起算时间控制哪些订单能开票；

<font style="color:#DF2A3F;">配置完成后重启门店服务</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1781602457420-133e0600-6082-4b0f-80fe-2aa9a1eb8ac1.png)



**2）业务分类子级中添加商品的税率、税收编码**

a）业务分类需展开至最后一级，维护填写税率和税收编码（税率和税收编码需由各品牌财务提供并确认）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1781609462712-c1dc867c-642b-403f-9c49-a6572be6cd40.png)

b)商品选择对应业务分类
