# 应用场景
当门店需要同一个订单下需要现金+微信/支付宝的混合两种以上的支付，或者其他两种不同的支付类型混合完成一个订单的支付时，系统需要开启混合支付功能才能支持该功能。

# 操作流程
路径：设备→系统设置→混合支付开关

#### 进入【混合支付开关】的功能，将【是否支持混合支付】的开关开起来，点击【提交】完成功能开启。
