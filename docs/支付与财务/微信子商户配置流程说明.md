# 一、说明

如果客户已经申请了微信子商户，可以通过下述流程进行配置。

# 二、准备工作

1.需要客户已经完成子商户申请流程，并从客户经理中获取到子商户编号，如果未申请完毕可联系客户经理协助开通

2.需要微信的管理员在现场，需要管理员扫码登录。

# 三、操作步骤

### 1.打开油菜花系统，找到【支付方式】，需要新增两个支付方式，其中【支付类型】需要选择【微信付款码支付】支付和【微信扫一扫支付】，且是否实点选择【否】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801d10fcb40a19&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801d114ac40a1a&type=max)

### 2.新增完支付方式后，设置一栏应该显示【设置（证书未导）】，点击进去，选择【微信VIP支付】并填入油菜花客户经理提供的【商户编号】，点击更新证书秘钥，然后点击确定即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801d1427ad0a1b&type=max)

# 四、测试步骤

在前台设置一个套餐，通过微信扫码支付后，看看付款是否成功、客户账户上是否有收款记录，然后测试退订单检查是否能正常退即可
