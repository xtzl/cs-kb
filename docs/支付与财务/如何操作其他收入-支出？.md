# 应用场景
当门店产生了一些类似卖废收入或者活动需要在花费一定的费用时，且想将这类的收入和支出都记录在系统，则可以通过录入其他收入或者其他支出的方式进行录入。

# 操作流程
路径：财务→其他收支

#### 在【其他收支】界面中，选择【新增收入】或者【新增支出】，在新增界面中，按照内容填写收入的明细，点击【保存】完成设置
