# 应用场景
预存款系统储值的一个种类，该储值与现金保持一致，可以用于支付使用，所以当需要使用预存款支付时，就需要设置一个预存款的支付方式。

# 操作流程
路径：财务→支付方式设置

#### 进入【支付方式设置】界面，选择【新增】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270021948-b29b600c-fe4f-4956-941a-e977da332ada.png?x-oss-process=image%2Fformat%2Cwebp%2Fresize%2Cw_750%2Climit_0)

#### 在【支付类型】选择预存款，并填写对应的支付名称，点击【确定】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270314689-b7167427-13d6-4d68-bf9e-2bbaf406cb4d.png)
