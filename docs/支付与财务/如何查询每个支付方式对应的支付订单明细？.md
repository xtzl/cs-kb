# 应用场景
查询每个支付方式对应支付订单明细，或者该支付方式总营收



# 操作流程
路径：财务--支付订单查询--选择支付方式查询

**点击财务，在支付订单界面中，输入筛选条件，点击查询，查询每个支付方式对应的订单明细**
