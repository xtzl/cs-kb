# 🔴如何安装
#### 收到货后，请按以下文档操作（注意，游乐宝/芸苔/娱乐管家均可使用，不需要配置）
:::info
🔴注意事项：

1，为让门店的引流效果更好， 门店可按以下步骤绑定员工的支付宝账号，当顾客使用支付宝“碰一下”支付时，就能获得相应的返佣。（也可以绑定老板或店长的支付宝账号，但建议绑定收银员支付宝账号，这样可以提升推广效果）

2，注意：收银返佣需要每天在设备上扫码绑定，因为每天凌晨会自动清空绑定信息。

3，门店收到设备后，按以下步骤“注册”设备后，还需要用支付宝“碰一下”支付一笔大于1元的订单才算完成“激活"

:::
