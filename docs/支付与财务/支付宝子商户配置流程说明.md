# 一、说明

如果客户已经申请了支付宝子商户，可以通过下述流程进行配置。

# 二、准备工作

1.需要客户已经完成子商户申请流程，如果未申请完毕可联系客户经理协助开通

2.需要支付宝的管理员在现场，需要管理员扫码登录。

# 三、操作说明

### 1.打开油菜花系统，找到【支付方式】，需要新增两个支付方式，其中【支付类型】需要选择【支付宝付款码支付】支付和【支付宝扫一扫支付】，且是否实点选择【否】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801cfa1c2309e7&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801cfaa0a409e9&type=max)

### 2.新增完支付方式后，设置一栏应该显示【设置（密钥未设）】，点击进去，选择【支付宝VIP支付】，再点击【查看APPID】如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801cfd798609eb&type=max)

### 3.让客户的支付宝管理员扫码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801cfe2c7b09ec&type=max)

### 4.登录后，如下图所示，点击下图中所显示的【企业】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e72735ade0175e37524356849&type=max)

### 5.点击【产品中心】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e72735ade0175e37549a0684a&type=max)

### 6.检查此位置是否已经有待处理的信息，如有，则需要签约，如没有则已经签约完毕，可以跳到第8步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e72735ade0175e375762e684e&type=max)

### 7.点击【签署协议】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e72735ade0175e3757e5c684f&type=max)

### 8.点击【账号中心】找到【APPID绑定】，然后就可以找到对应的APPID了，将APPID填入系统，然后填写到系统的APPID一栏中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801cf40cce09e2&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e46101801d040d5d09f1&type=max)

### 9.点击【支付宝授权】，会提示授权到XXXX商家中，直接【授权】即可，无需理会商家名称。

### 10.点击更新证书秘钥，此时支付宝授权令牌有显示则代表配置已经成功。

# 四、测试步骤

在前台设置一个套餐，通过支付宝扫码支付后，看看付款是否成功、客户账户上是否有收款记录，然后测试退订单检查是否能正常退即可
