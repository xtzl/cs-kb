# 🤗应用场景
目前系统仅支持汇付和支付宝、微信原生支付方式，但部分商家与富友有合作，因此新增支持富友支付方式。不管在收银台还是小程序都可以根据商家需要自行配置富友的支付宝、微信支付。



# 🧐如何设置？
1）收银支持富友支付

①娱乐管家后台 - 财务 - 基础设置 -支付方式设置 ，点击【新增】按钮![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716344062450-c014c291-10d7-4c2b-b31d-701c8c2ba95f.png)



②创建支付方式，并根据您的需要选择对应的支付类型；点击【确定】保存支付方式

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716344171718-3f218f3b-f85c-4438-9e3e-b9a41b138036.png)



③创建完后，点击【设置秘钥】；

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716344255276-7cd50cac-8bf1-4915-914a-ef4dbb153282.png)



④填写对应的商户号、秘钥、前缀，点击【确定】即可；

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716344360659-aeccb92c-cbdb-447a-8e8b-600bd96fd373.png)



2）小程序支持富友支付

①运维后台 - 业务管理- 平台商家管理 ，点击【编辑】按钮

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716367160226-d3d7a5e0-a205-4158-8fb4-fe7672867b29.png)



②选择小程序支付通道选择【富友】，并填写【微信appid】【支付宝appid】【商户号】【前缀】【秘钥】；点击保存即可

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716367382768-151c9f46-629a-48f9-b8bb-c7b53fbcf159.png)



3）富友作业后台配置

登录富友作业后台（8.fuioupay.com），进入页面；根据对应的门店商户信息，点击【添加appid】把微信小程序appid配置上去

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1716874859729-ae8e3129-5caf-4929-84c3-7437a45811c5.png)



# 🧐常见问题
问：去哪里获取【微信appid】【支付宝appid】【商户号】【前缀】【秘钥】信息？

答：微信、支付appid请到微信、支付宝后台注册认证小程序，注册后会有对应的appid信息；富友的商户号、订单前缀、秘钥信息请联系富友相关工作人员获取；



问：同时配置汇付、富友、支付宝/微信原生支付，系统会怎么处理呢？

<font style="color:rgb(51, 51, 51);">同时存在多个</font>**<font style="color:rgb(51, 51, 51);">启用</font>**<font style="color:rgb(51, 51, 51);">支付方式时，将按 </font>**<font style="color:rgb(51, 51, 51);">汇付＞富友＞微信/支付宝 </font>**<font style="color:rgb(51, 51, 51);">的顺序自动切换到最优先的支付方式；（小微收款不受限制）</font>
