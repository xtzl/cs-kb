如何设置过了0点售卖的订单数据显示在新账期？

应用场景

当门店需要设置过了0点售卖的订单数据显示在新账期，可以按照以下操作进行设置

操作流程

路径：设置→系统设置→每天0点自动追加账期

在【每天0点自动追加账期】界面中，将【门店自动追加账期】开关开启后，点击【保存】
