# 应用场景

收银员可以使用此功能填写其它支出金额。

# 操作步骤

操作路径：收银台——交账——其它支出——选择支出分类——输入支出金额——支付方式——填写备注——保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b207cc9f258cf&type=max)

# 注意事项

其它支出填写错误可以到后台修改。也可在后台新增其它支出。
