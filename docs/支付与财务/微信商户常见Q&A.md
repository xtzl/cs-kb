# 一个场地可以申请多少个微信子商户？

目前一个营业执照可申请多个微信子商户，暂时没有上限

# 可以不申请你们的微信子商户吗？

如果你场地这边需要开通盈客宝小程序，则必须开通油菜花的微信子商户；如果不需要开通盈客宝小程序，则可以使用你们自己申请的微信支付帐号

# 假设我想两个场地共用一个微信支付帐户可以吗？可以区分开不同场地的收款金额吗？

可以多个场地使用同个微信支付子帐户，但并不建议这样做，因为无法区分不同场地的收款信息，在财务对账的时候会比较麻烦

# 向油菜花申请微信子商户跟在微信官网申请的有什么区别？

从使用场景上，两者并没有实质性的差别，安全性也是一样的。两者最大的差别是费率的差别：官网的是0.6%，而油菜花子商户申请的费率是0.38%，为什么向油菜花申请的子商户费率会便宜一些呢？

# 申请微信支付时，能否用私人的银行卡号收钱？

如果申请时用的营业执照是个体户性质，则可使用法人的私人银行卡（只可以用法人的哦）；如果申请时营业执照是公司性质的，则只能用对公帐户

# 如果顾客退款，手续费会不会退？

退款不收取手续费，具体情况如下：

1）未结算资金退款，手续费是轧差计算，从未结算交易款扣除后再计算商户应缴手续费。

例如，未结算资金是100，申请退款金额是50，次日结算50元时，微信支付平台仅针对这50元的交易资金收取手续费。

2）可用余额退款；新资金流商户已结算订单的退款，微信仅扣除商户应该承担的退款金额，前期已收取的手续费，按比例直接返给用户。

例如，原订单金额是100元，申请退款50元，商户费率为0.6%，微信支付平台从商户对应的可用余额、或基本户中扣除49.7元，加上微信返还0.3元手续费一起，直接退给用户50元。
