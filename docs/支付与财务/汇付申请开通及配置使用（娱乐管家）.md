# 一，汇付与VIP支付有什么区别？

### 相比我们之前的微信和支付宝VIP支付，开通汇付的优势是：

- 可以绑定任何人的银行卡号进行收款（一个门店只能绑定一个人一张卡），但目前只能用于线下收银的场景，例如线下收银台，自助设备，闸机，POS机等（ 盈客宝小程序不支持用汇付，仍只能绑定法人银行卡或公司帐户收款 )

- 目前支持的油菜花硬件 ：收银台，闸机（含付款码过闸），自助设备，卡头（含散客正扫反扫），pos机

- 费率同样是 0.38%

- T+1到帐 （工作日+1到帐，周末或节假日顺延）

- 同样支持 微信和支付宝

- 开通后 不影响 现有系统的任何功能（如果系统里原来已经配置了VIP支付，会自动切换成汇付。

-------------------------------------------------------------------

1， 汇付是D+1，即不分交易日还是节假日的第二天到账
2，汇付是有支付牌照的第三方支付平台，是否有风险请客户自行评估
