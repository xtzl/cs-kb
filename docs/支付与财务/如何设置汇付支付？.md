# 应用场景
汇付属于支付方式的一种，如果已经开通了汇付账号，可以通过下述操作在系统中进行配置。

# 操作流程
路径：财务→支付方式设置

#### 在【支付方式设置】的界面中，点击【新增】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270021948-b29b600c-fe4f-4956-941a-e977da332ada.png)

#### 【支付类型】选择“微信支付-汇付”
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270060609-8541d9e8-6189-4614-ba17-b03babfa0d0c.png)

#### 其他支付内容按实际情况填写即可，点击【确定】完成新增。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270110681-a166cd70-3c1f-43e6-aca1-5e39537e333c.png)

#### 同样的方式，新增多一个支付方式用于支付宝支付，【支付类型】选择“支付宝-汇付”
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270078695-ae350070-ce99-4a23-beed-761e0e5503d3.png)

#### 其他支付内容按实际情况填写即可，点击【确定】完成新增。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270145473-f5d08b18-c89b-4047-a5aa-8284baa5514b.png)

#### 点击支付方式右边的设置，进入到设置界面，将油菜花销售助理提供的appid和apiket填入下列设置中，点【更新证书秘钥】，然后再点【确定】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718270191870-25f87bbf-4213-4d6b-b883-fddcd453f89f.png)
