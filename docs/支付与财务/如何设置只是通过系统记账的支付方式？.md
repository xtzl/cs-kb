# 应用场景
当门店有使用类似收款码一类无法对接到系统的收款方式时，可在系统中新增对应的支付方式作为记账使用。

# 操作流程
路径：财务→支付方式设置

#### 在【支付方式设置】中，点击新增
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717832303768-b3a059df-0ba5-41c7-af0f-8f6f2d9bd1b3.png)

#### 在【支付类型】中，选择“其他”，并按下图信息填写该支付方式的基本内容，点击【保存】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717832515641-99e30198-3049-49d9-ba20-300ec925a54e.png)
