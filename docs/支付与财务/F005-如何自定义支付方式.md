# 操作路径

后台--财务--财务管理--支付方式

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad1394dbc4417&type=max)

# 操作步骤

- 点击财务

- 点击财务管理

- 点击支付方式

- 点击新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad13ad9fa4418&type=max)

# 注意事项

- 选中一条记录点击界面上的编辑按钮或者点击支付名称链接进入编辑支付方式界面

- 修改需要修改的信息（修改信息和新增信息一样限制名称不能重复

- 修改完后点击保存按钮完成修改，客户端刷新后显示最新的支付方式
