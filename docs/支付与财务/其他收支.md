# 🔴报表说明
此报表用于查询通过其他收入和其他支出录入的收款或付款的明细数据和合计数据，并可用于查询通过强制退票、退预存款、退预售定金和注销卡押金的支出情况查询。

# 🔴报表样式
路径：后台→财务→订单对账→其它收支
