# 🔴报表说明
此报表用于总部人员对门店微信支付、支付宝支付订单对账核对使用，该报表会同步微信支付和支付宝支付平台的订单号并与系统订单号匹配，以此来进行自动对账。

# 🔴报表样式
路径：总部后台→报表→营业查询→支付对账
