如何设置汇付支付？

应用场景

汇付属于支付方式的一种，如果已经开通了汇付账号，可以通过下述操作在系统中进行配置。

操作流程

路径：财务→支付方式设置

1. 在【支付方式设置】的界面中，点击【新增】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea8131723bd5&type=med)

2. 【支付类型】选择“微信支付-汇付”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea8131763bd6&type=med)

3. 其他支付内容按实际情况填写即可，点击【确定】完成新增。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea81317a3bd7&type=med)

4. 同样的方式，新增多一个支付方式用于支付宝支付，【支付类型】选择“支付宝-汇付”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea81317e3bd8&type=med)

5. 其他支付内容按实际情况填写即可，点击【确定】完成新增。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea8131823bd9&type=med)

6. 点击支付方式右边的设置，进入到设置界面，将油菜花销售助理提供的appid和apiket填入下列设置中，点【更新证书秘钥】，然后再点【确定】完成设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea8131863bda&type=med)
