# 应用场景
如果门店有其他类型的收入或者支出需要录入系统，此时我们可以在系统中预设值好对应的收入分类和支出分类，方便我们后续对这一类的收入和支出进行统计。

# 操作流程
路径：财务→收支分类设置

#### 在【收支分类设置】界面中，点击新增，按照下图中的字段进行设置填写，并【保存】完成新增。
