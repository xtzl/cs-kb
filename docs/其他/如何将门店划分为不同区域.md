# 应用场景
当门店需要使用漫游，且漫游时，想要自定义编辑哪些门店和那些门店可以漫游，此时我们可以通过将想要漫游的门店划分成统一区域，并将漫游设置中的漫游范围改成按区域漫游，即可达到此效果。以下教程为将门店划分区域的操作流程。

# 操作流程
路径：登录总部后台→总部→区域管理

点击![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721614414381-b650a185-2093-40e8-b202-777bb8c4adf4.png)，选择【新增区域】，并编辑区域名称，点击保存，完成新增。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293213095-83dd00c8-b4e7-478f-90f9-1386b399a901.png)

选择对应的区域，可以在可选门店中点击![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721614474184-9ef9dd5a-e791-42f0-b6df-fe1d343db0fa.png)将门店放置到已选门店，并点击【保存】完成设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293266000-b5527c6e-64a3-4679-8b0f-e345817d462a.png)
