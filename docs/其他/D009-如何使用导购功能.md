# 操作路径

后台--商品--导购

# 操作步骤

- 点击商品

- 点击导购

# 注意事项
可批量导入系统设置用户、也可以自由另外增加导购员信息（导购员编号系统唯一，不可编辑，删除），禁用导购员，不会计算提成。
