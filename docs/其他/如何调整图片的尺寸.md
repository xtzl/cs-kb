# 场景说明

在盈客宝的设置中，你会看到下面这些需要上传图片的地方对图片的尺寸和大小是有要求的，如果没按要求可能会图片上传不成功，或上传的图片变形影响页面的美观，这个时候可参考下面的方法调整图片的尺寸或大小

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180ccea989e0f45&type=max)

# 操作方法

### 第1步

用电脑浏览器打开：https://www.gaoding.com/image

### 第2步

先点击右上角，注册一个帐号或微信扫码登陆，再上传你的图片，如下图

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180cceecc500f4b&type=max)

### 第3步

点击左侧边栏的“调整”，找到尺寸调整，输入你要调整的尺寸，最后点击“下载”即可，如下图

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180ccf222e80f4e&type=max)

# 注意事项

调整后，你的图片可能会被裁剪，导致一部分区域看不到，如下图，你们看到通过鼠标拖动可以调整图片的可视区域

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180ccf8becb0f53&type=max)
