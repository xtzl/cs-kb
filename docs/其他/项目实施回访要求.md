# 回访说明

实施完毕后，需要在【项目实施回访群】群通知销售助理回访

需要执行以下两个工作：

# 1.在【项目实施回访群】按照以下格式发送回访信息

通知格式如下：

XXXXX门店（门店名称），已完成实施任务，回访人：xxx（客户项目负责人） 电话号码，@销售助理 请回访

未完成工作如下：XXXXXX

实施时间：几月几日~几月几日，实施天数共xx天

并附上现场图片：

1.必拍照片: 门头, 收银台, 油菜花各个硬件产品(本次安装的各个产品)

2.不要拍摄: 一些出币相关的设备

3.建议拍摄: 现场活动物料, 现场开业套餐, 现场客流照片

4.线上功能确认内容截图，如无此截图 可联系梁建宁查询 或者重新打开验收单勾选后截图也可以

案例如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e98a35afd1929&type=max)

# 2.电话联系销售助理联系客户进行回访。

注意事项：

① 如果回访时间超过晚上10点，则可不需要等待助理回访后才离场，但是需要客户负责人在对应的企微群发送：“已安装培训完毕，同意技术离场”。助理第二天补充回访即可。

②如果联系不上对应的销售助理进行回访时，请联系黄洁惠进行回访，联系电话：17727669425

# 处罚细则

如未完成回访直接离开现场，按《油菜花现场实施处罚条例》中”未完成回访要求“进行处罚，一次处罚为200元。
