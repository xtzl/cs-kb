# 应用场景
游乐项目一经创建，无法删除，只能禁用游乐项目，不影响其他端口正常使用，对以往数据无影响

# 操作流程
路径：终端--游乐项目--点击项目对应端口，点击编辑端口状态为禁用

**点击终端，在游乐项目中，查找游乐项目，点击对应端口**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772159185899-1fd00dc1-d158-452a-86e3-24714edbfa5f.png)
