第一步：安装流量卡，使用WIFI连接的可忽略此步骤，视频可从50秒开始观看
第二步：开机激活，开机后需先连接 WIFI 或 手机热点，激活成功后再关闭 WIFI 或 手机热点，使用流量

第三步：打开油菜花软件，先输入服务器地址，再输入账号密码登录即可使用
