# 应用场景
系统支持短信推送功能，在使用短信推送前，需要进行短息推送配置，配置信息请联系油菜花销售助理获取。以下为配置教程。

# 操作流程
路径：登录总部后台→终端→短信平台设置

打开配置界面，根据获取参数进行填写，填写后先点【保存】，然后再点击【获取】，如果能正常获取短信条数则代表配置成功
