# 应用场景
可在系统后台录入商品供应商资料，方便后续做流水记账使用

# 操作流程
总部后台-->采购-->供应商设置-->新增完善供应商资料

1.进入系统后台【供应商设置】路径，点击【新增】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547336655-d200ba6e-532d-4843-a298-636764387a18.png)

2.在弹窗界面完善供应商资料

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547386468-3a6321f9-595e-45f8-84f3-8bccf5851589.png)

3.若有需要也可在此处关联员工账号，一旦关联了，只有该员工账号可以登录后台查询到对应的分成明细，其他账号是看不到分成情况的。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721547469278-67de94e2-1fb3-48b0-8396-816d67d5b233.png)
