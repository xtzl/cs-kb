# 🧐如何设置？
:::info
**① 在总部配置供应商**

:::

**步骤：**

登录总部后台，进入【采购 - 设置 - 供应商设置】，新增以下信息

1）供应商：联营的供应商需要在供应商模块配置后才可查询出来；

2）关联员工：关联员工后，<u><font style="background-color:#FBF5CB;">该员工即可在【手机报表】中查看到联营项目的数据</font></u>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721887929177-f47a3f5b-26d3-48e4-afe4-a9d6d1b0a8a9.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721887981375-b4394e33-b853-4140-bf10-bde6971a97bd.png)



:::info
**② 配置分成比例**

:::

**步骤：**

登录**门店后台**进入【联营 -联营服务商设置】，选择刚才配置的供应商，并且选择对应的联营机台、提成比例，点击保存即可；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721888339967-4e24cde2-03d2-4de1-bee3-776dc1613312.png)



:::info
**③ 查看统计联营数据**

:::

**步骤：**

登录**门店后台**进入【联营 - 项目分成查询】，选择好对应的筛选条件后，点击查询即可查询到对应分成的数据；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721888697812-211be512-f3bd-422a-8ca1-0cf6e2025563.png)



# 😎常见问题
问：目前联营支持什么储值进行分成呢？

答：目前联营的机台仅支持代币、套票、现金支付后进行分成；**<font style="color:#000000;background-color:#CEF5F7;">预存款不支持分成</font>**，请注意调整项目支付方式；



问：联营项目怎么打款？

答：暂不支持线上转账，联营项目分成均走线下打款，场地自行与第三方结算；
