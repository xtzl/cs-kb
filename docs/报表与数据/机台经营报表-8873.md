# 🔴报表说明
机台经营报表可用于查询每个机台下消费明细，以机台为维度，显示对应机台的投币、出币、出彩票、出礼品、以及对应的出礼品比率等数据；当选择时间只是当天，则查询实时数据；当选择的时间跨度超过当天，则查询数据为日结后数据，当天数据不统计在内。
