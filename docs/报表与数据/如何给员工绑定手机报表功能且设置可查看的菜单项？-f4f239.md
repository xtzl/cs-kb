如何给员工绑定手机报表功能且设置可查看的菜单项？

应用场景

门店想让某员工通过手机报表查看门店数据，可给予员工设置手机报表功能，让员工可以查看该数据。

操作流程

路径：设置→手机报表绑定

1. 进入【手机报表绑定】界面，点击【用户绑定】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f772e272a&type=med)

2. 勾选哪位员工的账号需要开通手机报表，并点击【授权】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f7733272b&type=med)

3. 选择该员工可查询的门店，单店版请【全选】，并在右边【权限管理】中，勾选可查询的权限，点击【保存】完成授权。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f7737272c&type=med)

4. 选择对应员工账号中的【绑定微信】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f773d272d&type=med)

5. 等待出现二维码后，给予员工扫码授权即可。（注意，首次扫码可能会提示需要关注公众号，关注公众号后，再重复扫码即可完成绑定）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ea1f7741272e&type=med)
