# 应用场景
总部可对门店全年业绩目标进行规划，并制定相应的月度业绩指标及每日业绩指标。系统支持录入对应的指标并通过手机报表、首页报表等位置提醒门店完成情况，并可通过【年指标完成率】和【月指标完成率】查看门店的指标完成情况。

# 操作流程
路径：登录总部后台→总部→指标设置

在【指标设置】界面中，点击【日指标设置】即可进入指标设置界面

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293402034-09ebedc3-9325-495e-8530-4864a82825fb.png)

在【日指标管理】中，可以录入每日指标金额，或者通过导入形式导入也可以。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293421092-7d76c212-c4ed-43bc-8e90-3fe3caddd15f.png)

在【月指标管理】中，可以录入每月指标金额，或者通过导入形式导入也可以。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293437221-7aeebe96-d0d4-4909-b02a-dec772ee7ed1.png)

设置完成后，门店管理层可通过手机报表、系统首页可以查看到每日指标完成进度。
