# 🔴报表说明
此报表用于查询所有门店交账结账历史，可通过此报表查看出所有门店各项支付方式的差账情况。并支持按月汇总或者按操作人汇总。

# 🔴报表样式
路径：总部后台→报表→营业查询→结账历史查询
