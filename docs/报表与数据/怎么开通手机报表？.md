# 应用场景
如果想要在手机上能查看门店的经营情况，需要在手机上开通手机报表功能。

# 操作流程
路径：设置→手机报表设置

#### 进入【手机报表设置】，在【是否启用手机报表】功能中，选择启用，点击【保存并推送】完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718440098893-587f7b90-36f0-4dc2-8991-2e5cda985fc6.png)

#### 在手机报表绑定里面点击用户授权-选择需要授权的用户-点击授权-选择可查询的门店-点击保存，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719021828240-9a3298de-43f5-438a-8a2b-0d7aaeb9784a.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719021862990-f8d2f554-bc62-4eb5-9c8c-6d1baeeb212c.png)

#### 授权成功之后，点击绑定微信-用微信扫一扫扫描界面上面的二维码，进行帮忙手机报表，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719021905387-ec885f8e-54bf-4570-a54e-6c4793f007ad.png)
