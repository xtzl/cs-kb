# 应用场景
查看本月营收，或者筛选具体时间段内营收数据

# 操作流程
路径：财务--日结记录--选择账期--点击查询

**点击财务，在日结记录中，筛选具体账期时间，点击查询，可查看时间段内小程序、店内和第三方营收汇总**
