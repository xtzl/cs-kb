# 应用场景
本教程用于开通手机报表，并设置手机报表的推送内容。

# 操作流程
路径：登录总部后台→总部→手机报表设置

在【手机报表设置】中，在【手机报表开关】一栏选择启用，开启该功能，并按照下述的报表设置进行设置，最后点击【保存并推送】完成报表设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721293609633-b47d9237-a42f-4970-aafc-da0ff265ac37.png)

注意：游乐数据呈现选择不一样的业态会显示不一样的数据内容，请根据自身需要进行调整。
