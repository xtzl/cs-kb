# 🔴报表说明
套票分摊用于计算机台耗票营收，为【确认收入报表】提供各个游乐项目的耗票数据。而此报表用于查询每个项目分摊的汇总情况，内容为分摊明细记录、按项目汇总和按套票汇总数据。需要查询时可通过此业务查询。
