# 应用场景
门店想让某员工通过手机报表查看门店数据，可给予员工设置手机报表功能，让员工可以查看该数据。

# 操作流程
路径：设置→手机报表绑定

#### 进入【手机报表绑定】界面，点击【用户绑定】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816388443-884f23a3-98a8-4e13-afce-31903f488d6b.png)

#### 勾选哪位员工的账号需要开通手机报表，并点击【授权】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816410096-41955892-7732-4192-8a7b-e2934380d1dd.png)

#### 选择该员工可查询的门店，单店版请【全选】，并在右边【权限管理】中，勾选可查询的权限，点击【保存】完成授权。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816449618-3396b448-8e6c-4517-a9bc-556410dbb077.png)

#### 选择对应员工账号中的【绑定微信】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816666815-7ade706d-1462-48cb-8727-8626e10cd918.png)

#### 等待出现二维码后，给予员工扫码授权即可。（注意，首次扫码可能会提示需要关注公众号，关注公众号后，再重复扫码即可完成绑定）
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816688197-99b19bb7-c077-49ff-b5a6-8cf245745fd3.png)
