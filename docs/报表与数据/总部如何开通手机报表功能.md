# 应用场景
新版娱乐管家总部版，如果想要在手机上能查看门店的经营情况，需要在手机上开通手机报表功能。

# 操作流程
路径：总部→手机报表设置

#### 进入【手机报表设置】，在【是否启用手机报表】功能中，选择启用，点击【提交】完成设置。
<font style="color:#2F4BDA;">消息推送设置：</font><font style="color:#000000;">可设置营收数据具体的推送时间</font>

<font style="color:#2F4BDA;">游乐数据呈现：</font><font style="color:#000000;">根据门店业态（电玩或票务）的不同，作不同的数据呈现</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725263909638-4efda640-0e90-4dfd-a1c8-2184a97a9732.png)

#### 在手机报表绑定里面点击用户授权
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725264226628-2baac4e8-808b-40b0-b721-c7a284dea243.png)

3.在弹窗界面添加要关联绑定的后台账号，在搜索栏输入已知的后台账号信息，点击【查询】并作授权

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725264509501-932c7937-eb64-46fd-8a8a-5d3a8390037f.png)

4.在授权界面，选择可查看到的数据报表所属门店，并勾选手机报表所显示的菜单，点击【确定】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725264667910-91762a0b-d2c0-4778-b895-746fbb8b0891.png)

5.查询所新增的授权账号信息，点击【绑定微信】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725264843640-71fc30b6-4d87-415c-ab63-d89fe4466b2f.png)

6.【绑定微信】弹窗如图所示，打开微信小程序，用小程序进行扫码绑定

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725264895703-0b4980cd-6582-47e3-978c-46d4c55d5e92.png)

7.扫码绑定成功后，可跳转到【油菜花信息科技公众号】，进行查看：

<font style="color:#DF2A3F;">若提示绑定成功，</font>则可点击【查看手机报表】，跳转到当日门店手机报表界面；

<font style="color:#DF2A3F;">若该微信号已绑定过手机报表，</font>则会提示已经当前商城已绑定

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725265196366-1b12a2ac-860e-467f-873a-eb0ff79ed26b.png)

**游乐掌柜手机报表展示：**

公众号消息推送界面如下：

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1725265582893-ab8303a2-8598-4ff4-8a25-15e2de956a86.png)

可点击查看详情跳到游乐掌柜手机报表界面
