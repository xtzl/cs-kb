# 一、 文档说明

本教程主要围绕如何下载娱乐管家安装包及升级包的操作来展开说明。此步骤为安装服务器前置步骤，需要先把对应的安装包下载完毕后再执行安装服务器的步骤。本教程仅适合于娱乐管家连锁商城安装下载安装包使用。

# 二、 准备工作

## 1、 FTP下载工具

下载链接： https://nos-pulic.nos-eastchina1.126.net/%E5%AE%9E%E6%96%BD%E7%BB%84/FTP%E4%B8%8B%E8%BD%BD%E5%99%A8.rar

## 2、 需要确认现有总部版本的版本号是多少

可先通过网页打开总部系统，在登录界面可看到对应的版本号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193af6e2123674c&type=med)

# 三、 注意事项

1. FTP下载工具属于内部机密工具，请注意不能外泄。

2. 和其他版本所需要的安装方式不一样，连锁门店仅需要直接下载总部对应的安装包，无需下载升级包。

# 四、 作业步骤

1. 打开FTP下载工具，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac799e1e03cfb&type=max)

2. 点击连接，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79aa5ec3cfd&type=max)

3. 选择快速连接

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79acf8c3cfe&type=max)

4. 选择历史记录，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79aef393cff&type=max)

5. 点击连接，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79b1a703d00&type=max)

6. 连接完毕后，如下图显示云盘目录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79b3b463d01&type=max)

7. 选择【安装包】，然后选择【大客户新版UI】(10.3.6以上版本）或者【大客户版】（10.3.5以下版本），总部对应版本的安装包，如总部使用的是10.3.1098，则只需要下载这个版本的安装包即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193af6d0c5b6747&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193af6c79c06746&type=max)

8. 左边选择你安装包的下载路径，选择后，直接把安装包拖动到左下方空白地方即可，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79fa6613d03&type=max)

9. 点击开始下载，即开始下载安装包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac79fd5603d04&type=max)
