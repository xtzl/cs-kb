# 现象

后台无法打开，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f8dde8604264c&type=max)

# 原因

仅安装了基础安装包，并且使用的是10.4.3001的安装包

# 解决方法

手动升级目前最新的版本即可，下次想避免可用10.4.2001安装包进行安装，则不会出现类似问题
