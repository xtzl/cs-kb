# 问题描述：

用户在后台配置通用配置卡信息或服务器地址同步游智云时，提示：服务器地址推送到游智云失败，请联系管理员(999999)的报错

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0bd7f9d4d1fb7&type=max)

# 解决方案：

在服务器所在数据库，执行语句：

delete from mall_configset where mallconfig='207'

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0bd7d3dce1f78&type=max)

完成语句执行后，重启系统服务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0bd7e75561f88&type=max)
