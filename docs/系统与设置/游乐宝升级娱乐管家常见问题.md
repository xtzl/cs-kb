#

## 注: 此文档用于记录游乐宝使用工具升级娱乐管家所有的常见问题，便于后期进行查阅解答

问题1

场景：升级之后娱乐管家游戏币套餐里面没有看见游戏币相关的商品

解决：转到娱乐管家10.3.8 版本时，发现看不到代币套餐的，执行一下这个语句。（注意，迁移后立即执行， 如果娱乐管家后面用了限定币，就不能再执行了，门店和总部都需要执行）

update Game_CoinSetMeal set LimitCoinNumber = 0 where LimitCoinNumber is null

问题2

场景：娱乐管家系统查询升级当天的机台经营报表，游乐项目有重复情况

解决：不影响正常使用。因游乐宝和娱乐管家门店名称不一致导致游乐项目升级当天重复，升级之前需要将娱乐管家系统修改成和游乐宝系统一致的门店名称

问题3

场景：娱乐管家系统微信支付和支付宝支付提成缺少文件，不能正常支付

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192fa13edc23fe3&type=max)

解决：在娱乐管家系统后台--财务--支付方式--更新一下微信支付和支付宝支付

问题4

场景：抖音美团套餐核销完之后，系统不统计金额

解决：抖音美团套餐需要重新设置结算价格

问题5

场景：抖音美团套餐核销时提示终端限制

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192f629682039a7&type=max)

解决：在娱乐管家系统后台--线上--线上商品管理--找到对应的商品--将可售卖终端改成不限制

问题6

场景：闸机项目不能正常扣票，会显示查询

解决：闸机项目有一部分消费设置会变成0，查询模式。需要修改才能入闸。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019305457bb25b69&type=max)

问题7

场景：游乐宝升级娱乐管家系统使用同一个加密狗升级，微信小程序提示APl业务异常或存币机显示H10

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192fa1493af3fec&type=max)

解决：联系陈彦峰 高晓钦，梁建宁在微信小程序管理平台修改微信小程序所属平台

问题8

场景：收银台不能打印套票和小票

解决：收银终端中的打印小票没有勾选，导致出不了小票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019305436cdf5b5e&type=max)

问题9

场景：小火车等既出票又出币的特殊机台，升级之后出币和出票有异常

解决：特殊机台需要重新设置参数调试

问题10

场景：升级完之后，使用会员级别变更报错（未知异常：请求总部返回异常，返回数据：（999999））

解决：添加会员升降级策略

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019399e1468b2bb9&type=med)

问题11

场景：钻石V9/魔方V9娱乐版卡头升级后，刷卡不上币，原因为卡头升级版本后，需要调整白盒子的通讯方式

解决：按照下图切换一下拨码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019399e146922bba&type=med)

问题12

场景：小程序授权提示未知状态

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000196c24c89e8189f&type=max)

解决：本地服务器电脑安装G2证书

问题13

场景：升级工具升级时，提示有重复的键

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000196c251775218a6&type=max)

解决：登录游乐宝，批量做实界面，合并重复储值。合并储值之后在升级系统
