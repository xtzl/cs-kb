# 安装说明

## 1.运行环境安装

#### 情况一（2选1）：客户操作系统为windows server 2016 Standard/Datacenter 或者更高版本

只需要安装Vcredist_x64运行环境即可

安装教程：【Vcredist_x64运行环境安装说明】

#### 情况二（2选1）：客户操作系统为windows server 2012 R2 Standard/Datacenter或更低版本

需要安装以下运行环境
NET Framework 3.5

01-2-1NET Framework 3.5运行环境安装说明（windows 2008版本且需要安装SQL2008数据库时使用）

01-2-2 NET Framework 3.5运行环境安装说明（windows 2012版本且需要安装SQL2008数据库使用）

G2根证书安装

01-2-5 G2根证书安装（windows server 2008 系统专用，用于解决支付超时问题）

## 2.安装SQL数据库以及SSMS数据库（SQL2016专用）工具

#### 情况一（2选1）：客户操作系统为windows server 2016 Standard/Datacenter 或者更高版本

教程请看【SQL2016数据库(用于Windows server 2016标准版及以上使用）安装说明】

#### 情况二（2选1）：客户操作系统为windows server 2012 R2 Standard/Datacenter或更低版本

教程请看【SQL2008数据库(仅用于Windows server 2012 R2标准版及以下使用）安装说明】

用于小程序和域名功能的VPN，必要安装

【小程序VPN安装教程】

用于与总部系统数据同步的VPN，必要安装

【连锁VPN安装教程】

## 4.安装油菜花系统（常规情况）

说明：由于系统授权分网络授权和加密狗授权，两者区别为是否有实体加密狗，如果没有实体加密狗，则代表使用网络授权，否则则为加密狗授权。现在大多客户是不发加密狗的，所以大部分客户为网络授权安装系统。

如果娱乐管家总部版本高于10.3.6以上，则使用此教程

【娱乐管家（连锁门店）10.3.6以上版本服务端安装（网络授权）】【娱乐管家锁链（加密狗授权）】

如果娱乐管家总部版本低于10.3.5以下，则使用此教程

【娱乐管家（连锁门店）10.3.5以下版本服务端安装（网络授权）】
