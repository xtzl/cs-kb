# 一. 文档说明

本文档主要明确了云服务器上面安装游乐宝系统和娱乐管家单店版系统中的工作内容、作业准则、工作要求以及禁止事项，请所有实施相关人员务必认真阅读。

# 二. 安装注意事项

1.游乐宝系统部署在游乐宝云服务器中，娱乐管家单店版系统部署在大客户服务器中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192a355d3c80ce2&type=max)

2.云服务器不需要重新安装数据库，运维会提前安装好数据库

3.系统命名必须按照【门店编号-门店名称-业务端口】来命名；

4.数据库实例名称必须按要求进行修改，命名规则为YCHMALL门店编码

5.业务端口及机台端口按照要求修改，业务端口取值为9999-9980之间，机台端口取值范围为1099-1080之间

# 三. 安装流程操作

1. 填写安装备案文件，门店编号+门店名称+业务端口（业务端口范围9999-9980，一个云服务最多只能安装20家门店），服务器地址+业务端口号

说明：业务端口一般顺延减少，例如安装备案文件里上一个系统的登录地址为62660002-XF潮汕梦幻星球-9984-1084，则代表业务端口为9984，机台端口为1084，这时候就不能再使用同一个端口，一般会业务端口设置为9983，机台端口设置为1083；所以按这个规则命名新的门店的安装备案就是：“门店编号-油菜花门店名称-9983-1083”，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001929e4a027f050c&type=max)

2. 双击运行安装程序，修改安装路径，文件夹命名规则为：门店编号+门店名称+业务端口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192a359a04d0cf2&type=med)

3.弹出安装程序时，按F1弹出修改示例设置；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192a359a0560cf3&type=med)

4.填写完点击确定，重新授权并按照正常安装流程安装即可

5.安装成功之后需要修改Setting文件参数，将安装备案里面的参数复制

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192a356dd350ce4&type=max)

6.将新安装门店的Setting文件中的参数修改成复制的参数
