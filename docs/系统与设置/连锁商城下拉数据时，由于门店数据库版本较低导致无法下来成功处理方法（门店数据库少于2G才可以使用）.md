# 文档说明

此文档用于指引内部人员遇到连锁商城下拉数据时，由于门店数据库版本较低导致无法下来成功处理方法（门店数据库少于2G才可以使用）

# 操作步骤

1.正常门店下拉后等待出现报错为止，并记录时间

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7535a733d5&type=max)

2.打开云服务器总部，找到这个生成的门店数据库备份

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7628a333d9&type=max)

3.按照记录的时间，从总部文件夹中找到对应的数据库备份文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f76b95333db&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f77be8133dd&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7837cb33df&type=max)

4.将找到的数据库备份文件，还原出数据库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f79728a33e3&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7a8cbb33e7&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7afe3133e8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7c4e4a33eb&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7d888733ee&type=max)

5.右键选择还原出来的数据库，选择【任务】-【生成脚本】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7e839533f1&type=max)

6.按照引导生成脚本

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7ed94433f2&type=max)

7.生成脚本对象按下面来选择

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7f4aaa33f3&type=max)

8.在编写选项中的【高级】设置一下编写语言为SQL2008R2和编写内容为“架构与数据”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f7fa2a633f5&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f804c5e33f6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f80be3033f7&type=max)

9.选择脚本保存位置，保存。注意，保存时修改保存文件为YCHMALL+加密狗编号，方便记录。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f8a29993426&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f819e8633f9&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f81e91933fa&type=max)

10.点下一步生成脚本

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f82286133fc&type=max)

11.等待脚本生成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f831e393402&type=max)

12.将生成的脚步给到门店技术进行执行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001973f8382423403&type=max)
