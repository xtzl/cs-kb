# 一、 作业说明

本作业说明为游乐宝系统版本升级的操作说明。初次安装系统使用的是001结尾的版本，所以必须按照此步骤进行版本升级。

# 二、 作业准备

1. 预下载游乐宝升级包

下载游乐宝升级包工具，使用工具下载升级包

FTP下载工具下载链接如下：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/5.常用软件工具/实施组_FTP下载器.rar

2. 服务器已安装解压工具RAR，下载链接如下：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/5.常用软件工具/WINRAR解压工具.exe

3. 已安装完毕游乐宝服务端，服务端并在正常服务中。

# 三、 作业标准

1. 必须使用FTP可下载版本中的最新的升级包。（非必要）

2. 升级后，Log文件未提示有错误。

# 四、 作业步骤

方法一：（自动升级）

在服务器上登录后台，登录后提示版本更新时，点击立即升级，并按照提示自动下载版本并升级即可。

方法二：（手动升级）

1. 将升级包的压缩包解压缩，得到后缀为exe的应用程序。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7e5338e3e43&type=max)

2. 将应用程序放置在YCHMALL文件夹目录下，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7e551b43e44&type=max)

3. 双击升级包，点击升级，等待片刻，即可完成升级。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7e56e543e45&type=max)

五、 常见问题

1. 获取版本失败

原因：商城ID不匹配，主要是由于曾经还原过数据库，且数据库的商城ID和重新安装的商城ID不匹配导致。

解决方法：替换商城ID，具体替换方法请咨询研发。

2. 升级失败

原因1：服务端版本不符合升级包所支持的最低版本

解决方法：先通过旧升级包进行升级后，再使用最新升级包进行升级

原因2：数据库异常

解决方法：由于数据库异常原因很多，总体思路为先解决数据库异常问题再进行升级

原因3：服务器性能太低导致超时

解决方法：重复尝试，如果未能解决请更换服务器。

原因4：其他原因

解决方法：通过LOG日志来排查。

下一步：固定IP地址（如果已经固定IP则可以跳过）
