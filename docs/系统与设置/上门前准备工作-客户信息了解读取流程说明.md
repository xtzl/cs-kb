# 流程说明：

此流程对客户情况读取进行要求，一般由实施组组长提供客户基本信息，并按照流程要求读取出必要的信息要点。并制定行程。

最终目的如下：

1.快速了解客户基础情况，获取最基础的信息；

2.获取客户的安装特殊要求，避免造成安装失误。

3.提前制定行程准备出发

# 操作说明：

## 第一步：通过实施组组长获取订单基础信息

一般信息如下显示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e3bc44c187b00&type=max)

关键字段说明：

1.系统产品线：本次实施客户使用的是哪款产品；

2.门店服务器部署方式：本次实施是否需要安装本地服务器；

3.门店密码狗编号：门店编码代码；

4.门店名称：这个客户门店名称，用于填写在验收单和费用结算单（服务商）/费用报销单（本部技术）；

5.门店联系人：出发现场前需要联系的是哪个客户；

6.管理员账号交接给谁：admin最终归属权，上门实施完毕后需要将此账号交还给此人，并提醒修改其账号密码；

7.门店地址：本次上门实施的具体地址；

8.销售助理：本次实施完毕后需要通知哪位进行回访；

9.需要安装的产品清单：本次需要安装的硬件设备清单；技术需要根据清单提前准备工具；

10.约定实施天数：本次实施要求多少天完成；

11.约定上门日期：本次实施要求哪一天开始实施；

12.小程序是否离线申请：部署服务器后是否需要通知实施组负责人修改小程序配置；

13.是否后期需要迁移本地服务器：是否需要将云预售服务器的数据迁移回本地。

## 第二步，联系销售助理，进一步获取客户情况

通过不限于钉钉、微信、电话等方式联系销售助理，并通过销售助理了解基础信息，信息内容包括：

1.门店现场准备情况；

2.门店内部人员关系情况；

3.门店安装特殊要求；

4.其他安装中的注意事项。

## 第三步，制定行程

#### 总体要求：

1.行程制定可根据实际情况进行合理安排。

#### 制定标准：

1.严格按照实施任务中所委派的开始实施时间来安排行程，必须在开始实施时间前到达门店；

2.本部自有工程师请按照《差旅报销标准》要求来制定行程；

3.服务商请根据自身情况制定行程。

#### 禁止事项：

1.禁止辅张浪费；

2.禁止未联系客户直接购票出发；
