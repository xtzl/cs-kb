# 一、说明

合作厂商卡丁车（深圳市艾特威科技有限公司）,是已经对接油菜花系统，因此不需要按照通用卡丁车控制模块的方法进行安装，直接可以接入到系统。

# 二、准备内容

1.游乐宝系统已开通卡丁车功能

2.卡丁车品牌必须为深圳市艾特威科技有限公司

3.卡丁车供应商提供卡丁车服务器相关信息，包含（卡丁车服务器地址、MQ虚拟主机、MQ账号、MQ密码以及门店ID），如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018016f1e7bb0707&type=max)

# 三、配置步骤

## 第一步：进入游乐宝后台界面→选择设备→设备管理→游乐项目→新增分类→保存。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018016ea5ade06f1&type=med)

## 第二步：进入游乐宝后台界面→选择设备→设备管理→游乐项目→卡丁车→新建项目→输入项目信息→下一步→完成。（注意，卡丁车项目只需要建一个即可，开启哪台车由第三方控制）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018016ea5aee06f2&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018016ea5bc806f3&type=med)

## 第三步：在【设备】-【查询】-【项目消费消息推送查询】-选择【设置项目通知】-选择【ACTEV卡丁车】填入第三方对接信息以及勾选卡丁车项目，保存（只需要勾选一个卡丁车项目）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461018016e7b98706ee&type=max)

# 四、日常流程逻辑

顾客消费核销-油菜花系统发出启动信息-合作商服务器数据库产生记录-通过ipad选择启动哪一台卡丁车

# 五、注意事项及常见问题

1.请选择正确的推送项目，项目消费推送失败时系统将自动进行订单退款/取消扣币（因此请不要选择无需消费推送的项目）

2.油菜花系统有核销记录，合作商服务器数据库没有产生记录导致没法启动卡丁车（原因：现场网络有问题无法成功推送信息）
