# 三、填写要求

#### 文字说明

## 首次填写

时间：第一天到场后完成一下填写内容

说明：第一天到场后，检查油菜花货物和现场实际情况，初步制定整个项目工作计划并按照表格内容进行填写。

### 内容一：填写基础信息，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a588293cf121d&type=max)

### 内容二：修改安装调试项目（根据需要安装的内容进行调整）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a5887c5cf122f&type=max)

### 内容三：根据项目工作内容，调整时间（默认模板会根据常规情况进行时间自动填写，但需要根据实际情况进行微调）

### 同步工作计划到群

将填写完的工作日志复制截图到客户群里面（如下图所示）

注意事项：复制时，将【完成进度】一列筛选排除掉“不需要”的内容，使工作计划更简洁。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a588ab3d0123e&type=max)

## 每日填写

时间：完成当日工作后，根据目前完成进度进行填写

填写内容说明：根据当日/前一天完成的工作内容，将已完成的内容标记未已完成；如果有与原计划偏差的计划，需要改成已超时来提醒客户

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a588d935e1245&type=max)

填写完毕后，截图到客户群里面
