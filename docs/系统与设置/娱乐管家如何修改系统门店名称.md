# 功能说明及应用

## 连锁版

1、登录总部后台-基础设置-商业架构管理-门店管理-点击门店编号-修改门店名称（ 修改后需要门店服务器电脑重启服务才能生效 ）

2、 服务器重启服务建议结束营业后再操作重启，重启过程系统设备都会用不了，会影响营业。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018befd9ed177c59&type=med)

## 单店版

1、登录系统后台-基础设置-门店管理-名称修改-保存（修改后需要门店服务器电脑重启服务才能生效）

2、 服务器重启服务建议结束营业后再操作重启，重启过程系统设备都会用不了，会影响营业。
