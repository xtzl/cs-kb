# 一. 文档说明

本文档主要明确了游乐宝系统修改门店编号中的工作内容、作业准则、工作要求以及禁止事项，请所有实施相关人员务必认真阅读。

# 二. 流程操作

1）停止游乐宝服务，需要先停止游乐宝服务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ae2ed9612b2c&type=max)

2）在对应的游乐宝数据库执行以下语句查询门店名称：

select * from Mall_Mall

3）在对应的游乐宝数据库执行以下语句修改门店加密狗编号

update Mall_Mall set MallCode ='新加密狗编号' where MallName ='门店名称'

3）新加密狗重新生成授权文件，系统重新授权

4）重启游乐宝系统服务

5）配置新加密狗的云互联
