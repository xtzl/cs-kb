# 一、下载升级包

联系油菜花客户，告知兑币机型号，获取兑币机升级包。下载并保存到U盘

# 二、手动操作升级

打开兑币机后台，选择显示桌面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cd46d3856cf&type=med)

进入安卓后台后，打开文件夹管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cd4713056d0&type=med)

进入文件管理后，左上角选择 U 盘存储器，直接点击安装包进行安卓即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cd4758556d1&type=med)
