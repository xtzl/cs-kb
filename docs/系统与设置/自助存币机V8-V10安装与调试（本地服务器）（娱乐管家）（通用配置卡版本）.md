# 一、作业说明

自助存币机V8/V10 是一款支持扫码，读卡的自助存币设备。请按照安装说明准确安装设备。

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f811a320b&type=med)

（存币机V8）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f8123320c&type=med)

（存币机V10）

# 三、功能说明

1.支持会员卡读卡存币

2.支持会员二维码反扫读取会员存币

3.支持正扫二维码读取会员信息存币

4.不支持识别假币

# 四、作业准备

1.预留可通外网的网线以及220V电源线；

2.提前了解本地服务器IP地址。

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

# 五、作业标准

1.存币机放置到位（由于存币机不支持识别假币，建议放置到收银台内部）；

2.存币机连接正常；

3.存币机存币数量正确无误差。

# 六、调试步骤

1.存币机先通网通电

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f812d320d&type=med)

2.通电后，存币机会显示H04的

3.用钥匙打开存币机，找到内部的主板，一直按第二个按钮，直到显示H07

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f8136320e&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f8140320f&type=med)

4.登录油菜花后台，选择【终端】-【卡头WiFi通讯设置】-【重新设置通讯网络】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f814a3210&type=med)

5.选择【内场】，并填写本地服务器IP地址以及业务端口，业务端口默认为9999

若不知道如何查看本地ip地址，可参考以下文档进行查看：

win2012服务器电脑如何查看IP和端口-百度经验 (baidu.com)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f822d3211&type=med)

6.在WIFI配置一栏中，修改WIFI名称和密码，如图所示（如果现场不需要连接卡头情况下，此界面可以随便填，但是长度不要超过15个字节）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f82373212&type=med)

注意，这一步如果无线名称是系统自动生成连接WIFI的情况下，通用配置卡是无法读写的，需要将这里的无线名称和密码长度改短才可以，后续版本会修复此问题

7.启用油菜花读卡助手

路径：后台管理网页-右上角下载-选择后台助手安装包-安装

安装教程：《娱乐管家读卡助手安装教程》

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f82403213&type=med)

安装完毕后，右下角会显示油菜花助手的运行图标

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f83553214&type=med)

8.最后插上读卡器，放上会员卡，把配置好的网络写进卡里面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88e4de43204&type=max)

8.写完保存后 ，就去存币机刷配置卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fc88f83603215&type=med)

9.完成配置

# 七、测试要求

1.开通会员，通过打卡位置读取会员卡，测试是否能正常读取

2.通过小程序会员二维码反扫读卡，测试否是能读取会员

3.通过正扫机器二维码，会员能正常登录

4.测试存币，存20币以上，并测试至少3次，无误差

# 八、常见问题

1.刷通用配置卡刷不了。

解决：检查后台是否是用程序端打开进行配置的，检查是否用了自动生成的WIFI信息进行配置，已知无线名称是系统自动生成连接WIFI的情况下，通用配置卡是无法读写的。

2.获取到ip为0

答：

1）检测路由器有没有开DHCP

2）网络里面有多个路由器，并且可能插到LAN口（现在市面很多路由器都是WANLAN同口，断电上电后偶尔会将WAN口适配成LAN口），造成有多个DHCP服务器

3.报H08报错

答：

1）此版本使用的是9999或者88的通讯端口，而不是1016或者外网机台端口

2）此版本需要通过通用配置卡进行配置

4.一直显示报错界面，程序没有启动

答：

1）这是因为错误操作按出等待刷配置卡造成的，不能按着配置按键再上电，而是先上电，再按配置按键。
2）恢复方法是，先关机，按下两个配置按键，开机，等10秒松手，1分钟后程序还原出厂

5.其他报错代码含义：

E01 未插网线

E04 连接游智云失败
E05 注册游智云失败

E06 检测升级失败

E08 连接业务系统失败

E09 注册业务系统失败

E10 获取token失败（系统错误，一般是禁用或者删除了系统营业设备导致）

E11 获取二维码失败
