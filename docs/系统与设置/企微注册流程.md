# 一、如何在官网注册企业微信

官网网址： https://work.weixin.qq.com/

注册时，需要填写企业信息（企业名称、行业类型、员工规模）、管理员信息（管理员姓名、管理员手机号、短信验证码、管理员绑定了实名银卡的微信进行扫码）

# 二、如何在APP注册企业微信

1、手机软件中心下载 “企微微信” APP

企业微信在【手机端->消息页面->左上角三横->右下角设置->管理企业->全新创建企业】

# 四、常见问题解答

1、
企业微信创建/注册/认证/验证上限是多少？

- 一个微信号可以注册5个企业微信

- 同一个手机号可以创建5个企业微信

- 同一个主体证件能验证/认证5个企业微信(港澳台的企业暂不支持认证企业微信）

2、企业微信要收费吗？收费标准？

- 小型企业规模（1-1000人）人民币 300元/次

- 中型企业规模（1001-10000人）人民币 3000元/次

- 大型企业规模（10001人及以上）人民币 30000元/次
