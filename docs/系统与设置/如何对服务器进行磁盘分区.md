# 一、操作说明

如果需要对服务器硬盘进行分区处理，调整盘符，可按照此流程操作，本流程以2016版本为例，其他版本可参考对应教程

# 二、安装要求

1.C盘为系统盘，空间至少为100G以上

2.D盘为油菜花系统安装盘，建议搭建在固态上

3.建立E盘，E盘为数据备份盘，建议使用机械硬盘

4.禁止油菜花系统安装到系统盘中

# 三、操作说明

## 1.进入计算机管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001936146557b4507&type=med)

## 2.选择磁盘管理，查看现有硬盘分布情况

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193614655834508&type=med)

## 3.（按需操作）如需要将固态硬盘切割分成两个硬盘，则可以将C盘分100G作为C盘系统盘，剩余部分则分为D盘

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193614656584509&type=med)

## 4.选择分多少空间到新的盘符中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019361465769450a&type=med)

## 5.查看分割后的情况，如果D盘符被占用，则将占用的修改成其他

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019361465771450b&type=med)

## 6.右键选择占用D盘的盘符，选择【更改驱动器号和路径】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001936142c6c044f8&type=max)

## 7.选择盘符，点击修改，选择分配成其他盘符（注意，分配前一定要确保这个硬盘没有安装其他软件，否则会导致该软件不能用，另外系统盘也不支持直接修改，会导致系统无法启动）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001936143814344fb&type=max)
