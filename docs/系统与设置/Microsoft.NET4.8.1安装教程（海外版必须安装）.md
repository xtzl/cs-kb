# 一、 作业说明

Microsoft.NET4.8.1作为海外版必要的运行环境，在安装娱乐管家之前，需要提前安装该环境。部分服务器操作系统版本自带该环境情况下，可跳过此步骤。

# 二、 作业准备

1. 下载Microsoft.NET4.8.1安装包。

下载链接如下：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/2.本地服务器运行环境/Microsoft.NET4.8.1(ENU).exe

# 三、 作业标准

Microsoft.NET4.8.1为安装完成状态。

# 四、 注意事项

1. 假如已经安装过Microsoft.NET4.8.1或者已有更高版本的Net Framework，则不需要再次安装。

# 五、 作业方法

1. 打开Microsoft.NET4.8.1安装包，则出现以下界面

2. 选择”我已经阅读并接受许可条款“前面打对勾，否则文件不能安装。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db8003fc47659&type=med)

3. 现在单击“安装”软件进行安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db8003fd1765a&type=med)

4. 现在提示软件安装完毕，已安装Microsoft.NET4.8.1，单击“完成”现在软件安装完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db8003fdc765b&type=med)
