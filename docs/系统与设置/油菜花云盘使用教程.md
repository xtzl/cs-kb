# 三、使用说明

## 上传文件操作方法

1.打开网盘工具，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197872ed7bb3b9c&type=max)

2.登录后，如果提示需要AK登录，请按下图进行配置

登录信息如下：

阿里云oss（nos-pulic）

Endpoint：默认（公共云）

AccessKey ID：LTAI****已脱敏

AccessKey Secret：****（已脱敏，请向运维索取）

OSS路径：oss://nos-pulic/

区域：华南1（深圳）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197873420143bc9&type=max)

3.登录后，就可以新建自己的文件夹，或者直接上传文件到对应文件夹

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019787397c393c01&type=max)

## 分享文件下载链接

1.找到你要分享的程序或者文件，点击【获取地址】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197873afdce3c0c&type=max)

2.将地址复制到浏览器即可下载。
