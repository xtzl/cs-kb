## 问题描述

连锁总部下新门店安装完毕后， 总部跟门店无法正常通讯产生队列问题

## 原因分析

原因一：总部数据库跟门店数据库的url地址不一致

原因二：门店服务的系统setting文件中的host参数没有修改正确

## 解决方案

### 1.检查总部数据库跟门店数据库的url地址与实际的是否相符

若不相符，需要改成一致。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d674a5aba59ed&type=max)

#### 操作步骤：

a.执行select * from Mall_MallInstance

b.若url地址不一致，则按以下步骤修改

修改门店数据库队列同步地址 （ 大客户、连锁门店总部版本需要修改）
SQL Server 执行以下SQL
select * from Mall_MallInstance --查询总部/门店队列同步地址信息
select * from Mall_Business --查询门店信息表
update Mall_MallInstance set MallURL ='http://192.**8.***.9:端口/' where Mall ='*****-B5C3-4A28-8476-AF5C0108D1E4'

### 2.检查setting文件中host参数设置是否正确

#### 操作步骤：

修改门店setting host 将localhost:9999/ 改成 *:9999/，并保存，保存成功后重启服务生效参数设置
