# 一、使用说明

本工具仅用于本地服务器安装油菜花系统使用，仅适用于操作系统在windows server 2016 标准版及以上的版本中使用，支持安装游乐宝或娱乐管家单店版。

# 二、准备工作

1.确保操作系统在windows server 2016 标准版以上，且操作系统为中文操作系统；

2.确保服务器硬盘分区至少为C D E三个以上的盘符；

3.下载自动安装包，下载链接如下：

国内版本：

https://pulic.oss.youcaihua.net/实施组安装工具/99.一键安装包/油菜花安装整合包（内部用）V4.8.2.exe

国外英文版系统专用

https://pulic.oss.youcaihua.net/实施组安装工具/99.一键安装包/YCH_Nano Auto-Install（​Internal Use Only）.exe

# 三、功能支持

1.支持自动安装SQL2016数据库及SSMS管理软件；

2.支持手动选择性安装；

3.内置常用软件：VPN安装包、FTP下载工具、RAR解压工具、前台收银台安装包、谷歌浏览器、限制数据库内存大小脚本、向日葵远程工具安装包、人脸识别运行环境、windows激活工具；

4.支持选择安装游乐宝还是娱乐管家单店版。

# 四、操作说明

## 1.提前确保windows操作系统是否在windows server 2016 及以上的版，如果低于该版本，可能不支持安装。

## 2.确认磁盘分区是否已经按要求分区；

分区要求：

①至少有3个以上的盘符，分别为C 、D、E盘；

②C盘为操作系统盘

③D盘为油菜花系统盘，预留空间建议不少于200G，如果服务器有固态硬盘的机械硬盘情况下，固态硬盘可划分C盘和D盘，C盘可划分100G后剩余所有空间划分为D盘，机械硬盘划分为E盘；

磁盘分区操作，请查看此链接：《如何进行磁盘分区》

## 3.右键管理员运行《油菜花安装整合包（内部用）》

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193614893a84533&type=max)

## 4.点击安装整合包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193614914b34535&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001936149bb534539&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001936158adb94566&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019361600d2d4578&type=max)
