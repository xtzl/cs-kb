# 应用场景
当总部想同步门店所有小程序的装修风格，可通过下面设置统一同步其他门店。

# 操作流程
路径：登录其中一个已经标记好的门店→小程序→小程序装修

在【小程序装修】中，编辑完毕之后，点击【同步到其他门店】即可将装修风格同步到其他门店。
