# 问题描述

部分客户存在一个场地同时使用多套系统的情况，需要在一台电脑上来回切换登录不同系统的收银程序， 可以如何操作？

# 解决方案

系统版本要求：10.4.2088

### 具体操作：

#### 1.登录系统后台，下载收银程序安装包，并运行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fdebefc1692&type=max)

#### 2.运行后，在弹窗点击如图指定路径，输入多个门店域名地址，并测试保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fdb56dd1674&type=max)

#### 3.后续如想切换，在登录收银程序时点击【修改服务器地址】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fe4cd5316d0&type=max)

#### 4.跳转回切换登录界面，可选择指定门店地址进行切换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fe5fa0316d9&type=max)
