# 现象描述

影音盒子，在通电后出现卡死，不正常显示情况，是由于工厂测试程序问题所导致，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199eb1ead05639d&type=max)

# 解决方案

重装【工厂测试程序】来解决

# 具体步骤

1.准备一个U盘，并下载好新的工厂测试程序，注意下载的为压缩包，需要解压后放置到U盘里面

下载链接：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/7.常用硬件安装包/氛围系统影音盒子工厂测试程序（20250819）.rar

2.U盘插入影音盒子后进入系统设置->存储->便携式存储设备显示的就是U盘目录，点击U盘进入U盘目录后找到复制过来的工程测试程序安装包点击该安装包安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199eb21250863a6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199eb21428e63a7&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199eb21734a63aa&type=max)

从上图位置找到APP安装包，点击安装。

3.检查一下工程测试程序有没有注册

点进去工程测试程序里边后点"关于"如果没有显示注册信息的话就重新注册，注册流程如下面视频操作
