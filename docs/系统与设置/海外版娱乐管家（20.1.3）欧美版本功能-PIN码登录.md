# 欧美版本功能-PIN码登录

## 一、功能概述

支持收银员通过个人数字 PIN 码快速登录收银终端，替代传统账号密码登录模式。收银员仅需输入专属数字 PIN 码即可完成身份验证，操作简便、输入高效，适配收银场景高频快速登录需求优化前台操作体验 。

## 二、功能操作指南

### 1、版本要求

欧美版本：V20.1.3193

东南亚版本：无该功能

国内&港澳台版本：无该功能

### 2、操作流程

①在后台-设置-用户设置，操作新增用户，可以看到PIN码框

注意：PIN码只支持4-6位纯数字

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84dd4f3e34ad&type=med)

②收银员操作收银台程序进行登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84dd4f4534ae&type=med)

## 三、常见问题答疑

### 1、收银台程序如何优先显示PIN码登录

答：在后台-设置-系统设置-登录模式，选择PIN码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d84dd4f4b34af&type=med)

### 1、收银员使用PIN码登录收银台时，可以通过键盘来进行填写吗？

答：可以通过键盘进行输入数字

### 2、收银员忘记PIN码该怎么办？

答：可以使用账号和密码进行登录。如果实在都忘记了，可以向管理员申请进行修改密码

### 3、如何修改PIN码

管理员登录后台-系统-设置-用户管理，选择需要修改的用户，点击编辑，进行修改
