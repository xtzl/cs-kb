# 一、 作业说明

本安装说明主要讲解如何在收银电脑或者办公电脑安装娱乐管家管理后台和收银前台的步骤。

# 二、 作业准备

1. 电脑一台，需要至少windows XP 64位以上的操作系统，建议至少windows 7 64位操作系统。

2. 前台和后台安装包各一个。

3. 已安装.net4.5.2以上的运行环境。

# 三、 注意事项

收银终端不要重复绑定

# 四、 安装标准

1. 安装路径必须是非系统盘

# 五、 安装步骤

1.下载收银端安装包及后台安装包

（单店版）收银端下载链接：https://nos-pulic.nos-eastchina1.126.net/10.3.3001/MallProCashVIPSetup.exe

（单店版）后台端下载链接：https://nos-pulic.nos-eastchina1.126.net/10.3.3001/MallAdminSetup.exe

连锁版请使用FTP下载工具进行下载：下载教程

2. 双击运行后台安装包，选择安装路径，点击安装。

3. 填入服务器地址，如系统登录网址为：http://y********.yun.youcaihua.net:88/admin，则服务器地址填写为y********.yun.youcaihua.net:88,如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f56e9e2b06e7d&type=max)

4. 点击确定，完成后台安装。

5. 登录后台，在【设备管理】-【硬件设备】 - 【收银终端】中点击新增。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7f31e5c3e84&type=max)

6. 填写终端名称，一般建议设置为一号收银台、二号收银台等（根据现场收银台数量进行设置），选择终端类型为PC终端，保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7f34aab3e85&type=max)

7. 使用收银前台安装包进行安装，安装方法与后台一致。

8. 输入服务器地址后，提示绑定终端，请填写管理员账号及密码，选择刚刚建立的收银终端，点击绑定即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f56e82b8d6e1c&type=max)
