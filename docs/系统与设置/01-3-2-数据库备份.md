# 一、 作业说明

本操作说明仅在特定情况下适用，常规安装情况不需要使用。如需使用备份和还原的方法请查看此教程学习。

# 二、 作业准备

1. 服务器电脑

# 三、 作业标准

1. 不影响原数据库内容。

2. 导出完整数据库

# 四、 注意事项

1. 对服务器数据库进行操作时务必确保在非营业状态下操作。

# 五、 作业步骤

1. 左下角【开始】菜单，找到SQL Server Management Studio，点击进去。

2. 在服务器名称输入服务器IP地址，如本机为数据库服务器则可输入“. ”或者“ localhost ”或者本机 IP，3选 1 即可。

3. 身份验证可使用SQL Server 身份验证，或者windows 身份验证。如使用SQL Server身份验证请输入数据库的登录账号及密码，默认为 sa ，默认密码为 ****（已脱敏，请向运维索取）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71de8543b7b&type=max)

4. 点击连接之后，进入数据库。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71e31343b7c&type=max)

5. 选择你要备份的数据库，右键，选择任务-选择备份。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71e5baf3b7d&type=max)

6. 在备份界面先删除原备份路径，点删除，如图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71e87a13b7e&type=max)

7. 再点添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71eb99e3b7f&type=max)

8. 点【…】选择路径，注意这里的路径不能选择任意一个盘下的根目录，偶尔会出现报错。并填写备份文件名称，注意后缀要加上.bak，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71f19a03b80&type=max)

9. 点击确定，然后再点击确定，回到一开始的界面点击确定开始备份，直到备份完成为止。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac71f4fe33b81&type=max)

# 六、 常见问题

1. 备份时提示备份失败。

原因：

&Oslash; 你登录数据库的数据库账户没有权限。

&Oslash; 你备份的路径有异常，如无写入权限等。

&Oslash; 备份路径超过两个以上。

&Oslash; 数据库应用程序有异常。

&Oslash; 数据库已损坏。
