# 一、油菜花推送升级

进入兑币机后台，查询设备串码并提供给油菜花客服，让客服给推送新版本兑币机程序

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cce489756af&type=med)

# 二、卸载旧程序

1.推送完程序之后，进入兑币机后台，点击显示桌面，先把原先的旧程序卸载

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cce4ccd56b0&type=med)

2.卸载程序之后，打开油菜花工程测试程序

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cce525b56b1&type=med)

# 三、应用更新下载

进入油菜花测试工程，点击应用更新。系统会自动下载，下载好程序之后，只需点击安装即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cce55d556b2&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7e23e461017f6cce5b0556b3&type=med)
