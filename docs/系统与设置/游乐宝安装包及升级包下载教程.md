# 一、 操作说明

本教程主要围绕如何下载游乐宝安装包及升级包的操作来展开说明。此步骤为安装服务器前置步骤，需要先把对应的安装包下载完毕后再执行安装服务器的步骤。

# 二、 操作准备

1、 FTP下载工具

下载链接：https://nos-pulic.nos-eastchina1.126.net/%E5%AE%9E%E6%96%BD%E7%BB%84/FTP%E4%B8%8B%E8%BD%BD%E5%99%A8.rar

# 三、 操作标准

1.下载完成游乐宝的安装包

2.下载完成游乐宝的升级包

# 四、 注意事项

1. FTP下载工具属于内部机密工具，请注意不能外泄。

# 五、 作业步骤

1. 打开FTP下载工具，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac736b8133bff&type=max)

如果提示需要注册，点输入代码即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195417ac19413cd&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195417ac19c13ce&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195417ac1a413cf&type=med)

2. 点击连接，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac736e1f13c00&type=max)

3. 选择快速连接

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac73718c13c01&type=max)

4. 选择历史记录，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac73739493c02&type=max)

5. 点击连接，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7375acb3c03&type=max)

6. 连接完毕后，如下图显示云盘目录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac73780163c04&type=max)

7. 选择【安装包】，然后选择【专业版】，找到001结尾的安装包，注意，此处建议使用当前发布最新版本的001结尾的安装包。例如：当前版本最新为8.1.4071，则需要下载8.1.4001的安装包。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac737bd6d3c05&type=max)

8. 左边选择你安装包的下载路径，选择后，直接把安装包拖动到左下方空白地方即可，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac737e4103c06&type=max)

9. 点击开始下载，即开始下载安装包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac73897b03c07&type=max)

10. 同样，升级包按照此方法进行下载，云盘路径为【升级包】-【专业版】 - 找到最新的升级包，拖动下载。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac738f7833c08&type=max)
