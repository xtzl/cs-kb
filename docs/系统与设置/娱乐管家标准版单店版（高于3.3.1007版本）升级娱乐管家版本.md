# 升级说明

3.3.1以上版本的标准版用户升级到大客户，需要先降级到3.2.7001，再升级到大客户版。

# 安装前准备

1.需要的升级包如下：（待补充）

2.下载降级工具到娱乐管家安装目录，工具下载链接如下：https://nos-pulic.nos-eastchina1.126.net/%E5%AE%9E%E6%96%BD%E7%BB%84/StandarToVIP.exe

# 流程说明

1.打开娱乐管家管理器，停止门店所有服务，包括业务服务和守护服务。

2.备份门店文件夹以及门店数据库。门店文件夹直接整个文件复制，并在D盘建立一个文件夹，命名为"油菜花升级前备份文件",将YCHMALL整个文件夹复制到该文件夹中，中间提醒时直接选择跳过即可。数据库备份请按照【数据库备份操作流程说明】来进行备份，同样备份存放在该路径。

3.将工具【StandarToVIP.exe】复制到YCHMALL文件夹内，并右键管理员运行，勾选【已经认真月度完此说明】，并依次点测试连接以及执行。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e885644377ef3&type=max)

4.检查下Setting文件的CurrentVersion是否等于3027001，在配置文件里CurrentVersion=3027001表示初始化成功。

5.运行升级包升级。

# 注意事项

升级超时
升级过程中，由于多种原因可能会出现升级超时失败的情况：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e8857d3ac7ef5&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e88581c737ef6&type=max)

该种情况下，请先检查程序版本和setting版本是否一致
程序版本：选中Mall.Monitor右击>选择属性>选择上方标签页“详细信息”>查看文件版本信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e88585f107ef7&type=max)

Setting版本：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e8858ea147efa&type=max)

上面的实例中程序与Setting版本不一致，程序已经升级到大客户了，但是setting版本没有更新，需要手工改setting版本的CurrentVersion改成当前大客户版本：100210XX

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e8859364b7efc&type=max)

改完保存后，重启服务后即可正常使用

2.2 执行降级工具时，工具进程被杀掉了(断电或电脑卡死等原因)
这种情况下，重新执行降级工具，如果弹出提示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e8859c6417efe&type=max)

将setting的CurrentVersion=3027001改为原先的版本号，重新执行降级工具

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e885a0d017f02&type=max)
