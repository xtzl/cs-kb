# 文档说明

在历史旧服务器，很多客户使用的是SQL2008，当遇到需要从游乐宝升级娱乐管家连锁总部时，由于总部数据库为SQL2016时，下拉门店会遇到SQL2016数据库无法还原到2008的数据库问题。本文档则用于指引如何将门店的数据库重新安装一个SQL2016，使其可以同时运行两个版本数据。并且下拉数据时，则可以直接下拉到SQL2016数据库环境中。

# 环境说明

此方法仅支持windows操作系统为windows server 2012 R2以上版本，windows server 2008 R2不支持。

# 风险说明

由于在windows server 2012 操作系统安装SQL 2016时，需要安装windows补丁支持，而安装补丁会有一定的服务器系统崩坏的风险，在使用本教程之前，务必对服务器数据进行备份保留。避免因为失败导致数据丢失。

# 操作说明

## 1. 安装windows补丁包，安装方法两个

### 方法一：手动安装补丁包（KB2919355）（如果此方法失败，则采用方法二）

参考文档：《微软官方说明》

具体操作：

按以下顺序安装补丁更新：

①clearcompressionflag.exe 注意此程序安装无任何提示运行完即可。

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/windows server 2012 R2 补丁目录/clearcompressionflag.exe

②Windows8.1-KB2919442-x64.msu

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/windows server 2012 R2 补丁目录/Windows8.1-KB2919442-x64.msu

③Windows8.1-KB2919355-x64.msu

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/windows server 2012 R2 补丁目录/Windows8.1-KB2919355-x64.msu

### 方法二：使用windows自带更新功能，更新对应的补丁

路径：控制面板→右上角查看方式改为类别→系统和安全→windows更新→检查更新→安装更新

特殊情况：如果windows 更新功能被禁用，可手动启动windows更新服务，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01994c40ae4f44d9&type=max)

注意：以上补丁安装完后都需要重启电脑才能生效。
