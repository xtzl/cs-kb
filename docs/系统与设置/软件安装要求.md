服务器主机：

1.服务器windows系统必须符合下列系统其中之一：
a.windows server 2008 R2 企业版
b.Windows server 2012 R2 标准版
c.Windows server 2016 R2 标准版
2.油菜花软件安装完毕，并且能正常运行，在服务管理其中能正常显示，重启电脑后能自动运行
3.服务器的VPN是否已经安装完毕，并且VPN已经在连接中的状态
4.服务器IP已按照规定固定完毕
5.服务器桌面只有火绒、VPN管理器、游乐宝\娱乐管家服务管理器，且没有360、腾讯安全管家、WPS等无关软件
6.防火墙功能正常开启，其他设备能通过局域网正常登录系统。
