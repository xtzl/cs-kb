# 业务描述

此功能模块用于查看机台运行情况和收入情况

# 基本操作流程

进入对应的界面 —刷新 — 查看

# 菜单路径

【设备】 -【终端设备看板】

# 流程操作

1. 进入对应的界面 ：点击【终端设备看板】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da20545e7e74&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da20545e7e73&type=max)

2. Tab键 ：默认、收入、投币、离线和禁用。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da2054947e75&type=max)

3. 查看状态 ：直接查看即可，数据为10分钟更新一次，需要手动刷新，刷新方式可以右键鼠标点击刷新，也可以按F5刷新页面。

4. 说明： 鼠标指向右边的 即可查看相关数据说明。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da2054987e76&type=max)

# 温馨提示

&Oslash; 自助终端、收银终端、刷卡终端和智能门闸，置于外面作为TAB标签，且默认展示自助终端；

&Oslash; 游乐项目的刷卡终端并入“刷卡终端”；

&Oslash; 碎票机列入“自助终端”列表。
