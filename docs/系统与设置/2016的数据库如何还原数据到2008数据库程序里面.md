# 一、文档说明

由于部分云服务器已经更新到2016数据库系统，而部分客户的服务器则因为操作系统为windows server 2012 R2或以下的版本，导致安装数据库只能安装2008数据库的情况下，需要将2016的数据库还原至2008时，会提示无法还原，此时我们则需要使用脚本的方式将2016的数据库生成脚本在2008数据库中利用脚本生成2008的数据库。

# 二、准备工作

1.2016的数据库需要进行备份，避免操作失误导致数据丢失

2.确保2008数据库是正常运行的

3.提前下载好 数据库索引工具

下载链接：https://pulic.oss.youcaihua.net/%E5%AE%9E%E6%96%BD%E7%BB%84%E5%AE%89%E8%A3%85%E5%B7%A5%E5%85%B7/%E7%89%B9%E6%AE%8A%E5%B7%A5%E5%85%B7%E5%8C%85/%E6%95%B0%E6%8D%AE%E5%BA%93%E7%B4%A2%E5%BC%95%E5%AF%BC%E5%87%BA%E5%B7%A5%E5%85%B7.exe

# 三、注意事项

此方法仅用于数据库大小不超过2G的情况下使用，如果数据库过大，建议将SQL升级到2016数据库来进行还原数据库。

# 四、操作说明

## 第一步 从2016数据库系统中，将目标数据库生成构建数据库的脚本

1.登录SQL2016 的SSMS系统

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24763dd2f1f&type=max)

2.找到目标数据库，右键→任务→生成脚本

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d248e12b2f27&type=max)

3.首页直接点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24b6e522f31&type=max)

4.选择【选择具体的数据库对象】并点击【全选】，然后点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24c5d662f36&type=max)

5.点击

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24ff28b2f44&type=max)

，选择脚本保存路径，并给脚本命名，建议命名为YCHMALL+加密狗编码.sql

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24e097e2f3e&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d24fa54e2f42&type=max)

6.点击【高级（A）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d251ea4e2f4a&type=max)

7.找到【服务器版脚本】，选择【SQL Server 2008 R2】；并选择【要编写的脚步数据的类型】为【架构和数据】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2542a232f53&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d254bd242f58&type=max)

8.点击【确定】后，点击【下一步】，确认信息后，再点【下一步】开始构建脚本，等待构建结束后，点击完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d255f6502f5a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d256e26b2f60&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2577e342f66&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2584d152f6a&type=max)

9.将脚本复制到SQL2008的服务器中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d25a02862f6e&type=max)

## 第二步 在2016数据库里面，导出数据库索引

1.将下载好的索引导出工具，放到SQL2016的服务器里面，并运行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979adac63c7ab9&type=max)

2.输入对应的数据库连接资料

服务器地址：填写localhost

数据库账号：对应的数据库登录账号

数据库密码：对应的数据库登录密码

目标数据库：选择需要还原去2008的数据库。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979ae1ed857b19&type=max)

点击导出索引，生成对应的SQL文件，并将SQL文件复制到2008的服务器中。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979ae227077b1c&type=max)

## 第三步 在服务器新建数据库，并执行脚本构建数据库内容

1.登录SQL2008数据库，右键【数据库】，点击【新建数据库】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d28d3dc43092&type=max)

2.填写新建的数据库名称，请填写数据库名称，建议使用原来数据库的名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d297cc3f30bc&type=max)

3.修改数据库文件的路径，建议放到YCHMALL文件夹中的DataBase文件夹中。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2a5845f3120&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2a631503127&type=max)

4.点击【确定】后，即可生成一个空白数据库，此时数据库是没有任何资料，下一步就是通过脚本生成数据表

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2acee51315d&type=max)

5.右键开始菜单，选择【命令提示符（管理员）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2b029f33178&type=max)

6.输入命令，并执行该命令

命令如下：

sqlcmd -S localhost -U sa -P **** -d 数据库名称 -i D:\sqlluser folder.sql（从2016复制过来的文件的路径）

例如：

sqlcmd -S localhost -U sa -P **** -d YCHMALL门店编码 -i D:\YCHMALL门店编码.sql

命令字段意思如下：

-S:数据库服务器地址，我这里是本机直接用localhost
-U:用户名
-P:密码
-d:数据库名
-i: sql文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d2b3a7c2318c&type=max)

7.等待执行成功后，数据库构成完成。

## 第四步 导入索引

注意：此步骤非常重要，不导入索引情况下，服务器运行会非常的慢，导致很容易服务器崩溃。

登录2008的数据库后，找到第二步导出的SQL文件，双击导入，并选择需要执行的数据库后，全选语句并点执行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001979ae4b9ed7b3c&type=max)
