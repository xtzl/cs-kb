# 一. 文档说明

由于部分游乐宝升级娱乐管家连锁总部系统，总部数据库是SQLServer2016，门店数据库是SQLServer2008，导致安装连锁门店系统无法安装成功，需要将门店先安装到SQLServer2016在通过脚本转换，安装门店服务器

# 二. 准备工作

1. 先在其他SQLServer2016数据库上部署娱乐管家连锁门店系统，可参考【娱乐管家连锁门店安装】

2. 门店游乐宝数据库和娱乐管家数据库先进行备份，避免数据丢失

3. 提前下载好 数据库索引工具

下载链接：https://pulic.oss.youcaihua.net/%E5%AE%9E%E6%96%BD%E7%BB%84%E5%AE%89%E8%A3%85%E5%B7%A5%E5%85%B7/%E7%89%B9%E6%AE%8A%E5%B7%A5%E5%85%B7%E5%8C%85/%E6%95%B0%E6%8D%AE%E5%BA%93%E7%B4%A2%E5%BC%95%E5%AF%BC%E5%87%BA%E5%B7%A5%E5%85%B7.exe

# 三. 注意事项

此方法仅用于数据库大小不超过2G的情况下使用，如果数据库过大，建议将SQL升级到2016数据库来进行还原数据库。

【SQLServer2008升级SQLServer2016操作流程】

# 四. 具体操作流程

## 第一步 从2016数据库系统中，将目标数据库生成构建数据库的脚本

1.登录SQL2016 的SSMS系统

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187892b59e5&type=med)

2.找到目标数据库，右键→任务→生成脚本

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187893259e6&type=med)

3.首页直接点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187893859e7&type=med)

4.选择【选择具体的数据库对象】并点击【全选】，然后点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187893d59e8&type=med)

5.点击

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187894459e9&type=med)

，选择脚本保存路径，并给脚本命名，建议命名为YCHMALL+加密狗编码.sql

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187894959ea&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187894e59eb&type=med)

6.点击【高级（A）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187895459ec&type=med)

7.找到【服务器版脚本】，选择【SQL Server 2008 R2】；并选择【要编写的脚步数据的类型】为【架构和数据】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187895959ed&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187895f59ee&type=med)

8.点击【确定】后，点击【下一步】，确认信息后，再点【下一步】开始构建脚本，等待构建结束后，点击完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187896559ef&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187896a59f0&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187896f59f1&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187897559f2&type=med)

9.将脚本复制到SQL2008的服务器中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187897959f3&type=med)

## 第二步 在2016数据库里面，导出数据库索引

1.将下载好的索引导出工具，放到SQL2016的服务器里面，并运行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187897f59f4&type=med)

2.输入对应的数据库连接资料

服务器地址：填写localhost

数据库账号：对应的数据库登录账号

数据库密码：对应的数据库登录密码

目标数据库：选择需要还原去2008的数据库。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187898559f5&type=med)

点击导出索引，生成对应的SQL文件，并将SQL文件复制到2008的服务器中。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187898a59f6&type=med)

## 第三步 在服务器新建数据库，并执行脚本构建数据库内容

1.登录SQL2008数据库，右键【数据库】，点击【新建数据库】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187898f59f7&type=med)

2.填写新建的数据库名称，请填写数据库名称，建议使用原来数据库的名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187899559f8&type=med)

3.修改数据库文件的路径，建议放到YCHMALL文件夹中的DataBase文件夹中。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001983187899a59f9&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318789a059fa&type=med)

4.点击【确定】后，即可生成一个空白数据库，此时数据库是没有任何资料，下一步就是通过脚本生成数据表

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318789a559fb&type=med)

5.右键开始菜单，选择【命令提示符（管理员）】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318789ab59fc&type=med)

6.输入命令，并执行该命令

命令如下：

sqlcmd -S localhost -U sa -P **** -d 数据库名称 -i D:\sqlluser folder.sql（从2016复制过来的文件的路径）

例如：

sqlcmd -S localhost -U sa -P **** -d YCHMALL门店编码 -i D:\YCHMALL门店编码.sql

命令字段意思如下：

-S:数据库服务器地址，我这里是本机直接用localhost
-U:用户名
-P:密码
-d:数据库名
-i: sql文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318789b059fd&type=med)

7.等待执行成功后，数据库构成完成。

## 第四步 导入索引

注意：此步骤非常重要，不导入索引情况下，服务器运行会非常的慢，导致很容易服务器崩溃。

登录2008的数据库后，找到第二步导出的SQL文件，双击导入，并选择需要执行的数据库后，全选语句并点执行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318789b659fe&type=med)

## 第五步 安装系统

1. 根据【娱乐管家连锁门店安装】安装娱乐管家门店

2. 根据流程步骤安装连锁门店时，在数据导入时点击已经手动导入完成不要点击从总部获取数据，选择对应的数据库进行安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198318effbe5a4f&type=max)
