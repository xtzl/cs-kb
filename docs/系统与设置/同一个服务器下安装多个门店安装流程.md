# 流程说明

此流程一般用于有特殊需要在同一个服务器中安装多个系统的情况下使用，包括游乐宝以及娱乐管家系统安装均支持，常用于以下几种情况：

a.游乐宝系统升级/置换娱乐管家功能；

b.万达系统置换游乐宝/娱乐管家系统；

# 适用范围

1.原来已经使用油菜花系统，需要在同一台服务器上安装另外一套系统；

2.两套系统必须都使用网络授权；

3.可以两套系统使用同一个门店编码，也可以使用不一样的门店编码；

4.游乐宝系统、娱乐管家单店、娱乐管家连锁系统均支持；

5.如果有果冻卡头、存币机以及柜台碎票机（特点为使用单独配置卡的旧设备），可能会出现无法连接第二套系统的情况，需要硬件核查；

6.硬件性能需要一定的支撑，建议服务器内存至少在32G以上，CPU性能至少达到I5以上级别性能，硬件空间至少预留100G以上；

# 安装标准

1.系统命名必须按照【门店编号-门店名称-业务端口】来命名；

2.数据库实例名称必须按要求进行修改，命名规则为YCHMALL门店编码

3.业务端口及机台端口按照要求修改，业务端口取值为9999-9990之间，机台端口取值范围为1099-1090之间

# 前期准备

1.检查数据库登录账号以及密码，看看是否能正常登录；

数据库默认登录账号为sa、密码为****（已脱敏，请向运维索取）

如发现无法登录，可查询原系统的settings文件参数，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e936ba3550b4d&type=max)

2.下载第二套需要安装的系统的安装包，以及安装是需要使用的软件，如VPN等；

3.提前配置VPN信息，包括小程序VPN以及连锁商城VPN（如单店系统可忽略）

4.如果有开启防火墙，请提前修改防火墙的入站规则，增加TCP端口和UDP端口，一般开放TCP：9990-9999和UDP：1099-1090；

5.备份原系统文件以及数据库备份。

# 流程操作

1.双击运行安装程序，修改安装路径，文件夹命名规则为：门店编号+门店名称+业务端口

说明：业务端口一般顺延减少，例如原系统的登录地址为192.168.110.10:9999，则代表业务端口为9999，这时候就不能再使用同一个端口，一般会设置为9998；所以按这个规则命名新的门店的文件夹就是：“00000000-油菜花门店名称-9998”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e9374d82c0b57&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e937513fc0b58&type=max)

2.弹出安装程序时，按F1弹出修改示例设置；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e937b290d0b62&type=max)

填写要求：

主服务端口：依次填写，如果原系统为9999，则第二套系统为9998；

机台服务端口：按照业务端口后两位来设置，如业务端口为9998，则机台端口设置为1098

实例名：直接填写门店编号，注意一定不能留空；

3.填写完点击确定，重新授权并按照正常安装流程安装即可。
