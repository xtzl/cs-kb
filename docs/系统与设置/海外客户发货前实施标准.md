# 服务器安装要求

1.服务器系统安装版本，根据订单要求，区分东南亚版本和欧美版本

- 东南亚版本20.1.2***

- 欧 美版本20.1.3***

2.服务器所需安装的运行环境

- .net 4.5.2

- .net 4.8.1

- vcredist_x64.exe

3.所需要安装的软件

- Chrome浏览器

- 向日葵远程工具

- WINRAR压缩软件或其他同类软件

- SSMS数据库管理工具

- SQL Service 2016 数据库软件

4.网络设置

服务器IP地址固定为：

- IP：192.168.110.10

- 子网：255.255.255.0

- 网关：192.168.110.1

- DNS：8.8.8.8 114.114.114.114（备选）

5.开机密码强制修改为设置：设置为****（已脱敏，请向运维索取）23456

可执行此CMD命令（需要用管理员权限执行）：net user Administrator Ych@123456

6.在电脑D盘新增一个文件夹: Nano Software, 把我们软件的后台和收银台的安装包, 授权文件等都放到这个文件夹

7.关闭服务器电脑的防火墙(非常重要)
8.关闭服务器电脑的自动更新(百度找一下相关教程)

9.打开远程桌面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f174db21f0bfc&type=max)

10.安装"油菜花助手"插件

11.改服务器时间，需要改成当地的服务器时间。

# 收银电脑设置

- 安装并运行收银软件, 输入服务电脑固定IP, 例如192.168.110.10:9999, 绑定对应的终端名称；

- 在收银软件中设置小票打印机；

- 安装"向日葵软件"；

- 安装谷歌浏览器，并将后台网页进行收藏并创建快捷方式到桌面上；

- 在电脑D盘新增一个文件夹: Nano Software, 把我们收银台的安装包放到这里；

- 安装油菜花助手，并测试读卡功能正常使用。

# 自助设备(例如发卡机, 售票机)

- 提前输入服务器地址, 连接服务器

- 编辑界面菜单, 关闭不需要的菜单, 例如团购核销, 赠币券核销等海外客户用不到的功能

- 如果有Nayax等, 可以提前沟通配置对接
