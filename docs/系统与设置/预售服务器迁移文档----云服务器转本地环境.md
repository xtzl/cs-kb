# 场景

客户需求，事先安装云服务器，提交小程序申请，进行预售活动。完成活动后，将服务器从云端迁移至本地环境

# 迁移准备：

1.确定云服务器安装的系统版本；

2.拷贝云端服务器系统数据库；

# 操作流程

## 预售服务器进入路径：

1.右键电脑桌面最左下角“开始”，在展开栏点击“运行”；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51260151ad&type=med)

2.在“运行”窗口输入“mstsc”，会弹出远程桌面窗口；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51261651ae&type=med)

3.在远程弹出窗口输入地址“125.88.214.15:38669”，点击“连接”，进入跳转界面；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51262c51af&type=med)

4.在跳转界面输入账号：administrator 密码****（已脱敏，请向运维索取）后，点击“确定”，进入远程服务器电脑桌面；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51263e51b0&type=med)

5.在显示桌面，点击最上方的图标，将该桌面缩小化；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51265351b1&type=med)

## 安装本地服务器，迁移工作：

1.【重点】登录门店域名，确定服务器当前版本

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f67f47d51e8&type=max)

2.在本地服务器中正常安装门店系统，注意： 本地部署需同步安装预售服务器系统版本（即若某门店云部署系统版本是8.1.6175，切换本地部署，也需在本地环境安装相同系统版本8.1.6175）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148492d15b0184d19fe6111973&type=max)

3.在预售服务器，找到目标门店，停掉所有服务。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f6b480d51ed&type=max)

3.进入预售服务器门店数据库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51266051b2&type=med)

4.在 预售服务器，找到对应门店数据库（名称格式：YCHMALL＋门店加密狗），拷贝备份数据；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c01847f51266a51b3&type=med)

备份操作可参考文档

5.在 本地环境还原数据库；

还原操作可参考文档

6.在云服务器的备案中，标记已迁移服务器

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148492d15b0184d19c3a4e1967&type=max)

7.【重点】本地系统安装完成后，需通知相关人员切换vpn，否则会影响部分功能使用如小程序数据同步等

常见问题：

1.还原数据库后无法启动服务：

可能性1：备份错数据库，导致数据库内的门店编码和你授权的门店编码不对应

解决方法：重新备份还原数据库

可能性2：本地服务器的系统安装版本和云服务器的系统安装版本不一致

解决方法：删除本地服务器的系统重新安装
