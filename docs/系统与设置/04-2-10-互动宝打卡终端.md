# 一、 作业说明

体育运动类场地的打卡终端与场地系统连接，需要安装接线与配置

# 二、 作业准备

电钻，十字螺丝刀，电络铁，电工胶布，扎带

# 三、 注意事项

12V电源的正负极别接错

# 四、 作业标准

打卡终端安装完能正常刷卡，后台计数准确

# 五、 作业步骤

1.把打卡终端的边缘网关与服务器放在一起，并通电通网，查看它的编号：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05110ea4&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb051e0ea5&type=med)

2.登录系统后台，找到运动打卡管理-门店配置，填写好边缘网关编码和本地服务器ip地址并保存，如果服务器是云部署的话就无需填写边缘网关编号：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05290ea6&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05340ea7&type=med)

3.找到卡头wifi通讯设置，设置打卡终端专用无线名称：YOChlkLGCZos0iixjyxHrZNlwL，连接密码：****（已脱敏，请向运维索取），和正确的服务器地址，保存后点击服务器地址同步到游智云：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05400ea8&type=med)

4.进入场地的无线AP管理或者路由器管理页面，配置好对应的无线网络名称密码：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb054c0ea9&type=med)

5.把打卡终端接上12V电源（注意正负极不要接错），并用络铁焊好缠上电工胶布或热缩管：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb055c0eaa&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb056a0eab&type=med)

6.在确保安全的情况下通电，打卡终端连上网后会依次显示9位数字编号：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05760eac&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05840ead&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05900eae&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb059a0eaf&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05ad0eb0&type=med)

7.登录系统后台，找到运动打卡管理-项目管理和场次管理那里添加相应的项目以及场次：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05b90eb1&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05c20eb2&type=med)

8.然后在新增好的项目那里点击添加设备，输入设备名称和打卡终端显示的编码并点击保存：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05ce0eb3&type=med)

9.绑定完成后打卡终端会显示对应的设备编号，系统后台也能看到设备在线或离线状态：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05de0eb4&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05e80eb5&type=med)

10.用会员卡或手环测试一下，如果能正常打卡就证明已经配置好了：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb05f90eb6&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb06070eb7&type=med)

11.接下来要将打卡终端安装到客户指定的位置，首先拆开它的面板并把底座用螺丝固定住：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb06130eb8&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb06220eb9&type=med)

12.最后接上面板，上好螺丝，把裸露在外的电源线用线槽盖起来，安装就已经全部完成了：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb06340eba&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0183c4eb06480ebb&type=med)
