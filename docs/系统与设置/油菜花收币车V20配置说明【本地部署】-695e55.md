# 一、 作业说明：

本文旨在说明油菜花收币车V20的安装配置

# 二、作业准备：

开箱检查配件是否齐全：充电线、门锁钥匙、币袋10个、无线扫码枪；

开箱检查机身是否无异常：玻璃显示屏、币袋存放点挡板

# 三、作业标准

收币车能够正常收币，并且数据能够回传到系统后台

# 四、注意事项

适配后台管理系统版本:娱乐管家版本10.3.6190及以上，游乐宝版本8.1.6912及以上；

收币车马达：双马达设计，单马达寿命1千万币；

收币车电池容量:448wh,可满负荷工作6小时；

兼容游戏币:厚度1.5-2.2mm,直径22-27mm；

车内币容量:3.5万币

# 五、作业步骤：

## 1.开机

打开收币车右下方的铁门，电源插头上方有个按钮，轻按开机

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2019000025983385c&type=max)

开机后观察收币车电量（电量建议维持在50%，50%的电量可工作6小时，电源支持边工作边充电）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201900009ee6b3866&type=max)

## 2.配置

连接场地跟本地服务器同个网段的WIFI，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190110774d56c3c&type=max)

网络成功接入之后，点击左上角返回，连接本地服务器，输入本地服务器IP地址及端口（通常情况是9999）

连接成功后，在界面下方会显示门店信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190110c9c476c50&type=max)

设置成功后，进入账号登录界面，在该界面输入门店账号密码，进行登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190110fc49c6c5f&type=max)

## 3.使用

登录成功后，收币车界面如图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201901116e5506c81&type=max)

在收币前，先将币袋绑在出币口

注意，可利用币袋的绳子打结进行加固防止松动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190111a84f06c96&type=max)

选择当前收币的日期，注意不能选错，否则会将收车的数据录到其他日期上

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190111ccf6e6caf&type=max)

扫卡头上的二维码，或者后台设备项目导出的二维码，对相应P位机台进行收币

机台设备二维码如何导出可以参考视频：使用扫码枪收币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201901122cffe6cd4&type=max)

成功扫码后，收币车机台指示灯会开始闪烁，此时开始将游戏币导入币口，收车的过程中，马达指示灯会持续闪烁

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201901126cace6cec&type=max)

若收币完成，收币车停止收币，马达会停止闪烁

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190112aa1626d02&type=max)

收币过程中，界面显示如图：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190112c24a86d0c&type=max)

当收币完成，马达收币界面会出现完成的字眼，点击完成，即可完成收币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190112d58a26d16&type=max)

点击完成，即可完成此轮收币，将收币数据回传到系统后台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190112f84356d1b&type=max)

收币完成后，关闭电源

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190113080c96d1d&type=max)

后台数据查看路径：报表 --- 手抄码表 --- 找到对应收币日期，查看币收入误差

# 六、常见问题：

点击显示屏界面 - 右上角齿轮设置按钮，设置币袋的币容量，方便后续给兑币机或者柜台售币机加币。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190205d5699277b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190205e5835277d&type=max)

## 2.收币明细

点击显示屏界面 - 右上角齿轮设置按钮，可查看收币车历史收币明细

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2019020624f40279c&type=max)

## 3.排除杂币

收币车通过学习正常的游戏币，排出尺寸不一样的游戏币及币箱留存的螺丝螺母杂质；

点击显示屏界面 - 右上角齿轮设置按钮，开启收币车学习设置，记忆游戏币大小、材料

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2019023f6c40b2ef5&type=max)

准备20枚门店正常使用的游戏币，投入收币车收币口，开始学习

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2019023f995962f17&type=max)

学习完成，投入几十枚游戏币，进行测试

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c20190241e42972fd5&type=max)

# 七、故障排查

1.开不了机怎么办?

无法开机请检查电池电量,如果电量都没法显示需要先进行充电,等电量充足再尝试开机

2.始终显示连接不上网络怎么办?

无法连接网络时,操作界面会显示"重新联网"的按钮,点击按钮可重新扫描附近的wifi,输入正确的密码即可连接

3.收币车登录时显示系统不支持该类设备的自动注册是什么问题?

说明管理系统比较旧,需要升级到最新版本才能使用,娱乐管家需要升级到版本10.3.6190以上

4.为什么学习了但是有些和本店图案不一样的杂币没有被排出?

为了保证出币速度,收币车仅支持排出尺寸不一样的杂币,不支持图案识别

5.控制台显示"故障-马达卡币"怎么处理?

马达有自动排出异物功能,但太大的异物不能自动排出,需要手动操作,见如下视频
