# 一、作业说明

如何正确安装并调试自助发卡机

# 二、作业准备

1.自助发卡机

2.十字螺丝刀

# 三、注意事项

无

# 四、作业标准

设备正常安装并能正常运行

# 五、作业步骤

1.拆除设备包装，检查设备整体外观是否完好无损。

2.安装顶部广告牌

3.打开后门，在卡槽里面放置会员卡，并加下压片。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cedeb73a6d&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cedebf3a6e&type=med)

4.找到发卡机背后底部电源处，连接网线和电源线，通电通网后打开电源开关，开机。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cedfd13a6f&type=med)

5.在初始化弹窗界面输入服务器IP地址信息。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cedfd83a70&type=med)

若门店是本地部署（即服务器系统是安装在本地电脑环境），

则选择内场，并输入本地服务器ip地址 ***.***.***.***:9999

若不知道如何查找网络ip地址或网关，可参考下述文档进行查找：

怎么查看自己电脑网关和ip地址？_百度知道 (baidu.com)

若门店是云端部署（即服务器系统是安装在油菜花云端服务器），

则选择外场，输入门店域名地址，如y********.yun.youcaihua.net:88；

6.进去主界面之后，点击右上角设置按钮并输入密码进入后台。密码****（已脱敏，请向运维索取）或1。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16ce51f63a69&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cee0b73a71&type=med)

7.进入后台之后，选择发卡模式。并选择所需功能。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148874857e018a16cee1cb3a72&type=med)

8.退出后台，测试各功能是否正常即可。

# 六、常见问题

1.发卡机不出卡？

检查是否缺卡或者没有加压片。

2.读卡失败？

检查读卡器链接是否正常。

测试会员卡能否正常读取信息。
