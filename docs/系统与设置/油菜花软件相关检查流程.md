# 一、文档说明

此文档用于检测油菜花系统各项设置是否正常的检查流程。请务必在上门巡检时按照此流程进行检查并且记录在检查报告中。

# 二、检查内容概况

- 油菜花软件程序版本更新

- 油菜花文件存放规范

- 服务内存占用率

- HOST日志异常检测

- 油菜花备份功能检查

- 油菜花数据库检查

- VPN配置检查

- （安全性检查）开机密码检查

- （安全性检查）防火墙是否开启

- （安全性检查）病毒查杀

- （安全性检查）无关软件清理

# 三、检查流程

### 1. 油菜花系统版本检查

合格标准：油菜花系统升级到最新版本

异常处理：未升级到最新版本则在营业结束后升级到最新版本

需要记录内容：当前油菜花系统版本

检查流程说明：登录油菜花系统后台，点击右上角选择系统信息，查看是否有更新信息，如果提示有更新信息，则代表有新版本可更新。并拍照记录。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197773e64817f8a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197773f72a37f93&type=max)

### 2.油菜花软件存放路径检查及文件夹命名规则

合格标准：

①油菜花程序一定不能放置在系统盘（一般WINDOWS系统盘为C盘）

②油菜花程序优先放置在固态硬盘（如有）

③油菜花程序尽量放置在Program Files的文件夹内，并且命名建议是YCHMALL；如果门店存在多个油菜花系统同时运行，则应命名按照YCHMALL+门店编码形式存放

异常处理：

①发现油菜花程序如果存放在系统盘，需要在营业结束之后，将其迁移到非系统盘；

②如果服务器有固态硬盘，且油菜花系统文件夹不是存放在固态硬盘中，需要在营业结束之后，将其调整到固态硬盘；

③如果发现文件不是存放在Program Files文件夹内，可建议迁移到对应文件夹内（非必须）；

④如果发现油菜花系统文件夹命名不规范，需要在营业结束后调整文件夹名称。

需要记录内容：文件夹存放路径拍照记录。

### 3. 服务器内存检查

合格范围：内存率不超过95%，CPU使用率不会超过30秒占比超过50%

异常处理：①检查是否有非油菜花应用占用CPU使用率；②修改数据库最大内存数；③删除无关的软件应用；④如果服务器太老旧，建议客户及时更换服务器，并将此内容记录在《巡检检查报告》中。

需要记录内容：任务管理器状态拍照

检查流程：

右键底部状态栏，选择【任务管理器】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977bcd648f0ffa&type=med)

查看CPU占用和内存占用率和CPU利用率是多少，并拍照记录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977bcd64950ffb&type=med)

### 4.HOST日志异常检测

合格标准：日志中不显示异常

异常处理：如发现异常，请及时联系研发确认异常是否影响门店使用。

需要记录内容：最后一个HOST日志最新一次记录需要拍照记录。

检查流程说明：

打开YCHMALL文件夹，检查LOG日志文件中，找到最近日期的HOST日志，打开并拉到最底，检查是否有报异常。并拍照截图。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019763320729220a&type=max)

### 5.油菜花备份功能检查

合格标准：

①数据库正常执行备份工作；

②数据库备份存放到指定文件夹（MallDataBackup），如果服务器有2个硬盘以上，应存放在与YCHMALL不同的磁盘上，且该磁盘不是系统盘。

③存放数据库备份的盘符空间冗余至少20%以上。

异常处理：

①MallDataBackup不存在备份数据，或者备份数据时间不是当日时间，在营业结束之后，调整后台的数据库备份参数，重新保存再重启服务器使其生效。

②备份文件夹在系统盘或者不在另外一个硬盘中，则在营业结束之后，调整后台的数据库备份参数，重新保存再重启服务器使其生效。

③存放数据库备份的盘符空间少于20%，建议客户增加硬盘并迁移备份到新硬盘。

需要记录内容：

①备份设置截图拍照

②备份文件夹截图拍照

检查流程说明：

登录系统后台→设置→数据备份设置，检查是否已经开启备份，并拍照记录。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cc4b30a1544&type=max)

打开服务器电脑，找到数据库备份路径文件夹，检查最近一次备份时间是否在当日，并拍照记录。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cc722fc154e&type=max)

### 6.油菜花数据库检查

合格标准：

①油菜花系统中的DataBase文件夹里面存放数据库原始文件，并且最后修改时间为当日

②打开数据库管理工具，数据库没有提示【质疑】

异常处理：

①如果DataBase文件夹为空，需要迁移原始文件到DataBase文件夹中

②如果提示数据库质疑，需要联系研发进行紧急处理（优先级最高）

需要记录内容：

①DataBase文件夹拍照记录。

②数据库管理器YCHMALL状态拍照。

检查流程说明：

打开服务器，并在YCHMALL文件夹目录下找到DataBase文件夹，检查文件夹是否存放数据库文件（mdf文件以及ldf文件），并拍照记录。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d0936cc1682&type=max)

服务器左下角开始菜单找到 Microsoft SQL Server Management Studio，打开并登录数据库，检查数据库中的YCHMALL库有没有标记异常，并拍照记录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d0b003d168c&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d0b4bed168d&type=max)

### 7.VPN配置检查

合格标准：

①VPN连接正常

②VPN中的虚拟网卡配置正常

③VPN自动连接开启

异常处理：

①VPN没有正常连接，假如客户不需要用小程序或者域名功能则不需要处理

②VPN中的虚拟网卡属性中，没有仅勾选IPv4协议，则去掉多余选项

③VPN没有设置自动连接，则勾选自动连接

需要记录内容：

①记录VPN的管理界面图

②记录VPN的虚拟网卡属性拍照截图

检查流程说明：

打开桌面VPN管理工具，查看VPN是否正常连接

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197819ca380268f&type=max)

打开对应VPN的网卡，检查配置是否正确

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197819ee5322697&type=max)

### 8.（安全性检查）开机密码检查

合格标准：要求要有开机密码，并由门店妥善保管

异常处理：没有开机密码，则设置开机密码

需要记录内容：拍照记录锁屏后是否提示需要开机密码的照片

检查流程说明：

在服务器桌面，按win键+L键进入锁屏，然后测试登录是否需要密码，如果没有提示需要密码则没有设置开机密码。

### 9.（安全性检查）防火墙是否开启

合格标准：防火墙正常开机，并且门店业务均为正常

异常处理：未开启防火墙，需要手动开启

需要记录内容：拍照记录防火墙状态

检查流程说明：

在服务器→控制面板→系统和安全→windows防火墙中，检查防火墙是否在正常开启。如果是关闭状态，必须要在营业结束后调整，避免因调整防火墙导致门店业务异常。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019781a7364326bd&type=max)

### 10.(安全性检查）病毒查杀

合格标准：没有检测到有病毒感染

异常处理：发现病毒进行杀毒处理

需要记录内容：拍照记录查杀结果

检查流程说明：

在门店营业结束后，使用杀毒软件进行查杀，并查看查杀结果。查杀完毕后卸载火绒

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019781a9faad26c6&type=max)

### 11.（安全性检查）无关软件清理

合格标准：无非服务器必备的软件

异常处理：发现非必要软件后，在营业结束后对其进行删除

需要记录内容：拍照记录【程序和功能】中已安装的程序

检查流程说明：

打开控制面板→程序→程序与功能，检查是否有无关程序在服务器中，如WPS、360杀毒等

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019781ad0f6c26d2&type=max)
