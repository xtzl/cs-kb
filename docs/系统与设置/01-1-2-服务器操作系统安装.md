0 1 - 2 服务器操作系统安装

一、 作业说明：

本教程仅提供一般方法给予服务器安装操作系统，适用范围为中小型服务器，部分机架式服务器无法通过此教程来进行安装。如遇到机架式服务器无法采用此教程，请联系服务器供应商了解对应服务器的安装方法。

二、 注意事项：

一般情况下，我们不主动为客户安装服务器操作系统，建议客户自行联系厂商进行安装。

如帮客户安装系统后，务必注意提醒客户自行激活操作系统，并告知客户如服务器操作系统不激活的情况下会引起系统异常。

1. 带PE启动盘一个。

四、 作业标准要求

1. 服务器开机能正常进入Windows server 2008 R2 企业版或Windows server 2012 R2 标准版 的操作界面。

2. 服务器分区符合以下要求

&Oslash; 仅分区为C、D两个盘符；

&Oslash; C盘容量为100G，包含操作系统所有文件，允许偏差+-5G；

&Oslash; 其余容量全部分配到D盘；

五、 作业步骤（以联想TS250为例）

1. 插入PE启动U盘，开启服务器，按启动快捷键F12进入U盘启动，并进入PE系统中。（各个品牌启动快捷键参考如下，特殊启动快捷键请联系供应商询问。）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d1112f3aa4&type=max)

2. 进入启动项选择后，选择U盘启动。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d155ba3aa5&type=max)

3. 在PE菜单中选择‘启动Windows 10 PEx64（新机型）’这个启动项，点击回车。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d178943aa6&type=max)

4. 硬盘分区，选择桌面上DG硬盘分区

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d1bf613aa7&type=max)

5. 先删除原有分区，再建立新分区

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d1f3cf3aa8&type=max)

6. 如本服务器使用的是Legacy启动模式，请转换分区表类型为MBR，否则请使用GUID（GPT）格式。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d253b23aa9&type=max)

7. 分区要求如下：

&Oslash; 分C、D两个硬盘即可。

&Oslash; C盘容量为100G。

&Oslash; 其余空间分配为D盘。

&Oslash; 如使用GUID（GPT）格式则系统会自动分500M为ESP/MSP分区。默认即可。

&Oslash; 其他设置为默认。

8. 关闭DG分区工具，并把镜像文件放到电脑D盘或者U盘中，并右击选择【装载】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d2c1313aaa&type=max)

9. 双击打开桌面上的【win系统安装】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d313493aab&type=max)

10. 在第一栏【选择包含Windows安装文件夹】中，选择镜像中的install.win文件。

文件路径如下：进入刚刚加载镜像文件夹，双击镜像内的【sources】文件夹，选择install.win文件即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d34f583aac&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d3bd833aae&type=max)

11. 选择磁盘安装的文件，直接指向C盘即可。并选择系统安装版本。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d7dd3c3ab8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d58daf3ab6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d6fa5e3ab7&type=max)

如果是安装Windows 2008系统，步骤和上述相似，只需在选择版本时选择Windows server 2008 R2 Enterprise（完全安装）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d840f83ab9&type=max)

注意：

&Oslash; 如果是安装Windows 2008，请选择 Windows server 2008 R2 Enterprise（完全安装）

&Oslash; 如果是安装Windows 2012，请选择Windows server 2012 R2 Standard（带有GUI的服务器）

12. 点击开始安装，然后点击确认。等待进度条读取完毕之后，重启电脑即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6dab96a3abe&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6d924ff3abd&type=max)

13. 安装完毕后，进入操作系统，运行万用驱动安装电脑驱动即可。

14. 驱动安装完毕后，请检查所有硬件是否正常运行，检查方法为：右键【此电脑】，选择管理，选择设备管理器，检查是否有带感叹号的硬件列表。如有请百度搜索对应硬件驱动进行安装。

下一步：在服务器上安装 NET Framework 3.5运行环境（Windows 2008版本）
