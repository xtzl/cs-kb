一、 作业说明：

此步骤为安装数据库的前置步骤，仅需要在服务器上安装即可，在安装SQL2008数据库前必须先启动服务器中的Net Framework 3.5功能，否则会导致数据库无法正常安装。

此步骤分为windows server 2008 R2版本和windows server 2012 R2版本，不同的版本安装方式有所差异，请务必注意。

二、 作业准备：

无

三、 作业标准

Net Framework 3.5在启用状态。

四、 作业步骤

1. 在“控制面板”找到“打开和关闭Windows功能”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6de727a3ae7&type=max)

2. 点击添加功能

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6deb9d43ae8&type=max)

3. 勾选“.net Framework 3.5.1 功能”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6def13f3ae9&type=max)

4. 点击【添加所需的角色服务】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6df46453aea&type=max)

5. 点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6dfa6e33aeb&type=max)

6. 直接点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6dff3003aec&type=max)

7. 这里默认就好了，然后直接点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6e05e4d3aed&type=max)

8. 点击安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6e09b653aee&type=max)

9. 等待安装完成即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6e0caa33aef&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6e1123b3af0&type=max)
