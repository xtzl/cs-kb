# 问题描述

在游乐宝系统用工具升级合并到新娱总部的前提下：

游乐宝系统是2008sql数据库，所合并的目标总部是2016数据库，

用升级工具升级时，因升级门店跟目标合并总部的数据库版本不一致，无法在原游乐宝操作系统上安装新娱门店系统，导致无法直接升级。

# 原因分析

安装新门店时，需要在原游乐宝系统的操作环境下下拉总部数据（类似在2008数据库上还原2016数据库的总部数据），因数据库只支持向下兼容的特性：即在2016sql数据库上可还原2008sql数据库数据，反之在2008sql数据库上无法还原2016sql数据库，

因此在升级时或安装总部下新门店时需优先解决数据库版本不一致的问题。

# 解决方案

### 情形一

操作系统是windows server 2008的情况下：

准备多一台服务器主机电脑（操作环境需要是2016windows server版本），并安装2016sql数据库（2008windows server不支持安装2016sql数据库）

将原游乐宝的所有系统文件转移到新主机电脑上，再进行附加还原系统，待新门店系统安装后，门店开始进行升级。

### 情形二

操作系统是windows server 2012R2/2016R2的情况下：

在服务器系统上加装2016sql数据库，安装新门店时指定2016sql数据库；

待新门店系统安装后，门店开始进行升级。
