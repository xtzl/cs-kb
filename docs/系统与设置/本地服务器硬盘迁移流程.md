# 一、 作业说明

本流程用于门店为解决硬盘读取限制问题，需要增加固态硬盘并将油菜花系统迁移到固态硬盘的操作说明

# 二、操作准备

1.服务器提前加装好固态硬盘

2.门店营业结束后操作

# 三、操作流程

## 1.对加装的固态硬盘进行分区

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdc904d2109f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdca047610a5&type=max)

注意：如果提示无法识别硬盘，需要转化格式，直接选择默认即可，直到能显示该盘符为止。

## 2.停止油菜花服务，将以下两个服务都停止。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdcf668810ba&type=max)

## 3.删除服务，右键开始，选择【命令提示符（管理员）】-执行以下语句

sc delete Mall.Host

sc delete Mall.Monitor

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdd0cc6f10c1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdd4c2e910cd&type=max)

提示删除成功后，检查一下服务管理器中是否还有这个服务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdd56a9810ce&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdd5d89c10cf&type=max)

如果这里已经不显示【商场业务服务】和【商场守护服务】，则代表已经删除成功，如果未停止服务直接删除，有可能会卡状态，此时需要重启服务器解决。

## 4.分离数据库

4.1登录数据库界面，检查数据库存放在哪个文件夹中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdec4ba91150&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbded06751152&type=max)

确认以下这个路径是否YCHMALL文件夹中，建议最好拍照记录好。

4.2 分离数据库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdee40f41159&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdef2e42115d&type=max)

## 5.剪切整个文件夹到新硬盘

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdf2ef861164&type=max)

## 6.剪切完成后，附加数据库

登录数据库，右键选择附加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fd17d55d84c80&type=max)

选择【添加】要附加的数据库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fd17dc4094c82&type=max)

原数据库路径在迁移后的硬盘中的【YCHMALL】文件夹内的【DATABASE】中，文件名称默认应该是YCHMALL.MDF

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fd17eb9144c84&type=max)

点击【确定】后，应该会返回到首页，右键刷新即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fd17f2de84c85&type=max)

## 7.双击运行迁移后的Mall.Monitor.exe，会自动安装服务并自动启动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdf4bd5a1169&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fbdf563ed116e&type=max)

到此为止，服务迁移完成。
