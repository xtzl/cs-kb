# 一、 作业说明

本安装说明主要讲解如何在收银电脑或者办公电脑安装 游乐宝 管理后台和收银前台的步骤、安装标准及注意事项。

# 二、 作业准备

1.电脑一台，需要至少windows 7 64位以上的操作系统

2.已安装.net4.5.2以上的运行环境。

下载链接：https://nos-pulic.nos-eastchina1.126.net/NET4.5%281%29.exe

3.提前获取门店云服务器的域名地址。一般格式为http://y（门店编号）.yun.youcaihua.net:88/admin

# 三、 说明事项

1.游乐宝的后台可使用网页进行登录，即云服务器域名地址，但是会有部分功能受到限制，如读卡功能（包括读取会员卡和写入配置卡功能）、打印模板设置功能以及打印功能均无法使用，必须安装客户端。

2.客户端下载可通过登录游乐宝后台后进行下载；

3.收银台只有客户端，没有网页版。

# 四、 作业标准

1.安装路径必须是非系统盘（特殊情况除外）；

2.安装完毕后，重新登录收银台不提示绑定信息。

# 五、 作业步骤

1. 打开云服务器域名地址，并使用管理员账号登录后台，选择【下载】并选择对应的安装包进行下载

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e50ce4e1b1a91&type=max)

2.下载完毕后，双击运行后台安装包，选择安装路径，点击安装。

2. 填入服务器地址，注意服务器地址需要填写端口号，如下图所示：(例如云服务器域名地址是http://y（门店编号）.yun.youcaihua.net:88/admin，则在这里填写的服务器地址是http://y（门店编号）.yun.youcaihua.net:88/, 注意中间的冒号是英文冒号，并且不要填入admin）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e50d28a841a9a&type=max)

3. 点击确定，完成后台安装。

4. 登录后台，在【设置】-【收银设置】 - 【收银终端】中点击新增。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b28d0e8d25a97&type=max)

5. 填写终端名称，一般建议设置为一号收银台、二号收银台等（根据现场收银台数量进行设置），选择终端类型为PC终端，保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7ef18f13e75&type=max)

6. 使用收银前台安装包进行安装，安装方法与后台一致。

7. 输入服务器地址，注意服务器地址需要填写端口号，(例如云服务器域名地址是http://y（门店编号）.yun.youcaihua.net:88/admin，则在这里填写的服务器地址是http://y（门店编号）.yun.youcaihua.net:88/, 注意中间的冒号是英文冒号，并且不要填入admin），提示绑定终端，请填写管理员账号及密码，选择刚刚建立的收银终端，点击绑定即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b28dd16215a99&type=max)

8.绑定终端后即可正常登录系统
