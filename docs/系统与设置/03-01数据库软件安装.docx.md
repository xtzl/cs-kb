Microsoft SQL Server 2008数据库安装说明

1、作业说明：

本安装说明为数据库安装的步骤说明，数据库作为油菜花系统的核心软件之一，安装时务必安装下述详细步骤进行安装，否则会引起后续安装的异常，请务必注意。

2、作业准备：

1.NET Framework 3.5已安装完毕。

2.SQL2008安装包文件已下载到服务器中。

下载链接如下：ed2k://|file|cn_sql_server_2008_r2_enterprise_x86_x64_ia64_dvd_522233.iso|4662884352|1DB025218B01B48C6B76D6D88630F541|/

3、作业标准：

1.数据库功能需要全部安装（步骤4）

2.数据库共享功能目录及共享功能目录（x86）都需要改成D盘目录下（步骤4）

3.数据库实例根目录需要改成D盘目录下（步骤5）

4.数据库引擎身份验证模式为混合模式（步骤7）

5.SA管理员账号密码为：****（已脱敏，请向运维索取）（步骤7）

4、注意事项：

1.此教程仅适用于服务器初次安装数据库时使用，已安装数据库的服务器需要将之前安装的数据库彻底删除后才能再次安装。

5、作业步骤：

%2.双击运行SQL2008数据库安装程序，数据库开始安装

%2.左边选择 安装 ，然后右边选择第一项

%2.点确定、下一步、接受许可条款，并进行安装，然后再点下一步

%2.全选，然后选择安装目录，装在D盘，点下一步

%2.选择默认实例，也装在D盘，然后下一步

%2.第一项服务“SQL Server 代理”的帐户名选NT AUTHORITY\SYSTEM，其他项服务的帐户名选NT AUTHORITY\NETWORK SERVICE

%2.设置密码，添加用户，然后下一步
