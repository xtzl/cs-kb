# 一、 作业说明

本安装说明为娱乐管家（单门店）服务端使用网络授权进行安装，服务端仅需在服务器上进行安装即可，其他电脑无需安装。网络授权方式对网络依赖度较高，所以一般情况下不使用网络授权。

# 二、 作业准备：

1. 预下载娱乐管家（单门店）服务端安装包

2. 预下载娱乐管家（单门店）升级包

3. 网络授权文件1个

4. 已安装数据库及运行环境的服务器一台。

# 三、 作业标准：

1. 娱乐管家（单门店）所有服务均能在正常服务状态

2. 其他电脑能正常访问娱乐管家（单门店）系统

四、 注意事项：

1. 如果已安装过娱乐管家（单门店）系统或者娱乐管家系统的服务器电脑，务必需要将娱乐管家（单门店）/娱乐管家彻底删除后才能重新安装。

2. 服务器安装前务必将无关的软件，如360杀毒、WPS等软件先卸载再进行下列操作。

五、 作业步骤：

1. 双击运行MallHostSetup.exe，确认安装路径是否正确，一般适用默认路径（D:\Program Files\YCHMall）即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7b9caa33d89&type=max)

2. 点击安装即可完成安装，安装完毕后，出现以下提示，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7b9e81e3d8a&type=max)

3. 点击注册，选择使用网络授权，将机器码复制出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7ba142f3d8b&type=max)

4. 将机器码以及这个门店的门店编号提供给油菜花相关人员（实施组组长、客服组组长），让其生成网络授权文件，一般文件后续LIC，大小为5KB。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7ba33ed3d8c&type=max)

5. 点击【浏览】，选择网络授权文件后，解锁安装参数填写。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7c1bfdf3d95&type=max)

6. 填写数据库密码，检查数据备份路径是否正确，如果都正确，点开始安装即可。

（注意，如果客户服务器有2块以上硬盘，则需要将数据备份路径盘符改到另外的硬盘目录下）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7c0ff5d3d93&type=max)

7. 依次点击安装服务即可完成全部安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7c1ff1a3d96&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7c217463d97&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7c24dd63d99&type=max)

# 六、 常见问题：

1. 提示“配置错无，请确认配置正确后重新安装。错误信息：设备未就绪。”

原因：数据备份路径错误，或者不正确。

解决方法：更正数据备份路径。

2. 服务无法启动，LOG日志无异常。

原因：服务启动超时

解决方法：

&Oslash; 下载超时注册列表，下载链接： https://nos-pulic.nos-eastchina1.126.net/%E5%BC%80%E5%90%AF%E6%9C%8D%E5%8A%A1%E8%B6%85%E6%97%B6%E6%96%B0%282%29.reg

&Oslash; 双击合并注册列表

&Oslash; 重启服务器
