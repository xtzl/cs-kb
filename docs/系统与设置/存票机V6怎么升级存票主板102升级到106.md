# 存票机V6怎么升级存票主板102升级到106

第一步：准备一个U盘，将升级apk放入
第二步：将U盘插入设备主板的usb口
第三步：退出油菜花软件返回设备系统桌面，进入操作系统设置，找到存储，选择拷贝的程序双击安装
第四步：找到新安装的应用的图标，点击进入点击升级，提示升级成功后重启一下设备即可，然后进入测试程序确认一下存票板的版本如果变更为106则升级成功
