## 问题描述

游乐宝升级新娱后，手机报表数据显示不全

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a4dd0ad16d7&type=max)

数据修复重算提示【无法连接到远程服务器】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a4eff3c16d8&type=max)

## 原因分析

升级后若遇到该报错，需要进行数据修复，重算下手机报表数据

## 解决方案

### 数据修复正常无报错

1.在【设置】->【数据修复】路径进行数据修复

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a5173cd16df&type=max)

若提示修复成功，则在【设置】->【定时任务监控】路径下搜索手机报表，执行下述俩个定时任务，再重启门店服务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a53be6316e4&type=max)

### 数据修复异常，提示【无法连接到远程服务器】

1.在【设置】->【数据修复】路径进行数据修复

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a5afe6816fb&type=med)

2.若提示【无法连接到远程服务器】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a5b024716fc&type=med)

有以下解决步骤：

a.打开数据库，执行语句【仅针对单店】

update Mall_MallInstance set MasterURL='http://127.0.0.1:9999/'

b.上述语句执行成功后，接着执行语句【仅针对单店】；

update MRPT_MallBasePushInfo set PushPoint='1975-01-01',LastUpdateTime=null （大概需要等待半小时）

c.执行成功后，再返回【设置】->【数据修复】路径进行数据修复；

d.若提示修复成功，则在【设置】->【定时任务监控】路径下搜索手机报表，执行下述俩个定时任务；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a2a62a7b21744&type=med)

e.执行完毕后重启门店服务
