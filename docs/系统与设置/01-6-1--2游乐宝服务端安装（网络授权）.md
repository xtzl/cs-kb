# 一、 作业说明

本安装说明为游乐宝服务端使用网络授权进行安装，服务端仅需在服务器上进行安装即可，其他电脑无需安装。网络授权仅用于特殊情况，如云服务器部署，或者特殊门店。由于网络授权受网络影响，一般情况不适用网络授权。

# 二、 作业准备：

1. 预下载游乐宝服务端安装包

2. 预下载游乐宝升级包

3. 网络授权文件1个

4. 已安装数据库及运行环境的服务器一台。

# 三、 作业标准：

1. 游乐宝所有服务均能在正常服务状态

2. 其他电脑能正常访问游乐宝系统

# 四、 注意事项：

1. 如果已安装过游乐宝系统或者娱乐管家系统的服务器电脑，务必需要将游乐宝/娱乐管家彻底删除后才能重新安装。

2. 服务器安装前务必将无关的软件，如360杀毒、WPS等软件先卸载再进行下列操作。

# 五、 作业步骤

1. 双击运行MallHostSetup.exe，确认安装路径是否正确，一般适用默认路径（D:\Program Files\YCHMall）即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a7e7a93d32&type=max)

2. 点击安装即可完成安装，安装完毕后，出现以下提示，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a80dce3d33&type=max)

3. 点击注册，选择使用网络授权，将机器码复制出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a83c223d34&type=max)

4. 将机器码以及这个门店的门店编号提供给油菜花相关人员（实施组组长、客服组组长），让其生成网络授权文件，一般文件后续LIC，大小为5KB。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a8c6223d35&type=max)

5. 点击【浏览】，选择网络授权文件后，解锁安装参数填写。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a8f06e3d36&type=max)

6. 填写数据库密码，检查数据备份路径是否正确，如果都正确，点开始安装即可。

（注意，如果客户服务器有2块以上硬盘，则需要将数据备份路径盘符改到另外的硬盘目录下）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a923073d37&type=max)

7. 依次点击安装服务即可完成全部安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a959f53d38&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a999213d39&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a9b91d3d3a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac7a9d6d63d3b&type=max)

8. 点修改【服务器超时时间为120秒】，然后重启服务器。

9. 点系统端口添加入站规则，然后开启服务器防火墙。

10. 完成所有的安装。

# 六、 常见问题：

1. 提示“配置错无，请确认配置正确后重新安装。错误信息：设备未就绪。”

原因：数据备份路径错误，或者不正确。

解决方法：更正数据备份路径。
