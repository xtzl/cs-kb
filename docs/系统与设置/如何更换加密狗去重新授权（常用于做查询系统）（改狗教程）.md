# 文档说明

此教程用于指引如何改门店的加密狗，并重新授权启动服务。常用于改狗做成查询狗用于系统查询用。

# 操作步骤

## 1.打开SSMS，登录到数据库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199e755c5df5bda&type=max)

## 2.选择需要改狗的数据库，并右键新建查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199e75647d05bdb&type=max)

## 3. 先修改Mall_mall表

3.1通过以下语句找到门店对应的ID号（注意，这个表的门店ID和下面步骤查找的Mall_Business表的门店ID是不一样的，要分别查找）

select * from Mall_Mall

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a0b5d212e3bda&type=max)

3.2然后执行

update Mall_Mall set MallCode ='新加密狗编号' where ID ='门店ID'

执行前将真实门店ID和新门店编码复制填写到语句中，假如旧加密狗编码对应ID列为5AD12AD1-6740-4F76-BA05-F6050BF04963，新门店编码为88888888则执行

update Mall_Mall set MallCode ='88888888' where ID ='5AD12AD1-6740-4F76-BA05-F6050BF04963'

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a0b61816a3bdf&type=max)

## 4.再修改 Mall_Business 表

4.1先执行以下数据，找到对应的门店ID，复制出来（注意，这个表的门店ID和上面步骤查找的Mall_mall表的门店ID是不一样的，要分别查找）

语句如下：

select * from Mall_Business

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199e75831255be2&type=max)

4.2然后再执行下述的语句

update Mall_Business set BusinessNum='新门店编码' where ID ='门店ID'

执行前将真实门店ID和新门店编码复制填写到语句中，假如旧加密狗编码对应ID列为5AD12AD1-6740-4F76-BA05-F6050BF04963，新门店编码为88888888则执行

update Mall_Business set BusinessNum='88888888' where ID ='5AD12AD1-6740-4F76-BA05-F6050BF04963'

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199e75c4d2b5bf1&type=max)

## 5.在YCHMALL文件夹中打开setup.exe,点击注册，选择新的门店编码的注册文件，等待界面更新到新的门店编码后，点击关闭即可（注意千万不要点安装）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d40199e75faa705bff&type=max)
