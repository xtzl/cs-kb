# 一、 作业说明
本安装说明为娱乐管家（海外版）服务端使用网络授权进行安装，服务端仅需在服务器上进行安装即可，其他电脑无需安装。

# 二、 作业准备

1. 预下载娱乐管家（海外版）服务端安装包

注意：

东南亚版请使用20.1.2001初始安装包

欧美版请使用20.1.3001初始安装包

2. 预下载
娱乐管家（海外版
）升级包

3. 网络授权文件1个

4. 已安装数据库及运行环境的服务器一台。

# 三、 作业标准
1.
娱乐管家（海外版
）所有服务均能在正常服务状态

2. 其他电脑能正常访问
娱乐管家（海外版
）系统

# 四、 注意事项
1. 如果已安装过娱乐管家其他版本系统的服务器电脑，务必需要将
娱乐管家其他版本的系统彻底删除后才能重新安装。如需同一服务器下安装多个娱乐管家系统，可参考 《
同一个服务器下安装多个门店安装流程》

2. 服务器安装前务必将无关的软件，如杀毒软件、办公软件等无关软件先卸载再进行下列操作。

3. 不同国家的需要根据实际情况选择安装包

东南亚版请使用20.1.2001初始安装包

欧美版请使用20.1.3001初始安装包

4. 授权文件时间不受时区影响，只需要时区正确即可。

# 五、 作业步骤
1. 双击运行MallHostSetup.exe，确认安装路径是否正确，一般适用默认路径（D:\Program Files\YCHMall）即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d8ee7733&type=med)

2. 点击安装即可完成安装，安装完毕后，出现以下提示，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d8f77734&type=med)

3. 点击注册，选择使用网络授权，将机器码复制出来

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d8fe7735&type=med)

4. 将机器码以及这个门店的门店编号提供给油菜花相关人员（实施组组长、客服组组长），让其生成网络授权文件，一般文件后续LIC，大小为5KB。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d9077736&type=med)

5. 点击【浏览】，选择网络授权文件后，解锁安装参数填写。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d90f7737&type=med)

6. 填写数据库密码，检查数据备份路径是否正确，如果都正确，点开始安装即可。

（注意，如果客户服务器有2块以上硬盘，则需要将数据备份路径盘符改到另外的硬盘目录下）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db819d9187738&type=med)

7. 依次点击安装服务即可完成全部安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db816ab9d7704&type=max)

# 六、 常见问题
1. 提示“配置错无，请确认配置正确后重新安装。错误信息：设备未就绪。”

原因：数据备份路径错误，或者不正确。

解决方法：更正数据备份路径。

2. 服务无法启动，LOG日志无异常。

原因：服务启动超时

解决方法：

点击修改服务超时时间为120秒，然后重启服务器

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db8173edf7719&type=max)

3.启动服务报错,也点击修改服务器超时时间并重启服务也没效果

原因：没有安装.net4.8.1

解决方法：安装.net4.8.1运行环境
