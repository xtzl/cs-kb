# 一、使用说明

本工具仅用于本地服务器安装油菜花海外版系统使用，仅适用于操作系统在windows server 2016 英文版及以上的版本中使用，支持安装娱乐管家海外欧美版和娱乐管家海外东南亚版使用。

# 二、准备工作

1.确保操作系统在windows server 2016 标准版以上，且操作系统为中文操作系统

2.确保服务器硬盘分区至少为C D两个以上的盘符；

3.下载自动安装包，下载链接如下：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/99.一键安装包/YCH_Nano Auto-Install（Internal Use Only）V2.1.exe

# 三、功能支持

1.支持自动安装SQL2016数据库及SSMS管理软件；

2.支持手动选择性安装；

3.内置常用软件：RAR解压工具、前台收银台安装包、谷歌浏览器、限制数据库内存大小脚本、向日葵远程工具安装包、人脸识别运行环境、.net 4.8.1运行环境等；

4.支持选择安装东南亚版本（20.1.2）或欧美版本（20.1.3）。

# 四、操作说明

## 1.提前确保windows操作系统是否在windows server 2016 及以上的版，如果低于该版本，可能不支持安装。

## 2.确认磁盘分区是否已经按要求分区；

分区要求：

①至少有2个以上的盘符，分别为C 、D盘；

②C盘为操作系统盘

③D盘为油菜花系统盘，预留空间建议不少于200G，如果服务器有固态硬盘的机械硬盘情况下，固态硬盘可划分C盘和D盘，C盘可划分100G后剩余所有空间划分为D盘，机械硬盘划分为E盘；

磁盘分区操作，请查看此链接：《如何进行磁盘分区》

## 3.右键管理员运行《油菜花安装整合包（内部用）》

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db49783a563ae&type=max)

## 4.点击安装整合包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db497c73863b0&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db498097d63b1&type=max)

## 5.安装完毕后，会提示是否安装.net 4.8.1运行环境，输入小写y，按回车开始安装

注意如果不需要安装则按q跳过

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db4993ba363ba&type=max)

## 6.安装完毕后，会提示是否开始安装数据库，如果输入“y”（小写），则会自动安装数据库，输入“q”则代表手动自行安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db49f27a763ce&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db4a1e69e6414&type=max)

## 7.数据库安装程序执行完后，可选择是否安装欧美版本还是东南亚版本，输入：1为欧美版本（20.1.3）；输入：2为东南亚版本（20.1.2）；如果是连锁版，输入:q，退出安装，并下载对应版本的安装包进行安装

输入1，则会显示安装娱乐管家欧美版：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db4a2f44d641e&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db4aab22c651d&type=med)

## 8.安装教程请查看下列教程来安装

按照正常国内版安装方案进行安装即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db4aab235651e&type=med)
