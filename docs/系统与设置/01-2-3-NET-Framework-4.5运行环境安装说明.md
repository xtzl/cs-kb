# 一、 作业说明

此步骤为安装油菜花系统软件必要步骤，此步骤需要在所有油菜花系统安装的电脑终端上安装，部分版本（如windows 10）自带有Net Framework 4.5或者更高的版本则可无需安装。

# 二、 作业准备

1. Net Framework 4.5.2安装包。

下载链接如下：

https://nos-pulic.nos-eastchina1.126.net/NET4.5%281%29.exe

# 三、 作业标准

Net Framework 4.5.2为安装完成状态。

# 四、 注意事项

1. 假如已经安装过4.5.2或者已有更高版本的Net Framework，则不需要再次安装。

# 五、 作业方法

1. 打开Net Framework 4.5.2安装包，则出现以下界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6f06e2d3b1b&type=max)

2. 选择”我已经阅读并接受许可条款“前面打对勾，否则文件不能安装。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6f097213b1c&type=max)

3. 现在单击“安装”软件进行安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6f0d0cf3b1d&type=max)

4. 现在提示软件安装完毕，已安装net framework 4.5，单击“完成”现在软件安装完成

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac6f10e173b1e&type=max)
