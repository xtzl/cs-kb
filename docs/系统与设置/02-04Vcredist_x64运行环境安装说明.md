# 一、作业说明

此运行环境功能涉及到照片录入、人脸识别等功能，仅需要在服务器中安装即可，属于服务器安装的前置任务。

# 二、作业准备

### 1.vcredist_x64.exe安装包

#### 下载链接：

https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/实施组安装工具/2.本地服务器运行环境/vcredist_x64.exe

# 三、作业标准

安装过程中无报错，安装完后续人脸识别、照片录入等功能均能正常工作。

# 四、作业方法

1.右键管理员运行vcredist_x64.exe安装包。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d12ee3c3f2989&type=med)

2.勾选【我同意许可条款和条件（A）】,然后点击安装。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d12ee3c3f298a&type=med)

3.点击下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d12ee3c4e298b&type=med)

4.等待完成即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d12ee3c5e298c&type=med)
