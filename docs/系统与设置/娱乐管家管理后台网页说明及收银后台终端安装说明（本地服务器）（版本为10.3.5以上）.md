# 一、 作业说明

本安装说明主要讲解如何在收银电脑或者办公电脑使用管理后台和安装收银前台说明文档。由于10.3.5版本以上的娱乐管家已经取消的管理后台的安装包，管理后台已经变成网页的形式来打开使用，务必要留意

# 二、 作业准备

1. 电脑一台，需要至少windows 7 64位操作系统，建议使用windows 10 64位以上的操作系统；

2. 收银台安装包；

3. 已安装.net4.5.2以上的运行环境；

4. 门店服务器固定IP地址。

5. 下载并安装谷歌浏览器，下载地址如下：

https://nos-pulic.nos-eastchina1.126.net/%E5%AE%9E%E6%96%BD%E7%BB%84/%E9%AB%98%E6%99%93%E9%92%A6/107.0.5304.122_chrome64_stable_windows_installer.exe

# 三、 注意事项

收银终端不要重复绑定

# 四、 安装标准

1. 安装路径必须是非系统盘

# 五、 安装步骤

## 管理后台网页部分

说明：云服务器会提供管理后台网页登录，所以直接使用网页进行登录即可。为方便客户时间，建议将网页独立生成一个快捷方式给予客户使用。如果需要后台读取会员卡的操作，如写配置卡、读会员信息等操作，则需要再下载并启用【油菜花助手】工具才可以

操作流程：

### 如何建立快捷方式到桌面

1.通过谷歌浏览器，打开管理后台网页，如服务器地址为192.168.10.10，则打开后台网页地址为：http://192.168.10.10:9999/admin

2.打开域名地址后，在谷歌浏览器右上角菜单-选择【更多工具】/【保存并分享】-【创建快捷方式】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201902fce233d4db4&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa4705dde3933&type=med)

3.创建完毕后，桌面和任务栏就出现油菜花的图标，并且双击进去能快速打开后台网页

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa4705dea3934&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa4705df33935&type=med)

## 收银台安装客户端部分

1.登录后台，在【终端】-【收银终端】-【新增】-先添加好对应的终端；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47061ee3940&type=med)

2.下载收银端安装包，在后台-右上角【下载】-选择下载收银台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47062c33941&type=med)

*如出现下载版本不对，请使用FTP重新下载收银台安装包：下载教程

2. 双击运行后台安装包，选择安装路径，点击安装。

3. 如出现下面提示，选择【更多信息】-【仍然运行】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47062cd3942&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47062d63943&type=med)

4.按照引导安装来完成安装过程

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47062df3944&type=med)

5. 安装完成后，弹出服务器地址需要填写

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa46fdce43930&type=max)

6.填入服务器地址，一般为：服务器IP地址:9999

7.弹出终端绑定后，输入管理员账号密码，并选择绑定的终端

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47062e93945&type=med)

8.完成安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fa47063cb3946&type=med)

# 常见问题

收银台读卡时偶尔提示未找到读卡器

原因：

可能同时打开后台网页导致，或者打开的油菜助手所导致，

解决方法：

关闭后台网页和油菜助手后重新插拔一下读卡器再试试。
