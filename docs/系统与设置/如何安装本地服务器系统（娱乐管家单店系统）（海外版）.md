# 文档说明

本文档用于指引如何安装海外版本地服务器操作指引。目前海外版分东南亚版以及欧美版本，不同版本的版本号略有不同，请务必注意不要安装错误。

目前区分如下（不定期更新）：

欧美版本所用地区：美国

东南亚版本所用地区：东南亚国家、中东国家等

# 前期准备

#### 1.确认服务器系统版本是以下其中一个版本

①windows server 2008 R2 Standard/Enterprise/Datacenter 其中之一

②windows server 2012 R2 Standard/Datacenter 其中之一

③windows server 2016 Standard/Datacenter 其中之一

④windows server 2019 Standard/Datacenter 其中之一

⑤以及版本更高的server版本

注意：中文版或者英文版都可以。
