# 一、 作业说明

本安装说明针对为海外客户安装英文版操作系统时，需要安装英文版数据库的步骤说明，数据库作为油菜花系统的核心软件之一，安装时务必安装下述详细步骤进行安装，否则会引起后续安装的异常，请务必注意。

# 二、 作业准备

## 1.服务器Windows版本至少为以下版本

Windows server 2016 R2 标准版（英文版）

Windows server 2019 R2 标准版（英文版）

以及更高版本

## 2. SQL2016安装包文件已下载到服务器中。

### 数据库运行环境（.net4.8.1）

# 三、 作业标准

1. 数据库安装及SSMS程序安装无报错

2. 数据库引擎身份验证模式为混合模式

3. SA管理员账号密码为：****（已脱敏，请向运维索取）

# 四、 注意事项

1. 此教程仅适用于服务器初次安装数据库时使用，已安装数据库的服务器需要将之前安装的数据库彻底删除后才能再次安装。

2.此教程仅针对WINDOWS 操作系统内核为英文版的才可以使用，国内版本请查看 数据库软件安装（2016版本）

# 五、 作业步骤

说明，本数据库需要安装两个程序，第一个为数据库主体程序，第二个为查询程序

## 主体程序安装说明

#### 1.数据库安装包和管理工具如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04be86db2b76&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04beec642b77&type=max)

#### 2. 右键选择运行SQL2016数据库安装程序（setup.exe），数据库开始安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04c791432b89&type=max)

#### 3. 左边选择【Installation】 ，然后右边选择第一项

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04ca35962b92&type=max)

#### 4. 一直点击【Next】，如图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04cb50042b9a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04cbcf832b9e&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04cc28182ba1&type=max)

#### 5.勾选【l accept the license terms】，点【Next】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04e88d952bee&type=med)

#### 7.点击勾选Database Engine Services、Client Tools Connectivity、Client Tools Backwards Compatibility、Client Tools SDK，路径改到D盘下，系统如果没有D盘，就安装到其他盘，不要在C盘即可，点Next，如图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04df4bb02bcb&type=max)

#### 8、直接点击【Next】即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04dfdd352bcf&type=max)

#### 9.无需修改，直接点【Next】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04e05b872bd1&type=max)

#### 10.选择【Mixed Mode (SOL Server authentication and Windows authentication)】，并输入密码和确认密码，填写为****（已脱敏，请向运维索取）56.(注意：如果客户有需求，可填写客户要求的数据库密码） 再点击【Add Current User】，完成后点击【Next】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04e4a6432bde&type=max)

#### 12.直接点击【Install】开始安装，直到安装结束

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04e5a5e72be2&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19989e7d4019a04eb93132c1b&type=max)
