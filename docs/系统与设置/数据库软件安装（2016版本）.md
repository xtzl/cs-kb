# 一、 作业说明

本安装说明为数据库安装的步骤说明，数据库作为油菜花系统的核心软件之一，安装时务必安装下述详细步骤进行安装，否则会引起后续安装的异常，请务必注意。

# 二、 作业准备

## 1.服务器Windows版本至少为以下版本

Windows server 2012 R2 标准版

Windows server 2016 R2 标准版（推荐使用）

Windows server 2019 R2 标准版（推荐使用）

以及更高版本

## 2. SQL2008安装包文件已下载到服务器中。

### SQL2016数据库安装包+数据库管理工具下载

### SQL2016限制数据库内存使用大小脚本下载

# 三、 作业标准

1. 数据库安装及SSMS程序安装无报错

2. 数据库引擎身份验证模式为混合模式

3. SA管理员账号密码为：****（已脱敏，请向运维索取）

# 四、 注意事项

1. 此教程仅适用于服务器初次安装数据库时使用，已安装数据库的服务器需要将之前安装的数据库彻底删除后才能再次安装。

# 五、 作业步骤

说明，本数据库需要安装两个程序，第一个为数据库主体程序，第二个为查询程序

## 主体程序安装说明

#### 1.解压数据库安装包

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6cd51652040&type=max)

#### 2. 右键选择运行SQL2012数据库安装程序（setup.exe），数据库开始安装

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6cea39f2044&type=max)

#### 3. 左边选择【安装】 ，然后右边选择第一项

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6d0d237205a&type=max)

#### 4. 直接点击【下一步】，如图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6d1d1fb2063&type=max)

#### 5.勾选【我接受许可条款】，点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6d2c43e2065&type=max)

#### 6.检查更新不需要勾选，此步骤直接点【下一步】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6d3720a2067&type=max)

如果出现下图报错，请按照下述方法来处理（如果没有报错就跳过这一步）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975e4a97ea11f0&type=max)

需要在数据库安装包的中找到DefaultSetup.ini文件，一般路径为【数据安装包→x64→DefaultSetup.ini】，打开该文件，并增加字段为“UpdateEnabled = False”，然后保存，重新运行程序即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975e4dd3791206&type=max)

#### 7.点击勾选数据库引擎服务、客户端工具连接、客户端工具向后兼容性、客户端工具SDK，路径改到D盘下，系统如果没有D盘，就安装到其他盘，不要在C盘即可，点下一步，如图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001961e57db59257b&type=max)

#### 8、直接点击【下一步】即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6d999c8207a&type=max)

#### 9.无需修改，直接点【下一步】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192e6da5cb1207e&type=max)

#### 10.选择【混合模式（SQL Server身份验证和Windows身份验证）】，并输入密码和确认密码，填写为****（已脱敏，请向运维索取）56. 再点击【添加当前用户】，完成后点击【下一步】

#### 12.直接默认参数点击【下一步】
