# 一、原因说明

如果服务器曾经做过迁移、还原数据库或者其他类似的操作时，升级时有可能报【当前版本无法读取】的报错。造成这个报错的原因是数据库内记录的商场ID和服务器中油菜花系统文件夹settings文件的其中一个参数不匹配所导致的。解决方法是替换该参数

# 二、报错示意图

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1c930696d38&type=max)

# 三、解决方法

1.登录数据库，并【新建查询】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1ca83fe6d3e&type=max)

2.执行数据库语句

select * from Mall_Mall

3.查询后，找到门店对应的ID

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1cc224a6d41&type=max)

4.右键复制该ID

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1cccbd56d46&type=max)

5.打开油菜花系统所在文件夹，并找到settings文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1ce49116d49&type=max)

6.将其中的【Cullmall】参数修改成从数据库复制出来的参数

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018fe1cf47db6d4c&type=max)

7.修改后保存该文件，并且重启服务。
