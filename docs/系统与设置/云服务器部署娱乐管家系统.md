# 一. 文档说明

本文档主要明确了云服务器部署娱乐管家单店版中的工作内容、作业准则、工作要求以及禁止事项，请所有实施相关人员务必认真阅读。

# 二. 注意事项

1.云服务器不需要安装数据库（运维已经提前安装了）

2.系统命名必须按照【门店编号-门店名称-业务端口】来命名；

3.数据库实例名称必须按要求进行修改，命名规则为YCHMALL门店编码

4.业务端口及机台端口按照要求修改，业务端口取值为9999-9980之间，机台端口取值范围为1099-1080之间

5.娱乐管家单店版系统必须部署在大客户服务器上面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad389b10284a&type=max)

# 三. 流程操作

## 3.1 娱乐管家单店版系统安装

1）填写云部署安装备案，门店编号+门店名称+业务端口+机台端口；服务器地址+业务端口

说明：业务端口一般顺延减少，例如安装备案上一个系统的安装备案为：60550003-浙江台州温岭酷幻潮玩-9982-1082，则代表业务端口为9982，机台端口为1082，这时候就不能再使用同一个端口，一般会设置为9981和1081；所以按这个规则命名新的门店的安装备案就是：“00000000-油菜花门店名称-9981-1081”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad190d0227e3&type=max)

2）双击运行安装程序，修改安装路径，文件夹命名规则为：门店编号+门店名称+业务端口，点击安装；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad3a44952857&type=med)

3）弹出安装程序时，按F1弹出修改示例设置；实例名必须填写门店编号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad3a449e2858&type=med)

4）填写完点击确定，重新授权并按照正常安装流程安装即可。

## 3.2 Setting参数修改

1）系统安装完成之后需要修改Setting文件，将下图安装备案里面的参数复制，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad2428a427ff&type=max)

2）将下图Setting文件里面的参数修改成刚复制的安装备案参数，保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad27acf22803&type=max)

3）升级娱乐管家单店版系统到最新版本

# 四. 云互联配置

1）在运维平台点击新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad2ee0a12820&type=max)

2）输入加密狗编号，点击获取VPN产品网站信息。将门店地址改成云服务器IP地址，娱乐管家端口改成门店业务端口，填写域名有效期，点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad3256fc282c&type=max)

3）点击UDP配置下面的添加，门店地址输入云服务器地址，机台端口改成门店云服务器机台端口，点击检查参数，点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192ad348eff2837&type=max)
