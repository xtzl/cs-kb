# 问题

扫钻石卡头上的二维码游玩时提示二维码已过期，收银台扫会员的二维码也提示二维码已过期，有可能是服务器上的时间与网络时间没有同步，需要到服务器上同步一下时间

# 解决方法

到本地服务器上同步一下时间
