# 一、文档说明

服务器温度检测可以反映服务器的运行状态，如果出现硬件温度过高的情况，可能会影响服务器的正常运行。

# 二、检查准备

温度检测工具下载：

https://pulic.oss.youcaihua.net/实施组安装工具/检查工具下载/温度检测工具（CUPIDHaddwareMonitor）.rar

# 三、检查方法

1.下载并打开温度检测工具

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019763019aac20d4&type=max)

2.记录并比对温度数据，判断是否正常

①主板温度

判断标准：

主板：通常 ≤50&deg;C

查看方法

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001976303d8b620de&type=max)

②CPU散热风扇转速

判断标准：

待机：800–1200 RPM，高负载：2000–4000 RPM

查看方法

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197630c82eb2122&type=max)

③CPU温度

判断标准

CPU：最大值 ≤80&deg;C

查看方法

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197630ef607212d&type=max)

④硬盘温度

判断标准

机械盘 ≤55&deg;C，SSD ≤70&deg;C（NVMe 硬盘可达 80&deg;C）

查看方法

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197631157012138&type=max)

3. 检查完毕后，需要将各项数据拍照记录

# 四、异常处理

1. 硬件普遍温度接近最大值，可判断为服务器运行环境较为恶劣，建议客户改善服务器环境

2. 硬件记录温度超过最大值，可判断服务器有宕机风险，需要及时处理（清理灰尘、检查散热风扇是否能正常工作、服务器工作环境过于恶劣需要调整服务器存放地方），必要时需要及时更换服务器
