# 升级须知

客户如果使用雪花云系统时，由于客户系统特殊性，会出现无法导出会员的情况，遇到这种类型情况，可通过此工具导出会员资料并且导入到油菜花系统。

# 升级前准备

1.下载数据导出工具，下载路径：

https://nos-pulic.nos-eastchina1.126.net/%E5%AE%9E%E6%96%BD%E7%BB%84/%E5%AE%9D%E5%85%B8%E9%9B%AA%E8%8A%B1%E4%BA%91%E6%95%B0%E6%8D%AE%E5%AF%BC%E5%87%BA%E5%B7%A5%E5%85%B7.exe

2.安装游乐宝系统到服务器中，安装方法参照：【新门店安装流程目录】

3.录入基础信息，包括以下内容：

a.机台数据，包括项目分类、游乐项目、机台物理参数；
b.零售商品，包括零售商品名称、价格、兑换值（不包含库存）；
c.游戏币套餐、预存款套餐、入会套餐、组合商品、游乐套票套餐等；
d.员工信息，包括角色设置以及用户设置两个部分；
e.权益优惠，包含商品促销、兑换折扣、活动赠送等；
f.线上商城搭建，包括线上套餐、线上兑换、注册会员权益等；

g.支付方式设置，请参考：微信VIP支付（子商户）配置、支付宝VIP支付（子商户）配置、支付宝微信支付宝汇付配置、微信原生支付配置、支付宝原生支付配置；

# 升级流程说明

## 步骤一：导出数据

1、 安装雪花云数据导出工具，并且直接运行，然后直接点【去登录】。（可以安装到任意一台电脑中运行使用，不需要一定是客户的电脑）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101a16672927&type=max)

2、使用客户的账号密码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101a31612928&type=max)

3、选择导出门店，并点击 “确定”： 一个账号有多个门店时，可在右上角切换门店后再点击最下面的“确定”。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101a4be9292a&type=max)

4、目前支持 导会员、导次票、导年票

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101a67a8292c&type=max)

5、开始导出

原系统会员有效期字段导出为空，按界面填写的自定义会员有效期为准，默认1年。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101ab455292d&type=max)

6、选择保存的文件夹保存导出的EXCEL

会员资料：最后一列会员ID用于与导出次票进行数据检查用的，导入游乐宝时请删除此列。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101ad0b1292e&type=max)

次票：次票 只导剩余次数大于0的会员的次票，散客票不导，其中票名，票类型、会员ID 三列仅用于参考核对数据，导入游乐宝时请删除这三列。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101aec7d292f&type=max)

年票：剩余次数可自己填写成99999， 游乐宝系统的年卡是按过期时间计算，同时会消耗次数，所以剩余次数可填99999， 票名和会员ID仅用于参考核对数据，导入游乐宝前请删除这两列。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c101b02112930&type=max)

7、会员号取的是手机号，密码默认****（已脱敏，请向运维索取）

8、预存款没有找到，以后需要再开发

9、时间预估：1020个会员，用时4分半， 788个会员用时3分半， 每秒导出3.7 个会员。2万会员预计需要90分钟。

## 步骤二：导入数据
