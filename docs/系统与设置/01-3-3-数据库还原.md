# 一、 作业说明

本操作说明仅在特定情况下适用，常规安装情况不需要使用。如需使用备份和还原的方法请查看此教程学习。

# 二、 作业准备

1. 服务器电脑

# 三、 作业标准

1. 数据库还原路径为DataBase目标路径。

2. 数据库成功还原并处于正常连接状态。

# 四、 注意事项

1. 对服务器数据库进行操作时务必确保在非营业状态下操作。

2. 还原数据库前，务必将游乐宝/娱乐管家的服务全部停止后再进行还原。

3.还原数据库时，一定要确保是覆盖原来数据库还是还原新的数据库，如果需要覆盖数据库，请务必先将被覆盖的数据库进行备份，避免将数据库覆盖错导致数据丢失。

# 五、 作业步骤

1. 左下角【开始】菜单，找到SQL Server Management Studio，点击进去。

2. 在服务器名称输入服务器IP地址，如本机为数据库服务器则可输入“. ”或者“ localhost ”或者本机 IP，3选 1 即可。

3. 身份验证可使用SQL Server 身份验证，或者windows 身份验证。如使用SQL Server身份验证请输入数据库的登录账号及密码，默认为 sa ，默认密码为 ****（已脱敏，请向运维索取）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac723d7013b9d&type=max)

4. 点击连接之后，进入【数据库】。 先检查原来是否有数据库，无论是否需要覆盖，都应先备份好同名的数据库，避免错误覆盖导致数据丢失。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac72378e33b9c&type=max)

5. 鼠标指向【数据库】点右键，选择【还原数据库】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac72408523b9e&type=max)

6. 在还原界面中，选择【源设备】，然后选择【添加】，接着选择你的备份文件，点击确定，直到回到还原数据库界面为止

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac72432503b9f&type=max)

。

7. 勾选需要还原的路径，并输入要还原的数据库名称（默认为YCHMALL），此步骤一定要多次确认，是覆盖原有的数据库还是只是还原出其他的数据库，如果不是覆盖数据库，请修改其他的数据库名称，避免覆盖错数据库导致数据丢失。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac72475733ba0&type=max)

8. 点击左上角【选项】,勾选【覆盖现有数据库】，并检查还原路径是否为默认油菜花DataBase文件夹路径，一般为（行数据）D:\Program Files\YCHMall \DataBase\YCHMALL.MDF，（日志）D:\Program Files\YCHMall \DataBase\YCHMALL.LDF。（非常重要，一定要检查数据库还原后的原文件路径）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ac724c24b3ba1&type=max)

9. 点击确定，完成还原。

# 六、 常见问题

1. 还原失败

原因：

&Oslash; 数据库可能在使用状态，请停止油菜花软件服务后再尝试还原。

&Oslash; 还原用的数据库文件可能有损坏。

&Oslash; 还原的数据库文件可能不是完整备份。

&Oslash; 还原后的路径不存在。

&Oslash; 其他未知原因。
