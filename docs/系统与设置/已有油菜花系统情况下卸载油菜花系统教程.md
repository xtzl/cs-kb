# 场景：

客户使用旧服务器情况下，油菜花系统已经安装好或者安装过，在不重装电脑的情况下可按照此教程利用原来的数据库程序重新安装系统。减少安装时间

# 安装准备：

1.检查服务器是否有异常

2.打开数据库管理器，检查数据库程序是否能正常打开

# 操作说明：

1.停止油菜花原来的应用服务

方法一：直接在YCHMALL的文件夹中，找到【Mall.Monitor.exe】程序，打开后，直接将对应的服务停掉。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b74ed3df4&type=med)

注意：需要将【商城业务服务】、【商城指纹服务】、【商城守护服务】、【报表服务】都停止服务。如果这里不到指纹服务，可以用CMD命令来执行

方法二：使用CMD命令来直接停止

停止服务的命令为 net stop 服务名

如使用CMD命令时，需要找到服务名称，在服务管理器中可找到，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193233546ec1d7b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932336538c1d7d&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932336d70b1d80&type=max)

右键开始菜单，右键选择CMD并用管理员运行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193233c2d1e1d9b&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019323391cdc1d91&type=max)

2.删除油菜花原来服务，右键开始菜单，右键选择CMD并用管理员运行

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b74f93df5&type=med)

删除服务的命令为 sc delete 服务名

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193233a9a4d1d98&type=max)

3.分离数据库

登录数据库-找到对应的数据库（一般默认为YCHMALL）-右键-任务-分离

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b75043df6&type=med)

勾选删除连接和更新系统信息，点确认

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b750f3df7&type=med)

注意：如果消息一栏有提示活动链接，证明步骤2的删除服务未执行到位，需要再次停止服务再删除服务

4.最后把这个文件夹移到其他文件夹即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b75193df8&type=med)

到此步为止，原油菜花服务就已经安装移除完毕。

# 常见问题：

1.删除服务后，如果按照服务时提示连接数据库失败

答：可能是数据库的登录密码不对，可以在原来的文件夹中找到setting配置文件，打开后找到数据库密码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0184518b75233df9&type=med)
