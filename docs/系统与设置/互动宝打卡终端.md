# **<font style="color:#333333;">一、 作业说明</font>**
<font style="color:#333333;">体育运动类场地的打卡终端与场地系统连接，需要安装接线与配置</font>

# **<font style="color:#333333;">二、 作业准备</font>**
<font style="color:#333333;">电钻，十字螺丝刀，电络铁，电工胶布，扎带</font>

# **<font style="color:#333333;">三、 注意事项</font>**
<font style="color:#333333;">12V电源的正负极别接错</font>

# **<font style="color:#333333;">四、 作业标准</font>**
<font style="color:#333333;">打卡终端安装完能正常刷卡，后台计数准确</font>

# **<font style="color:#333333;">五、 作业步骤</font>**
<font style="color:#333333;">1.把打卡终端的边缘网关与服务器放在一起，并通电通网，查看它的编号：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244325547-30777d03-4de1-40fb-8a9d-539b3c6a6921.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244325870-5b008969-2f99-418d-8de0-2f95adc3a940.jpeg)



<font style="color:#333333;">2.登录系统后台，找到运动打卡管理-门店配置，填写好边缘网关编码和本地服务器ip地址并保存，如果服务器是云部署的话就无需填写边缘网关编号：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244326072-d9d6c8d9-5959-4aa3-b028-3f9eb31da812.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732244326395-37ab4bb6-1055-49fc-a7a1-0a4c141b4d23.png)



<font style="color:#333333;">3.找到卡头wifi通讯设置，设置打卡终端专用无线名称：YOChlkLGCZos0iixjyxHrZNlwL，连接密码：Exns9K9Degxq1QsJKSKqxOeZdA，和正确的服务器地址，保存后点击服务器地址同步到游智云：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244326769-b3c19d79-9934-4d9d-9ade-792e4314ca2a.jpeg)



<font style="color:#333333;">4.进入场地的无线AP管理或者路由器管理页面，配置好对应的无线网络名称密码：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244326984-00fa9056-c57b-4c74-9ad6-1ef25faafa12.jpeg)



<font style="color:#333333;">5.把打卡终端接上12V电源（注意正负极不要接错），并用络铁焊好缠上电工胶布或热缩管：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244327207-5da26fe3-542c-4dbe-8855-a7d80f68d62d.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244327450-5ba8eb84-c29f-4367-b237-3438bf6a01a5.jpeg)



<font style="color:#333333;">6.在确保安全的情况下通电，打卡终端连上网后会依次显示9位数字编号：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244327719-8398cdf4-9fea-40d2-9da8-df0290ac5290.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244327935-55d5bb87-fdae-4bc1-9149-e8a40c684519.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244328139-a9a2b7f6-93f3-4800-b21a-95f706612ace.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244328364-ec9b7997-a3db-41b4-8e15-68df6df7bba2.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244328551-ee73513f-43ed-49cd-923f-b9ae11975234.jpeg)



<font style="color:#333333;">7.登录系统后台，找到运动打卡管理-项目管理和场次管理那里添加相应的项目以及场次：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244328836-bf541440-7df8-4106-8528-d335b630445e.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732244329346-8f7871e5-32ec-44f9-bd9a-0dcd56a7e44c.png)



<font style="color:#333333;">8.然后在新增好的项目那里点击添加设备，输入设备名称和打卡终端显示的编码并点击保存：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244329582-1836e3d6-9d64-4cd9-a628-7bb09bde0784.jpeg)



<font style="color:#333333;">9.绑定完成后打卡终端会显示对应的设备编号，系统后台也能看到设备在线或离线状态：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244329860-529acb74-7c6e-4c1e-9a07-2128bcb40a97.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732244330169-181b1955-e21d-4021-bc69-c7a5dfa7020d.png)



<font style="color:#333333;">10.用会员卡或手环测试一下，如果能正常打卡就证明已经配置好了：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244330404-e7fdccd0-cd8f-46c8-8f34-77ecd8e2232c.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244330748-5e1e7379-952e-494c-a59e-5915f6a1aded.jpeg)

<font style="color:#333333;">11.接下来要将打卡终端安装到客户指定的位置，首先拆开它的面板并把底座用螺丝固定住：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244330951-e21451c5-7c1d-4045-b78e-bc8fffac2312.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244331144-17ed337b-fbc5-4803-b2d2-7df21c9b013f.jpeg)



<font style="color:#333333;">12.最后接上面板，上好螺丝，把裸露在外的电源线用线槽盖起来，安装就已经全部完成了：</font>

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244331378-df5d1857-4baa-41b3-b43d-a9082a97753e.jpeg)<font style="color:#333333;"> </font>![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244331585-511d0e65-84c7-4b0b-9088-4ac0cda27df5.jpeg)
