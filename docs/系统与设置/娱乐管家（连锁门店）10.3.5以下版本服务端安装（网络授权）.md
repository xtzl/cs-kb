# 一、 文档说明

此文档旨在说明如何安装娱乐管家连锁版总部下门店本地服务器

# 二、 安装准备

#### 1.安装对应的数据库软件

windows server 2016以上系统请看此教程【SQL2016数据库(用于Windows server 2016标准版及以上使用）安装说明】

windows server 2012以下系统请看此教程【SQL2008数据库(仅用于Windows server 2012 R2标准版及以下使用）安装说明】

#### 2.小程序VPN和总部链接VPN配置完成

【小程序VPN安装教程】

【连锁VPN安装教程】

并获取对应的总部URL和门店URL

说明（什么是总部URL和门店URL地址）：

总部URL地址：指连接总部VPN后，可以访问到总部系统的IP地址，一般为： 192.168.**.1:999*；如果是填写到系统中，则格式为：http://192.168.**.1:999*/

门店URL地址：指总部服务器可通过连接VPN后，可以访问到门店服务器的IP地址，也就是油菜花提供的VPN配置中的IP地址，一般为：192.168.**.**：9999;如果是填写到系统中，则格式为：http://192.168.**.**:9999/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38b9f1d3591&type=med)

由于两个地址都是数据通讯相关的，务必要确认地址的正确性，以避免因为地址错误导致数据同步异常问题。

#### 3.下载对应的油菜花软件安装包

【娱乐管家（连锁商城）安装包下载教程】

#### 4.获取门店的安装文件和网络授权

说明：

安装文件：用于在总部添加门店信息使用，大小为4KB，后缀为*.lic；只有生成网络授权后才能生成安装文件。

网络授权：需要提供机器码给油菜花内部人员，生成用于安装系统的授权文件，大小为5KB，后缀*.lic；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38b9f263592&type=med)

# 三、 安装标准

门店服务器服务正常运行；

总部跟门店能够相互访问、通讯正常；

# 四、 注意事项：

总部服务器部署在油菜花云端服务器；

门店安装系统版本需跟总部服务器系统版本一致

# 五、 安装步骤

## 第一步 下载系统服务host文件，文件版本必须跟总部版本一致

如下图，假如总部系统版本是V10.3.4748版本，那么安装门店服务器所使用的安装包也必须是V10.3.4748版本

安装包下载方法可参考：【娱乐管家（连锁商城）安装包下载教程】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d377d51634e0&type=max)

下载门店对应服务器版本host文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38b9f2e3593&type=med)

## 第二步 获取机器码

双击运行并安装该host文件，在弹出的安装程序界面，点击注册

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38b9f363594&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38b9f3f3595&type=med)

点击网络授权，获取机器码，将该机器码给到相应人员，获取注册文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba0523596&type=med)

将获取到的机器码提供给油菜花工作人员（可联系技术主管梁建宁、技术支持高晓钦、陈彦峰、客服主管李韩艳获取），获取网络授权以及安装授权文件

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba05a3597&type=med)

## 第三步 通过安装授权在总部添加门店

拿到注册文件之后，点击【浏览】，选择获取到的注册文件，点击【确定注册】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba0633598&type=med)

（到这一步为止，等待添加门店信息后再继续安装）

## 第四步 登录连锁门店，添加门店并配置门店信息

#### 1.新增门店

获取门店安装文件后（可联系技术主管梁建宁、技术支持高晓钦、陈彦峰、客服主管李韩艳获取），当连锁VPN已经配置成功后（连锁VPN配置流程），则通过浏览器打开总部后台（一般使用总部URL地址加/admin可作为总部后台网址登录到总部系统中，如总部URL地址提供为192.168.*.1:999*,则总部后台网址为http://192.168.*.1:999*/admin），并登录到总部后台新增门店；

路径：总部后台→基础设置→商业架构管理→门店管理→新增

在【许可文件】中，选择4KB的安装授权文件，点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d37e7f34351f&type=max)

#### 2.修改门店连接配置

门店新增成功之后，修改总部跟门店URL地址；门店URL地址填写要根据给到总部vpn信息进行填写，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba1453599&type=med)

端口号以本地服务器端口为准，通常情况默认是9999，并且填写时需要补充“http://”

以下示例皆为参考示例，并不是实际门店填写地址，切忌作为门店信息录入

注意：总部URL有效地址应为连接总部VPN之后，可以正常通过门店服务器打开总部后台为准，比如，收到的总部地址为192.168.**.1:999*时，那配置完总部连接的VPN之后，使用http://192.168.**.1:999*/admin 在网页中打开则会打开到总部后台系统，代表地址是正确且VPN通讯正常，这时候填写的总部URL地址则为http://192.168.**.1:999*/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d37fd3d33525&type=max)

填写完毕后，点击保存完成总部系统的门店参数配置

## 第五步 继续安装门店服务器

1.把网络授权（5KB的注册文件）放到服务器中，点击软件安装中的【浏览】，选择获取到的注册文件，点击【确定注册】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba14d359a&type=med)

2.填入相应配置信息（数据库密码：默认为****（已脱敏，请向运维索取）），注意在总部地址栏填入总部URL地址（指192.168*.*.**:999*）,填写时需要补充http://以及最后的/，并选择门店URL的IP地址（注意此地址一定要确保是门店URL对应的IP地址，选错了可能会导致数据不同步）和修改数据库备份路径，点击安装。

（注意，如果客户服务器有2块以上硬盘，则需要将数据备份路径盘符改到另外的硬盘目录下）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba254359b&type=med)

3.当提示【商场数据导入】时，点击【从总部获取数据】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba25d359c&type=med)

4.以下界面只需要等待数据获取成功为止。不需要做任何操作。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba36f359d&type=med)

5.数据获取完成后，提示系统安装完成，点击【确认】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba377359e&type=med)

6.提示安装服务，依次安装服务即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d38ba37f359f&type=med)

## 第六步 检查总部与门店通讯

1）检查门店服务是否正常启动；

2）登录总部后台，检查门店是否连接正常，若门店连接正常，状态应显示正常而非离线；

路径：总部后台→系统管理→门店网络监控

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d382bbe93548&type=max)

3）检查总部分发数据是否正常，主要看队列数是否为0，如果不为零，或者状态为异常，则代表同步数据有问题，需要联系油菜花内部人员（可联系技术主管梁建宁、技术支持高晓钦、陈彦峰、客服主管李韩艳获取）检查总部同步数据是否异常。

路径：总部后台→切换至维护视图→跟踪调试→总部分发数据监控

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d386d8b9356b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d387bcfd356f&type=max)

4）检查远程升级功能中，是否产生队列

路径：总部后台→切换至维护视图→跟踪调试→远程升级

点击【刷新】，检查该界面下，对应门店下是否产生队列，以及版本是否与总部版本一致。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d388b3cd357a&type=max)

5）登录门店后台，检查门店上传数据是否有异常

门店登录网址，可用 http://localhost:9999/admin 打开门店后台，并登录系统，在以下路径找到【数据队列监控】

路径：门店后台→切换至维护视图→上传数据上报监控→刷新

刷新后，检查队列数是否为0

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193d389ba063583&type=max)

# 六、 常见问题：

1.门店跟总部的数据互不相通，有队列产生

解决：检查总部vpn是否正常开启，检查url地址填写是否有问题

2.总部数据下传不到门店

解决：检查总部ulr、门店url是否设置正确，若修正成功之后数据仍旧无法下传，则需要到数据库修改总部门店url地址，修正之后重新总部门店服务。

具体操作如下：

修改门店数据库队列同步地址 （ 大客户、连锁门店总部版本需要修改）

SQL Server 执行以下SQL
select * from Mall_MallInstance --查询总部/门店队列同步地址信息
select * from Mall_Business --查询门店信息表
update Mall_MallInstance set MallURL ='http://192.**8.***.9:端口/' where Mall ='*****-B5C3-4A28-8476-AF5C0108D1E4'

3.总部下门店装过预售服务器，检查无队列产生，总部、门店的url地址也测试无问题，但数据仍旧下传不到门店。

解决：因总部之前的数据有可能是下传到预售服务器，所以把总部之前新增的数据全部删除，重新新建，重新下传即可。
