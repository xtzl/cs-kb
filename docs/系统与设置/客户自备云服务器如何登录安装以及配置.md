# 一、文档说明

本文档指引客户自备阿里云服务器情况下，如何对系统进行安装及部署。

# 二、前期准备

1.申请阿里云服务器

2.提供阿里云服务器登录方式（如果是使用控制台登录，需要客户提供验证码进行登录）

3.提前申请域名，并对域名进行备案（注意，第一次备案后，配置系统之后可能出现不能使用的情况，有可能需要二次备案）

4.阿里云服务器创建好实例已完成基础配置（包括操作系统已部署完毕）

# 三、如何登录阿里云服务器

## 情况一：客户提供阿里云服务器的公网IP及登录账号密码。

此情况直接使用WINDOWS的【远程桌面】直接远程即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed25be625902&type=max)

注意：远程桌面默认使用是3389端口，如果客户服务器已经修改远程桌面的默认端口，则需要在公网IP地址后面添加对应的远程端口。同理，如果公网IP已用域名转发，则需要直接用域名来进行远程桌面访问服务器

例如：

①远程桌面端口为4567，则【计算机】一栏则写为：公网ip:4567

②远程桌面访问地址为http://youaihua.cn/,则【计算机】一栏则写为：http://youaihua.cn/

特别注意：如果使用公网IP地址访问，安装完毕后，一定要提醒客户，添加远程桌面源地址为：

120.79.21.247和203.12.201.150 （以上两个均为油菜花公网出口地址）

避免勒索病毒感染导致数据被锁。

## 情况二：客户提供阿里云控制台的账号密码，需要登录到阿里云控制台再跳转到对应服务器

1.网页打开阿里云服务器控制台：https://www.aliyun.com/

2.点击右上角【控制台】并输入账号密码进行登录，一般会提示需要验证码登录，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed2b469b590b&type=max)

3.先从首页找到【云服务器ECS】，点进去后，在左侧的菜单栏，找到客户提前购买准备好的实例，并选择【远程连接】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed4825f85957&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed2e2ca45914&type=max)

4.提示登录方式，使用默认登录方式（注意，如果需要使用密码登录，可直接点重置密码来重新设置新的密码进行登录）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed3514bb5925&type=max)

5.登录后即可按照本地安装流程进行安装系统（特别注意：自备云服务器不需要安装VPN，并且小程序链接也只用客户申请的域名链接即可）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed386c88592e&type=max)

## 特别说明：情况二下如何使用【远程桌面】功能进行服务器直接登录。

当按照情况二的情况下，只要知道公网IP且没有调整远程桌面端口的情况下，正常情况是可以直接通过公网IP搭配windows自带的【远程桌面】功能直接远程到服务器。

问题1：如何知道公网IP

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed3f187f5941&type=max)

问题2：远程桌面的账号密码是什么

账号默认均为administrator

密码则为情况二下被重置的登录密码。如果不清楚密码，可通过控制台远程后再修改。

# 四、如何部署油菜花服务器

操作说明：

如果是单个服务器安装，则正常按照本地服务器安装流程即可（但不需要安装VPN），可参考以下教程

【游乐宝本地服务器安装目录】

【娱乐管家单店版本地服务器安装目录】

【娱乐管家连锁版本地服务器安装目录】（连锁情况下，如果是不同服务器安装总部和门店，则链接地址为域名地址或者是阿里云服务器私网地址，如果是同一个服务器安装总部和门店，则直接用私网地址即可）

要求：

安装油菜花系统文件夹命名规则：YCHMLALL+门店编码+门店名称+业务端口号

如：YCHMALL-00000000-油菜花旗舰店-9999

# 五、设置入站规则

## 添加业务端口的入站规则

说明：阿里云服务器默认入站规则是不包含油菜花业务端口，所以需要手动添加入站端口

1.点击【安全组】，选择管理规则

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed49c3565959&type=max)

2.点击【手动添加】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed4f0993596c&type=max)

3.添加TCP协议端口（业务端口）以及UDP协议端口（机台端口，有则添加，没有则不需要添加）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed4e8956596b&type=max)

4.点击保存即可

## 修改远程端口的源地址（仅用于客户直接提供公网地址访问情况下使用）

说明：远程端口务必不要设置为所有IPv4地址都能访问，建议可添加自己的需要用的地址以及油菜花公网IP地址（用于后续油菜花售后提供服务使用），非常重要，能有效预防勒索病毒导致服务器被工具。

1. 同样在上述界面中，找到3389的入站规则，点击编辑

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d470aeba26459&type=max)

2.在【授权对象】一栏，填入油菜花公网地址

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d470e62be646f&type=max)

注意事项：假如实例已经修改了远程桌面的端口情况下，需要在修改后的端口添加入站规则，并添加对应的授权对象（源地址），授权给油菜花公网IP，以便于后续油菜花售后提供服务所使用。

# 六、测试端口通讯方法（仅用于客户没有设置特别拦截规则或者转发规则才能成功）

通过公网ip+业务端口的方式，直接在自己的电脑上访问服务器，正常是可以直接登录系统，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed52362a5978&type=max)

# 七、配置域名解析DNS（简单版）

说明：如果客户有自己配置域名能力，则让客户自行配置，如果客户没有配置能力，则我们仅用基础的配置转发功能进行配置。此域名功能主要有两个作用：①用于日常访问使用，避免经常使用公网IP访问而引起一些安全问题；②用于申请小程序功能使用（小程序必须使用域名功能来访问使用）

1.在控制台左上角，切换到域名目录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed53fae35982&type=max)

2.点击已有的域名

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed54af935985&type=max)

3.找到需要用到已备案的域名地址，点击解析

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed55bbd85986&type=max)

4.点击【快速添加解析】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed56d73f5989&type=max)

5.选择IPv4解析，并选择域名地址以及输入解析的公网IP地址

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed5970645995&type=max)

6.配置完成后，获得以下提示，则等待配置生效即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed5a5c045999&type=max)

7.生效后，则可以使用域名地址替换掉公网IP地址来直接访问系统后台。例如原来外网访问的公网地址为：http://1.23.45.67:9999/admin 这个地址则可以通过配置的域名地址来替换其中的ip地址，则为http://youcaihua.com:9999/admin

8.当通过简单配置域名后，可能会出现短时间能访问，后续再访问时，提示需要备案的情况，此时需要重新对此域名进行备案（海外客户不需要备案，仅用于国内客户使用）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197ed61e19259b9&type=max)

# 八、客户远程信息备案（仅适用与客户仅提供公网访问IP的情况下使用）

如果客户是提供公网IP访问的情况下，需要将该客户的链接信息同步给实施组组长，由实施组组长备案记录。

# 九、关于网络安全注意事项

1.建议客户在安装配置完后，尽快禁用或者修改公网IP的远程桌面功能，由于公网IP地址非常容易受到外部攻击，且远程的默认端口为3389属于极为容易受攻击的端口。所以不建议长期使用。
