四、输入一下语句，并执行

在数据库执行依次执行以下命令：

select * from Mall_Mall
select * from Mall_Business
update Mall_Mall set MallName ='新的店名' where MallCode ='加密狗'
update Mall_Business set BusinessName ='新的店名' where BusinessNum ='1'

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180da7422f9135e&type=max)
