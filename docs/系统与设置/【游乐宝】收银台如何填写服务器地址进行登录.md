# 应用场景

1、收银台首次安装/重装时提示填写服务器地址该如何填写？

2、未与服务器同一局域网如何填写服务器地址？

# 操作步骤

首次安装/重装收银台打开时，会自动提示填写服务器地址，填入正确服务器地址与端口号即可登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018712bc99522017&type=max)

如何查看服务器地址？到一个可以登录游乐宝后台/娱乐管家后台的电脑，右击后台图标点击打开文件所在位置，在里面找到settings的文件打开，里面的ServerIP就是服务器ip地址和端口号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101792b7b3aeb6328&type=max)

未与服务器同一局域网如何填写服务器地址？可以填写域名进行登录（需要开通云互联功能才能拥有域名）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc24018712bd1eeb201e&type=max)

开通云互联后不知道域名地址是什么？可联系我司客服进行咨询

# 注意事项

1、没有域名的情况下，收银电脑要与服务器电脑同一局域网才能进行登录
