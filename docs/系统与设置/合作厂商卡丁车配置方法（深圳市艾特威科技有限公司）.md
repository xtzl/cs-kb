# **一、说明**
     合作厂商卡丁车（深圳市艾特威科技有限公司）,是已经对接油菜花系统，因此不需要按照通用卡丁车控制模块的方法进行安装，直接可以接入到系统。

# **二、准备内容**
1.游乐宝系统已开通卡丁车功能

2.卡丁车品牌必须为深圳市艾特威科技有限公司

3.卡丁车供应商提供卡丁车服务器相关信息，包含（卡丁车服务器地址、MQ虚拟主机、MQ账号、MQ密码以及门店ID），如下图所示

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244184444-8aa7cabd-186d-45c5-b87a-ecd56227c08e.jpeg)

# **三、配置步骤**
## **<font style="color:#333333;">第一步：进入游乐宝后台界面→选择设备→设备管理→游乐项目→新增分类→保存。</font>**
![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244184694-68138e56-1d5a-4e1e-8e05-5a9a9de8abf0.jpeg)

## **<font style="color:#333333;">第二步：进入游乐宝后台界面→选择设备→设备管理→游乐项目→卡丁车→新建项目→输入项目信息→下一步→完成。</font>****<font style="color:#E53333;">（注意，卡丁车项目只需要建一个即可，开启哪台车由第三方控制）</font>**
![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244184959-2196f4f0-60f2-4576-ad1b-44e04000b9e9.jpeg)

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244185207-3ada721a-04a4-4b10-b820-febfc9e56021.jpeg)

## **<font style="color:#333333;">第三步：在【设备】-【查询】-【项目消费消息推送查询】-选择【设置项目通知】-选择【ACTEV卡丁车】填入第三方对接信息以及勾选卡丁车项目，保存</font>****<font style="color:#E53333;">（只需要勾选一个卡丁车项目）</font>**
![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732244185415-58128c05-ce2b-4248-9ffb-073ad51cd9dc.jpeg)

# **<font style="color:#333333;">四、日常流程逻辑</font>**
顾客消费核销-油菜花系统发出启动信息-合作商服务器数据库产生记录-通过ipad选择启动哪一台卡丁车

# **<font style="color:#333333;">五、注意事项及常见问题</font>**
<font style="color:#FF0000;">1.请选择正确的推送项目，项目消费推送失败时系统将自动进行订单退款/取消扣币（因此请不要选择无需消费推送的项目）</font>

<font style="color:#FF0000;">2.油菜花系统有核销记录，合作商服务器数据库没有产生记录导致没法启动卡丁车（原因：现场网络有问题无法成功推送信息）</font>
