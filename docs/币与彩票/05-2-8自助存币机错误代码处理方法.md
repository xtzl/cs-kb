一、 作业说明

存币机故障代码处理方法

二、 作业准备

存币机

三、 注意事项

无

四、 作业标准

存币机正常运行。

五、 作业步骤

1. 存币机报故障E02，代表是读卡失败。

1.1 感应模块故障，读不到卡，换一个读卡的感应模块

1.2 会员卡有问题，换一张会员卡试一下

1.3 读卡模块离卡槽太远

2. 存币机报故障E25，代表连接不上服务器。

2.1 检查网络是否正常

2.2 拿电脑连接存币机网线，ping服务器地址，看能否 ping 通，如果 ping 不通，则需检查交换机和路由器是否连接正常，各级路由设备防火墙是否有阻。

2.3 重新刷配置卡。

3. 存币机包故障E03 E40，代币马达卡币。

3.1 检查马达是否卡币，如若卡币，把卡主异物取出即可。

4. 存币机报故障E50，代表程序正在启动。

4.1 等待程序启动机器。
