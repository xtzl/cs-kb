# 操作步骤

如下图，一般将套餐里的“代币”设置成“本币”，将金币设置成”赠币“。例如，200元=200本币+20赠币，就设成200个代币和20个金币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179d64660c73d4b&type=max)

如下图，在游乐项目的设置中，调整卡头的扣费次序，例如先扣本币还是先扣赠币等（一般是先扣赠币）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179d65166bd3d4d&type=max)

# 注意事项

当会员卡中同时存在多种储值（包含门票），扣费次序如下：

1，如果存在门票，则优先扣门票（自动先扣最先过期的门票）

2，扣储值的时候，按你设置的次序扣费，当其中一种储值不够的时候，会自动切换成另外一种储值。例如原本要扣5个金币，但会员卡里只有3个金币，这时候刷卡就会扣3个金币和2个代币
