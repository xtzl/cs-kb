# 口令补币功能说明

一、功能描述

在后台生成一个口令码，将此口令给到顾客，顾客可在自助设备上面凭口令码取币

二、应用场景

当门店无人值守，店内有客诉需要补币给客人时，工作人员则可以通过后台远程生成口令码给用户补币或者顾客在兑币机上面核销或者购买游戏币的时候没有出币时需要通过自助兑币机进行补币

三、功能的后台路径以及使用说明

后台路径：会员》口令补币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d6add340f6a&type=max)

1.设置步骤：点击新增口令补币，填写需要补币的数量和生成补币口令的数量，有效期为生成的补币口令有效期，根据实际补币情况填写备注

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d832c900fa6&type=max)

2.把生成的口令提供给客人，到自助设备上面打开口令补币功能，输入口令取币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d83ebda0fa8&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992da4d316100d&type=max)

四、相关功能的常见问题

问：当发现口令的补币数量填写错等问题，需要取消生成的口令，该如何撤销？

答：在口令补币界面，找到生成的对应记录，点击后面的取消补币
