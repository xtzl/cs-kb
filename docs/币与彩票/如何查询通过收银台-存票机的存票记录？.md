# 应用场景
适用于想查询顾客存票数据来源

# 操作流程
路径：报表**→**机台类**→**存票记录

#### 手工存票：为收银台员工手动存彩票的记录
#### 碎票机：为会员在碎票机存彩票的记录
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718786270930-a6ca8fe2-4099-47aa-bb45-a60b7c5f331e.png)

# 常见问题
问：收银台如何查询会员存票记录？

答：登录收银软件-会员--会员资料里选择会员，读卡/手机号/会员码；查询到对应会员后点击彩票变更，可以查询到顾客什么时候存入的票数和在什么项目上存入的。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719558844145-20f551b2-1793-477b-b94d-3177bf074a5c.png)
