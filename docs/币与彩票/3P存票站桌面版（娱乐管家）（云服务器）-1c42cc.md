# 一、作业说明

本说明为3P存票站桌面版安装方法与调试说明。

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019192dcc70632ea&type=med)

# 三、功能说明

1.支持同时3位置进行存彩票

2.支持查看彩票排行

3.支持会员卡存票、扫码存票

# 四、作业准备

1.检查柜台碎票机配件是否齐全。

2.预留联网网口和电源口。

3.准备一些彩票用于测试。

4.微信小程序已经配置完成（如未发布成功则导致人脸识别功能暂时无法使用）（注意：如果使用非原生微信支付则无法使用人脸）

5.微信子商户功能已经配置完成（仅影响人脸识别功能）（注意：如果使用非原生微信支付则无法使用人脸）

6.（云服务器）提前准备好门店域名地址，一般格式为：y********.yun.youcaihua.net:88/admin

# 五、注意事项

1.安装前与客户确认自助存票机V6放置位置；

2.搬运时，需要至少2人一齐辅助位移，避免搬运时发生意外；

3.安装后，主要需要固定存票机底座，使其不摇晃；

# 六、作业标准

1.安装后无掉线情况；

2.所有配件已经安装到位；

3.连续碎票10次不出现卡票情况；

4.存票机底部需要固定好，保证无晃动。

# 八、整机测试

1. 测试散客存票，存20张票，并检查碎票数量和存入数量是否一致，存入后，打印是否正常；

2. 读卡测试，开一张会员卡，并进行读取，观察读取会员信息是否一致；

3. 反扫测试，使用小程序会员二维码进行扫码，读卡是否正常；

4. 屏幕测试，点击屏幕各项功能，是否能正常进入到对应的操作界面，检查是否有乱触情况；

5. 关机开机测试，关闭电源10秒重新开机，检查是否正常连接；

# 八、配件使用

## 1. 光眼、胶圈

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019192dccb2d32f7&type=med)

#### 使用说明：

- 胶圈用于替换压票滚轮位置的胶圈。

- 光眼用于替换感应光眼用。

以上设备都是易损件，当使用时间较长的情况下，可能出现损耗，损耗后可自行更换

## 2. 备用刀组

#### 使用说明：

碎票机内部有备用刀组，当原刀组已经磨损消耗较为厉害，并且出现票已经切不断卡顿的情况，此时需要更换备用刀组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019192dccb3532f8&type=med)

## 3.卡票钢尺

#### 使用说明：

当存在卡票时，可打开修理口后，使用卡票钢尺进行快速解决
