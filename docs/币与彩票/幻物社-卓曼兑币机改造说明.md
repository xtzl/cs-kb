# 文档说明

幻物社采购的是卓曼的芸苔兑币机，而门店使用的是娱乐管家系统，所以需要对兑币机进行改造。而我们提供的改造方案是替换芸苔兑币机的安装主板方案，需要提前从工厂那边取得已经安装好娱乐管家兑币机程序的主板进行更换来使用。

# 流程说明

第一步，确认主板型号

在改装卓漫兑币机之前需确定其兑币机主板，下图为卓漫兑币机主板之一，内置了芸苔兑币机程序，需要更换主板这块主板，并提前在主板安装好自助兑币机v6程序。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d426b9bdc59e9&type=max)

第二步，按照第一步的图上的接口，接入我们主板的接口位置。
第三步，在主板下方，找到兑币机的支付模块，将支付模块的接口改为【油菜花】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb45f87b07940&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb4602f8a7943&type=max)

第四步 将线捋好并扎紧

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb46209437956&type=max)

第五步 重置扫码器，用以下条形码扫扫码器，等待“滴滴”两声，完成配置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019eb462d8a27959&type=max)

第六步 相关功能进行测试，并拍照留底发给销售助理。
