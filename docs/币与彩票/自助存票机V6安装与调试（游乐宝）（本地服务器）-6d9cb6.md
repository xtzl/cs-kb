# 一、作业说明

本说明为自助存票机V6安装方法与调试说明。

# 二、外观说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344c6225201&type=med)

# 三、作业准备

1.检查柜台碎票机配件是否齐全，包括进钥匙、备用刀组、电源线、机台广告牌、小票打印纸、小票固定棒。

2.预留联网网口。

3.准备一些彩票用于测试。

4.微信小程序已经配置完成（如未发布成功则导致人脸识别功能暂时无法使用）（注意：如果使用非原生微信支付则无法使用人脸）

5.微信子商户功能已经配置完成（仅影响人脸识别功能）（注意：如果使用非原生微信支付则无法使用人脸）

6.（本地服务器）提前准备好门店本地服务器地址，一般格式为：192.168.*.*:9999

# 四、注意事项

1.安装前与客户确认自助存票机V6放置位置；

2.搬运时，需要至少2人一齐辅助位移，避免搬运时发生意外；

3.安装后，主要需要固定存票机底座，使其不摇晃；

# 五、作业标准

1.安装后无掉线情况；

2.所有配件已经安装到位；

3.连续碎票10次不出现卡票情况；

4.存票机底部需要固定好，保证无晃动。

## 11.存票抽奖设置

11.1先开启存票抽奖功能，勾选下图的开关

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cc6f5214&type=med)

11.2 登录后台-【设置】-【彩票设置】-【彩票抽奖】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cc7a5215&type=med)

抽奖规则：

a.超过7个奖品，系统将随机出奖品

b.存票达到的允许存票的范围内就可以参与抽奖

c.先在所有奖品中随机选一个奖品

d.抽中奖品的机率=（奖池彩票+抽奖的彩票）➗奖品价值彩票数 *100%

e.抽中奖品后，奖池彩票=原奖池彩票+抽奖的彩票-中奖礼品价值彩票

f.抽不中后，奖池彩票=原奖池彩票+抽奖的彩票

g.奖池按每台设备单独计算

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cd905216&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344ce685217&type=med)

11.3 当顾客中奖后，设备将通过小票打印机打印中奖凭证，中奖凭证可到前台-【售票】-【抽奖核销】中核销，注意，此处奖品不会和系统的商品挂钩，仅仅只用于核销使用

# 七、整机测试

1. 测试散客存票，存20张票，并检查碎票数量和存入数量是否一致，存入后，打印是否正常；

2. 读卡测试，开一张会员卡，并进行读取，观察读取会员信息是否一致；

3. 反扫测试，使用小程序会员二维码进行扫码，读卡是否正常；

4. 屏幕测试，点击屏幕各项功能，是否能正常进入到对应的操作界面，检查是否有乱触情况；

5. 关机开机测试，关闭电源10秒重新开机，检查是否正常连接；

# 八、配件使用

## 1. 光眼、胶圈

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cf9b521b&type=med)

#### 使用说明：

- 胶圈用于替换压票滚轮位置的胶圈。

- 光眼用于替换感应光眼用。

以上设备都是易损件，当使用时间较长的情况下，可能出现损耗，损耗后可自行更换

## 2. 备用刀组

#### 使用说明：

碎票机内部有备用刀组，当原刀组已经磨损消耗较为厉害，并且出现票已经切不断卡顿的情况，此时需要更换备用刀组。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cfa4521c&type=med)

# 九、常见问题

1.自助存票机屏幕出现服务器地址，并点连接无反应或者连接失败

答：连接失败，无法连接服务器，检查网络是否正常。

2.如何登录设备后台进行设置

答：长按右上角，输入管理密码（默认为1或者****（已脱敏，请向运维索取）1）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cfae521d&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cfb6521e&type=med)

3.管理密码忘记了怎么办？

答：机台内部的设置按键，直接登录到设备后台，并点击修改密码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c201905344cfbf521f&type=med)

4：系统是本地部署，当用会员码扫自助设备或核销或登录时，提示会员码过期。

答：校正本地服务器时间，检查本地服务器时间是否跟世界时间一致，若不一致更改一致即可；
