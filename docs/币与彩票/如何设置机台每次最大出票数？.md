# 🔴应用场景
为避免由于机台故障等异常情况不断“出票”等情况， 你可以设置“机台每次最大出票数”。 这个数据默认是“5000”， 表示出票数达到5000后， 会员需要重新刷卡或扫码才能继续存票， 你可以根据实际情况调整这个数值大小。
