# 如何区分赠币和本币？

为了财务统计方便，部分场地会直接把赠币当成“0元”，例如游戏币1元=1枚，优惠套餐为100元=100币+50赠币=150币；虽然这些游戏币都能用于玩机台，但财务人员需要通过报表能区分场地的“本币”一共卖出了多少，消耗了多少，这样方便记账

针对此类情况，门店在设置游戏币套餐的时候，通过代币和金币两种方式来区分本币和赠币，同时在卡头上也设置代币和金币的消耗顺序，这样通过后台报表查询代币和金币分别的销售和消耗数量，就能进行区分了

# 如何设置游戏币有效期？

游戏币套餐一般不设置有效期，因为比较容易引起客诉，但对于赠币，适当的设置有效期，可以有效的促进游戏币消耗，同时也不会让全场的剩余游戏币越来越多从而影响整体币单价。门店可按以下操作在套餐设置中开启有效期

# 赠币和补币如何管理？

## 油菜花系统给顾客赠币一共有以下几种方式：

1，活动赠送，包含生日赠送

这种方式优点是：赠送的过程全部由系统判定，包括这个会员是否符合领取的条件，赠送的数量，赠送的频次等，避免出现管理漏洞；缺点是：赠送的方式不够灵活，有些场景满足不了

对于此类方式的赠币，管理员只要控制好赠送的门槛（例如会员要提供身份证来判定生日的条件），并定期查看系统后台的赠币报表即可

2，通过套餐的方式赠送

这里讲的套餐赠送，指的是通过设置“0元套餐”的方式来赠币。这种方式的优点是：操作灵活，可以根据实际情况控制赠币的数量和频次等；缺点是：由于过于灵活，如果管控不好容易产生漏洞；

对于此类方式的赠币：如果是赠送频次较少（例如专门用来招待商场或亲戚朋友的招待套餐），可设置“授权售卖”，这时候必须有管理员输入账号密码才能售卖该套餐；如果是门店常规性活动，则领取赠币的顾客需要提供凭据，例如领币券等，员工只有拿到领币券才能给顾客赠币，下班的时候主管需要核对领币券的数量和后台赠币的数量

## 门店给顾客补币，一般有以下几种情况

- 场地安装了卡头，顾客反映刷卡后机台没有启动，这种时候可通过“取消机台扣币”功能核实顾客刷卡情况，同时为顾客退还相应的游戏币（需要主管授权）

- 有时候顾客投诉或优惠赠送也会采用“补币”的方式，补币过程中，系统会强制要求输入“备注”，门店需要规范备注的格式，这样可以方便后台查询的时候快速整理

- 使用提币机的场地，有时由于机台卡币或缺币等情况，导致顾客提币中途停止，这时候可采用“口令补币”或在系统后台查询提币记录然后手工给顾客补币
