# **<font style="color:#333333;">一、作业说明</font>**
<font style="color:#333333;">本说明为3P存票站桌面版安装方法与调试说明。</font>

# **<font style="color:#333333;">二、外观说明</font>**
![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1732241410245-cdcac857-c109-4056-9c76-4773f0a294f3.jpeg)

# **<font style="color:#333333;">三、功能说明</font>**
<font style="color:#333333;">1.支持同时3位置进行存彩票</font>

<font style="color:#333333;">2.支持查看彩票排行</font>

<font style="color:#333333;">3.支持会员卡存票、扫码存票</font>



# **<font style="color:#333333;">四、作业准备</font>**
<font style="color:#333333;">1.检查柜台碎票机配件是否齐全。</font>

<font style="color:#333333;">2.预留联网网口和电源口。</font>

<font style="color:#333333;">3.准备一些彩票用于测试。</font>

<font style="color:#333333;">4.微信小程序已经配置完成（如未发布成功则导致人脸识别功能暂时无法使用）（注意：如果使用非原生微信支付则无法使用人脸）</font>

<font style="color:#333333;">5.微信子商户功能已经配置完成（仅影响人脸识别功能）（注意：如果使用非原生微信支付则无法使用人脸）</font>

<font style="color:#333333;">6.（云服务器）提前准备好门店域名地址，一般格式为：y********.yun.youcaihua.net:88/admin</font>

# **<font style="color:#333333;">五、注意事项</font>**
<font style="color:#333333;">1.安装前与客户确认自助存票机V6放置位置；</font>

<font style="color:#333333;">2.搬运时，需要至少2人一齐辅助位移，避免搬运时发生意外；</font>

<font style="color:#333333;">3.安装后，主要需要固定存票机底座，使其不摇晃；</font>

# **<font style="color:#333333;">六、作业标准</font>**
<font style="color:#333333;">1.安装后无掉线情况；</font>

<font style="color:#333333;">2.所有配件已经安装到位；</font>

<font style="color:#333333;">3.连续碎票10次不出现卡票情况；</font>

<font style="color:#333333;">4.存票机底部需要固定好，保证无晃动。</font>

# **<font style="color:#333333;">八、整机测试</font>**
<font style="color:#333333;">1. 测试散客存票，存20张票，并检查碎票数量和存入数量是否一致，存入后，打印是否正常；</font>

<font style="color:#333333;">2. 读卡测试，开一张会员卡，并进行读取，观察读取会员信息是否一致；</font>

<font style="color:#333333;">3. 反扫测试，使用小程序会员二维码进行扫码，读卡是否正常；</font>

<font style="color:#333333;">4. 屏幕测试，点击屏幕各项功能，是否能正常进入到对应的操作界面，检查是否有乱触情况；</font>

<font style="color:#333333;">5. 关机开机测试，关闭电源10秒重新开机，检查是否正常连接；</font>
