# 1、作业说明

自助存币机V10是一款支持扫码，读卡的自助存币设备。请按照安装说明准确安装设备。

# 2、作业准备

1.自助存币机V10通电

2.自助存币机V10接入网线，并且已经接入局域网，网线能正常获取IP地址。

3.服务器已经部署完毕。

# 3、作业标准

自助存币机安装完毕并能正常运行

# 4、作业步骤

1.存币机先通网通电

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf7ce642c&type=med)

2.通电后，存币机会显示H04的

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf7d7642d&type=med)

3.用钥匙打开存币机，找到内部的主板，一直按第二个按钮，刚刚开始是H04的，需要一直按它，按到提示H07的时候，就可以等待刷卡了

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf7df642e&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf8e5642f&type=med)

4.登录油菜花后台，选择设备-基础设置-卡头WiFi通讯设置-重新设置通讯网络

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf8f36430&type=med)

5.填写服务器地址，点下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf8fb6431&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf9026432&type=med)

注意，这一步如果无线名称是系统自动生成连接WIFI的情况下，通用配置卡是无法读写的，需要将这里的无线名称和密码长度改短才可以，后续版本会修复此问题

12.最后插上读卡器，放上会员卡，把配置好的网络写进卡里面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf9e26433&type=med)

13.写完保存后 ，就去存币机刷配置卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b45cdf9ea6434&type=med)

14.刷完连接上后就开张会员卡，存币测试。
