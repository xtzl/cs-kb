# 问题描述

通常情况下就金币是只作为虚拟电子币存在（部分场地耗币量较大，机台电子币流通较快），不允许作为实物币提取出来，但部分客户因场地主观需要，亦可通过后台设置，让该金币储值以实物币的方式提取出来。

注意：该功能常态下默认不开启。

# 解决方案

设置路径： 【设置】->【系统设置】->【会员提币设置】->开启

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f7d53d2900952&type=max)

开启该提币设置后，后续即可在兑币机上登录会员， 选择金币提币

# 常见问题：

问题：在指定路径上找不到该功能，是什么原因导致的？

解答：

思路一：联系运维后台管理员确认是否有开启该功能。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f7d5ab6990988&type=max)

思路二：检查当前新娱版本是否为最新版本，因是新功能，部分版本较低的新娱系统不支持。
