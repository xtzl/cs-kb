# 怎么在收银台给会员手动存票

1》路径：

1）：商品--售卖商品--快捷功能--手动存票

2）：会员--会员资料--编辑资料--存票--

2》步骤：查找到相关的会员，输入需要存入彩票数量，填写号摘要后点击确定即可
