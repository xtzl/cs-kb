存票赠送

一、功能介绍：

• 支持给不同存票数量会员进行按比例存票数量*比例进行奖励彩票

二、操作流程

1）入口 【 存票赠送 - 手动赠送】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ef61931a4833&type=med)

2）输入你要统计的【存票时间】【存票数量】【存票类型】，点击④查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ef61931e4834&type=med)

3）确认查询出来的会员数量，填写当前赠送活动的名称，并且填写【赠票比例】；

a.会员赠送彩票数 = 会员存票数 * 赠票比例

b.赠送彩票数据量较多的情况下，执行时间比较长（0.5~2个小时），请在非营业时间进行；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ef6193224835&type=med)

4）发放失败或者需要追回的奖励，可以通过对应功能操作

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000198ef6193284836&type=med)
