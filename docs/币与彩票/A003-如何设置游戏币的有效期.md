# 操作步骤

按下图打操作，分别设置代币和金币有效期（一般只设置金币的有效期，因为金币一般是作为赠币使用的）；例如充值100得80币，额外送50币，赠币有效期为1个月，那么就在套餐里把金币设为有效期1个月
