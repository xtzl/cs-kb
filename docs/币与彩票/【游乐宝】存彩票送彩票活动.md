# 业务场景

门店举办机台存票活动，顾客游玩机台存满5000票，额外赠送200彩票，引导顾客到店游玩机台

# 实现步骤

第一步：新增存票任务
路径：后台--会员--任务管理--新增--本地任务

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f28cca6842b6b&type=max)

## 注意事项

1》本地任务和小程序任务区别
本地任务不需要手动领取，小程序任务需要手动领取触发
2》本地任务是顾客完成任务后奖励会直接到账

3》门店怎么查看任务完成情况

任务管理这边点击参与次数进行查看

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018f28d0cf602b87&type=max)

4.如果只有指定的个别机台可以参加怎么设置
适用项目--勾选一下限定机台--然后勾选对应项目
