**一、功能介绍：**

+ 支持给不同存票数量会员进行按比例存票数量*比例进行奖励彩票



**二、操作流程**

1）入口 【 存票赠送 - 手动赠送】

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1745232110285-ec2940e7-9821-4f80-9f99-7c1d29d4b01b.png)



2）输入你要统计的【存票时间】【存票数量】【存票类型】，点击④查询

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1745232251660-391b7b29-2156-4ab7-bc76-4b0fc3217e6e.png)



3）确认查询出来的会员数量，填写当前赠送活动的名称，并且填写【赠票比例】；

:::danger
a.会员赠送彩票数 = 会员存票数 * 赠票比例

b.赠送彩票数据量较多的情况下，执行时间比较长（0.5~2个小时），请在非营业时间进行；

:::

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1745232390918-cd095bc0-cb5f-400e-825a-1eb8584763e7.png)



4）发放失败或者需要追回的奖励，可以通过对应功能操作

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1745232624934-03803736-0cee-4eec-9f60-570c8157ad6c.png)
