# 🔴应用场景
+ 门店举办“彩票王大赛”，我想根据会员存票的数量进行排名PK，前N名有不同的奖品
+ 为促进会员消耗彩票，门店举办消耗彩票排名赛，一周内兑换消耗彩票超过10万可参与排名，第一名可得华为手机一部

进阶用法：

上面的设置的中， “存票倍数”和“兑票倍数”这两个参数分别控制排行榜的数值统计方式。 

👉举例：如果你想根据会员消耗彩票进行排行榜活动， 可将“<u>存票倍数</u>”设为0，“<u>兑票倍数</u>”设为1

👉举例：为进一步促进会员消耗彩票，可将“<u>存票倍数</u>”设为1，“<u>兑票倍数</u>”设为2，这样产生的效果是：为获取更高的排名，会员除了存票外，还要将这些存票及时兑换掉（因为“兑票倍数”为２，代表每次兑换消耗一张彩票，在排行榜上的分数为２，兑换越多，分数越高）

:::
