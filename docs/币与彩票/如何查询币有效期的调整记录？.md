# 应用场景
适用于查询调整过金币或代币有效期的记录。

# 操作流程
路径：会员**→**会员查询**→**调整币有效期查询

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718705040038-d8aad0fe-648e-489e-a09c-b4dda227fe80.png)



# 常见问题
问：可以只筛选查询同种类型的调整记录吗？

答：可以的，在【调整币有效期查询】筛选条件，筛选下类型，例如：金币或者代币。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719297585590-bf215454-9ab1-4549-80ac-198fa6e95972.png)
