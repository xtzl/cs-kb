# 🤗应用场景
一、快捷核销提币

新功能上线后，支持**兑币机首页直接扫码识别【美团券码】【抖音券码】【快手券码】【提币码】【会员码】**，并自动进入对应的核销/提币页面；

****

二、自选提币方式

目前客户在兑币机提币时，希望可以根据自己的需求进行提实物币或者存币到会员卡，因此兑币机新增了支持会员自选出币还是存币



# 🧐如何设置【自选提币方式】？
①兑币机右上角，点击【设置】

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716350284558-52f78a27-66f8-48a0-8e84-1ba636abbadf.png)



②点击【功能设置】

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716350376998-716f6bbd-e63f-431f-800c-84005ed65b28.png)



③根据您的需求自行选择提币方式；并且点击【确定】即可

![](https://cdn.nlark.com/yuque/0/2024/png/44741777/1716350444852-7dd62cd5-75ad-46c5-9a69-d016c9370ecd.png)



# 🙋‍♂️🙋‍♀️用户/会员看到的自选提币方式界面是什么样子的？
当您选择了提币方式为【实物币直出，代币登录会员，自动币可出币/登录存币】时；

用户核销团购套餐的时候，就会在兑币机展示【选择提币方式】弹窗，用户就可以根据自己需要选择对应提币方式了；

![](https://cdn.nlark.com/yuque/0/2024/jpeg/1584417/1716436089186-384d4da7-4134-44ff-a653-60c06a0119b6.jpeg)

# 🧐常见问题
问：团购提币方式有哪几种？

答：三种

1）团购套餐如果配置为自动币或实物币，客户核销后都直接出币；如果配置了代币，则需要登录注册会员并存入会员卡代币中

2）团购套餐不管任何币种，都要求用户注册登录后才可提币/存币

3）团购套餐配置是实物币则出币，代币则需要用户登录，自动币则允许用户自行选择出币或存币
