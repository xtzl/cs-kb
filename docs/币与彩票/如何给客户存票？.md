# 应用场景
自助碎票机出现故障或自助碎票机排队人数较多的情况下影响客户存票，如何在收银台给客户存彩票

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-存票

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击存票，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718777815088-641db0af-c412-4878-af01-6013606923f6.png)

#### 输入客户存的彩票数量，生成摘要，点击确认，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718777947968-7ef5ad1f-b75e-4a2d-9177-efdcf4b95acb.png)
