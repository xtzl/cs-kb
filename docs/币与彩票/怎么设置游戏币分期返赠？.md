# 🔴应用场景
暑假快到了， 为锁定学生党在暑假期间到店消费， 门店推出充值分期返赠活动，“充值59元得200币， 其中100币立即到账，剩下100币需要分成四周到店领取”

# 🔴常见问题
❓︎问：会员在小程序购买套餐可参与到分期返赠吗？

答：设置后， 会员无论是在收银台， 小程序或兑币机上购买， 都可获得分期返赠
