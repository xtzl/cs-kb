# 应用场景

PC端输入金额，系统直接计算最优惠的方案为顾客选择游戏币套餐，并计算出游戏币数量，又或者智能收银台中开启塞钞出币功能时，系统也同样根据当前金额进行游戏币套餐计算，换算出最优惠的游戏币方案并购买出币。

# 操作步骤

操作路径：登录游乐宝收银台——商品——智能售币——输入购买金额——确定——（选择存入会员卡或出实物币）——结账。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b81d11cd67465&type=max)

# 注意事项
1.实物币：输入金额选择实物币，系统会自动换算游戏币方案计算币数（
此处读与不读取会员卡，区别在于如果存在针对会员的优惠方案，读取会员卡会获得更优惠，
实物币中会过滤掉含有金币的游戏币套餐 ）；

2.电子币：输入金额，读取会员卡选择电子币（只能销售于会员，含代币或自动币），进行结账操作。

# 智能售币换算规则：
1、实物币包括实物币和自动

2、代币包括电子币与自动

3、代币的币数=代币+金币

4、币单价=优惠后的金额/币数

5、优惠排序：币单价正序=》套餐优惠价倒序=》代币数倒序

6、将币单价最低的币套餐加入购物车

7、重复6、直到剩余钱=0，或者查不出币套餐了
