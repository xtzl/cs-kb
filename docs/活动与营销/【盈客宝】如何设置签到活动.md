# 一，路径

游乐宝：线上——盈客宝管理——营销活动——签到

娱乐管家：线上管理——盈客宝小程序——小程序功能设置——营销活动——签到

# 二，后台签到设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bec6af75c7a7f&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bec6af7667a80&type=med)

是否定位：勾选后会员签到时需要启用定位，并且定位在门店地址附近才可以签到

奖励类型：支持代币、金币、彩票、积分和娃娃，代币、金币可设置有效期，彩票、积分和娃娃不可设置有效期

日签奖励：签到当天可获得的奖励数量，可设置0

循环模式：支持自然月、固定天数两种模式，固定天数指门店根据活动需要自行设置的签到循环周期。

连签奖励：支持连续签到和累计签到两种模式，需要在循环模式设置的签到周期内满足条件才可以获得连签奖励。设置连续签到奖励时每个挡位每个周期内只会赠送一次；支持支持代币、金币、彩票、积分，娃娃和优惠券奖励

规则说明：展示在小程序签到页面右上角内的规则说明

会员级别：可限制指定会员级别才可以参与签到

入口提示：开启后未签到每天用户第一次打开小程序时会提示签到

主题名称：展示在小程序签到页面顶部

# 六，常见问题

问：签到显示不在门店？

答：1，检查门店地址是否正确； 2，调整门店距离范围，例如500米。盈客宝管理>门店资料维护>定位，里面查看门店的定位信息和修改定位，在小程序首页点门店名称，可以看到顾客手机定位到门店的距离是多远。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c1f4186b51879&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c1f45f8e018b6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c1f469d4518c7&type=max)

问：签到显示无法获取定位

答：1，检查手机有没有开启GPS定位功能；2，小程序有没有授权允许定位，小程序右上角点三个点...，再点设置>位置信息，看是否允许定位权限。
