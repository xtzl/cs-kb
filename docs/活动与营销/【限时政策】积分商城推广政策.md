# 政策说明

即日起，全面推广积分商城功能，公司并提供对应的推广奖励。

# 政策奖励

推广后，技术人员能获得50元/店奖励。

# 政策奖励适用人员范围

全体技术支持、全体服务商团队

# 政策达成要求

1. 在推广期间内，技术人员所在的安装门店充值不少于500元菜籽，需要拍照记录；

2. 客户加【菜菜】微信，需要拍照记录；

3. 客户在朋友圈/社群/门店展架展示积分商城照片一张或以上，需要拍照记录；

4. 近一个有正常流水消耗。

# 常见问题

1.如何加菜菜的微信。

答：在宣传海报中有，或者直接扫下方的二维码来添加。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e6d7b3fc84dad&type=max)

2.添加菜菜微信有什么作用？

答：一方面相关推广的方案可以咨询菜菜，让门店可以更好利用积分商城促进消耗，另一方面菜菜每隔一段时间会宣发一些宣传物料，可用于快速更新门店物料。

3.线下物料可以哪里领取？

答：在油菜花信息科技公众号菜单中有。共有5套方案可选。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e6d7cf2ea4dce&type=max)

4.物料中没有二维码，门店人员不太会更新怎么办？

答：可以联系油菜花的设计师（陈美静）帮忙设计，服务商团队可让助理协助联系。

5.这个积分商城和以前的积分商城有什么区别？

答：外观上没有区别，但是大部分的货源从原来的第三方平台（京东商城）调整为源头直供，成本更低且种类更贴合咱们这个行业。
