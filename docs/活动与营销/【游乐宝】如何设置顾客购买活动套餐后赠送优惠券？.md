# 应用场景

用于门店开展营销活动使用

# 操作步骤

设置思路：先设置一个活动商品——再设置下买了这个商品要送的优惠券——设置一个充值赠送选择优惠券

## 第一步：设置活动商品（如已设置，可跳过此步骤）

设置路径：游乐宝后台——商品——商品管理——根据实际需要新增活动商品

注意：设置充值赠送也可以是其他商品（预存款充值、组合商品、游乐套票、游戏币），可根据实际情况灵活选择设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c80a3102254&type=max)

## 第二步：设置优惠券（如已设置，可跳过此步骤）

设置路径：游乐宝后台——营销——营销方案——创建方案——满减促销

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c835fed226b&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c8701f4226c&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c89ad2e226e&type=max)

## 第三步：设置充值赠送

设置路径：游乐宝后台——营销——营销方案——充值赠送——新增——选择充值赠送的商品——选择设置购买赠送的优惠券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c68bef3220f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c6c761e2215&type=max)

# 注意事项

1.在第一步中，设置活动商品时如果是零售商品的实物商品，设置完需要加一下库存（在入库单新增库存数量），不然收银台卖不了该商品；

3.设置充值赠送也可以是其他商品（预存款充值、组合商品、游乐套票、游戏币），可根据实际情况灵活选择设置；

2.赠送的券是立即到账的
