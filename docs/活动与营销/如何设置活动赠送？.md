# 🔴应用场景
在举办某些活动游玩时，游客满足一定条件后，可以在前台领取游戏币，此时可以设置活动赠送来进行赠予，并可以起到限制每个会员只能领一次的效果

# 🔴常见问题
❓️问：只能是会员才能赠送吗？

答：散客也支持，但为了规避散客重复获取的风险，需要输入身份证号码来进行记录。



❓️问：固定周期和自然日有什么区别？

答：固定周期按天数来计算，自然日则按照日历的自然日来计算。
