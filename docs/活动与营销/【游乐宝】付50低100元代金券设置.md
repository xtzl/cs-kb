# 业务场景

适用与门店促销活动付50抵100元活动

# 实现步骤

第一步：新增50元零售商品（如果已经有了可以跳过）

路径：后台--商品--零售商品--新增

注意事项：该商品启用库存控制设置为虚拟商品，这样设置后不需要设置商品库存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932da6b1ae3418&type=max)

第二步：新增100元优惠券
路径：后台--营销--商品促销--新增--满减促销--促销方式凭券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932daddc11342e&type=max)

第三步 设置充值赠送，购买指定零售商品送指定优惠券

路径：后台--营销--充值赠送--添加

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001932db18f913437&type=max)

# 常见问题：

顾客如何获取优惠券？
答:收银台或者小程序购买指定零售商品，系统将会自动将优惠券送到会员账户。

顾客如何使用优惠券？
答：收银台或者小程序购买套餐时，只要符合优惠券使用条件，系统会自动使用。

优惠券的有效期设置错了能否修改？
答：不能修改
