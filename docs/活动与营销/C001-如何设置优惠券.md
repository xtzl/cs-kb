# 操作路径

后台--营销--优惠劵--优惠劵设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad15f62a3446b&type=max)

# 操作步骤

- 点击营销

- 点击优惠劵设置

- 选择要修改的优惠劵

- 点击修改

- 点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017ad160bcf3446c&type=max)

# 注意事项
优惠劵有效期支持与促销方案的有效分开
