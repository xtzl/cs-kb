# 🚩运营建议说明
当门店积累一定的人气与口碑之后，门店可逐步通过一些优惠方案提升顾客购买欲望，并且可以根据不同的顾客群体和购买力给予不同的消费优惠。从而整体提升单个客户的客单价。

# 🚩套餐设计与促销策略 
## 核心目标
通过套餐赠送优惠券、限时优惠等功能，促进二次消费，提高客单价。

## 具体措施
### 建议方案①：充值套餐赠送后续使用的优惠券:
    - _案例：充值赠送赠币券_
        * 套餐：充值100元得299币，并赠送3张50币赠币券，每次消费可核销1张赠币券。
        * 优势：锁定长期消费，有效提高客单价。
        * 系统设置：后台→营销→赠币券→选择“任意购买制定套餐自动核销”。
        * 参考操作：【[如何设置充值套餐赠送优惠券？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/ywpnv3xq9ek76fha)】【[如何设置赠币券](https://ychylb.yuque.com/staff-gcg8pk/ylgj/bssorkrqnns9pxn0)】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1773718871683-d3213cd1-5b6b-4164-ab79-73f34c01a81c.png)

注意事项：赠币券可使用条件可以根据场地情况来调整。如可设置后续购买任意指定游戏币套餐都可以自动核销，或者消费满多少钱自动核销，或者是只要到店就自动核销几种情况。但注意使用门槛不建议设置太高，避免降低顾客对优惠券的期待感。

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774334238623-f2f3bf32-7f3d-481a-b936-6d763a29bcf9.png)

### 建议方案②：利用限时抢购，营造饥饿营销效果，制造稀缺感，提高承担率。
    - 限时抢购游戏币套餐“199元500币”，制造稀缺感。
    - 设置：商品管理→限购规则→每人限1份。
    - 参考操作：【[如何限购指定商品／套餐每个会员只能买１份](https://ychylb.yuque.com/staff-gcg8pk/ylgj/orszh4mvwcqszw09)】

# 🚩升单与交叉销售 
## 核心目标
通过智能推荐和捆绑销售提高客单价。

## 建议方案
### 建议方案1：通过智能升单功能，提升顾客单次购买单价
    - 说明：客户购买低价套餐时，系统弹出高价套餐对比，并且参与升单则可额外获得奖励。
    - 路径：小程序→升单设置→配置推荐逻辑（如“满100元加赠30币”）。
    - 参考操作：【[智能升单](https://ychylb.yuque.com/staff-gcg8pk/mw9lzp/ihoglg9wbrgdvwpf?singleDoc# 《智能升单》)】【[如何开启兑币机“智能升单”功能？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/abi7tcgpvk2dr8hr)】【[如何升级套餐](https://ychylb.yuque.com/staff-gcg8pk/ylgj/lw6uf4ic2u2hx8fa)】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1773719093951-a5843fe7-e431-4b7a-a95b-86d06d6d176d.png)

    - 注意事项：升单功能支持线上套餐核销后也可以升单，设置路径为：后台→线上→美团商品绑定/抖音快手商品绑定→设置升单商品。
    - 效果展现：

![兑币机购币升单](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774335780135-7fb06554-ae39-4958-b787-d45b14967615.png)![兑币机核销渠道升单](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774335854873-67255964-0f9d-4766-a7a1-d975b3a6a5c6.png)

### 建议方案2：利用组合商品功能，模糊商品价值，提升客户购买欲望
    - 说明：用游戏币+新机台体验券+零食打包销售，提升价值感。
    - 案例：春节套餐“200元=220币+新机台游玩1次+抽奖机会+零食大礼包”。
    - 参考操作：【[如何设置组合套餐？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/zguyq8fs2ccwwthn)】【[转盘抽奖](https://ychylb.yuque.com/staff-gcg8pk/mw9lzp/qu4sz8c2v0p5nyz9)】【[盲盒抽奖](https://ychylb.yuque.com/staff-gcg8pk/ylgj/bckfgitisxgaqohq)】![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1773719396636-5d7e327f-d311-4d25-a9bb-b41799cd08c0.png)
    - 说明事项：抽奖权益，如果是通过系统来抽奖，则可以赠送抽奖券的形式来实现。如果是现场抽奖箱抽奖或砸金蛋模式，则可以提前定制实体抽奖券给到顾客或者直接给顾客抽取即可。
