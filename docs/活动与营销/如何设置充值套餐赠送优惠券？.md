# 🔴应用场景
充值赠送优惠券有两种方式， 一种是赠送实体券， 这种方式要先把券码导出来打印， 另一种是充值套餐后自动赠送到会员账户， 会员在小程序上就能查看到优惠券

# 🔴常见问题
❓️问：赠送给客户的优惠券， 客户在哪里查看？

答：如果客户是小程序会员的话，在小程序中“我的”查看



❓️问：客户收到优惠券时，能不能有个“消息提醒”

答：可以的， 请参考：[如何设置公众号消息推送？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/kpwtg3p5a2f83bgs)
