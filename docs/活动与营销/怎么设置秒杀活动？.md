# 🔴应用场景
秒杀活动一般会对商品的可购买数量进行限制，例如每个会员只能买1份， 或一共100份套餐，卖完即止。 同时会对购买时间进行限制，例如星期四晚上10点开始秒杀，如果你要做的秒杀活动符合这样的特征，就请按以下操作

# 🔴常见问题
❓️问：客户在哪里能参与到秒杀活动

答：设置秒杀活动后， 小程序首页的活动专区有展示



❓️问：如果我只想被邀请的超级VIP会员才能参与秒杀活动，要怎么操作？

答：你可以用限购券的方式，只有获得限购券的会员才能参与活动，（[如何设置优惠券](https://ychylb.yuque.com/staff-gcg8pk/ylgj/kgab0ueegsn276dw)）。 你可以手动给指定会员派券，让他们可参与活动（[如何给会员手动派发优惠券？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/xxlvdmny1vt88su2)）
