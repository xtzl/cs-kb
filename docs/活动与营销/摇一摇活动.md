# 场景应用
门店可创建摇一摇活动，会员通过微信或店铺小程序扫描氛围大屏显示的活动二维码即可参与，在规定活动时间内会员摇晃手机次数越多，排名越高。活动结束时会根据设置的活动奖励按排名自动发放对应的名次奖励，若发放失败，可在活动详情页面进行手动发放。



# 版本依赖
+ 娱乐管家：V10.4.2190或以上
+ 边缘网关版本：2026031701
+ 影音盒子：V1.1.8
+ 氛围系统小程序：V1.1.1

# 操作流程
### 后台设置
#### 功能路径：
【小程序】-->【营销活动】-->【氛围摇一摇】-->【新增】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776059788014-26d5c858-e16f-4d57-97cf-68c1a83e3126.png)



#### 活动设置说明
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776059833712-251e5097-ede6-4b86-ad71-f97ae4ab113a.png)

活动名称：可设置重复的活动名称。

开始时间：设置开始时间，到点后自动开始摇一摇活动，因定时任务为1分钟执行一次，所以建议设置的活动开始时间与当前时间间隔大于1分钟。

防止薅羊毛：可设置每个手机号参与每天一次（默认勾选），会判断同一手机号是否在历史活动中有参与；距离门店X米，根据【小程序】-【门店资料维护】中设定的门店定位来作圆心判定玩家当前距离。

报名限时：氛围大屏上会显示活动报名阶段，该限时为参与人员扫码报名期限。

比赛时长：氛围大屏上会显示活动开始阶段的活动结束倒计时。

活动排名显示：氛围大屏上会显示活动结束后的获奖排名页面，页面显示倒计时。

奖品：弹窗设置每个排名或排名区间的奖品，排名不可重复。

氛围语音：已接入AI语音包，可根据所填内容生成摇一摇活动各阶段对应的语音播报。



#### 完成活动设置
活动创建成功后，应显示如下状态，且根据设置的“开始时间”会自动开始活动。

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776059934914-ef3aebbc-7c31-4bac-8090-b418eaa7b7d3.png)



#### 列表操作功能说明
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776059950675-76ae74f1-adad-424e-8bdd-793540079bce.png)

开始按钮：活动状态处于“未开始”的活动会显示该按钮，点击可手动开始摇一摇活动。

结束按钮：活动状态处于“进行中”的活动会显示该按钮，点击可手动结束摇一摇活动。

查看按钮：点击可查看活动的设置页面，只有活动状态为“未开始”的活动可进行编辑操作。

复制活动：点击可复制相应的活动。



#### 活动详情功能说明
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776059965475-7d4765cf-fd9d-4eb1-a406-ac665ac7f955.png)

摇一摇活动结束后所有参与活动的会员数据均记录在【营销】-->【摇一摇活动】-->【活动详情】

奖励发放情况状态分别为：处理中、已发放、发放失败，其中，处理中状态为系统自动发放奖励任务执行中，发放失败状态会有相应失败原因文案记录在“错误信息”中，且可进行手动“重发”操作。



#### 氛围系统小程序【场景】配置
配置路径：【氛围小程序】-->【场景】-->【摇一摇】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774243235875-8836c5b3-b87c-4079-b35c-cf2729bc6ff9.png)

勾选所需要显示摇一摇活动的氛围区域，可配合【灯光盒子】设置摇一摇活动各阶段的灯光氛围。
