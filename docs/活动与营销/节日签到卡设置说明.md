# 一、功能路径

新版娱乐管家后台系统——小程序——节日签到卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf30ea23326ce&type=max)

# 二、设置说明

1、设置活动名称和活动时间

注：同一个活动时间仅支持一个活动在进行中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf4402d362bf0&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf4402d892bf1&type=med)

2、获得签到卡设置

设置签到卡赠送时间，在赠送时间内购买指定套餐获得签到卡（支持送签到卡的购买渠道包括：小程序，收银台，POS机，自动设备），退套餐时自动作废签到卡，已领取的签到币数，可以在后台的签到卡查询处追回

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3515ec12799&type=max)

支持设置会员最多可获得的签到卡数量（最多仅支持获得10张签到卡）和每日最多使用签到卡的数量。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3507d6f2797&type=max)

3、打卡规则设置

会员获得签到卡后打卡的方式有三种可以设置，分别是A、卡头投电子币，B、会员提币，C、当天单笔订单金额大于等于多少元

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3aac6aa2890&type=max)

支持设置打卡奖励天数（最大天数可设置10天），分别设置每天打卡的奖励（奖励仅支持设置代币和金币）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3ad8778289c&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3af417828a2&type=max)

节日签到卡活动设置完成后即可点击生成规则，自动生成活动规则说明

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3b2996128ae&type=max)

# 三、常见问题解答

### Q1：签到卡作废后，已获得币数如何追回？

说明：小程序——节日签到卡——签到卡查询——追回奖励

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3bb915828d1&type=max)

### Q2：会员如何在小程序上打卡，或查看打卡记录？

1、小程序——节日签到卡——活动表——签到卡活动二维码导出二维码可扫码进入签到卡活动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3c1039e2930&type=max)

2、小程序——广告图管理——新增，上传首页banner图片，选择小程序路径，可实现点击小程序首页广告图跳转签到卡活动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3c398bd2967&type=max)

3、小程序——小程序装修——副功能区选择小程序路径——功能路径——节日签到卡，可实现点击小程序副功能区跳转签到卡活动

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf3d6741a2a58&type=max)

### Q3：为什么刚购买了签到卡，打开签到打卡界面不用打卡就可以直接领取奖励？

原因1：如果门店活动设置的签到卡赠送时间和打卡时间是一致的，并且当天购买签到卡套餐之前会员有进行了提币或者投电子币，那该会员购买签到卡后就直接完成了当天的打卡任务可以领取奖励

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf42d24272b99&type=max)

原因2：如果门店活动打卡规则有勾选每天单笔订单金额大于等于多少元可以完成打卡并且购买获得签到卡的套餐金额是符合这个打卡金额的，那购买获取签到卡后是可以直接完成打卡领取奖励的（如图所示例如：打卡定义每天单笔订单金额≥20，购买获得签到卡的商品售价也是大于或等于20元，购买该商品后即可直接完成打卡领取奖励）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019bf4030e4b2b08&type=max)

### Q4：为什么从小程序签到卡活动点击购买活动套餐可获取签到卡按钮跳转的界面显示了全部的小程序商品？

目前从小程序签到卡活动点击购买活动套餐可获取签到卡按钮跳转的界面确实是会显示所有上架中的小程序商品，后续会进行优化，修改成跳转的界面只单独显示购买可获得签到卡的套餐
