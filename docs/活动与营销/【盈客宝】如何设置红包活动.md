# 1、路径

游乐宝：线上——盈客宝管理——营销活动——红包活动

娱乐管家：线上管理——盈客宝小程序——小程序功能设置——营销活动——红包活动

# 2、红包活动设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bec60331a7a4f&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bec60c4727a50&type=max)

通用码： 一个红包活动通用一个二维码，每个会员都可以扫码领取一次红包，直到红包活动结束或红包领取完毕

一物一码：根据红包派发数量生成对应数量的二维码，每个二维码可以扫码领取一次，一个会员可以扫多个不同的二维码领取

方案名称：展示在红包页面顶部

方案有效期：红包可以被领取的有效时间

赠送储值：支持代币、金币、彩票、积分和娃娃，代币、金币可设置有效期，彩票、积分和娃娃不可设置有效期

赠送规则：指定数量，即每人每次领取的红包奖励固定数量；拼手气，可设置红包数量范围，领取红包在这个范围内随机获得奖励

会员级别：通用码活动可以限制会员必须到指定级别才可以领取红包

是否定位：勾选后会员签到时需要启用定位，并且定位在门店地址附近才可以领取红包

转发分享：进入红包活动后显示邀请好友一起瓜分的分享按钮

领取次数：通用码活动每个会员可领取1次，一物一码活动不限制

活动规则：展示在红包页面底部

# 3、活动概况
