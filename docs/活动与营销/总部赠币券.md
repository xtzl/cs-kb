# 应用场景
赠币券可用于引流使用，而总部支持统一设置赠币券并给予门店使用的权限。

# 操作流程
路径：登录总部后台→促销→赠币券

点【+新增赠币券】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721545912692-12320e78-b57a-4051-bfe2-cb6b00c7e663.png)

在新增赠币券方案中，按照下图描述进行配置，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546076229-cc5fd534-6f3a-4ec4-996c-31ea26f8c1bc.png)

如果需要自动派送，也可以按照下图所示进行配置。
