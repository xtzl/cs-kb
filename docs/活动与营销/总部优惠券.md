# 应用场景
总部可统一设置优惠券，在原来的促销方式下增加优惠券的核销优惠方式，以下则为优惠券的设置教程。

# 操作流程
路径：登录总部后台→促销→赠币券

点【新增代金券】/【新增限购券】/【新增特价券】/【新增折扣券】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546542888-e658a427-4b51-43e6-a423-b78e83637837.png)

在新增的优惠券方案中，按照下图描述进行配置，点击【确定】完成设置

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546743659-f335b416-9d92-485c-8c5e-d8ff616a764a.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546788430-b2552e2c-a4bc-4697-ac9b-b94a1bdc1de8.png)

如果需要使用自动派券，可在【自动派券】一栏中进行相关设置，如下图所示

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546913599-b7a52f0c-6526-4621-8829-f064ec37a92f.png)

如有验券人员要求，可在【核销人员】中，绑定对应的人员（场景：派发周边商品的优惠券，周边商盟可通过游乐掌柜进行验券，而此处则可以限制哪个账号验证哪些优惠券）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721546945003-55e71280-9ef0-4da6-a96d-f281d55b8579.png)
