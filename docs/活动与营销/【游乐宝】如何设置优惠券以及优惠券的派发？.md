# 优惠券的分类

在游乐宝系统中有4种券，我们先来认识这4种券的区别，您再根据需要选择对应的券来创建。

特价券：对现有的商品价格进行设置固定的折扣价格，设置成指定的价格进行优惠，一定要先创建商品才可以设置这个券

折扣券：对现有的商品设置折扣比例，按照设置的比例进行优惠，一定要先创建商品才可以设置这个券

满减券：设置券的额度，可以设置购买指定商品满M减N，也可以设置无门槛券

限购券：设置会员限时限量购买指定商品

# 关键参数

自动促销：顾客直接购买指定商品即可享受优惠，无需使用优惠券(不能生成券），适合通过会员级别设置不同的方案进行优惠。

凭券促销：顾客需凭优惠券购买指定商品才能享受优惠（可以生成券），优惠券是优惠或购买凭证。

# 特价券

## 设置路径

游乐宝后台 > 营销 > 创建方案 > 特价促销

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977ca9a14414dd&type=max)

新增特价促销方案

### 情况1特价券自动促销（无券）

选择自动促销，这种方式是没有券生成的，在收银台购物车加购商品时会自动按特价来优惠，适合设置会员级别特价的商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cc520581546&type=max)

### 情况2特价券凭券促销（有券）

选择凭券促销会生成优惠券，在收银台购买商品时需要通过优惠券才可以达成指定金额优惠购买

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d8088011910&type=med)

设置优惠券的名称、发行张数、优惠券图片等信息↓

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cd2c18c157c&type=max)

立即审核通过此方案，也可以稍后再说，后面再审核↓

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cd2ecb7157d&type=max)

稍后审核的步骤↓

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977cd64bb41586&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d6ffd3c18a0&type=max)

# 相关问题

### 1.券发放出去后发现设置错了或发多了一张，可以将券作废吗？

可以的，可以通过后台禁用优惠券方案或者作废优惠券。禁用后顾客得到的优惠券就不能用了↓

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001977d3604231773&type=max)

如果是发多了，可以通过作废，将多余的优惠券作废掉↓
