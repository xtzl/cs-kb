# 应用场景

用于小程序引流、开展活动时使用

# 操作步骤

## 第一步：设置抽奖方案

设置路径：游乐宝后台——营销——营销方案——小程序抽奖——新增抽奖方案——保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c4072272193&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c50ef18219d&type=max)

## 第二步：盈客宝设置抽奖

方法1：游乐宝后台设置，在小程序进入抽奖页面

设置路径：游乐宝后台——线上——盈客宝管理——功能开关——首页——副功能区——选择抽奖——保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0c5306c021a0&type=max)

方法2：游乐宝后台下载活动二维码，贴出二维码，顾客直接扫二维码进入抽奖页面

设置路径：游乐宝后台——营销——营销方案——小程序抽奖——抽奖活动二维码——下载

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c332938bc2d66&type=max)

# 注意事项

## 顾客如何兑奖？

1.抽中奖品为虚拟储值或优惠券将自动充值到会员账户中；
2.抽中奖品为实物奖品需用户在有效期内凭兑奖券到线下门店领取；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c33389f1c2d7d&type=max)

3.顾客到收银台后，出示中奖券码，收银台兑换即可

兑换路径：收银台——会员——抽奖核销

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c3338dcdc2d7e&type=max)

## 如何查看抽奖记录？

查看路径：游乐宝后台——营销——小程序抽奖——抽奖记录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c14eb4c018c3340e9132d8c&type=max)

## 如何追回奖励？

实物、虚拟奖品待核销：抽奖记录找到此记录点击【取消奖励】

实物已核销：无法追回

虚拟奖品已核销：抽奖记录找到此记录点击【追回奖励】（注：会员账户余额足够，余额不足是无法追回奖品）
