# 🔴应用场景
有时候，优惠券发错了， 或优惠券设置有误， 需要把会员卡里的优惠券“作废”

# 🔴常见问题
问：会员使用过的优惠券， 可以“作废”吗？

答：“作废”主要针对的是未使用的优惠券， 如果是已经使用的优惠券， 你可能要在收银单将订单“退货”， 请参考：[如何给客户退单？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/cy38rfrnzcc8q4hf)
