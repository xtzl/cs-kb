# 🔴应用场景
使用消息推送功能时，需要提前在公众号设置相应模板，此教程用于说明如何设置该模板。 

# 🔴操作流程
## <font style="color:rgb(51, 51, 51);">一、登录微信公众平台</font>
<font style="color:rgb(51, 51, 51);">服务号的超级管理员微信扫码登录到公众号，</font><font style="color:rgb(51, 51, 51);">跳转链接</font>[<font style="color:rgb(79, 124, 206);">https://mp.weixin.qq.com/</font>](https://mp.weixin.qq.com/)

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259146748-d2ce7b55-95ca-4592-a99f-fa3953d0b6f2.png)

## <font style="color:rgb(28, 30, 33);">二、开通模板消息功能</font>
<font style="color:rgb(28, 30, 33);">点击左下角的菜单“新的功能”</font>

+ <font style="color:rgb(28, 30, 33);">如果在未开通的页面看到有模板消息代表未开通模板消息，需要点击模板消息的“去开通”按钮，按照引导开通；</font>
+ <font style="color:rgb(28, 30, 33);">如果未开通中没有模板消息代表已开通；</font>
+ <font style="color:rgb(28, 30, 33);">只有已认证的企业服务号才会有模板消息功能，订阅号没有。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259182849-d4a04a67-47eb-425c-9837-bdfa8839a844.png)

### <font style="color:rgb(51, 51, 51);">申请开通模板消息接口</font>
<font style="color:rgb(28, 30, 33);">主营行业选择生活服务休闲娱乐，副营行业可以不填写，填写申请理由</font>

<font style="color:rgb(229, 51, 51);">注意：理由中不要体现营销消息，不然后期会被封禁。可以填写例如：用于小程序会员消费时自动接收消费通知和余额通知。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259213520-e248b65c-a5d8-40a1-9157-2f6bcae8c156.png)

### <font style="color:rgb(28, 30, 33);">填写资料提交</font>
<font style="color:rgb(51, 51, 51);">申请理由和行业选择完毕后，点击【提交】。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259235673-c693fa5d-71e6-4a30-8790-c9f9ba46ba2d.png)

### <font style="color:rgb(28, 30, 33);">等待审核</font>
<font style="color:rgb(51, 51, 51);">等待审核结果(经验：一般当日申请，次日能出审核结果)。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259252798-67385fb7-4f81-4791-a77b-7f1a306c8046.png)

## <font style="color:rgb(28, 30, 33);">三、设置类目模板库</font>
### <font style="color:rgb(28, 30, 33);">设置类目模板库</font>
<font style="color:rgb(28, 30, 33);">开通消息模板后，设置类目模板库</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259281202-63b82e11-2a28-470e-9213-0fa00ea8b9b1.png)

### <font style="color:rgb(51, 51, 51);">选择</font>**<font style="color:rgb(51, 51, 51);">生活服务</font>**<font style="color:rgb(51, 51, 51);"> > </font>**<font style="color:rgb(51, 51, 51);">休闲娱乐</font>**
![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1774259300162-196329cf-17b6-4ec2-a431-bc8811ec4531.png)

## <font style="color:rgb(51, 51, 51);">四、添加想要的模板消息</font>
### <font style="color:rgb(51, 51, 51);">从类目模板库中添加自己想要的模板</font>
<font style="color:rgb(51, 51, 51);">添加完成后，在油菜花后台就可以看到自定义的模板消息</font>
