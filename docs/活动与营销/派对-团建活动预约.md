# 应用场景
使用此功能可帮你实现：

+ 系统化管理派对或团建活动的预订，收费，调价，业绩提成计算等整体流程
+ 可灵活根据实际到场消费人数，调整商品数量和价格等，满足各类场景需求  
+ 所有收定金和结算的流程都在系统里完成，并且可查询，避免管理漏洞，方便对帐

# 后台设置流程
1. 按以下操作，创建派对或团建活动，例如50人起订的团建活动，特惠总价5000元，含50人门票费，饮料费等，需要收取订金1000元。
2. 你可以设置多个不同类型的团建套餐，这些都只是<u><font style="color:#DF2A3F;">基础套餐</font></u>，等客户实际到场消费后，可根据情况灵活调整套餐中的商品类型，数量和价格
