# 一、新增满减活动

活动促销-》促销方案设置-》满减促销-》新增

# 二、设置满减活动
1、顾客需要获得优惠券才能参与满减活动，在满减活动的使用类型需要设置凭券促销。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c973ab3420a70&type=max)

2、设置满减活动方案有效期，可以设置时间范围或者通过设置指定使用日、指定时间段、不可用日期。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c974007ce0a77&type=max)

3、设置适用人群，可以设置无限制或者仅限会员使用，仅限会员使用可以勾选对应的会员级别才能参与凭券满减活动。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9742235c0a7a&type=max)

4、设置参与商品，可以选择所有商品，或者选择从商品列表添加，可以点击添加商品搜索对应的商品参与活动，或者从商品分类添加，可以选择对应的商品分类下的所有商品参与活动。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c97453a530a7e&type=max)

5、设置规则类型，可以设置为无门槛或满减规则。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c974895600a87&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9749a9a90a88&type=max)

6、设置完成后点击保存，需要进行审核满减方案才生效，点击立即审核后选择通过并且输入描述后点击保存即可审核通过。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c974b4c130a8a&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c974c5c4b0a8c&type=max)

# 三、设置满减优惠券

在优惠券设置里边新增一张优惠券，设置好优惠券信息，优惠券有效期，选择优惠券绑定的促销方案（满减促销方案）勾选。可设置优惠券是否允许转赠给他人，并且可设置只有指定的账号才能核销优惠券。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c974ecb730a8e&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c976ef4250acc&type=max)

注意：优惠券发行张数=（导出/打印券码+会员手动派发+小程序派发+小程序新人赠送）的优惠券数量，不受发行张数限制：商品买赠、系统自动派发的数量。

# 四、如何派发优惠券

1、可以设置游乐掌柜自动派券和系统自动派券，设置派券周期和派券日期，勾选对应会员级别设置好每次派券数量，可勾选开卡成为对应会员级别自动赠送优惠券，可设定自动派券的时候，覆盖该会员未使用的优惠券。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c976c42ca0ac9&type=max)

2、可通过手动筛选会员派发优惠券、导入表格派发优惠券和打印优惠券二维码、导出优惠券券码等方式派发。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9771cbbe0adb&type=max)

3、可通过发布到小程序线上优惠券，让会员在小程序领券中心领取优惠券。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c977670100ae1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9777dab20ae3&type=max)

4、可通过小程序路径下载优惠券二维码，直接让会员小程序扫码领取优惠券。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c977bb6080ae8&type=max)
