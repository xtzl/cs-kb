# 🔴应用场景
有时候场地需要制作纸质优惠券， 每张优惠券上都有一个二维码， 收银台扫这个二维码就能核销这个优惠券。 本篇教程将会介绍如何在油菜花系统中导出优惠券的二维码

# 🔴操作流程
首先你需要先设置优惠券（[如何设置优惠券](https://ychylb.yuque.com/staff-gcg8pk/ylgj/kgab0ueegsn276dw)）

接着按以下操作导出优惠券码

# 🔴常见问题
问：导出时有“一券一码”和“一批次一码” ，分别是什么意思？

答：如上图， “一券一码”表示一个码代表一张优惠券，核销完就失效； “一批次一码”表示所有优惠券都是相同的一个二维码，可以多次扫码（由系统来控制每个会员能使用多少次优惠券）
