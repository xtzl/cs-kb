# 业务场景

适用与门店购买活动套餐后可以指定时间内到店签到领取游戏币，领取彩票，

# 实现步骤

第一步：新增赠币券

路径：后台--营销--赠币券--新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195bca483be4c0f&type=max)

第二步：给活动套餐设置成充值赠送赠币券

路径：后台--商品--找到对应的套餐--赠送设置--添加优惠券--选择设置好的赠币券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195bca8d5914c30&type=max)

# 常见问题

1》赠币券设置到店核销后，怎么核销赠币券

可以再收银台--会员--会员资料--读取会员信息后--点击优惠券--找到对应的赠币券点击核销

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195bcadd3f44c44&type=max)

或者也可以再兑币机的功能设置里面勾选赠币券，直接通过兑币机核销
