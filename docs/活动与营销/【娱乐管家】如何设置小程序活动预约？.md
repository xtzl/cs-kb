# 业务场景

1.常见于家庭娱乐中心，票务制儿童乐园的生日会等门店活动预约，预知人数，帮助门店做好接待和物料准备；

2.大型儿童乐园、旅游景区、博物馆、游客到店预约，用于顾客分流、人流控制、指导场地预约接待人员准备等。

# 推广方式

1.下载活动二维码，制作成海报、在朋友圈、会员群转发；

2.门店、居民区海报粘贴：将二维码或海报印刷出来，在门店或居民区广告栏粘贴、分享；

3.小程序首页广告图：利用广告图做头条宣传，点击直接跳转预售；

4.公众号推文扩散：将拼团功能或商品链接，嵌入公众号推文，点击即可跳转；

5.模板消息推送：将拼团功能或商品链接嵌入模板消息，精准推送，点击可直接购买。

# 操作步骤

### 一、设置路径

油菜花后台 > 小程序 > 营销活动 > 活动预约

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019753aaaf286fd7&type=max)

### 二、新增一个预约活动

填写活动基础信息，带*的为必填项。

注意：

1.周期性举办的活动，譬如每周六举办的活动，可以设置一个长的预约周期，把周一至周五以及周日添加到特殊日期中，再添加时间段场次；

2.景区或大型乐园利用活动预约管控人流的情况，活动日期应该设置长一点，譬如结束日期到2099年，避免活动结束，影响预约的情况。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019753aaaf436fd8&type=max)

### 三、设置活动类型

预约活动的类型分为：免费预约、付费预约

1.免费预约

用户扫签到码即可签到入场

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019753aaaf586fd9&type=max)

2.付费预约

用户需的往收银台-机台扣费/验票过闸入场

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019753cb2bdf7072&type=max)
