1.使用场景

（1）新店开业前，利用商品预售，售卖早鸟套餐，拉新引流、回笼资金

（2）节假日活动预热，提前预购造势

（3）推广方式：

a.下载活动二维码，制作成海报，在朋友圈、会员群转发

b.门店、居民区海报粘贴：将二维码或海报印刷出来，在门店或居民区广告栏粘贴，分享

c.小程序首页广告图：利用广告图做头条宣传，点击直接跳转预售

d.公众号推文扩散：将预售功能或商品链接，嵌入公众号推文，点击即可跳转

e.模板消息推送：将预售功能或商品链接嵌入模板消息，精准推送，点击可直接购买

3.关键参数

（1）活动时间：活动时间中的时间段默认都是0点，要注意选择开始合结束的时间点

（2）发货时间：可选择指定日期或统一多少天后发货，购买门票/游戏币等虚拟套餐，要到了发货时间才会显示在会员账户，供会员查询

（3）库存数量：预售商品限制数量，购买之后减库存
