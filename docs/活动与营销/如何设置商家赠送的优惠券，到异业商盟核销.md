# 实现步骤

1、总部创建一个门店-异业商盟的角色

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e296af4a65a72&type=max)

2、门店给商盟创建对应的用户，角色选择【门店-异业商盟】，账号门店可以自定义，建议使用商盟手机号/商盟名称；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e296c35b75a84&type=max)

3、给商盟开一个游乐掌柜账号，设置该账号只有券核销功能，具体操作步骤如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e296e880b5a9b&type=max)

4、后台创建一个虚拟商品，创建步骤：商品--零售商品--新增；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e297396ac5ac6&type=max)

5、门店后台营销--优惠券--新增限购券，设置优惠券的活动时间以及券有效期，需添加上创建的虚拟商品；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e298216095b79&type=max)

6、添加核销人员，点击确定并审核优惠券方案；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e297ba1535b49&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e297caa075b4c&type=max)

7、商家登录游乐掌柜，店务--券核销--扫优惠券/输入优惠券券码核销；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e298735b35b9b&type=max)
