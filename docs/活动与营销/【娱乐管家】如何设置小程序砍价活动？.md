# 使用场景

1.通过砍价助力活动造势，扩散、攒人气，让顾客调动身边好友，吸粉、加大商城、小程序曝光；

2.适用于吸粉引流、新店开业、品牌会员日、打造爆品、制造刷屏、会员群活跃等。

# 关键参数

- 砍价商品库存：参与砍价活动商品的数量，控制活动成本输出，当砍价达到最低价且在购买时间内即锁定库存，超过购买时间自动解锁；

- 砍价最低价：即最低购买价格，一般设置的时候考虑噱头1元购、1分购、9.9元购等；

- 砍价有效期：传播时间限制，即发起砍价到结束砍价的时间限制，促进用户正在规定时间内快速传播；

- 帮砍金额：支持固定和随机两种形式，固定金额系统会根据最低价和帮砍人数自动计算，无需设置；

- 最低价前是否可以购买：字面意思，看到最低价前顾客是否可以购买。
