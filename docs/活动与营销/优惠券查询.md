# 🔴报表说明
此报表用于查询发放出去的优惠券的使用情况，包括待使用、已使用、已过期、已作废四种情况，并且可以对一些发放错误的优惠券进行作废

# 🔴报表样式
路径：后台→营销→优惠券→优惠券查询
