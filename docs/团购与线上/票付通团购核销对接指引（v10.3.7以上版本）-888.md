# **<font style="color:#333333;">三、OTA电商团购网产品绑定</font>**
## **<font style="color:#333333;">1.获取票付通商品</font>**
<font style="color:#333333;">路径：娱乐管家管理后台—线上—OTA门票管理</font>

<font style="color:#333333;">操作：点击获取票付通商品，获取渠道设置的对应商品</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732761590352-f661d5c0-b286-4990-9e07-4df9d9708505.png)



## **<font style="color:#333333;">2.绑定娱乐管家本地商品</font>**
<font style="color:#333333;">操作：点击列表【未绑定】按钮，绑定本地商品（通用商品，预存款充值，游乐套票（只能绑定计次票、期限票），游戏币，组合商品），商品选择类型默认游乐套票。</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732761628465-2a318e95-7bf8-4dfd-82dc-40fb597749a0.png)

## **<font style="color:#333333;">3.解除绑定或重新绑定商品操作。</font>**
<font style="color:#333333;">操作：点击对应商品最右边的绑定商品则可以重新绑定商品，而点击解绑则解除已绑定的商品。</font>

<font style="color:#333333;">备注：</font>

<font style="color:#333333;">1）如：OTA(A商品)绑定娱乐管家A套票，用户购买A商品后，未进行核销，但娱乐管家将A商品重新绑定到B套票，用户进行核销时对A套票项目无效，只对B套票项目有效。</font>

<font style="color:#333333;">2）如：OTA(A商品)绑定娱乐管家A套票，用户购买A商品后，未进行核销，但娱乐管家将A商品解绑，用户进行核销时会提示：没有获取到对应渠道的在售门票。重新绑定娱乐管家商品后可进行核销。</font>

<font style="color:#333333;">3）绑定商品后会生成本地订单，自动创建对应商品的渠道定价</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1732761772259-2166cedd-786c-4f31-8712-b07bfbc806dd.png)
