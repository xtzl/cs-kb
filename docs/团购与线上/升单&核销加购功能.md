# 未消费情况下升单加购场景
## 一、**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（自助服务场景）</font>**兑币机套餐推荐升单
### <font style="color:rgb(51, 51, 51);">核心功能</font>
<font style="color:rgb(51, 51, 51);">可在后台开启兑币机升单功能，顾客选购套餐待支付环节，设备自动推荐加价即可升级的高性价比套餐，还可配置首次升级额外赠送福利，撬动客单提升。</font>

### <font style="color:rgb(51, 51, 51);">配置规则</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">录入游戏币套餐时务必填写套餐原价，系统依靠原价核算折扣力度，以此向顾客展示优惠差额，增强说服力；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">手动开启后台兑币机升单总开关。</font>

### 配置说明
<font style="color:rgb(51, 51, 51);">第一步：设置游戏币套餐时，需要设置对应的套餐的原价，用于系统计算折扣率使用，推荐游客时，会按照折扣率来推荐优惠套餐。</font>

## 二、（自助服务场景/收银台服务场景）抖音 / 美团团购<font style="color:#DF2A3F;">核销时</font>连带加购
### 核心功能
顾客在线上渠道购买游戏币套餐后，在<font style="color:#DF2A3F;">核销时</font>，系统自动推荐后台预设的加购套餐，通过价格对比吸引顾客购买更高价值的套餐，提升客单价。

### <font style="color:rgb(0, 0, 0);">配置说明</font>
第一步：设置推荐的套餐，可参考[如何设置游戏币套餐？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/iell1iz226lseupw)<font style="color:#DF2A3F;">注意：套餐需要先上架，核销商品绑定后再将套餐设置不上架</font>；

第二步：绑定抖音团购商品，在「核销加购商品」栏目中选择需推荐的游戏币加购套餐；

# 已消费情况下补差价场景
## 四、<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">（收银台服务场景）已购套餐</font><font style="color:#DF2A3F;background-color:rgba(0, 0, 0, 0);">已消费后</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">补差价升级</font>
### 核心功能
顾客<font style="color:#DF2A3F;">体验过后</font>觉得非常满意，并想补差价升级成更高等级的套餐场景下，系统支持通过补差价的形式升级更高一级的套餐。

### 规则说明
1）币、预存款、弹珠套餐：只能1对1升级，只能升同类型套餐

2）套票：仅支持共享项目的套票，或者不共享仅单项目的套票类型

• 一张单次票：可以升级成一张多次票或者期限票

• 多张单次票：允许多张单次票，升级成一张多次票（不允许升到期限票）

• 一张多次票：可以升级成一张多次票或者期限票

• 多张多次票：可以升级成一张多次票

• 期限票：只能1对1升级，只能升到期限票

3）升级限制：套餐金额：升级的套餐金额不能超过原套餐金额游玩次票：升级的套餐游玩次票不能超过原套餐游玩次票

### 计算公式与示例
![](https://cdn.nlark.com/yuque/0/2026/png/22767468/1786351823075-862adc78-0a98-429a-aae3-853ecd775cbc.png)

**A）普通套票套餐：**

原套餐单次票套餐会员实付100元（套票已使用），升级成10次票套餐200元

+ 升级补差价 = 200 -100 =100元
+ 升级后可用套票数 = 10 - 1 =9次

**B）团购&期限票套餐：**

原抖音团购套餐5天期限票套餐，会员**实付100元**，抖音**分账结算价99元**（首次使用时间2025-10-10），升级成1年票套餐200元（升级时间2025-12-10）

+ 升级补差价 = 新套餐金额 - 团购订单会员实付金额 = 200 -100 =100元
+ 新套票年票有效期：2025-10-10 ~ 2026 -10-10  （新套餐的开始时间与原套餐的首次使用时间保持一致）

### 常见问题
**一、哪些订单能升级？**

1）没有参与过升单活动的订单

2）会员能选择最近60天订单升级，散客只能选择当日订单升级

**二、关于退款**

1）非套票类型的升级套餐订单可以退款，退款金额为订单的实付金额；

2）套票类型的套餐，升级后新旧套餐都不能退单；

**三、关于优惠**

1）原套餐有赠送储值，升级后会在账户后自动扣回赠送储值(不够扣就不扣)；如果升级的套餐进行退单，不会返还原套餐的赠送储值；

2）升级套餐订单，可使用会员折扣、优惠券等优惠；
