说明：建议电脑上操作，图片不清晰可以单击放大查看。

注册小程序认证费用300元，每年都需要年审认证。

主要流程

一、准备资料

二、官网公众号注册

三、完成公众号注册认证后，去备案

# 一、准备资料：

1.法人姓名、手机号2个、身份证号码；

2. 管理员姓名、手机号2个、身份证号码；（如法人为管理员，可忽略）

3. 一个未注册过公众号/小程序的邮箱（如没有，可以到网易邮箱免费申请）；

4. 公司营业执照；

5. 小程序名称、小程序介绍、小程序头像。

提示：

- 如法人为小程序管理员，请准备2个手机号码用于备案；如否，请准备4个手机号码；（用于备案时必填的法人和小程序管理员手机号码+应急备用号码）

- 同一营业执照主体下，同一个人允许为多个小程序备案，可以提交一致的手机号、应急手机号及邮箱；不同主体，则不能使用已备案的手机号重复提交。

# 二、官网小程序注册流程：

百度搜索“微信公众平台” → 进入微信公众平台官网 → 点击立即注册：

公众号平台：https://mp.weixin.qq.com/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2714af9a51d0&type=max)

选择“小程序 ”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2715c04851d1&type=max)

点击“ 前往注册 ”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2716549951d2&type=max)

填写资料后，勾选“ 你已阅读并同意 ”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2718581f51d3&type=max)

点击“前往邮箱”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2719b4b151d4&type=max)

登录邮箱后，进入邮件点击链接激活账号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b271d1c3b51d6&type=max)

激活账号后，自动跳转至此界面，注册地区：中国大陆，主体类型：企业

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19ad88ff3019aee0f2d4c30c0&type=max)

主体信息登记：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e1972303f7ecb&type=max)

管理员信息登记：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2883cc895349&type=max)

信息登记完成后，在小程序首页点击“去认证”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b27973f6a5245&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b279a38fb5247&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b279c158a5249&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b279d84db524b&type=max)

法人认证：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b27a156505250&type=max)

选择是否开票，如选了不开票，后期不可再重新申请

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b27a2606f5251&type=max)

扫码支付300元认证费，每年需要认证一次。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b27a3db375252&type=max)

等待审核，期间会有审核机构致电确认，收到电话后2小时左右，可以登录小程序查看审核结果。如“已认证”，即可进入下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b27a40e6e5253&type=max)

认证通过后，按顺序分别完成小程序信息、小程序类目、小程序备案

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019ff9d73faf0209&type=max)

小程序信息：填写小程序名称、小程序介绍，上传小程序头像即可

（建议填写营业执照完整名称或者截取营业执照上的品牌名称，若填写其他名称涉及商标授权，需提供对应商标授权资料）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874e8515312&type=med)

小程序类目，一定要选：生活服务 - 休闲娱乐！！！（其他不要选）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874e85a5313&type=med)

# 三、小程序备案：

完成小程序信息和小程序类目后，点：去备案

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019ff9dc8cfc0236&type=max)

小程序管理员扫码进入，选择地区和上传营业执照后，会带出营业执照相关信息 点提交。 （如地址提示不通过，复制主体名称到国家企业信用信息公示系统查询 链接：https://www.gsxt.gov.cn/index.html，把查询出来的地址复制到备案页面的地址上 ）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874ea3b5315&type=med)

填写当页信息

①填写营业执照地址

②选择居民身份证并上传

③输入法人手机号接收验证，及填写应急手机号（2个手机号不能重复）

④邮箱（可填公众号的邮箱或其他）

⑤法人扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874ea465316&type=med)

填写当页信息

①服务内容标识，选：休闲娱乐/游乐园、嘉年华

②互联网信息服务前置审批项，选：以上都不涉及

③备注：根据电玩城和儿童乐园选择填写

电玩城 填：游艺厅游戏币套餐售卖或积分兑换。不涉及文化类等前置审批项

儿童乐园 填：儿童乐园淘气堡门票售卖或积分兑换。不涉及文化类等前置审批项

④选择居民身份证，上传 ‘小程序管理员’ 身份证正反面

⑤填写 ‘小程序管理员’ 姓名和证件号

⑥‘小程序管理员’ 手机号和应急号码

⑦ （2个号码）邮箱（可填小程序账号的邮箱或其它）

⑧小程序管理员扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0f28cec52624&type=med)

承诺书会自动带出，点提交

如不能自动带出承诺书，需自行打印盖章，无公章的可签字、按指纹，并在旁边写上‘无公章’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874eb235318&type=med)

拉到最下面勾选同意，提交

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874eb2c5319&type=med)

提交后等待审核，审核时间1~20个工作日。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b2874eb40531a&type=med)

# 四、审核时间：

1. 审核时间为1~20个工作日，期间请留意腾讯的来电确认；

2. 如来电告知审核通过，请留意信管局的短信，点入短信上的链接填写验证码（法人和小程序管理员都会有短信通知），验证码有效期仅1天，请务必当天操作。

# 五、充值快速验证套餐

小程序注册电子会员【腾讯】会收取0.03元/次的快速获取手机号码费用，新小程序有赠送1000次。
‘小程序管理员’ 或 ‘管理成员’ 扫以上二维码后先选择【手机号快速验证组件】，再选择套餐进行充值。
