**说明：注册公众号认证费用300元，复用公众号资料申请的小程序第一年不需要额外支付认证费，后续每年公众号和小程序都需要单独年审认证。

# 一、准备资料：

1. 法人姓名、手机号2个、身份证号码；

2. 管理员姓名、手机号2个、身份证号码；（可以和法人的一致）

3. 一个未注册过公众号/小程序的邮箱（如没有，可以到网易邮箱免费申请）；

4. 公司营业执照；

5. 公众号&小程序名称、小介绍、头像。

# 二、公众号注册流程：

1. 百度搜索“微信公众平台” → 进入微信公众平台官网 → 点击立即注册

官网链接：https://mp.weixin.qq.com/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d899f434e&type=med)

2. 页面跳转到以下界面，选择服务号进行注册资料填写

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019f7d9eb6230c72&type=max)

3. 主体类型，统一选择‘企业’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e6dff4334d5a&type=max)

4. 填写基本信息，填写好邮箱后点击激活邮箱，邮箱会收到验证码，登录邮箱查询验证码并填写，编辑密码后点击“注册”进入下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e70630ef519a&type=max)

5. 账号类型 选：服务号

主体类型 选：企业

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e70654bc519b&type=max)

6. 填写主体信息登记，企业类型根据执照类型选择 ‘企业’ 或 ‘个体工商户’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7067bbc519c&type=max)

7. 填写管理员信息登记

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e707433051b2&type=max)

8. 填公众号信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e708581751c5&type=max)

9. 前往微信公众平台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e708820b51ca&type=max)

10. 申请微信认证

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7090d2251d0&type=max)

11. 开通

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e70a13b851e2&type=max)

12. 开通微信认证，机构类型根据 ‘执照类型’ 选择

企业 选：企业法人

个体 选:个体工商户

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e773da4b5b8f&type=med)

13. 管理员扫码验证身份

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7513dea5667&type=max)

14. 勾选 ‘同意’ 并下一步

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7516c27566a&type=max)

15. 机构类型根据 ‘执照类型’ 选择

企业 选：企业法人

个体 选:个体工商户

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7535391567b&type=max)

16. 填写企业资质信息并上传执照

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e753d8945683&type=max)

17. 行业资质信息

经营行业 选：其他→非特定行业

合规承诺，点击阅读并同意

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7543a125692&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e773da605b90&type=med)

18. 主体验证信息，三选一进行验证，推荐【法人扫脸】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7548dfb56ac&type=max)

19. 填写认证联系人信息（管理员信息）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e754c6dc56b5&type=max)

20. 填写公众号账号名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e75506ae56c2&type=max)

21. 确认信息，并填写是否要发票（注意：发票不能后补，请谨慎选择），如需要发票需填写纳税识别号；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e7555d1e56d5&type=max)

22. 支付认证费用：微信扫码支付300元认证费（每年需向腾讯缴纳300元的认证费用），腾讯认证第三方会给运营者致电（请保持电话畅通）。

公众号认证审核时间一般为１-５个工作日，通过后完成公众号注册。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a0e755856056e3&type=max)

# 三、小程序注册流程：

- 公众号注册通过后，在【广告与服务】-【小程序管理】-点‘开通’

- 选择【快速注册并认证小程序】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b96e5d244327&type=max)

- 勾选-‘快速创建’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b96f5e3b432a&type=max)

- 管理员扫码验证

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b9701e25432c&type=max)

- 全勾选-‘下一个’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b9706bc0432d&type=max)

- 填写邮箱、密码。注意：小程序邮箱不可和公众号同一个，也不可以用之前申请公众号小程序的邮箱，如没有可在163邮箱注册一个

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b971c90a432f&type=max)

- ‘前往邮箱’激活账号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b9723be04330&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97263f24332&type=max)

- 激活后回到公众平台退出公众号登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001966c1ad98c506a&type=max)

选择账号密码登录，重新输入小程序账号密码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b973ee2e4338&type=max)

- 登录后填写小程序管理员信息，会自动带出法人信息，如管理员非法人，可直接修改为管理员信息。如法人为管理员，需把手机号前的‘+86’去掉后才能点发送验证码，还需管理员用填写的手机号微信扫码验证

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b9752dc1433a&type=max)

- 注册成功后，点‘前往首页’填写小程序信息

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b976bfdd4343&type=max)

- 按顺序分别完成小程序信息、小程序类目、小程序备案

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019ff9e1345d02e4&type=med)

- 小程序信息：填写小程序名称、小程序介绍，上传小程序头像即可 （建议填写营业执照完整名称或者截取营业执照上的品牌名称，若填写其他名称涉及商标授权，需提供对应商标授权资料）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d8eda4360&type=med)

小程序类目，一定要选：生活服务 - 休闲娱乐！！！（其他不要选）

-

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d8ee24361&type=med)

# 三、小程序备案：

完成小程序信息和小程序类目后，点：去备案

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019ff9e1347b02e5&type=med)

小程序管理员扫码进入，选择地区和上传营业执照后，会带出营业执照相关信息 点提交。 （如地址提示不通过，复制主体名称到国家企业信用信息公示系统查询 链接：https://www.gsxt.gov.cn/index.html，把查询出来的地址复制到备案页面的地址上 ）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d8fc24363&type=med)

填写当页信息

①填写营业执照地址

②选择居民身份证并上传

③输入法人手机号接收验证，及填写应急手机号（2个手机号不能重复）

④邮箱（可填公众号的邮箱或其他）

⑤法人扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d8fca4364&type=med)

填写当页信息

①服务内容标识，选：休闲娱乐/游乐园、嘉年华

②互联网信息服务前置审批项，选：以上都不涉及

③备注：根据电玩城和儿童乐园选择填写

电玩城 填：游艺厅游戏币套餐售卖或积分兑换。不涉及文化类等前置审批项

儿童乐园 填：儿童乐园淘气堡门票售卖或积分兑换。不涉及文化类等前置审批项

④选择居民身份证，上传 ‘小程序管理员’ 身份证正反面

⑤填写 ‘小程序管理员’ 姓名和证件号

⑥‘小程序管理员’ 手机号和应急号码

⑦ （2个号码）邮箱（可填小程序账号的邮箱或其它）

⑧小程序管理员扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d90de4365&type=med)

承诺书会自动带出，点提交

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d90e64366&type=med)

拉到最下面勾选同意，提交

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d90ee4367&type=med)

提交后等待审核，审核时间1~20个工作日。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700192b97d90f64368&type=med)

# 四、审核时间：

1. 审核时间为1~20个工作日，期间请留意腾讯的来电确认；

2. 如来电告知审核通过，请留意信管局的短信，点入短信上的链接填写验证码（法人和小程序管理员都会有短信通知），验证码有效期仅1天，请务必当天操作。

# 五、充值快速验证套餐：

小程序注册电子会员【腾讯】会收取0.03元/次的快速获取手机号码费用，新小程序有赠送1000次。
‘小程序管理员’ 或 ‘管理成员’ 扫以上二维码后先选择【手机号快速验证组件】，再选择套餐进行充值。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a01a08091455e30a3&type=med)
