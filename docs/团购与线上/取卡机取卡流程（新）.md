# 🤗应用场景
版本要求：

娱乐管家≥ 10.3.7167

游乐宝≥  8.1.6955 

取卡机版本≥  24.0830 



一、一次性取多张副卡

+ 支持取卡机【会员取副卡】时，可以选择同时取多张副卡（最大支持5张）

二、副卡限额；

+ 在兑币机取卡时，如果门店开启了副卡限额功能；则取副卡时，会员可设置副卡额度；

三、团购核销后会员快速取副卡

+ 支持使用团购核销时，如果会员需要可在核销后快速取副卡；

---

# 🧐如何同时取多张副卡？
①取卡机首页点击【取副卡】

②进入取副卡页面时，可通过- +按钮进行调整出卡数量；

③点击确定，等待出卡即可；

# 🧐如何给副卡限额？
:::success
前置条件：门店需开启了副卡限额功能    点击查看【[如何开启副卡限额](https://ychylb.yuque.com/staff-gcg8pk/ylgj/rse0look95zvosnu)】

:::

①取卡机首页点击【取副卡】

②进入取副卡页面时，可通过- +按钮进行调整出卡数量；

③选择副卡额度，点击【确定】开始出卡；

# 🧐团购核销后会员如何快速取卡？
①取卡机首页点击【团购核销】

②点击【会员核销】

③点击【需要取副卡】，选择出卡数；点击确定，取卡机即开始出卡；

# 🧐常见问题
问：如果出多张副卡过程中，客户未及时取卡或者出现异常情况会怎么样呢？

答：客户未及时取副卡的情况下，**取卡机会等待30s**，超时未取卡后会回收副卡并且自动还卡，并退还押金；



问：同时取多张副卡，最大能取多少张？

答：5张



问：什么时候会员才可以配置副卡额度？

答：门店开启副卡额度开关后才可配置



问：副卡额度选项怎么来的？

答：门店自行在后台配置额度，详见 [点击查看【如何开启副卡限额】](https://ychylb.yuque.com/staff-gcg8pk/ylgj/rse0look95zvosnu)



问：选择限额且一次出多张副卡的情况下，对应的副卡额度是多少？

答：当前额度选多少，该过程中出的副卡额度均一致；
