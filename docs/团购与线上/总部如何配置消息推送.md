# 应用场景
当需要使用公众号消息推送功能时，需要按照下面流程进行授权方能使用；这里需要注意授权的公众号必须与申请的小程序主体一致（使用同一营业执照信息开通）才能正常推送，如果公众号与小程序主体不一致是无法授权绑定成功。

# 操作流程
路径：总部后台→会员→消息推送→关联公众号

在【关联公众号】界面中，选择需要设置的门店，在操作一栏选择【关联公众号】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723173465414-f811e2df-4e34-45e0-a0ef-65fa38d9ca74.png)

点击【立即授权】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723173494840-3a165560-6a35-4acf-91bf-3aded92e62df.png)

使用公众号的管理员的微信扫一扫扫码，并按微信上的提示授权绑定公众号，完成绑定。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723173547282-1b6e591c-847e-4cec-a599-222ae5a310fe.png)
