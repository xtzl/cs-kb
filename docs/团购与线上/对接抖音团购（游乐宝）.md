# 1、第三方应用授权

登录抖音来客PC网页--选择【门店管理】--【第三方应用授权】--【新增授权】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fd0ce47ae1ea0&type=max)

选择所属服务商名称【广州油菜花信息科技有限公司】

选择应用【油菜花】

授权行业【到综行业解决方案】

授权范围勾选【门店管理】【团购核销】【团购核销对账】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182aef94b9b1fd4&type=max)

勾选【我已阅读并同意】，同时在弹出【生活服务商家授权技术服务商协议】中勾选【我已仔细阅读上架授权技术服务商协议】，然后点【确定】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182aefb27541fda&type=max)

出现以下界面则代表已经进入等待审核阶段

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0182aefbc7401fdb&type=max)

# 3、绑定抖音商品

绑定门店之后再到线上商品管理那里选择抖音团购，输入【抖音团购券码】（劵码获取请看下一页）点击【搜索】并选择油菜花本地商品，填入相关信息，点击【保存】：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180ad6fc615049d&type=med)

→绑定商品得先下单购买获取优惠劵码

→发布商品，商品【劵码类型】需为抖音劵

5、常见问题

问：

此团购券不可在本店消费，请让消费者打开购买App查看该订单详情页!
答：
1.此团购对应的门店，没有添加油菜花服务商授权，请按照第一步的步骤执行

2.团购套餐没有绑定对应的油菜花核销商品，请按照第三部的步骤执行

问：

抖音来客中指定门店核销记录找不到或者核销门店为空，是什么原因造成？

答：

该情况是由于门店未匹配poi的问题导致。

详细介绍：目前抖音来客下面是可以开多家店的，也有自己的门店id,油菜花系统也有自己的门店id。所以如果有业务需求【商家要求到账到各个分店】，则需要我们这边做个关联，将油菜花系统的门店id与抖音来客的门店id一一对应起来。这一步在变现这边叫做poi匹配。 只有匹配完成的门店，在核销的时候传递抖音来客的门店id，这样就能在来客的核销记录看到分账到各个门店。
