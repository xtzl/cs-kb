# 一、登录微信公众平台

服务号的超级管理员微信扫码登录到公众号，跳转链接https://mp.weixin.qq.com/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975483f70d739c&type=max)

# 二、开通模板消息功能

点击左下角的菜单“新的功能”

- 如果在未开通的页面看到有模板消息代表未开通模板消息，需要点击模板消息的“去开通”按钮，按照引导开通；

- 如果未开通中没有模板消息代表已开通；

- 只有已认证的企业服务号才会有模板消息功能，订阅号没有。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197548cb5d173a9&type=max)

### 申请开通模板消息接口

主营行业选择生活服务休闲娱乐，副营行业可以不填写，填写申请理由

注意：理由中不要体现营销消息，不然后期会被封禁。可以填写例如：用于小程序会员消费时自动接收消费通知和余额通知。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975495aba573b6&type=max)

### 填写资料提交

申请理由和行业选择完毕后，点击【提交】。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001975496feb573b8&type=max)

### 等待审核

等待审核结果(经验：一般当日申请，次日能出审核结果)。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197549fd40973c8&type=max)
