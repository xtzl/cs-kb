# 🔴应用场景
为促进小程序会员注册，派发小程序领取优惠券

# 🔴操作流程


在营销，优惠券，新建一个优惠券，在底部小程序领券选择小程序可领取优惠券，设置可领取时间

设置派发优惠券份数，单个会员账号只能扫码领取一次

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772174975825-74f0de44-1b07-4785-8720-c4378208e27d.png)



点击小程序，在营销活动中点击小程序路径，导出小程序领券二维码

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772175504192-7b6b2b18-4d86-48f4-8ec8-cc7318d979c0.png)



点击优惠券路径，点击二维码，点击下载导出优惠券二维码

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772175722442-086bc3ae-1246-40b7-a702-88431ef808f8.png)



小程序会员注册后扫码领券界面

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1772175840580-09f41dc8-8f22-49da-afa7-c34631b2b8dd.jpeg)
