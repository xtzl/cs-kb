# ![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1777530089115-4ca7a9fc-c986-494e-b7e0-d78fb5d4ef56.png)场景说明：
针对部分儿童乐园场馆可能会存在高危的项目如蹦床项目、跑跑车项目，作为门店运营方，为规范运营管理，落实安全责任，提升风险认知，明确双方责任边界，可发出一份安全协议让顾客签署后再行游玩。

# 功能说明：
娱乐管家系统可为此类活动场景提供安全协议签署与保险功能。顾客需通过小程序扫码签署协议并激活门票方可入场。保险功能需在签署时填写息，费用从门店菜籽余额扣除，支持投保后取消与重新提交。

### 注意事项
1.使用该功能必须开通盈客宝小程序 ；

2.安全协议关联的套票设置必须设置每次激活可用；

3.应用该功能建议配套闸机使用

4.若是涉及人脸核销，需检查系统人脸识别插件是否激活，人脸识别激活时间为周一 09:00到周五 14:00

### 流程步骤：
#### 人脸核销模式：
用户购票 -> 线上签署协议 -> 投保并支付费用 ->录人脸->扫脸过闸

#### 票码核销模式：
用户购票 -> 收银台绑定票码->线上签署协议 (关联票码）-> 投保并支付费用 ->票码核销过闸

#### 路径：
小程序 -->营销活动 --> 安全协议

#### 1.协议内容设置：
说明：顾客在游玩有风险的项目时，建议门店先让顾客签署完协议再行游玩，明确清楚责任，避免客诉纠纷

具体操作设置内容如下：

##### ![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776394872987-09e87c73-df77-4e58-a125-01a434b4d627.png)注意： 若后续需要给顾客投保，签署填写内容必须勾选【姓名】、【身份证】
#### 2.投保设置：
设置说明：门店可提供保险让顾客自行选择是否购买，可凭借该保险作为安全保障。

新娱系统对接俩大保险平台：【太平洋保险】&【亚太险财】 （保费不一样，赔偿也不一样）

门店管理员需充值菜籽（比例1:1），后续通过扣菜籽的方式将保费打到保险公司平台商户（无论是门店支付还是玩家支付）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776396079264-0e09a8ac-eef3-4846-890e-2141c9e6def7.png)

并且保费可设置为由顾客强行支付

 顾客支付保费的情形下，费用还是会到门店商户号上，再由扣除门店对应的菜籽支付给保险平台

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1777529742482-31a3b7f9-5f27-4a1e-b12c-5dfbf6f31462.png)

#### 3.顾客访问窗口设置：
设置说明：设置顾客线上小程序访问路径，方便客人做线上做安全协议签署。

完成该设置，顾客方可进入盈客宝小程序进行线上签署安全协议

设置说明：安全协议会关联该套票设置，此设置为必要设置。

安全协议所关联的套票，在原有设置基础上，需额外检查是否有设置每次激活可用

# 常见问题：
#### 1.如何查询顾客安全协议签署信息?
解决：

在路径：小程序-营销活动-安全协议-签署记录下可以查看会员签署协议内容及打印

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1776397833892-bf76eb21-c2ca-445a-a8d1-2d93792490a7.png)

#### 2.会员安全协议投保是否支持取消，投保失败后需如何处理？
解决：

投保一般在完成投保17分后生效，若投保还未生效，则可在后台退保，

当会员填写的身份证信息等错误，会投保失败，支持重新填写提交投保;

#### 3.当客户场地应用场景是允许人脸进闸后直接感应出闸，后续再凭人脸进闸的情况，套票应如何设置？ 
解决：

套票设置调整：

套票 ->高级设置 -> 验票出闸：勾选【不验票出闸】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1777521182923-9821486e-2606-49df-96b1-6582fc975b26.png)

#### 4.协议投保功能支持哪些身份进行投保？
解决 ：

持有中国居民身份证，持护照或港澳台证件的顾客进行投保，且当儿童不确定自己的身份证信息，也可以通过儿童生日信息进行投保（仅太平洋保险支持，亚太财险不支持）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1777535302282-16410980-9e26-4e07-a755-f204716a2fb7.png)
