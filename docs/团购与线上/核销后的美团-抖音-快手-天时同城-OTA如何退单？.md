# 应用场景
当核销过的线上渠道，顾客因为其他原因需要退货，可按照下述操作进行操作

# 操作流程
路径：收银台→商品→团购核销

#### 在【团购核销】界面中，通过订单号、验证码、手机号等信息进行搜索，找到对应的订单，点击取消核销。
<font style="color:#DF2A3F;">注意：此处只是取消了在油菜花系统的订单，这时候还需要在对应的线上平台中，找到对应的客户订单强制退单才能将钱原路退回。</font>
