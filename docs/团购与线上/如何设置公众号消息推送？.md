# 🔴应用场景
为了提升对离店会员的触达， 同时及时提醒他们相关消费动向， 你可使用“公众号消息推送“功能， 针对目标群体会员发送消息。 

目前油菜花系统中的“消息推送”一共有两种形式， 一种是“手动推送”，例如六一活动快到了，你们店里提前向会员预告相关活动资讯； 另一种是“自动消息推送”，例如会员扣淘气堡门票时， 或会员优惠券即将到期时，自动推送相关提醒。
