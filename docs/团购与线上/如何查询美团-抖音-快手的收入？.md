# 应用场景
如何查询具体时间内美团/抖音/快手渠道总营收

# 操作流程
方法一：

路径：财务--渠道报表--选择具体渠道

**点击财务，在渠道报表中，筛选渠道类别，查询不同渠道对应的总营收**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772099050514-470082a2-7fee-4f67-8932-86227b70612e.png)



方法二：

路径：财务--日结记录

**点击财务，在日结记录中，筛选具体时间，可查询时间段内核销渠道总营收**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1772099137690-db456a72-717a-4404-b8b0-6db8aff9eb41.png)
