# 介绍说明

“抖音来客”是抖音生活服务商家经营平台，商家入驻后可以发布团购商品、绑定抖音账号并通过短视频、直播、线上门店（POI）等渠道将团购商品展现给用户，用户线上购买、线下到店消费，帮助商家达成提升客流，助力经营的效果。

# 入驻流程

## 一、注册登录

可下载抖音来客APP或登录抖音来客PC端（ https://life.douyin.com/p/login ）完成注册登录首页

## ![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/注册登录抖音来客01.png) 二、完成认领门店并提交资质

### 单店商家—认领单店

抖音来客APP端和PC端均可操作

首页点击【入驻抖音门店】-【认领单店】，进入门店搜索页搜索需要认领的门店，并确认门店信息。选择门店后，进入“提交资质”页，按提示上传资质材料及信息，并提交审核。

![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/单店认领门店.png)

### 连锁店商家—认领连锁店

请在抖音来客PC端操作！

![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/连锁店认领1.png)

登录抖音来客PC端（ https://life.douyin.com/p/login ），认领的门店类型选择【连锁店商家】

![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/连锁店认领.png)

选择后按提示上传资质材料及信息，并提交审核。

![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/连锁店认领2.png)

入驻申请提交后，等待审核结果，查看审核详情：
● 申请提交后，1-3个工作日内会反馈审核结果
● 在首页可查看“审核详情” ，审核进度将会通过短信方式进行通知
● 如审核不通过，可以按提示修改信息后再次提交申请
● 审核通过后，门店入驻成功

## ![](http://imgk.pospal.cn/docs/云后台/营销/抖音团购/审核结果.png) 三、绑定收款账户

无收款账户无法创建团购商品，所以商家在完成门店认领且审核通过后，前往绑定收款账户，绑定收款账户后，即可把已核销收入进行结算或提现。 （ 如何绑定收款账户 ）

四、绑定抖音号

平台支持门店或公司绑定其唯一抖音号，即代表该门店或公司主体在抖音平台的官方身份。成功绑定抖音账号，即可获得“蓝V标识”、“内容营销”、“团购推广”等权益。 （ 如何绑定抖音账号？）

## 四、创建管理团购

注意：
1. 认领门店成功且绑定了收款账户的商家可以发布团购商品。
2. 由抖音生活服务业务人员帮忙开通团购的商家，可以联系业务人员协助发布团购商品。
3. 多门店经营的商家，目前仅品牌户账号有创建商品权限，门店账号无创建权限，若需创建，请切换至品牌户账号登录。

（ 如何创建团购商品？ 如何管理团购商品？ ）

## 五、 管理门店信息

线上门店是抖音本地生活 经营的基础，通过“管理门店信息”、“门店装修”、“主页装修”、“管理评价信息”等方式可以让用户更了解你的门店及企业。 而团购商品 更是本地商家 在抖音上经营好生意的前提，发布一款符合自己门店特色又极具性价比的团购商品，会更容易吸引顾客的下单购买哦！（ 如何管理门店信息？ ）
