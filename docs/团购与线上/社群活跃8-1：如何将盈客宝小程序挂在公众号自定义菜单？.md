# 1.使用场景

微信小程序是一个“即用即走”的快捷使用工具，和公众号相对比，虽然流畅性和边界性打打提高，但因为缺少图文消息、模板消息等功能，进而致使对客户留存和反复触达效用大大降低。因此，油菜花在盈客宝推广的过程中，都建议客户结合公众号共同推广，而共同推广的前提就是要把 小程序挂在公众号的自定义菜单 。

进行操作之前，我们要说明一点：将小程序挂在微信公众号是腾讯公众平台的功能，与油菜花系统无关。

前提条件：公众号和小程序必须是统一主体（即同一个营业执照开通的）

# 2.设置流程

（1）流程：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5eb535130b9&type=med)

（2）步骤：

步骤1：关联小程序

路径：微信公众平台->广告与服务->小程序->小程序管理

注意：公众号和小程序主体相同才能关联，一个公众号最多可以关联5个小程序

公众号后台登录地址： https://mp.weixin.qq.com/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5eb539030ba&type=med)

步 骤 2：添加自定义菜单

路 径：微信公众平台->内容与互动->内容工具->自定义菜单

步骤2-1：在公众号后台新增自定义菜单

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5eb53ee30bb&type=med)

步骤2-2：从盈客宝后台复制小程序跳转路径

- 跳转到小程序首页

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5eb565f30bc&type=med)

- 跳转到具体的商品/活动/功能页面 （这里要选择：公众号外部使用）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5eb582430bd&type=med)
