说明：注册公众号认证费用300元，每年都需要年审认证。

主要流程

一、准备资料

二、官网公众号注册（官网链接：https://mp.weixin.qq.com/）

# 一、准备资料：

1.法人姓名、手机号、身份证号码；

2. 管理员姓名、手机号、身份证号码（可以和法人的一致）；

3. 一个未注册过公众号/小程序的邮箱（如没有，可以到网易邮箱免费申请）；

4. 公司营业执照；

5. 两个手机号，用于小程序备案；

# 二、官网公众号注册流程：

1.百度搜索“微信公众平台” → 进入微信公众平台官网 → 点击立即注册：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc904431c7c&type=med)

2.页面跳转到以下界面，选择服务号进行注册资料填写：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc904611c7d&type=med)

3.填写基本信息，填写好邮箱后点击激活邮箱，邮箱会收到验证码，登录邮箱查询验证码并填写，编辑密码后点击“注册”进入下一步：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc904711c7e&type=med)

4.选择类型：选择中国大陆 → 选择服务号 → 选择并继续→确认选择的是“服务号”之后点确定：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc904811c7f&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc904901c80&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc9057d1c81&type=med)

5.进入信息登记页面填写信息：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc9058c1c82&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc906ce1c83&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc906df1c84&type=med)

６.信息填写完进入公众号信息页面，填写好公众号信息后完成注册：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc9071f1c85&type=med)

7.注册完成后，点击微信认证→点击开通→点击开始申请→勾选同意并遵守协议，进入下一步：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc907371c86&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc907581c87&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc907691c88&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc908501c89&type=med)

8.填写企业资料，上传相关文件：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc9086a1c8a&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc909571c8b&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc9099a1c8c&type=med)

9. 确认名称：填写认证的公众号名称：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81480a4846c0180efc909aa1c8d&type=med)

1０.确认信息，并填写是否要发票；需要发票的话选择合适的发票并提供收件人及地址；

1１.支付认证费用：直接微信扫二维码支付300元认证费（每年需向腾讯缴纳300元的认证费用），之后腾讯认证第三方会给运营者账户里转入小额汇款并致电运营者（请保持电话畅通），需运营者将小额汇款截图发送到指定QQ或邮箱内，完成认证。

公众号认证审核时间一般为１-５个工作日，通过后完成公众号注册
