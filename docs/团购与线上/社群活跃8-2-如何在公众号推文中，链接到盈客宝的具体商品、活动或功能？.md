# 1.使用场景

门店针对特定的节日、活动做推文推广的时候，希望在推文中嵌入上皮购买链接或者优惠券领取链接等

# 2.设置流程

（1）流程：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec858830cb&type=med)

（2）步骤：

步骤1：关联小程序（若已经关联，则跳过此步骤）

路径：微信公众平台->广告与服务->小程序->小程序管理

注意：公众号和小程序主体相同才能关联，一个公众号最多可以关联5个小程序

公众号后台登录地址： https://mp.weixin.qq.com/

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec859830cc&type=med)

步 骤 2：添加图文消息

路 径：微信公众平台->内容与互动->创作->图文素材->新的创作

步骤2-1：新建图文消息，在需要跳转处，插入小程序

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec85d630cd&type=med)

步骤2-2： 获得小程序跳转地址

- 跳转到小程序首页

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec876c30ce&type=med)

- 跳转到具体的商品/活动/功能页面（这里要选择：小程序内部i使用）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec894130cf&type=med)

步骤2-3： 展示方式效果展示

- 展示方式-文字，适用于点击可以直接购买的，一般用在文章尾部

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec89be30d0&type=med)

- 展示方式-图片，适用于图片附带产品或活动介绍的，一般用在文章尾部

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec8a8930d1&type=med)

- 展示方式-小程序卡片，适用于推广小程序、或推广特定商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec8ae730d2&type=med)

- 展示方式-小程序码，适用于主推小程序注册的情况，例如：会员上线

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec8c2f30d3&type=med)

步骤2-2：从盈客宝后台复制小程序跳转路径

- 跳转到小程序首页

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec8d7730d4&type=med)

- 跳转到具体的商品/活动/功能页面 （这里要选择：公众号外部使用）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ec8ecf30d5&type=med)

# 3.关键参数

暂无

# 4.客户案例

星趣童堡、奥飞欢乐世界、哇哇哇游乐城、酷客领域等
