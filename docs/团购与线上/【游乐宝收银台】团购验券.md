# 应用场景

用于线上第三方平台购买的商品在游乐宝中核销商品（目前支持：美团 /大众点评、口碑、抖音团购核销）。

# 操作步骤

操作路径：登录游乐宝收银台——商品——团购验券——选择第三方平台——扫描团购验证码——验证——读卡——核销。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240187114bd4ba1d78&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b819c7ccb743f&type=max)

核销成功后，订单中含有套票类型商品可以选择绑定票码或打印套票使用（具体设置在后台设置-【套票设置】-【绑定票码设置】功能中设置）；最多可查看最近两天核销记录（查看更多日期只能到后台【商品订单查询】中查看）

# 注意事项
1、商城后台绑定有美团/大众点评、口碑、票付通、抖音团购的门店信息（后台线上-线上渠道中设置）。

2、需要将本店指定商品绑定到美团/大众点评、口碑、
票付通、抖音团购 线上售卖的商品，在游乐宝核销的商品已绑定本店商品为准（后台线上-线上商品中设置）。

3、计时票不允许设置成核销商品。

4、预存款、游戏币（代币类型）必须有会员才能核销；套票可以存入会员卡，也可以打印套票/绑定票码使用（具体设置在后台设置-【套票设置】-【绑定票码设置】功能中设置）；实物币类型、自动类型游戏币可以直接出实物币（必须连接柜台售币机且绑定柜台售币机仓库有实物币库存）。

5、美团大众、口碑、票付通、抖音团购核销商品价格取本地商品价格。

6、美团大众、口碑、 票付通、抖音团购核销失败，支持再次核销，并且核销失败的订单不展示。

7、核销入会，支持上传会员相片。

8、美团、口碑、 票付通、抖音团购核销可以选择核销数量

①如果绑定的是入会套餐，核销数量不可编辑默认是1；其他商品类型的可修改核销数量；
②核销数量需大于0，小于等于券码可核销数量；
③核销多个后，在同一个订单显示多个数量。

9、渠道核销订单支持退单（此退单操作仅是对业务系统的退单，并没有对美团/口碑/票付通/抖音平台进行退单操作）。
