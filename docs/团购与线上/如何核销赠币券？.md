# 应用场景
场地开业时为吸引人流，只要新人在线上小程序注册会员就会赠送赠币券到会员账户

核销方式有2种：

收银台核销：输入会员手机号或者会员小程序二维码登录，在显示界面储值显示区域，点击优惠券，选择相应赠币券进行核销

兑币机核销：打开会员小程序，在【我的】会员中心-优惠券列表找到赠币券券码，在兑币机界面下栏地点击【赠币券核销】，出示券码进行核销

# 操作流程
#### 收银台核销：
路径：会员→会员资料→优惠券→核销

1.登录收银台，点击【会员】，在会员界面，储值信息栏点击【优惠券】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718790648599-910fef61-b031-43bf-a4eb-c0659576eb12.png)

2.在会员优惠券查询界面，找到赠币券，点击【核销】，进行核销

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718790685080-1f849f5b-bd4b-42cc-a5c3-cf9a2d291e7e.png)

#### 兑币机核销：
操作：

1.打开兑币机右上角齿轮设置，开启兑币机赠币券核销功能

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718790826336-aeef4daf-b63a-41a9-871c-0126bc61786c.png)

2.点击兑币机核销

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718790871581-11bd151c-17c5-4f49-8288-9bda81db0d24.png)

3.在赠币券核销界面，在反扫口出示小程序会员核销券码进行核销

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718791165277-1404bdf4-3316-4ef9-b071-810a0fb79a7f.png)
