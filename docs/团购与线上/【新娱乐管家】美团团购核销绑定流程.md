# 一、新增美团渠道

1、线上→线上渠道管理→新增
2、渠道类别选择美团大众，渠道编号可自定义填写，切换至往来单位填写透支额度（必填项）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce9102024228a&type=max)

透支额度填：9999999

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce912372f2290&type=max)

# 二、美团开店宝授权

1、点击【美团大众】渠道的授权与绑定【未绑定】跳转到美团开店宝界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb28b31e810a9&type=max)

2、账号密码或美团经营宝app扫码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb1696bda0bd5&type=max)

3、勾选 ‘核销管理’ 和 ‘团购核销’，下一步选择门店名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2829a5d0ff9&type=max)

4、油菜花系统显示‘授权成功’，即可进行下一步绑定套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb28472a40ffe&type=max)

# 三、关联美团大众套餐

1、新增一个套餐：游戏币或者套票等，设置成“下架”，可售卖终端设置成不限制。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce91b93f222a9&type=max)

2、选择油菜花系统显示的结算方式：线上→结算价规则设置→美团大众结算价设置，3选1

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb29bc36210ca&type=max)

3、绑定商品：
线上——美团商品绑定——新增
①选择美团商品，适用于普通团购商品

②输入美团商品id，适用于美团直播、 美团通兑、 美团圈圈、 隐藏单等商品
对应美团商品售价 可以不填。填写后支持同一商品id，历史不同的定价核销不同的商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce91bf8df22ad&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce91d9e8f22b3&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce954a9412302&type=med)

# 四、如何核销美团大众套餐

1、收银台：收银员在收银台界面→商品→团购验券→美团大众，输入券码进行核销即可。
2、兑币机：点击兑币机首页屏幕右上角设置进入→功能设置→勾选美团核销，顾客核销时点首页美团核销或者提币→美团核销出示团购券码在机器上反扫即可。
3、小程序：进入小程序我的界面→会员俱乐部→团购核销，输入美团大众券码或者点击扫码兑换扫描二维码核销即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ce954aa222303&type=med)

注意：如果需要限制每个会员的核销次数，可在美团团购核销关联商品里边设置会员限购次数，通过兑币机核销的需进入机器后台设置，开启需要登录注册会员核销后生效

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cec4305002729&type=max)
