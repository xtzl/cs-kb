# 一、新增抖音渠道

路径：门店后台--->线上--->线上渠道管理--->新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918340e55808c6&type=max)

说明：红框为必填项， 渠道类别需要选择抖音团购，切换至往来单位填写透支额度（必填项）

# 二、抖音来客授权

登录抖音来客网页端（
https://life.douyin.coms/p
） ，在店铺管理-服务应用授权-服务商代理下新增授权。

服务商： 广州油菜花信息科技有限公司

选择应用： 油菜花

授权行业： 到综行业解决方案

授权范围：门店管理、团购核销、团购核销对账、商品查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fd0cc3beb1e4c&type=max)

说明：按照要求，添加服务商应用授权后，抖音平台会自动审核，授权通过后，即可进入下一步。

# 三、抖音门店绑定

路径：门店后台--->线上--->线上渠道管理--->配置--->输入抖音来客门店管理那边的抖音门店名称--->点击搜索--->勾选对应门店--->保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001918356869f08f8&type=max)

注意事项，如果输入抖音门店名称搜索不到对应门店信息请检查两个位置
1》抖音来客服务商应用授权那边是否授权都是已经完成状态
2》 抖音门店名称是否和抖音来客门店管理那边的门店名称一致

# 四、抖音套餐绑定

第一步: 门店后台---商品----新增对应的抖音套餐--如果该套餐只用于抖音核销，套餐可以不用上架售卖 （具体请参考系统套餐设置，如果已经有对应的抖音套餐可以跳过）
第二步:门店后台---线上---线上商品管理---新增---渠道选择抖音团购---找到油菜花系统这边对应的套餐，填写渠道结算价，开始时间，结束时间都是必填项，手续费默认为0不需要修改，分组也不用选择

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191836337d50909&type=max)

第三步:门店后台---线上---抖音快手商品绑定---新增--找到对应套餐填写抖音商品的id--保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191836a3f6b0912&type=max)

注意事项：
1》如何获取抖音商品ID ？

抖音来客后台--商品管理--商品发布那边可以复制商品ID

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700191836dd9150924&type=max)

“抖音商品id”：复制抖音商品id填入
“抖音商品售价”：非必填项，填写后支持同一抖音商品id，历史不同的定价核销不同的商品

“会员限购”：非必填项，填写后限制每个会员账户可以核销这个套餐的售卖数量，兑币机需要开启会员登录核销，针对活动套餐，防止顾客核销囤币囤票
注意：抖音来客创建团购商品，券码形式要选“抖音券”

可参照下面视频教程，记得团购商品的券码形式要设成“抖音券”

https://player.bilibili.com/player.html?bvid=BV1xq4y1y74F

# 五、如何核销抖音团购套餐

1、收银台：收银员在收银台界面--->商品--->团购验券--->抖音团购，输入券码进行核销即可。
2、兑币机：点击兑币机首页屏幕右上角设置进入--->功能设置--->勾选抖音核销，顾客核销时点首页抖音团购或者提币--->抖音团购出示团购券码在机器上反扫即可。
3、小程序：进入小程序我的界面--->会员俱乐部--->团购核销，输入抖音团购券码或者点击扫码兑换扫描二维码核销即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019183779835093e&type=max)
