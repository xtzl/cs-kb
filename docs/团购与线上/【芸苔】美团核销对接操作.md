# 应用场景

将第三方渠道美团/大众对接到芸苔系统，便于核销，统一管理门店数据。

# 操作步骤

1.门店先申请好美团/大众账号。

2.进入到芸苔后台--我的--门店管理--选择需绑定美团的门店。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b5c51238c76d1&type=max)

3.点击美团门店绑定的‘未绑定’--搜索美团平台上的门店名称--确认

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b5c641fc676ef&type=max)

4.授权后显示 success 代表授权成功，关掉success界面，再次点击美团美团绑定的‘未绑定’--已经完成--选择门店，显示‘同步信息成功’后，保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b65f8d3657e96&type=max)

5.返回系统首页--游戏币套餐--绑定团购套餐--团购平台选‘美团’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b5c6bb38676fd&type=max)

6.团购套餐选择对应需核销的商品--填写该套餐游戏币数量--系统记账金额

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b5c6e642c76fe&type=max)

7.勾选‘核销终端’，选择核销门店--确认，即可绑定完毕

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b5c7226e47707&type=max)
