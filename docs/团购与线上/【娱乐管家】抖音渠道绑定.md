# 一、新增抖音渠道

1、线上管理-》线上渠道设置-》线上渠道管理-》新增
2、渠道类别选择抖音团购，渠道编号可自定义填写，切换至往来单位填写透支额度（必填项）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c99efe1840e31&type=max)

# 二、抖音来客授权

登录抖音来客网页端（https://life.douyin.coms/p） ，在店铺管理-服务应用授权-服务商代理下新增授权。
服务商： 广州油菜花信息科技有限公司
选择应用： 油菜花
授权行业： 到综行业解决方案
授权范围：门店管理、团购核销、团购核销对账、商品查询

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019fd0cba22e1e37&type=max)

注意：授权完成后可以在抖音渠道-》配置里边开启抖音团购核销功能，并且复制抖音来客-》店铺管理-》门店管理的抖音门店id填写后关联抖音门店

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c99f941d60e57&type=max)

# 三、关联抖音团购套餐

1、新增一个套餐：游戏币或者套票等，设置成“下架”。

2、线上管理-》线上渠道设置-》线上商品管理-》新增

渠道选择抖音团购，搜索新增好的套餐，设置渠道结算价（必填项）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a027ba80e66&type=max)

3、线上管理-》抖音团购对接-》抖音团购商品绑定-》新增

在关联团购核销商品输入
“抖音商品id”：复制抖音商品id填入
“抖音商品售价”：可以不填，填写后支持同一抖音商品id，历史不同的定价核销不同的商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a07925d0e74&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a22791f0ecb&type=med)

注意：抖音来客创建团购商品，券码形式要选“抖音券”

可参照下面视频教程，记得团购商品的券码形式要设成“抖音券”

# 四、如何核销抖音团购套餐

1、收银台：收银员在收银台界面-》商品-》团购验券-》抖音团购，输入券码进行核销即可。
2、兑币机：点击兑币机首页屏幕右上角设置进入-》功能设置-》勾选抖音核销，顾客核销时点首页抖音团购或者提币-》抖音团购出示团购券码在机器上反扫即可。
3、小程序：进入小程序我的界面-》会员俱乐部-》团购核销，输入抖音团购券码或者点击扫码兑换扫描二维码核销即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a1652380e9c&type=max)

注意：如果需要限制每个会员的核销次数，可以在抖音团购核销关联商品里边设置会员限购次数。兑币机需进入机器后台设置，开启需要登录注册会员核销后生效

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a1840000ea6&type=max)

# 五、抖音渠道结算价规则设置

线上管理-》线上渠道设置-》估算价规则设置-》抖音团购订单结算价设置
1、当选择了“取抖音订单结算金额(商家实际收到的金额，已经扣除支付手续费和佣金费用)”时
1.1、系统进行核销的时候，系统订单取抖音订单的订单金额生成本地系统订单。
1.2、券码核销成功1小时后抖音才会有分账结果，分账完成后订单金额会自动更新为抖音订单结算金额。
1.3、在分账未完成之前，当前账期无法做实(券码核销之后1小时左右，抖音更新了结算金额才可以做实)。
2、当选择了“渠道定价金额”时，取商品渠道定价中的“渠道结算价”
