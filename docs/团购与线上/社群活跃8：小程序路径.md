# 1.使用场景

（1）将盈客宝小程序挂在公众号自定义菜单时，需要跳转到盈客宝指定功能、商品或活动页面时

（2）公众号推文中，需要嵌入盈客宝指定功能、商品或活动页面时

（3）盈客宝弹窗广告、首页广告轮播图、支付结果页需要跳转到指定功能、商品、活动和页面时

（4）消息推送，推送模板消息时，需要插入盈客宝对应的功能、商品、活动时

# 2.设置流程

（1）路径：线上->盈客宝管理->营销->小程序路径

（2）用途：小程序路径分为“小程序内部使用”和“公众号外部使用”两种，复制地址的时候复制错了，将无法跳转。

- 公众号外部路径：将盈客宝挂在公众号自定义菜单时，需要跳转到对应页面时间，用此链接

- 小程序内部路径：除上述外，其他所有的跳转，一般都是直接使用小程序内部路径。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aa5ea3ffd30b1&type=med)

（3）路径产生：

- 商品路径：商品在盈客宝上发布【https://www.yuque.com/docs/share/f8cd60fb-271b-47a8-b651-8f6c77a9664d?# 《如何在盈客宝商城上架币套餐/门票等虚拟商品？》】之后，即会自动产生商品路径

- 优惠券路径：优惠券在盈客宝上发布【https://www.yuque.com/docs/share/8540749a-84b4-4026-875f-47557300cf4f?# 《社群活跃8：领券中心》】之后，即会自动产生优惠券路径

- 红包路径：红包活动在盈客宝上发布【https://www.yuque.com/docs/share/7601333a-5eff-4d30-b868-75c6b4833597?# 《获客引流2：游戏币红包》】之后，即会自动产生红包路径

- 活动预约路径：活动预约在盈客宝上发布【https://www.yuque.com/docs/share/be520acb-011e-4f50-91b9-2910c36a909e?# 《社群活跃6：活动预约》】之后，即会自动产生红包路径

暂无

星趣童堡、奥飞欢乐世界、哇哇哇游乐城、酷客领域等
