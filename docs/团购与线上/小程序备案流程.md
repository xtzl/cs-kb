# 一、准备资料：

- 营业执照照片、法人身份证正反面照片、小程序管理员身份证正反面照片；

- 法人为小程序管理员的情况下，准备2个手机号码；如法人不是小程序管理员，准备4个手机号码（用于备案时必填的法人和小程序管理员手机号码+应急备用号码）

- 2个邮箱（可以用公众号、小程序账号的邮箱）

提示：

- 同一营业执照主体下，同一个人允许为多个小程序备案，可以提交一致的手机号、应急手机号及邮箱；不同主体，则不能使用已备案的手机号重复提交。

# 二、备案操作：

- 登录微信小程序后台，扫码后在手机上选择对应的小程序进行登录。（不要选错公众号登录哦）

登录链接：https://mp.weixin.qq.com/（可百度搜索“微信公众平台” → 进入微信公众平台官网）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05beb6b41b81&type=max)

- 进入小程序 首页 左侧工具栏最下方的 ' 设置 ’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05c6e6e31b86&type=max)

- 点击 ‘ 去备案 ’

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05cb3a9a1b8c&type=max)

- 小程序管理员扫码

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05cd49871b8f&type=max)

选择地区和上传营业执照后，会带出营业执照相关信息 点提交。 （如地址提示不通过，复制主体名称到国家企业信用信息公示系统查询 链接：https://www.gsxt.gov.cn/index.html，把查询出来的地址复制到备案页面的地址上 ）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05fd40c51bc6&type=med)

填写当页信息

①填写营业执照地址

②选择居民身份证并上传

③输入法人手机号接收验证，及填写应急手机号（2个手机号不能重复）

④邮箱（可填公众号的邮箱或其他）

⑤法人扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05fd40d11bc7&type=med)

填写当页信息

①服务内容标识，选：休闲娱乐/游乐园、嘉年华

②互联网信息服务前置审批项，选：以上都不涉及

③备注：根据电玩城和儿童乐园选择填写

电玩城 填：游艺厅游戏币套餐售卖或积分兑换。不涉及文化类等前置审批项

儿童乐园 填：儿童乐园淘气堡门票售卖或积分兑换。不涉及文化类等前置审批项

④选择居民身份证，上传 ‘小程序管理员’ 身份证正反面

⑤填写 ‘小程序管理员’ 姓名和证件号

⑥‘小程序管理员’ 手机号和应急号码

⑦ （2个号码）邮箱（可填小程序账号的邮箱或其它）

⑧小程序管理员扫码认证，需扫脸认证（认证需要找背景白色且无杂物的地方）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0f263adc261e&type=max)

承诺书会自动带出，点提交

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05fd40db1bc8&type=med)

拉到最下面勾选同意，提交

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05fd41ef1bc9&type=med)

提交后等待审核，审核时间1~20个工作日。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c05fd41fc1bca&type=med)

# 三、审核时间：

1. 审核时间为1~20个工作日，期间请留意腾讯的来电确认；

2. 如来电告知审核通过，请留意信管局的短信，点入短信上的链接填写验证码（法人和小程序管理员都会有短信通知），验证码有效期仅1天，请务必当天操作。
