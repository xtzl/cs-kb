# 一、新增美团渠道

1、线上管理-》线上渠道设置-》线上渠道管理-》新增
2、渠道类别选择美团大众，渠道编号可自定义填写，切换至往来单位填写透支额度（必填项）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a26e6220f00&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a274d7a0f03&type=max)

# 二、美团开店宝授权

在美团大众渠道，操作一栏点击授权按钮跳转到美团开店宝界面扫码登陆授权，授权成功后会显示success的界面，代表已经授权成功，关闭界面后点击绑定门店，选择对应门店绑定即可。

# 三、关联美团大众套餐

1、新增一个套餐：游戏币或者套票等，设置成“下架”，可售卖终端设置成不限制。

2、线上管理-》线上渠道设置-》线上商品管理-》新增

渠道选择美团大众，搜索新增好的套餐，设置渠道结算价（必填项）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a300dd40f1f&type=max)

3、
线上管理-》美团大众对接-》美团大众商品绑定-》新增
在关联团购核销商品输入
“美团商品id”：①选择美团上架商品、②手动输入美团商品id（适用：美团通兑品或已下架的团购）
“美团商品售价”：可以不填，填写后支持同一商品id，历史不同的定价核销不同的商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a32037a0f23&type=max)

# 四、如何核销美团大众套餐

1、收银台：收银员在收银台界面-》商品-》团购验券-》美团大众，输入券码进行核销即可。
2、兑币机：点击兑币机首页屏幕右上角设置进入-》功能设置-》勾选美团核销，顾客核销时点首页美团核销或者提币-》美团核销出示团购券码在机器上反扫即可。
3、小程序：进入小程序我的界面-》会员俱乐部-》团购核销，输入美团大众券码或者点击扫码兑换扫描二维码核销即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a4090360f66&type=med)

注意：如果需要限制每个会员的核销次数，可以在美团团购核销关联商品里边设置会员限购次数。兑币机需进入机器后台设置，开启需要登录注册会员核销后生效

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018c9a3ad3e10f46&type=max)

# 五、美团渠道结算价规则设置

线上管理-》线上渠道设置-》结算价规则设置-》美团大众结算价设置
1、当选择了“取美团大众订单金额”时，默认取美团大众订单的订单金额
2、当选择了“渠道定价金额”时，取商品渠道定价中的“渠道结算价”
