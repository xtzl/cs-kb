# 应用场景
绑定渠道商品时，如果想对此商品针对每个会员限购核销，该如何设置？

# 操作流程
路径：线上-抖音快手商品绑定/美团商品绑定

**1.进入后台-点击线上，选择抖音快手商品绑定/美团商品绑定，找到想要限购的商品，点击右侧的修改按钮**
