# 问题描述

客户有大额本地推投流、常态化直播，想分账号测套餐、测素材、分时直播，放大流量，又或者想分开做口碑：主账号做高端品牌，子账号做引流低价套餐等原因，开创了多个抖音来客账户，想要在同一套娱乐管家系统实现核销，需如何操作？

# 解决方案

系统版本要求：10.4.2088

根据文档完成抖音来客系统授权：点击此处进行查看

### 系统操作

#### 1.点击指定路径，点击【配置】，进入配置界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fc73bc715da&type=max)

#### 2.在弹窗配置界面，点击【新增】，输入需要关联的抖音来客门店ID， 关联并保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fc7e61715e0&type=max)

#### 3.在抖音商品绑定界面关联系统核销商品，选中关联的抖音来客门店

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fc8d0d115e8&type=max)

#### 4.完成抖音来客门店跟系统套餐绑定后，进行核销测试，测试之后可在后台查询相关数据

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019e0fce4a9c160d&type=max)
