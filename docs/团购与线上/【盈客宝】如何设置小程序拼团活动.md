# 1、功能路径
游乐宝拼团功能路径：线上——盈客宝管理——营销活动——拼团

娱乐管家拼团功能路径：线上管理——盈客宝小程序——小程序功能设置——营销活动——拼团

# 2、功能设置

步骤1：设置活动名称和生效日期，设置活动重要参数

（1）成团人数：必须要达到成团人数，拼团才算成功。

（2）拼团有效期：发起拼团后，必须在有效期内达到拼团人数，否则拼团无效。

（3）免拼成团：开启免拼成团后，拼团有效期内人数未满的团，系统将默认拼团成立。只需要对已付款参团的买家发货。建议合理开启，以提高成团率。

（4）拼团预热：开启后，商品详情页展示未开始的拼团活动，但活动开始前会员无法拼团购买。

（5）每人开团次数：限制每人开团次数。

（6）每人参团次数：限制每人参团次数。

# 4、注意事项

注意：

1、拼团活动如果没有开启免拼成团，那么到拼团有效期结束还没有成团的订单将会在拼团活动结束后自动退款，记得在微信商户号预留余额给这些没有拼团成功的顾客退款。
2、拼团成功后如果需要退单，可以直接在收银台搜索对应订单操作退单（多人拼团活动拼团成功后可以在收银台只给其中一个会员的拼团订单退单）。
