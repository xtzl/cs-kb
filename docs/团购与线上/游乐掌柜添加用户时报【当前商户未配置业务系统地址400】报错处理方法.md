# 情况说明

使用手机报表时，需要开通游乐掌柜功能，当绑定游乐掌柜时，报【当前商户未配置业务系统地址400】报错，需要点一下开通小程序才能解决。

报错截图如下：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c70d22521738&type=max)

# 解决方法

1.提交小程序开通申请

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195eb94ed474614&type=max)

2.提交时填入正确的VPN地址或者域名地址（与开通小程序流程一致）等待开通后再试试。

3.如果提交后依然报同样的错误，提交门店编码给到客服添加一下地址，如下图所示

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195eb96b71d461f&type=max)
