# 应用场景
门店希望在美团抖音等线上平台售卖计时类产品，如2小时票等，超时部分按一定规则进行收费。同时希望游客在进闸前需要支付一定的押金，且押金用于支付超时部分的费用。并且在离场时实现自动原路退款功能。



# 版本依赖
10.4.3152及以上版本



# 不适用场景
1.仅计次不计时场景

2.仅支持现金支付押金场景，不支持储值支付押金场景

3.不支持没有小程序的使用场景



# 流程说明
入场：顾客购买门票（线上/线下）→生成腕带/存到会员账号中→用微信小程序的【签署安全协议】界面扫码激活→同意安全协议后支付押金→激活腕带/电子门票→凭票进场

离场：顾客游玩结束后→通过闸机扫码出闸→系统自动发起退款→押金扣除超时费用后自动原路退回



# 设置要点
##### 第一步：需要将打印二维码内容设置为小程序链接+票码
路径：设置→系统设置→套票打印设置→二维码内容设置

<font style="color:#DF2A3F;">注意：无论是通过打印二维码的方式生成的实体票还是通过现有的腕带二维码进行绑定关联，都需要设置此内容。</font>

##### 第三步：在设置计次计时票时，需要设置以下内容
1. 设置为【激活可用】，可设置为首次激活（一张票只需要激活签署一次）或者每次激活（一张多次票每次游玩都需要激活签署）

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1783070703415-16d50377-2d8c-4143-8e37-811634afe86c.png)

2. 限时游玩设置为【超时补费】

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1783070740905-7a0c55b6-6d8f-4131-b9c0-088b98ef3281.png)

3. 超时结算勾选【现金支付】和【出闸自动退余额】

<font style="color:#DF2A3F;">注意：如果有存在允许离场时间的情况下，【出闸自动退余额】功能不可以打开，否则会导致允许离场功能失效。不开启的情况下，顾客也可以通过小程序上的退押金功能自助来退。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1783070778632-fea18127-6543-439a-9786-8946da2ed914.png)

4. 超时计费设置对应的【封顶金额】，也就是需要付多少押金

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1783070992855-5f97e88d-0f46-475c-859d-d7dd033cd9e6.png)
