# 第一步.首先需要注册一个公众号

## 1、准备资料

1.1 法人姓名、手机号、身份证号码；

1.2 管理员姓名、手机号、身份证号码（可以和法人的一致）；

1.3 两个未注册过公众号的邮箱（如没有，可以到网易邮箱免费申请），一个用来申请公众号、一个用来申请小程序；

1.4 公司营业执照；

1.5 开户许可证（个体工商户不用）；

1.6公章。

注意事项：公众号审核通过时间一般为2-3天

# 第二步、复用公众号快速注册小程序。

1、登陆公众号，进入公众号管理后台首页

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d08e5adc725f0&type=med)

# 常见问题解答

1.能不能直接注册小程序？

答：可以，但不建议，注册小程序需要300元认证费，如果直接注册小程序后再注册公众号时，公众号无法复用小程序注册资料，只能再次交认证费后才能注册。而注册公众号后再注册小程序则能直接复用公众号即可完成注册小程序，无需再次交认证费。

2.服务类目错了怎么办？

答：一个月可修改一次，如果本月已经修改过则无法修改等待下月才能修改，务必要注意。
