# 设置步骤

娱乐管家后台 > 营销 > 优惠券 > 新增代金券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754da1ea77440&type=max)

# 填写代金券详细信息

1.填写代金券的详细信息，带*号的为必填项

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754da1e86743e&type=max)

2.小程序领券设置为可领取，设置券可在小程序上领取的时间范围及张数，确定无误后保存并审核通过此优惠券方案

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754da1e71743d&type=max)

3.在上一步设置完小程序领券，就可以在【线上优惠券】最下面看到这个优惠券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754da1e99743f&type=max)

# 领券步骤

### 方法1小程序首页领券中心跳转领取

在小程序装修，首页里的副功能区设置【领券中心】路径，在小程序首页就可以看到领券中心点进去领券了

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754dfc15b7448&type=max)

### 方法2导出二维码会员扫码领取

导出小程序路径的优惠券路径这个优惠券二维码，顾客扫码就可以进入领券中心页面，领取优惠券

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754f1637e7470&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754f323717477&type=max)
