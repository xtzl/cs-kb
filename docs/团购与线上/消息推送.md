# 一、功能概述

消息推送功能集公众号推送营销信息跟自动推送消息给会员，从而带动会员的活跃性，增加门店收入，提醒会员及时消费

# 二、应用场景

为了提升对离店会员的触达，同时及时提醒他们相关消费动向，可以使用“公众号消息推送“功能，针对目标群体会员发送消息。

目前油菜花系统中的“消息推送”一共有两种形式，一种是“手动推送”，例如门店活动快到了，需要提前向会员预告相关活动资讯；另一种是“自动消息推送”，例如会员扣淘气堡门票时，或会员优惠券即将到期时，自动推送相关提醒。

###

# 三、功能操作指南

## 路径：连锁门店：总部后台→会员→消息推送

## 单店：门店后台→会员→消息推送

1、关联公众号：

在【关联公众号】界面中，选择需要设置的门店，在操作一栏选择【关联公众号】--使用公众号的管理员的微信扫一扫扫码，并按微信上的提示授权绑定公众号，完成绑定。

注意事项：授权的公众号必须与申请的小程序主体一致（使用同一营业执照信息开通）才能正常推送，如果公众号与小程序主体不一致是无法授权绑定成功。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01993657677e0e5e&type=max)

2、营销消息推送：

在消息推送页面，选择【营销消息推送】--底部新增按钮，选择推送人群，填写推送内容，推送时间等，填写完成后，可以先测试推送，测试正常后，再保存等待系统自动推送。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01993659cd370e68&type=max)

3、自动消息推送：

在消息推送页面，选择【自动消息推送】，按门店的实际情况勾选需要推送的提醒。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb0199365ab8eb0e70&type=max)
