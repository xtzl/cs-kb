# 一、作业说明

安装服务器后，需要给客户开通小程序并且协助客户进行发布，此文档用于指引如何协助客户开通小程序及发布小程序。

# 二、作业准备

1.小程序已经申请完毕

2.服务器已经安装完毕

3.（本地服务器）服务器能正常访问外网

4.（本地服务器）小程序VPN已经配置完成

# 三、注意事项

通常我们所说的小程序开通是指客户需要在微信小程序官方网站申请开通使用小程序的资格，申请流程可参考《 01-11-02小程序申请流程（未有公众号） 》《 01-11-03小程序申请流程（已有公众号） 》教程协助客户申请小程序。

# 四、作业标准

小程序发布成功并且能正常投入使用。

# 五、作业步骤

1.登录油菜花系统后台，进入【小程序】，点击【小程序授权】，然后点击【去开通】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b99f98717f84&type=max)

2.协助客户在此界面提交相关信息。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9a085147f87&type=max)

3.点击下一步后，有可能会提示填写VPN地址及端口

特别说明：此部分根据VPN信息不一样，可能会有不同的情况

如果是2025年4月以后的门店，使用的是新VPN信息，则统一使用域名地址链接。此域名地址仅用于小程序链接使用，外网是无法访问的（如果开通云互联除外）。

如果是2025年4月以前的门店，且使用的是旧VPN信息，则按照原来的流程不变。

## 新VPN的小程序配置方法

（本地服务器）填写 本地服务器的域名地址，一般为：门店编码.hub信息.youcaihua.net；端口为88

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000196d21340fe4899&type=max)

云服务器，与原来一样，填写域名地址

例如：

#### 本地服务器：

假如编码为12345678，分配的hub为 v001，填写域名则为：12345678.v001.youcaihua.net，端口为88

#### 云服务器：

假如编码为12345678，所属集群服务器是1号服务器，则填写域名为：12345678.yun1.youcaihua.net，端口为88

技巧说明：

如果不知道域名是否有配置，配置什么，可以通过后台-【设置】-【中台配置信息】中查看，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000196d21b04f248c9&type=max)

## 旧VPN的小程序配置方法

#### 情况一：本地服务器

（本地服务器）如果提示需要填写VPN地址及端口，请输入本地服务器小程序VPN地址及端口，一般为10.**.**.**，端口默认为9999；假如提示VPN不通，请检查是否防火墙是否禁用的该端口，如果是请添加入站规则。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9732d0f7e49&type=med)

#### 情况二：云服务器

（云服务器）如果提示需要填写VPN地址及端口，请输入云服务器域名地址以及端口，一般为y********(加密狗编码).yun.youcaihua.net，端口为88

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9732e227e4a&type=med)

4.填写完毕后，点击确定提交申请成功，如下图所示：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b903b87e7cad&type=max)

3.再次点击【小程序授权】，则会直接到授权界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9a371347f90&type=max)

6.通过小程序管理员的微信扫一扫，扫二维码进行授权，完成小程序绑定。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9a433a27f96&type=med)

7.授权完毕后，告知销售助理走审批流程，等待腾讯官方审核完毕后，即可

8.发布成功后，再次点开开通盈客宝，相关内容是否已经显示在上面即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700193b9a433ab7f97&type=med)

# 六、常见问题

1.客户收到小程序发布失败怎么办？

答：原因有几个，一般为小程序未上架商品、小程序类目没选择正确类目等原因。

2.客户原来有其他小程序，授权后提示失败。

答：有可能此小程序已用于其他模板，无法重复使用，需要重新复用资料再次申请新的小程序使用。

3.小程序发布成功但无法支付

答：小程序商户支付未绑定或者未走白名单流程，又或者商户支付所绑定的公众号与小程序未关联，又或者所关联的商户支付和小程序主体不一致等原因。建议由销售端进行处理。

4.客户已经开通的标准版小程序，需要改成电玩版需要怎么切换？

答：由销售提流程切换，一般需要1~3天工作日。

5.如果有多个门店，能公用一个小程序吗？

答：可以
