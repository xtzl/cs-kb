# 一. 文档说明

本文档主要说明给客户远程培训时，需要使用企业微信直播功能给客户培训的具体流程

# 二. 直播开启具体流程

1.在企业微信-工作台中，打开直播

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c7341c761fa3&type=max)

2.选择预约直播或立即直播

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c73b824a2155&type=max)

3.输入直播主题（即培训门店名称），取消开始直播回放勾选，点开始直播会进入直播界面

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c73c0931216f&type=max)

4.点击分享直播，将直播链接分享至客户群中

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c73d2e3221b1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c73df96421e0&type=max)

5.点击屏幕演示，选择桌面，点击确定共享电脑屏幕

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c7418ffa22b1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c74217dd22d1&type=max)

6. 客户进入直播之后，需点击右下角的申请发言，直播人员同意之后才可以进行发言沟通

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c74b1e0324ca&type=max)

# 三. 直播常见问题

问题1：客户进入直播之后，右下角没有申请发言的按钮

解决：创建直播时，在更多直播设置中取消了允许观众视频发言。需重新创建直播

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c7560dca2712&type=max)

问题2：直播时切换软件，直播会黑屏

解决：屏幕演示选择时，没有选择桌面。导致切换其他的软件或界面会导致黑屏情况

问题3：直播开启之后没有分享直播，怎么二次分享给客户进入直播

解决：在直播顶部，点击分享直播可以二次分享

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c75cfcea289c&type=max)

问题4：预约直播在哪里可以查询

解决：在企业微信工作中，直播里面可以查询到预约的直播

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c75f3924291f&type=max)

点击预约的直播，可以提前开启直播

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195c7608284296d&type=max)
