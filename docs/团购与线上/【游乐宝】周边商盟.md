# 周边商盟，需要满足以下条件：
1，业务系统已开通【盈客宝】功能业务；

# 周边商盟设置

## 1，如何添加合作商家
操作路径：线上》线上兑换》商盟管理

创建合作商家名称和编辑商家资料

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfafdba250e4b&type=max)

## 2，如何设置兑换比例
操作路径：线上》线上兑换》兑换设置》周边商盟

周边商盟，可兑换的储值有三种，分别是彩票，积分，娃娃，只能选择其中一种进行兑换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfafde32a0e4d&type=max)

## 3，如何查询合作商家的交易订单
操作路径：线上》线上兑换》订单管理》周边商盟

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfafe0a5f0e4f&type=max)

## 4，合作商家如何线下结款
操作路径：线上》线上兑换》商盟结款

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfafe30eb0e50&type=max)

## 5，导出合作商家兑换二维码
操作路径：线上》线上兑换》商盟管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfafe645d0e51&type=max)

## 6，顾客如何兑换

1）顾客通过门店小程序界面点击周边商盟进行选择门店进行消费兑换。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfc7397c311ce&type=max)

2）通过兑换二维码进行兑换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfc75295711d0&type=max)

## 7，合作商家如何创建账号
1）设置合作商家账号

设置》员工管理》用户管理

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c148208302fea&type=max)

游乐掌柜路径：设置》游乐掌柜

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfaff0c550e55&type=max)

2）合作商家通过扫二维码进入到游乐掌柜

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfaff39cc0e56&type=max)

3）合作商家添加店员账号，与编辑门店资料
