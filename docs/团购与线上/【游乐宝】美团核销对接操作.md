# 应用场景

将第三方渠道美团/大众对接到游乐宝系统，便于核销，统一管理门店数据。

# 操作步骤

1、门店先申请好美团/大众账号。

2、进入到游乐宝后台，线上→线上渠道→美团/大众点评→配置→去授权

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2ccdc431152&type=max)

3、账号密码或美团经营宝app扫码登录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2d5a4c51166&type=med)

4、勾选 ‘核销管理’ 和 ‘团购核销’，下一步选择门店名称

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2d5a4d21167&type=med)

5、油菜花系统显示‘授权成功’，即可进行下一步绑定套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2d5a4e01168&type=med)

6、游乐宝系统后台--商品--管理商品资料--新增--游戏币

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b3d5a7b835f02&type=max)

设置套餐：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b41dbb9ab6241&type=max)

7、选择油菜花系统显示的结算方式：线上→结算价规则设置→美团大众结算价设置

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19be34de7019cb2d4d0b21164&type=max)

8、美团账号绑定成功且设置好对应套餐后，到线上--线上商品--美团大众绑定对应的商品即可。

①选择美团商品，适用于普通团购商品

②输入美团商品id，适用于美团直播、 美团通兑、 美团圈圈、 隐藏单等商品
指定美团商品售价 可以不填。填写后支持同一商品id，历史不同的定价核销不同的商品

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018b236b26d25062&type=max)

# 注意事项

1.如核销套餐允许散客购买，游乐宝系统设置套餐时，售币类型要选‘自动’，‘代币’是只能核销到会员账户里。

2.如该售卖套餐只能通过团购才能核销，不能直接在线下购买，把商品设置为‘下架’状态即可。

3.如需在游乐宝系统后台统计团购套餐的销售额，结算价按美团售价填写即可。
