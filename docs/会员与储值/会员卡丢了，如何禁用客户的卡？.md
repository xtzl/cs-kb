# 应用场景
客户实体会员卡丢失了，没有时间来门店补办实体卡，如何避免其他人捡到实体会员卡到门店消费

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-登录会员-编辑资料旁的下拉列表-启用/禁用

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击启用/禁用
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592701199-9012ec7f-65f0-4452-9ccc-754101eec903.png?x-oss-process=image%2Fformat%2Cwebp%2Fresize%2Cw_750%2Climit_0)

#### 选择禁用，点击确认，即可将会员卡进行禁用，禁止客户使用，如下图所示：
