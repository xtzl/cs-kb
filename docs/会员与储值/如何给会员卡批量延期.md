# 应用场景

适用于会员卡大批量过期，并且续期会员卡不需要收费，收银台单个延期繁琐，想给会员卡批量延期的商户操作。

# 游乐宝操作步骤

登录游乐宝后台：会员--会员管理--会员批量延期，点击延期按钮操作

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf0d2d0f77ebc&type=max)

# 娱乐管家操作步骤

登录娱乐管家后台：会员管理--会员资料--会员批量延期，点击延期按钮操作
