# 应用场景
客户在丢失实体会员卡之后进行了会员卡禁用，当后续实体会员卡找回后需要进行启动实体会员卡才能正常使用

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-登录会员-编辑资料旁的下拉列表-启用/禁用

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击启用/禁用
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592701199-9012ec7f-65f0-4452-9ccc-754101eec903.png)

#### 选择启用，点击确认，即可将会员卡进行启用，如下图所示：
