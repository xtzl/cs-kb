# 应用场景
给重点会员添加会员标签，收银人员可以通过会员标签辨别重点会员或者特殊会员

# 操作流程
路径：登录娱乐管家收银台-会员-登录会员-新增标签

#### 登录娱乐管家收银台-会员-输入会员手机号/扫描会员二维码-新增标签-选择需要给客户添加的标签，如下图所示：
