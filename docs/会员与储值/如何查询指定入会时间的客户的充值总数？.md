# 应用场景
适用于查询指定入会时间内的会员一共消费多少金额。

# 操作流程
路径：会员**→**会员活跃分析表

填写入会的时间，筛选入会时间进行查询

# 常见问题
1、按到店天数查询无法统计新注册会员数。

2、统计日期，选择本天，可查当天的实时数据。
