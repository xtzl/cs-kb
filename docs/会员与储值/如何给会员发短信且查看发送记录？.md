# 应用场景
适用于门店需要给单个会员或者多个会员发送门店的营销消息等信息，可以使用短信功能通知会员

# 操作流程
路径：会员**→**发送短信

#### 1、短信发送总共以下2总方式：
方法1、根据门店需要条件查询出对应会员，可单个或者批量勾选对应会员进行编辑短信内容发送；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718702925596-cea5334a-477d-4085-b24a-f009adcb7d58.png)

方法2、①可以将查询出来的会员进行批量导入进行发送；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718703408920-bb0db0f1-2a98-4f40-a92a-908c158544d6.png)

②下载对应的模版进行导入；

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718703434990-c91a5b6e-afe3-449a-8ff4-44c5c886f23c.png)

#### 2、发送后可查询历史发送记录，界面可以看出短信是否发送成功
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718703464938-861c7880-2895-4a78-acfb-0066af15c81c.png)

#### 3、如若发现短信发送失败，可以查询出失败的记录，重新进行发送。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718703518884-fedcd321-f8df-4a6e-92f3-ff5a5ec1939d.png)
