# 1、作业说明

本说明为置换系统（其他品牌系统转换成油菜花系统）时，需要将客户原来的会员数据导入到油菜花系统中的作业说明。导入数据会视情况分两个步骤，仅导入会员资料以及会员储值（代币数、彩票数及积分数等储值），和导入会员次卡类或期限卡内数据导入。如需导入次数类（如次卡或者月卡季卡年卡）则需要再执行《游乐宝系统会员计次卡及期限卡数据导入》。

# 2、作业准备

## 1.有office工具电脑一台

## 2.原系统会员数据一份（重要），此内容需要客户自行导出相关数据。

# 3、注意事项

## 1.导入前需要先将数据库进行备份，以免导出错误无法挽救。

# 4、作业标准

1.导入后客户给予的原数据与导入后数据一致。

## 3.将相关的会员信息复制到这个模板中

### 注意事项：

a.会员卡号必须唯一不重复，且不能纯6位数字，不能为空（重要）。

b.手机号可以为空，可以重复，但必须按照11位格式导入。

c.会员级别必填，但必须先在油菜花系统上建立对应的会员级别后再导入（重要）

d.此案例仅为例子，注意复制之前需要和客户确认各个信息对应到油菜花系统是那种储值类型。如上述案例来说：原系统叫“可用币”，则和客户确认后是否与油菜花“代币”含义一致，如一致则复制到代币一栏中。

e.会员密码一般来说无法导出，可批量设置同一个初始密码，如****（已脱敏，请向运维索取），当顾客换卡是再根据情况重新设置新密码。

f.会员生日需要导入时必须安装日期格式填写。

g.会员有效期为必填项，而且为日期格式。

h.押金是无法导入系统，建议客户手工记录。

i.芯片号不用填。

## 4.备份数据库，备份方法请看数据库备份说明

## 5.与客户核查EXCEL表内会员信息是否有误

## 6.填写导入的代币和金币的价值（说明：由于仅导入会员储值数，并没有导入储值对应的价值，所以此位置需要设置对应导入的储值的价值，计算方法为原系统售币总金额/原系统总币数，由客户来提供，如果没有可默认填1。此数值会影响储值平衡表。）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017c6e809e1c0b8a&type=med)

## 7.点击导入会员，等待完成（如果有失败，会提示是否下载失败原因，可根据失败原因对EXCEL表进行调整）

# 6、常见问题

## 1.导入后为什么会员名称方面出现【须换卡】字眼

答：用于区分哪些会员是从旧系统导入，哪些是新开卡

## 2.导入数据后，原卡无法使用

答：由于各个厂商的会员卡都是有独立加密的，所以需要将原来的会员卡回收，然后通过系统中补卡功能给客户重新换卡才能使用，操作方法为：【前台】-【会员】模块-【会员资料】-通过卡号/手机号/会员姓名等信息查询该会员信息-点【补卡/换卡】功能-放新卡到读卡器上-点击【读卡】-点击【换卡】-将新会员卡给客户使用。

## 3.原来的会员是否可以在小程序直接进行绑定？

答：可以，微信对应的手机号与原会员资料的手机号一致即可自动绑定，如果一个手机号名下有多张会员卡，则在小程序中【我的】-设置-切换会员卡中进行切换。

## 4.导入时提示XXXX数据库异常等错误，没有失败原因可下载。

答：一般为导入数据中的生日或者会员有效期格式错误导致

## 5.导入时间很久

答：一般原因为EXCEL表格下方有大量的空白导致，用alt+a复制所有内容再粘贴到新EXCEL一般可以解决

## 6.导入数据太多

答：建议5000条数据到1次。
