# 应用场景
当收银员或服务人员需要修改会员信息时，应该如何修改

# 操作流程
路径：收银前台→会员→会员资料

在【会员资料】中通过读卡或者输入手机号搜索对应的会员信息，并点击编辑资料

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723518293946-5d55f8e8-67a5-47a7-928b-1619b1a591ce.png)

填写需要修改的会员资料，并可支持直接入会员照片，会员照片用于人脸识别使用，点击保存完成修改

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1723518365759-418bbc0e-1c2c-4718-9003-069fae3aef3f.png)
