# 如何锁定账号储值?

1》路径：

1）收银台--会员--账号锁定/解锁
2）收银台--商品--售卖商品--快捷功能栏--账号锁定解锁
2》步骤：点开账号锁定勾选需要锁定的储值类型，然后点击确定，

# 如何取消储值的锁定

1》步骤去掉账号储值的锁定里面对应类型的勾选后点击保存。
