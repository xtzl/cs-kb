# 应用场景
客户忘记了会员卡密码，需要修改会员卡密码

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-修改密码

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击修改密码，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592805143-cc1f052c-f575-4069-a64c-099c88b7c9b8.png)

#### 将验证旧密码取消，输入客户的新密码之后，点击确认，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592876525-e898d3a3-41f4-4eac-845b-62f2dfc54134.png)
