# 常见门票运营场景介绍

## 常见的门票形式

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179aca246773150&type=max)

- 一般来说，对于散客，使用纸质二维码门票或纸质腕带比较常见

- 对于会员顾客，使用RFID会员卡较多，一般都再让顾客绑定微信成为小程序会员，这样顾客在手机上查询到自己的购票信息，剩余次数等，如果到场忘记带卡，也可出示小程序会员码作为核销凭证

- 对于月卡年卡用户，一般都会让客户在购买时录入照片，通过收银台人工比对照片或人脸识别设备来验证会员唯一性，避免顾客将会员卡转借他人使用

## 常见售票方式和渠道

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179acb290253152&type=max)

- 对于使用二维码门票的场地，无论是使用纸质门票还是腕带，我们都更推荐使用“绑定票码”的方式，这样出票速度更快，成本也更低，门店只需要提前让供应商印刷好一批带有二维码的门票或腕带即可；（如果现场打印，首先是出票速度往往跟不上高峰期客流的排队速度，其次，打印机长期使用也容易发生各种故障，同时还有各种打印耗材费用）

- 对于使用RFID芯片卡或腕带的场地，收银台只要配备了“读卡器”即可读写芯片里的会员信息，套餐信息等

- 门店还可通过美团等OTA平台售卖门票，油菜花系统目前已对接了美团，口碑，携程，驴妈妈等主流团购和OTA平台，顾客在这些平台上购票，可直接通过油菜花系统核销（如果没有对接，则员工需要先登录各个OTA平台核销门票，然后再通过油菜花系统出票，流程繁琐，而且核对账目也比较麻烦）

- 通过“自助售票机”和“手持POS机”也可以售卖门票，可以缓解客流高峰期的服务压力，有条件的场地可根据情况配置相应的硬件

## 门票验证方式

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179acfef1db3174&type=max)

- 小型场地可通过收银台验票（收银台一般需要安装扫码枪或读卡器）

- 上图中的“刷卡终端”和“验票/刷卡桩”也是常用的验票硬件，两者的区别是：刷卡终端只适合芯片卡或芯片腕带，而且声光提醒在嘈杂环境下不够明显；验票/刷卡桩不单适合芯片卡或腕带，同时也支持纸质/电子二维码验票，验票时有清晰的语音和灯光提醒，验票成功后会打印小票凭据

- 上图中，“手持POS机”不单是移动的收银台，同时也可作为移动式的验票终端，缓解客流高峰期的验票压力

- 门禁闸机是最常见的门票验票终端，它支持芯片卡，腕带，纸质/电子二维码门票，人脸识别等所有类型门票介质，可最大程度提升验票效率和节省人工（原本每个出入口都需要有人看管，使用闸机后，基本一个人看管就够了）；此外，售卖月卡年卡的场地建议配备人脸识别模块，可以提升场地的管理效率

## 如何实现月卡年卡专人专用？

为避免月卡或年卡用户将会员卡转借他人，场地一般可通过以下方式验证会员唯一性

- 所有购买了月卡和年卡的用户都需要录入照片（收银台电脑需连接USB摄像头）

- 没有采购人脸识别闸机的场地：月卡年卡会员到场后需要到收银台领取腕带，由员工人工比对照片，验证成功后给进场的会员绑定腕带 （点击查看设置教程）

- 已经采购了人脸识别闸机的场地：月卡年卡会员导出后，直接刷脸进闸（可录入多个家庭成员照片，例如录入小孩和爷爷奶奶照片，这样无论是爷爷或奶奶带着小孩过来，都能刷脸进闸）（点击查看设置教程）

## 如何做好场内会员中途离场管理？

小孩子临时需要上厕所或吃饭，中途离场非常常见；为避免中途离场过程中换人进场或漏检票等情况，常见的做法如下：

- 在离场的小孩手臂上盖一个章（要买可以水洗的），重新进场的时候检查这个章就可以了，这种方式虽然简单，但部分家长考虑到卫生问题，并不同意给小孩手上盖章，所以存在一定局限性

- 为进场的每个小孩绑定一个纸质腕带，当天内凭着腕带可多次进场，该腕带一旦撕下立即失效；为进一步加强管理，避免有些小孩隔天还过来玩，场地可设置7种不同颜色腕带，每天使用一种颜色

- 有时候为了控制在场人数，可以限制顾客每次的离场时长，例如离场累计不超过2小时，超时门票自动失效。离场时间主要通过闸机来判定，结合上述方案中提到的腕带，可以更加高效的管理顾客临时进出的情况，也能避免许多管理漏洞 （如果觉得刷手环还不够方便，可以使用闸机上的人脸识别功能）

## 如何避免门票黄牛党？

常见的黄牛卖票，一般有以下两种方式：

- 在门店促销活动的购买了多次数的门票（一般门票次数越多，总价越优惠），再把次数以低于门店的价格售卖给其他人。买家购买后，到收银台刷黄牛的会员卡或报手机号就能获得门票或腕带；这种方式比较难避免黄牛，毕竟黄牛是让买家扮演成“真实的客户”到前台领取腕带或门票的，如果非要进行管控的话，建议在会员信息中增加录入照片环节，非本人到场不可领取腕带或门票

- 一些黄牛购买了月卡或年卡，由于一般的月卡年卡是指定时间内无限次玩的，所以他们就可以比较低的价格卖给其他顾客，然后帮这些顾客刷卡进场。此类的方式比较容易解决，可通过人脸识别辨别唯一性，或限定门票的每天可使用次数

## 如何实现顾客买的门票只能平日或指定时段内使用，要怎么设置？

为了提升门店在闲时的客流量，一般门店会针对平日和节假日采用不同的价格方案，需要系统能根据节假日自动调价，闸机能根据平日和节假日门票自动识别

- 节假日门票自动调价；这方面可以使用油菜花系统的自动调价功能

- 部分平日闲时门票，在门票次数上一般会有优惠，这时候需要在门票中做相应设置

## 门票预售要怎么做？

预售可以帮场地提前锁客，有利于门店引流和快速回本。以下分两种情况介绍门票预售的常见思路。

一，门店服务器电脑已安装了油菜花系统

- 通过“盈客宝”小程序进行预售，顾客扫码即可注册为会员并购买门票，结合分销功能自动统计员工业绩

- 通过“油菜花云POS机”进行预售和地推，POS机相当于移动的收银台，可随时随地进行办卡和售票

- 对于售卖纸质门票的场地，可先通过油菜花系统售票，系统后台自动生成一系列门票二维码，导出这批二维码给到门票打印厂家，让他们将门票二维码印刷到纸质门票上。预售的时候就直接现场给票，顾客拿着纸质票就能直接到场消费

二，门店连服务器都没有，油菜花系统未安装

- 首先确定要售卖的门票套餐，需要先与油菜花相关人员确定这些套餐都可以通过系统实现

- 通过表格登记预售客户的信息，包含：姓名，手机号，所购门票名称，数量，金额和付款方式等

- 后期按照油菜花系统的“会员导入模板”和“套票导入模板”，批量将会员信息和套票信息导入到系统

## 门店下个月才开业，现在开始预售的年卡是从卖出后就开始计算有效期吗？

油菜花系统中有“售出后xx天生效”的设置选项，但预售期一般都持续一段时间，所以设置的有效期建议统一从预售的最后一天开始设置（预售第一天购买的用户可能会因此多得到几天有效期，但一般在可接受范围内）

# 如何按门票核销确认财务收入

一，为什么要按门票核销确认财务收入

售卖出去的门票，如果客户没有来消费，其实相当于场地的“负债”，因为只有客户真正到场了，门店提供了相应的服务，这笔交易才算彻底完成。如果按照门票的核销来确认门店实际收入，就能客观的了解门店的实际运营收入和开支（假设顾客到店耗卡，没购买任何东西，如果只统计门店的员工，租金和水电等开支，那么门店的收入是负数的，而如果把客户耗卡的收入也计算进去，才能真实反映门店的实际财务情况）
