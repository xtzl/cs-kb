1，下载会员套票资料导入模板
操作路径：会员》会员管理》会员资料导入

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfad516b10d54&type=max)

模板导入

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfba7a1a31069&type=max)

注意：导入套票前，游乐宝系统中必须要有该会员，才能进行导入，如果会员资料查询中没有该会员，即导入不了。
2，模板内容填写

会员号：会员的卡号
套票套餐编号：商品》商品管理，套票套餐编号对应的是后台的商品编号。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfad549f10d55&type=max)

计次票：（5次卡，10次卡，20次卡等）
期限票：（月卡，季卡，年卡）
开卡日期：统一填写导入当天时间
剩余次数：按照一下格式填写
计次票：（5次卡，10次卡，20次卡等）剩余5次，即填写5，没有次数的填写0；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfad58b5c0d57&type=max)

期限票：（月卡，季卡，年卡）留空

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018bfad5aaeb0d58&type=max)

截止日期（必填）：格式为2022/5/12
票码（不填写）：
