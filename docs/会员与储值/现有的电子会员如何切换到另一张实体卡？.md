# 第一步

在收银台将两个会员卡的手机号改成同一个手机号

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019754547ec472f9&type=max)

# 第二步

在小程序【我的】页面点击设置>切换会员卡>选择想要切换的卡片绑定。

注意：切换卡片后，储值、套票、优惠券不会合并，是直接切换到那张卡了，如果想要合并储值，请使用收银台【储值过户】功能过户储值
