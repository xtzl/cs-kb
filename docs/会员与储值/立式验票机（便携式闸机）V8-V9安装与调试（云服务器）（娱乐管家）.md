# 一、作业说明

本说明用于安装立式验票机（便携式闸机）V8/V9的安装说明，包括户外版和室内版通用，并包含对接第三方闸机教程。

户外刷卡桩V8/V9 立式验票机V8/V9

# 三、功能支持

1.支持刷储值，扣次数和月卡/年卡等收费模式;
2.支持人脸识别，RFID会员卡/腕带，纸质/电子二维码，会员小程序码，微信支付宝付款码，票付通门票码、美团抖音门店验证核销等多种门票介质;
3.装备8英寸高清显示屏，便于顾客了解项目信息和验票详情;
4.支持人脸识别，避免月卡年卡等“转借他人使用”等管理漏洞;
5.验票后支持打印小票凭证（仅支持立式验票机V8/V9）;

6.支持体温检测（需要额外定制体温功能）；

7.支持直接录入人脸功能；

8.支持防水（仅支持户外刷卡桩V8/V9）

9.支持亲子配对功能；

10.支持语音播报功能；

11.支持计时功能，并支持计时结算；

12.支持手机号直接入场；

13.支持查询会员消费情况；

14.支持加装到第三方闸机进行控制。

# 四、安装准备

1.冲击钻*1、14mm冲击钻钻头*1

2.铁锤*1

3.12mm扳手*1

4.2mm一字螺丝*1

5.记号笔*1

6.十字螺丝刀4mm*1

7.六角螺丝刀*1套

# 五、配件说明

人脸识别面板*1

立式验票桩柱子*1

12mm膨胀螺丝*4（一个主机配4个膨胀螺丝）

电源适配器*1

58mm打印纸*1

34mm开孔器*1

# 六、前期准备

1.安装位置需要预留220V电源

2.安装刷卡位置需要预留网线

# 七、安装要求：

1. 立式验票机V8/V9（户外刷卡桩V8/V9）安装到地面不摇晃；

2. 安装后功能能正常使用（刷卡功能正常、扫码功能正常、屏幕显示正常、打印功能正常）

# 八、注意事项

1.安装前需要确保电源是断电状态

2.安装时需要佩戴手套，以免因五金件锋利导致弄伤手

3.固定立式验票桩底部前，需要提前与现场确定底部是否有电源线管或者供暖水管，以免打膨胀螺丝时将管路打穿。

# 十、测试流程

## 立式验票桩V9/V10、户外刷卡桩V9/V10

1.开机通电，屏幕正常显示对应的项目并无报错；

2.前台录入人脸并购买套票，在设备上直接刷脸后显示通过；

3.使用会员二维码刷码正常入场并扣除次数或正确的储值数，用会员二维码刷码能显示通过；

4.使用会员卡刷卡入场，正常扣正确的储值数或者次数并设备正常显示通过；

5.使用付款码反扫后，能正常验证，并显示通过，对应扣款价格设置正确；

## 便携式闸机

1.开机通电，屏幕正常显示对应的项目并无报错；

3.前台录入人脸并购买套票，在闸机上直接刷脸后正常开闸；

4.使用会员二维码刷码正常入场并扣除次数或正确的储值数，用会员二维码刷码能正常离场；

5.使用会员卡刷卡入场，正常扣正确的储值数或者次数并闸机正常打开，刷卡出场闸门正常打开；

6.使用付款码反扫后，能正常验证，并显示通过，对应扣款价格设置正确；

# 十二、常见问题

1.排队机如何配合闸机使用？

答：闸机本身不需要特别设置，在排队机中绑定相应项目即可，具体教程可查看排队机教程。

2.立式验票桩使用计时票时，如果选择扣基础金额，出闸时是否支持直接付款码支付超时金额直接出场？

答：支持，刷卡后就会提示需要付多少钱，使用付款码直接支付即可。

3.人脸识别的精准度如何调节？

答：后台→设置→系统设置→人脸识别，在此界面中调整

阈值越低，精准度越差，但是识别速度越快

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917d3c71f77c2c&type=med)

4.立式验票桩参数中，下图参数的作用是？

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917d3c71ff7c2d&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917d3c720a7c2e&type=med)

答：强制人脸识别，开启后，无论是否需要人脸的套票，都强制需要录入人脸和匹配人脸才能通过。一般不需要开启。

5.立式验票桩是否支持直接第三方平台直接过闸？

答：仅支持单次票，需要关联系统的单次票才可以。暂不支持多次票。

6.闸机项目是否支持不使用计时票直接按时间扣储值？

答：支持可通过设置项目消费，将扣值模式改成计时模式即可。但注意计时模式下，同一个会员只能入一次。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917d3c72137c2f&type=med)

7.立式验票桩是否可以直接通过付款码付款入闸？

答：支持

8.闸机是否支持游客游玩离场后重新进场不扣费？

答：支持，如果是储值类客户，在游乐项目设置中修改允许离场时间即可；如果是套票按次扣费，则需要在对应的票设置中进行设置允许离场时间。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e7001917d3c73227c30&type=med)
