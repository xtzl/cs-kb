# 如何限制某些会员不能使用某些油菜花设备或者游玩某些游乐项目使用

路径：后台--设置--会员设置--会员级别可用终端设置
步骤：第一步：后台新增一个会员级别，

第二步：设置一下级别可用终端，选择对应的会员级别，去掉所有终端可用的勾选，不想让会员游玩哪些机台或者设备上面使用就去掉对应的勾选后保存即可。
第三步：把需要限制的会员的会员卡级别变更为指定级别
