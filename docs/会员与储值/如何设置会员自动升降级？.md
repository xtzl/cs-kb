# 应用场景
设置各个门店的会员升降级策略，会员根据策略自动升级或降级（只有参与策略的会员级别才会产生成长值），所有产生订单操作只要金额达到升降级策略金额就会产生成长值

# 操作流程
路径：会员→会员运营→会员升降级

#### 1、界面点击添加门店升降级策略；  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719404700113-0f84b2b3-c47d-4efb-a913-bf044cae32e9.png)  

#### 2、设置成长值规则
  
	① 升降级：自动升级/自动升降级  
	② 成长值规则：设置同一个订单每消费满多少元，发放多少成长值

a、若一个订单购买金额小于成长值发放最小值时，将不发放成长值（如每消费10元发放1成长值，若订单金额小于10时，将不发放成长值  
b、只根据同一个订单的消费金额发放成长值，零头将不发放成长值（如每消费10元发放1成长值，订金金额为59时，只发放5个成长值）  
c、会员入会的卡押金金额不用于计算成长值

③ 成长值有效期：永不过期/定时过期  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719405296436-bf84b0d6-d97e-49b7-bddf-fe31323defe5.png)  
注：成长值有效期规则修改后，所有未过期的成长值将按最新的设定执行过期操作如原来是永不过期，修改为逐笔过期（每笔成长值自发放之日起1年后过期）当天营业结束后，将把1年前发放的所有未过期的成长标记为过期

**3、****<font style="color:rgba(0, 0, 0, 0.88);">升降级设置</font>**

开启自动升降级后可以设置保级策略  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719405934914-7dfb8f40-db79-4fff-8d6c-f7cd4bc32055.png?x-oss-process=image%2Fformat%2Cwebp)  
保级策略下，成长值变化规则:  
	① 购买商品：增加相应成长值  
	② 成长值过期：减少相应成长值  
	③ 会员升级：减少级别相应成长值  
	④ 会员保级：减少保级所需成长值  
	⑤ 会员降级：成长值归0  
	⑥ 手动修改会员级别：成长值归0  
详细设置：  
	① 添加对应等级；  
	② 添加升级成长值：会员达到每个级别所需成长值，将自动升级；  
	③ 添加保级成功值：等级有效期到期后，会员成长值-保级成长值，如果≥0则保级成功，同时扣除保		级成长值如果<0则保级失败，降一级别。同时成长值归0；  
	④ 添加升级赠送：1、每个会员每个级别只会赠送一次。2、跳级升级，中间级别奖励也会赠送。  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719406221846-52635650-c7e0-48b5-ad49-9ded949c3df0.png)

# 常见问题
**一、所有会员初始成长值是多少？**  
所有会员初始成长值都为0

**二、什么时候会根据剩余成长值数量重新计算各会员的会员级别？**  
只有获取到成长值或者成长值过期时，才会根据剩余成长值数量重新计算各会员的会员级别

**三、历史会员有会员级别初始化需求应该怎么操作？**  
针对历史会员有会员级别初始化需求时，请通过“增减会员成长值”功能初始指定会员的成长值数量（如把钻石卡会员成长值初始为1000，若不初始化，钻石卡会员首笔交易后会降为普通卡会员）

**四、会员消费后为什么没有马上获得成长值？**  
会员成长值发放及升降级策略在总部计算，会员消费后到发放成长值会有10分钟左右的间隔
