# 应用场景
客户的实体卡消磁了，不能正常使用，如何给客户换卡

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-补/换卡

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击补/换卡，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592983466-2fc1ec89-9f22-496d-ae9d-79141342bc89.png)

#### 将新的实体卡放在读卡器上面，点击读卡，读取到实体卡号码之后，再点击换卡，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593027441-e9fb57d0-5f2c-4751-8949-cd446b5494e9.png)
