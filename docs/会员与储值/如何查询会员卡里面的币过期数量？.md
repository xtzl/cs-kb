# 应用场景
适用于查询会员已过期的游戏币汇总数据以及明细数据。

# 操作流程
<font style="color:#000000;">路径：会员</font>**→**<font style="color:#000000;">会员币批次</font>**→**<font style="color:#000000;">过期币查询</font>

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718705021505-e8a10dc5-57df-4790-8453-1e1accbf050d.png)

# 常见问题
问：可以查看查询出来的日期，过期币合计总数吗？

答：可以，【过期币】查询出来的数据右下角有合计数量显示。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719295868845-c3f24fa1-eb58-4b06-8b9a-66a4592fbfbd.png)

# 关联操作
如何查看过期游戏币的对应批次是否已补币？

在【过期补币】这边找到对应的记录，“是否已补币”这边可以看到是否有进行过过期补币。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719296063304-ff6f6f3e-0ee6-41c6-abf4-1cd23c949fab.png)
