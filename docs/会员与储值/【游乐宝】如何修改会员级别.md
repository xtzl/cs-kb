# 如何修改会员级别

1》路径：
1）收银台--会员--级别变更
2）收银台--商品--售卖商品--快捷功能栏--会员级别变更

2》步骤：点开会员级别变更，选择变更级别，选择需要变更的会员级别

注意：

### 1)是否换卡：

这个是用户会员再更换级别的时候，如果需要把实体会员卡更换到对应级别实体卡的时候使用，勾选后放上一张新的会员卡，系统会把卡号从原卡号更换为对应的会员卡号。如果不需要换卡选择否

### 2)修改有效期：

在会员级别变更时，如需修改会员卡有效期，直接将有效期那一行的时间选择到对应的时间即可
