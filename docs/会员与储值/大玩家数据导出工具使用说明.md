# 文档说明

此说明用于使用爬虫工具将大玩家数据导出EXCEL表，用于置换系统时使用。

# 前期准备

1.下载导出工具

下载链接：https://nos-pulic.oss-cn-shenzhen.aliyuncs.com/%E5%AE%9E%E6%96%BD%E7%BB%84%E5%AE%89%E8%A3%85%E5%B7%A5%E5%85%B7/%E7%89%B9%E6%AE%8A%E5%B7%A5%E5%85%B7%E5%8C%85/api-data-export.exe

# 操作说明

1.登录系统后 找到 统计→会员结存入口

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db99b1a143624&type=max)

2. 打开浏览器控制台 (ctrl + F12）-> 网络（network)

- 点下查询会员列表”按钮“，会出现一个 'list' 结尾接口，然后右键复制。如下

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d940a00526808&type=max)

3. 将复制的内容粘贴到 api-data-export.exe 的命令行界面上，按回车

（会按每次请求 100 条数据拉取，需要点时间）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db99c6fe53629&type=max)

4. 需要注意的是对方系统有两种类型的会员，两种都要操作一遍上面的2、3 步骤

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d940aef506811&type=max)

注意事项：授权就是会员，另一个就是临时卡。

如果需要导出“未授权会员“，操作下⾯界⾯后复制信息。继续上⾯的步骤

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019db99e687c3642&type=max)
