# 应用场景
门店有活动时或门店装修升级，需要短信通知会员时，可以开通此功能。

# 操作流程
### 1.开通短信平台需要联系谁？
**联系油菜花销售，开通短信平台，获取账号密码；**

### 2.门店后台如何配置？
**路径：门店后台--运维--短信平台设置**

a.短信平台：选择通道三  
b.地址：[http://sms3.mobset.com/SDK2](http://sms3.mobset.com/SDK2)

c.企业ID，用户名，密码：填写油菜花销售提供的账号密码  
d.默认：选择是  
e.信息填写后，点击保存，保存后点击获取，有显示短信条数，说明已经配置完成

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719731731432-e6ff838f-23a6-4729-8d6c-458afcfb1041.png)

### 3.如何给会员发送短信
路径：门店后台--会员--发送短信

    1. 先按筛选条件查询到对应会员
    2. 勾选需要发送短信的会员，点击发送短信

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719732039742-3555f5d7-462b-4ecf-a2d9-5c173bcf8e97.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719731964410-0c244d5c-d1e8-42d4-a17c-08331fd1d8de.png)

### 4.发短信注意事项
1. 避免短信发送失败，建议短信格式为：“尊敬的用户，XXXXXX短信内容，拒收请回复R”；
2. 短信条数扣除规则：一旦短信的内容超过70个字，例如70到140字之间，在我们系统会显示只发送一条短信，手机端也会收到一条短信，但是短信条数会扣两条。因为短信的条数扣值，运营商是按照70个字为一条计算费用，超过就属于长短信。超过70字在140字以内是按照两条计费，210字按照3条，以此类推。
3. 签名也包含在字数统计。
