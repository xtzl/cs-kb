# 应用场景
适用于延期一整个会员级别的会员卡有效期。

# 操作流程
<font style="color:#000000;">路径：会员</font>**→**<font style="color:#000000;">会员</font>**→**<font style="color:#000000;">会员批量延期</font>

#### <font style="color:#000000;">1、点击延期，选择需要延期的会员级别，延期天数填写延期时间（如需往前延期可填写负数），备注里填写延期原因后保存；</font>
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718682335689-c94ff17a-3d2b-4a35-93ea-f5e8a97ce7a7.png)

#### 2、在后台--会员--会员批量延期里可查询对应延期记录、操作人、操作时间。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718682415733-4b87a72d-1514-420b-8da1-16020618d780.png)

# 常见问题
问：单次批量延期，延期天数最多可填写多少。

答：最多可填写到999或者-999。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719278315641-3fc61a0b-3490-4ce6-8034-b30b1ba141a1.png)



问：批量延期会员的有效期，已过期的会员会受到影响吗？

答：会的。

# 关联操作
如何只续期个别会员的有效期？

答：收银台-会员-会员资料-续期
