# 一、作业说明

自助发卡机是一款集开卡、借卡、充值一体的设备，支持实体卡场地用于开会员卡和临时卡的功能，同时也支持电子会员场地用于租用实体卡还卡与一体的自助设备。

# 三、支持功能

说明：由于发卡机有两种功能，不同工作模式有不同的功能应用

## 取还卡模式（取还卡模式适用已手机电子会员场地，可以实现取实体卡，自助换卡等功能）

1.支持付押金购买临时卡，并支持退卡自动退卡押金，适用于散客购买使用；

2.支持会员付押金取副卡（分身卡），并支持还卡后押金原路退还，押金可设置微信支付宝支付、也可以设置为储值支付；

3.支持会员充值游戏币套餐和预存款套餐；

4.支持线上平台团购核销会员卡套餐，线上平台支持美团、大众、抖音、票付通平台；

5.支持卡箱不足或卡箱满时提醒收银台；

6.支持微信刷脸付款和微信刷脸读取会员信息

7.支持查询会员卡储值情况；

8.支持放置全屏广告和半屏广告，支持图片广告或者视频广告；

## 发卡模式（发卡模式适用于已实体卡为主场地，散客设备开卡成为会员，电子会员可以直接开实体卡等功能）

1.支持散客可以通过发卡机直接办理会员卡并出实体卡

2.支持电子会员通过发卡机付费获得实体卡

3.支持会员充值游戏币套餐和预存款套餐；

4.支持线上平台团购核销会员卡套餐，线上平台支持美团、大众、抖音、票付通平台；

5.支持限制哪些会员级别可在发卡机进行核销发卡或充值；

6.支持卡箱不足时提醒收银台；

7.支持微信刷脸付款和微信刷脸读取会员信息

8.支持查询会员卡储值情况；

9.支持放置全屏广告和半屏广告，支持图片广告或者视频广告；

# 四、作业准备

1.十字螺丝刀*1

2.预留可通外网的网线以及220V电源线

3.会员卡*n

4.游乐宝系统版本在8.1.6726以上

# 五、注意事项

1.挪动位置时，至少2人以上进行搬运，以免发生意外

2.调试时，请佩戴好手套，以免应内部五金件锋利造成误伤

# 六、作业标准

1.发卡机联网正常

2.发卡机模式设置正确

3.会员卡卡槽中，压片能正确压住会员卡

4.所有功能正常使用

5.发卡机地脚打下，并稳固坐落在指定地方

# 八、作业步骤

## 步骤一：配件安装
1.拆除设备包装，检查设备整体外观是否完好无损、配件齐全；

2.安装顶部广告牌

3.打开后门，在卡槽里面放置会员卡，并加下压片和检查废卡槽是否安装到位；

（注意：一定要放置卡槽压片，否则可能会导致出卡异常）

### 【取还卡模式】独有功能

#### 1.【购买临时卡】 散客开临时卡，使用完可以直接塞卡进行还卡，押金自动退回。

临时卡设置套餐流程如下：

①设置临时卡级别

路径：后台→会员→会员级别

点击新增，在级别名称中，填写临时卡的会员级别名称，并在卡类型中选择【临时卡】，并根据实际情况填写其他相关的参数设置。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019191a39ce62c60&type=max)

②设置入会套餐

路径：后台→商品→商品管理→新增→入会套餐

在新增入会套餐的界面中，选择入会级别为上一步设置的临时卡级别，并设置对应的参数，如卡押金（退卡时会原路退该押金）、绑定套餐（点添加商品来添加，可添加游戏币套餐，添加的套餐的金额会叠加卡押金、工本费等费用形成本入会套餐的最终售价）等

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019191a5cf5b2c64&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e70019191a925c62c70&type=max)

#### 2.【取副卡】已经注册的会员可以在发卡机进行取副卡，游玩后可进行还卡，自动退回副卡押金（还卡储值押金会退回给会员、微信支付宝押金会原谅退回付款账号）

路径：后台→设置→会员设置→副卡、腕带

# 九、测试要求

1.通过取还卡模式，测试取卡功能是否正常，还卡功能是否正常

2.通过充值套餐，测试读卡功能是否正常和扫码功能是否正常

3.通过购买套餐，测试微信支付功能是否正常和支付宝支付功能是否正常

4.通过人脸识别功能，测试人脸识别是否能正确读取到会员信息（聚合平台支付，如汇付功能则无法使用人脸功能）

# 十、常见问题
1.发卡机不出卡？

检查是否缺卡或者没有加压片。

2.读卡失败？

检查读卡器链接是否正常。

测试会员卡能否正常读取信息。

3.系统是本地部署，当用会员码扫自助设备或核销或登录时，提示会员码过期。

答：校正本地服务器时间，检查本地服务器时间是否跟世界时间一致，若不一致更改一致即可；
