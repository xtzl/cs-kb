# 一、文档说明

在置换第三方系统时，原系统会员卡是无法直接使用在油菜花系统的，需要使用加密程序重新加密。而并非所有会员卡都能重新加密，遇到第三方会员卡时，请务必与销售助理/销售经理确认是否已经对会员卡进行测试。仅支持测试可重新加密使用的会员卡才能按照本教程来使用。

# 二、前期准备工作

1.与销售端确认是否已经通过测试。

2.确认读卡器是否支持重新加密。仅下图此款读卡器支持加密：

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001971608ad0938a8&type=max)

3.收银台电脑必须通外网。

4.销售端提前开通好转卡额度。

5.系统版本要求：

娱乐管家：10.3.8以上

游乐宝版本：8.1.7以上

6.（仅在下面描述的情况一失效后才需要）提前获取【应用ID】号。获取时需要提供门店编码给到实施组组长或者客服组组长来查询。

7.（仅在下面描述的情况一失效后才需要）提前下载第三方转换卡工具

# 三、转卡功能开通及使用说明

## 情况一：系统支持直接转卡（优先使用此步骤，如果失败才尝试情况二）

### 第一步：开启第三方转卡功能

路径：登录收银前台→更多→通用设置→第三方卡转换→开启→保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001971610878938cc&type=max)

### 第二步：第三方卡加密

①先将会员卡放到读卡器中

②在收银台，打开【会员补卡】界面，找到【第三方卡】点击它，等待加密完成。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019716171d5d38e0&type=max)

注意：加密后，新会员卡号不会和第三方旧系统的会员卡号一致，会重新生成一个复杂的会员卡号，但不影响使用。

## 情况二：系统不支持直接转换，需要使用工具来进行转换

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019716216b38390a&type=max)

# 四、第三方系统通过转换卡功能如何重新激活旧会员的会员卡

## 第一步：先通过旧会员卡信息在前台会员资料查询中找到对应的会员

这里有几种情况

情况一：导入数据时，有导入对应的会员卡号，且卡号与会员卡片上的卡号一致，则可以直接在会员资料查询中直接输入会员卡号来找到会员资料（不支持直接读卡查询，只能手动输入）。

情况二：导入数据时使用了手机号作为会员卡号，并录入了手机号，且门店有开通小程序。此情况可先引导客户通过扫门店二维码绑定会员后，再到会员资料查询界面，扫小程序会员二维码读取资料。

情况三：导入数据时使用了手机号作为会员卡号，但没有小程序。此情况只能在会员资料查询界面中通过手机号找到对应的会员信息。

## 第二步：点击补卡，将原会员卡放到读卡器中，先重新加密，然后再给会员进行补卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f44000197163688003962&type=med)

# 五、常见问题

1.加密时提示【网络异常请重试】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019716341f533958&type=max)

答：加密需要有外网，无外网不能转换

2.卡片读取失败，提示转换额度不足

答，缺少转换额度，需要找销售申请开通额度

3.转换时提示失败

答：有可能是读卡器不支持

3.使用工具转换时，如果遇到转换失败 ：-1，

答：请插拔一下读卡器，可能是 收银台和后台已占用读卡器。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019716365f793960&type=max)
