# 如何锁定账号储值?

1》路径：收银台--会员--账号锁定
2》步骤：点开账号锁定勾选需要锁定的储值，然后点击确定，

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179ccfb06a53abe&type=med)

# 如何取消储值的锁定

1》步骤去掉账号储值的锁定里面对应类型的勾选后点击保存。
