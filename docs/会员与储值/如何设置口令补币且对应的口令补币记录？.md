# 应用场景
应用于顾客在兑币机上面核销或者购买游戏币的时候没有出币，可以使用口令补币功能给顾客远程补币。

# 操作流程
路径：会员**→**口令补币**→**新增口令补币

#### 1、点击新增口令补币，填写补币数量，备注里填写补币原因后保存；
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718682554004-2477d089-8eb6-486c-a0d8-28e95b67464a.png)

#### 2、将显示的口令补币码给顾客，让顾客在兑币机口令补币功能上输入。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718682645502-bb1796a3-db93-4726-84a7-6f807370163f.png)
