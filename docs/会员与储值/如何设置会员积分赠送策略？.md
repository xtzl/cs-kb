# 应用场景
购买商品赠送积分：设置充值消费比例（充值包含：代币、金币、预存款）；

消耗储值赠送积分：消耗现有会员储值获得积分（消耗包含：代币、金币、预存款）；

会员日加速：应用于门店每周（每月）设定的会员日使用，在设定的日期内会员充值或消费会根据指定的倍数获得积分；

# 常见问题
问：如何设置指充值或消费代币（金币）才获得积分？

答：会员--积分赠送策略![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719299074775-e0c7ed33-17e5-4196-b8e9-cd7189ae0098.png)

问：如何设置参与赠送积分的对应会员级别以及积分倍数？

答：设置参与赠送积分的级别；积分倍数：默认填写1，需要翻倍赠送的可以填写（填写2，即得2倍积分）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719742586431-71482e2f-e715-4b67-b4c6-f05ca3060cf8.png)  
问：如何设置会员日积分加速？  
答：会员日积分加速:默认填写1，需要翻倍赠送的可以填写（填写2，即得2倍积分）；

设置指定日期或指定星期为会员日。
