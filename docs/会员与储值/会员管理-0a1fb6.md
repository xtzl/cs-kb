# 一、功能概述

会员管理报表是集会员信息多维度查询、储值余额实时查看、支持单个或多个会员增减储值以及延期会员有效期。

# 二、业务价值

### 会员信息与储值余额查询

支持通过会员卡号、会员名称、手机号、会员级别、入会时间等多类条件，精准筛选或模糊查询会员。可查看会员基本信息（如会员状态、身份证号等），以及各类储值相关数据（预存款本金、预存款赠金、代币、金币等），满足对会员信息全面掌握的需求。

### 批量增减会员储值

支持对符合筛选条件的会员，进行批量储值金额的增加或减少操作。能灵活应对不同业务场景，如会员储值优惠活动时的批量充值，或特殊情况的批量扣费等，提升会员储值管理效率。

### 会员延期

可对会员有效期进行延期操作，延长会员享受权益的时间，便于在会员即将到期或有特殊需求时，灵活调整会员有效期，增强会员粘性。

# 三、功能操作指南

## 路径：门店后台-会员-会员管理

### 如何查询会员储值余额

- 所有条件都不选，点击查询即是查询所有会员的储值，底部合计是所有会员的剩余储值；

- 输入会员号或会员手机号等条件，则是查询指定条件的会员信息以及储值；

- 点击蓝色的会员卡号可查询会员详细资料，点击储值余额蓝色字体可查询储值变更明细。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d7f66f90f9d&type=max)

### 如何增减会员储值

在会员管理里通过条件查询到对应会员后，点击会员后面操作“增减储值”的蓝色字体，进入增减储值界面，按需选择“增加储值”、“减少储值”，在对应储值框填写数量后点击确定即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d8cb3920fbd&type=max)

### 如何批量增减会员储值

在会员管理界面，点击批量增减储值，先下载模板，完善模板信息后导入。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d92cd490fcc&type=max)

#### 导入模板注意事项：

- 手机号与会员卡号填入其中一个即可；

- 如果填入的手机号存在多个会员账号，则储值会增减到最近有消费记录的会员账号中；

- 填入整数增加储值，填入负数扣减储值。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d93d59f0fce&type=max)

### 如何给指定会员延期

在会员管理界面，勾选对应会员后，点击会员延期按钮，选择过期时间后点击确定；

可同时勾选多个会员进行延期。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992d9780a30fd3&type=max)

# 四、常见问题解答

#### Q1：为什么会员管理里没有增减储值和会员延期功能？

答：在角色管理里检查账号对应的权限是否有“增减储值”和“会员延期权限”；如果没有权限的话，需要勾选上，点击右上角的保存；对应账号需重新登录后台生效。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992da1a1850ff9&type=max)

#### Q2：通过会员管理里减扣储值的明细在哪里可以查询？

答：在会员--储值变更记录，变更原因筛选“补账户储值”

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992daaa6dc101c&type=max)

#### Q3：通过会员管理给会员延期的记录在哪里可以查询？

答：在会员--会员信息变更查询里可以查询到，变更属性为“会员有效期”。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f440001992db1956e102c&type=max)
