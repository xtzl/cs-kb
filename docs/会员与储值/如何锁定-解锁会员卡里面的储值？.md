# 应用场景
将会员卡里的储值进行锁定，禁止客户使用储值

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-账户锁定/解锁

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击账户锁定/解锁，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593372771-c55bb84a-4bfb-4ba0-a24f-224b90082100.png)

#### 勾选需要锁定的储值类型，点击确定，储值解锁取消勾选之后点击确认，如图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593415228-ea99fe4a-8dca-4089-bfbd-5e3712f468dc.png)
