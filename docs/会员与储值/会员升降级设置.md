# 应用场景
总部支持统一设置会员自动升级策略和会员自动升降级策略，不同策略可针对不同场景下使用；并建议搭配不同会员等级设置不同的会员权益来进行区分，如更高级的会员支持兑换、售卖时产生不同的折扣优惠。
