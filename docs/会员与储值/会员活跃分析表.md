# 🔴报表说明
此报表用于查询会员一段时间内的消费和游玩情况，也可以查询一段时间内每个会员级别消费的人数和金额数，还会通过设置梯度来分析每个梯度消费人数，如需查询此相关数据请通过此报表进行。
