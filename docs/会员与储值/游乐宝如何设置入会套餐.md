一． 入会套餐

1. 入会套餐：顾客购买入会套餐，办理场地会员卡

2. 路径：商品--商品管理--新增--入会套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee060d52d69b5&type=max)

进入新增入会套餐界面填写套餐名称，入会级别，卡工本费，卡押金和添加绑定入会商品，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee060efe669b6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee0610a7369b8&type=max)

保存之后，即可在商品管理界面查看到新增的入会套餐

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee06123f069b9&type=max)

3. 呈现演示：

收银台--商品--会员入会--选择对应的入会套餐--填写会员信息（带星号的是必填选项），点击开卡即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee0613c9769ba&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee061511d69bc&type=max)

4. 常见问题：

问题1

场景：给客户0元注册会员

解决：新增入会套餐的时候不绑定入会商品，卡工本费和卡押金设置为0

问题2

场景：入会套餐有些需要读取实体会员卡，有些只需要输入手机号就可以注册

解决：后台-会员-会员级别-对应的会员级别入会介质不一样。
