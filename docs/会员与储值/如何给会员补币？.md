# 应用场景
当客户在机台上面投币之后，机台没有正常启动，如何给会员账户里面补游戏币储值

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-补币

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击补币，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718778494738-aa40c01e-21fd-4836-a030-c85b36628e4d.png)

#### 选择对应的补币类型，输入补代币数量，输入补币原因，点击存会员卡，如图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718778530052-03b1ef8f-e322-4446-a85e-33150eb09047.png)
