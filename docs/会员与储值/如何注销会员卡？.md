# 应用场景
客户会员卡不在使用，需要将客户会员卡进行注销

# 操作流程
路径：登录娱乐管家收银台-会员-登录会员-编辑资料旁的下拉列表-注销

####  登录娱乐管家收银台-会员-输入会员手机号/扫描会员二维码-点击编辑资料旁边的下拉列表-注销，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592518965-5ae7ce8b-32ff-467e-a627-e7fc47c2a04c.png)

#### 点击退卡，显示注销成功则表示客户会员注销成功了，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718592565512-c7b25594-8fdc-4c28-ac84-70f3035de526.png)
