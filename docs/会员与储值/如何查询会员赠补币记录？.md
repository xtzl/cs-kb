# 应用场景
适用于门店需要查询会员通过收银台补币、通过活动赠送、充值赠送方案、等方式获取到游戏币的记录。

# 操作流程
路径：会员→储值查询→赠补币记录

# 常见问题
问：如何查询某个活动赠送/充值赠送方案的赠币情况？  
答：增补币类型选择“活动赠币”/“充值赠送”，方案名称输入创建的活动赠送/充值赠送方案的名称
