# 一、功能概述

会员级别就是会员卡的等级，通过在后台创建不同的会员等级（例如普通卡, 金卡, 铂金卡等），后期可根据不同会员等级制定营销方案或跟进策略，例如通过级别设置限购或折扣。

彩票大师会员指的是基于普通会员的基础上，针对在彩票机消费的会员另建彩票会员级别，有利于刺激会员打票与耗票。

# 三、常见问题答疑

## 1.收银台注销卡时提示“会员不能注销”，如何解决？

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01993c29201c2048&type=max)

### 解决方法

后台找到对应级别点进去，将“允许注销”改为是就可以了。
