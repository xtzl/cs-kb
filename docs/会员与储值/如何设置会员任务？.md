# 应用场景
设置会员任务

# 操作流程
任务系统分为会员成就和任务中心，两者的差异见下图  
![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1766755769959-ba4931b3-e247-4a04-87e1-d7b249fa695f.png)  
应用场景

通过"会员任务"这个功能, 您可根据会员在指定时间范围内的存票, 兑票, 游玩次数等数量设置奖励, 例如"一周内消耗彩票超过10万奖励50币"等,  从而实现激励会员到店, 提升耗币耗票等运营目标.  总的来说, 主要亮点有: 

1. **<font style="color:rgb(6, 6, 7);">关联活动与奖励</font>**<font style="color:rgb(6, 6, 7);">：打造会员全周期运营，将运营活动与成就奖励紧密结合，激发会员长期忠诚度。</font>
2. **<font style="color:rgb(6, 6, 7);">进度与奖励可视化</font>**<font style="color:rgb(6, 6, 7);">：通过直观展示任务进度和奖励，增强会员的参与感和成就感，提升活动吸引力。</font>
3. **<font style="color:rgb(6, 6, 7);">活动效果量化分析</font>**<font style="color:rgb(6, 6, 7);">：对会员活动参与度和活动成效进行细致量化分析，优化运营策略，提高活动ROI。</font>
4. **<font style="color:rgb(6, 6, 7);">减少管理漏洞</font>**<font style="color:rgb(6, 6, 7);">: 各类的成就奖励由系统派发, 避免人工操作引发的漏洞</font>

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1766757801154-7f9b5bff-f560-4b78-a27e-5fd62e24cbe1.png)

### 第2步: 小程序查看任务进度，领取奖励
![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1766757289324-5ff2a6cb-bc09-4cfc-9406-341733af7d54.png)  
	奖励的领取方式：需勾选“收银台&小程序领取”  
	会员可以在小程序看到所有任务，（包括可完成的，完成中，和已完成的）

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1766755976185-3e1aadd2-e7d6-45fa-a95b-4f59a91766f7.png)  
	可设置任务奖励抽奖券，然后将抽奖活动入口展示的任务中心，会员完成任务后，可一键跳转到抽奖活动，无缝衔接  
![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1766756998220-2a9f69ce-b980-4922-9b29-4af1523094f6.png)

### 第3步: 联动氛围系统
可通过氛围系统，当会员完成任务可以通过屏幕恭喜完成任务活动奖励的会员
