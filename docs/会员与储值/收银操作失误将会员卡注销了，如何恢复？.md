# 应用场景
收银员操作失误不小心将客户会员卡注销，需要恢复客户的会员卡信息和剩余储值

# 操作流程
路径：登录娱乐管家系统后台-会员

#### 登录娱乐管家系统后台-会员-会员注销记录-查询到收银操作失误注销的会员卡-查询注销会员账户储值余额，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718765779935-c8ac5d08-2e5e-4ec7-9ef1-3bc7e8ea7f59.png)

####  登录娱乐管家收银台-商品-会员入会-选择入会套餐-填写会员手机号-点击开卡，给客户重新注册一个会员，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718766429082-cf3c43ea-0e9f-4638-aca2-55a03b50cd6c.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718766456401-38d23c6a-d92f-44d3-a117-23695b0df808.png)

#### 登录娱乐管家系统后台-会员-会员管理-补录储值-输入客户新注册的会员卡号-填写客户之前剩余的会员储值进行补录储值，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718766654512-a7d80de8-e083-4c1c-9771-8a75048952b0.png)
