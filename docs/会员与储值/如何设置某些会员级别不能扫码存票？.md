# 应用场景
门店需要指定会员级别才可扫码进行存票，不符合门店的规则的会员级别不支持扫码存票只能刷卡存票

# 操作流程
路径：设置**→**系统设置**→**会员扫码存票限制

#### 勾选对应会员级别保存后，则改会员级别的会员将不可进行扫码存票。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718704032170-0a6b3915-9ceb-4168-893a-aeb3058c7168.png)

# 常见问题
问：我想限制只有某个会员级别才能扫码存票，其余的会员都需要刷卡才能存票？

答：设置--系统设置--会员扫码存票限制
