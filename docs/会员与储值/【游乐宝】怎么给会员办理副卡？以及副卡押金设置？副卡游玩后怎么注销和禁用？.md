# 怎么给会员办理副卡

1》路径：

1）商品--售卖商品--主副卡

2）会员--编辑资料--主副卡

2）步骤：

输入会员相关信息，放一张空白会员卡，点击开副卡，第二种路径的操作方式就不需要输入会员账号了。

注意： 副卡所有的消费储值都是直接从主卡上面扣除

# 副卡押金设置

路径：

1》设置--会员设置--副卡腕带设置

步骤：

1》填写押金数量，和押金类型

## 注意 下方标红不是必须设置，可以按照场地经营模式来调整

1> 芯片卡或者腕带：是会员卡或者电子腕带类型做副卡 二维码腕带是带二维码的纸质腕带，对二维码有要求，
2>押金类型是元的话，就是收现金（微信支付宝纸钞）
3>取卡有效期，这个可以限制副卡使用时长，没有归还会直接锁定副卡，这时副卡需要到收银台的副卡管理里面解锁才能继续使用

4>出闸后自动解绑是指会员副卡游玩闸机时会自动与主卡解除绑定，相当于再收银台还副卡卡，

# 副卡如何注销或者锁定

路径：

1）商品--售卖商品--主副卡

2）会员--编辑资料--主副卡

步骤：

输入主卡后，会自动显示主卡下面开了几张副卡，选择对应的副卡点击还卡或者锁定即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179cd3e38db3b09&type=max)

### 注意

副卡不知道绑定的是哪个主卡怎么办？
把副卡拿到收银台会员资料读一下卡，点击查询会显示主卡的资料
