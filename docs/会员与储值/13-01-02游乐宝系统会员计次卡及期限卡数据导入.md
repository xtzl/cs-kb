# 一、作业说明

本说明为置换系统（其他品牌系统转换成油菜花系统）时，需要将客户原来的会员数据导入到油菜花系统中的作业说明。导入数据会视情况分两个步骤，仅导入会员资料以及会员储值（代币数、彩票数及积分数等储值），和导入会员次卡类或期限卡内数据导入。本教程为导入计次卡及期限卡数据导入说明。

# 二、作业准备

1.有office工具电脑一台

2.原系统会员数据一份（重要），此内容需要客户自行导出相关数据。

# 三、注意事项

1.导入前需要先将数据库进行备份，以免导出错误无法挽救。

# 四、作业标准

1.导入后客户给予的原数据与导入后数据一致。

# 五、作业步骤

1.先完成《游乐宝系统会员资料及储值数据导入》

说明：由于导入次数需要系统已有会员信息才能导入，所以需要先安装上述步骤进行导入。

2.根据客户原系统的次数游玩项目在油菜花系统中设置对应的项目，步骤为【后台】-【设备】-【设备管理】-【游乐项目】-【新增】-新增对应的项目

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d0350d442237a&type=med)

3.设置需要导入的次数所对应的套餐，这里分两种情况：

a.原系统有显示顾客所充值次数的套餐，则我们需要在油菜花系统设置对应的计次票。

b.原系统没有显示顾客充值次数的套餐，仅有次数，那我们仅需要在油菜花系统上设置一个计次票，可参考命名为【原系统导入次数】，次数设置为999，即可。

以上设置完，系统均产生商品编码，这个编码需要记录下来，导入时需要使用。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d0350d451237b&type=med)

4.先将会员信息（原系统会员卡号、会员储值、会员个人资料等信息）通过会员数据导入功能导入进去，可参考《会员数据导入》教程进行导入。

5.点击下载模板，将原系统信息按照模板表格填写完毕，然后点选择文件，再点导入即可完成次数导入。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d0350d461237c&type=med)
