# 应用场景
应用于门店做活动有优惠套餐，购买后需要在规定天数内适用，过期作废；

适用于顾客购买套餐游戏币后没有使用完就过期，可以在后台进行操作延期处理



# 操作流程
路径：会员**→**会员币批次**→**过期补币

#### 勾选对应过期记录点击补币，补币说明里填写原因后保存即可。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718679603477-b54280c2-ab7e-4503-b8af-dcd54a71055c.png)



# 常见问题
问：补币后的代币有效期是多久？

答：补币后代币默认是永久有效，如不想代币永久有效可调整币有效期

路径：会员--调整币有效期

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719558356439-e7a671a1-7643-4fb7-844d-2246ec8e5d5b.png)

问：如果统一调整过期代币/金币补币的有效期？

答：连锁门店在总部后台-系统设置-币有效期设置--过期代币补币有效期设置/过期金币补币有效期设置里设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719558420871-0ed9381e-0c28-4887-9d00-2e416c5c79c7.png)
