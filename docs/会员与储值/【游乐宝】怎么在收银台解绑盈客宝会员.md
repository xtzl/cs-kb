# 怎么在收银台解绑盈客宝会员

应用场景：

1）客户的微信号更换了或者微信绑定的手机号更换了
1》先查询到会员，操作解绑，然后变更会员信息的手机号，客户微信再扫码登陆小程序就会自动关联

路径：

1》会员--会员资料--编辑资料--解绑微信

步骤：
1》输入会员相关信息，查询到会员账号后，点击解绑微信即可
