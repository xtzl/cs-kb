# 一、作业说明

自助发卡机是一款集开卡、借卡、充值一体的设备，支持实体卡场地用于开会员卡和临时卡的功能，同时也支持电子会员场地用于租用实体卡还卡与一体的自助设备，支持团购核销后进行发卡，支持发4种不同的会员卡。

# 二、产品外观

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487000cc6a85&type=med)

# 三、支持功能

特色功能：

1.根据不同会员级别进行发卡（最多四种不同卡面）

2.与旧版发卡机相比，不在区分发卡模式和取还卡模式，可同时使用所有功能。

其他功能：

1.【买临时卡】支持付押金购买临时卡，并支持退卡自动退卡押金，适用于散客购买使用；

2.【办会员卡】支持散客可以通过发卡机直接办理会员卡并出实体卡；

3.【开主卡】支持电子会员通过发卡机付费获得实体卡；

4.【取副卡】支持会员付押金取副卡，并支持还卡后押金原路退还，押金可设置微信支付宝支付、也可以设置为储值支付；

5.【会员充值】支持会员充值游戏币套餐和预存款套餐；

6.【团购核销】支持非会员核销团购套餐，支持线上平台团购核销会员卡套餐，线上平台支持美团、大众、抖音、票付通平台；

7.【赠币券】支持赠币券核销

8.支持开会员卡时发送手机验证码并核验（需要开通短信功能才能支持）

9.支持开卡时同时设置会员密码

10.支持限制哪些会员级别可在发卡机进行核销发卡或充值；

11.支持卡箱不足或卡箱满时提醒收银台；

12.支持微信刷脸付款和微信刷脸读取会员信息（需注意是否有人脸识别模块，没有即不支持）

13.支持查询会员卡储值情况；

14.支持放置全屏广告和半屏广告，支持图片广告或者视频广告；

15.支持设置副卡使用额度；

16.支持主扫登录，显示二维码扫码后登录会员；

17.手机号登录，可以在取卡机填写手机号登录会员；

18.支持展示税费，付款页面展示包含的税费；

# 四、作业准备

1.预留可通外网的网线以及220V电源线

2.会员卡*n

3.娱乐管家系统版本在10.4.2190以上

4.取卡机软件更新最新版本

# 四、作业标准

设备正常安装并能正常运行

# 五、注意事项

1.挪动位置时，至少2人以上进行搬运，以免发生意外

2.调试时，请佩戴好手套，以免应内部五金件锋利造成误伤

3.位置确定后，需要对轮子进行固定，以免设备在使用中进行位移

# 六、作业标准

1.发卡机联网正常

2.会员卡卡槽中，压片能正确压住会员卡

3.所有功能正常使用

4.发卡机地脚打下，并稳固坐落在指定地方

5.能正常收取现金

# 七、配件清单

# 八、作业步骤

## 步骤一：配件安装

1.拆除设备包装，检查设备整体外观是否完好无损、配件齐全；

2.确定好设备摆放位置后，打下轮锁进行固定

3.打开取卡机正面左侧打开屏幕门锁，把卡箱取出

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001286a86&type=med)

4.用在卡箱小钥匙打开卡箱，里面分别放置会员卡，并加下压片和检查废卡槽是否安装到位；（注意：一定要放置卡槽压片，否则可能会导致出卡异常）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001426a87&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001586a88&type=med)

5.卡箱放好会员卡，上锁后，需要把卡箱按照原有顺序与方向，放回发卡机。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4870016e6a89&type=med)

4.找到发卡机背后底部电源处，连接网线和电源线，通电通网后打开电源开关，开机。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001856a8a&type=med)

## 步骤二：设备联网

1.在初始化弹窗界面输入服务器IP地址信息，点击【确定】完成联网。

门店是云端部署（即服务器系统是安装在油菜花云端服务器），输入门店域名地址，

如 【********（前面*号为门店编码）.yun1.youcaihua.net:88】

## 步骤三：功能设置

### ①卡槽对应级别设置

说明：由于不同的会员级别可能对应的卡面不一样，所以需要此步骤来为发卡机设置不同的卡槽对应的是不同卡面以及对应不同的会员级别。

1.进去主界面之后，长摁右上角设置按钮并输入密码进入后台。密码1或****（已脱敏，请向运维索取）261。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001b36a8c&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001bd6a8d&type=med)

2.进入发卡机软件后台，需要先设置卡槽

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001ce6a8e&type=med)

3.点击设置卡槽，进入卡槽设置，支持4种不同会员卡进行同时发卡，需要选择卡槽对应的发卡级别，取卡机会根据会员级别给顾客发不同卡面的卡。

注意：如果选择卡槽不限制，该卡槽会对未选择的级别进行发卡。

常见案例：黄金卡级别发黄金卡的卡面，则选择放黄金卡的卡槽限制只能用于黄金卡；同理，铂金卡级别发铂金卡的卡面限制对应卡槽只用于铂金卡；临时卡级别发临时普通卡的卡面限制对应卡槽只用于临时普通卡。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d487001e96a8f&type=med)

# 九、测试要求

1.通过开副卡功能，测试取卡功能是否正常，还卡功能是否正常

2.通过充值套餐，测试读卡功能是否正常和扫码功能是否正常

3.通过购买套餐，测试微信支付功能是否正常和支付宝支付功能是否正常

4.通过购买套餐，选择现金支付，测试纸钞口功能是否正常

# 十、常见问题

问：取卡机不出卡？

答：1、检查是否缺卡或者没有加压片。

问：取卡机提示缺卡？

答：检查取卡机的卡槽是否安放到位，卡槽是否有卡片

问：取卡机开关打开了但是并没有启动？

答：

1、取卡机前后都有开关，检查开关是否都是开启状态

2、检查电源线是否有松动

问：办会员卡时，提示获取会员级别相应商品信息失败，未找到相应的商品！

答：后台-会员-会员级别，重新设置一遍会员的补卡换卡续期费用，可能存在历史缓存，需要重新保存一遍（BUG）

问：卡片回收回来是否会自动返回卡槽

答：不会，回收回来的卡会掉到废卡箱，需要重新收集卡，放回卡槽

问：提示未绑定仓库

答：终端-智能硬件，选择对应取卡机，点击名字进入编辑，售卖仓库选择对应仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a19cff446a019d4c06531e6fe3&type=med)

问：提示支付订单失败，请到后台管理配置此支付方式的设置

答：财务-支付方式，选择对应支付方式，把对应取卡终端勾选上

问：会员主卡可以进行还卡操作吗？

答：不可以，主卡插卡至还卡口，会提示非临时卡，然后把卡退回

问：读卡失败？

答：检查读卡器链接是否正常。测试会员卡能否正常读取信息。

问：限额的额度支持漫游吗？

答：暂不支持

问：哪些设备支持副卡限额功能？

答：卡头、闸机；但限额副卡无法提实物币，且限额的副卡不能取副卡；

问：副卡限额支持哪些储值？

答：代币、金币、预存款；

问：副卡额度不足会怎么样？

答：卡头会提示E512错误码
