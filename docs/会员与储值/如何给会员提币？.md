# 应用场景
收银人员如何在收银台软件上面给客户提币

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-提币

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击提币，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718778153223-8ca14f18-0e4d-4270-b5eb-7ae634756031.png)

#### 输入提币数量，点击提币之后，对应的数量游戏币会从柜台售币里面出来，如图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718778198734-201345b1-8a5d-4239-ae56-bce5dab02661.png)
