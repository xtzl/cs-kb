# 应用场景
会员分群功能可以帮助门店筛选会员客群，便于做会员活动方案策划，同时可以快捷的发送优惠券、短信发布店内活动提醒给顾客，吸引顾客到店消费游玩



# 操作路径
A. 如何设置会员分群？

①路径：门店后台→会员→会员分群；

②点击底部“增加人群”按钮，填写分群名称并设置统计规则，统计规则包含基础属性（例如会员性别，会员级别，会员储值），会员行为属性（包括最近到店日期，购买金额，频次），同时可以设置会员标签，会员价值属性。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407204111-25c4f3f2-d7ad-4ac3-934f-ea8118c494ca.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407207864-ca11f7aa-146e-4ccf-9aea-2034298b1230.png)

B.如何通过分群给顾客发送短信

在会员分群页面，点击分群后面的短信按钮，系统弹出发送页面，可以查看发送的会员数量，并填写短信内容；  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407275182-01b412cc-aef9-412b-8c41-e01bca68c9f5.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407278874-d076e62c-8176-4699-93fc-9c94af398b5a.png)



C.如何通过分群给顾客发送短信

在会员分群页面，点击分群后面的优惠券按钮，可以显示优惠券弹窗，选择优惠券，并给顾客派发优惠券。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407359170-64a1cc65-939f-4430-a486-3e9297b68371.png)![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719407363518-20335871-c389-47a7-b413-abdb0601e6b7.png)
