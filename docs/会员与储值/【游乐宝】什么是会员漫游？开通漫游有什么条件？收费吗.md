# 什么是会员漫游？

答：简单来说就是多门店的会员储值互通，A店会员经过漫游后，可以把A店会员的储值漫游到B店去游玩使用，漫游过去后与B店会员没有任何区别。

# 开通漫游有什么条件

答：1.门店使用油菜花系统必须是同一种类型的系统
2.门店的服务器电脑必须是可以访问外网（服务器电脑浏览网页）

# 收费吗

答：属于增值服务需要收费
