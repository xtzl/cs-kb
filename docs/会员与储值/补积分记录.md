# 一、功能概述

补积分记录主要用于查询门店在收银台操作的给会员补积分的明细记录

# 二、业务价值

### 方便门店查询

支持通过操作时间、账期、会员号、手机号、会员级别、终端、操作人、授权人等条件精准筛选会员的补积分明细记录

# 三、功能详解

### 路径：门店后台-会员-补积分记录

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01993691c29a0fbb&type=max)

### 如何查询会员补积分记录明细

打开报表后选择对应的条件进行筛选查询即可根据对应条件筛选会员补积分明细记录

### 如何查看会员补积分记录合计

打开报表后选择对应的条件进行筛选查询即可在报表底部查看根据对应条件筛选出来的会员补积分的合计数量
