# 应用场景
适用门店会员截图会员二维码进行提币购买等操作，不想要会员码固定，需要会员码有时效，可以设置二维码的有效时长

# 操作流程
路径：设置**→**系统设置**→**会员设置**→**会员二维码设置

#### 门店可以很根据运营的实际需求选择会员二维码的有效期时长动态二维码最长时间10分钟。![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718703971688-427b0240-288c-414a-8fa6-80ae41caebd4.png)
# 常见问题
1、小程序会员二维码会提示30秒的刷新时间，这个不影响会员码的使用的，举例：后台设置有效时长是5分钟，那么小程序生成二维码后5分钟内都是有效的，小程序的二维码刷新了生成的二维码在5分钟内还是可以使用的
