# 1 新娱乐管家系统后台流程
## 1.1 软件版本
10.3.9061或以上

## 1.2 硬件版本支持
**卡头版本：**V14或以上（重启卡头连接网络时显示）

**控制板版本：**V9或以上（重启卡头连接网络时查看，MCU:版本号）

**抽奖机屏幕：**V1.0.4或以上（屏幕又下角即可查看）

**升级流程：**游智云推送版本，重启设备后自动升级

## 1.3 抽奖机活动逻辑
业务描述：

1、后台设置抽奖机活动，抽奖机抽中奖球后则获得设置的相应奖励

2、同一台抽奖机支持多个活动，多活动有以下场景：

2.1会员登录时，优先消耗有券的活动，如果都有券，则显示最后创建的活动

2.2会员无券时，优先显示可以兑换的活动，都可以兑换时，则显示最后创建的活动

2.3会员登录时，一个活动支持兑换，一个不支持兑换，优先进入支持兑换的

2.4会员登录时，都无券，都支持兑换，会员一个活动兑换储值充足，一个活动兑换储值不足，优先显示会员兑换储值充足的活动

3、抽奖机可通过购买商品、完成本地会员任务、储值兑换获得抽奖券和抽奖次数

4、抽奖券已用完后，购买时赠送抽奖券的商品无法退款（需要重新获得抽奖券或者活动结束才可以进行退款）

5、奖项等级可设置特等奖、一等级~七等奖以及谢谢惠顾。

6、奖励可设置代币、金币、积分、彩票、娃娃、成长值、优惠券

## 1.4 抽奖机绑定流程
**业务描述：**抽奖机设备与业务系统进行绑定，用户在后台设置了抽奖活动后可在抽奖机进行抽奖。

操作流程：启动抽奖机——系统后台刷配置卡（终端--卡头wifi通讯设置--网络参数写入配置卡）——抽奖机刷配置卡连接网络——卡头显示设备编号——系统后台添加抽奖机设备（终端--智能硬件--添加--幸运抽奖机--填写信息--保存）——绑定成功

第一步：启动抽奖机，此时卡头显示请在系统后台制作通用配置卡。

## 1.5 新增活动设置流程
**业务描述：**后台新增抽奖机菜单模块，可用于新增或修改抽奖机活动，并结合抽奖机进行抽奖。

**操作流程：**系统后台——小程序——抽奖机活动————新增——设置活动信息——保存

**Ps：**设置完成抽奖机活动后重启抽奖机设备即可进行抽奖。

### 1.5.1 活动表
**业务描述：**用户可通过此表查看活动时间、活动名称、参与人数、总抽奖券数、已抽奖券次数、最后修改时间、活动状态以及对活动进行查看、编辑、结束、复制活动。

操作流程：小程序——抽奖机活动——活动表

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845015519-7fcb4f90-acf8-4497-b250-8e15b86be700.png)

**业务描述：**用户可通过此报表查看会员的抽奖记录、抽奖时间、会员信息、抽奖消耗类型、奖球、奖品类型、奖品等级、奖品名称、出奖状态以及追回奖励操作。

**操作流程：**小程序——抽奖机活动——抽奖记录

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845015846-f9a758c7-1ff8-4201-a70f-9a7d06f9df1d.png)

### 1.5.3 抽奖券获取记录
**业务流程：**用户可通过此表查看会员的抽奖券详细获取记录，获取时间、会员卡号、会员手机号、活动名称、本次获取的抽奖券数量、累计获取抽奖券数量、获取来源以及详细信息。

**PS:**单个商品如有多个活动设置赠送抽奖券，购买时可赠送多个活动的抽奖券。

**操作流程：**小程序——抽奖机活动——抽奖券获取记录

# 2 抽奖机设备
## 2.1 抽奖机抽奖流程
**业务描述：**用户在后台设置好抽奖活动以后，可在抽奖机设备上进行抽奖，可用会员卡登录抽奖或者扫码登录抽奖。

**操作流程：**刷卡或者扫码登录——点击抽奖——抽奖中——显示中奖号码——奖励存入会员账户——完成抽奖——退出

**Ps：**抽奖可使用抽奖券或者储值兑换进行抽奖。

第一步：先插卡或者扫码登录进入抽奖界面。



![](https://cdn.nlark.com/yuque/0/2025/jpeg/1584417/1753845018845-ec7ab044-03fb-4d8d-be1a-4e448b9c3190.jpeg)

第二步：点击开始抽奖或者储值抽奖，此时卡头显示抽奖进行中，抽奖机屏幕会闪动奖球号。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845019167-deb07143-f00d-4ae2-9364-c312b943234f.png)

第三步：抽中号码，卡头已经屏幕显示中奖号码以及对应的奖励、奖项等级，奖品抽中后自动存入会员账号。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845019577-717df440-d39f-4480-952c-3d4d14f158a6.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845019956-4fba8825-b670-45b1-be8d-a0cb304380fc.png)

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845020321-2e7e9a32-19c4-46cd-aa80-e02007eb6e56.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845020730-adac5348-a668-457e-8b92-efce32c77fac.png)

第四步：卡头上可点击再来一次或者退出，点击再来一次再次进入抽奖界面，点击退出可回到默认界面。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845021071-120f190c-fb99-475d-b7b4-e3ddda36d8b0.png)![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845021421-b87a6054-17fe-4992-95e2-ad6dbc9efd55.png)



## 2.2 抽奖机屏幕中奖号码
**业务描述：**中奖号码页面可以显示奖品等级、奖项以及对应的奖球号码，此功能显示可在后台智能硬件操作开关控制，设置较多等级时页面滚动显示。

**操作流程：**后台智能硬件菜单勾选显示中奖号码（不勾选则不显示），屏幕会轮播自动显示中奖号码。

**Ps：**多个活动时建议隐藏中奖号码，多活动时屏幕不显示中奖号码。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845021786-1c63aa11-5707-42e7-9b34-e60f32aad641.png)

## 2.3 抽奖机屏幕中奖名单
**业务描述：**用户可通过此页面查看会员中奖名单，界面滚动显示最后十位中奖会员，中奖名单显示会员姓名、中奖时间、中奖等级以获得的奖励名称。

**操作流程：**后台智能硬件菜单勾选显示中奖名单（不勾选则不显示），屏幕会轮播自动显示中奖名单。

**Ps：**多个活动时，中奖名单显示多个活动会员中奖信息。

![](https://cdn.nlark.com/yuque/0/2025/png/1584417/1753845022166-cc409731-e475-430b-827f-df082c164678.png)

## 2.4 抽奖机卡头信息重置流程
**业务描述：**拆开抽奖机卡头，长按按钮可以重置卡头信息，重新刷配置卡（需注意如需重新绑定其他抽奖机，后台抽奖机设备需先解绑）

**Ps：**非专业人员谨慎操作
