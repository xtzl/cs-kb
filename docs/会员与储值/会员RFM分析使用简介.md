# 应用场景
会员RFM分析是门店用来判断会员某段周期内的价值，根据上次到店时间到当前时间间隔、消费频率和总消费金额来给会员进行分类

# 操作流程
路径：会员**→**会员RFM

#### 1、点击设置RFM设置，会出现下图标签定义，门店可按照界面选择系统自动计算还是自定义RFM值的方式编辑后数值，填写好之后可按照设置的计算；
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718701277179-0b87cacb-02d3-4281-b779-46c4ca0970f0.png?x-oss-process=image%2Fformat%2Cwebp%2Fresize%2Cw_825%2Climit_0)

#### 2、根据上述设置，会显示出门店各个会员的RFM分类。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719333431848-7b5f6937-1d9b-4c15-bf51-96b9c9200cbf.png)

# 常见问题
1、如何给某一RFM分类的会员发送短信和优惠劵，选择按RFM分类汇总，点击对应分类的短信或优惠劵进行发送
