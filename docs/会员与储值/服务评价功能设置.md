# 应用场景
此功能用于设置公众号推送给会员填写的服务评价功能，用于总部收集门店对会员的评价。需要开通公众号功能并设置消息推送功能才能使用。

# 操作流程
路径：总部后台→会员→服务评价

在【服务评价】功能界面中，选择【评价设置】并选择开启该功能，可设置评价维度和评价奖励，设置推送公众号消息内容。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721549935140-dca83c36-9ae4-41e8-a455-26c000c4d49f.png)

在评价详情中可查询到评价明细内容。
