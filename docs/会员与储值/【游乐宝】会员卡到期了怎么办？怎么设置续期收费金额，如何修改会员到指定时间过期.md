# 会员卡到期了怎么办

1》路径：2）商品--售卖商品--会员续期

1）收银台--会员--续期
2》步骤：点开续期，填写续期的时长，然后选择续期的单位点击保存

# 怎么设置续期收费金额

1》路径：游乐宝后台--会员--会员管理--会员级别设置

2》步骤：找到对应会员级别设置点击对应的级别，填写续期价格保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179ccff67123ad0&type=med)

# 如何修改会员到指定时间过期

1》路径：收银台--会员--会员级别变更

2》步骤：点开会员级别变更，选择变更级别，变更级别和会员当前级别一致，是否换卡选择否，然后选择会员账号的有效期再保存即可
注意：会员账号的有效期目前支持往后调整，无法往前调整
