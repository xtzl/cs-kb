# 应用场景
适用于门店查询某个时间段入会的一个情况。

# 操作流程
路径：会员→会员查询→入会记录查询

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718706509340-ef9c436e-5bb4-4f83-8e38-7c9dea75a69e.png)

# 常见问题
问：如何查询某个时间段入会的会员数量？

答：点击 入会时间 后面的方框，选择需要查询的日期，点击查询

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719501574542-b3c667c8-489d-4f80-ba12-4c4a0a97739d.png)

  
问：如何查询某个时间段每个入会套餐入会的会员数量？  
答：点击 入会时间 后面的方框，选择需要查询的日期，点击查询，选择“按套餐汇总”  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719502375039-e1b7985c-32b9-4c84-84c2-365f0d075623.png)



问：选择“按套餐汇总”查询数据时，有一行 套餐名称 显示空白的会员入会数据是什么原因？  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719502564395-49f676d7-fd76-4228-908f-bc7b00b2f336.png)

答：原因是 小程序入会设置，设置的是“自动注册”，没有购买入会套餐入会![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719502797069-81b0e383-35f1-4b84-bee2-93f071dc4944.png)  


问：如何查询某个时间段小程序入会的会员明细？

答：点击 操作人 后面的方框，选择“系统服务”，点击查询

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719501829873-a10a6b5c-d16f-40ba-8ba5-4d5d3006066d.png)
