# 会员账号的储值怎么过户给另一个会员账号

1》路径：收银台--会员--储值过户

2》步骤：收银台点击储值过户后，输入需要转入会员储值的账号，然后填写过户的储值数量，如需过户账号下面所有的储值，点击全部过户后点击过户按钮后输入转出会员账号的密码即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179ccf9402e3aaf&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e10179ccf9403d3ab0&type=med)

## 注意

使用储值过户的前提是后台允许会员储值过户，如果后台是没有启用的话，是无法储值过户的，系统会提示系统不允许XX过户
