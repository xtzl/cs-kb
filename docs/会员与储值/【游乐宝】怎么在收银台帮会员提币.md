# 怎么在收银台帮会员提币

前提：收银台电脑有连接柜台售币机

路径

1》商品--售卖商品--快捷功能--提币

2》会员--会员资料--提币

步骤：

1》读卡或者手动输入会员相关相关信息，（会员手机号，会员二维码，名称，手机号），输入提币数量点击提币
2》查询到会员后--点击提币--输入提币数量即可
