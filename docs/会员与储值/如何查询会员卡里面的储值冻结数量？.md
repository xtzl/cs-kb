# 应用场景
适用于查询会员储值的冻结情况，对已冻结储值作解冻或者情况操作。

# 操作流程
路径：会员**→**储值查询**→**冻结储值管理

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718786175272-5fbf9c3e-409f-4cde-898c-8cad7a588c4d.png)

# 常见问题
问：冻结的储值可以解冻吗？

答：可以，【冻结储值管理】选中需要解冻的记录，点击解冻储值。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719310086811-d3fb62fa-3597-43bb-b34c-1b4833ce16c3.png)

# 关联操作
问：已冻结的储值记录备注是：增加数量超出额度/余额超出超出，这个额度如何修改？

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719311398849-04868c5f-36f2-4e49-8631-bbf9d8090369.png)

答：会员储值限制-储值额度设置，这里重新设置提交。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719311529081-b9402ddb-c346-48da-8c4f-af9d46ca2f15.png)
