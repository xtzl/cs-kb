# 业务描述

首页为进入游乐宝管理系统的第一个展示页面（此页面默认展示，不支持关闭），主要是让店面的营业情况一目了然，整洁全面。

# 页面所涵盖内容

1. 首部栏目：营业收入、进店会员1. （如果开通了客流监控，进店会员被客流监控替换）、耗币数和网络渠道收入（同比：（今日数-同期数）/|同期数|*100%)；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da0902cd7e1e&type=max)

2. 中部栏目1：乐园关键指标和会员消费排行榜（ 仅展示前五名的消费 ）；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da0902fd7e1f&type=max)

3. 中部栏目2：商品销售额占比（TOP7）、项目启动次数占比（TOP7）和票售卖情况（TOP7）（此三项只划分7个类别，第7个类别以后的统一归为“其他”项）；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da0e84897e30&type=med)

4.底部栏目：收入构成、机台投币排行、币售卖情况（TPO7）统计表。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81485aecc240186da0903207e20&type=max)
