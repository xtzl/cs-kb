# 应用场景
查询单个会员或者所有会员的套票情况

# 操作流程
路径：报表**→**套票类**→**套票查询

#### 门店可以按售卖时间，会员卡号等筛选，把表格底部横条往右拉，即可查询使用次数，到期时间，未分摊金额等。
