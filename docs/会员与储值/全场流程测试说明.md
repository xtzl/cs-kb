# 流程说明

本流程用于指引实施人员对现场安装结束后如何进行现场全部功能测试。

# 测试条件准备

1.预约现场负责人，因需要现场负责人一同测试检验，所以需要提前与现场负责人进行测试

2.门店所有套餐上架完毕；

3.所有机台通电完成（无卡头情况下可忽略）

4.安排门店工作人员在场陪同演练；

5.收银电脑、自助设备通电

# 全程流程测试内容

## 1.收银内容演练

包含内容

a 会员开卡、会员充值、商品销售、礼品回收兑换、第三方核销

b 日常会员资料查询、补卡换卡、会员挂失、消费查询

c 订单查询、订单退货、兑换退货取货

d 日常交账对账

e 特殊流程测试（点餐流程、预约活动等）

## 2.仓库管理流程演练

包含内容

a 礼品周转全流程（入库 出库 调拨 盘点）

b 实物币流转全流程（收币、加币、清币）

## 3.财务流程演练

包含内容

a 日常对账

b 账期做实

## 4.游客流程演练

包含内容

a 自助设备购币、提币、核销流程

b 自助设备存票流程（扫码存票、读卡存票、无卡存票）

c 游乐游玩卡头流程（刷卡扣费、退电子彩票、退实物彩票、扫码游戏）

d 闸机过闸流程（人脸过闸、二维码过闸、核销过闸、会员卡过闸）以及上述的游客出闸过程

e 其他自助设备使用流程测试

f 小程序购币流程、小程序购票流程等
