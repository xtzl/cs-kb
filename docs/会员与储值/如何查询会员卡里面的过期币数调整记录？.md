# 应用场景
适用于查询在【过期补币】功能上进行操作过补币的记录。

# 操作流程
路径：会员**→**会员币批次**→**过期补币记录

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718785528529-660b3704-6f79-43ad-baac-a0f2c8d27492.png)

# 常见问题
问：可以查询到是哪个账号进行的过期补币吗？

答：可以，【过期补币记录】这边找到对应的记录，有操作人账号的记录显示。

# 关联操作
过期的游戏币如何进行补币？

【过期补币】功能，选中需要补币的记录，然后点击补币。
