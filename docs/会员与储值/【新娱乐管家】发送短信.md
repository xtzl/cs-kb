# 一、功能概述

适用于门店需要给单个会员或者多个会员发送门店的营销消息等信息，可以使用短信功能通知会员

# 二、业务价值

通过精准的时机选择,可以让短信营销发挥最大效用,确保商家的促销活动能够顺利达成预期目标。

# 三、功能详解

1.开通短信平台

联系油菜花销售，获取配置，开通短信平台，获取账号密码；

2.操作路径：会员→发送短信

3.

方法1、根据门店需要条件查询出对应会员，可单个或者批量勾选对应会员进行编辑短信内容发送；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb0199380835ae14bd&type=max)

方法2、①可以将查询出来的会员进行批量导入进行发送；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb01993809367114c0&type=max)

②下载对应的模版进行导入；

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb0199380a7b3214c1&type=max)

#### 4、发送后可查询历史发送记录，界面可以看出短信是否发送成功

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a199314bdb0199380b9de014c2&type=max)

#### 5、如若发现短信发送失败，可以查询出失败的记录，重新进行发送。
