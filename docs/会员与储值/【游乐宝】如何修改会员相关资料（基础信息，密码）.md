# 怎么修改会员基础信息？

1》路径：

1）商品--售卖商品--会员资料修改

2）收银台--会员--编辑资料

2》步骤：点击资料修改后，修改按照需求填写资料保存即可

# 怎么修改会员密码，客户忘记了会员密码怎么办？

1》路径：

1）商品--售卖商品--会员密码修改

2）会员--编辑资料--修改密码

2》步骤：点击修改密码，验证旧密码后，输入会员新设置的密码

### 1）客户忘记会员密码了怎么办？

修改密码时选择不授权即可
注意：密码只能纯数字，不然会影响会员无法在自助上面提币，并且无法注销会员卡
