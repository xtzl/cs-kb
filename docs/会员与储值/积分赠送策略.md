# 一、功能概述

积分赠送策略是客户激励体系的核心功能，主要通过消耗储值或者充值等行为获得积分，积分用于兑换其他价值礼品，从而提高客户消费意愿，达到门店提高创收的目的

# 二、业务价值

#### 一、提升家庭用户复购与驻留时长

- ‌积分兑换实物奖励‌：通过游戏消耗或充值获得积分，可兑换玩具、文具等实物礼品，直接刺激儿童及家长的重复消费行为。例如弹珠机玩家通过积累珠子兑换礼品券，显著延长单次游玩时间。

- ‌会员分层权益‌：设置不同积分等级（如银卡/金卡会员），高级会员可享受专属兑换比例或优先参与亲子活动，增强家庭用户的归属感。

#### 二、构建“游戏-积分-消费”闭环

- ‌动态积分增值机制‌：用户消费获得的积分可随时间增值（如40期后兑换5倍消费券），形成“消费→积分→再消费”的循环，提升客单价。例如“我店模式”通过积分增值使单用户消费频次提升3倍4。

- ‌异业合作扩展场景‌：与周边餐饮、零售品牌合作，积分可跨店兑换优惠券，吸引家庭用户从单一娱乐向复合消费延伸。

#### 三、优化运营效率与数据应用

- ‌精准营销推送‌：通过积分获取数据识别高价值家庭用户，定向推送亲子活动或设备优惠信息，提升转化率。

- ‌设备组合策略‌：将彩票机（积分兑换）、亲子机（互动体验）与礼品机（实物奖励）组合布局，形成“玩-赢-兑”的完整消费路径，提高坪效。

#### 四、增强品牌差异化竞争力

- ‌主题化积分活动‌：结合动漫IP或节日主题设计限时积分任务（如集齐角色徽章兑换周边），强化场地特色。某动漫主题电玩城通过此类活动实现月盈利60-90万元。

- ‌社交裂变传播‌：家长分享积分兑换成果至社交平台可获额外积分，低成本扩大品牌曝光。

综上，积分体系通过游戏化激励和跨场景联动，帮助场地实现用户留存、收入多元化和运营精细化。

#### 参数设置

积分赠送策略：根据场地运营需要，去设置，两种规则可以同时设置，也可以只设置其中一种

充值预存款也赠送积分：勾选后购买预存款套餐也会赠送积分

充值代币/金币也赠送积分：勾选后表示购买代币/金币套餐也赠送积分

会员级别积分有效期说明：默认是1年，如果需要修改，请登陆会员级别设置那边修改

积分倍数：购买商品和消耗储值都按照此积分倍数增加积分

会员日积分加速：当门店有会员日或者有活动日时可以根据需要设置，会员当日会额外获得积分，会员日积分加速 获得积分=赠送积分*会员级别积分倍数*会员日积分倍数
