1.使用场景

（1）当场地使用钻石V2卡头，液晶版卡头，且会员可以直接通过扫码扣币的方式启动机台时。成人电玩追求快速上分，比较少用这种方案。儿童乐园以及乐园外场相对较多。

（2）扫码游戏支持散客、会员以及“散客 会员”三种模式，一般门店内适用于仅会员的模式，避免部分顾客因为支持手机临时游戏，减少会员充值；而无人值的外场等则更适合使用散客模式，减少人工投入，实现顾客即玩即走；既有门店，又有外场的店，建议店内机台仅会员，店外机台使用兼容模式，既满足散客即玩即走，也能满足会员对内外场通用的需求。

（3）针对外场设备的管理，若门店局域网无法覆盖到，则需要联系油菜花客户经理开通域名（连卡头版），一遍卡头可以访问服务器。

3.关键参数

（1）适用人群：无限制，指散客扫码可以直接微信付款，会员扫码可以扣会员开卡储值（预存款/代币/金币）；当会员卡余额不足时，会直接跳转到微信支付页面，会员卡储值余额满足最低扣费时，点击更高的扣费系统提示充值。

a.会员扫码，余额不足时 b.会员扫码，储值余额介于最低值和更高值之间时

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e101798dfcc5fd239b&type=med)

（2）启动次数：指要启动游戏机的次数，系统按照这个次数告知卡头发送对应脉冲数给机台，以启动游戏机。

（3）游戏名称：游戏名称是自定义的，一般设置的是为"XX币/YY局”或“XX元/YY局”，为了便于顾客理解，模拟机等一局有固定时长也可以设置一局多少时长、两局多少时长。

4.活学活用

案例：武汉赛尔之城是如何用扫码游戏方案实现外场移动项目（小火车等）扫码扣费和员工绩效核算的？

需求：赛尔之城是门店 外场的运营模式，外场设备有固定的（蹦床、木马等）和移动的（小火车）两种，外场员工的绩效核算有按售卖核算和按核销核算两种方式。

难点：a.内场、外场储值通用，需要实现内场、外场系统统一

b.外场布网、取电、以及员工安全要求实现扫码购买、扫码核销

实现：a.扫码售卖：使用导购员或分销功能，将导购或分销员二维码印刷出来即可实现扫码售卖和员工绩效自动核算

b.扫码核销：将员工作为游乐项目，项目作为游戏名称，核销之后，将消耗的游戏币数量记录到每个员工头上，以便核算员工收入。
