如何设置收银台兑换不需要/需要输入会员卡密码？

��应用场景

为了节省时间，提高效率，可设置在会员收银台进行该操作时，不需要输入会员密码

��操作流程

路径：收银台→更多→通用设置

在【通用设置】界面中，需要会员密码验证一栏找到【兑换】，取消勾选，点击【确认】完成设置。
