# 前言说明：

1.本次置换客户非常重要，属于本年中最重要的项目（没有之一）

2.本次置换系统前因是因为多奇妙（新城集团）将60+门店转卖给天空之城，在完成交接后，需要快速切换系统改为油菜花系统，切断翠花系统的使用。

3.本次置换由油菜花技术负责系统部分、网络部分以及改造部分的工作，卡头安装工作交给天空之城机修负责。所有硬件的不能再有翠花标示。

4.本次置换目标在11月底内完成置换。

原套票导入说明：

（2023年11月23日更新）

•原计次票需要区分种类：

历史导入次数（普通票） 没有限制使用

历史导入次数（双宝卡）没有限制使用，仅名字不一致

历史导入次数（周间票）限制周一到周五，其他功能保持不变

•原计次票需要区分种类：

历史导入期限票（普通票） 没有限制使用

历史导入期限票（双宝卡）没有限制使用，仅名字不一致

历史导入期限票（周间票）限制周一到周五，其他功能保持不变

导入数据标准说明：

1.会员数据来源：最终数据会通过企业微信群中的陈荣同步出来。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf4c6290f2887&type=med)

•会员币信息
•计次会员票务信息
•计时会员票务信息
•商品库存查询
币单价在备注.txt文件中，其中商品资料导入，只导入库存大于0的商品， 库存数量是否准确，取决于交割前门店是否已做盘点。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf4c6291b2888&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf4c629252889&type=med)

3.“3_安庆券_20231120” 留档查询使用，不导入系统。

4.对于“100日币兑换券”处理方法是：系统建一个代币有效期只有当天有效的0元套餐，查EXCEL 确认是否领取，0元售卖并做好登记，12月底彻底截至，之后就不用了。

5.《4_会员对应卡号_20231120》 只是备份存档用，不需要导入系统

6.会员级别 、会员有效期， 根据场地要求 微调，密码默认****（已脱敏，请向运维索取），如果提供资料缺少这部分资料，请自行补充

7.其他类型的券需和门店沟通确认领取方式。

8.商品库存信息中的商品分类和供应商 如果需要，则需提前在油菜花系统录入。

9.手机列 一定要对应手机号，可以为空

10.会员号列， 优先取会员卡号， 如果没有领卡的会员， 可以填手机号， 如果一个 会员有多个 卡号的， 填其中一个卡号， 其他卡号 填到备注列

11.会员次票、年票 中的“会员号” 必须和 “会员币信息” 表中的“会员号”完全匹配，例如有多个卡号的， 币信息 取的是哪个， 套票信息也要取哪一个。

12.会员号必须唯一

13.数据确认：

会员资料查询，确认导入会员数量、查询会员储值余额，确认会员储值余额信息、会员套票查询 确认次票、年票导入数量与剩余次数信息。

抽查一部分会员号，手机号，储值余额，套票余额数据是否与excel 一致。

# 系统设置（由门店负责人设置，技术辅助设置），以下参数仅供参考，具体根据实际门店要求来定

1、设置初始化资料（收银终端、员工权限、收银员账号、出入库类型、其他支付方式等）

•收银终端：预设三个，分别为【一号收银台】、【二号收银台】、【三号收银台】，且均绑定主仓库

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf12d2e88000e&type=med)

•员工权限：预设总部财务、手机报表、仓管、经理、收银员权限，权限截图如下：

•总部财务：仅提供管理后台所有查询权限（设置无任何权限）

•手机报表：仅勾选手机报表一项权限

•仓管：仅勾选仓库相关权限以及商品资料中零售商品编辑权限

•经理：前台仅勾选【通用】、【订单】、【更多】、【交账】、【套票】功能；后台除【设置】外所有功能

•收银员：默认收银权限

•管理员：所有权限

2、配置微信支付和支付宝支付，以及其他支付（收钱吧等），并将高频使用的支付方式放在第一位；【其他】支付类型开启实点

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf12d2e96000f&type=med)

3、预设置常见项目（淘气堡）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148a1afdff018bf12d2e9f0010&type=med)

注意：淘气堡项目需要设置两个，分别是闸机类型的淘气堡（用于绑定闸机）和模拟机类型的淘气堡扣币（用于直接扣淘气堡币），原因为实际使用场景下，会存在年卡会员带其他人进场游玩情况，需要有单独卡头直接扣币。

4、预设置常规套餐---部分门店情况不一样，请根据部分不同门店不同要求设置。

•入会套餐：名称：开卡入会，价格为0，不作绑定，会员级别为普通卡，名字和手机号必填

•电竞卡：游戏币套餐，售币类型自动，其他默认，命名规则：200元=180币（例）

•畅玩卡：组合套餐，淘气堡计次票+游戏币套餐，命名规则：淘气堡2次票+100游戏币

•淘气宝畅玩卡：计次票，期限票

•开卡套餐：开卡5元=5币

•其他套餐：①商城积分换20币--游戏币套餐，0元，有效期为1天；②100日币（199权益卡）--游戏币套餐，0元，有效期为1天。

•会员日赠币：活动赠币，周三赠送30币当日有效

•补卡/换卡费用：补卡5元，换卡0元。

5、小程序上架套餐

•会员入会：默认自动入会，级别设置普通卡，有效期3650天

•门店资料维护：填写门店具体信息和定位

•商品资料维护：发布常规套餐，特别注意畅玩卡套餐需要增加有效期说明

# 6、培训要求

说明：由于原多奇妙店长不确定是否预留下来，所以是否需要培训原店长由天空之城负责人确认，其他人员培训请按照下列要求来培训。

•收银员：旧会员更新使用（重点培训）、开卡、充值、兑换、订单处理、前台扣费、交账

•收银主管：收银员基础上增加交账对账和做实。

•仓管：库存录入、库存盘点

•经理：收银员内容+收银主管内容+后台报表查询

•管理员（目标人群是天空之城店长代管）：重点培训套票设置、营销活动

其他说明：

1、原宝点的 新空白卡，需要到 第三方转卡界面转卡后， 再去开卡入会才能识别卡片， 收银台需上外网，会消耗转换额度。【注意先手动替换最新的 收银台DLL，后面新版本发布后就不用手工替换】。
2、客人手里的已开会员卡，建议是先通过手机号 或会员卡号 查询会员资料，确认余额、次卡、年卡正确后，再去补卡换卡界面进行换卡操作，避免 客人报错手机号， 比如，爸爸有一个手机号， 里面也有会员，但是储值为0， 妈妈有一个手机号，里面有储值 有年卡， 这种情况下，如果不先先查询确认一下会员账户线下，很容易补错卡； 同样 先 第三方转卡后，再通过手机号 或卡号搜索到正确的会员，再进行换卡。
3、补卡丹阳店是5元， 换卡是0元。
4、原会员有多张卡的，可以设置一个 0 代币 开副卡。
