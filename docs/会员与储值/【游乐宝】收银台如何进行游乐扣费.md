# 应用场景

针对小型场地没有使用任何刷卡设备的情况下，可以使用收银台刷卡功能来扣会员卡里的游戏币或者扣会员卡内的套餐次数。

# 基本操作流程

进入收银台界面-游乐-机台扣费-选择游乐项目-读取会员卡-会员信息确认-刷卡扣费

## 当顾客会员卡里面有套票会优先扣套票，没有套票会扣项目设置对应的储值数量。

# 注意事项

项目需要在后台建立好游戏项目而且添加端口后才能在此业务操作。

此功能只能代替扣费功能，并不能启动机台。
