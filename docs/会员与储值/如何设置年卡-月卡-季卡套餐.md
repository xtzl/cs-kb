# 应用场景
年卡、月卡、季卡属于在规定时间内可以在指定项目任意游玩的套餐，如果门店想设置此类套餐，可以按照下述步骤进行设置。

# 操作流程
路径：商品→游乐套票

#### 进入【游乐套票】的界面，点击【新增期限票】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718432188823-67defac5-00bc-4700-8223-5db23abd6550.png)

#### 按照下图中的描述对期限票进行参数填写，点击【确定】完成新增
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718432780946-cb58e33a-f0c6-420a-ab52-7e079502cd3e.png)
