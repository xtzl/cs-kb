# 漫游支持哪些类型储值 ？

答：游乐宝目前支持会员的预存款，金币，代币，积分，彩票等储值类型的漫游，暂时不支持彩票漫游

# 如何查看是否允许了该类型储值漫游？

路径：后台--设置--储值漫游配置--漫游设置
勾选了就代表允许改储值漫游
