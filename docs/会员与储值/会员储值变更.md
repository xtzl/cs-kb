# 一.功能概况

储值变更主要是用于查看会员的储值充值使用变更话情况

# 二.业务价值

## 便于查询会员详细储值变更情况

储值变更查询属于综合类报表，在对会员储值变化有疑问时，我们可以通过储值变更查询对应会员的储值获取情况，表内会详细标明会员储值获取和使用情况，这样可以更快了解当前会员的储值变化
