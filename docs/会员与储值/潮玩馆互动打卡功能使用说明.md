# 功能说明
潮玩馆互动打卡功能依托互动打卡终端硬件，可自主配置线下游玩项目的游戏规则与分数核算逻辑，同时支持玩家完成任务、解锁成就后自动发放对应奖励。  

## **<font style="color:#333333;">项目游戏设置说明</font>**
### **<font style="color:#333333;">总体概述</font>**
<font style="color:#333333;">项目游戏设置用于定义单款游玩项目的通关判定规则与分数计算逻辑，玩家达成设定条件后判定游戏结束，并发放对应分数奖励。  </font>

### **<font style="color:#333333;"> 核心字段释义</font>**
![运动终端设置基础界面](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314495193-63b70a3c-a848-4153-b422-9b85dae49a6f.jpeg)

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">基础外观配置</font>**
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">项目名称：自定义当前游玩项目名称，如「迷路之馆 (迷宫)」；</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">跑灯颜色、灯带底色：设置打卡终端灯光展示配色。</font>
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">打卡终端管理</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 支持新增打卡点位，标记</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">起点终端</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">为计时启动节点、</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">终点终端</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">为本局游戏结束节点，在该设置内可统一调整打卡顺序、添加打卡设备、添加打卡点分值（打卡得分功能开启时）以及删除打卡设备。</font>
3. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">打卡得分</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 开启后，玩家每完成一次终端打卡即可获取对应分值，细分 3 种打卡计分规则： </font>
+ **<font style="color:#FFFFFF;background-color:#DF2A3F;">随机打卡，分数相加</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：单独为每个点位配置分值，完成打卡后累加分数；可设置「有效最少打卡数」（未达标无成绩）、「累计封顶分」；同一个终端仅能计分 1 次，重复打卡不重复加分。</font>
+ **<font style="color:#FFFFFF;background-color:#DF2A3F;">顺序打卡，分数相加</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：各点位独立设置分值，玩家必须严格按预设顺序打卡，跳序打卡判定无效，界面标红叉，所有合规打卡分数累加。</font>
+ **<font style="color:#FFFFFF;background-color:#DF2A3F;">取最高的一个打卡点分数</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：仅结算本局难度最高、分值最大的打卡点分数，其余点位不计入总分。</font>
4. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">计时得分</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 开启后，系统自动统计「起点打卡」至「终点打卡」的总耗时，依据预设时长阶梯一次性结算额外时间奖励分。 </font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">计时规则：可新增多组阶梯区间，设置对应时长范围匹配的得分，支持 “用时越短分越高” 或 “用时越长分越高” 两种计分逻辑。</font>
5. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">总分计算</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 本局最终得分 = 打卡得分 + 计时得分，同时可配置本项目全局最高分上限。</font>
6. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">游戏超时</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 设定本局最大游玩时长，到达时限直接结束结算，超时后再次打卡不再新增分数。 </font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">勾选「超时没有成绩」：超时后本局所有打卡、计时得分全部清零；</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">不勾选「超时没有成绩」：超时后结算当前已获取的全部分数。</font>
7. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">特殊限制逻辑</font>**
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">仅配置 1 个打卡终端时，</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">计时得分、超时没有成绩</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">两项功能无法启用；</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">若只需设置打卡分数封顶，可将「有效至少打卡数」填 0，仅配置累计封顶分值即可。</font>

### **<font style="color:#333333;">场景一：顺序闯关迷宫（固定路线打卡 + 用时加分）  </font>**
**<font style="color:#333333;">案例场景：</font>**<font style="color:#333333;"> 玩家沿固定路线依次打卡迷宫点位，每打卡一处获得固定分值，完成全部路线后，用时越短额外时间分越高。  </font>

**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">配置步骤</font>**<font style="color:#333333;">：  </font>

1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开启「打卡得分」，打卡规则选择</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">顺序打卡，分数相加</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，逐个录入每个打卡点对应分值；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开启「计时得分」，新增多组时长阶梯，时长数值越小、对应得分越高；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">按需设置游戏超时时长，可勾选「超时没有成绩」。</font>

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314495477-982f01d1-a0ee-4cb6-840a-d56496388d1d.jpeg)

### **<font style="color:#333333;">场景二：随机寻宝（最低打卡数量要求 + 时间额外奖励）</font>**
**<font style="color:#333333;">案例场景：</font>**<font style="color:#333333;">区域内随机分布打卡宝藏，需找到指定数量宝藏才算通关，全部打卡完成后，耗时达标可领取额外时间奖励。</font>

**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">配置步骤</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>

1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开启「打卡得分」，打卡规则选择</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">随机打卡，分数相加</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">；填写「有效打卡数至少 X 个」，未达标无成绩，设置本局总分封顶值；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开启「计时得分」，配置时长阶梯，全部打卡完成后才结算时间奖励；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">设置游戏超时时长，</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">禁止勾选「超时没有成绩」</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，超时可结算已完成打卡分数。</font>

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314495830-aea55694-2d19-4513-aa73-2dbd0a1315bc.jpeg)

### **<font style="color:#333333;">场景三：难度分级攀爬（仅取最高难度打卡分，无计时）</font>**
**<font style="color:#333333;">案例场景：</font>**<font style="color:#333333;">不同打卡点位对应不同攀爬难度，难度越高分值越高，玩家自由挑战点位，最终仅结算本局完成的最高难度点位分数，不统计用时。</font>

**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">配置步骤</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：</font>

1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">开启「打卡得分」，打卡规则选择</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">取最高的一个打卡点分数</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，按点位难度设置对应分值；</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">关闭「计时得分」；</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">游戏超时填 0，即不限制游玩时长。</font>

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314496189-7d4ad7bb-9f31-42d8-b031-5391988e99d7.jpeg)

### **<font style="color:#333333;">场景四：纯计时竞速（无打卡分，仅按通关时长计分）</font>**
**<font style="color:#333333;">案例场景</font>**<font style="color:#333333;">：障碍跑、耐力举重类项目，仅统计起点至终点总时长，完全依靠耗时结算分数，无打卡点位分值。</font>

**<font style="color:#333333;">配置步骤</font>**<font style="color:#333333;">：</font>

<font style="color:#333333;">关闭「打卡得分」；</font>

<font style="color:#333333;">开启「计时得分」，自定义时长阶梯匹配对应得分；</font>

<font style="color:#333333;">设置游戏超时上限，勾选「超时没有成绩」，超时直接判定本局无效。</font>

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314496421-aa0eb283-548d-493b-8eb0-a1552314112f.jpeg)

## **<font style="color:#333333;">得分后奖励配置（任务 + 成就）</font>**
### **<font style="color:#333333;">总体概述</font>**
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">打卡游玩可设置两类奖励：</font>

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">任务奖励</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：发放储值类奖励（金币、代币、积分、能量、彩票）和经验类奖励（成长值）；</font>
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">成就奖励</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：解锁勋章、额外储值 / 成长值。</font>

### 通用玩法拓展答疑
1. 如何自定义能力值体系？

不使用原有储值名称，将代币 / 金币等储值类型重命名为力量、敏捷、耐力等属性，玩家可在「新运动馆」小程序查看自身属性数值，直观体现游玩能力。

2. 如何实现玩家等级成长体系？

配置任务 / 成就时勾选「奖励同等数量的成长值」，再开启后台「会员自动升级」功能，形成「游玩得分→完成任务→获取成长值→累积升级」闭环，可自定义新手、学徒、资深、大宗师等段位。

3. 能力值商业化玩法

玩家可消耗指定能力值兑换礼品、稀有道具，提升复购意愿。

4. 玩家查询入口

「新运动馆」小程序 - 任务模块，可查看全部任务、成就、属性数值；任务领取机刷卡可查看个人成绩与任务进度。

+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">按得分倍数奖励：本局总分乘以固定倍率，换算为对应储值数量；</font>

+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">每天最多一次：单项目每日仅能领取 1 次奖励；多次游玩刷新更高成绩时，自动补发新旧成绩奖励差额；</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">每次：每完成一局游戏，均可领取一次对应奖励。</font>

###   成就模块字段说明  
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 成就为长期累积奖励，可与单次任务奖励叠加领取，满足累计总分条件即可解锁勋章。  </font>

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314497269-5cd3d998-0dee-449c-88bb-7d10de13a265.jpeg)

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">启用成就</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：开关控制该项目勋章体系是否生效；</font>
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">成就名称</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：自定义勋章标题；</font>
3. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">达成条件</font>**
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">总分（通用）：玩家所有游玩记录累计总分达标即可解锁；</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">分项得分 1-4：仅对接第三方专用设备时可用，普通场景仅支持总分判定；</font>
4. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">有效期</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：勋章在玩家小程序内展示的时长；</font>
5. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">奖励</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：解锁勋章发放对应储值，可勾选同步发放等额成长值；</font>
6. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">成就图库选择</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：上传对应勋章图标，展示在小程序「我的成就」页面。</font>

### **<font style="color:#333333;">场景二： 得分自动兑换积分，每日仅领 1 次</font>**
配置：任务规则选「按得分倍数奖励」，奖励类型设为积分；奖励周期选择「每天最多一次」，当日多次游玩仅结算最优成绩奖励。  

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1785314499087-af88a6f9-2cab-483e-95c0-c57d59ffd700.png)

### **<font style="color:#333333;">场景三： 每局按分数区间发放固定积分</font>**
配置：任务规则选「阶梯规则」，新增多档分数区间与对应积分；奖励周期选择「每次」，每完成一局均可领取奖励。  

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1785314499389-b63b8830-a844-4f33-a976-883bef771b19.jpeg)

### **<font style="color:#333333;">场景四： 游玩获取经验，累积升级</font>**
配置：任务 / 成就内勾选「奖励同等数量的成长值」；后台开启「会员自动升降级」，设置各等级所需成长值门槛。 参考文档：[会员升降级设置](https://ychylb.yuque.com/staff-gcg8pk/ylgj/ql0u654pgrpesfez)

 配置：开启成就，达成条件设置「总分≥指定数值」，上传勋章图片，按需叠加储值奖励。
