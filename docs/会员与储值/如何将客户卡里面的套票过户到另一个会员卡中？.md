# 应用场景
当套票有剩余次数或想保留，或想转给某个会员，可通过套票过户的功能，将套票转到其他用户账号

# 操作流程
路径：收银台→套票→套票查询→套票过户

#### 登录收银台，点击左边菜单栏【套票】，根据查询条件筛选到指定套票，选中点击，在套票信息界面点击【过户】，在弹窗界面，输入要过户的会员账号，点击【过户】
