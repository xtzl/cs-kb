# 应用场景
会员想要查询自己的会员账户开了多少张副卡，该如何查询？

# 操作流程
路径：收银台-会员-主副卡管理

**在【会员】界面，搜索到该会员，点击编辑资料右侧的展开按钮，找到主副卡管理，点击进去**

**进去即可查看到会员拥有的副卡数量**
