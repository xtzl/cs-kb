# 应用场景
顾客购买商品获得积分，累计一定积分可以兑换礼品。

# 操作流程
## 一、会员如何获得积分？
### 1.[如何设置会员积分赠送策略？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/erx3x52vactcwnm2)
### 2.[如何通过小程序签到获得积分？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/rgs3ptdvdth5s8os)
### 3.购买指定套餐获得积分
路径：门店后台--营销--充值赠送

    1. 点击新增选择对应商品；
    2. 赠送类型勾选积分并填写赠送积分；
    3. 赠送规则选择“购买赠送”；
    4. 赠送周期选择“立即赠送”。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719743087397-f1891b2b-d404-4b43-9ad7-6246ff3b801b.png)



### 4.如何设置会员到店赠送积分？
路径：门店后台--营销--活动赠送

    1. 点击新增，填写活动名称；
    2. 设置赠送积分数量；
    3. 填写方案活动开始时间以及结束时间；
    4. 适用于散客，选择否；
    5. 设置可用会员级别，勾选代币允许参与赠送积分；
    6. 设置赠送周期。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719743810190-ecb157be-6bc2-4874-893b-10d46f5d4030.png)

#### 收银台如何给会员签到？
**路径：**收银台--商品--活动赠送

读取会员卡、输入会员卡号或会员手机号，识别到会员信息，选择可赠送方案，点击赠送即可。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719743867888-ebeaefba-7e9b-493b-ba08-839bceb35cd1.png)

## 二、会员积分如何使用？
### 1、会员如何使用积分在收银台兑换礼品？
**路径：**收银台--商品--兑换商品--积分兑换

读取会员卡、输入会员卡号或会员手机号，识别到会员信息，选择兑换礼品，点击兑换即可。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719744099138-f5bbb1d8-a7e8-4a46-9209-77c8df7adee7.png)

### 2.小程序上如何兑换礼品？
小程序--首页--兑换中心里兑换门店自有礼品

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719745554661-078f3abd-b72d-4119-ac3e-e2840394e51f.png)
