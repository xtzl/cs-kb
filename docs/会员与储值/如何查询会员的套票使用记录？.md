# 应用场景
适用于门店需要查询会员套票目前的一个使用状态，统计未使用、使用中或已使用的套票数据。

# 操作流程
路径：报表→套票类→套票使用记录

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718706435186-0803d6ed-ece2-4182-81fc-3e1dbe9aac03.png)

# 常见问题
问：如何查询某个时间段每个会员不同套票的使用情况？

答：点击 使用时间 后面的方框，选择查询的日期，点击查询，选择“按会员卡号汇总”  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719503579385-7b33b23a-4272-41d1-8351-09d24b798d26.png)
