# 会员验票过闸

1.会员在买完票后可以绑定票码，也可以不绑定票码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019777e05dc10313&type=max)

2.验票过闸路径：游乐 > 验票过闸

选择入闸、会员，选上对应的项目，读取会员后就可以自动识别到会员账户里的套票，点击过闸既可以

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019777e02e930311&type=max)

# 散客验票过闸

1.散客在收银台买过票之后，需要绑定一下票码或者腕带

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019777e991ab0331&type=max)

2.在验票过闸这里选择入闸、散客、选择项目，输入票码点击查询就可以识别到票，点击过闸将票的次数使用掉

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019777e966080330&type=max)

# 常见问题汇总

1.问：有票的情况下，怎么使用储值进行过闸？

答：当会员账户里有票且可用的情况下，系统会优先选择票进行过闸。如果不想使用套票进行过闸，可以点击套票使其处于未选中状态，这时再点击过闸就可以进行扣储值过闸了。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c9084a1963f4400019777efdfcc034a&type=max)

2.问：什么时候进行游玩的都可以取消游乐扣费吗？

答：只有账期还没有做实的才可以取消游玩记录返还次数。
