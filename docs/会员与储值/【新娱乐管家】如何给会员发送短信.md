# 1、如何给会员发送短信

1.1.步骤：会员---发送短信---筛选发送条件---勾选指定会员---发送短信

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018cd2541a507c26&type=med)

# 2、注意事项

（1）如未开通短信服务，需要联系销售人员先开通短信服务才能正常发送短信

（2）避免短信发送失败，建议短信格式为：：“尊敬的用户，XXXXXX短信内容，拒收请回复R”

（3）一旦短信的内容超过70个字，例如70到140字之间，在我们系统会显示只发送一条短信，手机端也会收到一条短信，但是短信条数会扣两条。因为短信的条数扣值，运营商是按照70个字为一条计算费用，超过就属于长短信。超过70字在140字以内是按照两条计费，210字按照3条，以此类推。
