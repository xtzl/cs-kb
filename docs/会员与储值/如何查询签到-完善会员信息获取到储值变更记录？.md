# 常见问题
问：如何查询签到会员获得储值的数据？

答：在 备注 这一查询条件里，填写“小程序签到”，点击查询

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719500757333-ed0674a1-5c26-4904-94dd-95824737b053.png)



问：如何查询完善会员信息获得储值的数据？

答：在 备注 这一查询条件里，填写“完善资料”，点击查询  
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1719500341577-b31942c3-179b-4bf6-b4f8-c551caf46715.png)
