# 应用场景
顾客在游玩过程中临时存入卡头内，后续顾客忘记暂存多少彩票，门店可以通过彩票暂存功能查询对应会员当时存的彩票数

# 操作流程
路径：会员**→**储值查询**→**彩票暂存记录

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718786082237-a3dfbe30-462f-4a24-a0a2-18bd504ac1d3.png)

# 常见问题
问：顾客在想游玩但是没有带实体卡，需要先将彩票暂存一下，后续带实体卡再将彩票存入会员？

答：前提：对于游乐项目设置彩票暂存模式

顾客游玩后暂时存入卡头，后续在后台彩票暂存记录查询对应会员存的彩票数，根据对应数量存入到会员卡内
