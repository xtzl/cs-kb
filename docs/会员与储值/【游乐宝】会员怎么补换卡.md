# 会员怎么补卡

1》路径：

1）：收银台--商品--售卖商品--快捷功能--会员补卡

2）：收银台--会员--会员查询--编辑资料--补换卡

2》步骤： 点击对应的操作功能，查询到相应会员，然后读取新的会员卡号，点击补卡即可

# 会员怎么换卡：

注意事项：导入的会员信息，不能直接换卡，需要先补卡才能换卡

1》路径：

1）：收银台--商品--售卖商品--快捷功能--会员补卡

2）：收银台--会员--会员查询--编辑资料--补换卡

2》步骤： 点击对应的操作功能，查询到相应会员，然后读取新的会员卡号，点击换卡即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b824fbdd574c6&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017b824d09d074c4&type=max)

# 怎么设置补卡和换卡价格

1》路径：后台--会员--会员级别

2》步骤：找到对应的会员级别，填写好对应补卡和换卡价格即可
