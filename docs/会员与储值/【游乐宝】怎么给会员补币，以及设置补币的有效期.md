# 怎么给会员补币

1》路径：

1)商品--售卖商品--补币功能
2)收银台--会员--补币
2》步骤： 点开补币功能，选择补币的类型，填写补币数量和原因，然后点击存会员卡

注意：游乐宝补币支持给客户补金币和代币（游戏币 ），需要补哪种就填写对应的数量即可

## 设置补币的代币有效期（根据场地经营模式设置，非必要，默认永久有效），

1》路径：游乐宝后台--设置--代币设置--补币有效期设置
2》步骤： 设置补币有效期的规则后点击保存
注意：再设置补币的有效期规则，补币数量需要递增否则无法保存，系统会提示次级大的币数要小于次级小的币数

## 补币数量不对，或者因为其他原因需要取消怎么取消

1》路径：收银台--会员--补币--历史补币记录

2》步骤：在历史补币记录里面找到需要取消的补币记录，选中后点击确认取消
