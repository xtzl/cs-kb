# 应用场景
将客户A会员卡里的储值过户到客户B的会员卡里面

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-储值过户

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击储值过户，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593581653-1e3f517c-c959-4ca1-a029-faae83993494.png)

#### 读取过户的目标会议账号-输入需要过户的储值数量，点击过户，如下图所示：
