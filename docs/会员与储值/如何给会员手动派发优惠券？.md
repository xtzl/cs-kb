# 应用场景
针对于门店需要给某特定会员进行派送优惠劵，可以进行手动派发优惠劵

# 操作流程
路径：营销**→**优惠劵

#### 1、选择对应优惠券，点击后面的派券，勾选需要派券的会员，此操作可以通过在界面查询出会员进行勾选派发，也可以通过导入会员的方式派发；
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718699314094-d5459ba1-47ee-4441-9f86-d5044684044f.png)

#### 2、手动勾选会员需在界面填写派发张数，点击确定即可。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718699540959-6ca9c605-4d7b-440f-a0b8-1a958b6c68b8.png)

#### 3、导入派发的话可以下载还模版，将模版填写好后进行导入派发。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718699638456-ea3c2c16-8ef5-44cf-9d8e-f6f72e94400d.png)

# 常见问题
1、如果派发优惠劵之后需要进行撤回的话，营销——优惠劵查询——找到派送的记录，勾选，点击作废
