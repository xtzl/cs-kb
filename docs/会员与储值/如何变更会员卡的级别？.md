# 应用场景
给单个会员或者重要客户修改会员级别

# 操作流程
路径：登录娱乐管家收银台-会员-会员资料-级别变更

#### 登录娱乐管家收银台-会员-会员资料-输入会员手机号/扫描会员二维码-点击编辑资料旁的下拉列表-点击级别变更，如下图所示：
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718593120256-52d62331-4aa3-4f9e-92f8-6402272b20a0.png)
