# 一、作业说明

本文章主要解答切换系统时的常见问题

# 二、常见问题

1.原顾客的会员卡，切换系统后还能使用吗？

答：不能，由于每家系统的IC卡加密不一样，所以不同厂商的IC卡是不能用于我们系统，而且我们也无法破解加密，只能将原会员卡回收，通过我们系统使用前台【换卡】功能来进行换卡。

2.切换系统后，收银员应该怎么操作换卡？

答：一般导入系统至少会导入原会员卡号、会员名称、手机号其中之一，收银员可在前台的【会员资料查询】中用其中一个资料找回原会员，然后通过【换卡】功能进行换卡。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d1211d8b128b2&type=med)

3.假如客户不想让顾客进行换卡，希望能实现无卡化，请问该怎么做？

答：可以通过小程序进行绑定，让顾客用会员码进行消费。具体操作是：①需要导入资料是必须导入会员手机号，由于系统是通过手机号和微信绑定的手机号进行关联的，所以如果在导入过程中没有导入手机号则无法完成关联，补救方法为查询该会员在我们系统上的会员资料，然后修正会员的手机号，再让顾客进行绑定。②告知客户将小程序二维码粘贴到显眼位置，并指引客户只要扫码后点击几下授权即可快速完成绑定。③根据客户场地的设备调整小程序下方的快捷按钮是扫一扫还是会员码，大多数情况下建议调成直接显示会员码，仅在全场只有钻石V2的情况下才有可能改成扫一扫模式。④测试全场的会员码或者扫一扫功能是否都能正常使用。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d1211d8c028b3&type=med)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d1211d8d028b4&type=med)

4.客户想问他们原来的设备是否能改一下就能使用？

答：大部分情况下是不能，即使可以，里面的所有的主板、线路、电源全部都需要更换，而且显示屏尺寸也不一致，改完之后外观十分的丑，且费用也不一定比新买的便宜多少，另外设备改装需要发回工厂那边改装才能正常使用，这个还涉及到来回运费问题。总体来说不建议改装。

5.之前系统的订单能查看吗？可以导入到系统吗？

答：原系统的订单不能在新系统上查看，但是可以在原系统上查看，原来系统的数据还是保留在原系统上。但是不能导入到新系统，因为两套系统架构不一样。

6.客户对币单价/币价值比较注重，那系统能体现原系统的币储值情况吗？

答，可以，在导入前，需要客户自行统计原系统币单价是多少。一般计算方式为：所有币套餐购买的金额/所有会员的币数量=币单价

在导入会员资料的界面中，在导入前设置对应的币单价后再导入即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e7c2a7f02017d1211d8df28b5&type=med)

7.客户想对票单价进行核算，可以实现不？

答：暂时不支持。因为票导入进去之后是不产生任何价值的，所以也不会产生对应的消费金额。

8.如果数据导入之后发现错了怎么办？

答：将导入前的数据库备份还原。重新导入一次

9.会员数据一次最多可以导入多少条数据？

答：建议不要超过1W条数据

10.顾客想查之前的消费记录怎么办？

答：通过旧系统进行查看。

11.导入后的会员都会带【须换卡】，如果要去掉怎么办？

答：数据库执行 update Mall_LeaguerBase set RealName =REPLACE(RealName,'[须换卡]','')

12.客户原来旧的其他系统会员卡，经过我们测试可以进行转换，那应该怎么转换成油菜花会员卡？

答：游乐宝版本高于8.1.6785的情况下：

打开收银台，更多-通用设置-打开第三方转换卡

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0f075c7225c1&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148bf72a08018c0f07e5dd25c3&type=max)

低于8.1.6785的情况下：开启第三方转换卡功能，操作步骤如下：http://kms.gzych.vip/webdoc/real/Pub2c93a81480a4846c01822398cb0074cd.html?STATE=0&OPERATE=3

13.如果导入会员后发现会员数据是错的，那改怎么办？

答：

娱乐管家连锁/多商户：无法删除也无法重新导入

游乐宝单店/娱乐管家单店：在数据库执行以下语句

SELECT * FROM Mall_LeaguerBase

update Mall_LeaguerBase set IsDelete=1,LeaguerCode=LeaguerCode+'[已删除]' where Summary='[导入会员]' and CreateTime <='2023-08-26 14:11:00.000'

说明：其中 语句中的时间则代表仅删除这个时间节点之前的会员数据。
