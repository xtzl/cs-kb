# 应用场景
在总部可以统一设置入会套餐，并下发到对应的连锁门店中，可参考下述流程进行设置。

# 操作流程
路径：总部后台→商品→入会套餐

在【入会套餐】界面中，选择【+新增】

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721549372614-f0daf83e-a58c-4639-af67-01e26726d6da.png)

在新增界面中按下图说明进行填写，点击【确定】完成新增

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721549650334-a16e0712-6eac-4f81-bfa6-f91d4dfff716.png)
