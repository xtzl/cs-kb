# 应用场景
在系统上已经建立了[岗位权限](https://ychylb.yuque.com/staff-gcg8pk/ylgj/thh3hydi5pw0c8ll)后，如何给对应岗位的员工新增登录账号。

# 操作流程
路径：登录娱乐管家后台-用户管理-新增用户

#### 按照路径进入到对应的界面，并点击【新增用户】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717813645055-7287c997-7e97-4b0c-9d70-e626759042d9.png)

#### 根据下图说明填写对应的信息，点击确定完成添加
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717813837170-06908522-1fb2-43fd-9e72-4623b3361070.png)

#### 再次点击编辑可修改账号信息，并支持开通员工卡、机修卡等系统内置功能卡
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717814081349-0643bdb9-46e8-4928-8cc2-c03b85d160ef.png)

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717814105991-70d4baa1-2623-41a5-879f-57031756fe6c.png)
