# 员工卡使用场景

油菜花系统中，员工卡一共有以下两种场景：

- 作为授权卡。假设A员工开通了员工卡，当用户需要A员工授权操作的时候，A员工可以刷他的员工卡进行授权，不需要输入帐号密码

- 员工绩效卡。启用机台绩效功能后，员工在机台上刷卡，则对应机台的耗币收入会自动归纳到该员工

要注意的是：如果IC卡开成了员工卡，则该IC卡无法再用于会员卡

# 操作路径

后台--设置--员工管理--用户管理

# 操作步骤

在“用户管理”中找到对应的员工资料，点击下图中的“开员工卡“按钮就能开卡（电脑要连接IC卡读卡器，并且把卡放到读卡器上）
