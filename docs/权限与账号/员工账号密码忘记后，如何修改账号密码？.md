# 应用场景
当员工忘记账号的登录密码后，管理员应该如何对其员工账号密码进行重置。

# 操作流程
路径：设置→用户管理→选择需要编辑的账号→直接输入两次新密码→确定

#### 打开用户管理界面，找到对应的需要修改的账号，点账号名称进去后，直接输入两次新密码，点击确定完成重置。
