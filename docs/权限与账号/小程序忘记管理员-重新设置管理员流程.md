一、适用情景：

忘记小程序管理员 或 强制更换小程序管理员

二、准备工作：

1、需确认新的管理员手机号及身份证号码

2、需准备未注册过公众号或小程序的邮箱1个

3、需法人扫脸验证或打开验证（企业需公户打款，个体工商户可法人个人账户打款）

三、操作步骤

1、打开微信公众号官网：https://mp.weixin.qq.com/，选【使用账号登录】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e2c3feb561b&type=med)

2、点击【找回账号或密码】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e2c3ff5561c&type=med)

3、选【找回账号】

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e1b85dc5603&type=max)

4、阅读须知,点击【同意】进入下一步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e1b85f25605&type=max)

5、选择找回的账号类型为【小程序】，输入要找回的小程序的名称或原始ID，点击搜索，进入下一步。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e1b85f85606&type=max)

6、①验证主体，可法人扫脸或支付验证（企业需公户打款，个体工商户可法人本人账号打款）

②重新设置管理员，填写新管理员信息

③输入未注册过公众号和小程序的邮箱（该邮箱号为小程序账号）

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018e2e1b86045608&type=max)

6、填写完资料后，查收新扫码微信号上（即步骤5中填写的新小程序管理员）收到的小程序账号找回的信息通知，并在规定时间内使用企业对公账户打款指定金额至腾讯收方账号验证。

7、法人扫脸或支付验证后，请在找回账号或密码的页面点击【找回密码】，输入小程序的登录邮箱（即步骤5中填写的新邮箱地址）和新管理员扫码。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195a85ddabd13dc&type=max)

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a81490676e700195a85eaa2113e6&type=max)

8、填写邮箱后，页面会提示您登录填写的邮箱中，查收【找回小程序登录密码】的邮件，然后点击邮件中的网页链接地址，根据页面提示完成小程序登录密码置。

9、重置密码后，可返回微信公众平台扫码登录或账号密码登录小程序。
