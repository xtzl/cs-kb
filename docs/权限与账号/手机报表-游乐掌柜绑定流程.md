**应用场景**

<font style="color:rgb(0, 0, 0);">绑定手机报表可给予员工通过手机小程序查看门店的营业数据。</font>

<font style="color:rgb(0, 0, 0);">游乐掌柜是</font><font style="color:rgb(51, 51, 51);">对导购、导玩、机修、仓库、管理授权、等门店的业务集成的小程序</font>

<font style="color:rgb(51, 51, 51);"></font>

<font style="color:rgb(51, 51, 51);"></font>

**操作流程**

# **一、创建员工账号**
<font style="color:rgb(51, 51, 51);">路径：登录娱乐管家后台-用户管理-新增用户</font>

<font style="color:rgb(51, 51, 51);">参考文档：</font>

[如何给员工开账号？](https://ychylb.yuque.com/staff-gcg8pk/ylgj/co8gpynye6zeod1p)

#### 按照路径进入到对应的界面，并点击【新增用户】
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717813645055-7287c997-7e97-4b0c-9d70-e626759042d9.png)

#### 根据下图说明填写对应的信息，并勾选对应的角色权限，点击确定完成添加
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717813837170-06908522-1fb2-43fd-9e72-4623b3361070.png)



# **二、绑定游乐掌柜**
<font style="color:rgb(0, 0, 0);">路径：设置→游乐掌柜</font>

<font style="color:rgb(0, 0, 0);"></font>

1. **<font style="color:rgb(51, 51, 51);">在【游乐掌柜】界面中点击【新增】，打开新增界面，选择已有账号的员工，并勾选对应的权限，以及输入该员工绑定的微信的手机号，点击【保存】完成设置</font>**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1775715695640-d9ec5d64-02c4-4d28-aecf-755a41edd29a.png)

2. **<font style="color:rgb(51, 51, 51);">在【游乐掌柜】界面中点击关注公众号获取消息推送，再用微信扫描二维码</font>**

![](https://cdn.nlark.com/yuque/0/2026/png/1584417/1775716344297-ffdd401b-b654-4306-9906-4cb79e1e9bd3.png)

3. **微信扫码后关注公众号，进入公众号点击前往小程序或者点击下面的游乐掌柜即可进入小程序**

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1775717212332-ccae4303-4d6b-4676-aa4f-d5fe161aa050.jpeg)![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1775717978390-467966a3-4400-4492-90b8-ed1a389832fd.jpeg)![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1775717425521-cddc63be-1abf-417e-b5ff-a5987dc3f026.jpeg)





# **三、绑定手机报表**


1. **打开手机报表功能：路径：进入后台【设置】-【手机报表设置】，在【是否启用手机报表】功能中，选择启用，点击【保存并推送】完成设置**

![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772676804591-c296d460-aa0d-4a8b-84f5-352f83273cfc.png)

2. **在手机报表绑定里面点击用户授权-选择需要授权的用户-点击授权-选择可查询的门店-点击保存，如下图所示：**![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677101608-3e2318b7-32fe-4c2e-8196-5d92b0f33878.png)![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677167387-60afa162-89bf-4c8f-be58-b17554d00b16.png)![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677207441-53c02568-5751-4ea9-a3fd-478e4236bb9c.png)
3. **授权成功之后，点击绑定微信-用微信扫一扫扫描界面上面的二维码，进行绑定手机报表，如下图所示：**![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677322368-fe16decd-3200-4870-98d5-37e9d5115494.png)
4. **手机扫码后点击关注油菜花信息科技这个服务号，进入公众号点击激活并查看手机报表**

![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677699162-32d260b0-0f77-44a7-b46c-519e4feb05af.png)![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772677647676-6ba61b84-2cd6-4a4c-b8b8-86630da2472e.png)

5. **后期查看门店数据可打开该服务号，点击底部的手机报表选择【娱乐管家-新】，进入就可以看到门店营业数据了，如果一个账号绑定了多个门店可以在右上角切换门店查看数据**

![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1775720105014-4dddab00-2fef-4779-afa8-4539443b3311.jpeg)![](https://cdn.nlark.com/yuque/0/2026/jpeg/1584417/1775719832599-978267a6-43fe-45b2-9ee7-d18eaa43ad84.jpeg)





# **四、常见问题**
1. **游乐掌柜中查看数据显示该账号无权限**

检查后台绑定的账号是否有绑定手机报表，如没有按照上面绑定后刷新后在查看

2. **手机报表的数据跟后台的数据对不上**

因为手机报表的数据有大概半小时的延迟

3. **客户查看手机报表中的AI风控提示：**

![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772680564990-031be592-a9d0-479c-877b-44afee0c7f7f.png)

在门店后台填写线上url后提交，线上url就是域名地址可找客服，实施人员查看，示例：[http://加密狗编号.****.youcaihua.net:88](http://78850055.v020.youcaihua.net:88/)/，<font style="color:#DF2A3F;">最后要加/</font>

![](https://cdn.nlark.com/yuque/0/2026/png/34413466/1772680729546-489d426b-7075-4155-8cf9-2e79c8f8825b.png)
