# 一． 收银员角色创建

1. 路径：游乐宝后台-设置-员工管理-角色管理-新增角色

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee057a9d16989&type=max)

进入新增角色信息界面填写角色名称，取消所有操作权限，点击保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee057c1cf698a&type=max)

点击新增的角色，操作端类型选择收银服务台

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee057d865698b&type=max)

点击收银员权限，系统会把收银员的权限自动勾选，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee057f292698c&type=max)

# 二． 收银员账号创建

1. 路径：游乐宝后台-设置-员工管理-用户管理-新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee0580de9698e&type=max)

进入新增用户信息界面，填写用户名，姓名，密码，是否有收银权限选择是。点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee05824a2698f&type=max)

点击保存之后，在用户管理里面可以查看到新增的收银员账号。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee0583e256990&type=max)

2. 常见问题

问题1

场景：收银员账号不能在收银台收银

解决：在创建收银员账号的时候，是否有收银权限选择是

问题2

场景：收银员账号不能给客户补币

解决：在设置收银员角色的时候，没有给与收银员补币权限
