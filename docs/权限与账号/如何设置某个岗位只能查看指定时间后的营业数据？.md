# 应用场景
当门店有部分岗位需要设置不允许查看所有的数据，只允许查看部分数据时，可按此教程设置。

# 操作流程
路径：设置→角色管理

#### 进入【角色管理】界面，选择需要修改的岗位（也就是对应的门店角色）
#### 在编辑界面中，选择【账期权限】中的【仅近期】，并输入可查询的天数，点击【保存】完成设置
