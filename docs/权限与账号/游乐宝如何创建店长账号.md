# 一． 店长角色创建

1. 路径：游乐宝后台-设置-员工管理-角色管理-新增角色

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee05583c86972&type=max)

进入新增角色信息界面填写角色名称，勾选上所有操作权限，点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee0559c646974&type=max)

# 二． 店长账号创建

1. 路径：游乐宝后台-设置-员工管理-用户管理-新增

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee055b5426975&type=max)

进入新增用户信息界面，填写用户名，姓名，密码，是否有收银权限选择是。点击保存即可。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee055c90a6976&type=max)

点击保存之后，在用户管理里面可以查看到新增的店长账号。

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=2c93a8148c3e04c2018ee055e0a96977&type=max)
