# 应用场景
场地开通了游乐掌柜功能后，需要给员工开通游乐掌柜权限，可按照此教程进行开通

# 操作流程
路径：设置→游乐展柜

#### 在【游乐掌柜】界面中点击【新增】，打开新增界面，选择已有账号的员工，并勾选对应的权限，以及输入该员工绑定的微信的手机号，点击【保存】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717817205899-96137d90-7916-4b1b-b8dc-edc44119bf42.png)
