# 应用场景
当门店需要给员工开通机修卡并设置刷卡额度时，可按照此教程进行设置

# 操作流程
路径：终端→机修卡额度设置

#### 在【机修卡额度设置】界面下，勾选对应的门店，选择【设置】，填写日维修额度和月维修额度，以及最大机修卡张数，点击保存完成设置。
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1718608693527-8ae325c9-95ad-41e9-aee2-6044350b6ae9.png)

说明：

①所有机修卡是共用额度，也就是无论开多少张机修卡，如果设置为日额度为100次，当A员工的机修卡当日已经刷卡次数为100次，则B员工的机修卡额度为0.



路径：设置→用户管理

#### 进入【用户管理】界面，选择需要开通机修卡的账号，在编辑界面下，选择【员工卡】类型为“机修卡”，并选择【读卡】，读卡完毕后，点击【确定】完成设置
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717816888936-825ba90e-bf81-4ec8-a5cc-d4fd5d48109d.png)
