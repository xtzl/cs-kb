# 应用场景
如何在娱乐管家系统上建立不同的员工岗位以及设置对应的权限

# 操作流程
路径：登录娱乐管家后台-设置-角色管理-新增

#### 点击新增后，可选择快捷创建角色，如下图所示
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717665146478-9e603214-61b2-49af-9959-e4039c483833.png)

#### 如果需要修改角色权限，可选择不同界面后，勾选需要赋予该职位的权限或者去掉勾选撤掉该职位的权限
![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1717665355874-6a95d77f-63b3-4a3f-b68d-82ee13471189.png)
