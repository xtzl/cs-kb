# 应用场景
当员工不小心将机修卡或者员工卡弄丢了，可以通过下面操作进行补卡。

# 操作流程
路径：设置→用户管理

#### 在【用户管理】中选择你要补员工卡或者机修卡的账号，点进去进行编辑，将空白卡放到读卡器上，并直接点击【读卡】替换掉原来的卡号，然后点击【确定】完成补卡。
