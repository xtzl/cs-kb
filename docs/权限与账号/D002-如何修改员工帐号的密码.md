# 操作路径

后台--设置--员工管理

# 操作步骤

如果是员工自己修改自己和密码，点击右上角的”下拉箭头“就能看到修改密码的选项

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a80435a041f9e&type=max)

如果是管理员要修改某个员工的密码，则在”员工管理“中找到对应的员工帐号，进入后直接修改为最新的密码即可

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017a80450ec81f9f&type=max)

# 注意事项

尽量不要多个员工共用一个帐号密码，当员工发生流动的时候一定要即时修改密码
