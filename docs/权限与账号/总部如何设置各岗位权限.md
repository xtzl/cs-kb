# 应用场景
当总部需要给门店的职位的权限进行新增或者编辑时，可通过此操作流程进行设置

# 操作流程
路径：登录总部后台→角色管理

点击【+新增】添加门店觉得，并在【角色类型】中选择【门店角色】，并编辑对应的门店权限以及收银台权限，完成后点击【保存】完成设置。（可通过顶部的系统自带的职位模板进行套用设置）
