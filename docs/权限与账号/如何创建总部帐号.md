# 应用场景
当总部管理员想给予总部人员建立总部权限以及总部账号时，可在总部建立相应的角色，并设置对应的账号。

# 操作流程
步骤一：设置总部角色（职位权限）

路径：登录总部后台→总部→角色管理

点击【+新增】，选择角色类型为“总部角色”，并输入角色名称，勾选下方的对应的界面权限，点击【保存】完成设置。（在顶部位置，可以选择系统默认的角色权限模板）

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721292591033-e6a9f40f-be2e-4225-8007-dbb3a35d6c6c.png)

步骤二：设置用户账号

路径：登录总部后台→总部→用户管理

点击【+新增用户】，并填写对应的账号信息，并在角色一栏选择对应的总部角色，点击【确定】完成设置。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721612069813-39644df2-db1c-4fc8-9b7f-3945b30e29e3.png)
