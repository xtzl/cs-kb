# 操作路径

后台--设置--会员设置--人脸识别

# 操作步骤

- 点击设置

- 点击会员设置

- 点击人脸识别

- 录入人脸照片

- 进行保存

![](https://kms.gzych.vip/webdoc/view/actionImg/Publoadimg.do?id=4028801e784962e1017aad419b3731fa&type=max)

# 注意事项
1、收银台保存会员相片或者会员家庭成员相片时，验证录入相片是否满足人脸识别要求，只有满足人脸识别要求时才可保存会员相片

2、如果会员已录入会员相片或者会员家庭成员相片，并且部分相片不满足人脸识别要求时，收银台读到该会员信息时显示需要修改会员相片的提示
