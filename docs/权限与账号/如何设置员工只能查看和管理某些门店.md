# 应用场景
当总部想设置部分账号只能查看或者管理指定门店时，可按照下面操作流程进行设置。

# 操作流程
路径：登录总部后台→总部→用户管理

选择需要编辑的账号，点进去。

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721292684833-c15bbec1-e963-4157-b483-c67368cfca22.png)

在角色一栏，选择对应可查看的门店及角色，点击【确定】完成编辑

![](https://cdn.nlark.com/yuque/0/2024/png/1584417/1721292739033-cf7acca0-a0b6-493a-982f-f6d4e87c3853.png)
