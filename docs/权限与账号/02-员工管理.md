# 员工权限管理

为防止员工越权操作而造成资金损失，员工的系统操作权限需要进行严格管控而且丝毫不能松懈，例如某些敏感操作需要授权才能操作或完全不允许操作。在油菜花系统中，每个菜单都可设置操作权限，从而精确控制每个员工的权限范围。

作为门店的管理者或店长，每天除了查看营业数据外，不定期的查看员工在系统中的授权操作记录也是非常重要的一项工作（只需要查看一些需要授权的敏感操作即可，不需要查看全部的操作记录）

以下是常见的要特别注意的敏感权限，设置的时候要特别注意：

后台权限

- 设置套餐或商品的权限

- 营收报表查询的权限

- 会员数据查看和导出的权限

- 设置促销活动的权限

- 后台“设置”菜单中的权限

收银台权限

- 特惠套餐售卖的权限

- 套餐或商品退货权限

- 兑换商品退货的权限

- 游戏币补币或赠币权限

- 取消活动赠送的权限

- 取消游乐扣币的权限

- 注销会员的权限

- 会员储值过户的权限

- 免补票出闸权限

- 出币异常处理（适用于实物币场地）

- 加币清币（适用于实物币场地）

# 员工绩效管理

给员工制定合理的业绩目标可以有效的刺激员工的工作积极性，员工的绩效一般从以下两个方面进行管理：

- 以销售业绩为导向：统计每个员工的销售订单，按所销售的商品获得相应的提成，有助于场地业绩的达成

- 以耗币结果为导向：统计每个员工所负责机台的耗币，按耗币金额来统计员工的收入，有助于促进顾客的储值消耗和机台耗币

可借助油菜花系统的以下功能统计员工的绩效：

- 使用导购功能

- 使用分销功能

- 机台绩效管理

- 收银绩效查询

# 员工资料管理

有些场地由于员工流动性比较大，往往会设置一些公用的帐号，例如收银帐号分别是sy01, sy02, sy03等等， 这在帐号的管理上虽然是方便了，但要注意每个帐号的密码要不一样，而且每个员工都要一个独立的帐号，这样主要是避免员工混用帐号，造成后期财务统计上分不开，出现了问题也很难追责。

在员工资料管理中，最最重要的环节是：当发生员工流动的时候，一定要及时删除或更改员工的密码。

# 员工会员卡管理制度

员工的会员卡分成两种情况：

- 用于员工个人消费和福利用途的 会员卡：一般会为员工单独设置一个会员级别，针对这个会员级别一般会有针对性的福利活动，例如每个月员工绩效达标可领100币，每个月有两次50元购买100币机会等（有些场地也会禁止员工持有会员卡，不让员工有任何接触到游戏币的机会）；一般来説，将游戏币和门票作为员工的福利更加常见一些，毕竟这些也能节省场地的一些成本。

- 用于场地工作需要的 会员卡：例如场地的机修卡，闸机管理员卡，统计机台绩效的员工卡，公共卡等；这些类型的卡都是业务上的需要而开设的，具体要根据场地的实际情况而来。
